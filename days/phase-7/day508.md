# Day 508 · 修复剩余 GitHub 问题

> Casey 在 GitHub issue tracker 上有几十个未关闭的 bug 报告。Day 508 是"清债"——批量修复剩余 issues。这不是一个单一技术主题,而是**工程实践**:bug 分类、优先级、批量处理。

## 0 · 为什么要有这一天

### 真实场景:Issue tracker 失控

让我们把镜头拉近。你跟着 Casey 做到 Day 507。HH 项目跑 500+ 天,GitHub issue tracker 累积了 ~50 个 open issues。每个 issue 都是一个"用户报告的问题"——有些是真 bug,有些是误解,有些是 feature request。

Issue 类型分布(典型开源项目):

- **Crash bug**(15%):某些操作崩溃,优先级最高。例:"加载 corrupt HHA 文件 panic"。
- **Visual glitch**(25%):渲染异常但不崩。例:"sprite 边缘锯齿"、"颜色错"。
- **UX issue**(20%):操作不直观。例:"热重载没提示"。
- **Feature request**(25%):希望加新功能。例:"支持 KTX2 纹理格式"。
- **Duplicate**(10%):重复 issue,关掉。
- **Wontfix**(5%):决定不修,关掉加说明。

如果不清理,issue tracker **失控**——50 个变 500 个,真正重要的 crash bug 淹没在 feature request 噪声里。新用户报告 issue 时,你不知道是不是已报告过。开发者打开 issue tracker,看到 500 个未分类问题,**瘫痪**——不知道从哪开始。

工业级项目(Linux kernel、Rust compiler、TensorFlow)有专门的 **issue triage team**(分类团队),每周花几小时清理。这是开源维护的核心工作。

### Issue Triage 的工程实践

**Triage**(分类)是医疗术语——急诊室医生对病人分类:重伤优先,轻伤等待。软件 issue triage 同构:

**P0(Critical)**:必须立即修。Crash、数据丢失、安全漏洞。
**P1(High)**:本周修。Visual glitch 影响体验、关键功能 bug。
**P2(Medium)**:本月修。UX 不直观、小 bug。
**P3(Low)**:有空修。Feature request、polish。
**Wontfix**:决定不修(技术原因、超 scope)。
**Duplicate**:重复(指向已有 issue)。
**Invalid**:不是 bug(用户误解)。

每个 issue 进入 triage 流程:

1. **读 issue**,理解报告者说什么
2. **复现**(reproduce)——尝试用最小步骤重现
3. **分类**——P0/P1/P2/P3/Wontfix/Duplicate/Invalid
4. **打标签**(label)——bug、enhancement、crash、graphics
5. **指派**(assign)——给合适的人
6. **里程碑**(milestone)——计划哪个版本修

这是**项目管理的日常**。开源项目维护者大部分时间花在这。

### MCVE:最小可复现案例

工业级 bug 报告的标准:**MCVE(Minimal Complete Verifiable Example)**。

报告 bug 时,用户常贴整个项目:"我的游戏 crash 了,这是 50k 行代码"。开发者打开看,半天找不到问题。

MCVE 要求:
- **Minimal**(最小):只保留触发 bug 的最少代码。100 行内。
- **Complete**(完整):可以独立运行,不依赖用户的私有数据。
- **Verifiable**(可验证):开发者跑一遍就能看到 bug。

例:

**糟糕的报告**:"游戏崩了,救命。" (无信息)

**好的报告**:
```
Title: Crash when loading HHA with empty bitmap section

Reproduce:
1. Create HHA with empty [bitmaps] section
2. Run game with --load test.hha
3. Game panics

Backtrace:
thread 'main' panicked at 'index out of bounds: len=0, index=0',
src/asset_loader.rs:42

MCVE: https://github.com/user/hh-mcve/tree/crash-empty-bitmaps
```

这个报告:具体 reproduce 步骤、backtrace、最小复现代码。开发者 5 分钟内能开始 debug。

**Stack Overflow 的 MCVE 标准**:发问题前必读。社区会拒绝不符合 MCVE 的问题。

## 2 · 心智模型

### 类比:花园除草

花园(代码库)总有杂草(bug)。不除草,杂草淹没蔬菜。

Issue triage 是除草:

- 拔大草(crash bug,优先)
- 拔小草(glitch,中)
- 修剪花边(UX,低)
- 区分杂草和花(feature vs bug,不拔花)

每周除草一次,花园整洁。半年不除,失控。

### Bug 分类学

| 类别 | 症状 | 严重度 | 案例 |
|---|---|---|---|
| Crash | 程序退出 | P0 | 解引用空指针 |
| Data loss | 数据被破坏 | P0 | 写文件不全 |
| Security | 安全漏洞 | P0 | 缓冲区溢出 |
| Glitch | 视觉异常 | P1 | 颜色错 |
| Performance | 卡顿 | P1 | GC spike |
| UX | 体验差 | P2 | 操作繁琐 |
| Feature | 缺功能 | P3 | 期望新行为 |

### MCVE:最小可复现

**M**inimal **C**omplete **V**erifiable **E**xample。

修 bug 第一步:写 MCVE。从 issue 描述提炼出最小代码,稳定复现 bug。

MCVE 要求:

- **Minimal**:删掉无关代码,只留触发 bug 的最小集
- **Complete**:可独立运行,不依赖大量环境
- **Verifiable**:每次跑都重现 bug
- **Example**:具体代码,不是抽象描述

无 MCVE 的 bug 难修——你不知道是不是真的复现了。

### Bug 生命周期

```
[Reported] → [Triaged] → [Reproduced] → [In Progress] → [Fixed] → [Verified] → [Closed]
```

每个状态有 owner。Reporter(报告者)、Triager(分类者)、Assignee(修复者)、Reviewer(审查者)。

GitHub 用 label 表达状态:`bug`、`crash`、`P0`、`in-progress`、`needs-repro`。

### 修复的策略

**Fix forward**:从头改(彻底),适合根因清晰的 bug。
**Workaround**:绕过(临时),适合紧急。
**Revert**:回滚(临时),适合新引入的 bug。
**Document**:文档说明(不修),适合 wontfix。

Casey Day 508 大多用 fix forward。

### Lv1 · 概念辨析

**题**:为什么 MCVE 是修 bug 的关键?

**参考解答**:三个理由:

第一,**隔离**。Bug 可能在复杂交互中触发。MCVE 删无关代码,暴露真正触发条件。

第二,**可验证**。MCVE 每次跑都重现 bug。修复后跑 MCVE 验证 bug 消失。否则你不知道修复是否生效。

第三,**沟通**。Reporter 给 Assignee MCVE,后者立即理解问题。无 MCVE 的 bug 报告像"程序卡了"——无法 debug。

MCVE 是 bug 报告的"可执行规范"。

**题**:写一个 mock issue tracker。模拟 5 个 issue,每个有 severity、status。实现 triage 函数:按 severity 排序,显示。

完成标准:`cargo run` 输出排序后的 issue 列表。

**参考解答**:

```rust
use std::collections::HashMap;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
enum Severity { P0, P1, P2, P3 }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum Status { Open, InProgress, Fixed, Wontfix, Duplicate }

#[derive(Debug, Clone)]
struct Issue {
    id: u32,
    title: String,
    severity: Severity,
    status: Status,
    assignee: Option<String>,
}

struct IssueTracker {
    issues: HashMap<u32, Issue>,
    next_id: u32,
}

impl IssueTracker {
    fn new() -> Self { Self { issues: HashMap::new(), next_id: 1 } }
    
    fn add(&mut self, title: &str, severity: Severity) -> u32 {
        let id = self.next_id;
        self.next_id += 1;
        self.issues.insert(id, Issue {
            id, title: title.into(), severity,
            status: Status::Open, assignee: None,
        });
        id
    }
    
    fn start_fix(&mut self, id: u32, assignee: &str) {
        if let Some(i) = self.issues.get_mut(&id) {
            i.status = Status::InProgress;
            i.assignee = Some(assignee.into());
        }
    }
    
    fn close_fixed(&mut self, id: u32) {
        if let Some(i) = self.issues.get_mut(&id) {
            i.status = Status::Fixed;
        }
    }
    
    fn close_wontfix(&mut self, id: u32) {
        if let Some(i) = self.issues.get_mut(&id) {
            i.status = Status::Wontfix;
        }
    }
    
    fn close_duplicate(&mut self, id: u32) {
        if let Some(i) = self.issues.get_mut(&id) {
            i.status = Status::Duplicate;
        }
    }
    
    fn triage(&self) -> Vec<&Issue> {
        let mut open: Vec<&Issue> = self.issues.values()
            .filter(|i| i.status == Status::Open || i.status == Status::InProgress)
            .collect();
        open.sort_by(|a, b| a.severity.cmp(&b.severity));
        open
    }
    
    fn stats(&self) -> (usize, usize, usize) {
        let open = self.issues.values().filter(|i| i.status == Status::Open).count();
        let in_progress = self.issues.values().filter(|i| i.status == Status::InProgress).count();
        let fixed = self.issues.values().filter(|i| i.status == Status::Fixed).count();
        (open, in_progress, fixed)
    }
}

fn main() {
    let mut tracker = IssueTracker::new();
    
    // 添加 5 个 issues
    let i1 = tracker.add("加载老 HHA crash", Severity::P0);
    let i2 = tracker.add("删除最后一个 piece crash", Severity::P0);
    let i3 = tracker.add("sRGB 颜色错", Severity::P1);
    let i4 = tracker.add("UI panel 重叠点击穿透", Severity::P1);
    let i5 = tracker.add("热重载 mmap 撕裂", Severity::P0);
    let i6 = tracker.add("键盘快捷键文档不全", Severity::P3);
    let i7 = tracker.add("重复 - 加载 crash", Severity::P3);
    
    println!("=== Triage 排序 ===\n");
    for issue in tracker.triage() {
        println!("  #{:<3} [{:?}] {}", issue.id, issue.severity, issue.title);
    }
    
    println!("\n=== 修复过程 ===\n");
    
    tracker.start_fix(i1, "casey");
    println!("开始修 #{} (assigned: casey)", i1);
    
    tracker.close_fixed(i1);
    println!("关闭 #{} (fixed)", i1);
    
    tracker.close_fixed(i2);
    println!("关闭 #{} (fixed)", i2);
    
    tracker.close_fixed(i5);
    println!("关闭 #{} (fixed)", i5);
    
    tracker.close_duplicate(i7);
    println!("关闭 #{} (duplicate of #{})", i7, i1);
    
    tracker.close_wontfix(i6);
    println!("关闭 #{} (wontfix)", i6);
    
    println!("\n=== Triage 修复后 ===\n");
    for issue in tracker.triage() {
        println!("  #{:<3} [{:?}] [{}] {}", issue.id, issue.severity,
                 issue.status_as_str(), issue.title);
    }
    
    let (open, in_progress, fixed) = tracker.stats();
    println!("\nStats: open={}, in_progress={}, fixed={}", open, in_progress, fixed);
}

impl Issue {
    fn status_as_str(&self) -> &'static str {
        match self.status {
            Status::Open => "OPEN",
            Status::InProgress => "IN_PROG",
            Status::Fixed => "FIXED",
            Status::Wontfix => "WONTFIX",
            Status::Duplicate => "DUP",
        }
    }
}
```

## 8 · Rust / Arch 落地代码

下面是 Day 508 完整的 issue tracker 系统。

```rust
// (基于 Lv2,加完整测试和更多功能)

use std::collections::HashMap;
use std::fmt;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
enum Severity { P0, P1, P2, P3 }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
enum Status { Open, InProgress, Fixed, Wontfix, Duplicate, Closed }

impl fmt::Display for Status {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        let s = match self {
            Status::Open => "OPEN",
            Status::InProgress => "IN_PROG",
            Status::Fixed => "FIXED",
            Status::Wontfix => "WONTFIX",
            Status::Duplicate => "DUP",
            Status::Closed => "CLOSED",
        };
        write!(f, "{}", s)
    }
}

#[derive(Debug, Clone)]
struct Label(String);

#[derive(Debug, Clone)]
struct Issue {
    id: u32,
    title: String,
    description: String,
    severity: Severity,
    status: Status,
    assignee: Option<String>,
    labels: Vec<Label>,
    reporter: String,
    created_at: u64,
    mcve: Option<String>,
}

impl Issue {
    fn new(id: u32, title: &str, severity: Severity, reporter: &str) -> Self {
        Self {
            id, title: title.into(), description: String::new(),
            severity, status: Status::Open,
            assignee: None, labels: Vec::new(),
            reporter: reporter.into(),
            created_at: 0,
            mcve: None,
        }
    }
    
    fn with_mcve(mut self, mcve: &str) -> Self {
        self.mcve = Some(mcve.into());
        self
    }
    
    fn with_label(mut self, label: &str) -> Self {
        self.labels.push(Label(label.into()));
        self
    }
}

struct IssueTracker {
    issues: HashMap<u32, Issue>,
    next_id: u32,
    current_time: u64,
}

impl IssueTracker {
    fn new() -> Self { Self { issues: HashMap::new(), next_id: 1, current_time: 0 } }
    
    fn tick(&mut self) { self.current_time += 1; }
    
    fn add(&mut self, title: &str, severity: Severity, reporter: &str) -> u32 {
        let id = self.next_id;
        self.next_id += 1;
        let mut issue = Issue::new(id, title, severity, reporter);
        issue.created_at = self.current_time;
        self.issues.insert(id, issue);
        id
    }
    
    fn get_mut(&mut self, id: u32) -> Option<&mut Issue> { self.issues.get_mut(&id) }
    
    fn assign(&mut self, id: u32, who: &str) {
        if let Some(i) = self.issues.get_mut(&id) {
            i.assignee = Some(who.into());
            if i.status == Status::Open {
                i.status = Status::InProgress;
            }
        }
    }
    
    fn close(&mut self, id: u32, status: Status) {
        if let Some(i) = self.issues.get_mut(&id) {
            i.status = status;
        }
    }
    
    fn triage_sorted(&self) -> Vec<&Issue> {
        let mut v: Vec<&Issue> = self.issues.values()
            .filter(|i| matches!(i.status, Status::Open | Status::InProgress))
            .collect();
        v.sort_by(|a, b| {
            a.severity.cmp(&b.severity)
                .then_with(|| a.created_at.cmp(&b.created_at))
        });
        v
    }
    
    fn filter_by_label(&self, label: &str) -> Vec<&Issue> {
        self.issues.values()
            .filter(|i| i.labels.iter().any(|l| l.0 == label))
            .collect()
    }
    
    fn stats(&self) -> Stats {
        let mut s = Stats::default();
        for i in self.issues.values() {
            match i.status {
                Status::Open => s.open += 1,
                Status::InProgress => s.in_progress += 1,
                Status::Fixed => s.fixed += 1,
                Status::Wontfix => s.wontfix += 1,
                Status::Duplicate => s.duplicate += 1,
                Status::Closed => s.closed += 1,
            }
        }
        s
    }
}

#[derive(Default)]
struct Stats {
    open: usize,
    in_progress: usize,
    fixed: usize,
    wontfix: usize,
    duplicate: usize,
    closed: usize,
}

impl fmt::Display for Stats {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "open={}, in_progress={}, fixed={}, wontfix={}, duplicate={}",
               self.open, self.in_progress, self.fixed, self.wontfix, self.duplicate)
    }
}

fn main() {
    println!("=============================================\n");
    println!(" Day 508 · 修复剩余 GitHub Issues\n");
    println!("=============================================\n");
    
    let mut tracker = IssueTracker::new();
    
    // 模拟 issue tracker
    let issues_data = vec![
        ("加载老 HHA crash", Severity::P0, "alice", Some("load_old_hha() panic")),
        ("删除最后 piece crash", Severity::P0, "bob", Some("pop on empty vec")),
        ("热重载 mmap 撕裂", Severity::P0, "alice", None),
        ("sRGB 颜色错", Severity::P1, "carol", Some("linear to sRGB")),
        ("UI 点击穿透", Severity::P1, "bob", None),
        ("字体模糊", Severity::P2, "dave", None),
        ("快捷键文档不全", Severity::P3, "erin", None),
        ("重复: HHA crash", Severity::P3, "alice", None),
    ];
    
    let mut ids = Vec::new();
    for (title, sev, reporter, mcve) in issues_data {
        tracker.tick();
        let id = tracker.add(title, sev, reporter);
        if let Some(m) = mcve {
            if let Some(i) = tracker.get_mut(id) {
                i.mcve = Some(m.into());
            }
        }
        ids.push(id);
    }
    
    println!("=== 初始 triage ===\n");
    for issue in tracker.triage_sorted() {
        let mcve_marker = if issue.mcve.is_some() { "MCVE" } else { "    " };
        println!("  #{:<3} [{:?}] {} {}", issue.id, issue.severity, mcve_marker, issue.title);
    }
    
    println!("\nStats: {}\n", tracker.stats());
    
    println!("=== 修复过程(模拟 Day 508)===");
    
    // P0 优先
    let p0s: Vec<u32> = tracker.triage_sorted().iter()
        .filter(|i| i.severity == Severity::P0)
        .map(|i| i.id)
        .collect();
    
    for id in &p0s {
        tracker.assign(*id, "casey");
        println!("→ 修复 #{} (assigned: casey)", id);
        tracker.close(*id, Status::Fixed);
        println!("  ✓ #{} fixed", id);
    }
    
    // Duplicate 关闭
    tracker.close(ids[7], Status::Duplicate);
    println!("→ #{} 是 #{} 的重复,关闭", ids[7], ids[0]);
    
    // Wontfix
    tracker.close(ids[6], Status::Wontfix);
    println!("→ #{} wontfix(快捷键文档,优先级低)", ids[6]);
    
    // P1 修
    let p1s: Vec<u32> = tracker.triage_sorted().iter()
        .filter(|i| i.severity == Severity::P1)
        .map(|i| i.id)
        .collect();
    
    for id in &p1s {
        tracker.close(*id, Status::Fixed);
        println!("→ ✓ #{} fixed", id);
    }
    
    println!("\n=== 修复后 triage(剩余 open)===");
    let remaining = tracker.triage_sorted();
    if remaining.is_empty() {
        println!("(全部清空!)");
    } else {
        for issue in remaining {
            println!("  #{:<3} [{:?}] {}", issue.id, issue.severity, issue.title);
        }
    }
    
    println!("\nStats: {}", tracker.stats());
    
    // Release notes
    println!("\n=== Release Notes(Day 508)===");
    println!("Fixed {} P0 crashes:", p0s.len());
    for id in &p0s {
        if let Some(i) = tracker.issues.get(id) {
            println!("  - #{}: {}", id, i.title);
        }
    }
    println!("Closed {} duplicates, {} wontfix, fixed {} P1 issues",
             tracker.stats().duplicate, tracker.stats().wontfix, 2);
}
```
