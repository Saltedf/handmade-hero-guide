## 2 · 心智模型

### 类比:乐高城市的自动生成

想象程序自动生成乐高城市。早期只能生成平房。Day 502 加"楼梯",让生成器能造两层楼。

加楼梯后:

- 生成器有时生成两层楼(30% 概率)
- 楼梯连接两层
- 玩家走楼梯上下

数据结构必须支持——`Room` 加 `connected_rooms: Vec<(Stair, RoomId)>`,记录"我有哪些楼梯连到哪些房间"。

### Procedural Generation 扩展性

程序生成(procedural generation)是游戏设计的核心。Minecraft 的世界、《Spelunky》的关卡、《Caves of Qud》的迷宫,都是程序生成。

生成器的基本架构:

```
1. 决定房间大小、形状
2. 放置墙、地板
3. 放置门、窗
4. 放置家具、怪物、宝箱
5. (Day 502 新增)放置楼梯
6. 连接其他房间
```

每个"放置"步骤是 generator 的一个 module。加楼梯 = 加 module。

可扩展性好的 generator:加新 module 不需要改老 module。Casey Day 502 验证 HH generator 的可扩展性。

### 房间 / 楼梯的关系

多层地图的拓扑:

```
Room A (一层)
  ↓ 楼梯 down
Room B (二层)
  ↓ 楼梯 down
Room C (三层)
```

每个 Room 有 `connected_rooms`,记录所有连通的房间(用门或楼梯)。

楼梯的"方向":Up(往上)、Down(往下)、Both(双向)。

### 楼梯位置约束

楼梯不能随便放。约束:

- 不能在墙里(必须是空地)
- 不能挡门(门口前后 1 格不能放楼梯)
- 不能重叠(已有楼梯位置不能再放)
- 楼梯前后必须有路(玩家能走到)

实现:`is_valid_stair_position(room, pos) -> bool`,检查所有约束。

### 楼梯渲染

楼梯是 sprite,但比一般 sprite 复杂——有"上"和"下"两种 sprite,玩家走上去时画面要切换层。

简化:Casey Day 502 只画一个标记性 sprite(箭头),实际"上下"逻辑用数据驱动。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 generator 用 `rng.gen::<f32>() < probability` 而不是直接 `rng.gen_bool(0.3)`?

**参考解答**:两者等价,但 `gen::<f32>() < p` 更灵活:

- 可以用任意概率(0.0 到 1.0)
- 可以叠加多个概率(`if rng.gen::<f32>() < 0.3` Up,else if `< 0.6` Down)
- 数学上等价于均匀分布的百分位

`gen_bool(0.3)` 是 `gen::<f32>() < 0.3` 的语法糖。两者性能一样。

Casey 风格倾向显式:用 `gen::<f32>()`,表达"概率"的概念更清晰。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:实现房间生成器,加楼梯模块。给定 10x10 房间,30% 概率放楼梯。验证 1000 次生成,统计楼梯出现率。

完成标准:`cargo run` 输出 1000 次生成中,楼梯出现次数约 300。

**参考解答**:

```rust
use rand::Rng;

#[derive(Debug, Clone, Copy, PartialEq)]
enum Tile {
    Floor,
    Wall,
    Door,
    Stair(StairDirection),
}

#[derive(Debug, Clone, Copy, PartialEq)]
enum StairDirection { Up, Down }

#[derive(Debug, Clone)]
struct Room {
    width: u32,
    height: u32,
    tiles: Vec<Tile>,
    stairs: Vec<(u32, u32, StairDirection)>,
}

impl Room {
    fn new(width: u32, height: u32) -> Self {
        let mut tiles = vec![Tile::Floor; (width * height) as usize];
        // 边缘是墙
        for x in 0..width {
            tiles[x as usize] = Tile::Wall;    // 上边
            tiles[((height - 1) * width + x) as usize] = Tile::Wall;    // 下边
        }
        for y in 0..height {
            tiles[(y * width) as usize] = Tile::Wall;    // 左边
            tiles[(y * width + width - 1) as usize] = Tile::Wall;    // 右边
        }
        Self { width, height, tiles, stairs: Vec::new() }
    }
    
    fn get(&self, x: u32, y: u32) -> Tile {
        self.tiles[(y * self.width + x) as usize]
    }
    
    fn set(&mut self, x: u32, y: u32, tile: Tile) {
        self.tiles[(y * self.width + x) as usize] = tile;
    }
    
    fn is_valid_stair_pos(&self, x: u32, y: u32) -> bool {
        if x < 1 || x >= self.width - 1 || y < 1 || y >= self.height - 1 {
            return false;    // 不能在边缘
        }
        if self.get(x, y) != Tile::Floor {
            return false;    // 必须是地板
        }
        // 不能靠近已有楼梯
        for (sx, sy, _) in &self.stairs {
            let dx = (*sx as i32 - x as i32).abs();
            let dy = (*sy as i32 - y as i32).abs();
            if dx + dy < 3 { return false; }
        }
        true
    }
}

struct RoomGenerator {
    stair_probability: f32,
}

impl RoomGenerator {
    fn new(stair_prob: f32) -> Self {
        Self { stair_probability: stair_prob }
    }
    
    fn generate(&self, rng: &mut impl Rng) -> Room {
        let mut room = Room::new(10, 10);
        self.place_stairs(&mut room, rng);
        room
    }
    
    fn place_stairs(&self, room: &mut Room, rng: &mut impl Rng) {
        if rng.gen::<f32>() >= self.stair_probability {
            return;
        }
        
        // 尝试最多 10 次找有效位置
        for _ in 0..10 {
            let x = rng.gen_range(1..room.width - 1);
            let y = rng.gen_range(1..room.height - 1);
            
            if room.is_valid_stair_pos(x, y) {
                let direction = if rng.gen() { StairDirection::Up } else { StairDirection::Down };
                room.set(x, y, Tile::Stair(direction));
                room.stairs.push((x, y, direction));
                return;
            }
        }
    }
}

fn main() {
    let mut rng = rand::thread_rng();
    let generator = RoomGenerator::new(0.3);
    
    println!("=============================================\n");
    println!(" Day 502 · 为生成器添加楼梯\n");
    println!("=============================================\n");
    
    println!("=== 单次生成示例 ===\n");
    let room = generator.generate(&mut rng);
    println!("room: {}x{}", room.width, room.height);
    println!("stairs: {:?}", room.stairs);
    
    // ASCII 渲染
    for y in 0..room.height {
        for x in 0..room.width {
            let c = match room.get(x, y) {
                Tile::Floor => '.',
                Tile::Wall => '#',
                Tile::Door => 'D',
                Tile::Stair(StairDirection::Up) => '<',
                Tile::Stair(StairDirection::Down) => '>',
            };
            print!("{}", c);
        }
        println!();
    }
    
    println!("\n=== 统计:1000 次生成 ===\n");
    let mut with_stair = 0;
    let mut total = 0;
    for _ in 0..1000 {
        let room = generator.generate(&mut rng);
        if !room.stairs.is_empty() {
            with_stair += 1;
        }
        total += 1;
    }
    println!("total={}, with_stair={} ({:.1}%)",
             total, with_stair, with_stair as f32 / total as f32 * 100.0);
    println!("预期约 30%");
    
    println!("\n=== 不同概率 ===\n");
    for prob in [0.0, 0.1, 0.3, 0.5, 0.7, 1.0] {
        let gen = RoomGenerator::new(prob);
        let mut count = 0;
        for _ in 0..1000 {
            let r = gen.generate(&mut rng);
            if !r.stairs.is_empty() {
                count += 1;
            }
        }
        println!("probability={:.1}: 实际 {:.1}% ({} / 1000)",
                 prob, count as f32 / 10.0, count);
    }
}
```

```rust
// ============================================================
// Day 502 · 为生成器添加楼梯
// ============================================================

use rand::Rng;
use std::fmt;

// ============================================================
// Tiles & entities
// ============================================================

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum Tile {
    Floor,
    Wall,
    Door,
    StairUp,
    StairDown,
}

impl fmt::Display for Tile {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        let c = match self {
            Tile::Floor => '.',
            Tile::Wall => '#',
            Tile::Door => 'D',
            Tile::StairUp => '<',
            Tile::StairDown => '>',
        };
        write!(f, "{}", c)
    }
}

#[derive(Debug, Clone)]
struct Stair {
    x: u32,
    y: u32,
    direction: StairDirection,
    target_room: u32,    // 连到哪个 room
}

#[derive(Debug, Clone, Copy, PartialEq)]
enum StairDirection { Up, Down }

#[derive(Debug, Clone)]
struct Door {
    x: u32, y: u32,
    target_room: u32,
    target_x: u32, target_y: u32,
}

#[derive(Debug, Clone)]
struct Room {
    id: u32,
    width: u32,
    height: u32,
    tiles: Vec<Tile>,
    doors: Vec<Door>,
    stairs: Vec<Stair>,
}

impl Room {
    fn new(id: u32, width: u32, height: u32) -> Self {
        let mut tiles = vec![Tile::Floor; (width * height) as usize];
        for x in 0..width {
            tiles[x as usize] = Tile::Wall;
            tiles[((height - 1) * width + x) as usize] = Tile::Wall;
        }
        for y in 0..height {
            tiles[(y * width) as usize] = Tile::Wall;
            tiles[(y * width + width - 1) as usize] = Tile::Wall;
        }
        Self { id, width, height, tiles, doors: Vec::new(), stairs: Vec::new() }
    }
    
    fn get(&self, x: u32, y: u32) -> Tile {
        self.tiles[(y * self.width + x) as usize]
    }
    
    fn set(&mut self, x: u32, y: u32, tile: Tile) {
        self.tiles[(y * self.width + x) as usize] = tile;
    }
    
    fn is_valid_stair_pos(&self, x: u32, y: u32) -> bool {
        if x < 1 || x >= self.width - 1 || y < 1 || y >= self.height - 1 {
            return false;
        }
        if self.get(x, y) != Tile::Floor {
            return false;
        }
        // 远离门
        for d in &self.doors {
            let dist = (d.x as i32 - x as i32).abs() + (d.y as i32 - y as i32).abs();
            if dist < 2 { return false; }
        }
        // 远离其他楼梯
        for s in &self.stairs {
            let dist = (s.x as i32 - x as i32).abs() + (s.y as i32 - y as I32).abs();
            if dist < 3 { return false; }
        }
        true
    }
    
    fn render_ascii(&self) -> String {
        let mut s = String::new();
        for y in 0..self.height {
            for x in 0..self.width {
                s.push_str(&format!("{}", self.get(x, y)));
            }
            s.push('\n');
        }
        s
    }
}

impl Room {
    fn is_valid_stair_pos_fixed(&self, x: u32, y: u32) -> bool {
        if x < 1 || x >= self.width - 1 || y < 1 || y >= self.height - 1 {
            return false;
        }
        if self.get(x, y) != Tile::Floor {
            return false;
        }
        for d in &self.doors {
            let dist = (d.x as i32 - x as i32).abs() + (d.y as i32 - y as i32).abs();
            if dist < 2 { return false; }
        }
        for s in &self.stairs {
            let dist = (s.x as i32 - x as i32).abs() + (s.y as i32 - y as i32).abs();
            if dist < 3 { return false; }
        }
        true
    }
}

struct GeneratorConfig {
    room_min_size: u32,
    room_max_size: u32,
    stair_probability: f32,
    door_probability: f32,
}

impl Default for GeneratorConfig {
    fn default() -> Self {
        Self {
            room_min_size: 8,
            room_max_size: 12,
            stair_probability: 0.3,
            door_probability: 0.5,
        }
    }
}

struct RoomGenerator {
    config: GeneratorConfig,
}

impl RoomGenerator {
    fn new(config: GeneratorConfig) -> Self { Self { config } }
    
    fn generate(&self, rng: &mut impl Rng, room_id: u32) -> Room {
        let w = rng.gen_range(self.config.room_min_size..=self.config.room_max_size);
        let h = rng.gen_range(self.config.room_min_size..=self.config.room_max_size);
        let mut room = Room::new(room_id, w, h);
        
        self.place_doors(&mut room, rng);
        self.place_stairs(&mut room, rng);
        
        room
    }
    
    fn place_doors(&self, room: &mut Room, rng: &mut impl Rng) {
        if rng.gen::<f32>() >= self.config.door_probability {
            return;
        }
        
        // 简化:在右边墙中部放一个门
        let y = room.height / 2;
        let x = room.width - 1;
        room.set(x, y, Tile::Door);
        room.doors.push(Door {
            x, y, target_room: 0,
            target_x: 1, target_y: y,
        });
    }
    
    fn place_stairs(&self, room: &mut Room, rng: &mut impl Rng) {
        if rng.gen::<f32>() >= self.config.stair_probability {
            return;
        }
        
        // 尝试 10 次找有效位置
        for _ in 0..10 {
            let x = rng.gen_range(1..room.width - 1);
            let y = rng.gen_range(1..room.height - 1);
            
            if room.is_valid_stair_pos_fixed(x, y) {
                let direction = if rng.gen() { StairDirection::Up } else { StairDirection::Down };
                let tile = match direction {
                    StairDirection::Up => Tile::StairUp,
                    StairDirection::Down => Tile::StairDown,
                };
                room.set(x, y, tile);
                room.stairs.push(Stair {
                    x, y, direction, target_room: 0,
                });
                return;
            }
        }
    }
}

struct World {
    rooms: Vec<Room>,
    current_room: u32,
}

impl World {
    fn new() -> Self { Self { rooms: Vec::new(), current_room: 0 } }
    
    fn add_room(&mut self, room: Room) -> u32 {
        let id = room.id;
        self.rooms.push(room);
        id
    }
    
    fn use_stair(&mut self, stair_idx: usize) {
        if let Some(room) = self.rooms.iter_mut().find(|r| r.id == self.current_room) {
            if let Some(stair) = room.stairs.get(stair_idx) {
                let target = stair.target_room;
                println!(">> 走楼梯({:?})到 room {}", stair.direction, target);
                self.current_room = target;
            }
        }
    }
}

fn main() {
    println!("=============================================\n");
    println!(" Day 502 · 为生成器添加楼梯\n");
    println!("=============================================\n");
    
    let mut rng = rand::thread_rng();
    let gen = RoomGenerator::new(GeneratorConfig::default());
    
    // 生成 3 个房间
    let mut world = World::new();
    for i in 0..3 {
        let room = gen.generate(&mut rng, i);
        world.add_room(room);
    }
    
    // 链接房间:room0 的楼梯连到 room1,room1 的楼梯连到 room2
    if let Some(r0) = world.rooms.iter_mut().find(|r| r.id == 0) {
        for s in &mut r0.stairs {
            s.target_room = 1;
        }
    }
    if let Some(r1) = world.rooms.iter_mut().find(|r| r.id == 1) {
        for s in &mut r1.stairs {
            s.target_room = 2;
        }
    }
    
    println!("=== 生成的 3 个房间 ===\n");
    for room in &world.rooms {
        println!("Room {} ({}x{}):", room.id, room.width, room.height);
        println!("  doors: {}, stairs: {}", room.doors.len(), room.stairs.len());
        for s in &room.stairs {
            println!("    stair at ({},{}) {:?} -> room {}", s.x, s.y, s.direction, s.target_room);
        }
        print!("{}", room.render_ascii());
        println!();
    }
    
    println!("=== 统计:1000 次生成 ===\n");
    let mut with_stair = 0;
    let mut with_door = 0;
    let mut total_stairs = 0;
    
    for _ in 0..1000 {
        let room = gen.generate(&mut rng, 0);
        if !room.stairs.is_empty() { with_stair += 1; total_stairs += room.stairs.len(); }
        if !room.doors.is_empty() { with_door += 1; }
    }
    
    println!("生成 1000 个房间:");
    println!("  有楼梯的: {} ({:.1}%,预期 ~30%)",
             with_stair, with_stair as f32 / 10.0);
    println!("  有门的: {} ({:.1}%,预期 ~50%)",
             with_door, with_door as f32 / 10.0);
    println!("  楼梯总数: {}", total_stairs);
    
    println!("\n=== 模拟走楼梯 ===\n");
    println!("current room: {}", world.current_room);
    world.use_stair(0);
    println!("current room: {}", world.current_room);
    world.use_stair(0);
    println!("current room: {}", world.current_room);
}
```
