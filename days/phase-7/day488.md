### Immediate-mode UI(Editor UI 的核心)

传统 UI 工具包(retained mode)维护一棵 widget 树,每帧遍历渲染。Qt、GTK 都是。

Immediate-mode UI 每帧重新声明 UI:

```rust
fn draw_editor_ui(state: &mut State, ui: &mut Ui) {
    if ui.button("Save").clicked() {
        save_level(state);
    }
    if ui.button("Load").clicked() {
        load_level(state);
    }
    ui.slider("Speed", &mut state.speed, 0.0, 10.0);
}
```

每帧都调用,UI 看起来"持续显示",但状态都从外部数据读,UI 函数本身无状态。

优点:

- **无状态**:不用同步 widget 树和数据
- **数据驱动**:UI 直接反映外部数据,无滞后
- **易学**:写 UI 像写普通代码,不用学 widget 框架

缺点:

- **CPU 多**:每帧都重建 UI(但现代 CPU 快,可接受)
- **重绘开销**:widget 多时,每帧 layout 计算多

游戏开发几乎都选 immediate mode,因为:

- 游戏 UI 高频变化(每帧都不同)
- 程序员写代码 > 配 XML/JSON
- 性能可接受(几千 widget 没问题)

Dear ImGui 是 immediate mode UI 的标杆,Rust 等价有 `egui`。Casey 在 HH 自己写 immediate mode UI,但概念和 ImGui 一致。

### Editor 状态机

Editor 不是"持续工作",而是状态机:

```
Inactive → 按 E → Active(无选中)
Active → 鼠标点击 entity → Active(选中)
Active(选中) → 拖动 → Active(拖动中)
Active(选中) → Delete → Active(无选中,entity 删了)
Active → 按 E → Inactive
```

每个状态有不同的 update 逻辑:

```rust
match editor.state {
    EditorMode::Inactive => { /* 不处理鼠标 */ }
    EditorMode::Active => {
        if mouse_clicked {
            if let Some(id) = hit_test(mouse_pos) {
                editor.selected = Some(id);
                editor.drag_state = DragState::Pending;
            }
        }
    }
    EditorMode::Dragging(id) => {
        // 更新 entity 位置到鼠标位置
        if mouse_released {
            editor.drag_state = DragState::None;
        }
    }
}
```

这是 **state machine pattern**,工业 UI/game 都用。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏内编辑器是工业游戏开发的标配。Unity Editor、Unreal Editor、Godot Editor 都是"游戏内"的——它们自己就是用引擎本身做的(Unity Editor 用 Unity 写,Unreal Editor 用 Unreal 写)。

这种"用自己造自己"叫 **"bootstrapping"**。优势:

- 引擎功能完整用到(渲染、UI、asset)
- 编辑器和游戏共享代码,不重复实现
- 编辑器运行的代码就是游戏运行的代码,所见即所得(WYSIWYG)

Casey 的 HH 编辑器是 bootstrap 思想的简化版——他用 HH 自己的渲染、UI、entity 系统搭编辑器。

Unity/Unreal 的编辑器更复杂:

- **Inspector** 自动从 C# class 反射生成字段 UI
- **Scene view** 是另一个 camera,与 game view 独立
- **Asset pipeline** 编辑器直接调,实时预览
- **Multi-user editing** 多人同时编辑(部分支持)

Casey Day 488 做基础编辑器,理解后看 Unity/Unreal 编辑器代码能秒懂架构。

### 3.2 · 🎨 图形学视角

编辑器的图形学需求:

第一,**线条渲染**。选中 entity 的边框是线条,需要 line rendering API。OpenGL 的 `GL_LINES` 简单但慢(每个 line 一个 draw call)。工业用 `GL_LINE_STRIP` + batching。

第二,**Gizmo 渲染**。移动手柄(translate gizmo)是 3D 几何(箭头)。需要线框 / 实心混合渲染。

第三,**ID buffer**(GPU picking)。把 entity id 渲染到 offscreen buffer,鼠标位置读像素得 id。但 Casey 用 ray-AABB,不用 GPU picking。

第四,**depth override**。选中边框想"画在所有 entity 之上",不受深度测试影响。OpenGL 用 `glDisable(GL_DEPTH_TEST)` 实现。

Casey 简化:边框用普通线渲染,不做 depth override。后面如果选中被遮挡,再处理。

### 3.3 · 🐧 Linux 系统编程视角

Linux 上的"游戏内编辑器"对应是 **REPL(Read-Eval-Print Loop)**。Lisp、Python、Bash 都有 REPL——程序跑着,你输入命令,实时改状态。

Emacs 是 "self-documenting editor"——它的内部状态可被 elisp 实时修改,类似游戏内编辑器。

Linux 的 `/proc` 和 `/sys` 文件系统是"运行时编辑器"——你写 `/proc/sys/vm/swappiness` 实时改内核参数。

这些是不同领域的"游戏内编辑"思想。理解它,你看 Linux 内核调试工具(kdb、systemtap、bpftrace)能秒懂。

### 3.4 · 🦀 Rust 生态视角

Rust 里写游戏内编辑器的几个 idiomatic 选择。

第一,**`egui` crate**。Immediate-mode UI 的 Rust 实现。`egui` 在游戏里跑(集成到 wgpu / glow 后端)做 editor UI。


第二,**`bevy_egui`** Bevy 的 egui plugin。Bevy 编辑器生态用这个。

第三,**`bevy_inspector_egui`** 自动从 Rust struct 反射生成 inspector UI。Unity Inspector 的 Rust 等价。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 Casey 用 immediate-mode UI 而不是传统的 retained-mode(如 Qt)?

**参考解答**:三个理由:

第一,**数据同步**。Retained mode 维护 widget 树,必须和数据同步——数据变,widget 树要更新。同步代码复杂、易错。Immediate mode 每帧从数据重建 widget,永远同步。

第二,**性能足够**。Editor UI 通常几百到几千 widget,immediate mode 每帧重建 CPU 开销小(微秒级)。Retained mode 优势在百万级 widget,editor 用不到。

第三,**编程模型简单**。Immediate mode 像"声明式"代码:

```rust
if ui.button("Save").clicked() { save(); }
```

Retained mode 像"OO"代码:

```rust
let btn = Button::new("Save");
btn.on_click(|_| save());
layout.add(btn);
// 必须保留 btn 引用,某处 dispose
```

Immediate mode 写起来直觉,不漏 dispose,没有 widget 树同步 bug。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:实现一个简化的 game editor。状态:`EditorMode::Inactive` 和 `EditorMode::Active`。Active 时按 E 切回 Inactive。Active 时点击屏幕坐标(用 Day 487 的 hit test)选中 entity,显示"selected: entity N"。再加 immediate-mode UI:按 S 显示"Saving..."。

完成标准:命令行模拟——输入 `e`、`click 100 200`、`s` 等命令,看 editor 响应。

**参考解答**:

```rust
use std::io::{self, BufRead, Write};

#[derive(Debug, Clone, Copy, PartialEq)]
enum EditorMode {
    Inactive,
    Active,
}

#[derive(Debug, Clone)]
struct Entity {
    id: u32,
    name: String,
    pos: (f32, f32, f32),
    aabb_min: (f32, f32, f32),
    aabb_max: (f32, f32, f32),
}

struct Editor {
    mode: EditorMode,
    selected: Option<u32>,
    entities: Vec<Entity>,
}

impl Editor {
    fn new() -> Self {
        Self {
            mode: EditorMode::Inactive,
            selected: None,
            entities: vec![
                Entity {
                    id: 1, name: "hero".to_string(),
                    pos: (0.0, 0.0, 0.0),
                    aabb_min: (-10.0, -10.0, -10.0),
                    aabb_max: (10.0, 10.0, 10.0),
                },
                Entity {
                    id: 2, name: "goblin".to_string(),
                    pos: (50.0, 0.0, 0.0),
                    aabb_min: (45.0, -5.0, -5.0),
                    aabb_max: (55.0, 5.0, 5.0),
                },
                Entity {
                    id: 3, name: "chest".to_string(),
                    pos: (0.0, 50.0, 0.0),
                    aabb_min: (-5.0, 45.0, -5.0),
                    aabb_max: (5.0, 55.0, 5.0),
                },
            ],
        }
    }
    
    fn toggle_mode(&mut self) {
        self.mode = match self.mode {
            EditorMode::Inactive => EditorMode::Active,
            EditorMode::Active => EditorMode::Inactive,
        };
        if self.mode == EditorMode::Inactive {
            self.selected = None;   // 退出编辑模式清空选中
        }
        println!("Mode: {:?}", self.mode);
    }
    
    fn click(&mut self, x: f32, y: f32) {
        if self.mode != EditorMode::Active {
            println!("(Editor inactive, ignore click)");
            return;
        }
        
        // 简化 hit test:在 2D 平面找包含 (x, y) 的 entity
        // 假装射线从 (x, y, +∞) 朝 -Z
        let mut hit: Option<u32> = None;
        for e in &self.entities {
            if x >= e.aabb_min.0 && x <= e.aabb_max.0 &&
               y >= e.aabb_min.1 && y <= e.aabb_max.1 {
                hit = Some(e.id);
                break;   // 第一个命中即可(简化,应该选最近的)
            }
        }
        
        match hit {
            Some(id) => {
                self.selected = Some(id);
                let e = self.entities.iter().find(|e| e.id == id).unwrap();
                println!("Selected: entity {} ({}) at {:?}", id, e.name, e.pos);
            }
            None => {
                self.selected = None;
                println!("Click at ({}, {}): no entity hit", x, y);
            }
        }
    }
    
    fn save(&self) {
        // Immediate-mode UI:假装弹一个 dialog
        println!("[UI] Save dialog opened");
        println!("[UI] Saving {} entities...", self.entities.len());
        for e in &self.entities {
            println!("  - {} {}: pos {:?}", e.name, e.id, e.pos);
        }
        println!("[UI] Saved.");
    }
    
    fn draw_overlay(&self) {
        if self.mode != EditorMode::Active {
            return;
        }
        
        println!("\n=== Editor Overlay ===");
        println!("Mode: Active");
        match self.selected {
            Some(id) => {
                let e = self.entities.iter().find(|e| e.id == id).unwrap();
                println!("Selected: {} (id={})", e.name, e.id);
                println!("Inspector:");
                println!("  Position: ({}, {}, {})", e.pos.0, e.pos.1, e.pos.2);
                println!("  AABB: {:?} .. {:?}", e.aabb_min, e.aabb_max);
            }
            None => println!("Selected: none"),
        }
        println!("Palette: [1] Goblin  [2] Chest  [3] Torch");
        println!("[S] Save  [E] Exit editor");
        println!("======================\n");
    }
}

fn main() {
    let mut editor = Editor::new();
    let stdin = io::stdin();
    
    println!("=== Game Editor ===");
    println!("Commands: e (toggle editor), click <x> <y>, s (save), q (quit)");
    println!();
    
    loop {
        // 模拟每帧渲染
        editor.draw_overlay();
        
        print!("> ");
        io::stdout().flush().unwrap();
        
        let mut line = String::new();
        if stdin.lock().read_line(&mut line).unwrap() == 0 {
            break;   // EOF
        }
        
        let line = line.trim();
        let parts: Vec<&str> = line.split_whitespace().collect();
        
        if parts.is_empty() { continue; }
        
        match parts[0] {
            "q" | "quit" => break,
            "e" | "edit" => editor.toggle_mode(),
            "s" | "save" => {
                if editor.mode == EditorMode::Active {
                    editor.save();
                } else {
                    println!("(Editor inactive, cannot save)");
                }
            }
            "click" if parts.len() == 3 => {
                let x: f32 = parts[1].parse().unwrap_or(0.0);
                let y: f32 = parts[2].parse().unwrap_or(0.0);
                editor.click(x, y);
            }
            "list" => {
                println!("Entities:");
                for e in &editor.entities {
                    let selected = if Some(e.id) == editor.selected { " ← selected" } else { "" };
                    println!("  [{}] {} at {:?}{}", e.id, e.name, e.pos, selected);
                }
            }
            _ => println!("Unknown command: {}", line),
        }
    }
    
    println!("Bye");
}
```

为什么这么写:`draw_overlay` 是 immediate-mode UI 的模拟——每次调用都"重新声明"UI,状态从外部数据读。这就是 ImGui / egui 的核心思想。

```rust
use std::collections::HashMap;

// ========================================
// 数据结构
// ========================================

#[derive(Copy, Clone, Debug, PartialEq, Eq)]
enum EditorMode {
    Inactive,
    Active,
}

#[derive(Copy, Clone, Debug, PartialEq, Eq)]
enum DragState {
    None,
    Pending,      // 鼠标按下但还没移动
    Dragging,     // 正在拖动
}

#[derive(Debug, Clone)]
struct Entity {
    id: u32,
    name: String,
    pos: [f32; 3],
    tags: Vec<String>,
}

#[derive(Debug, Clone)]
struct EntityClass {
    name: String,        // 类别名("goblin")
    default_tags: Vec<String>,
    default_size: [f32; 3],
}

// ========================================
// Editor 状态
// ========================================

struct Editor {
    mode: EditorMode,
    selected: Option<u32>,
    drag_state: DragState,
    drag_offset: [f32; 3],
    entities: Vec<Entity>,
    palette: Vec<EntityClass>,
    next_id: u32,
    
    // 简化:记录每帧的 UI 事件
    last_action: String,
}

impl Editor {
    fn new() -> Self {
        Self {
            mode: EditorMode::Inactive,
            selected: None,
            drag_state: DragState::None,
            drag_offset: [0.0; 3],
            entities: vec![
                Entity { id: 1, name: "hero".into(), pos: [0.0; 3], tags: vec!["character".into()] },
                Entity { id: 2, name: "goblin_1".into(), pos: [50.0, 0.0, 0.0], tags: vec!["enemy".into()] },
                Entity { id: 3, name: "chest_1".into(), pos: [0.0, 50.0, 0.0], tags: vec!["item".into()] },
            ],
            palette: vec![
                EntityClass {
                    name: "goblin".into(),
                    default_tags: vec!["enemy".into(), "goblin".into()],
                    default_size: [10.0, 10.0, 10.0],
                },
                EntityClass {
                    name: "chest".into(),
                    default_tags: vec!["item".into(), "chest".into()],
                    default_size: [8.0, 8.0, 8.0],
                },
                EntityClass {
                    name: "torch".into(),
                    default_tags: vec!["decoration".into(), "torch".into()],
                    default_size: [4.0, 16.0, 4.0],
                },
            ],
            next_id: 100,
            last_action: String::new(),
        }
    }
    
    fn toggle_editor(&mut self) {
        self.mode = match self.mode {
            EditorMode::Inactive => EditorMode::Active,
            EditorMode::Active => EditorMode::Inactive,
        };
        if self.mode == EditorMode::Inactive {
            self.selected = None;
            self.drag_state = DragState::None;
        }
        self.last_action = format!("Toggled editor to {:?}", self.mode);
    }
    
    // 鼠标点击(简化:在 2D 平面)
    fn on_click(&mut self, x: f32, y: f32) {
        if self.mode != EditorMode::Active {
            self.last_action = "Click ignored (editor inactive)".to_string();
            return;
        }
        
        // Hit test:简化 2D
        let hit = self.entities.iter()
            .find(|e| {
                (e.pos[0] - x).abs() < 10.0 && (e.pos[1] - y).abs() < 10.0
            })
            .map(|e| e.id);
        
        match hit {
            Some(id) => {
                self.selected = Some(id);
                self.drag_state = DragState::Pending;
                let entity = self.entities.iter().find(|e| e.id == id).unwrap();
                self.drag_offset = [
                    entity.pos[0] - x,
                    entity.pos[1] - y,
                    entity.pos[2],
                ];
                self.last_action = format!("Selected {} (id={})", entity.name, id);
            }
            None => {
                self.selected = None;
                self.drag_state = DragState::None;
                self.last_action = format!("Click ({}, {}): no hit", x, y);
            }
        }
    }
    
    fn on_drag(&mut self, x: f32, y: f32) {
        if self.mode != EditorMode::Active { return; }
        
        if let Some(id) = self.selected {
            self.drag_state = DragState::Dragging;
            if let Some(e) = self.entities.iter_mut().find(|e| e.id == id) {
                e.pos[0] = x + self.drag_offset[0];
                e.pos[1] = y + self.drag_offset[1];
            }
            self.last_action = format!("Dragging {} to ({}, {})", id, x, y);
        }
    }
    
    fn on_release(&mut self) {
        if self.drag_state == DragState::Dragging {
            self.last_action = format!("Released drag");
        }
        self.drag_state = DragState::None;
    }
    
    fn delete_selected(&mut self) {
        if let Some(id) = self.selected {
            self.entities.retain(|e| e.id != id);
            self.last_action = format!("Deleted entity {}", id);
            self.selected = None;
        }
    }
    
    fn add_entity(&mut self, palette_idx: usize, x: f32, y: f32) {
        if palette_idx >= self.palette.len() { return; }
        let class = &self.palette[palette_idx];
        let id = self.next_id;
        self.next_id += 1;
        let entity = Entity {
            id,
            name: format!("{}_{}", class.name, id),
            pos: [x, y, 0.0],
            tags: class.default_tags.clone(),
        };
        self.entities.push(entity);
        self.last_action = format!("Added {} at ({}, {})", class.name, x, y);
    }
    
    fn save(&mut self) -> String {
        let mut out = String::new();
        out.push_str(&format!("# Level with {} entities\n", self.entities.len()));
        for e in &self.entities {
            out.push_str(&format!(
                "{} {} {} {} {} {}\n",
                e.id, e.name, e.pos[0], e.pos[1], e.pos[2],
                e.tags.join(",")
            ));
        }
        self.last_action = format!("Saved ({} entities)", self.entities.len());
        out
    }
}

// ========================================
// 演示
// ========================================

fn main() {
    let mut editor = Editor::new();
    
    println!("=== In-Game Editor Demo ===\n");
    
    // 模拟一帧
    editor.toggle_editor();
    println!("Action: {}\n", editor.last_action);
    
    // 点击不同位置
    editor.on_click(0.0, 0.0);   // 应该选中 hero
    println!("Action: {}", editor.last_action);
    println!("Selected: {:?}", editor.selected);
    
    // 拖动
    editor.on_drag(10.0, 5.0);
    println!("Action: {}", editor.last_action);
    editor.on_release();
    println!();
    
    // 选中另一个
    editor.on_click(50.0, 0.0);
    println!("Action: {}", editor.last_action);
    
    // 删除
    editor.delete_selected();
    println!("Action: {}", editor.last_action);
    println!("Entities: {}", editor.entities.len());
    println!();
    
    // 添加新 entity
    editor.add_entity(0, 100.0, 100.0);   // palette[0] = goblin
    println!("Action: {}", editor.last_action);
    println!("Entities: {}", editor.entities.len());
    println!();
    
    // 保存
    let saved = editor.save();
    println!("Action: {}", editor.last_action);
    println!("Saved content:");
    println!("---");
    print!("{}", saved);
    println!("---");
    
    // 退出编辑模式
    editor.toggle_editor();
    println!("\nAction: {}", editor.last_action);
    
    // 编辑器 inactive 时点击无效
    editor.on_click(0.0, 0.0);
    println!("Action: {}", editor.last_action);
    
    println!("\n=== Immediate-mode UI 模拟 ===");
    println!("(每帧重新声明 UI,从 editor state 读)");
    
    // 模拟渲染几帧
    for frame in 0..3 {
        println!("\nFrame {}:", frame);
        render_editor_overlay(&editor);
    }
}

fn render_editor_overlay(editor: &Editor) {
    if editor.mode == EditorMode::Inactive {
        println!("  [Game mode - no editor overlay]");
        return;
    }
    
    println!("  ┌─────────────────────────────┐");
    println!("  │ Editor Active               │");
    println!("  ├─────────────────────────────┤");
    
    match editor.selected {
        Some(id) => {
            let e = editor.entities.iter().find(|e| e.id == id);
            if let Some(e) = e {
                println!("  │ Selected: {} (id={})         │", e.name, e.id);
                println!("  │   pos: ({:5.1}, {:5.1}, {:5.1})    │", e.pos[0], e.pos[1], e.pos[2]);
                println!("  │   tags: {:?}             │", e.tags);
            }
        }
        None => {
            println!("  │ Selected: none              │");
        }
    }
    
    println!("  ├─────────────────────────────┤");
    println!("  │ Palette:                    │");
    for (i, class) in editor.palette.iter().enumerate() {
        println!("  │   [{}] {}                  │", i + 1, class.name);
    }
    println!("  ├─────────────────────────────┤");
    println!("  │ [S] Save  [E] Exit  [Del]   │");
    println!("  └─────────────────────────────┘");
    println!("  Last action: {}", editor.last_action);
}

#[cfg(test)]
mod tests {
    use super::*;
    
    #[test]
    fn test_toggle_editor() {
        let mut editor = Editor::new();
        assert_eq!(editor.mode, EditorMode::Inactive);
        
        editor.toggle_editor();
        assert_eq!(editor.mode, EditorMode::Active);
        
        editor.toggle_editor();
        assert_eq!(editor.mode, EditorMode::Inactive);
    }
    
    #[test]
    fn test_select_entity() {
        let mut editor = Editor::new();
        editor.toggle_editor();
        
        editor.on_click(0.0, 0.0);   // hero 在 (0, 0, 0)
        assert_eq!(editor.selected, Some(1));
    }
    
    #[test]
    fn test_drag() {
        let mut editor = Editor::new();
        editor.toggle_editor();
        
        editor.on_click(0.0, 0.0);
        editor.on_drag(10.0, 5.0);
        
        let entity = editor.entities.iter().find(|e| e.id == 1).unwrap();
        // drag_offset = (0 - 0, 0 - 0) = (0, 0)
        // new pos = (10 + 0, 5 + 0) = (10, 5)
        assert_eq!(entity.pos[0], 10.0);
        assert_eq!(entity.pos[1], 5.0);
    }
    
    #[test]
    fn test_delete_selected() {
        let mut editor = Editor::new();
        let initial_count = editor.entities.len();
        
        editor.toggle_editor();
        editor.on_click(0.0, 0.0);
        editor.delete_selected();
        
        assert_eq!(editor.entities.len(), initial_count - 1);
        assert_eq!(editor.selected, None);
    }
    
    #[test]
    fn test_add_entity() {
        let mut editor = Editor::new();
        let initial_count = editor.entities.len();
        
        editor.toggle_editor();
        editor.add_entity(0, 100.0, 100.0);   // goblin
        
        assert_eq!(editor.entities.len(), initial_count + 1);
        assert!(editor.entities.iter().any(|e| e.name.contains("goblin")));
    }
    
    #[test]
    fn test_save_load() {
        let mut editor = Editor::new();
        editor.toggle_editor();
        
        let saved = editor.save();
        assert!(saved.contains("hero"));
        assert!(saved.contains("goblin_1"));
        assert!(saved.contains("chest_1"));
    }
    
    #[test]
    fn test_inactive_ignores_click() {
        let mut editor = Editor::new();
        // mode = Inactive
        editor.on_click(0.0, 0.0);
        assert_eq!(editor.selected, None);
    }
}
```
