## 0 · 为什么要有这一天

Day 491 跑通的编辑器只能做一件事:点一个 entity,看 inspector。这是"教学版"。

真正的关卡编辑器要:

- **多选**:Shift+点选第二个 entity,两个都选中。可以一起移动。
- **框选**:鼠标拖出一个矩形,矩形内的 entity 全选中。这是关卡设计师的核心操作。
- **复制粘贴**:Ctrl+C 选中,Ctrl+V 复制。可以快速铺大量同类 entity。

- **旋转**:R 键,鼠标移动决定角度。 entity 的 rotation 属性。
- **对齐**:多个选中 entity,按 X / Y 键对齐到第一个选中的 X / Y 坐标。

每加一个交互,你都要面对 immediate-mode UI 的**状态问题**:多选要存一个 `HashSet<EntityId>`;框选要存"按下点 + 当前点";复制粘贴要存"剪贴板"。这些状态跨帧存在哪?怎么和 UI 框架配合?

- 实现 hit testing 在多个 entity 重叠时怎么决定谁被点
- 用 HashSet / Vec 管理"选中"这种集合状态
- 处理修饰键(Ctrl/Shift/Alt)的复合输入

## 2 · 心智模型

### 类比:白板上的便利贴

想象你用白板规划项目,白板上贴着便利贴(entity):

- **点一张**:选中这张。
- **Shift+点另一张**:这张也选中,两张都高亮。
- **空白处拖一下**:画个矩形,矩形内的全选中。
- **Ctrl+C / Ctrl+V**:复制一份贴到旁边。
- **拖一张**:这张跟你手指走。
- **R + 移动**:旋转。
- **多选后按 X**:全部左对齐到第一张。

每个操作都有一个"状态"在白板外维持:选中的集合、剪贴板里的便利贴、正在拖的那张、正在画的矩形。

Editor 交互就是把这些状态在程序里精确管理。

### Immediate-mode 状态管理

Immediate-mode UI 的核心问题:**跨帧状态存哪?**

Retained-mode UI:状态存在 widget 树里。`list.selectedItems()` 直接拿。

Immediate-mode UI:widget 每帧重建,不能存在 widget 里。状态必须存在**外部的"editor state"对象**里,每帧作为参数传给 UI 函数。

```rust
struct EditorState {
    selected: HashSet<EntityId>,        // 多选集
    clipboard: Vec<Entity>,              // 剪贴板
    drag: Option<DragState>,             // 拖拽中
    box_select: Option<BoxSelectState>,  // 框选中
    mode: EditorMode,                    // Select / Rotate / Place
}

enum EditorMode {
    Select,
    Rotate,
    Place(EntityType),
}

struct DragState {
    entity_id: EntityId,
    start_screen: Vec2,
    start_world: Vec2,
}

struct BoxSelectState {
    start_screen: Vec2,
    current_screen: Vec2,
}
```

每帧:

```rust
fn update_editor(state: &mut EditorState, input: &Input, world: &mut World) {
    handle_select(state, input, world);
    handle_drag(state, input, world);
    handle_box_select(state, input, world);
    handle_clipboard(state, input, world);
    handle_rotate(state, input, world);
    handle_align(state, input, world);
}
```

每个 handler 读 input,改 state / world。这就是 immediate-mode UI 的本质:**外部状态对象 + 每帧调用 handler**。

### Hit testing:决定谁被点

点击屏幕时,屏幕坐标可能是 `(100, 200)`。这个点在哪个 entity 上?

简单做法:遍历所有 entity,看哪个的 bounding box 包含这个点。如果有多个,选**最上层**的(z 最高,或后画的)。

```rust
fn hit_test(world: &World, screen_pos: Vec2, camera: &Camera) -> Option<EntityId> {
    let world_pos = screen_to_world(screen_pos, camera);
    
    // 按 z 倒序(高的优先),第一个 hit 的返回
    let mut sorted: Vec<&Entity> = world.entities.iter()
        .filter(|e| e.z > 0)   // 简化:忽略 z<=0
        .collect();
    sorted.sort_by(|a, b| b.z.partial_cmp(&a.z).unwrap());
    
    for e in sorted {
        if e.bounds_contains(world_pos) {
            return Some(e.id);
        }
    }
    None
}
```

复杂情况:entity 是不规则形状(sprite + alpha mask),要做像素级 hit test——采样 sprite 的 alpha 值,如果透明就算没 hit。

### 屏幕坐标 ↔ 世界坐标

```rust
fn screen_to_world(screen: Vec2, camera: &Camera) -> Vec2 {
    // 减去 camera 偏移
    screen - camera.pos
}

fn world_to_screen(world: Vec2, camera: &Camera) -> Vec2 {
    world + camera.pos
}
```

如果 camera 有 zoom / rotate:

```rust
fn screen_to_world(screen: Vec2, camera: &Camera) -> Vec2 {
    let p = screen - camera.center;
    let p = p / camera.zoom;       // 反 zoom
    let p = rotate(p, -camera.angle);  // 反 rotate
    p + camera.target
}
```

每对转换必须**严格对应**,否则拖拽时 entity "漂移"。Day 491 的 bug 1 就是这种。

### 拖拽:三状态机

拖拽是个小状态机:

```
[Idle] --mouse_down on entity--> [MaybeDrag]
[MaybeDrag] --mouse_move > threshold--> [Dragging]
[MaybeDrag] --mouse_up--> [Idle](没拖,只是点)
[Dragging] --mouse_move--> update entity pos
[Dragging] --mouse_up--> [Idle]
```

为什么有 `MaybeDrag` 中间态?为了区分"点击"和"拖拽"。如果鼠标按下后立即进入拖拽,点击(选中)就丢了。所以加一个阈值(threshold,比如 3 像素),移动距离 < 阈值算点击,> 阈值才算拖拽。

```rust
const DRAG_THRESHOLD: f32 = 3.0;

match state.drag {
    None => {
        if input.mouse_down && hit.is_some() {
            state.drag = Some(DragState {
                entity_id: hit.unwrap(),
                start_screen: input.mouse_pos,
                start_world: world.entity_pos(hit.unwrap()),
            });
        }
    }
    Some(ref drag) => {
        let moved = (input.mouse_pos - drag.start_screen).length();
        if moved > DRAG_THRESHOLD {
            // 真正进入拖拽
            let world_pos = screen_to_world(input.mouse_pos, camera);
            world.set_entity_pos(drag.entity_id, world_pos);
        }
        if !input.mouse_down {
            state.drag = None;
        }
    }
}
```

### 框选:和拖拽的冲突

按下鼠标时,框架要决定:这是拖 entity 还是画框?

规则:**先 hit test**。点中 entity → 拖;没点中 → 画框。

```rust
if input.mouse_down && state.drag.is_none() && state.box_select.is_none() {
    match hit_test(world, mouse, camera) {
        Some(id) => {
            // 开始拖
            state.drag = Some(...);
        }
        None => {
            // 开始画框
            state.box_select = Some(BoxSelectState {
                start_screen: mouse,
                current_screen: mouse,
            });
        }
    }
}
```

框选时,每帧检测哪些 entity 的 bounding box 和框相交:

```rust
fn entities_in_box(world: &World, box_screen: Rect, camera: &Camera) -> Vec<EntityId> {
    let world_box = Rect {
        min: screen_to_world(box_screen.min, camera),
        max: screen_to_world(box_screen.max, camera),
    };
    world.entities.iter()
        .filter(|e| e.bounds_intersects(world_box))
        .map(|e| e.id)
        .collect()
}
```

mouse_up 时,把所有在框里的 entity 加入 selected_set。

### 修饰键:Ctrl / Shift / Alt

修饰键改变默认行为:

- **无修饰**:点击 → 替换选中(单选)
- **Shift**:点击 → 加入选中(多选)
- **Ctrl**:点击 → 切换选中(已选中则取消,未选中则加入)
- **Ctrl+Shift**:点击 → 从选中移除
- **Alt**:点击 → 克隆(快速复制)

```rust
fn handle_click(state: &mut EditorState, id: EntityId, mods: KeyModifiers) {
    if mods.shift && !mods.ctrl {
        state.selected.insert(id);
    } else if mods.ctrl && !mods.shift {
        if state.selected.contains(&id) {
            state.selected.remove(&id);
        } else {
            state.selected.insert(id);
        }
    } else if mods.alt {
        let cloned = world.clone_entity(id);
        state.selected.clear();
        state.selected.insert(cloned.id);
    } else {
        state.selected.clear();
        state.selected.insert(id);
    }
}
```

### 旋转

旋转有两种 UI:

**模式切换**:R 键切换到 rotate mode,鼠标移动改变角度。case 492 用这个。

**Gizmo**:entity 上画一个"手柄"圆,拖手柄旋转。商业引擎(Unity、Unreal)用这个。

简化版:

```rust
if state.mode == EditorMode::Rotate && !state.selected.is_empty() {
    let pivot = average_pos_of_selected(world, &state.selected);
    let to_mouse = screen_to_world(input.mouse_pos, camera) - pivot;
    let angle = to_mouse.y.atan2(to_mouse.x);
    
    for id in &state.selected {
        world.set_entity_rotation(*id, angle);
    }
}
```

### 对齐

对齐到第一个选中的 X(或 Y):

```rust
fn align_x(world: &mut World, state: &EditorState) {
    if state.selected.len() < 2 { return; }
    let first_id = state.selected.iter().next().unwrap();
    let target_x = world.entity_pos(*first_id).x;
    
    for id in &state.selected {
        if *id != *first_id {
            let pos = world.entity_pos(*id);
            world.set_entity_pos(*id, Vec2::new(target_x, pos.y));
        }
    }
}
```

更工业化的对齐:对齐到选中的**中心**、**最小**、**最大**、**等距分布**。

### 3.2 · 🎨 图形学视角

编辑器交互涉及几个图形学概念。

**Bounding box / Bounds**:entity 的"边界框"。轴对齐叫 AABB(Axis-Aligned Bounding Box)。Hit test 用 AABB,O(n) 复杂度。如果 entity 很多,用空间分割(BVH / 八叉树)优化到 O(log n)。

**Picking**:点选 3D 物体的算法。CPU 法:遍历所有 triangle 看射线和谁相交。GPU 法:渲染时给每个 entity 一个唯一颜色 ID,读鼠标位置像素的颜色就知道选了谁。叫 **color-coded picking** 或 **ID buffer**。

**Gizmo rendering**:gizmo(手柄)不受光照影响,颜色固定,depth test 关闭。OpenGL 单独 render pass。

**Outline rendering**:选中时 entity 周围画轮廓。技术:渲染 entity 时同时画一个放大的副本,前面(stencil)挖空。或后处理:Sobel 边缘检测。

Casey 简化:用 4 条线画一个矩形框。

### 3.4 · 🦀 Rust 生态视角

Rust 表达 editor state 用 trait + struct。

**`HashSet` vs `Vec`**:多选集用 HashSet,因为查 `contains` 是 O(1),且自动去重。Vec 是 O(n) 查找,但保留插入顺序。Casey 用 HashSet;商业引擎常保留顺序(Vec + `contains` 检查),因为"最后选中的"是特殊状态(active entity)。

**`SmallVec`**:多选通常几个,用 `SmallVec<[EntityId; 4]>` 避免堆分配。`smallvec` crate。

**`HashMap<EntityId, T>`**:entity 上挂任意数据用 HashMap。Bevy 的 ECS 用 sparse set。

**`Command` pattern**:每个交互包装成 Command struct,执行 / 撤销。和 undo/redo 配合。

```rust
trait Command {
    fn execute(&mut self, world: &mut World);
    fn undo(&mut self, world: &mut World);
}

struct MoveCommand {
    id: EntityId,
    from: Vec2,
    to: Vec2,
}

impl Command for MoveCommand {
    fn execute(&mut self, world: &mut World) {
        world.set_entity_pos(self.id, self.to);
    }
    fn undo(&mut self, world: &mut World) {
        world.set_entity_pos(self.id, self.from);
    }
}
```

每个交互记录 Command,push 到 undo stack。Day 489 已经做了 undo/redo,Day 492 的交互都接入这个系统。

Rust 编译器对 borrow checker 的考验:`world.set_entity_pos(id, pos)` 借了 `&mut World`,但同时想读 selected 集合(也在 world 里),需要先 clone 出来再 mutate。

```rust
// 错:同时借 &world 和 &mut world
for id in &world.editor.selected {
    world.set_entity_pos(*id, new_pos);  // borrow checker 抗议
}

// 对:先收集要改的
let ids: Vec<EntityId> = world.editor.selected.iter().copied().collect();
for id in ids {
    world.set_entity_pos(id, new_pos);
}
```

## 5 · 对照与变奏

Editor 交互在不同领域有不同表现。

**2D 编辑器**:Photoshop、GIMP、Krita、Aseprite。 Casey 的 HH editor 是这类。

**3D 编辑器**:Blender、Maya、3ds Max。增加深度(z 轴),hit test 更复杂。

**Vector graphics**:Inkscape、Illustrator。增加 Bezier 曲线编辑,节点级操作。

**CAD**:FreeCAD、AutoCAD。增加精确尺寸输入,捕捉(snap)更精细。

**Audio**:Audacity、Reaper。音频片段编辑,时间轴。

所有这些工具都有"多选 + 框选 + 拖拽 + 复制粘贴"的核心。差异在领域特定操作。

历史演化:早期编辑器(Vim、Emacs)是 mode-based(先选模式再操作)。现代编辑器(VSCode、Unity)是 hit-test-driven(直接点)。后者更直观,学习曲线低。

跨领域对照:

- **电子表格**(Excel):cell 是 entity,多选 / 框选 / 复制粘贴 / 拖拽全有。Excel 的"填充柄"(右下角小方块拖动)是拖拽 + 复制合一。
- **思维导图**:节点是 entity,连线表示关系。拖节点、连节点。
- **节点图**(Unreal Blueprint、Blender Compositor):节点是 entity,连接是关系。最复杂。

学会这套交互模式,任何"对象编辑器"你都能设计。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 Casey 用 `MaybeDrag` 中间态,而不是 mouse_down 立即进入 dragging?

**参考解答**:为了区分**点击**和**拖拽**两种语义。

点击 = 选中一个 entity。拖拽 = 移动一个 entity。两者都从 mouse_down 开始,但意图不同。

如果 mouse_down 立即 dragging,用户点击选中时鼠标稍微动一下,entity 就被移走了——这不是用户想要的。

`MaybeDrag` 状态:mouse_down 后等一个阈值(3 像素),如果没移动算点击,移动超过阈值算拖拽。这是 UI 设计的"**drag threshold**"惯例,所有桌面 OS 都遵循。

```rust
use std::collections::HashSet;

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash)]
struct EntityId(u32);

#[derive(Copy, Clone, Debug)]
struct Entity {
    id: EntityId,
    pos: (f32, f32),
    name: &'static str,
}

#[derive(Copy, Clone, Debug, Default)]
struct KeyModifiers {
    shift: bool,
    ctrl: bool,
    alt: bool,
}

#[derive(Debug)]
enum DragState {
    None,
    Maybe { id: EntityId, start: (f32, f32) },
    Active { id: EntityId },
}

struct Editor {
    entities: Vec<Entity>,
    selected: HashSet<EntityId>,
    drag: DragState,
    clipboard: Vec<Entity>,
    next_id: u32,
}

impl Editor {
    fn new() -> Self {
        let entities = vec![
            Entity { id: EntityId(1), pos: (10.0, 10.0), name: "hero" },
            Entity { id: EntityId(2), pos: (50.0, 30.0), name: "sword" },
            Entity { id: EntityId(3), pos: (100.0, 50.0), name: "tree" },
        ];
        Self {
            entities, selected: HashSet::new(),
            drag: DragState::None, clipboard: Vec::new(), next_id: 4,
        }
    }
    
    fn entity(&self, id: EntityId) -> &Entity {
        self.entities.iter().find(|e| e.id == id).unwrap()
    }
    
    fn hit_test(&self, pos: (f32, f32)) -> Option<EntityId> {
        // 简化:任何 entity 在 5 像素内算 hit
        let mut best: Option<(EntityId, f32)> = None;
        for e in &self.entities {
            let d = ((e.pos.0 - pos.0).powi(2) + (e.pos.1 - pos.1).powi(2)).sqrt();
            if d < 5.0 {
                match best {
                    Some((_, bd)) if bd < d => {}
                    _ => best = Some((e.id, d)),
                }
            }
        }
        best.map(|(id, _)| id)
    }
    
    fn click(&mut self, pos: (f32, f32), mods: KeyModifiers) {
        match self.hit_test(pos) {
            Some(id) => {
                if mods.shift {
                    self.selected.insert(id);
                } else if mods.ctrl {
                    if !self.selected.remove(&id) {
                        self.selected.insert(id);
                    }
                } else {
                    self.selected.clear();
                    self.selected.insert(id);
                }
                self.drag = DragState::Maybe { id, start: pos };
                println!(">> Click: selected = {:?}", self.selected);
            }
            None => {
                if !mods.shift && !mods.ctrl {
                    self.selected.clear();
                    println!(">> Click empty: clear selection");
                }
            }
        }
    }
    
    fn mouse_move(&mut self, pos: (f32, f32)) {
        const THRESHOLD: f32 = 3.0;
        match self.drag {
            DragState::Maybe { id, start } => {
                let d = ((pos.0 - start.0).powi(2) + (pos.1 - start.1).powi(2)).sqrt();
                if d > THRESHOLD {
                    self.drag = DragState::Active { id };
                    println!(">> Drag start: id {:?}", id);
                }
            }
            DragState::Active { id } => {
                if let Some(e) = self.entities.iter_mut().find(|e| e.id == id) {
                    e.pos = pos;
                }
            }
            DragState::None => {}
        }
    }
    
    fn mouse_up(&mut self) {
        if let DragState::Active { id } = self.drag {
            println!(">> Drag end: id {:?} now at {:?}", id, self.entity(id).pos);
        }
        self.drag = DragState::None;
    }
    
    fn copy(&mut self) {
        self.clipboard.clear();
        for id in &self.selected {
            if let Some(e) = self.entities.iter().find(|e| &e.id == id) {
                self.clipboard.push(*e);
            }
        }
        println!(">> Copy: {} entities", self.clipboard.len());
    }
    
    fn paste(&mut self) {
        let offset = 5.0;
        for e in &self.clipboard {
            let new_id = EntityId(self.next_id);
            self.next_id += 1;
            self.entities.push(Entity {
                id: new_id,
                pos: (e.pos.0 + offset, e.pos.1 + offset),
                name: e.name,
            });
            println!(">> Paste: created {:?} ({}) at {:?}", new_id, e.name, (e.pos.0 + offset, e.pos.1 + offset));
        }
    }
    
    fn print_state(&self) {
        println!("State: {} entities, selected {:?}", self.entities.len(), self.selected);
        for e in &self.entities {
            let sel = if self.selected.contains(&e.id) { "*" } else { " " };
            println!("  {} {:?} {} at {:?}", sel, e.id, e.name, e.pos);
        }
    }
}

fn main() {
    let mut editor = Editor::new();
    
    println!("=== Initial state ===");
    editor.print_state();
    
    println!("\n=== Click hero (10,10) ===");
    editor.click((10.0, 10.0), KeyModifiers::default());
    editor.print_state();
    
    println!("\n=== Shift+Click sword (50,30) ===");
    editor.click((50.0, 30.0), KeyModifiers { shift: true, ..Default::default() });
    editor.print_state();
    
    println!("\n=== Drag from (10,10) to (20,20) ===");
    editor.click((10.0, 10.0), KeyModifiers::default());  // 假装重新点
    editor.mouse_move((15.0, 15.0));   // 还在阈值内
    editor.mouse_move((20.0, 20.0));   // 超过阈值,真拖
    editor.mouse_up();
    editor.print_state();
    
    println!("\n=== Ctrl+C / Ctrl+V ===");
    editor.copy();
    editor.paste();
    editor.print_state();
}
```

```rust
// ============================================================
// Day 492 · 为编辑器添加更多交互
// ============================================================

use std::collections::HashSet;

// ============================================================
// 基础类型
// ============================================================

#[derive(Copy, Clone, Debug, PartialEq, Eq, Hash)]
struct EntityId(u32);

#[derive(Copy, Clone, Debug)]
struct Entity {
    id: EntityId,
    pos: Vec2,
    rotation: f32,    // 弧度
    name: &'static str,
}

#[derive(Copy, Clone, Debug, Default)]
struct Vec2 { x: f32, y: f32 }

impl Vec2 {
    const fn new(x: f32, y: f32) -> Self { Self { x, y } }
    fn length(self) -> f32 { (self.x * self.x + self.y * self.y).sqrt() }
}

impl std::ops::Sub for Vec2 {
    type Output = Vec2;
    fn sub(self, other: Vec2) -> Vec2 { Vec2::new(self.x - other.x, self.y - other.y) }
}

impl std::ops::Add for Vec2 {
    type Output = Vec2;
    fn add(self, other: Vec2) -> Vec2 { Vec2::new(self.x + other.x, self.y + other.y) }
}

#[derive(Copy, Clone, Debug, Default)]
struct KeyModifiers {
    shift: bool,
    ctrl: bool,
    alt: bool,
}

#[derive(Copy, Clone, Debug, Default)]
struct Input {
    mouse_pos: Vec2,
    mouse_down: bool,
    mods: KeyModifiers,
    key_r: bool,      // 旋转模式
    key_x: bool,      // 对齐 X
    key_y: bool,      // 对齐 Y
}

// ============================================================
// Editor state
// ============================================================

#[derive(Debug)]
enum DragState {
    None,
    Maybe { id: EntityId, start: Vec2 },
    Active { id: EntityId, original_pos: Vec2 },
}

#[derive(Debug)]
struct BoxSelect {
    start: Vec2,
    current: Vec2,
}

#[derive(Copy, Clone, Debug, PartialEq)]
enum EditorMode {
    Select,
    Rotate,
}

struct Editor {
    entities: Vec<Entity>,
    selected: HashSet<EntityId>,
    drag: DragState,
    box_select: Option<BoxSelect>,
    clipboard: Vec<Entity>,
    mode: EditorMode,
    next_id: u32,
}

impl Editor {
    fn new() -> Self {
        Self {
            entities: vec![
                Entity { id: EntityId(1), pos: Vec2::new(10.0, 10.0), rotation: 0.0, name: "hero" },
                Entity { id: EntityId(2), pos: Vec2::new(50.0, 10.0), rotation: 0.0, name: "sword" },
                Entity { id: EntityId(3), pos: Vec2::new(100.0, 50.0), rotation: 0.0, name: "tree" },
                Entity { id: EntityId(4), pos: Vec2::new(20.0, 80.0), rotation: 0.0, name: "rock" },
            ],
            selected: HashSet::new(),
            drag: DragState::None,
            box_select: None,
            clipboard: Vec::new(),
            mode: EditorMode::Select,
            next_id: 5,
        }
    }
    
    fn entity(&self, id: EntityId) -> &Entity {
        self.entities.iter().find(|e| e.id == id).expect("entity not found")
    }
    
    fn entity_mut(&mut self, id: EntityId) -> &mut Entity {
        self.entities.iter_mut().find(|e| e.id == id).expect("entity not found")
    }
    
    fn hit_test(&self, pos: Vec2) -> Option<EntityId> {
        // 简化:5 像素半径
        let mut best: Option<(EntityId, f32)> = None;
        for e in &self.entities {
            let d = (e.pos - pos).length();
            if d < 5.0 {
                match best {
                    Some((_, bd)) if bd <= d => {}
                    _ => best = Some((e.id, d)),
                }
            }
        }
        best.map(|(id, _)| id)
    }
    
    // ========================================
    // 交互:点击 / 选中
    // ========================================
    
    fn handle_mouse_down(&mut self, input: &Input) {
        // 模式切换:R 键
        if input.key_r {
            self.mode = if self.mode == EditorMode::Select { EditorMode::Rotate } else { EditorMode::Select };
            println!(">> Mode: {:?}", self.mode);
            return;
        }
        
        match self.hit_test(input.mouse_pos) {
            Some(id) => {
                self.apply_selection(id, input.mods);
                self.drag = DragState::Maybe { id, start: input.mouse_pos };
            }
            None => {
                // 空白处按下:开始框选(或清选)
                if !input.mods.shift && !input.mods.ctrl {
                    self.selected.clear();
                    println!(">> Click empty: clear selection");
                }
                self.box_select = Some(BoxSelect {
                    start: input.mouse_pos,
                    current: input.mouse_pos,
                });
            }
        }
    }
    
    fn apply_selection(&mut self, id: EntityId, mods: KeyModifiers) {
        if mods.shift {
            self.selected.insert(id);
            println!(">> Shift+click {:?}: add to selection", id);
        } else if mods.ctrl {
            if !self.selected.remove(&id) {
                self.selected.insert(id);
                println!(">> Ctrl+click {:?}: add", id);
            } else {
                println!(">> Ctrl+click {:?}: remove", id);
            }
        } else if mods.alt {
            // Alt = 克隆
            let original = *self.entity(id);
            let new_id = EntityId(self.next_id);
            self.next_id += 1;
            self.entities.push(Entity {
                id: new_id,
                pos: original.pos + Vec2::new(5.0, 5.0),
                rotation: original.rotation,
                name: original.name,
            });
            self.selected.clear();
            self.selected.insert(new_id);
            println!(">> Alt+click {:?}: cloned to {:?}", id, new_id);
        } else {
            self.selected.clear();
            self.selected.insert(id);
            println!(">> Click {:?}: select", id);
        }
    }
    
    // ========================================
    // 交互:拖拽 / 框选
    // ========================================
    
    fn handle_mouse_move(&mut self, input: &Input) {
        const DRAG_THRESHOLD: f32 = 3.0;
        
        // 拖拽状态机
        match self.drag {
            DragState::Maybe { id, start } => {
                let d = (input.mouse_pos - start).length();
                if d > DRAG_THRESHOLD {
                    let orig = self.entity(id).pos;
                    self.drag = DragState::Active { id, original_pos: orig };
                    println!(">> Drag start: {:?}", id);
                }
            }
            DragState::Active { id, .. } => {
                self.entity_mut(id).pos = input.mouse_pos;
            }
            DragState::None => {}
        }
        
        // 框选更新
        if let Some(ref mut bs) = self.box_select {
            bs.current = input.mouse_pos;
        }
    }
    
    fn handle_mouse_up(&mut self) {
        // 完成拖拽
        if let DragState::Active { id, original_pos } = self.drag {
            let now = self.entity(id).pos;
            println!(">> Drag end: {:?} moved {:?} -> {:?}", id, original_pos, now);
        }
        self.drag = DragState::None;
        
        // 完成框选
        if let Some(bs) = self.box_select.take() {
            let min_x = bs.start.x.min(bs.current.x);
            let max_x = bs.start.x.max(bs.current.x);
            let min_y = bs.start.y.min(bs.current.y);
            let max_y = bs.start.y.max(bs.current.y);
            
            let mut count = 0;
            for e in &self.entities {
                if e.pos.x >= min_x && e.pos.x <= max_x && e.pos.y >= min_y && e.pos.y <= max_y {
                    self.selected.insert(e.id);
                    count += 1;
                }
            }
            println!(">> Box select: {} entities selected", count);
        }
    }
    
    // ========================================
    // 交互:复制粘贴
    // ========================================
    
    fn copy(&mut self) {
        self.clipboard.clear();
        let ids: Vec<EntityId> = self.selected.iter().copied().collect();
        for id in ids {
            let e = *self.entity(id);
            self.clipboard.push(e);
        }
        println!(">> Copy: {} entities", self.clipboard.len());
    }
    
    fn paste(&mut self) {
        let offset = Vec2::new(5.0, 5.0);
        let mut new_ids = Vec::new();
        for e in &self.clipboard {
            let new_id = EntityId(self.next_id);
            self.next_id += 1;
            self.entities.push(Entity {
                id: new_id,
                pos: e.pos + offset,
                rotation: e.rotation,
                name: e.name,
            });
            new_ids.push(new_id);
        }
        self.selected.clear();
        for id in new_ids {
            self.selected.insert(id);
        }
        println!(">> Paste: created {} entities", self.clipboard.len());
    }
    
    // ========================================
    // 交互:旋转(简化)
    // ========================================
    
    fn handle_rotate(&mut self, input: &Input) {
        if self.mode != EditorMode::Rotate || self.selected.is_empty() { return; }
        
        // 围绕选中集中心旋转
        let ids: Vec<EntityId> = self.selected.iter().copied().collect();
        let mut center = Vec2::new(0.0, 0.0);
        for id in &ids {
            center = center + self.entity(*id).pos;
        }
        center.x /= ids.len() as f32;
        center.y /= ids.len() as f32;
        
        let to_mouse = input.mouse_pos - center;
        let angle = to_mouse.y.atan2(to_mouse.x);
        
        for id in ids {
            self.entity_mut(id).rotation = angle;
        }
        println!(">> Rotate: angle = {:.1}°", angle.to_degrees());
    }
    
    // ========================================
    // 交互:对齐
    // ========================================
    
    fn align_x(&mut self) {
        if self.selected.len() < 2 { return; }
        let first = *self.selected.iter().next().unwrap();
        let target_x = self.entity(first).pos.x;
        
        let ids: Vec<EntityId> = self.selected.iter().copied().filter(|&id| id != first).collect();
        for id in ids {
            let pos = self.entity(id).pos;
            self.entity_mut(id).pos = Vec2::new(target_x, pos.y);
        }
        println!(">> Align X to {:.1}", target_x);
    }
    
    fn align_y(&mut self) {
        if self.selected.len() < 2 { return; }
        let first = *self.selected.iter().next().unwrap();
        let target_y = self.entity(first).pos.y;
        
        let ids: Vec<EntityId> = self.selected.iter().copied().filter(|&id| id != first).collect();
        for id in ids {
            let pos = self.entity(id).pos;
            self.entity_mut(id).pos = Vec2::new(pos.x, target_y);
        }
        println!(">> Align Y to {:.1}", target_y);
    }
    
    // ========================================
    // 渲染(简化为 println)
    // ========================================
    
    fn render(&self) {
        println!("--- Editor state ---");
        println!("mode: {:?}", self.mode);
        println!("selected: {:?}", self.selected);
        if let Some(bs) = &self.box_select {
            println!("box_select: {:?} -> {:?}", bs.start, bs.current);
        }
        for e in &self.entities {
            let sel = if self.selected.contains(&e.id) { "*" } else { " " };
            println!("  {} {:?} {} at ({:.1},{:.1}) rot {:.0}°",
                     sel, e.id, e.name, e.pos.x, e.pos.y, e.rotation.to_degrees());
        }
        if let DragState::Active { id, .. } = self.drag {
            println!("  dragging: {:?}", id);
        }
    }
}

fn simulate() {
    let mut editor = Editor::new();
    
    println!("=== 初始 ===");
    editor.render();
    
    // 1. 点 hero
    println!("\n=== 点 hero ===");
    let input = Input { mouse_pos: Vec2::new(10.0, 10.0), mouse_down: true, ..Default::default() };
    editor.handle_mouse_down(&input);
    editor.handle_mouse_up();
    editor.render();
    
    // 2. Shift+点 sword(多选)
    println!("\n=== Shift+点 sword ===");
    let input = Input {
        mouse_pos: Vec2::new(50.0, 10.0), mouse_down: true,
        mods: KeyModifiers { shift: true, ..Default::default() },
        ..Default::default()
    };
    editor.handle_mouse_down(&input);
    editor.handle_mouse_up();
    editor.render();
    
    // 3. 拖 hero(假装重新点 hero)
    println!("\n=== 拖 hero(从 (10,10) 到 (30,30))===");
    let input = Input { mouse_pos: Vec2::new(10.0, 10.0), mouse_down: true, ..Default::default() };
    editor.handle_mouse_down(&input);
    for x in [12.0, 15.0, 20.0, 25.0, 30.0] {
        editor.handle_mouse_move(&Input { mouse_pos: Vec2::new(x, x), ..Default::default() });
    }
    editor.handle_mouse_up();
    editor.render();
    
    // 4. 框选 (40,5)-(110,60)
    println!("\n=== 框选 ===");
    let input = Input { mouse_pos: Vec2::new(40.0, 5.0), mouse_down: true, ..Default::default() };
    editor.handle_mouse_down(&input);
    editor.handle_mouse_move(&Input { mouse_pos: Vec2::new(110.0, 60.0), ..Default::default() });
    editor.handle_mouse_up();
    editor.render();
    
    // 5. Ctrl+C / Ctrl+V
    println!("\n=== Ctrl+C / Ctrl+V ===");
    editor.copy();
    editor.paste();
    editor.render();
    
    // 6. R + 鼠标(旋转)
    println!("\n=== R 模式 + 鼠标到 (50,50) ===");
    editor.mode = EditorMode::Rotate;
    let input = Input { mouse_pos: Vec2::new(50.0, 50.0), ..Default::default() };
    editor.handle_rotate(&input);
    editor.render();
    
    // 7. 对齐 X(需要多选)
    println!("\n=== 多选后按 X(对齐 X)===");
    editor.mode = EditorMode::Select;
    editor.selected.clear();
    editor.selected.insert(EntityId(1));
    editor.selected.insert(EntityId(2));
    editor.selected.insert(EntityId(3));
    editor.align_x();
    editor.render();
}

    }
    
    #[test]
    fn test_shift_multiselect() {
        let mut editor = Editor::new();
        let input = Input { mouse_pos: Vec2::new(10.0, 10.0), mouse_down: true, ..Default::default() };
        editor.handle_mouse_down(&input);
        editor.handle_mouse_up();
        
        let input = Input {
            mouse_pos: Vec2::new(50.0, 10.0), mouse_down: true,
            mods: KeyModifiers { shift: true, ..Default::default() },
            ..Default::default()
        };
        editor.handle_mouse_down(&input);
        editor.handle_mouse_up();
        
        assert_eq!(editor.selected.len(), 2);

    }
    
    #[test]
    fn test_drag_threshold() {
        let mut editor = Editor::new();
        let input = Input { mouse_pos: Vec2::new(10.0, 10.0), mouse_down: true, ..Default::default() };
        editor.handle_mouse_down(&input);
        
        // 移动 1 像素,不触发 drag
        editor.handle_mouse_move(&Input { mouse_pos: Vec2::new(11.0, 10.0), ..Default::default() });
        assert!(matches!(editor.drag, DragState::Maybe { .. }));
        
        // 移动 5 像素,触发 drag
        editor.handle_mouse_move(&Input { mouse_pos: Vec2::new(15.0, 10.0), ..Default::default() });
        assert!(matches!(editor.drag, DragState::Active { .. }));
    }
    
    #[test]
    fn test_copy_paste() {
        let mut editor = Editor::new();
        editor.selected.insert(EntityId(1));
        editor.selected.insert(EntityId(2));
        
        let initial_count = editor.entities.len();
        editor.copy();
        editor.paste();
        
        assert_eq!(editor.entities.len(), initial_count + 2);
        // 新 entity 位置应偏移
        let new1 = editor.entities.iter().find(|e| e.id == EntityId(5)).unwrap();
        assert_eq!(new1.pos.x, 15.0);  // 10 + 5
    }
    
    #[test]
    fn test_align_x() {
        let mut editor = Editor::new();
        editor.selected.insert(EntityId(1));  // (10,10)
        editor.selected.insert(EntityId(2));  // (50,10)
        
        editor.align_x();
        
        // 第一个不动
        assert_eq!(editor.entity(EntityId(1)).pos.x, 10.0);
        // 第二个对齐
        assert_eq!(editor.entity(EntityId(2)).pos.x, 10.0);
        // Y 不变
        assert_eq!(editor.entity(EntityId(2)).pos.y, 10.0);
    }
    
    #[test]
    fn test_box_select() {
        let mut editor = Editor::new();
        let input = Input { mouse_pos: Vec2::new(0.0, 0.0), mouse_down: true, ..Default::default() };
        editor.handle_mouse_down(&input);
        editor.handle_mouse_move(&Input { mouse_pos: Vec2::new(105.0, 60.0), ..Default::default() });
        editor.handle_mouse_up();
        
        // entity 1, 2, 3 应被选中(在 (0,0)-(105,60) 框内)
        assert!(editor.selected.contains(&EntityId(1)));
        assert!(editor.selected.contains(&EntityId(2)));
        assert!(editor.selected.contains(&EntityId(3)));
        // entity 4 (20,80) 不在
        assert!(!editor.selected.contains(&EntityId(4)));
    }
}
```
