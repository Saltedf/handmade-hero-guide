# Day 495 · 改进对齐点编辑 UI

> Day 494 给 entity 加了 piece + alignment point 数据结构。Day 495 给编辑器加 UI——可视化这些 alignment point,让设计者拖动调整位置。这是 Casey "用编辑器造编辑器"哲学的体现——先做工具,再用工具做内容。

## 0 · 为什么要有这一天

Day 494 之后,entity 内部有 piece 树,每个 piece 有命名的 alignment point。但**这些数据看不见**——你只能从代码或 JSON 看,不知道"head 的 neck 点到底在哪个像素"。

关卡设计师看不到的东西就调不了。Day 495 做编辑器 UI:

- 在游戏画面上**可视化**所有 alignment point(画小圆点 + 名字)

- 可以**添加**新 alignment point(命名 + 位置)

这是 Casey "工具优先"哲学的体现。在 HH 早期 Day 1-400,Casey 是手写代码改数据。后期 Day 488+ 他开始做工具,用工具改数据——效率指数级提升。

为什么这么重要?因为**手动改 1000 个 entity 的 JSON 是不可能的**。即使最有耐心的设计者也坚持不了。只有可视化编辑器能 scale 到大规模内容生产。

## 2 · 心智模型

### 类比:家具店的家具组装图

### WYSIWYG 编辑器

**WYSIWYG** = What You See Is What You Get(所见即所得)。

非 WYSIWYG 编辑:你写代码 / JSON,看不到效果,跑起来才看。出错难调试。

WYSIWYG 编辑:你在画面上看到的就是最终效果,直接操作。

工业级 WYSIWYG 编辑器:

- **Photoshop**:画图所见即所得
- **Word**:排版所见即所得(早期 WordStar 不是)
- **Unity Scene view**:3D 编辑所见即所得
- **Blender**:3D 建模所见即所得
- **Visual Studio WinForms designer**:拖控件所见即所得

Casey 的 HH editor 是 WYSIWYG——你拖 alignment point,立即看到子 piece 跟着动。

### 双向坐标转换

编辑 alignment point 时,数据是相对 piece 的(offset),但鼠标位置是屏幕的。需要双向转换:

```
屏幕坐标 → 世界坐标(piece 位置)→ piece 局部坐标(相对 piece 原点)
```

第一步:`screen_to_world(screen, camera) = screen - camera_offset`
第二步:`world_to_local(world, piece) = world - piece.world_pos`

反过来,把 local offset 渲染到屏幕:

```
piece.world_pos + offset → world_pos → screen_pos
```

拖动时:

```rust
fn drag_alignment_point(piece: &Piece, point_name: &str, mouse_screen: Vec2, camera: &Camera) -> Vec2 {
    // 鼠标的世界位置
    let mouse_world = screen_to_world(mouse_screen, camera);
    // 减去 piece 的世界位置,得 piece 局部坐标
    let new_offset = mouse_world - piece.world_pos;
    new_offset
}
```

### Visual feedback(视觉反馈)

WYSIWYG 编辑器的关键是**立即反馈**。鼠标移动 1 像素,画面立即变。

实现:

- 鼠标按下 → 进入 drag state
- 每帧:drag state 中,鼠标位置转数据,更新数据
- 每帧:渲染前先 compute_world_transforms(让子 piece 跟着新 offset)
- 渲染时画 alignment point 标记

延迟超过 1 帧(16ms),用户就觉得"卡"。所以数据更新必须在 input 处理后、渲染前。

### 命中测试:小圆点的 hit test

Alignment point 是 3 像素半径的圆。Hit test:

```rust
fn hit_alignment_point(piece: &Piece, mouse_world: Vec2, radius: f32) -> Option<&AlignmentPoint> {
    piece.alignment_points.iter().find(|ap| {
        let world_pos = piece.world_pos + ap.offset;
        let dist = (world_pos - mouse_world).length();
        dist < radius
    })
}
```

复杂情况:多个 piece 重叠时,鼠标可能 hit 多个 alignment point。规则:**z-order 高的优先**(后画的 piece 在上),或**最近选中的 piece 优先**(让用户继续操作上次选的)。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 Casey 选择"双击添加"而不是"按钮添加" alignment point?

**参考解答**:三个理由:

第一,**直接操作**(direct manipulation)。双击位置直接告诉系统"我要在这里加"。按钮添加要:点按钮 → 弹对话框 → 选 piece → 输入名字 → 选位置 → 确认。多 4 步。

第二,**位置语义**。双击的位置就是要加 alignment point 的位置。按钮添加的位置是默认(0,0),用户要再拖。

第三,**WYSIWYG 哲学**。直接在画面操作,不用切换到其他界面。

代价:用户要学"双击"手势。但现代 UI 用户都熟悉。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:在 Day 494 piece 系统基础上加 alignment point 编辑。功能:列出 piece + alignment point,模拟拖动一个 alignment point,验证 piece 的 offset 跟着变。

完成标准:`cargo run` 输出拖动前后的 alignment point offset 和 piece world_pos。

**参考解答**:

```rust
// 复用 day494 的 Vec2, Piece, PieceTree, Entity...

#[derive(Debug)]
enum EditorTool {
    Select,
    EditAlignmentPoints,
}

#[derive(Debug)]
struct Editor {
    tool: EditorTool,
    dragging_point: Option<(usize, String)>,    // (piece index, point name)
}

impl Editor {
    fn new() -> Self {
        Self { tool: EditorTool::Select, dragging_point: None }
    }
    
    fn try_grab_point(&mut self, entity: &Entity, mouse_world: Vec2) -> bool {
        if !matches!(self.tool, EditorTool::EditAlignmentPoints) { return false; }
        
        for (i, piece) in entity.pieces.pieces.iter().enumerate() {
            for ap in &piece.alignment_points {
                let world_pos = piece.world_pos + ap.offset;
                let dist = ((world_pos.x - mouse_world.x).powi(2) + (world_pos.y - mouse_world.y).powi(2)).sqrt();
                if dist < 5.0 {
                    self.dragging_point = Some((i, ap.name.clone()));
                    println!(">> Grabbed alignment point '{}' on piece '{}'", ap.name, piece.name);
                    return true;
                }
            }
        }
        false
    }
    
    fn drag(&mut self, entity: &mut Entity, mouse_world: Vec2) {
        if let Some((piece_idx, ref point_name)) = self.dragging_point {
            let piece_world = entity.pieces.pieces[piece_idx].world_pos;
            let new_offset = mouse_world - piece_world;
            
            // 更新 alignment point offset
            for ap in &mut entity.pieces.pieces[piece_idx].alignment_points {
                if ap.name == *point_name {
                    println!(">> Drag '{}': offset {} -> {}", ap.name, ap.offset, new_offset);
                    ap.offset = new_offset;
                    break;
                }
            }
            
            // 重算所有 piece 的世界变换
            entity.compute_world_transforms();
        }
    }
    
    fn release(&mut self) {
        if self.dragging_point.is_some() {
            println!(">> Released alignment point");
            self.dragging_point = None;
        }
    }
}

fn main() {
    // 复用 day494 的 make_knight
    let mut knight = make_knight_simple();
    knight.compute_world_transforms();
    
    println!("=== 初始 ===");
    for p in &knight.pieces.pieces {
        println!("  {}: world {}", p.name, p.world_pos);
    }
    
    let mut editor = Editor::new();
    editor.tool = EditorTool::EditAlignmentPoints;
    
    println!("\n=== 模拟:鼠标按下 body 的 neck 点 ===");
    // body 的 neck point: world (50, 30)
    let grabbed = editor.try_grab_point(&knight, Vec2::new(50.0, 30.0));
    println!("grabbed: {}", grabbed);
    
    println!("\n=== 拖到 (50, 25) ===");
    editor.drag(&mut knight, Vec2::new(50.0, 25.0));
    
    println!("\n=== 释放 ===");
    editor.release();
    
    println!("\n=== 拖动后 ===");
    for p in &knight.pieces.pieces {
        println!("  {}: world {}", p.name, p.world_pos);
        for ap in &p.alignment_points {
            println!("    point '{}': offset {}", ap.name, ap.offset);
        }
    }
    
    // head world 应该跟着变:body(50,50) + neck(0,-25) + head(0,0) = (50, 25)
    let head = knight.pieces.get_simple(1);
    println!("\nhead world: {} (预期 50,25)", head.world_pos);
}

fn make_knight_simple() -> Entity {
    let mut e = Entity::new("knight", Vec2::new(50.0, 50.0));
    e.pieces.add(
        Piece::new(PieceId(0), "body", "knight_body", Vec2::new(0.0, 0.0))
            .with_alignment_points(vec![
                AlignmentPoint::new("neck", 0.0, -20.0),
                AlignmentPoint::new("hand_r", 15.0, 0.0),
            ])
    );
    e.pieces.add(
        Piece::new(PieceId(1), "head", "knight_head", Vec2::new(0.0, 0.0))
            .with_parent(PieceId(0), "neck")
    );
    e
}

// 简化:为示例,假设 PieceTree 有 get_simple 方法
impl PieceTree {
    fn get_simple(&self, idx: usize) -> &Piece { &self.pieces[idx] }
}
```

为什么这么写:`EditorTool` enum 表达工具状态。`dragging_point: Option<(usize, String)>` 表达当前拖拽。每帧 drag 时更新数据 + 重算 transforms,保证实时反馈。

// ============================================================
// Day 495 · 改进对齐点编辑 UI

use std::fmt;
use std::io::{self, Write};

#[derive(Copy, Clone, Debug, PartialEq)]
struct Vec2 { x: f32, y: f32 }

impl Vec2 {
    const fn new(x: f32, y: f32) -> Self { Self { x, y } }
    const ZERO: Self = Self::new(0.0, 0.0);
    fn length(self) -> f32 { (self.x * self.x + self.y * self.y).sqrt() }
}

impl std::ops::Add for Vec2 {
    type Output = Vec2;
    fn add(self, o: Vec2) -> Vec2 { Vec2::new(self.x + o.x, self.y + o.y) }
}

impl std::ops::Sub for Vec2 {
    type Output = Vec2;
    fn sub(self, o: Vec2) -> Vec2 { Vec2::new(self.x - o.x, self.y - o.y) }
}

impl fmt::Display for Vec2 {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "({:.1},{:.1})", self.x, self.y)
    }
}

// ============================================================
// Piece system(简化自 day494)
// ============================================================

#[derive(Clone, Debug)]
struct AlignmentPoint {
    name: String,
    offset: Vec2,
}

#[derive(Clone, Debug, PartialEq, Eq, Hash, Copy)]
struct PieceId(usize);

#[derive(Clone, Debug)]
struct Piece {
    id: PieceId,
    name: String,
    offset: Vec2,
    alignment_points: Vec<AlignmentPoint>,
    parent: Option<(PieceId, String)>,
    world_pos: Vec2,
}

struct PieceTree {
    pieces: Vec<Piece>,
}

impl PieceTree {
    fn new() -> Self { Self { pieces: Vec::new() } }
    fn add(&mut self, piece: Piece) -> PieceId {
        let id = piece.id;
        self.pieces.push(piece);
        id
    }
    
    fn compute(&mut self) {
        // 简化拓扑排序:按 id 顺序(BFS 友好)
        let mut changed = true;
        while changed {
            changed = false;
            for i in 0..self.pieces.len() {
                let new_pos = {
                    let p = &self.pieces[i];
                    match &p.parent {
                        None => p.offset,
                        Some((pid, pn)) => {
                            let parent = &self.pieces[pid.0];
                            let point = parent.alignment_points.iter()
                                .find(|ap| &ap.name == pn);
                            match point {
                                Some(pt) => parent.world_pos + pt.offset + p.offset,
                                None => continue,
                            }
                        }
                    }
                };
                if new_pos != self.pieces[i].world_pos {
                    self.pieces[i].world_pos = new_pos;
                    changed = true;
                }
            }
        }
    }
}

struct Entity {
    name: String,
    world_offset: Vec2,
    pieces: PieceTree,
}

impl Entity {
    fn new(name: &str, world_offset: Vec2) -> Self {
        Self { name: name.into(), world_offset, pieces: PieceTree::new() }
    }
    
    fn compute(&mut self) {
        if !self.pieces.pieces.is_empty() {
            let original = self.pieces.pieces[0].offset;
            self.pieces.pieces[0].offset = original + self.world_offset;
            self.pieces.compute();
            self.pieces.pieces[0].offset = original;
        }
    }
}

struct Camera { offset: Vec2 }

fn screen_to_world(screen: Vec2, camera: &Camera) -> Vec2 {
    screen - camera.offset
}

#[derive(Debug, PartialEq)]
enum EditorTool {
    Select,
    EditAlignmentPoints,
    AddAlignmentPoint { piece: PieceId, pos: Vec2, name_buffer: String },
}

struct Editor {
    tool: EditorTool,
    selected_piece: Option<PieceId>,
    dragging_point: Option<(PieceId, String)>,
    camera: Camera,
}

impl Editor {
    fn new() -> Self {
        Self {
            tool: EditorTool::Select,
            selected_piece: None,
            dragging_point: None,
            camera: Camera { offset: Vec2::ZERO },
        }
    }
    
    fn switch_tool(&mut self, tool: EditorTool) {
        println!(">> Switch tool: {:?} -> {:?}", self.tool_kind(), tool_kind(&tool));
        // 取消进行中操作
        self.dragging_point = None;
        self.tool = tool;
    }
    
    fn tool_kind(&self) -> &'static str { tool_kind(&self.tool) }
    
    fn try_grab(&mut self, entity: &Entity, mouse_screen: Vec2) -> bool {
        if !matches!(self.tool, EditorTool::EditAlignmentPoints) { return false; }
        
        let mouse_world = screen_to_world(mouse_screen, &self.camera);
        
        for piece in &entity.pieces.pieces {
            for ap in &piece.alignment_points {
                let pos = piece.world_pos + ap.offset;
                if (pos - mouse_world).length() < 5.0 {
                    self.dragging_point = Some((piece.id, ap.name.clone()));
                    println!(">> Grabbed '{}.{}' at {}", piece.name, ap.name, pos);
                    return true;
                }
            }
        }
        false
    }
    
    fn drag(&mut self, entity: &mut Entity, mouse_screen: Vec2) {
        let Some((piece_id, ref point_name)) = self.dragging_point else { return; };
        
        let mouse_world = screen_to_world(mouse_screen, &self.camera);
        let piece_world = entity.pieces.pieces[piece_id.0].world_pos;
        let new_offset = mouse_world - piece_world;
        
        let piece = &mut entity.pieces.pieces[piece_id.0];
        for ap in &mut piece.alignment_points {
            if ap.name == *point_name {
                ap.offset = new_offset;
                break;
            }
        }
        
        entity.compute();
    }
    
    fn release(&mut self) {
        if let Some((pid, pn)) = self.dragging_point.take() {
            println!(">> Released {}.{}", pid.0, pn);
        }
    }
    
    fn add_point_input(&mut self, ch: char) {
        if let EditorTool::AddAlignmentPoint { ref mut name_buffer, .. } = &mut self.tool {
            name_buffer.push(ch);
        }
    }
    
    fn confirm_add(&mut self, entity: &mut Entity) {
        if let EditorTool::AddAlignmentPoint { piece, pos, name_buffer } = &self.tool {
            let piece = *piece;
            let pos = *pos;
            let name = name_buffer.clone();
            if !name.is_empty() {
                let piece_world = entity.pieces.pieces[piece.0].world_pos;
                let offset = pos - piece_world;
                entity.pieces.pieces[piece.0].alignment_points.push(AlignmentPoint { name: name.clone(), offset });
                println!(">> Added alignment point '{}' at {} (offset {})", name, pos, offset);
                entity.compute();
            }
            self.tool = EditorTool::EditAlignmentPoints;
        }
    }
    
    fn delete_selected(&mut self, entity: &mut Entity) {
        if let Some((pid, pn)) = &self.dragging_point {
            // 不太对:dragging 不应被删。简化演示
            return;
        }
        // 真实实现:有个 selected_point 字段
    }
}

fn tool_kind(t: &EditorTool) -> &'static str {
    match t {
        EditorTool::Select => "Select",
        EditorTool::EditAlignmentPoints => "EditAP",
        EditorTool::AddAlignmentPoint { .. } => "AddAP",
    }
}

fn visualize(entity: &Entity, editor: &Editor) {
    println!("--- Scene visualization ---");
    println!("entity '{}' at {}", entity.name, entity.world_offset);
    println!("tool: {}", editor.tool_kind());
    
    for piece in &entity.pieces.pieces {
        let parent = match &piece.parent {
            None => "(root)".to_string(),
            Some((p, n)) => format!("parent={} via {}", p.0, n),
        };
        println!("  [{}] piece '{}' world {} {}",
                 piece.id.0, piece.name, piece.world_pos, parent);
        for ap in &piece.alignment_points {
            let world = piece.world_pos + ap.offset;
            let is_dragging = editor.dragging_point.as_ref()
                .map(|(pid, n)| *pid == piece.id && n == &ap.name)
                .unwrap_or(false);
            let marker = if is_dragging { "[*DRAG*]" } else { "[ ]" };
            println!("    {} ap '{}' world {} offset {}",
                     marker, ap.name, world, ap.offset);
        }
    }
}
