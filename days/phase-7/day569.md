# Day 569 · 从光探针位置光线投射

> Day 568 修好了 raycast。Day 569 Casey 把它用在"正确的地方"——从每个 light probe(光探针)位置射 N 条 ray,采周围环境光,写入 probe 自己的存储。这是 voxel GI 的核心更新逻辑。

## 0 · 为什么要有这一天

让我们把镜头贴近 voxel grid。你跟着 Handmade Hero 走到 Day 551——Casey 实现了 propagation(光扩散),voxel grid 里的光从光源扩散到邻居,**间接光产生了**。你跑游戏,场景比之前好——但**奇怪的事情发生了**:光照"漏墙"。一面墙后应该是黑的(墙挡光),但 voxel grid 显示墙后仍有微弱光——光"漏"过来了。

为什么?**因为 propagation 是"邻居平均",不考虑遮挡**。墙的 voxel 是 occupied,但 propagation 算法只看"邻居 voxel 是否 occupied",不看"邻居的邻居是否被墙挡"。具体:墙左侧 voxel(亮)→ 墙 voxel(不传播) → 墙右侧 voxel(应该是黑)。但如果 propagation 算"墙右侧 voxel 的邻居是墙,跳过;墙右侧 voxel 的另一个邻居是远处亮 voxel"——这远处亮 voxel 跨越墙的影响,光被"折线"传过来。

更准确的方法:**raycasting**——从每个 voxel(probe)位置射 64 条 ray(覆盖球面),每条 ray 沿方向走直到撞墙,沿途累加光。撞墙的位置,墙的反射颜色影响这条 ray 的"看见什么"。**raycasting 的关键**:ray 是直线,墙能完全挡住——光不可能"折线"传过来。

这叫 **probe raycasting**——比 propagation 准确,因为:

1. **考虑遮挡**:ray 撞墙才停,看不到墙后的光
2. **采样球面**:不是只 6 邻居,而是 64 方向(更细)
3. **可加 BRDF**:沿 ray 方向的颜色按 cos 加权(类似 Day 553)
4. **物理正确**:模拟"光沿直线传播"的物理定律

代价:每 probe 64 ray,每 ray 几十步 raycast。1000 个 probe = 几百万 raycast。CPU 上慢得不可承受,GPU 上可控——每 probe 一个 workgroup,64 thread 同时 raycast,并行执行。

Day 569 实现 probe raycasting,让 voxel GI 从 propagation 升级到 raycasting。**这是从"diffusion 模型"到"ray model"的升级**——视觉质量质变,但 GPU 计算量上升几个数量级。

完成这一天之后,你具备:

- 理解 probe-based GI 的更新流程——probe 作为"光采集器",每帧 raycast 采样环境
- 能用 raycast 累加球面光照,理解 attenuation 衰减和 max_steps 截断的工程意义
- 知道 propagation vs raycasting 的取舍——diffusion 简单但漏墙,raycasting 准确但贵
- 理解 GPU 并行 raycasting 的工作分配——每 probe 一个 workgroup,每 ray 一个 thread

## 1 · Casey 今天做了什么

Casey 的步骤:

第一步,他遍历所有 probe(每个非空 voxel):

- 从 probe 位置射 64 条 ray(Fibonacci 球面)
- 每 ray 用 Day 568 的 raycast 算法
- 累加 ray 沿途的 voxel 光照(被 occupied 衰减)

第二步,probe 把累加结果存进自己的 voxel(平均 / 加权)。

第三步,probe 之间**间接传播**——propagation 简单跑几次,让 raycast 结果扩散到邻居。

第四步,GPU 实现——每 probe 一个 workgroup,64 thread 同时 raycast。

视频里他演示:probe raycasting 让光照边界更锐利(因为考虑遮挡),propagation-only 让光"漏墙"。

## 2 · 心智模型

### 2.1 类比:用 64 个相机拍全景

你站在房间里某点,要拍"360 全景":

- 64 个相机围成球,各拍一个方向
- 每个相机看出去,可能看到墙、灯、家具
- 把 64 张照片拼起来 = 这点的"环境光"

**probe raycasting 就是这个**——每 ray 一个"虚拟相机",看出去采周围。Probe 把 64 张"照片"合成为自己的 irradiance(各方向光的积分)。

**Propagation(Day 551)则像"6 个邻居聊天"**——只问邻居的光,不直接看。**这是两者根本区别**:propagation 是"间接信息"(从邻居 hearsay),raycasting 是"直接观察"(自己看)。raycasting 能看见墙后(因为 ray 撞墙就停,知道"看不见"),propagation 不知道墙在哪里(只看 voxel 是否 occupied)。

**类比延伸**:raycasting 像"雷达"——主动发 ray 探测,精确但耗能。Propagation 像"传话游戏"——信息从邻居传过来,便宜但失真。两者都是光传播的近似,trade-off 在精确度 vs 计算成本。

**工业游戏的混合**:Unreal Lumen 用"raycasting for surface + propagation for volume"——表面用精确 raycasting,体积用 propagation 加速。这就是为什么 Lumen 既能跑得快又能看起来对。

### 2.2 严谨展开:probe raycast update

让我把 probe raycast 算法彻底展开,你会看到 ray-march 沿方向累加光照的精确逻辑。

```rust
fn update_probe(
    grid: &VoxelGrid,
    probe_pos: V3,
    sample_dirs: &[[f32; 3]],  // 64 个方向
) -> V3 {
    let mut sum = [0.0; 3];
    let mut count = 0;

    for dir in sample_dirs {
        // 沿 dir raycast,累加光照
        let mut t = 0.0;
        let mut attenuation = 1.0;
        let mut step_count = 0;
        let max_steps = 64;

        while step_count < max_steps {
            t += 1.0;
            let p = [
                probe_pos[0] + dir[0] * t,
                probe_pos[1] + dir[1] * t,
                probe_pos[2] + dir[2] * t,
            ];
            let i = p[0] as i64;
            let j = p[1] as i64;
            let k = p[2] as i64;
            if i < 0 || j < 0 || k < 0 ||
               i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
                break;
            }
            let voxel = grid.get(i as usize, j as usize, k as usize);
            sum[0] += voxel.light[0] * attenuation;
            sum[1] += voxel.light[1] * attenuation;
            sum[2] += voxel.light[2] * attenuation;

            if voxel.occupied {
                break;  // 撞墙,这条 ray 停
            }
            attenuation *= 0.95;
            step_count += 1;
        }
        count += 1;
    }

    [sum[0] / count as f32, sum[1] / count as f32, sum[2] / count as f32]
}
```

### Cosine-weighted 加权

如果 sample_dirs 是 cosine-weighted(Day 553),方向偏向某 normal,采样更有效。Casey 这天用均匀 Fibonacci(因为 probe 不固定 normal)。

如果 probe 知道自己表面的 normal(比如贴墙的 probe),可以用 cosine-weighted,效果更好。

## 3 · 四域深入

### 3.1 · 游戏编程视角

Probe-based GI 的工业实现:

- **DDGI**(NVIDIA):每 probe 64-256 ray,动态更新
- **Irradiance Volume**(Greger 1998):probe 网格,raycast 离线
- **Unreal Lightmass**:baked probe,用 raycasting offline

DDGI 和 Casey 这天的实现最像——probe 网格 + raycast update + propagation。

### 3.2 · 图形学原理

Probe raycasting 的数学:

```
E(p) = ∫_hemisphere L(p, ω) cos(θ) V(p, ω) dω
```

- E:irradiance
- L:radiance(从方向 ω)
- cos:Lambertian 因子
- V:visibility(被遮挡?)

离散化为 N ray:

```
E(p) ≈ Σ L(p, ω_i) cos(θ_i) V(p, ω_i) * Δω
```

每 ray 算 L(p, ω_i)——ray-march 沿方向,累加 voxel 光照。V(p, ω_i)——ray 撞墙就 = 0,否则 = 1。

### 3.3 · Linux 系统编程视角

"per-element update + scatter to neighbors"模式:

- **Cellular automata**:每 cell 独立更新,影响邻居
- **MapReduce**:per-record map,aggregate reduce
- **Database index update**:行变,更新索引

probe raycast 是 cellular automata 类——每 probe 独立算,结果 scatter 到自己的存储。

### 3.4 · 🦀 Rust 生态视角

Rust 用 rayon 并行 probe update:

```rust
use rayon::prelude::*;

grid.probes.par_iter_mut().for_each(|probe| {
    let result = update_probe(&grid, probe.pos, &sample_dirs);
    probe.irradiance = result;
});
```

注意 borrow——`grid` 共享读,`probe` 独立写。Rust borrow checker 保证安全。**Rayon 的设计哲学**:work-stealing scheduler,动态负载均衡——某些 probe 在简单区域(少 ray 撞墙)快完成,worker 偷其他 worker 的 probe 加速整体。这是为什么 rayon 比 OpenMP 的 `parallel for` 更高效——work-stealing 适应不规则工作量。

GPU 用 `wgpu::ComputePass`:

```rust
let mut pass = encoder.begin_compute_pass(&wgpu::ComputePassDescriptor { label: None });
pass.set_pipeline(&probe_update_pipeline);
pass.set_bind_group(0, &grid_bind_group, &[]);
pass.dispatch(probe_count as u32, 1, 1);  // 每 probe 一个 workgroup
```

**GPU 工作分配**:每个 probe 是一个 workgroup,workgroup 内 64 thread 各跑一条 ray。**64 是 GPU wave/warp 大小(AMD wave64 / NVIDIA warp32 * 2)的倍数**——让 GPU 充分并行。线程间共享 probe_pos(同 workgroup),用 shared memory (`workgroup_uniform`) 存。

**Rust GPU 生态的 probe raycast 实现**:
- `bevy` 的 `bevy_pbr` 模块有 DDGI-style probe update
- `rend3` 的 GI 用 voxel raycast
- `rust-gpu`(Rust to SPIR-V 编译器)可以写 shader 用 Rust 语法——类型安全、IDE 支持

**性能数字**:16³ voxel = 4096 probe,每 probe 64 ray,每 ray 32 步——总 ray-march 步 4096 × 64 × 32 = 8.4M。RTX 3060 上 8.4M ray-step 约 2 ms——60 FPS frame budget 16 ms 内能跑 8 次。这意味着 probe raycast 每帧可跑——dynamic GI 实时。

**题**:probe raycasting 比 propagation 准确,但慢。为什么不全部用 raycasting?

**参考解答**:(1) Raycasting 每 probe 64 ray,1000 probe = 64000 raycast,每 raycast 几十步 = 几百万 voxel fetch。GPU 上几 ms,但贵。(2) Propagation 每 probe 6 邻居读,极快(几 us),适合做"次要传播"。(3) Hybrid:主光源 raycast 算,间接光 propagation 算,平衡性能 / 质量。Casey 这天做 raycast,但 propagation 还在(Day 551),作为补充。

**参考解答**:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, Default)]
struct Voxel { light: V3, occupied: bool }

struct VoxelGrid {
    data: Vec<Voxel>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![Voxel::default(); dim*dim*dim], dim }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim + j) * self.dim + i
    }
    fn get(&self, i: usize, j: usize, k: usize) -> Voxel { self.data[self.idx(i, j, k)] }
    fn set(&mut self, i: usize, j: usize, k: usize, v: Voxel) {
        self.data[self.idx(i, j, k)] = v;
    }
}

fn fibonacci_dirs(n: usize) -> Vec<V3> {
    let mut pts = Vec::with_capacity(n);
    let golden = (1.0_f32 + 5.0_f32.sqrt()) / 2.0;
    let angle_inc = std::f32::consts::TAU * golden;
    for i in 0..n {
        let t = i as f32 / n as f32;
        let inc = (1.0 - 2.0 * t).acos();
        let az = angle_inc * i as f32;
        pts.push([inc.sin()*az.cos(), inc.sin()*az.sin(), inc.cos()]);
    }
    pts
}

// Propagation-based update(对照)
fn update_via_propagation(grid: &VoxelGrid, probe_pos: V3) -> V3 {
    let i = probe_pos[0] as usize;
    let j = probe_pos[1] as usize;
    let k = probe_pos[2] as usize;
    grid.get(i, j, k).light
}

// Raycast-based update(考虑遮挡)
fn update_via_raycast(
    grid: &VoxelGrid,
    probe_pos: V3,
    dirs: &[V3],
) -> V3 {
    let mut sum = [0.0f32; 3];
    let mut count = 0;

    for dir in dirs {
        let mut t = 0.0;
        let mut attenuation = 1.0;
        for _ in 0..32 {
            t += 1.0;
            let p = [
                probe_pos[0] + dir[0] * t,
                probe_pos[1] + dir[1] * t,
                probe_pos[2] + dir[2] * t,
            ];
            let i = p[0] as i64;
            let j = p[1] as i64;
            let k = p[2] as i64;
            if i < 0 || j < 0 || k < 0 ||
               i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
                break;
            }
            let voxel = grid.get(i as usize, j as usize, k as usize);
            sum[0] += voxel.light[0] * attenuation;
            sum[1] += voxel.light[1] * attenuation;
            sum[2] += voxel.light[2] * attenuation;
            if voxel.occupied { break; }
            attenuation *= 0.95;
        }
        count += 1;
    }

    [sum[0]/count as f32, sum[1]/count as f32, sum[2]/count as f32]
}

fn main() {
    let mut grid = VoxelGrid::new(16);

    // 光源
    grid.set(8, 8, 8, Voxel { light: [10.0, 8.0, 6.0], occupied: false });
    // 墙(在光源和 probe 之间)
    grid.set(6, 8, 8, Voxel { light: [0.0; 3], occupied: true });

    let probe_pos = [10.0, 8.0, 8.0];  // 光源对面,墙另一侧
    let dirs = fibonacci_dirs(16);

    let prop = update_via_propagation(&grid, probe_pos);
    let ray = update_via_raycast(&grid, probe_pos, &dirs);

    println!("Probe at {:?} (墙对面):", probe_pos);
    println!("  Propagation: ({:.3}, {:.3}, {:.3})", prop[0], prop[1], prop[2]);
    println!("  Raycast:     ({:.3}, {:.3}, {:.3})", ray[0], ray[1], ray[2]);
    // Propagation: 探针直接读自己 voxel 的 light(可能是 0,因为光源很远)
    // Raycast: 沿 16 个方向,只有不撞墙的方向能"看到"光源,所以总和可能小
    // 实际:墙挡住了光源到 probe 的直接路径,raycast 应该让 probe "暗"
}
```

## 8 · Rust / Arch 落地代码

完整 probe raycasting update:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, Default)]
struct Voxel { light: V3, occupied: bool, albedo: V3 }

struct VoxelGrid {
    data: Vec<Voxel>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![Voxel::default(); dim*dim*dim], dim }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim + j) * self.dim + i
    }
    fn get(&self, i: usize, j: usize, k: usize) -> Voxel { self.data[self.idx(i, j, k)] }
    fn set(&mut self, i: usize, j: usize, k: usize, v: Voxel) {
        self.data[self.idx(i, j, k)] = v;
    }
}

fn fibonacci_dirs(n: usize) -> Vec<V3> {
    let mut pts = Vec::with_capacity(n);
    let golden = (1.0_f32 + 5.0_f32.sqrt()) / 2.0;
    let angle_inc = std::f32::consts::TAU * golden;
    for i in 0..n {
        let t = i as f32 / n as f32;
        let inc = (1.0 - 2.0 * t).acos();
        let az = angle_inc * i as f32;
        pts.push([inc.sin()*az.cos(), inc.sin()*az.sin(), inc.cos()]);
    }
    pts
}

// 单条 ray 的累加
fn ray_march(
    grid: &VoxelGrid,
    origin: V3,
    dir: V3,
    max_steps: usize,
) -> V3 {
    let mut sum = [0.0; 3];
    let mut attenuation = 1.0;

    for step in 1..=max_steps {
        let t = step as f32;
        let p = [
            origin[0] + dir[0] * t,
            origin[1] + dir[1] * t,
            origin[2] + dir[2] * t,
        ];
        let i = p[0] as i64;
        let j = p[1] as i64;
        let k = p[2] as i64;
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            break;
        }
        let voxel = grid.get(i as usize, j as usize, k as usize);

        // 累加(光线被 voxel 的 albedo 染色)
        sum[0] += voxel.light[0] * voxel.albedo[0] * attenuation;
        sum[1] += voxel.light[1] * voxel.albedo[1] * attenuation;
        sum[2] += voxel.light[2] * voxel.albedo[2] * attenuation;

        if voxel.occupied { break; }
        attenuation *= 0.95;
    }
    sum
}

// Probe 通过 64 ray 更新自己的 irradiance
fn update_probe(
    grid: &VoxelGrid,
    probe_pos: V3,
    dirs: &[V3],
) -> V3 {
    let mut sum = [0.0; 3];
    let n = dirs.len() as f32;
    for dir in dirs {
        let contribution = ray_march(grid, probe_pos, *dir, 32);
        sum[0] += contribution[0];
        sum[1] += contribution[1];
        sum[2] += contribution[2];
    }
    [sum[0] / n, sum[1] / n, sum[2] / n]
}

// 更新所有 probe
fn update_all_probes(
    grid: &mut VoxelGrid,
    dirs: &[V3],
) {
    let dim = grid.dim;
    let snapshot = grid.data.clone();  // 双缓冲

    for k in 0..dim {
        for j in 0..dim {
            for i in 0..dim {
                if snapshot[(k * dim + j) * dim + i].occupied {
                    continue;  // 墙不是 probe
                }
                let probe_pos = [i as f32 + 0.5, j as f32 + 0.5, k as f32 + 0.5];

                // 用 snapshot 读,避免 in-place 干扰
                let mut temp_grid = VoxelGrid { data: snapshot.clone(), dim };
                let new_light = update_probe(&temp_grid, probe_pos, dirs);

                // 写回原 grid
                let existing = grid.get(i, j, k);
                grid.set(i, j, k, Voxel {
                    light: new_light,
                    occupied: existing.occupied,
                    albedo: existing.albedo,
                });
            }
        }
    }
}

fn main() {
    let mut grid = VoxelGrid::new(16);

    // 光源
    grid.set(8, 12, 8, Voxel {
        light: [5.0, 4.0, 3.0],
        occupied: false,
        albedo: [1.0; 3],
    });
    // 一些墙
    for j in 0..16 {
        grid.set(5, j, 5, Voxel {
            light: [0.0; 3], occupied: true, albedo: [0.8, 0.6, 0.4],
        });
    }

    let dirs = fibonacci_dirs(16);

    println!("Before probe update:");
    for pos in [(8, 5, 8), (3, 5, 3), (8, 12, 8)] {
        let v = grid.get(pos.0, pos.1, pos.2);
        println!("  ({},{},{}): light=({:.2},{:.2},{:.2}) occupied={}",
            pos.0, pos.1, pos.2, v.light[0], v.light[1], v.light[2], v.occupied);
    }

    update_all_probes(&mut grid, &dirs);

    println!("\nAfter probe update:");
    for pos in [(8, 5, 8), (3, 5, 3), (8, 12, 8)] {
        let v = grid.get(pos.0, pos.1, pos.2);
        println!("  ({},{},{}): light=({:.2},{:.2},{:.2}) occupied={}",
            pos.0, pos.1, pos.2, v.light[0], v.light[1], v.light[2], v.occupied);
    }
}
```

```rust
use rayon::prelude::*;
use std::sync::Mutex;

// snapshot 是共享读
let snapshot = grid.data.clone();
let snapshot_grid = VoxelGrid { data: snapshot, dim: grid.dim };

let updates: Vec<((usize, usize, usize), V3)> = (0..dim)
    .flat_map(|k| (0..dim).map(move |j| (j, k)))
    .flat_map(|(j, k)| (0..dim).map(move |i| (i, j, k)))
    .collect::<Vec<_>>()
    .par_iter()
    .filter_map(|&(i, j, k)| {
        let idx = (k * dim + j) * dim + i;
        if snapshot_grid.data[idx].occupied { return None; }
        let probe_pos = [i as f32 + 0.5, j as f32 + 0.5, k as f32 + 0.5];
        let new_light = update_probe(&snapshot_grid, probe_pos, dirs);
        Some(((i, j, k), new_light))
    })
    .collect();

for ((i, j, k), new_light) in updates {
    let existing = grid.get(i, j, k);
    grid.set(i, j, k, Voxel {
        light: new_light,
```
