### 解析器设计的通用方法论

工业级 parser 设计遵循"两阶段"方法:

**阶段 1:Lexer(词法分析)**。把字符流切成 token。Token 是最小的语法单位——identifier、string、number、symbol、keyword。

输入:`piece body { sprite = "hero_body" }`
输出:
```
[Identifier "piece"]
[Identifier "body"]
[LeftBrace]
[Identifier "sprite"]
[Equals]
[String "hero_body"]
[RightBrace]
```

Lexer 的核心是**有限状态机(FSM)**——根据当前字符决定下一步状态。

**阶段 2:Parser(语法分析)**。把 token 流构建成 AST。AST 是嵌套结构,反映语法嵌套。

```
HhtFile {
    entity: Entity {
        name: "hero",
        pieces: [
            Piece {
                name: "body",
                sprite: "hero_body"
            }
        ]
    }
}
```

Parser 用**递归下降**——每个语法结构对应一个函数,函数调用对应嵌套。

**为什么分两阶段?** 关注点分离。Lexer 关心"字符 → 单词",parser 关心"单词 → 结构"。两者算法不同(状态机 vs 递归),分开实现清晰。同一 lexer 服务多个 parser(IDE 高亮用 lexer,代码生成用 parser)。

### 工业级 parser 的 5 个要素

成熟 parser 库(`serde_json`、`toml-rs`、`rustc_parse`)的 5 个核心要素:

**1. Token 化(lexing)**。字符 → token 流,带位置信息(line / col)。

**2. 递归下降 parsing**。Token 流 → AST。每个语法结构对应函数。

**3. 位置追踪**。每个 token 记录 file / line / col / length。错误信息含位置。

**4. 错误恢复**。Parser 遇到错不立即停,跳过坏 token,继续报多个错。

**5. 友好错误信息**。Rust 风格:`"expected '=' but found '}' at line 5, col 12"`,带上下文 + 指针。

第二步,写 lexer——字符流 → token 流:

```rust
fn lex(text: &str) -> Vec<Token> {
    let mut tokens = Vec::new();
    let mut chars = text.chars().peekable();
    while let Some(&c) = chars.peek() {
        match c {
            '#' => { /* comment */ }
            '[' => { /* section */ }
            '"' => { /* quoted string */ }
            '=' => { tokens.push(Token::Equals); chars.next(); }
            '\n' => { tokens.push(Token::Newline); chars.next(); }
            _ if c.is_alphabetic() => { /* identifier */ }
            _ => { chars.next(); }
        }
    }
    tokens
}
```

第三步,写 parser——token 流 → AST:

```rust
fn parse(tokens: &[Token]) -> HhtFile {
    let mut pos = 0;
    let mut file = HhtFile::default();
    let mut section = String::new();
    
    while pos < tokens.len() {
        match &tokens[pos] {
            Token::Section(s) => { section = s.clone(); pos += 1; }
            Token::Identifier(name) => {
                pos += 1;
                if matches!(tokens.get(pos), Some(Token::Equals)) {
                    // key = value
                    pos += 1;
                    if let Some(Token::String(v)) = tokens.get(pos) {
                        file.add_kv(&section, name, v);
                        pos += 1;
                    }
                } else {
                    file.add_tag(&section, name);
                }
            }
            _ => { pos += 1; }
        }
    }
    file
}
```

第五步,加友好错误信息:`"expected '=' but found '}' at line 5, col 12"`。

## 2 · 心智模型

### 类比:翻译外文

读外文分两步:

1. **识别单词**:把字符流切成单词(token)
2. **理解结构**:单词组成句子(AST)

HHT 解析器同构:

1. **Lexer**(词法分析):字符 → token
2. **Parser**(语法分析):token → AST

每个单词 / token 是最小单位。AST(Abstract Syntax Tree,抽象语法树)是结构化表示。

### Token vs AST

**Token** 是扁平的单词流:

```
[Section, "bitmaps"]
[Identifier, "sword"]
[Equals]
[String, "path/to/sword.png"]
[Newline]
```

**AST** 是嵌套的结构:

```
HhtFile {
    sections: {
        "bitmaps": [
            Tag { name: "sword", value: "path/to/sword.png" }
        ]
    }
}
```

Parser 把扁平 token 流变成嵌套 AST。

### Lexer 状态机详解

Lexer 本质是**有限状态机(FSM,Finite State Machine)**。每个状态对应"当前正在读什么",字符决定状态转换。

HHT lexer 的状态机:

```
状态转换:
[Start] --letter--> [Identifier]
[Start] --digit--> [Number]
[Start] --'"'--> [String]
[Start] --'#'--> [Comment]
[Start] --'['--> emit LeftBracket, [Start]
[Start] --']'--> emit RightBracket, [Start]
[Start] --'='--> emit Equals, [Start]
[Start] --'\n'--> emit Newline, [Start]
[Start] --space/tab--> [Start]
[Start] --EOF--> emit Eof, [Done]

[Identifier] --letter/digit/underscore--> [Identifier]
[Identifier] --other--> emit Identifier, [Start]

[String] --any--> [String]
[String] --'"'--> emit String, [Start]
[String] --'\\'--> [Escape]

[Escape] --'n'--> push '\n', [String]
[Escape] --'t'--> push '\t', [String]
[Escape] --'"'--> push '"', [String]
[Escape] --'\\'--> push '\\', [String]

[Comment] --non-newline--> [Comment]
[Comment] --newline/EOF--> emit Comment, [Start]

[Number] --digit/dot/minus--> [Number]
[Number] --other--> emit Number, [Start]
```

每个状态决定怎么处理下一字符。简单 HHT lexer 大概 5-7 个状态,真实 parser 库(JSON parser)有 20+ 状态。

**手写 lexer vs 用工具**:手写适合小语言(HHT、INI),工具(`flex`、`logos` crate)适合大语言(JSON、Python)。Casey 手写,因为 HHT 简单。

### 递归下降解析的原理

递归下降 parser 用**递归函数对应每个语法结构**。函数调用 = 语法嵌套。

以 HHT 为例:

```rust
// parse 一个完整文件
fn parse_file(tokens) -> HhtFile {
    let mut sections = Vec::new();
    while peek_token() != Eof {
        sections.push(parse_section());    // 递归调用
    }
    HhtFile { sections }
}

// parse 一个 section
fn parse_section(tokens) -> Section {
    expect(Token::LeftBracket);
    let name = parse_identifier();
    expect(Token::RightBracket);
    expect(Token::Newline);

    let mut tags = Vec::new();
    while peek_token() != Token::LeftBracket && peek_token() != Token::Eof {
        tags.push(parse_tag());    // 递归调用
    }
    Section { name, tags }
}

// parse 一个 tag
fn parse_tag(tokens) -> Tag {
    let name = parse_identifier();
    if peek_token() == Token::Equals {
        consume(Equals);
        let value = parse_string();
        Tag { name, value: Some(value) }
    } else {
        Tag { name, value: None }
    }
}

// parse 一个 identifier
fn parse_identifier(tokens) -> String {
    if let Token::Identifier(s) = next_token() {
        s
    } else {
        panic!("expected identifier");
    }
}
```

每个函数消费 token,返回 AST 节点。函数调用对应语法嵌套——`parse_section` 调用 `parse_tag`,`parse_tag` 调用 `parse_identifier`。

**为什么叫"递归下降"?** 因为 parsing 是从顶(整个文件)向下(单个 token),通过递归调用。每个函数"下降"一层语法。

**为什么用递归?** 因为语法本身是递归的——entity 包含 piece,piece 包含 alignment_point,alignment_point 包含元组。递归函数自然处理递归语法。

### 错误恢复与多错误报告

简单 parser:遇到错就 panic 或返回 Err。用户每次只看一个错。

**错误恢复(error recovery)**:遇到错,跳过坏 token,试图恢复,继续解析。一次报告多个错。

具体策略(以 HHT 为例):

```
看到 unknown keyword:跳到下一个 '\n'(行尾)
看到不期望的 '{':跳过这个 token,假设后续可能合理
看到不期望的 '}':记录错误,继续(因为可能 '}' 应该忽略)
看到不期望的 EOF:记录错误,终止 parse
```

每个错误后,parser "复位"到一个**合理状态**——通常是 statement 边界(行尾、`}`、`;`)。

工业级编译器(rustc、clang)用错误恢复,一次报告所有错误。用户一次修多个,迭代快。

代价:错误恢复复杂(可能误报"级联错误"——一个真错导致后面 10 个假错)。但工业级值得。

### 位置追踪

每个 token 记录 line / col / length:

```rust
struct Token {
    kind: TokenKind,
    line: u32,        // 1-based 行号
    col: u32,         // 1-based 列号
    length: u32,      // token 长度
}
```

错误信息含位置:

```
Error: expected '=' but found '"'
  --> assets.hht:5:12
   |
 5 |     sprite "hero_body"
   |            ^
```

`^^^^` 在错 token 下方。多 token 错误用 `~^^^~` 范围。

工业级 parser 必须有位置追踪。Casey Day 510 加基础位置,Day 518 完善错误显示。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 lexer 和 parser 分开,不合一?

**参考解答**:三个理由:

第一,**关注点分离**。Lexer 关心字符 → 单词,parser 关心单词 → 结构。两者算法不同(状态机 vs 递归下降),分开实现清晰。

第二,**复用**。同一 lexer 可服务多个 parser(如 IDE 高亮用 lexer,代码生成用 parser)。

第三,**错误恢复**。Lexer 错误(非法字符)和 parser 错误(语法结构错)处理方式不同,分开易定制。

合一的(scannerless parser)存在,但少用,因为上述优势。

### Lv2 · 动手实践

**题**:实现 token 化 + 解析。支持:string、section、tag、key=value、注释。给定 HHT 文本,输出 token 流 + AST。

完成标准:`cargo run` 输出 token 流,然后 AST。

**参考解答**:

```rust
use std::collections::HashMap;

#[derive(Debug, Clone, PartialEq)]
enum TokenKind {
    Section(String),
    Identifier(String),
    String(String),
    Equals,
    Newline,
    Comment(String),
    Eof,
}

#[derive(Debug, Clone)]
struct Token {
    kind: TokenKind,
    line: u32,
    col: u32,
}

struct Lexer<'a> {
    chars: Vec<char>,
    pos: usize,
    line: u32,
    col: u32,
    _phantom: std::marker::PhantomData<&'a str>,
}

impl<'a> Lexer<'a> {
    fn new(text: &'a str) -> Self {
        Self {
            chars: text.chars().collect(),
            pos: 0, line: 1, col: 1,
            _phantom: std::marker::PhantomData,
        }
    }
    
    fn peek(&self) -> Option<char> {
        self.chars.get(self.pos).copied()
    }
    
    fn advance(&mut self) -> Option<char> {
        let c = self.chars.get(self.pos).copied();
        if let Some(ch) = c {
            self.pos += 1;
            if ch == '\n' { self.line += 1; self.col = 1; }
            else { self.col += 1; }
        }
        c
    }
    
    fn skip_whitespace_inline(&mut self) {
        while let Some(c) = self.peek() {
            if c == ' ' || c == '\t' {
                self.advance();
            } else {
                break;
            }
        }
    }
    
    fn lex_all(&mut self) -> Vec<Token> {
        let mut tokens = Vec::new();
        
        loop {
            self.skip_whitespace_inline();
            
            let c = match self.peek() {
                Some(c) => c,
                None => {
                    tokens.push(Token { kind: TokenKind::Eof, line: self.line, col: self.col });
                    break;
                }
            };
            
            let line = self.line;
            let col = self.col;
            
            if c == '\n' {
                self.advance();
                tokens.push(Token { kind: TokenKind::Newline, line, col });
            } else if c == '#' {
                // comment
                let mut s = String::new();
                while let Some(c) = self.peek() {
                    if c == '\n' { break; }
                    s.push(c);
                    self.advance();
                }
                tokens.push(Token { kind: TokenKind::Comment(s), line, col });
            } else if c == '[' {
                // section
                self.advance();
                let mut name = String::new();
                while let Some(c) = self.peek() {
                    if c == ']' { break; }
                    name.push(c);
                    self.advance();
                }
                self.advance();    // ]
                tokens.push(Token { kind: TokenKind::Section(name.trim().to_string()), line, col });
            } else if c == '"' {
                self.advance();
                let mut s = String::new();
                while let Some(c) = self.peek() {
                    if c == '"' { break; }
                    if c == '\\' {
                        self.advance();
                        if let Some(esc) = self.peek() {
                            match esc {
                                'n' => s.push('\n'),
                                't' => s.push('\t'),
                                '"' => s.push('"'),
                                '\\' => s.push('\\'),
                                _ => s.push(esc),
                            }
                            self.advance();
                        }
                    } else {
                        s.push(c);
                        self.advance();
                    }
                }
                self.advance();    // closing "
                tokens.push(Token { kind: TokenKind::String(s), line, col });
            } else if c == '=' {
                self.advance();
                tokens.push(Token { kind: TokenKind::Equals, line, col });
            } else if c.is_alphanumeric() || c == '_' {
                let mut name = String::new();
                while let Some(c) = self.peek() {
                    if c.is_alphanumeric() || c == '_' || c == '/' || c == '.' || c == '-' {
                        name.push(c);
                        self.advance();
                    } else {
                        break;
                    }
                }
                tokens.push(Token { kind: TokenKind::Identifier(name), line, col });
            } else {
                self.advance();    // 跳过未知
            }
        }
        
        tokens
    }
}

#[derive(Debug, Default, Clone)]
struct HhtFile {
    sections: HashMap<String, Vec<Tag>>,
}

#[derive(Debug, Clone)]
struct Tag {
    name: String,
    value: Option<String>,
}

fn parse(tokens: &[Token]) -> HhtFile {
    let mut file = HhtFile::default();
    let mut pos = 0;
    let mut current_section = String::new();
    
    while pos < tokens.len() {
        match &tokens[pos].kind {
            TokenKind::Eof => break,
            TokenKind::Section(name) => {
                current_section = name.clone();
                pos += 1;
            }
            TokenKind::Identifier(name) => {
                let name = name.clone();
                pos += 1;
                let value = if pos < tokens.len() {
                    if matches!(tokens[pos].kind, TokenKind::Equals) {
                        pos += 1;
                        if let TokenKind::String(v) = &tokens[pos].kind {
                            let v = v.clone();
                            pos += 1;
                            Some(v)
                        } else { None }
                    } else { None }
                } else { None };
                
                file.sections.entry(current_section.clone()).or_default()
                    .push(Tag { name, value });
            }
            _ => { pos += 1; }
        }
    }
    
    file
}

fn main() {
    let text = r#"
# HHT example
[bitmaps]
player
sword = "path/to/sword.png"
goblin = "enemies/goblin.png"

[sounds]
footstep
swing = "audio/swing.wav"
"#;
    
    println!("=== Lexing ===\n");
    let mut lexer = Lexer::new(text);
    let tokens = lexer.lex_all();
    
    for tok in &tokens {
        if !matches!(tok.kind, TokenKind::Newline) {
            println!("  L{}:C{} {:?}", tok.line, tok.col, tok.kind);
        }
    }
    
    println!("\n=== Parsing ===\n");
    let file = parse(&tokens);
    
    for (section, tags) in &file.sections {
        println!("[{}]", section);
        for tag in tags {
            match &tag.value {
                Some(v) => println!("  {} = {:?}", tag.name, v),
                None => println!("  {}", tag.name),
            }
        }
    }
}
```
