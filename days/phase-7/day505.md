> 关卡设计师要铺一片树林——一棵一棵点太慢。Day 505 给编辑器加"刷子"模式:鼠标拖动时连续放置 entity(树、石头、草),按间隔撒。

## 0 · 为什么要有这一天

Day 492 加了点击放置一个 entity。但实际设计关卡时,经常要"一片":

- 森林:100 棵树,分布在 100x100 区域
- 草地:1000 根草,随机散布
- 石堆:10 块石头,堆在一起

一棵一棵点 = 1000 次点击 = 设计师疯掉。

工业级编辑器有"刷子"工具:鼠标拖动时,按规则(间隔 / 随机 / 噪声)连续放置。

Day 505 实现 3 种刷子模式:

- **Grid brush**:网格刷,固定间隔放(整齐)
- **Random brush**:随机刷,在鼠标附近随机位置(自然)
- **Jittered grid**:抖动网格,网格 + 随机偏移(中间)

为什么这件事重要?因为**关卡设计效率决定项目成败**。手点 100 棵树要 1 小时,刷子 5 秒。商业游戏开发,工具的效率是核心竞争优势。

- 实现 brush 工具的核心算法
- 处理"拖动时连续触发"的事件流
- 在游戏世界撒点(spatial distribution)
- 控制刷子的密度 / 大小 / 模式

## 2 · 心智模型

### 类比:画图软件的刷子

Photoshop 的笔刷:鼠标按下,拖动,笔刷连续留下痕迹。笔刷有大小、硬度、间隔、散布。

Casey 的 entity 刷子同构:鼠标按下拖动,entity 连续"画"到场景。

差异:Photoshop 画的是像素,Casey 画的是 entity。

### Brush 间隔控制

最简单的刷子:鼠标每移动 N 像素,放一个 entity。

```rust
if (mouse - last_place_pos).length() > spacing {
    place_entity(mouse);
    last_place_pos = mouse;
}
```

间距 = spacing。spacing 大 = 稀疏,小 = 密集。

### Grid Brush

更整齐:把世界分成网格,每个 grid cell 中心放一个 entity。

```rust
let cell_x = (mouse.x / cell_size).floor() * cell_size + cell_size / 2.0;
let cell_y = (mouse.y / cell_size).floor() * cell_size + cell_size / 2.0;
place_entity((cell_x, cell_y));
```

优势:整齐对齐。劣势:机械感强。

### Random Brush

每次放置,在鼠标周围随机偏移:

```rust
let angle = rng.gen::<f32>() * 2.0 * PI;
let radius = rng.gen::<f32>() * brush_radius;
let offset = (angle.cos() * radius, angle.sin() * radius);
place_entity(mouse + offset);
```

优势:自然。劣势:可能重叠,分布不均。

### Jittered Grid

最常用的"中间方案":grid + 抖动。

```rust
let cell_x = floor(mouse.x / cell_size) * cell_size;
let cell_y = floor(mouse.y / cell_size) * cell_size;
let jitter_x = (rng.gen::<f32>() - 0.5) * cell_size;
let jitter_y = (rng.gen::<f32>() - 0.5) * cell_size;
place_entity(cell + jitter);
```

每个 cell 内随机偏移。结果:大致整齐但不机械。

这是 procedural generation 的经典技巧。Poisson disk sampling 是更高级版本。

### Stroke(笔触)概念

鼠标按下 → 移动 → 抬起,是一次 stroke。

Stroke 内连续放置,但 stroke 之间不连续。区分:

- stroke_start:鼠标按下,记录起点
- stroke_move:鼠标移动,按 spacing 放置
- stroke_end:鼠标抬起,结束

```rust
enum BrushState {
    Idle,
    Stroking { last_place: Vec2, accumulator: f32 },
}
```

`accumulator` 累积移动距离,超过 spacing 时放置一次。这样不漏点(高速移动)。

struct Brush {
    mode: BrushMode,
    radius: f32,
    spacing: f32,
    entity_type: EntityType,
}

enum BrushMode {
    Grid { cell_size: f32 },
    Random,
    Jittered { cell_size: f32, jitter: f32 },
}

impl Brush {
    fn should_place(&self, last: Vec2, current: Vec2) -> bool {
        (current - last).length() >= self.spacing
    }
    
    fn placement_pos(&self, mouse: Vec2, rng: &mut impl Rng) -> Vec2 {
        match self.mode {
            BrushMode::Grid { cell_size } => {
                let cx = (mouse.x / cell_size).floor() * cell_size + cell_size / 2.0;
                let cy = (mouse.y / cell_size).floor() * cell_size + cell_size / 2.0;
                Vec2::new(cx, cy)
            }
            BrushMode::Random => {
                let angle = rng.gen::<f32>() * 2.0 * std::f32::consts::PI;
                let r = rng.gen::<f32>() * self.radius;
                mouse + Vec2::new(angle.cos() * r, angle.sin() * r)
            }
            BrushMode::Jittered { cell_size, jitter } => {
                let cx = (mouse.x / cell_size).floor() * cell_size + cell_size / 2.0;
                let cy = (mouse.y / cell_size).floor() * cell_size + cell_size / 2.0;
                let jx = (rng.gen::<f32>() - 0.5) * jitter;
                let jy = (rng.gen::<f32>() - 0.5) * jitter;
                Vec2::new(cx + jx, cy + jy)
            }
        }
    }
}

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 jittered grid 比 pure random 更"好看"?

**参考解答**:Pure random 会导致聚集(几个点挤在一起)和空洞(大片没点)。视觉上不均匀,显得"乱"。

Jittered grid 保证每个网格 cell 内恰好一个点(只是位置抖动),所以:

- 没有聚集(cell 内只有一个)
- 没有空洞(cell 都有点)
- 仍有自然变化(位置抖动)

视觉上"均匀而自然"。这是 procedural generation 的基本美学。

更高级的 Poisson disk sampling 进一步保证任意两点最小距离,更均匀。

use rand::Rng;

#[derive(Copy, Clone, Debug)]
struct Vec2 { x: f32, y: f32 }

impl Vec2 {
    fn new(x: f32, y: f32) -> Self { Self { x, y } }
    fn length(self) -> f32 { (self.x * self.x + self.y * self.y).sqrt() }
}

impl std::ops::Add for Vec2 {
    type Output = Vec2;
    fn add(self, o: Vec2) -> Vec2 { Vec2::new(self.x + o.x, self.y + o.y) }
}

impl std::ops::Sub for Vec2 {
    type Output = Vec2;
    fn sub(self, o: Vec2) -> Vec2 { Vec2::new(self.x - o.x, self.y - o.y) }
}

#[derive(Clone)]
enum BrushMode {
    Grid { cell_size: f32 },
    Random,
    Jittered { cell_size: f32, jitter: f32 },
}

struct Brush {
    mode: BrushMode,
    spacing: f32,
}

impl Brush {
    fn placement_pos(&self, mouse: Vec2, rng: &mut impl Rng) -> Vec2 {
        match &self.mode {
            BrushMode::Grid { cell_size } => {
                let cx = (mouse.x / cell_size).floor() * cell_size + cell_size / 2.0;
                let cy = (mouse.y / cell_size).floor() * cell_size + cell_size / 2.0;
                Vec2::new(cx, cy)
            }
            BrushMode::Random => {
                let angle = rng.gen::<f32>() * 2.0 * std::f32::consts::PI;
                let r = rng.gen::<f32>() * 10.0;
                Vec2::new(mouse.x + angle.cos() * r, mouse.y + angle.sin() * r)
            }
            BrushMode::Jittered { cell_size, jitter } => {
                let cx = (mouse.x / cell_size).floor() * cell_size + cell_size / 2.0;
                let cy = (mouse.y / cell_size).floor() * cell_size + cell_size / 2.0;
                let jx = (rng.gen::<f32>() - 0.5) * jitter;
                let jy = (rng.gen::<f32>() - 0.5) * jitter;
                Vec2::new(cx + jx, cy + jy)
            }
        }
    }
}

fn simulate_stroke(brush: &Brush, start: Vec2, end: Vec2, rng: &mut impl Rng, count: usize) -> Vec<Vec2> {
    let mut positions = Vec::new();
    let total_dist = (end - start).length();
    let step = total_dist / count as f32;
    
    let direction = Vec2::new(
        (end.x - start.x) / total_dist,
        (end.y - start.y) / total_dist,
    );
    
    for i in 0..count {
        let mouse = Vec2::new(
            start.x + direction.x * step * i as f32,
            start.y + direction.y * step * i as f32,
        );
        positions.push(brush.placement_pos(mouse, rng));
    }
    
    positions
}

fn main() {
    let mut rng = rand::thread_rng();
    
    println!("=== Grid Brush (cell=10) ===");
    let brush = Brush {
        mode: BrushMode::Grid { cell_size: 10.0 },
        spacing: 10.0,
    };
    let positions = simulate_stroke(&brush, Vec2::new(0.0, 0.0), Vec2::new(100.0, 0.0), &mut rng, 10);
    for (i, p) in positions.iter().enumerate() {
        println!("  {}: ({:.1}, {:.1})", i, p.x, p.y);
    }
    
    println!("\n=== Random Brush ===");
    let brush = Brush {
        mode: BrushMode::Random,
        spacing: 5.0,
    };
    let positions = simulate_stroke(&brush, Vec2::new(0.0, 0.0), Vec2::new(100.0, 0.0), &mut rng, 10);
    for (i, p) in positions.iter().enumerate() {
        println!("  {}: ({:.1}, {:.1})", i, p.x, p.y);

    println!("\n=== Jittered Grid (cell=10, jitter=10) ===");

use rand::Rng;
use std::fmt;

#[derive(Copy, Clone, Debug, PartialEq)]
struct Vec2 { x: f32, y: f32 }

impl Vec2 {
    const fn new(x: f32, y: f32) -> Self { Self { x, y } }
    const ZERO: Self = Self::new(0.0, 0.0);
    fn length(self) -> f32 { (self.x * self.x + self.y * self.y).sqrt() }
}

impl std::ops::Add for Vec2 {
    type Output = Vec2;
    fn add(self, o: Vec2) -> Vec2 { Vec2::new(self.x + o.x, self.y + o.y) }
}

impl std::ops::Sub for Vec2 {
    type Output = Vec2;
    fn sub(self, o: Vec2) -> Vec2 { Vec2::new(self.x - o.x, self.y - o.y) }
}

impl fmt::Display for Vec2 {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "({:.1},{:.1})", self.x, self.y)
    }
}

// ============================================================
// Entity types
// ============================================================

#[derive(Debug, Clone, Copy, PartialEq)]
enum EntityType { Tree, Rock, Grass, Flower }

impl fmt::Display for EntityType {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        let c = match self {
            EntityType::Tree => 'T',
            EntityType::Rock => 'R',
            EntityType::Grass => 'g',
            EntityType::Flower => 'F',
        };
        write!(f, "{}", c)
    }
}

#[derive(Debug, Clone)]
struct Entity {
    pos: Vec2,
    entity_type: EntityType,
    rotation: f32,
    scale: f32,
}

// ============================================================
// Brush modes
// ============================================================

#[derive(Clone)]
enum BrushMode {
    Stamp,
    Grid { cell_size: f32 },
    Random { radius: f32 },
    Jittered { cell_size: f32, jitter: f32 },
    PoissonDisk { min_distance: f32 },
}

impl fmt::Display for BrushMode {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            BrushMode::Stamp => write!(f, "Stamp"),
            BrushMode::Grid { cell_size } => write!(f, "Grid(cell={:.1})", cell_size),
            BrushMode::Random { radius } => write!(f, "Random(r={:.1})", radius),
            BrushMode::Jittered { cell_size, jitter } => write!(f, "Jittered(cell={:.1},jit={:.1})", cell_size, jitter),
            BrushMode::PoissonDisk { min_distance } => write!(f, "Poisson(min={:.1})", min_distance),
        }
    }
}

// ============================================================
// Brush
// ============================================================

struct Brush {
    mode: BrushMode,
    entity_type: EntityType,
    spacing: f32,
    random_rotation: bool,
    random_scale_range: Option<(f32, f32)>,
}

impl Brush {
    fn new(mode: BrushMode, entity_type: EntityType) -> Self {
        Self {
            mode, entity_type,
            spacing: 10.0,
            random_rotation: false,
            random_scale_range: None,
        }
    }
    
    fn placement_pos(&self, mouse: Vec2, rng: &mut impl Rng) -> Vec2 {
        match &self.mode {
            BrushMode::Stamp => mouse,
            BrushMode::Grid { cell_size } => {
                let cx = (mouse.x / cell_size).floor() * cell_size + cell_size / 2.0;
                let cy = (mouse.y / cell_size).floor() * cell_size + cell_size / 2.0;
                Vec2::new(cx, cy)
            }
            BrushMode::Random { radius } => {
                let angle = rng.gen::<f32>() * 2.0 * std::f32::consts::PI;
                let r = rng.gen::<f32>() * radius;
                Vec2::new(mouse.x + angle.cos() * r, mouse.y + angle.sin() * r)
            }
            BrushMode::Jittered { cell_size, jitter } => {
                let cx = (mouse.x / cell_size).floor() * cell_size + cell_size / 2.0;
                let cy = (mouse.y / cell_size).floor() * cell_size + cell_size / 2.0;
                let jx = (rng.gen::<f32>() - 0.5) * jitter;
                let jy = (rng.gen::<f32>() - 0.5) * jitter;
                Vec2::new(cx + jx, cy + jy)
            }
            BrushMode::PoissonDisk { min_distance } => {
                // 简化:类似 random,但用 min_distance 隐含约束
                // (真实 Poisson disk 需要全局状态)
                let angle = rng.gen::<f32>() * 2.0 * std::f32::consts::PI;
                let r = *min_distance + rng.gen::<f32>() * min_distance;
                Vec2::new(mouse.x + angle.cos() * r, mouse.y + angle.sin() * r)
            }
        }
    }
    
    fn make_entity(&self, pos: Vec2, rng: &mut impl Rng) -> Entity {
        let rotation = if self.random_rotation {
            rng.gen::<f32>() * 2.0 * std::f32::consts::PI
        } else {
            0.0
        };
        let scale = if let Some((lo, hi)) = self.random_scale_range {
            rng.gen_range(lo..=hi)
        } else {
            1.0
        };
        Entity {
            pos, entity_type: self.entity_type,
            rotation, scale,
        }
    }
}

// Stroke state machine
// ============================================================

#[derive(Debug)]
enum StrokeState {
    Idle,
    Active { last_placement: Vec2, accumulator: f32 },
}

struct EditorBrush {
    brush: Brush,
    state: StrokeState,
}

impl EditorBrush {
    fn new(brush: Brush) -> Self {
        Self { brush, state: StrokeState::Idle }
    }
    
    fn stroke_start(&mut self, mouse: Vec2, rng: &mut impl Rng, entities: &mut Vec<Entity>) {
        let pos = self.brush.placement_pos(mouse, rng);
        let entity = self.brush.make_entity(pos, rng);
        entities.push(entity);
        self.state = StrokeState::Active {
            last_placement: pos,
            accumulator: 0.0,
        };
    }
    
    fn stroke_move(&mut self, mouse: Vec2, rng: &mut impl Rng, entities: &mut Vec<Entity>) {
        if let StrokeState::Active { last_placement, accumulator } = &mut self.state {
            let last = *last_placement;
            let moved = (mouse - last).length();
            *accumulator += moved;
            
            while *accumulator >= self.brush.spacing {
                *accumulator -= self.brush.spacing;
                // 在 last 到 mouse 的连线上,放一个点
                let t = (*accumulator + self.brush.spacing) / moved.max(0.001);
                let raw_pos = Vec2::new(
                    last.x + (mouse.x - last.x) * t,
                    last.y + (mouse.y - last.y) * t,
                );
                let pos = self.brush.placement_pos(raw_pos, rng);
                let entity = self.brush.make_entity(pos, rng);
                entities.push(entity);
                *last_placement = pos;
            }
        }
    }
    
    fn stroke_end(&mut self) {
        self.state = StrokeState::Idle;
    }
}

fn render_to_ascii(entities: &[Entity], width: u32, height: u32, scale: f32) {
    let w = (width as f32 * scale) as usize;
    let h = (height as f32 * scale) as usize;
    let mut grid = vec![vec!['.'; w]; h];
    
    for e in entities {
        let gx = (e.pos.x * scale) as usize;
        let gy = (e.pos.y * scale) as usize;
        if gx < w && gy < h {
            grid[gy][gx] = e.entity_type.to_string().chars().next().unwrap();
        }
    }
    
    for row in &grid {
        let s: String = row.iter().collect();
        println!("{}", s);
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    
    #[test]
    fn test_grid_brush_snaps() {
        let brush = Brush::new(BrushMode::Grid { cell_size: 10.0 }, EntityType::Tree);
        let mut rng = rand::thread_rng();
        
        let p = brush.placement_pos(Vec2::new(7.0, 3.0), &mut rng);
        // 网格中心 5,5
        assert_eq!(p.x, 5.0);
        assert_eq!(p.y, 5.0);
        
        let p = brush.placement_pos(Vec2::new(12.0, 18.0), &mut rng);
        // 网格中心 15,15
        assert_eq!(p.x, 15.0);
        assert_eq!(p.y, 15.0);
    }
    
    #[test]
    fn test_random_brush_within_radius() {
        let brush = Brush::new(BrushMode::Random { radius: 10.0 }, EntityType::Tree);
        let mut rng = rand::thread_rng();
        
        for _ in 0..100 {
            let p = brush.placement_pos(Vec2::new(50.0, 50.0), &mut rng);
            let dist = ((p.x - 50.0).powi(2) + (p.y - 50.0).powi(2)).sqrt();
            assert!(dist <= 10.0);
        }
    }
    
    #[test]
    fn test_jittered_brush_in_cell() {
        let brush = Brush::new(
            BrushMode::Jittered { cell_size: 10.0, jitter: 10.0 },
            EntityType::Tree,
        );
        let mut rng = rand::thread_rng();
        
        for _ in 0..100 {
            let p = brush.placement_pos(Vec2::new(5.0, 5.0), &mut rng);
            // 应在 cell (0,0) 附近
            assert!(p.x >= -5.0 && p.x <= 15.0);
            assert!(p.y >= -5.0 && p.y <= 15.0);
        }
    }
    
    #[test]
    fn test_stroke_accumulator() {
        let brush = Brush {
            mode: BrushMode::Stamp,
            entity_type: EntityType::Tree,
            spacing: 20.0,
            random_rotation: false,
            random_scale_range: None,
        };
        let mut editor = EditorBrush::new(brush);
        let mut rng = rand::thread_rng();
        let mut entities = Vec::new();
        
        // 起始:1 个
        editor.stroke_start(Vec2::new(0.0, 0.0), &mut rng, &mut entities);
        assert_eq!(entities.len(), 1);
        
        // 移动 5(小于 spacing):不应放
        editor.stroke_move(Vec2::new(5.0, 0.0), &mut rng, &mut entities);
        assert_eq!(entities.len(), 1);
        
        // 移动到 30:应放一个
        editor.stroke_move(Vec2::new(30.0, 0.0), &mut rng, &mut entities);
        assert!(entities.len() >= 2);
    }

    fn test_stroke_end_resets() {
        let brush = Brush::new(BrushMode::Stamp, EntityType::Tree);
        let mut editor = EditorBrush::new(brush);
        let mut rng = rand::thread_rng();
        let mut entities = Vec::new();
        
        editor.stroke_start(Vec2::new(0.0, 0.0), &mut rng, &mut entities);
        assert!(matches!(editor.state, StrokeState::Active { .. }));
        
        editor.stroke_end();
        assert!(matches!(editor.state, StrokeState::Idle));
    }
