# Day 550 · SIMD 光线投射点与法线计算

> Voxel 光照的关键操作是 **raycast**——从某点出发,沿方向走,问"沿途经过了哪些 voxel,有没有撞到墙"。如果每帧要做几百万次 raycast,串行太慢。Day 550 Casey 用 **SIMD**(单指令多数据)一次处理 4 条射线,GPU/CPU 利用率 4 倍提升。

## 0 · 为什么要有这一天

先解释 **SIMD**。CPU 一次常规操作(加、乘、比较)只处理一个数,叫 **scalar(标量)**。但现代 CPU 有 **SIMD 寄存器**(SSE/AVX),一条指令同时处理 4/8/16 个数。

例子:4 个 f32 加 4 个 f32。

- Scalar:4 条 add 指令
- SSE(128-bit):1 条 add 指令,同时算 4 个 f32

加速 4 倍(理论上)。

光线投射(raycast)是 SIMD 的理想场景:

- 一帧从相机发出 100 万条 ray
- 每条 ray 的算法相同(沿方向走,查 voxel)
- 数据结构相同(voxel grid)

这种"重复算法 + 独立数据"的模式,SIMD 完美匹配。

Casey 在 Day 547-549 是 scalar 实现先把功能跑通,Day 550 用 SIMD 优化"光线 vs voxel"的核心循环。

完成这一天之后,你具备:

- 理解 SIMD 的原理和适用场景
- 能用 Rust 的 portable-simd 写 4-wide 代码
- 知道 raycast 的 Amanatides-Woo 算法

## 1 · Casey 今天做了什么

Casey 的步骤:

第一步,他识别"热点循环"——raycast 中每步算下一个 voxel 索引、查 occupied、算碰撞点。每条 ray 走 10-100 步,1M ray = 10M-100M 步操作。

第二步,他把 4 条 ray 打包,用 SSE/AVX 同时算:

- 4 个 ray origin 拼成 `__m128`(SSE 128-bit,4 个 f32)
- 4 个 ray direction 拼成 `__m128`
- 算下一步的 t 值:一次 `_mm_add_ps` 同时算 4 个

第三步,处理 divergence(分叉):如果 ray 1 在第 5 步撞墙,ray 2 还在走,要 mask 掉 ray 1,继续 ray 2。SIMD 必须齐步走,但逻辑上每条 ray 独立——用 mask 暂停"已完成"的 ray。

视频里他强调:"SIMD 优化 50% 是数据布局,30% 是指令选择,20% 是分支优化。" 数据布局最重要——如果数据不能 16 字节对齐,SIMD 加载慢。

## 2 · 心智模型

### 类比:超市 4 个收银台同时收

想象超市有 4 个收银台。每个收银员处理一个顾客(算一个 ray)。串行:1 个收银员处理 4 个顾客 = 4 倍时间。并行(4 个收银员):4 个顾客同时处理 = 1 倍时间。

但有个限制:4 个收银员必须**同步**——一个收银员处理完一个顾客,要等其他人也处理完,才能开始下一批。如果一个顾客买的特别多,其他收银员要等。

SIMD 是这个超市:4 条 ray 同时算一步,如果某条 ray 已经撞墙(完成),它的"收银员"在 mask 标记下空闲,继续参与运算但不更新结果。

### 严谨展开:Amanatides-Woo voxel traversal

经典算法,1987 年提出。给定 ray 起点 origin、方向 dir、grid 大小,遍历 ray 经过的所有 voxel。

```rust
fn amanatides_woo(
    origin: [f32; 3], dir: [f32; 3],
    grid: &VoxelGrid,
) -> Option<VoxelHit> {
    let voxel_size = grid.voxel_size;

    // 当前 voxel index
    let mut i = (origin[0] / voxel_size).floor() as i64;
    let mut j = (origin[1] / voxel_size).floor() as i64;
    let mut k = (origin[2] / voxel_size).floor() as i64;

    // step:+1 或 -1,看方向
    let step_x = if dir[0] > 0.0 { 1 } else { -1 };
    let step_y = if dir[1] > 0.0 { 1 } else { -1 };
    let step_z = if dir[2] > 0.0 { 1 } else { -1 };

    // t_max:到下一个 voxel 边界的距离(沿 ray 参数 t)
    let next_boundary = |i: i64, step: i64, voxel_size| -> f32 {
        if step > 0 { (i + 1) as f32 * voxel_size } else { i as f32 * voxel_size }
    };
    let mut t_max_x = (next_boundary(i, step_x, voxel_size) - origin[0]) / dir[0];
    let mut t_max_y = (next_boundary(j, step_y, voxel_size) - origin[1]) / dir[1];
    let mut t_max_z = (next_boundary(k, step_z, voxel_size) - origin[2]) / dir[2];

    // t_delta:穿过一个 voxel 沿 t 的距离
    let t_delta_x = (voxel_size / dir[0]).abs();
    let t_delta_y = (voxel_size / dir[1]).abs();
    let t_delta_z = (voxel_size / dir[2]).abs();

    loop {
        // 当前 voxel 是否占据?
        if grid.is_occupied(i, j, k) {
            return Some(VoxelHit { i, j, k /* ... */ });
        }

        // 走到最近的下一个 voxel 边界
        if t_max_x < t_max_y && t_max_x < t_max_z {
            i += step_x;
            t_max_x += t_delta_x;
        } else if t_max_y < t_max_z {
            j += step_y;
            t_max_y += t_delta_y;
        } else {
            k += step_z;
            t_max_z += t_delta_z;
        }

        // 出界检查
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim[0] ||
           j as usize >= grid.dim[1] ||
           k as usize >= grid.dim[2] {
            return None;
        }
    }
}
```

每条 ray 走 N 步,N 取决于 ray 在 grid 里走了多远。

### SIMD 4-wide 版

把 4 条 ray 打包:

```rust
use std::simd::f32x4;

struct RayPacket4 {
    origin_x: f32x4,  // 4 条 ray 的 origin.x
    origin_y: f32x4,
    origin_z: f32x4,
    dir_x: f32x4,
    dir_y: f32x4,
    dir_z: f32x4,
    // 当前状态
    i: [i64; 4],
    j: [i64; 4],
    k: [i64; 4],
    t_max_x: f32x4,
    t_max_y: f32x4,
    t_max_z: f32x4,
    active: [bool; 4],  // 哪些 ray 还在算
}

fn step_packet(packet: &mut RayPacket4, grid: &VoxelGrid) {
    // 同时算 4 条 ray 的下一步
    for r in 0..4 {
        if !packet.active[r] { continue; }
        // 检查当前 voxel
        if grid.is_occupied(packet.i[r], packet.j[r], packet.k[r]) {
            packet.active[r] = false;  // 撞墙了,完成
            continue;
        }
        // 走到下一个 voxel
        // ...同 scalar 版
    }
}
```

注意 `i/j/k` 是 `[i64; 4]` 不是 `i64x4`——因为 SIMD int 操作硬件支持不完整,f32 SIMD 比整数 SIMD 用得多。Casey 实际用浮点 SIMD 算 t_max/t_delta,整数用 scalar。

### 真正的 SIMD 完美版

如果硬件支持 AVX2(整数 SIMD),把 i/j/k 也打包:

```rust
use std::simd::i64x4;

let step_x_v = i64x4::from_array([step_x[0], step_x[1], step_x[2], step_x[3]]);
let i_v = i64x4::from_array([i[0], i[1], i[2], i[3]]);
let new_i_v = i_v + step_x_v;  // 一条指令算 4 个
```

但 portable-simd 的支持仍在演化,Casey 用了简化版。

## 3 · 四域深入

### 3.1 · 游戏编程视角

SIMD raycast 的工业用法:

- **Voxel raycast**:CryEngine LPV,GPU compute shader
- **Ray tracing(BVH)**:Embree(Intel),8/16-wide AVX-512
- **Particle physics**:每帧几万粒子,4-wide SIMD 算碰撞
- **Animation**:骨骼变换矩阵 4x4,SIMD 矩阵乘法

游戏引擎的"内层循环"几乎都是 SIMD 优化的。

### 3.2 · 图形学视角

GPU 本质是 **SIMT**(单指令多线程),是 SIMD 的"伪装"——程序员看到的是单条 ray 的代码,GPU 硬件把 32 条 ray(warp)绑一起执行。所以 GPU raycast 天然并行,不用显式 SIMD。

CPU SIMD 的价值在 **少量 ray** 的场景——比如 CPU lightmap baking,几十万 ray 不够 GPU 启动开销,CPU SIMD 反而快。

### 3.3 · Linux 系统编程视角

Linux 内核 SIMD 用得保守——因为 SIMD 寄存器要保存/恢复(上下文切换开销)。内核里只在确定不会睡眠的代码段用 SIMD。

`<linux/simd.h>` 提供包装。x86 kernel 用 SSE/AVX 做 `memcpy`、`memset`、CRC32、AES。

### 3.4 · Rust 生态视角

Rust 的 SIMD 选项:

- **`std::simd`**(portable-simd):nightly,跨平台 SIMD
- **`packed_simd2`**:稳定版,但语法稍长
- **`wide`**:跨平台,封装 f32x4 等
- **直接 intrinsic**:`core::arch::x86_64::__m128`,平台特化

```rust
// portable-simd 示例
#![feature(portable_simd)]
use std::simd::f32x4;

let a = f32x4::from_array([1.0, 2.0, 3.0, 4.0]);
let b = f32x4::from_array([5.0, 6.0, 7.0, 8.0]);
let c = a + b;  // 一次指令算 4 个
println!("{:?}", c.to_array());  // [6.0, 8.0, 10.0, 12.0]
```

如果不想用 nightly,用 `wide`:

```rust
use wide::f32x4;

let a = f32x4::from([1.0, 2.0, 3.0, 4.0]);
let b = f32x4::from([5.0, 6.0, 7.0, 8.0]);
let c = a + b;
```

## 5 · 对照与变奏

SIMD 演化:

- **MMX(1996)**:64-bit,整数 SIMD
- **SSE(1999)**:128-bit,4-wide float
- **AVX(2011)**:256-bit,8-wide float
- **AVX-512(2016)**:512-bit,16-wide float
- **ARM NEON**:128-bit,Raspberry Pi / 手机
- **RISC-V V**:可变长度 vector

每代翻倍宽度,但程序员的代码也复杂化。

GPU 的 SIMT 思路:让程序员不操心 SIMD,GPU 硬件自动 batch。代价:必须 1000+ ray 才划算(启动开销)。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 SIMD 必须"齐步走"——所有 lane 同时执行同一指令?如果 ray 1 撞墙了,ray 2 还在走,怎么处理?

**参考解答**:SIMD 硬件设计是"一个控制流 + 多个数据流"——指令只有一份,数据有多份。如果允许每条 ray 走不同控制流,等于回到 scalar。处理 divergence 用 **mask**:每条 ray 有 active 位,撞墙的 ray 设 mask=false,后续指令仍然执行但结果丢弃(写到无关寄存器)。这样硬件仍然齐步走,但 mask 控制每条 ray 的"逻辑结果"是否生效。

### Lv2 · 动手实践

**题**:用 `wide` crate 写 4-wide f32 加法,验证比 scalar 快。

要求:
- 创建 10000 个 f32 数组 a 和 b
- 用 scalar 算 a[i] + b[i]
- 用 wide::f32x4 SIMD 算
- 打印两种方法的耗时

**参考解答**:

```rust
// Cargo.toml: wide = "0.7"

use wide::f32x4;
use std::time::Instant;

fn scalar_add(a: &[f32], b: &[f32], out: &mut [f32]) {
    for i in 0..a.len() {
        out[i] = a[i] + b[i];
    }
}

fn simd_add(a: &[f32], b: &[f32], out: &mut [f32]) {
    let n = a.len();
    let mut i = 0;
    while i + 4 <= n {
        let av = f32x4::from_slice(&a[i..i+4]);
        let bv = f32x4::from_slice(&b[i..i+4]);
        (av + bv).write_to_slice_unaligned(&mut out[i..i+4]);
        i += 4;
    }
    while i < n {
        out[i] = a[i] + b[i];
        i += 1;
    }
}

fn main() {
    let n = 100_000;
    let a: Vec<f32> = (0..n).map(|i| i as f32).collect();
    let b: Vec<f32> = (0..n).map(|i| (i*i) as f32).collect();
    let mut out_scalar = vec![0.0; n];
    let mut out_simd = vec![0.0; n];

    // 跑多次取平均
    let t1 = Instant::now();
    for _ in 0..100 {
        scalar_add(&a, &b, &mut out_scalar);
    }
    let dt1 = t1.elapsed();

    let t2 = Instant::now();
    for _ in 0..100 {
        simd_add(&a, &b, &mut out_simd);
    }
    let dt2 = t2.elapsed();

    println!("Scalar: {:?}", dt1);
    println!("SIMD:   {:?}", dt2);
    println!("Speedup: {:.2}x", dt1.as_secs_f64() / dt2.as_secs_f64());

    // 验证结果一致
    for i in 0..n {
        assert_eq!(out_scalar[i], out_simd[i]);
    }
}
```

## 8 · Rust / Arch 落地代码

完整的 4-wide SIMD raycast(简化):

```rust
// 用数组模拟 SIMD lane,实际可以用 wide::f32x4
struct RayPacket4 {
    origin_x: [f32; 4],
    origin_y: [f32; 4],
    origin_z: [f32; 4],
    dir_x: [f32; 4],
    dir_y: [f32; 4],
    dir_z: [f32; 4],
    i: [i64; 4],
    j: [i64; 4],
    k: [i64; 4],
    t_max_x: [f32; 4],
    t_max_y: [f32; 4],
    t_max_z: [f32; 4],
    t_delta_x: [f32; 4],
    t_delta_y: [f32; 4],
    t_delta_z: [f32; 4],
    active: [bool; 4],
    hit: [Option<(i64, i64, i64)>; 4],
}

impl RayPacket4 {
    fn new(origins: &[[f32; 3]; 4], dirs: &[[f32; 3]; 4], voxel_size: f32) -> Self {
        let mut p = RayPacket4 {
            origin_x: [origins[0][0], origins[1][0], origins[2][0], origins[3][0]],
            origin_y: [origins[0][1], origins[1][1], origins[2][1], origins[3][1]],
            origin_z: [origins[0][2], origins[1][2], origins[2][2], origins[3][2]],
            dir_x: [dirs[0][0], dirs[1][0], dirs[2][0], dirs[3][0]],
            dir_y: [dirs[0][1], dirs[1][1], dirs[2][1], dirs[3][1]],
            dir_z: [dirs[0][2], dirs[1][2], dirs[2][2], dirs[3][2]],
            i: [0; 4], j: [0; 4], k: [0; 4],
            t_max_x: [0.0; 4], t_max_y: [0.0; 4], t_max_z: [0.0; 4],
            t_delta_x: [0.0; 4], t_delta_y: [0.0; 4], t_delta_z: [0.0; 4],
            active: [true; 4],
            hit: [None, None, None, None],
        };

        for r in 0..4 {
            p.i[r] = (origins[r][0] / voxel_size).floor() as i64;
            p.j[r] = (origins[r][1] / voxel_size).floor() as i64;
            p.k[r] = (origins[r][2] / voxel_size).floor() as i64;

            let step_x = if dirs[r][0] > 0.0 { 1.0 } else { -1.0 };
            let boundary_x = (p.i[r] as f32 + if dirs[r][0] > 0.0 { 1.0 } else { 0.0 }) * voxel_size;
            p.t_max_x[r] = (boundary_x - origins[r][0]) / dirs[r][0];
            p.t_delta_x[r] = (voxel_size / dirs[r][0]).abs();
            // 同理 y, z(略)
        }
        p
    }

    fn step(&mut self, grid: &VoxelGrid) -> bool {
        let mut any_active = false;
        for r in 0..4 {
            if !self.active[r] { continue; }
            any_active = true;

            // 检查当前 voxel
            if grid.is_occupied(self.i[r], self.j[r], self.k[r]) {
                self.hit[r] = Some((self.i[r], self.j[r], self.k[r]));
                self.active[r] = false;
                continue;
            }

            // 走到下一个 voxel
            if self.t_max_x[r] < self.t_max_y[r] && self.t_max_x[r] < self.t_max_z[r] {
                self.i[r] += if self.dir_x[r] > 0.0 { 1 } else { -1 };
                self.t_max_x[r] += self.t_delta_x[r];
            } else if self.t_max_y[r] < self.t_max_z[r] {
                self.j[r] += if self.dir_y[r] > 0.0 { 1 } else { -1 };
                self.t_max_y[r] += self.t_delta_y[r];
            } else {
                self.k[r] += if self.dir_z[r] > 0.0 { 1 } else { -1 };
                self.t_max_z[r] += self.t_delta_z[r];
            }

            // 出界
            if self.i[r] < 0 || self.j[r] < 0 || self.k[r] < 0 ||
               self.i[r] as usize >= grid.dim[0] ||
               self.j[r] as usize >= grid.dim[1] ||
               self.k[r] as usize >= grid.dim[2] {
                self.active[r] = false;
            }
        }
        any_active
    }
}

struct VoxelGrid {
    occupied: Vec<bool>,
    dim: [usize; 3],
}

impl VoxelGrid {
    fn is_occupied(&self, i: i64, j: i64, k: i64) -> bool {
        if i < 0 || j < 0 || k < 0 { return false; }
        let i = i as usize; let j = j as usize; let k = k as usize;
        if i >= self.dim[0] || j >= self.dim[1] || k >= self.dim[2] { return false; }
        self.occupied[(k * self.dim[1] + j) * self.dim[0] + i]
    }
}

fn main() {
    let mut grid = VoxelGrid {
        occupied: vec![false; 16*16*16],
        dim: [16, 16, 16],
    };
    // 在 (5,5,5) 放一个墙
    grid.occupied[(5 * 16 + 5) * 16 + 5] = true;

    let origins = [[0.0; 3]; 4];
    let dirs = [
        [1.0, 0.5, 0.0],
        [1.0, 0.5, 0.0],
        [1.0, 0.5, 0.0],
        [1.0, 0.5, 0.0],
    ];
    let mut packet = RayPacket4::new(&origins, &dirs, 1.0);

    while packet.step(&grid) {}

    for r in 0..4 {
        println!("Ray {}: {:?}", r, packet.hit[r]);
    }
}
```
