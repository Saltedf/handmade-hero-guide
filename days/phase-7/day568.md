# Day 568 · 调试光线投射器

> Cascade voxel grid 加好后,反射的 raycast 有 bug——某些角度反射"穿过墙",某些"撞了不该撞的"。Day 568 Casey 系统调试 raycaster,用 debug overlay 找出每个 bug。

## 0 · 为什么要有这一天

让我们把镜头贴近画面。你跟着 Handmade Hero 走到 Day 567——Casey 加了 cascade voxel grid,反射 raycast 应该工作了。你跑游戏,**奇怪的事情发生了**:你站在墙前,本该在墙上看到自己(玩家角色)的反射——但是反射**穿过了墙**,墙后空荡的走廊反射出来。你抬头看天花板,本该看到地板的反射——但是某些角度**反射全黑**(过遮挡),另一些角度**反射颜色随机跳变**(抖动)。整个反射系统像"鬼屋"——光影错乱。

这是 raycast 系统的典型 bug。Raycast 是 graphics 里最微妙的算法之一——它涉及浮点精度、voxel 边界、算法边界条件,任何一处出错都产生视觉 artifact。而且 raycast 在 GPU fragment shader 跑,你看不见中间状态,debug 困难。

Raycast bug 的常见症状和原因的对应关系,是 graphics 程序员的诊断手册:

- **穿过墙(light leaking)**:本该被墙挡的光,在墙后看到光。原因:voxel traversal 漏步——Amanatides-Woo 算法在 voxel 边界处跳过中间 voxel
- **过遮挡(over-occlusion)**:本该看到的反射,没看到。原因:voxel grid 太粗或 ray step 太大,薄墙被错误地标记为"挡光"
- **噪声(noise)**:某些像素 raycast 撞到错误的 voxel,出现杂色。原因:floating point 误差累积,ray 偏离预期方向
- **抖动(jittering)**:相机一动,反射颜色随机变。原因:raycast 没用 temporal smoothing,每帧独立采样导致噪声模式变化

每个症状对应不同 bug,需要不同的修复策略。**Casey 这天就是按症状→原因→修复的流程,逐个解决**。

调试 raycast 是 graphics 工程师的日常——这天的技能对所有 ray-based 系统(ray tracing、shadow ray、GI ray、reflection ray)通用。学到的方法论你可以用到任何 ray tracer 项目。

完成这一天之后,你具备:

- 理解 DDA(Digital Differential Analyzer)和 Amanatides-Woo 算法的微妙边界陷阱
- 能用 path visualization 调试 raycast——把不可见的 ray 路径画在屏幕上,bug 立刻暴露
- 知道 floating point 误差对长 raycast 的影响,以及 Kahan summation、re-normalization 等修复技巧
- 理解 temporal accumulation 如何消除 raycast 噪声,以及它在 TAA(Temporal Anti-Aliasing)的应用

## 1 · Casey 今天做了什么

Casey 的几个 bug 和修复:

**Bug 1:穿过墙**——他在 path visualization 看到 ray 从 voxel (5,5,5) 直接到 (7,5,5),跳过了 (6,5,5)。Bug:Amanatides-Woo 算法的 `t_max` 比较用了 `<=` 而非 `<`,边界 voxel 被跳过。Fix:改成 `<`。

**Bug 4:抖动**——相机一动,反射方向变,撞不同 voxel,颜色跳变。Fix:加 temporal accumulation(`new = old * 0.8 + sample * 0.2`)。

## 2 · 心智模型

### 2.1 类比:GPS 导航错误

GPS 给你导航路径,但你按路径走发现各种奇怪问题:

- **穿过墙**:导航说"穿过这栋楼"——算法漏算了楼(类似 raycast 漏 voxel)。物理上不可能,但算法"看不见"楼
- **过遮挡**:导航说"这条路堵了"但实际空——算法错算了阻碍。你可能错过本可走的路
- **噪声**:路径随机跳——GPS 信号抖(floating point 误差)。同一出发点,每次算出不同路径
- **抖动**:每次更新路径变——GPS 没用历史信息。你刚走两步,路径突然改向

每个错误有特定症状,debug 时根据症状猜原因。**这是诊断思维的核心:症状 → 假设 → 验证 → 修复**。Raycast debug 完全一样。

### 2.2 严谨展开:Amanatides-Woo 的边界陷阱

回顾 Day 550 学的 Amanatides-Woo 算法——这是 3D grid 上最经典的 voxel traversal 算法,1987 年 Amanatides 和 Woo 提出。核心思想是"跟踪 ray 在每个轴上下一次穿过 voxel 边界的距离 `t_max_x/y/z`,取最小者作为下一步"。

```rust
if t_max_x < t_max_y && t_max_x < t_max_z {
    i += step_x;
    t_max_x += t_delta_x;
} else if t_max_y < t_max_z {
    j += step_y;
    t_max_y += t_delta_y;
} else {
    k += step_z;
    t_max_z += t_delta_z;
}
```

**陷阱一:tie-breaking**。如果 `t_max_x == t_max_y`(ray 正好从 voxel 角穿过,两个轴同时到边界),`<` 让我们走 x 方向。但 floating point 相等是 fragile——可能 `t_max_x` 比 `t_max_y` 大 0.0001,走 y;下一帧再算,可能反过来。**这就是 bug 3 噪声的根源**。

正确的处理:**用 epsilon 避免边界 tie**:

```rust
const EPS: f32 = 1e-6;
if t_max_x < t_max_y + EPS && t_max_x < t_max_z + EPS {
    i += step_x;
    t_max_x += t_delta_x;
}
```

或者:**对角走**——同时 t_max_x 和 t_max_y 在边界时,同时 +x 和 +y(对角 voxel)。这避免漏 voxel,但增加计算复杂度(每步可能跨多 voxel)。

**陷阱二:边界 voxel 漏步**。Bug 1 的现象——ray 从 voxel (5,5,5) 直接到 (7,5,5),跳过了 (6,5,5)。原因:`<=` vs `<`。如果用 `<=`,当 `t_max_x == t_max_y` 时**两个条件都满足**,但 if-else 只走一个分支,另一个 voxel 被漏掉。修复用 `<` 严格小于。

**陷阱三:起点正好在 voxel 边界**。Ray 从 (5.0, 5.0, 5.0) 出发(整数坐标,正好在 voxel 边界),`floor((5.0)/1.0) = 5`,初始 voxel 是 (5,5,5)。但 ray 方向如果是 (-1, 0, 0),应该立刻进入 (4,5,5)。如果初始化错算成 (5,5,5),ray 在原 voxel "卡住"一步——视觉上是反射延迟。**Fix**:初始化时检查 `floor(pos - dir * EPS)`,沿反方向偏移一点。

### 2.4 Floating point 误差累积

每步 `t_max += t_delta`,浮点加法累积误差。**问题**:浮点加法不满足结合律——`(a + b) + c` ≠ `a + (b + c)`(精度上)。1000 步后,误差可能让 ray 偏离原方向几个 voxel。具体数学:float32 的相对精度是 1e-7,1000 步累积误差 1e-4——对单位长度 1.0 的 voxel,这是 0.0001 voxel 偏差,看起来小。但**对边界 voxel**(ray 正好穿过 voxel 角),0.0001 偏差可能让 ray 走错方向。

修复技巧:

- **Kahan summation**:补偿浮点误差的加法。原理是维护一个"误差补偿项",每次加法把丢失的精度补回来:

```rust
struct KahanSum { sum: f32, compens: f32 }
impl KahanSum {
    fn add(&mut self, value: f32) {
        let y = value - self.compens;
        let t = self.sum + y;
        self.compens = (t - self.sum) - y;
        self.sum = t;
    }
}
```

Kahan summation 把 1000 步累积误差从 1e-4 降到 1e-7——基本消除 floating point drift。

- **重新归一化 dir**:每 100 步归一化方向。`dir = normalize(dir)`。这防止 dir 因浮点误差变成非单位向量,导致 t_delta 计算错
- **Double precision**:关键路径用 f64(慢但准)。CPU ray tracer 常用 f64,GPU ray tracer 用 f32(快但精度差)
- **Offset origin**:沿 normal 偏移 epsilon,避免 ray 从表面出发立刻撞自己

Casey 这天用第一个——Kahan summation。

### 2.5 Temporal accumulation 消除抖动

抖动的根源:每帧 raycast 独立采样,采到不同 voxel(因为相机略动),颜色随机跳变。**这是 path tracing 的本质噪声**—— monte carlo 采样的 variance。

修复:**temporal accumulation(时间累积)**——不是每帧用新采样值,而是和上一帧加权平均:

```rust
static ACCUM: Mutex<Vec<Color>> = ...;
fn temporal_smooth(pixel_idx: usize, new_sample: Color) -> Color {
    let mut accum = ACCUM.lock().unwrap();
    let old = accum[pixel_idx];
    let blended = old * 0.8 + new_sample * 0.2;  // 80% 历史 + 20% 新
    accum[pixel_idx] = blended;
    blended
}
```

**`new = old * 0.8 + sample * 0.2`**——这相当于"指数移动平均"(EMA)。新采样贡献 20%,历史 80%。一帧噪声被 80% 历史稀释,**抖动减少 5 倍**。

但 temporal accumulation 有副作用:**延迟**(相机快速移动时,反射"跟不上"——历史值过期)。Fix:motion vector——检测相机移动,移动越大,历史权重越低(快速移动时不用 temporal)。

这就是 **TAA(Temporal Anti-Aliasing)** 的核心思想——现代游戏标配。Casey 这天用简化版,后面 Day 573+ 完善。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 raycast "穿过墙" 的 bug 是 `<` vs `<=` 的差别?具体什么时候触发?

**参考解答**:Amanatides-Woo 算法每步选 `t_max_x, t_max_y, t_max_z` 中最小的,沿该方向走。如果 `t_max_x == t_max_y`(同时到边界),用 `<` 选 x,但下次 `t_max_y` 不变(还是同样值),仍可能选 y——结果走了对角线,跳过中间 voxel。这 voxel 如果是墙,ray "穿过墙"。Fix:用 `<` 严格选,但保证 t_max_x += t_delta_x 让 x 变,后续 y 比较正确。或者用 epsilon 避免边界相等。

### Lv2 · 动手实践

**题**:实现 raycast with path visualization,验证 bug。

要求:
- 8³ voxel grid,(4,4,4) 是墙
- 从 (0,0,0) 沿 (1,1,1)/sqrt(3) 方向 raycast
- 记录 path,打印每步 voxel index
- 验证 ray 经过 (1,1,1) → (2,2,2) → (3,3,3) → (4,4,4) 撞墙

**参考解答**:

```rust
type V3 = [f32; 3];

#[derive(Debug)]
struct PathStep {
    voxel: (i64, i64, i64),
    t: f32,
    occupied: bool,
}

struct VoxelGrid {
    data: Vec<bool>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![false; dim*dim*dim], dim }
    }
    fn get(&self, i: i64, j: i64, k: i64) -> bool {
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= self.dim || j as usize >= self.dim || k as usize >= self.dim {
            return false;
        }
        self.data[(k as usize * self.dim + j as usize) * self.dim + i as usize]
    }
    fn set(&mut self, i: usize, j: usize, k: usize, v: bool) {
        self.data[(k * self.dim + j) * self.dim + i] = v;
    }
}

fn raycast_with_path(
    grid: &VoxelGrid,
    origin: V3,
    dir: V3,
    max_steps: usize,
) -> (Option<PathStep>, Vec<PathStep>) {
    let voxel_size = 1.0;
    let mut i = origin[0].floor() as i64;
    let mut j = origin[1].floor() as i64;
    let mut k = origin[2].floor() as i64;

    let step_x = if dir[0] > 0.0 { 1 } else { -1 };
    let step_y = if dir[1] > 0.0 { 1 } else { -1 };
    let step_z = if dir[2] > 0.0 { 1 } else { -1 };

    let next_boundary = |i: i64, step: i64| -> f32 {
        if step > 0 { (i + 1) as f32 } else { i as f32 }
    };

    let mut t_max_x = (next_boundary(i, step_x) - origin[0]) / dir[0];
    let mut t_max_y = (next_boundary(j, step_y) - origin[1]) / dir[1];
    let mut t_max_z = (next_boundary(k, step_z) - origin[2]) / dir[2];

    let t_delta_x = (voxel_size / dir[0]).abs();
    let t_delta_y = (voxel_size / dir[1]).abs();
    let t_delta_z = (voxel_size / dir[2]).abs();

    let mut path = Vec::new();
    let mut t = 0.0;

    for _ in 0..max_steps {
        let occupied = grid.get(i, j, k);
        path.push(PathStep { voxel: (i, j, k), t, occupied });

        if occupied {
            return (Some(path.last().unwrap().clone()), path);
        }

        // 选最小 t_max,带 epsilon
        const EPS: f32 = 1e-7;
        if t_max_x < t_max_y + EPS && t_max_x < t_max_z + EPS {
            i += step_x;
            t = t_max_x;
            t_max_x += t_delta_x;
        } else if t_max_y < t_max_z + EPS {
            j += step_y;
            t = t_max_y;
            t_max_y += t_delta_y;
        } else {
            k += step_z;
            t = t_max_z;
            t_max_z += t_delta_z;
        }

        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            return (None, path);
        }
    }
    (None, path)
}

fn main() {
    let mut grid = VoxelGrid::new(8);
    grid.set(4, 4, 4, true);  // 墙

    let origin = [0.5, 0.5, 0.5];
    let dir = [1.0 / 3.0_f32.sqrt(); 3];  // (1,1,1)/sqrt(3)

    let (hit, path) = raycast_with_path(&grid, origin, dir, 100);

    println!("Ray path:");
    for step in &path {
        println!("  t={:.3} voxel=({},{},{}) occupied={}",
            step.t, step.voxel.0, step.voxel.1, step.voxel.2, step.occupied);
    }
    println!("Hit: {:?}", hit);
}
```

    origin: V3,
    dir: V3,
    max_steps: usize,
    debug: bool,
) -> (Option<PathStep>, Vec<PathStep>) {
    let mut i = origin[0].floor() as i64;
    let mut j = origin[1].floor() as i64;
    let mut k = origin[2].floor() as i64;

    let step_x = if dir[0] > 0.0 { 1i64 } else { -1 };
    let step_y = if dir[1] > 0.0 { 1 } else { -1 };
    let step_z = if dir[2] > 0.0 { 1 } else { -1 };

    let next_b = |idx: i64, step: i64| -> f32 {
        if step > 0 { (idx + 1) as f32 } else { idx as f32 }
    };

    let mut t_max_x = (next_b(i, step_x) - origin[0]) / dir[0];
    let mut t_max_y = (next_b(j, step_y) - origin[1]) / dir[1];
    let mut t_max_z = (next_b(k, step_z) - origin[2]) / dir[2];

    let t_delta_x = (1.0 / dir[0]).abs();
    let t_delta_y = (1.0 / dir[1]).abs();
    let t_delta_z = (1.0 / dir[2]).abs();

    let mut path = Vec::new();
    let mut t = 0.0;

    for step_num in 0..max_steps {
        let occupied = grid.get(i, j, k);
        let pos = [
            origin[0] + dir[0] * t,
            origin[1] + dir[1] * t,
            origin[2] + dir[2] * t,
        ];
        let step_info = PathStep {
            voxel: (i, j, k), pos, t, occupied,
        };
        if debug {
            path.push(step_info.clone());
        }

        if occupied {
            return (Some(step_info), path);
        }

        // 选最小,带 epsilon
        const EPS: f32 = 1e-7;
        if t_max_x < t_max_y + EPS && t_max_x < t_max_z + EPS {
            i += step_x;
            t = t_max_x;
            t_max_x += t_delta_x;
        } else if t_max_y < t_max_z + EPS {
            j += step_y;
            t = t_max_y;
            t_max_y += t_delta_y;
        } else {
            k += step_z;
            t = t_max_z;
            t_max_z += t_delta_z;
        }

        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            return (None, path);
        }

        if step_num > 1000 {
            eprintln!("Warning: raycast exceeded 1000 steps, aborting");
            return (None, path);
        }
    }
    (None, path)
}

// 用 Kahan summation 减少 t 累积误差
struct KahanSum {
    sum: f32,
    compensation: f32,
}
impl KahanSum {
    fn new() -> Self { KahanSum { sum: 0.0, compensation: 0.0 } }
    fn add(&mut self, value: f32) {
        let y = value - self.compensation;
        let new_sum = self.sum + y;
        self.compensation = (new_sum - self.sum) - y;
        self.sum = new_sum;
    }
    fn value(&self) -> f32 { self.sum }
}

fn main() {
    let mut grid = VoxelGrid::new(8);
    // 一面墙
    for j in 0..8 {
        for k in 0..8 {
            grid.set(4, j, k);
        }
    }

    // 测试 1:正面 ray
    let origin = [0.5, 4.0, 4.0];
    let dir = [1.0, 0.0, 0.0];
    let (hit, path) = raycast(&grid, origin, dir, 100, true);
    println!("Front ray hit: {:?}", hit.as_ref().map(|h| h.voxel));
    println!("Path length: {}", path.len());

    // 测试 2:斜 ray(可能漏 voxel)
    let dir = [1.0, 0.001, 0.0];
    let (hit, path) = raycast(&grid, origin, dir, 100, true);
    println!("\nNear-axis ray hit: {:?}", hit.as_ref().map(|h| h.voxel));

    // 测试 3:对角 ray(经典边界 case)
    let dir = [1.0, 1.0, 1.0];
    let norm = (3.0_f32).sqrt();
    let dir = [dir[0]/norm, dir[1]/norm, dir[2]/norm];
    let (hit, path) = raycast(&grid, [0.5; 3], dir, 100, true);
    println!("\nDiagonal ray hit: {:?}", hit.as_ref().map(|h| h.voxel));
    println!("Diagonal path steps:");
    for step in &path {
        println!("  ({},{},{})", step.voxel.0, step.voxel.1, step.voxel.2);
    }

    // 验证 Kahan summation
    let mut k = KahanSum::new();
    let mut naive = 0.0f32;
    for _ in 0..10000 {
        k.add(0.1);
        naive += 0.1;
    }
    println!("\n1000 * 0.1:");
    println!("  Naive:  {}", naive);
    println!("  Kahan:  {}", k.value());
    println!("  Exact:  1000.0");
}
