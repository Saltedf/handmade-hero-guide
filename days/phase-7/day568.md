# Day 568 · 调试光线投射器

> Cascade voxel grid 加好后,反射的 raycast 有 bug——某些角度反射"穿过墙",某些"撞了不该撞的"。Day 568 Casey 系统调试 raycaster,用 debug overlay 找出每个 bug。

## 0 · 为什么要有这一天

Raycast bug 的常见症状:

- **穿过墙**:本该被墙挡的光,在墙后看到光(光"漏"过来)
- **过遮挡**:本该看到的反射,没看到(光被错误挡住)
- **噪声**:某些像素 raycast 撞到错误的 voxel,出现杂色
- **抖动**:相机一动,反射颜色随机变

每个症状对应不同 bug:

- 穿过墙 = voxel traversal 漏步(DDD algorithm 边界 bug)
- 过遮挡 = voxel 太粗或 ray step 太大
- 噪声 = floating point 误差累积
- 抖动 = raycast 没用 temporal smoothing

调试 raycast 是 graphics 工程师的日常——这天的技能对所有 ray-based 系统(ray tracing, shadow ray, GI ray)通用。

完成这一天之后,你具备:

- 理解 DDA(Digital Differential Analyzer)算法的陷阱
- 能用 path visualization 调试 raycast
- 知道 floating point 误差的影响

## 1 · Casey 今天做了什么

Casey 的几个 bug 和修复:

**Bug 1:穿过墙**——他在 path visualization 看到 ray 从 voxel (5,5,5) 直接到 (7,5,5),跳过了 (6,5,5)。Bug:Amanatides-Woo 算法的 `t_max` 比较用了 `<=` 而非 `<`,边界 voxel 被跳过。Fix:改成 `<`。

**Bug 2:过遮挡**——ray 从远处看玩家,被空气 voxel 挡了。Bug:cascade transfer 后,粗 grid 的"空"voxel 被错标为"occupied"。Fix:transfer 时只传 light,不传 occupied。

**Bug 3:噪声**——ray 在 voxel 边界附近,t_max_x 和 t_max_y 几乎相等,floating point 误差决定走哪边。Fix:加 epsilon 偏移。

**Bug 4:抖动**——相机一动,反射方向变,撞不同 voxel,颜色跳变。Fix:加 temporal accumulation(`new = old * 0.8 + sample * 0.2`)。

视频里他强调:"调试 raycast 90% 时间在 visualization——把不可见的 ray 变可见,bug 自己跳出来。"

## 2 · 心智模型

### 类比:GPS 导航错误

GPS 给你导航路径,但你按路径走发现:

- **穿过墙**:导航说"穿过这栋楼"——算法漏算了楼(类似 raycast 漏 voxel)
- **过遮挡**:导航说"这条路堵了"但实际空——算法错算了阻碍
- **噪声**:路径随机跳——GPS 信号抖(floating point 误差)
- **抖动**:每次更新路径变——GPS 没用历史信息

每个错误有特定症状,debug 时根据症状猜原因。

### 严谨展开:Amanatides-Woo 的边界陷阱

回顾 Day 550 的算法:

```rust
if t_max_x < t_max_y && t_max_x < t_max_z {
    i += step_x;
    t_max_x += t_delta_x;
}
```

如果 `t_max_x == t_max_y` 同时是边界,`<` 让我们走 x 方向。但 floating point 相等是 fragile——可能 `t_max_x` 比 `t_max_y` 大 0.0001,走 y;下一帧再算,可能反过来。

正确的处理:

```rust
// 用 epsilon 避免边界 tie
const EPS: f32 = 1e-6;
if t_max_x < t_max_y + EPS && t_max_x < t_max_z + EPS {
    i += step_x;
    t_max_x += t_delta_x;
}
```

或者:**对角走**——同时 t_max_x 和 t_max_y 在边界时,同时 +x 和 +y(对角 voxel)。这避免漏 voxel。

如果 path 看起来"奇怪"——跳过 voxel、对角跳跃——就是 Amanatides-Woo bug。

### Floating point 误差

每步 t_max += t_delta,浮点加法累积误差。1000 步后,误差可能让 ray 偏离原方向几个 voxel。

Fix:

- **Kahan summation**:补偿浮点误差的加法
- **重新归一化 dir**:每 100 步归一化方向
- **Double precision**:关键路径用 f64(慢但准)

Casey 这天用第一个——Kahan summation。

## 3 · 四域深入

### 3.1 · 游戏编程视角

### 3.2 · 图形学视角

Raycast 算法的几个经典陷阱:

- **Self-intersection**:ray 从表面出发,可能立刻撞"自己"。Fix:origin 沿 normal 偏移 epsilon
- **Acne**:阴影 ray 撞表面,产生摩尔纹。Fix:增加 bias
- **Precision loss at distance**:远距离 voxel 误差累积
- **Edge cases at grid boundary**:出界判定错

每个都是 path tracing 实现的常见 bug。

### 3.3 · Linux 系统编程视角

"floating point precision"在系统编程也关键:

- **DNS amplification**:多次转换累积误差
- **Time representation**:nanosecond timer overflow
- **GPS coordinates**:double vs float
- **Game physics**:havok 用 double 在关键位置

### 3.4 · Rust 生态视角

Rust 的 floating point:


## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 raycast "穿过墙" 的 bug 是 `<` vs `<=` 的差别?具体什么时候触发?

**参考解答**:Amanatides-Woo 算法每步选 `t_max_x, t_max_y, t_max_z` 中最小的,沿该方向走。如果 `t_max_x == t_max_y`(同时到边界),用 `<` 选 x,但下次 `t_max_y` 不变(还是同样值),仍可能选 y——结果走了对角线,跳过中间 voxel。这 voxel 如果是墙,ray "穿过墙"。Fix:用 `<` 严格选,但保证 t_max_x += t_delta_x 让 x 变,后续 y 比较正确。或者用 epsilon 避免边界相等。

### Lv2 · 动手实践

**题**:实现 raycast with path visualization,验证 bug。

要求:
- 8³ voxel grid,(4,4,4) 是墙
- 从 (0,0,0) 沿 (1,1,1)/sqrt(3) 方向 raycast
- 记录 path,打印每步 voxel index
- 验证 ray 经过 (1,1,1) → (2,2,2) → (3,3,3) → (4,4,4) 撞墙

**参考解答**:

```rust
type V3 = [f32; 3];

#[derive(Debug)]
struct PathStep {
    voxel: (i64, i64, i64),
    t: f32,
    occupied: bool,
}

struct VoxelGrid {
    data: Vec<bool>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![false; dim*dim*dim], dim }
    }
    fn get(&self, i: i64, j: i64, k: i64) -> bool {
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= self.dim || j as usize >= self.dim || k as usize >= self.dim {
            return false;
        }
        self.data[(k as usize * self.dim + j as usize) * self.dim + i as usize]
    }
    fn set(&mut self, i: usize, j: usize, k: usize, v: bool) {
        self.data[(k * self.dim + j) * self.dim + i] = v;
    }
}

fn raycast_with_path(
    grid: &VoxelGrid,
    origin: V3,
    dir: V3,
    max_steps: usize,
) -> (Option<PathStep>, Vec<PathStep>) {
    let voxel_size = 1.0;
    let mut i = origin[0].floor() as i64;
    let mut j = origin[1].floor() as i64;
    let mut k = origin[2].floor() as i64;

    let step_x = if dir[0] > 0.0 { 1 } else { -1 };
    let step_y = if dir[1] > 0.0 { 1 } else { -1 };
    let step_z = if dir[2] > 0.0 { 1 } else { -1 };

    let next_boundary = |i: i64, step: i64| -> f32 {
        if step > 0 { (i + 1) as f32 } else { i as f32 }
    };

    let mut t_max_x = (next_boundary(i, step_x) - origin[0]) / dir[0];
    let mut t_max_y = (next_boundary(j, step_y) - origin[1]) / dir[1];
    let mut t_max_z = (next_boundary(k, step_z) - origin[2]) / dir[2];

    let t_delta_x = (voxel_size / dir[0]).abs();
    let t_delta_y = (voxel_size / dir[1]).abs();
    let t_delta_z = (voxel_size / dir[2]).abs();

    let mut path = Vec::new();
    let mut t = 0.0;

    for _ in 0..max_steps {
        let occupied = grid.get(i, j, k);
        path.push(PathStep { voxel: (i, j, k), t, occupied });

        if occupied {
            return (Some(path.last().unwrap().clone()), path);
        }

        // 选最小 t_max,带 epsilon
        const EPS: f32 = 1e-7;
        if t_max_x < t_max_y + EPS && t_max_x < t_max_z + EPS {
            i += step_x;
            t = t_max_x;
            t_max_x += t_delta_x;
        } else if t_max_y < t_max_z + EPS {
            j += step_y;
            t = t_max_y;
            t_max_y += t_delta_y;
        } else {
            k += step_z;
            t = t_max_z;
            t_max_z += t_delta_z;
        }

        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            return (None, path);
        }
    }
    (None, path)
}

fn main() {
    let mut grid = VoxelGrid::new(8);
    grid.set(4, 4, 4, true);  // 墙

    let origin = [0.5, 0.5, 0.5];
    let dir = [1.0 / 3.0_f32.sqrt(); 3];  // (1,1,1)/sqrt(3)

    let (hit, path) = raycast_with_path(&grid, origin, dir, 100);

    println!("Ray path:");
    for step in &path {
        println!("  t={:.3} voxel=({},{},{}) occupied={}",
            step.t, step.voxel.0, step.voxel.1, step.voxel.2, step.occupied);
    }
    println!("Hit: {:?}", hit);
}
```

## 8 · Rust / Arch 落地代码

带 debug overlay 的 raycast:

```rust
type V3 = [f32; 3];

#[derive(Clone, Debug)]
struct PathStep {
    voxel: (i64, i64, i64),
    pos: V3,
    t: f32,
    occupied: bool,
}

struct VoxelGrid {
    data: Vec<bool>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![false; dim*dim*dim], dim }
    }
    fn get(&self, i: i64, j: i64, k: i64) -> bool {
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= self.dim || j as usize >= self.dim || k as usize >= self.dim {
            return false;
        }
        self.data[(k as usize * self.dim + j as usize) * self.dim + i as usize]
    }
    fn set(&mut self, i: usize, j: usize, k: usize) {
        self.data[(k * self.dim + j) * self.dim + i] = true;
    }
}

// Amanatides-Woo with epsilon fix
fn raycast(
    grid: &VoxelGrid,
    origin: V3,
    dir: V3,
    max_steps: usize,
    debug: bool,
) -> (Option<PathStep>, Vec<PathStep>) {
    let mut i = origin[0].floor() as i64;
    let mut j = origin[1].floor() as i64;
    let mut k = origin[2].floor() as i64;

    let step_x = if dir[0] > 0.0 { 1i64 } else { -1 };
    let step_y = if dir[1] > 0.0 { 1 } else { -1 };
    let step_z = if dir[2] > 0.0 { 1 } else { -1 };

    let next_b = |idx: i64, step: i64| -> f32 {
        if step > 0 { (idx + 1) as f32 } else { idx as f32 }
    };

    let mut t_max_x = (next_b(i, step_x) - origin[0]) / dir[0];
    let mut t_max_y = (next_b(j, step_y) - origin[1]) / dir[1];
    let mut t_max_z = (next_b(k, step_z) - origin[2]) / dir[2];

    let t_delta_x = (1.0 / dir[0]).abs();
    let t_delta_y = (1.0 / dir[1]).abs();
    let t_delta_z = (1.0 / dir[2]).abs();

    let mut path = Vec::new();
    let mut t = 0.0;

    for step_num in 0..max_steps {
        let occupied = grid.get(i, j, k);
        let pos = [
            origin[0] + dir[0] * t,
            origin[1] + dir[1] * t,
            origin[2] + dir[2] * t,
        ];
        let step_info = PathStep {
            voxel: (i, j, k), pos, t, occupied,
        };
        if debug {
            path.push(step_info.clone());
        }

        if occupied {
            return (Some(step_info), path);
        }

        // 选最小,带 epsilon
        const EPS: f32 = 1e-7;
        if t_max_x < t_max_y + EPS && t_max_x < t_max_z + EPS {
            i += step_x;
            t = t_max_x;
            t_max_x += t_delta_x;
        } else if t_max_y < t_max_z + EPS {
            j += step_y;
            t = t_max_y;
            t_max_y += t_delta_y;
        } else {
            k += step_z;
            t = t_max_z;
            t_max_z += t_delta_z;
        }

        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            return (None, path);
        }

        if step_num > 1000 {
            eprintln!("Warning: raycast exceeded 1000 steps, aborting");
            return (None, path);
        }
    }
    (None, path)
}

// 用 Kahan summation 减少 t 累积误差
struct KahanSum {
    sum: f32,
    compensation: f32,
}
impl KahanSum {
    fn new() -> Self { KahanSum { sum: 0.0, compensation: 0.0 } }
    fn add(&mut self, value: f32) {
        let y = value - self.compensation;
        let new_sum = self.sum + y;
        self.compensation = (new_sum - self.sum) - y;
        self.sum = new_sum;
    }
    fn value(&self) -> f32 { self.sum }
}

fn main() {
    let mut grid = VoxelGrid::new(8);
    // 一面墙
    for j in 0..8 {
        for k in 0..8 {
            grid.set(4, j, k);
        }
    }

    // 测试 1:正面 ray
    let origin = [0.5, 4.0, 4.0];
    let dir = [1.0, 0.0, 0.0];
    let (hit, path) = raycast(&grid, origin, dir, 100, true);
    println!("Front ray hit: {:?}", hit.as_ref().map(|h| h.voxel));
    println!("Path length: {}", path.len());

    // 测试 2:斜 ray(可能漏 voxel)
    let dir = [1.0, 0.001, 0.0];
    let (hit, path) = raycast(&grid, origin, dir, 100, true);
    println!("\nNear-axis ray hit: {:?}", hit.as_ref().map(|h| h.voxel));

    // 测试 3:对角 ray(经典边界 case)
    let dir = [1.0, 1.0, 1.0];
    let norm = (3.0_f32).sqrt();
    let dir = [dir[0]/norm, dir[1]/norm, dir[2]/norm];
    let (hit, path) = raycast(&grid, [0.5; 3], dir, 100, true);
    println!("\nDiagonal ray hit: {:?}", hit.as_ref().map(|h| h.voxel));
    println!("Diagonal path steps:");
    for step in &path {
        println!("  ({},{},{})", step.voxel.0, step.voxel.1, step.voxel.2);
    }

    // 验证 Kahan summation
    let mut k = KahanSum::new();
    let mut naive = 0.0f32;
    for _ in 0..10000 {
        k.add(0.1);
        naive += 0.1;
    }
    println!("\n1000 * 0.1:");
    println!("  Naive:  {}", naive);
    println!("  Kahan:  {}", k.value());
    println!("  Exact:  1000.0");
}
```
