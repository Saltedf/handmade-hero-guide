# Day 565 · 重建多光源

> Day 560 precompute irradiance 假设光源静态,但游戏里有动态光源(火把、子弹爆炸的火光)。Day 565 Casey 加 **multi-light reconstruction**——把多光源的贡献分离存储,fragment shader 重建总和。

## 0 · 为什么要有这一天

回顾:Day 560 precompute 是**所有光源加总**后存进 voxel grid。但如果某光源动了,要重新算 grid——慢。

**Multi-light reconstruction** 思路:**每个光源独立存**自己的贡献,fragment shader 实时把它们加起来。

```
final_light = light_static_baked + light_dynamic_1 + light_dynamic_2 + ...
```

每个 light 单独存 voxel grid?太贵(10 光源 × 16³ × 4 字节 = 几 MB)。优化:

- **Static light**:baked 一次,不变(墙、地板反射的太阳光)
- **Dynamic light**:实时计算(火把、子弹爆炸)
- **Hybrid**:baked static + real-time dynamic

Casey 这天做 hybrid——分离 baked 和 dynamic,运行时合并。

完成这一天之后,你具备:

- 理解 baked vs dynamic lighting 的边界
- 能分离多光源贡献
- 知道现代游戏的"real-time GI + baked GI"组合

## 1 · Casey 今天做了什么

Casey 的步骤:

第一步,他把 voxel grid 拆成两个:

- `baked_grid`:precomputed,存所有静态光源
- `dynamic_grid`:每帧重新计算,存动态光源(火把等)

第二步,fragment shader 采样两个 grid,加总:

```glsl
vec3 light = texture(baked_grid, pos).rgb + texture(dynamic_grid, pos).rgb;
```

第三步,他实现动态光源——火把的 light 用 PointLight 结构存,每帧根据火把位置算影响 voxel。

第四步,他用 **distance-based culling**——只算火把半径内的 voxel(其他 voxel 不受火把影响),省时间。

视频里他演示:点燃火把,周围墙亮起来;移开火把,墙恢复 dark。baked 太阳光始终存在。

## 2 · 心智模型

### 类比:房间的固定灯 vs 手电筒

房间里:

- **吸顶灯**(static):位置固定,光照固定。可以预先画"光照图"——开灯时整面墙都亮
- **手电筒**(dynamic):位置动,光照方向变。要实时算"手电筒照到哪儿,那儿亮"

吸顶灯的光照可以 baked(关灯前一直这样),手电筒要 real-time(每帧重算)。

最终看到的:墙上 = 吸顶灯的固定光照 + 手电筒的动态光照。两者相加。

### 严谨展开:动态光源的 voxel 注入

```rust
struct DynamicLight {
    pos: Vec3,
    color: Vec3,
    radius: f32,
}

fn inject_dynamic_light(
    grid: &mut VoxelGrid,
    light: &DynamicLight,
) {
    let center = [
        (light.pos.x / VOXEL_SIZE) as i64,
        (light.pos.y / VOXEL_SIZE) as i64,
        (light.pos.z / VOXEL_SIZE) as i64,
    ];
    let r = (light.radius / VOXEL_SIZE) as i64;

    for dk in -r..=r {
        for dj in -r..=r {
            for di in -r..=r {
                let d2 = di*di + dj*dj + dk*dk;
                if d2 > r*r { continue; }
                let i = (center[0] + di) as usize;
                let j = (center[1] + dj) as usize;
                let k = (center[2] + dk) as usize;
                if i >= grid.dim[0] || j >= grid.dim[1] || k >= grid.dim[2] { continue; }

                let falloff = 1.0 - (d2 as f32 / (r*r as f32)).sqrt();
                let existing = grid.get(i, j, k);
                grid.set(i, j, k, [
                    existing[0] + light.color.x * falloff,
                    existing[1] + light.color.y * falloff,
                    existing[2] + light.color.z * falloff,
                ]);
            }
        }
    }
}
```

每帧重新生成 dynamic grid(清零 + 注入所有动态光源)。

### Fragment shader 重建

```glsl
vec3 baked_light = texture(baked_grid, world_pos / voxel_size).rgb;
vec3 dynamic_light = texture(dynamic_grid, world_pos / voxel_size).rgb;
vec3 total_light = baked_light + dynamic_light;
return surface_color * total_light;
```

简单加法。如果某光源太强,加 HDR tonemap。

### 优化的方向

如果 1000 个动态光源(战斗场景很多子弹爆炸),dynamic grid 更新慢。优化:

- **Culling**:只更新玩家可见的光源
- **Per-pixel lighting**:光源不存 voxel grid,fragment shader 直接遍历光源点积法线
- **Tiled/Cluster lighting**:屏幕分 tile,每 tile 只处理影响它的光源

工业游戏(Unreal Lumen)用 Cluster + screen-space——把光源分配到屏幕的 3D cluster(2D tile + depth slice)。

Casey 这天用 voxel grid 注入,简单。

## 3 · 四域深入

### 3.1 · 游戏编程视角

多光源的工业实现:

- **Forward rendering**:fragment shader 遍历所有光源,慢但准
- **Deferred rendering**:G-buffer 存 normal/pos,光照 pass 一遍算所有
- **Forward+ / Cluster forward**:光源分 cluster,只算影响当前 cluster 的
- **Voxel-based**:光源注入 voxel(本项目)

Forward+ 是现代主流——多光源 + MSAA 兼容。Casey 选 voxel-based 是因为已有 voxel GI 系统。

### 3.2 · 图形学视角

光照方程的多光源形式:

```
L_o = Σ_i L_i * f_r * cos(θ_i) * V_i
```

i 是光源索引,L_i 是光源强度,f_r 是 BRDF,V_i 是 visibility(被遮挡?)。

Deferred 把 L_o 拆成"G-buffer + light loop",光源 loop 在 pixel shader 跑。

### 3.3 · Linux 系统编程视角

"加性贡献"模式在系统编程:

- **Atomic counter**:多线程各加自己的贡献
- **Reduce operation**:MPI/MapReduce 的 reduce
- **Sensor fusion**:多传感器数据融合

都是"N 个独立源 → 1 个加总结果"的模式。

### 3.4 · Rust 生态视角

Rust 表达 light list:

```rust
#[repr(C)]
#[derive(Clone, Copy, bytemuck::Pod, bytemuck::Zeroable)]
struct GpuLight {
    pos: [f32; 4],     // xyz + radius
    color: [f32; 4],   // rgb + intensity
}

let light_buffer = device.create_buffer_init(&wgpu::util::BufferInitDescriptor {
    contents: bytemuck::cast_slice(&lights),
    usage: wgpu::BufferUsage::STORAGE,
    label: None,
});
```

WGSL 读:

```wgsl
@group(0) @binding(0) var<storage, read> lights: array<GpuLight>;

@fragment
fn fs_main(...) -> ... {
    var total = vec3<f32>(0.0);
    for (var i: u32 = 0; i < arrayLength(&lights); i = i + 1) {
        let l = lights[i];
        let d = l.pos.xyz - world_pos;
        let dist = length(d);
        if (dist < l.pos.w) {  // w = radius
            let falloff = 1.0 - dist / l.pos.w;
            total = total + l.color.rgb * falloff;
        }
    }
    return vec4<f32>(total, 1.0);
}
```

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 baked + dynamic 分离存储,而不是全 real-time?

**参考解答**:(1) Real-time 慢——多光源 per-pixel 计算 GPU 时间长;(2) 静态光源不需要重算,baked 一次省 CPU/GPU;(3) Static baked 可以离线烘焙超高质量(real-time 必须简化算法);(4) Hybrid 让大部分场景 fast(baked) + 少量动态元素 flexible(real-time)。代价:baked 和 dynamic 要分开存,GPU 多一个 texture fetch,但 fetch 开销远小于 real-time 计算。

### Lv2 · 动手实践

**题**:实现 baked + dynamic grid,验证动态光源效果。

- 1 个 baked 光源(位置固定)

type V3 = [f32; 3];

struct VoxelGrid {
    data: Vec<V3>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![[0.0; 3]; dim*dim*dim], dim }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim + j) * self.dim + i
    }
    fn get(&self, i: usize, j: usize, k: usize) -> V3 {
        self.data[self.idx(i, j, k)]
    }
    fn set(&mut self, i: usize, j: usize, k: usize, v: V3) {
        self.data[self.idx(i, j, k)] = v;
    }
    fn clear(&mut self) {
        for v in self.data.iter_mut() { *v = [0.0; 3]; }
    }
}

            }

fn main() {
    let mut baked = VoxelGrid::new(16);
    let mut dynamic = VoxelGrid::new(16);

    // baked 太阳光
    let sun = Light { pos: [8.0, 15.0, 8.0], color: [0.5, 0.5, 0.5], radius: 5.0 };
    inject_light(&mut baked, &sun);

    // 模拟 5 帧,火把移动
    for frame in 0..5 {
        dynamic.clear();
        let torch_x = 3.0 + frame as f32 * 2.0;

        inject_light(&mut dynamic, &torch);

        // 中心 voxel 的总光照
        let b = baked.get(8, 5, 8);
        let d = dynamic.get(8, 5, 8);
        println!("Frame {}: torch_x={}, baked={:?}, dynamic={:?}, total=({:.2}, {:.2}, {:.2})",
            frame, torch_x, b, d,
            b[0]+d[0], b[1]+d[1], b[2]+d[2]);
    }

## 8 · Rust / Arch 落地代码

完整 multi-light hybrid:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, Default)]
struct Voxel { light: V3, occupied: bool }

struct VoxelGrid {
    data: Vec<Voxel>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![Voxel::default(); dim*dim*dim], dim }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim + j) * self.dim + i
    }
    fn get(&self, i: usize, j: usize, k: usize) -> Voxel { self.data[self.idx(i, j, k)] }
    fn set(&mut self, i: usize, j: usize, k: usize, v: Voxel) {
        self.data[self.idx(i, j, k)] = v;
    }
    fn clear_lights(&mut self) {
        for v in self.data.iter_mut() {
            v.light = [0.0; 3];
        }
    }
}

#[derive(Clone, Copy)]
struct Light {
    pos: V3,
    color: V3,
    radius: f32,
}

fn inject_light(grid: &mut VoxelGrid, light: &Light, occupied_grid: &VoxelGrid) {
    let cx = light.pos[0] as i64;
    let cy = light.pos[1] as i64;
    let cz = light.pos[2] as i64;
    let r = light.radius as i64;

    for dk in -r..=r {
        for dj in -r..=r {
            for di in -r..=r {
                let d2 = di*di + dj*dj + dk*dk;
                if d2 > r*r { continue; }
                let i = (cx + di) as usize;
                let j = (cy + dj) as usize;
                let k = (cz + dk) as usize;
                if i >= grid.dim || j >= grid.dim || k >= grid.dim { continue; }

                // 遮挡检查:从 light 到 voxel 路径上是否有墙?
                if is_occluded(occupied_grid, light.pos, [i as f32, j as f32, k as f32]) {
                    continue;
                }

                let falloff = 1.0 - (d2 as f32 / (r*r as f32)).sqrt();
                let existing = grid.get(i, j, k);
                grid.set(i, j, k, Voxel {
                    light: [
                        existing.light[0] + light.color[0] * falloff,
                        existing.light[1] + light.color[1] * falloff,
                        existing.light[2] + light.color[2] * falloff,
                    ],
                    occupied: existing.occupied,
                });
            }
        }
    }
}

fn is_occluded(grid: &VoxelGrid, from: V3, to: V3) -> bool {
    // 简化:沿 from->to 采样
    let dx = to[0] - from[0];
    let dy = to[1] - from[1];
    let dz = to[2] - from[2];
    let steps = (dx.abs().max(dy.abs()).max(dz.abs())) as usize + 1;
    for s in 1..steps {
        let t = s as f32 / steps as f32;
        let p = [from[0] + dx*t, from[1] + dy*t, from[2] + dz*t];
        let i = p[0] as usize;
        let j = p[1] as usize;
        let k = p[2] as usize;
        if i < grid.dim && j < grid.dim && k < grid.dim {
            if grid.get(i, j, k).occupied { return true; }
        }
    }
    false
}

fn main() {
    let mut baked = VoxelGrid::new(16);
    let mut dynamic = VoxelGrid::new(16);
    let occupied = VoxelGrid::new(16);  // 简化:全空

    // Baked:太阳
    let sun = Light {
        pos: [8.0, 15.0, 8.0],
        color: [0.6, 0.6, 0.5],
        radius: 8.0,
    };
    inject_light(&mut baked, &sun, &occupied);

    // Dynamic:玩家手持火把
    let mut player_pos: V3 = [3.0, 5.0, 8.0];

    // 模拟 5 帧
    for frame in 0..5 {
        dynamic.clear_lights();

        // 火把跟着玩家
        let torch = Light {
            pos: player_pos,
            color: [2.5, 1.0, 0.3],
            radius: 4.0,
        };
        inject_light(&mut dynamic, &torch, &occupied);

        // 采样几个 voxel
        let samples = [
            ([8, 5, 8], "中心"),
            ([player_pos[0] as usize, 5, 8], "玩家位置"),
            ([3, 5, 3], "角落"),
        ];

        println!("\nFrame {} (player at {:?}):", frame, player_pos);
        for (pos, name) in samples.iter() {
            let b = baked.get(pos[0], pos[1], pos[2]);
            let d = dynamic.get(pos[0], pos[1], pos[2]);
            println!("  {}: baked=({:.2},{:.2},{:.2}) + dynamic=({:.2},{:.2},{:.2}) = total ({:.2},{:.2},{:.2})",
                name,
                b.light[0], b.light[1], b.light[2],
                d.light[0], d.light[1], d.light[2],
                b.light[0]+d.light[0], b.light[1]+d.light[1], b.light[2]+d.light[2]);
        }

        // 玩家移动
        player_pos[0] += 1.0;
    }
}
```

GPU 实现的 shader(WGSL):

```wgsl
@group(0) @binding(0) var baked_tex: texture_3d<f32>;
@group(0) @binding(1) var dynamic_tex: texture_3d<f32>;
@group(0) @binding(2) var tex_sampler: sampler;

@fragment
fn fs_main(
    @location(0) world_pos: vec3<f32>,
    @location(1) normal: vec3<f32>,
) -> @location(0) vec4<f32> {
    let uvw = world_pos / 16.0;  // voxel_size = 1, dim = 16

    let baked = textureSample(baked_tex, tex_sampler, uvw).rgb;
    let dynamic = textureSample(dynamic_tex, tex_sampler, uvw).rgb;

    let total_light = baked + dynamic;
    let n = normalize(normal);
    let ndl = max(dot(n, vec3(0.0, 1.0, 0.0)), 0.0);

    return vec4<f32>(total_light * ndl, 1.0);
}
```
