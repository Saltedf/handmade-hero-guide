# Day 513 · 添加原始 token 和对齐点解析

> Day 510 的 HHT parser 处理简单 tag。Day 513 扩展 parser,支持"raw token"——未解析的 token 流,用于表达复杂结构(alignment point、entity piece 嵌套)。

## 0 · 为什么要有这一天

### 真实场景:复杂 entity 的 HHT 表达

让我们把镜头拉近。你跟着 Casey 做到 Day 510。HHT parser 能处理 flat INI 结构(section + tag)。但你的策划说:"我要在 HHT 里定义 entity,每个 entity 有多个 piece,每个 piece 有 alignment point。"

期望的 HHT 长这样:

```
[entities]
hero {
    piece body {
        sprite = "hero_body"
        alignment_point neck = (0, -20)
        alignment_point hand_r = (15, 0)
    }
    piece head {
        sprite = "hero_head"
        parent = body.neck
    }
    piece sword {
        sprite = "iron_sword"
        parent = body.hand_r
    }
}
```

Day 510 的 parser **完全处理不了**这个:
- 嵌套 `{ ... }` 块——parser 不知道 brace matching
- 元组 `(0, -20)`——parser 把 `(`、`0`、`,`、`-20`、`)` 当 5 个 token,不知是元组
- 路径 `body.neck`——parser 把 `body`、`.`、`neck` 当 3 个 token,不知是引用
- `piece` 关键字——parser 把它当普通 identifier,不知是关键字

Day 513 扩展 parser,支持这些复杂结构。

### 为什么用 raw token 而不是直接构建 Entity

面对嵌套结构,有两种 parser 设计:

**设计 A:直接构建**。Parser 在 `entity` 关键字后,**立即调用** `parse_entity_body`,递归构建 `Entity` struct。Parser 和 entity 语义耦合。

**设计 B:Raw token + delayed**。Parser 遇到 `{`,不立即解释内容,而是**收集所有 token 到 raw block**。后续代码再递归解析 raw block。

Casey Day 513 选 B。为什么?

**理由 1:关注点分离**。Generic parser 处理语法(`{`、`}`、token 流),不懂 entity 语义。Entity parser 处理语义(`piece`、`alignment_point`),不管语法细节。两个独立的代码层,各自测试、各自演化。

**理由 2:可扩展**。加新 entity 类型(比如 `room { ... }`、`trigger { ... }`),parser 不变,只加新语义 parser。如果用设计 A,parser 要加新分支。

**理由 3:错误友好**。如果 entity 解析出错,raw block 完整,可以指出具体哪个子表达式错。直接构建在错误时可能丢失上下文。

**理由 4:渐进式解析**。可以"懒解析"——只解析当前用到的 entity,其他 entity 保持 raw 形式(节省 CPU)。直接构建必须解析所有。

Raw token 模式是工业级 parser 的常见设计。Python 的 parser 用类似模式(AST 节点保留 raw token 引用)。Rust 的 syn crate 把 raw token 流暴露给用户,用户用 macro 处理。

### Raw token 收集的算法

遇到 `{`,parser 进入收集模式。**关键:track 嵌套深度**。外层 `{` depth=1,内层 `{` depth=2。`}` 减 depth。depth=0 时收集结束。

```rust
fn collect_raw_block(tokens: &[Token], pos: &mut usize) -> Vec<Token> {
    // 假设 tokens[*pos] 是 {
    *pos += 1;    // consume 外层 {
    let mut depth = 1;
    let mut collected = Vec::new();
    
    while *pos < tokens.len() {
        match &tokens[*pos].kind {
            TokenKind::LeftBrace => {
                depth += 1;
                collected.push(tokens[*pos].clone());
                *pos += 1;
            }
            TokenKind::RightBrace => {
                depth -= 1;
                *pos += 1;    // consume 这个 }
                if depth == 0 {
                    break;    // 外层 } 找到,结束
                }
                collected.push(tokens[*pos - 1].clone());    // 内层 },保留
            }
            TokenKind::Eof => break,
            _ => {
                collected.push(tokens[*pos].clone());
                *pos += 1;
            }
        }
    }
    
    collected
}
```

返回的 `Vec<Token>` 是 raw block 内的所有 token(不含外层 brace)。调用者再递归解析。

### Delayed parsing:语义层的递归下降

Raw block 给专门的"语义 parser":

```rust
fn parse_entity(raw: &[Token]) -> Entity {
    let mut pos = 0;
    let mut entity = Entity::default();
    
    while pos < raw.len() {
        match &raw[pos].kind {
            TokenKind::Identifier(name) if name == "piece" => {
                pos += 1;
                let piece = parse_piece(raw, &mut pos);
                entity.pieces.push(piece);
            }
            _ => { pos += 1; }
        }
    }
    
    entity
}

fn parse_piece(raw: &[Token], pos: &mut usize) -> Piece {
    let name = expect_identifier(raw, pos);
    let piece_raw = collect_raw_block(raw, pos);    // 嵌套收集
    parse_piece_body(&piece_raw)    // 又一层 delayed
}
```

每个语义层有自己的 parser,从 raw 流构建 domain object。**两层 parser**:generic(parser) + domain(parse_entity)。

### 元组 `(x, y)` 和路径 `a.b` 的语法

HHT 支持两种"复合语法":

**元组 `(x, y)`**:lexer 切成 5 个 token——`LeftParen`、`Number(x)`、`Comma`、`Number(y)`、`RightParen`。parser 组合:

```rust
fn parse_vec2(tokens: &[Token], pos: &mut usize) -> Vec2 {
    expect(LeftParen, tokens, pos);
    let x = expect_number(tokens, pos);
    expect(Comma, tokens, pos);
    let y = expect_number(tokens, pos);
    expect(RightParen, tokens, pos);
    Vec2 { x, y }
}
```

**路径 `a.b`**:lexer 切成 3 个 token——`Identifier(a)`、`Dot`、`Identifier(b)`。parser 组合:

```rust
fn parse_path(tokens: &[Token], pos: &mut usize) -> (String, String) {
    let piece = expect_identifier(tokens, pos);
    expect(Dot, tokens, pos);
    let ap = expect_identifier(tokens, pos);
    (piece, ap)
}
```

两种复合语法都用"lexer 切 token + parser 组合"模式。

## 2 · 心智模型

### 类比:打包礼物

简单礼物:parser 直接拆开,看到内容。

复杂礼物(套娃):parser 外层拆开,看到内层礼物,但**不立即拆**。把内层当 raw block,递归给专门的"拆礼物者"。

Raw token 模式:parser 是"通用拆礼物者",只拆外层。内层给专门的处理函数。

### Token 流的递归结构:可视化

让我们看一段 HHT 的 token 流,理解嵌套:

```
原文:
entity hero {
    piece body {
        sprite = "hero_body"
    }
}
```

Token 流:
```
[Identifier "entity"]
[Identifier "hero"]
[LeftBrace]
    [Identifier "piece"]
    [Identifier "body"]
    [LeftBrace]
        [Identifier "sprite"]
        [Equals]
        [String "hero_body"]
    [RightBrace]
[RightBrace]
[Eof]
```

`{` 和 `}` 配对,形成嵌套。**depth tracking** 是核心:
- 外层 `{` → depth=1
- 内层 `{` → depth=2
- 内层 `}` → depth=1
- 外层 `}` → depth=0 → 结束

这个 depth 计数是所有"嵌套解析"的基础——XML、JSON、HTML、Lisp S-expression 都用类似机制。

### Raw block 收集的实际场景

考虑更复杂的嵌套(三层):

```
entity hero {
    piece body {
        sprite = "x"
        child {
            nested = "deep"
        }
    }
}
```

Token 流(简化,只看 braces):
```
{ { { } } }
1 2 3 2 1 0
```

外层 `{` 启动收集,depth=1。看到第二层 `{`,depth=2,**保留这个 `{` 在 raw block**(因为它是内层)。看到第三层 `{`,depth=3,保留。第三层 `}`,depth=2,保留(因为还在外层 block 内)。第二层 `}`,depth=1,保留。第一层 `}`,depth=0,**结束收集**(不保留外层 `}`)。

最终 raw block(不含外层 brace):
```
[Identifier "piece"]
[Identifier "body"]
[LeftBrace]
    [Identifier "sprite"]
    [Equals]
    [String "x"]
    [Identifier "child"]
    [LeftBrace]
        [Identifier "nested"]
        [Equals]
        [String "deep"]
    [RightBrace]
[RightBrace]
```

调用者拿到这个 raw block,可以递归调 `collect_raw_block` 处理 piece 内的 `child { ... }`。

### Delayed parsing 的工业级应用

Raw token + delayed parsing 模式不只是 HHT 用。工业级场景:

**编译器前端**:`rustc` parser 把源码 → token → AST,AST 节点保留 raw token span(用于错误信息、宏展开、IDE 支持)。这是 Rust 编译器的核心设计。

**JSON streaming parser**:大 JSON 文件不全解析(节省内存),按需解析子树。`serde_json::StreamDeserializer` 是 streaming。

**glTF loader**:glTF 是 JSON,parser 先解析 JSON 通用结构(树形),然后游戏代码按需深入节点(`accessors`、`buffers`、`meshes`)。Lazy parsing。

**Shader 编译器**:`glslang` 把 GLSL 切 token + 通用 AST。后续优化、SPIR-V 生成各阶段处理 AST。AST 保留 raw token 引用,用于 source map。

**Macro system**:Rust macro 接收 `TokenStream`(就是 raw token 流)。Macro 决定如何解释(展开)这些 token。这是 Rust macro 强大的基础。

### 错误恢复 + raw token

Raw token 还帮助错误恢复。如果某个 piece 内有错(比如 `sprite = "missing_quote`),raw block 仍完整。Parser 可以:

1. 报错(piece 7 第 12 行)
2. 跳过这个 piece 的 raw block
3. 继续解析 piece 8、9、10

直接构建时,如果错,entity struct 可能半完整,后续处理复杂。Raw token 让"跳过错误范围"简单——找到 matching `}`,跳过这之间的所有 token。

这是工业级 parser 的错误恢复核心机制。

Raw block 的"真正解析"在专门函数:

### Lv2 · 动手实践

**题**:扩展 HHT parser,支持 `entity name { ... }` 嵌套,里面是 piece。

完成标准:`cargo run` 解析嵌套 entity,输出 AST。

**参考解答**:

```rust
use std::collections::HashMap;

#[derive(Debug, Clone, PartialEq)]
enum TokenKind {
    Identifier(String),
    String(String),
    Number(f32),
    LeftBrace, RightBrace,
    LeftParen, RightParen,
    Equals, Comma, Dot,
    Newline,
    Eof,
}

#[derive(Debug, Clone)]
struct Token { kind: TokenKind }

fn lex(text: &str) -> Vec<Token> {
    let mut tokens = Vec::new();
    let chars: Vec<char> = text.chars().collect();
    let mut i = 0;
    
    while i < chars.len() {
        let c = chars[i];
        if c.is_whitespace() && c != '\n' { i += 1; continue; }
        if c == '\n' { tokens.push(Token { kind: TokenKind::Newline }); i += 1; continue; }
        if c == '#' {
            while i < chars.len() && chars[i] != '\n' { i += 1; }
            continue;
        }
        
        match c {
            '{' => { tokens.push(Token { kind: TokenKind::LeftBrace }); i += 1; }
            '}' => { tokens.push(Token { kind: TokenKind::RightBrace }); i += 1; }
            '(' => { tokens.push(Token { kind: TokenKind::LeftParen }); i += 1; }
            ')' => { tokens.push(Token { kind: TokenKind::RightParen }); i += 1; }
            '=' => { tokens.push(Token { kind: TokenKind::Equals }); i += 1; }
            ',' => { tokens.push(Token { kind: TokenKind::Comma }); i += 1; }
            '.' => { tokens.push(Token { kind: TokenKind::Dot }); i += 1; }
            '"' => {
                i += 1;
                let mut s = String::new();
                while i < chars.len() && chars[i] != '"' {
                    s.push(chars[i]); i += 1;
                }
                if i < chars.len() { i += 1; }    // closing
                tokens.push(Token { kind: TokenKind::String(s) });
            }
            _ if c.is_alphanumeric() || c == '_' => {
                let mut s = String::new();
                while i < chars.len() && (chars[i].is_alphanumeric() || chars[i] == '_') {
                    s.push(chars[i]); i += 1;
                }
                if let Ok(n) = s.parse::<f32>() {
                    tokens.push(Token { kind: TokenKind::Number(n) });
                } else {
                    tokens.push(Token { kind: TokenKind::Identifier(s) });
                }
            }
            _ => { i += 1; }
        }
    }
    
    tokens.push(Token { kind: TokenKind::Eof });
    tokens
}

#[derive(Debug, Default, Clone)]
struct Vec2 { x: f32, y: f32 }

#[derive(Debug, Default, Clone)]
struct AlignmentPoint {
    name: String,
    offset: Vec2,
}

#[derive(Debug, Default, Clone)]
struct Piece {
    name: String,
    sprite: String,
    alignment_points: Vec<AlignmentPoint>,
    parent: Option<(String, String)>,    // (parent piece name, alignment point name)
}

#[derive(Debug, Default, Clone)]
struct Entity {
    name: String,
    pieces: Vec<Piece>,
}

// 收集 { ... } 内的 raw token,返回内容(不含外层 brace)
fn collect_raw_block(tokens: &[Token], pos: &mut usize) -> Vec<Token> {
    // 假设 tokens[*pos] 是 {
    *pos += 1;
    let mut depth = 1;
    let mut collected = Vec::new();
    
    while *pos < tokens.len() {
        match &tokens[*pos].kind {
            TokenKind::LeftBrace => { depth += 1; collected.push(tokens[*pos].clone()); *pos += 1; }
            TokenKind::RightBrace => {
                depth -= 1;
                *pos += 1;
                if depth == 0 { break; }
                collected.push(tokens[*pos - 1].clone());
            }
            TokenKind::Eof => break,
            _ => { collected.push(tokens[*pos].clone()); *pos += 1; }
        }
    }
    
    collected
}

fn skip_noise(tokens: &[Token], pos: &mut usize) {
    while *pos < tokens.len() {
        match &tokens[*pos].kind {
            TokenKind::Newline => *pos += 1,
            _ => break,
        }
    }
}

fn parse_vec2(tokens: &[Token], pos: &mut usize) -> Vec2 {
    // (x, y)
    if !matches!(tokens[*pos].kind, TokenKind::LeftParen) { return Vec2::default(); }
    *pos += 1;
    let x = match &tokens[*pos].kind { TokenKind::Number(n) => *n, _ => 0.0 };
    *pos += 1;
    if matches!(tokens[*pos].kind, TokenKind::Comma) { *pos += 1; }
    let y = match &tokens[*pos].kind { TokenKind::Number(n) => *n, _ => 0.0 };
    *pos += 1;
    if matches!(tokens[*pos].kind, TokenKind::RightParen) { *pos += 1; }
    Vec2 { x, y }
}

fn parse_alignment_point(tokens: &[Token], pos: &mut usize) -> AlignmentPoint {
    // alignment_point NAME = (x, y)
    *pos += 1;    // skip 'alignment_point'
    let name = match &tokens[*pos].kind {
        TokenKind::Identifier(s) => s.clone(),
        _ => String::new(),
    };
    *pos += 1;
    if matches!(tokens[*pos].kind, TokenKind::Equals) { *pos += 1; }
    let offset = parse_vec2(tokens, pos);
    AlignmentPoint { name, offset }
}

fn parse_piece_block(raw: &[Token]) -> Piece {
    let mut piece = Piece::default();
    let mut pos = 0;
    
    while pos < raw.len() {
        skip_noise(raw, &mut pos);
        if pos >= raw.len() { break; }
        
        match &raw[pos].kind {
            TokenKind::Identifier(s) if s == "sprite" => {
                pos += 1;
                if matches!(raw[pos].kind, TokenKind::Equals) { pos += 1; }
                if let TokenKind::String(v) = &raw[pos].kind {
                    piece.sprite = v.clone();
                    pos += 1;
                }
            }
            TokenKind::Identifier(s) if s == "alignment_point" => {
                let ap = parse_alignment_point(raw, &mut pos);
                piece.alignment_points.push(ap);
            }
            TokenKind::Identifier(s) if s == "parent" => {
                pos += 1;
                if matches!(raw[pos].kind, TokenKind::Equals) { pos += 1; }
                let parent_piece = match &raw[pos].kind {
                    TokenKind::Identifier(s) => s.clone(),
                    _ => String::new(),
                };
                pos += 1;
                if matches!(raw[pos].kind, TokenKind::Dot) { pos += 1; }
                let parent_ap = match &raw[pos].kind {
                    TokenKind::Identifier(s) => s.clone(),
                    _ => String::new(),
                };
                pos += 1;
                piece.parent = Some((parent_piece, parent_ap));
            }
            TokenKind::Identifier(_) => {
                // 未识别,跳过
                pos += 1;
            }
            _ => { pos += 1; }
        }
    }
    
    piece
}

fn parse_entity(tokens: &[Token], pos: &mut usize) -> Entity {
    // entity NAME { ... }
    *pos += 1;    // skip 'entity'
    let name = match &tokens[*pos].kind {
        TokenKind::Identifier(s) => s.clone(),
        _ => String::new(),
    };
    *pos += 1;
    skip_noise(tokens, pos);
    
    let mut entity = Entity { name, pieces: Vec::new() };
    
    if matches!(tokens[*pos].kind, TokenKind::LeftBrace) {
        let raw = collect_raw_block(tokens, pos);
        
        // 解析 raw block 内的 piece
        let mut raw_pos = 0;
        while raw_pos < raw.len() {
            skip_noise(&raw, &mut raw_pos);
            if raw_pos >= raw.len() { break; }
            
            match &raw[raw_pos].kind {
                TokenKind::Identifier(s) if s == "piece" => {
                    raw_pos += 1;
                    let piece_name = match &raw[raw_pos].kind {
                        TokenKind::Identifier(s) => s.clone(),
                        _ => String::new(),
                    };
                    raw_pos += 1;
                    skip_noise(&raw, &mut raw_pos);
                    if matches!(raw[raw_pos].kind, TokenKind::LeftBrace) {
                        let piece_raw = collect_raw_block(&raw, &mut raw_pos);
                        let mut piece = parse_piece_block(&piece_raw);
                        piece.name = piece_name;
                        entity.pieces.push(piece);
                    }
                }
                _ => { raw_pos += 1; }
            }
        }
    }
    
    entity
}

fn main() {
    let text = r#"
entity hero {
    piece body {
        sprite = "hero_body"
        alignment_point neck = (0, -20)
        alignment_point hand_r = (15, 0)
    }
    piece head {
        sprite = "hero_head"
        parent = body.neck
    }
    piece sword {
        sprite = "iron_sword"
        parent = body.hand_r
    }
}
"#;
    
    let tokens = lex(text);
    let mut pos = 0;
    let entity = parse_entity(&tokens, &mut pos);
    
    println!("=== Parsed Entity ===\n");
    println!("entity: {}", entity.name);
    for piece in &entity.pieces {
        println!("  piece '{}': sprite={}", piece.name, piece.sprite);
        for ap in &piece.alignment_points {
            println!("    ap '{}': ({}, {})", ap.name, ap.offset.x, ap.offset.y);
        }
        if let Some((p, ap)) = &piece.parent {
            println!("    parent: {}.{}", p, ap);
        }
    }
}
```
