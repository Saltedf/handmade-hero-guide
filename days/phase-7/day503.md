
# Day 503 · 构造相机缓动函数

> 玩家走到屏幕边缘,相机要跟随。但"瞬移"看着难受,要"平滑跟随"。Day 503 给相机加 easing 函数——相机位置随时间渐近目标,而不是瞬移。

## 0 · 为什么要有这一天

到 Day 502,相机跟随玩家是**硬跟随**:

```rust
camera.pos = player.pos - screen_center;
```

玩家走一步,相机立刻跟一步。问题:

- 屏幕抖动(每帧重画,玩家移动 1 像素,相机移 1 像素)
- 玩家突然传送(走楼梯)时,相机瞬移,玩家失去方向感
- 镜头看着"机械",没有电影感

工业级游戏的相机是**软跟随**——相机目标在玩家位置,实际相机位置慢慢追上目标。这种"慢慢追上"叫 **easing**(缓动)或 **lerp**(线性插值)或 **damping**(阻尼)。

Day 503 实现 easing。数学上:`camera.pos += (target - camera.pos) * factor`,factor 控制追得快慢。

为什么这件事重要?

- **玩家体验**:平滑相机让游戏感觉"专业"
- **晕动症**:硬跟随让人晕,缓动减少
- **电影感**:缓动是 cinematic 的基础

## 2 · 心智模型

### 类比:狗绳

主人(玩家)走路,狗(相机)用绳子(lerp)跟着。

硬跟随:狗用刚性绳子,主人移 1 米,狗立刻移 1 米。抖动。

软跟随:狗用弹性绳子,主人移 1 米,狗被拉过去,但因为有弹性,狗渐渐靠近主人,慢慢停下。

绳子的"弹性"就是 easing factor。弹性大,狗快速追上;弹性小,狗慢慢追。

### Lerp(线性插值)

Lerp = Linear Interpolation。

```rust
fn lerp(a: f32, b: f32, t: f32) -> f32 {
    a + (b - a) * t
}
```

`t = 0` 返回 a,`t = 1` 返回 b。`t = 0.5` 返回中点。

相机跟随用 lerp:

```rust
camera.pos = lerp(camera.pos, target, 0.1);    // 每帧追 10%
```

每帧相机追 target 的 10%。10 帧后大致追上(实际数学是指数衰减)。

### Exponential Decay(指数衰减)

每帧追 10%,多久追完?

数学上,每帧剩 90% 的距离。n 帧后剩 `0.9^n`。

- 1 帧:0.9
- 10 帧:0.349
- 30 帧:0.042(基本追完)
- 60 帧:0.002

30 帧 = 半秒,所以 0.1 的 lerp factor 大约 0.5 秒追完。

公式:`pos_n = target + (pos_0 - target) * (1 - factor)^n`

`(1 - factor)^n` 指数衰减。

### Frame-rate independence

问题:`camera.pos += (target - camera.pos) * 0.1` 每帧 10%。

- 60 FPS:每秒追 1 - 0.9^60 ≈ 99.8%
- 30 FPS:每秒追 1 - 0.9^30 ≈ 95.8%

不同帧率,相机表现不同。要修正。

解法:用 dt 调整 factor。

```rust
let factor = 1.0 - (-easing_rate * dt).exp();
camera.pos += (target - camera.pos) * factor;
```

`-easing_rate * dt` 的 exp 给出"指数衰减",frame-rate independent。

`easing_rate` 是连续参数(单位 1/秒)。`easing_rate = 5.0` 表示"5 秒内追完约 99%"。

### Easing 曲线类型

不同场景用不同 easing:

**Linear(线性)**:t 直接用,匀速。机械感。

**Ease-in(慢入)**:开始慢,后面快。加速。

**Ease-out(慢出)**:开始快,后面慢。减速。

**Ease-in-out(慢入慢出)**:两端慢,中间快。自然。

**Spring(弹簧)**:过冲后回弹。生动。

数学公式(其中 t 是 0-1 的进度):

- Linear: `t`
- Ease-in: `t * t`
- Ease-out: `1 - (1-t) * (1-t)` = `t * (2 - t)`
- Ease-in-out: `t * t * (3 - 2*t)`
- Spring: 复杂,涉及正弦 / 余弦

相机跟随常用 ease-out 或 exponential decay。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 `1.0 - (-rate * dt).exp()` 比简单 `rate * dt` 更好?

**参考解答**:两个原因:

第一,**稳定性**。如果 `rate * dt > 1`(比如低帧率 + 高 rate),`rate * dt` 让 factor > 1,相机过冲(超过 target)甚至来回弹。`1 - exp(-x)` 对任意正 x 都在 (0, 1),永远不过冲。

第二,**数学意义**。`exp(-rate * dt)` 是"剩余比例"。`1 - exp(-rate * dt)` 是"已完成比例"。这个公式源自微分方程 `dx/dt = -rate * (x - target)`,解是指数衰减。物理意义清晰。

简化版本 `rate * dt` 是 `1 - exp(-rate * dt)` 的泰勒展开一阶近似,只在 `rate * dt << 1` 时准确。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:实现最小相机缓动。给定初始 camera pos = (0,0),target = (100, 0)。用 ease-out 公式,跑 60 帧,看 camera.pos 怎么接近 100。

完成标准:`cargo run` 输出每帧的 pos,展示从 0 渐近 100。

**参考解答**:

```rust
#[derive(Copy, Clone, Debug)]
struct Vec2 { x: f32, y: f32 }

fn lerp(a: f32, b: f32, t: f32) -> f32 {
    a + (b - a) * t
}

struct Camera {
    pos: Vec2,
    target: Vec2,
    smoothing: f32,    // 单位 1/秒
}

impl Camera {
    fn update_buggy(&mut self, dt: f32) {
        // 简化版(非帧率无关)
        let factor = self.smoothing * dt;
        self.pos.x = lerp(self.pos.x, self.target.x, factor);
        self.pos.y = lerp(self.pos.y, self.target.y, factor);
    }
    
    fn update_fixed(&mut self, dt: f32) {
        // 帧率无关版
        let factor = 1.0 - (-self.smoothing * dt).exp();
        self.pos.x = lerp(self.pos.x, self.target.x, factor);
        self.pos.y = lerp(self.pos.y, self.target.y, factor);
    }
}

fn main() {
    println!("=== 帧率无关版(dt = 1/60)===");
    let mut cam = Camera {
        pos: Vec2 { x: 0.0, y: 0.0 },
        target: Vec2 { x: 100.0, y: 0.0 },
        smoothing: 5.0,
    };
    let dt = 1.0 / 60.0;
    for frame in 0..60 {
        cam.update_fixed(dt);
        if frame % 5 == 0 {
            println!("  frame {}: pos.x = {:.2}", frame, cam.pos.x);
        }
    }
    println!("  final: pos.x = {:.2} (target 100)", cam.pos.x);
    
    println!("\n=== 不同 smoothing 值 ===\n");
    for smoothing in [1.0, 5.0, 10.0, 30.0] {
        let mut cam = Camera {
            pos: Vec2 { x: 0.0, y: 0.0 },
            target: Vec2 { x: 100.0, y: 0.0 },
            smoothing,
        };
        for _ in 0..60 {
            cam.update_fixed(1.0 / 60.0);
        }
        println!("  smoothing={}: 1秒后 pos.x = {:.2}", smoothing, cam.pos.x);
    }
    
    println!("\n=== 不同帧率比较 ===\n");
    for fps in [30.0, 60.0, 120.0] {
        let mut cam = Camera {
            pos: Vec2 { x: 0.0, y: 0.0 },
            target: Vec2 { x: 100.0, y: 0.0 },
            smoothing: 5.0,
        };
        let dt = 1.0 / fps;
        for _ in 0..fps as usize {    // 跑 1 秒
            cam.update_fixed(dt);
        }
        println!("  fps={}: 1秒后 pos.x = {:.2} (应该接近,因为帧率无关)", fps, cam.pos.x);
    }
}
```

为什么这么写:`smoothing` 单位是 1/秒,直观。`1.0 - exp(-smoothing * dt)` 给出帧率无关的 factor。dt = 1/60 在 60 FPS,dt = 1/30 在 30 FPS,结果相同。

// ============================================================
// Day 503 · 构造相机缓动函数
// ============================================================

use std::fmt;

// ============================================================
// Vec2
// ============================================================

#[derive(Copy, Clone, Debug, PartialEq)]
struct Vec2 { x: f32, y: f32 }

impl Vec2 {
    const fn new(x: f32, y: f32) -> Self { Self { x, y } }
    const ZERO: Self = Self::new(0.0, 0.0);
    fn length(self) -> f32 { (self.x * self.x + self.y * self.y).sqrt() }
}

impl std::ops::Add for Vec2 {
    type Output = Vec2;
    fn add(self, o: Vec2) -> Vec2 { Vec2::new(self.x + o.x, self.y + o.y) }
}

impl std::ops::Sub for Vec2 {
    type Output = Vec2;
    fn sub(self, o: Vec2) -> Vec2 { Vec2::new(self.x - o.x, self.y - o.y) }
}

impl std::ops::AddAssign for Vec2 {
    fn add_assign(&mut self, o: Vec2) { self.x += o.x; self.y += o.y; }
}

impl std::ops::Mul<f32> for Vec2 {
    type Output = Vec2;
    fn mul(self, s: f32) -> Vec2 { Vec2::new(self.x * s, self.y * s) }
}

impl fmt::Display for Vec2 {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "({:.1},{:.1})", self.x, self.y)
    }
}

// ============================================================
// Lerp & easing functions
// ============================================================

fn lerp(a: f32, b: f32, t: f32) -> f32 {
    a + (b - a) * t
}

fn lerp_vec(a: Vec2, b: Vec2, t: f32) -> Vec2 {
    Vec2::new(lerp(a.x, b.x, t), lerp(a.y, b.y, t))
}

fn ease_linear(t: f32) -> f32 { t }

fn ease_in_quad(t: f32) -> f32 { t * t }

fn ease_out_quad(t: f32) -> f32 { t * (2.0 - t) }

fn ease_in_out_quad(t: f32) -> f32 {
    if t < 0.5 { 2.0 * t * t } else { -1.0 + (4.0 - 2.0 * t) * t }
}

fn ease_out_cubic(t: f32) -> f32 {
    let f = 1.0 - t;
    1.0 - f * f * f
}

fn ease_in_out_cubic(t: f32) -> f32 {
    if t < 0.5 { 4.0 * t * t * t } else {
        let f = 2.0 * t - 2.0;
        1.0 + f * f * f / 2.0
    }
}

fn ease_out_elastic(t: f32) -> f32 {
    if t == 0.0 || t == 1.0 { return t; }
    let p = 0.3;
    let s = p / 4.0;
    let f = 2.0 * std::f32::consts::PI * (t - s) / p;
    (2.0_f32.powf(-10.0 * t)) * f.sin() + 1.0
}

// 帧率无关 exponential decay factor
fn exp_decay_factor(rate: f32, dt: f32) -> f32 {
    1.0 - (-rate * dt).exp()
}

// ============================================================
// Camera
// ============================================================

struct Camera {
    pos: Vec2,
    target: Vec2,
    smoothing: f32,    // 1/秒
    bounds: Option<(Vec2, Vec2)>,    // (min, max)
    lookahead: f32,
    velocity_estimate: Vec2,
    shake: f32,
}

impl Camera {
    fn new() -> Self {
        Self {
            pos: Vec2::ZERO,
            target: Vec2::ZERO,
            smoothing: 5.0,
            bounds: None,
            lookahead: 0.0,
            velocity_estimate: Vec2::ZERO,
            shake: 0.0,
        }
    }
    
    fn set_target(&mut self, target: Vec2, player_velocity: Vec2) {
        // lookahead:相机往玩家移动方向偏
        self.target = target + player_velocity * self.lookahead;
        // 估算速度(简化:直接用 player_velocity)
        self.velocity_estimate = player_velocity;
    }
    
    fn set_bounds(&mut self, min: Vec2, max: Vec2) {
        self.bounds = Some((min, max));
    }
    
    fn update(&mut self, dt: f32) {
        let factor = exp_decay_factor(self.smoothing, dt);
        let new_pos = lerp_vec(self.pos, self.target, factor);
        self.pos = new_pos;
        
        // 应用 bounds
        if let Some((min, max)) = self.bounds {
            self.pos.x = self.pos.x.max(min.x).min(max.x);
            self.pos.y = self.pos.y.max(min.y).min(max.y);
        }
        
        // Shake 衰减
        if self.shake > 0.0 {
            self.shake *= (-5.0 * dt).exp();
            if self.shake < 0.01 { self.shake = 0.0; }
        }
    }
    
    fn render_pos(&self) -> Vec2 {
        // 加 shake 偏移
        if self.shake > 0.0 {
            let shake_x = (rand_byte() as f32 / 255.0 - 0.5) * self.shake * 2.0;
            let shake_y = (rand_byte() as f32 / 255.0 - 0.5) * self.shake * 2.0;
            self.pos + Vec2::new(shake_x, shake_y)
        } else {
            self.pos
        }
    }
    
    fn trigger_shake(&mut self, intensity: f32) {
        self.shake = self.shake.max(intensity);
    }
}

// 简单的伪随机(不用 rand crate)
fn rand_byte() -> u8 {
    use std::cell::Cell;
    thread_local! {
        static STATE: Cell<u32> = Cell::new(0x12345678);
    }
    STATE.with(|s| {
        let mut x = s.get();
        x ^= x << 13;
        x ^= x >> 17;
        x ^= x << 5;
        s.set(x);
        (x & 0xFF) as u8
    })
}

    println!("t      linear  in-quad  out-quad  in-out-cubic  out-elastic");
    for i in 0..=10 {
        let t = i as f32 / 10.0;
        println!("{:.1}    {:.3}   {:.3}    {:.3}     {:.3}         {:.3}",
                 t,
                 ease_linear(t),
                 ease_in_quad(t),
                 ease_out_quad(t),
                 ease_in_out_cubic(t),
                 ease_out_elastic(t));
    }
}

fn demo_camera_smoothing() {
    println!("\n=== 相机缓动 ===\n");
    
    let mut cam = Camera::new();
    cam.pos = Vec2::new(0.0, 0.0);
    cam.set_target(Vec2::new(100.0, 0.0), Vec2::ZERO);
    cam.smoothing = 5.0;
    
    let dt = 1.0 / 60.0;
    println!("Initial: pos = {}, target = {}", cam.pos, cam.target);
    println!();
    
    for frame in 0..=60 {
        if frame % 10 == 0 {
            println!("  frame {:2}: pos.x = {:6.2} (delta to target = {:5.2})",
                     frame, cam.pos.x, cam.target.x - cam.pos.x);
        }
        cam.update(dt);
    }
    println!("  final: pos.x = {:.2}", cam.pos.x);
}

fn demo_smoothing_factor_comparison() {
    println!("\n=== 不同 smoothing 比较(1秒后)===");
    
    for smoothing in [1.0, 2.0, 5.0, 10.0, 30.0] {
        let mut cam = Camera::new();
        cam.pos = Vec2::ZERO;
        cam.set_target(Vec2::new(100.0, 0.0), Vec2::ZERO);
        cam.smoothing = smoothing;
        
        let dt = 1.0 / 60.0;
        for _ in 0..60 { cam.update(dt); }
        
        println!("  smoothing={:5.1}: pos.x = {:6.2} ({:.0}%)",
                 smoothing, cam.pos.x, cam.pos.x);
    }
}

fn demo_frame_rate_independence() {
    println!("\n=== 帧率无关性验证 ===\n");
    
    println!("跑 1 秒,不同 FPS:");
    for fps in [30.0, 60.0, 120.0, 240.0] {
        let mut cam = Camera::new();
        cam.pos = Vec2::ZERO;
        cam.set_target(Vec2::new(100.0, 0.0), Vec2::ZERO);
        cam.smoothing = 5.0;
        
        let dt = 1.0 / fps;
        for _ in 0..(fps as usize) { cam.update(dt); }
        
        println!("  {:4.0} FPS: pos.x = {:.2}", fps, cam.pos.x);
    }
    println!("(应该都接近,因为帧率无关)");
}

fn demo_bounds_and_lookahead() {
    println!("\n=== Bounds + Lookahead ===\n");
    
    let mut cam = Camera::new();
    cam.set_bounds(Vec2::new(0.0, 0.0), Vec2::new(500.0, 500.0));
    cam.lookahead = 5.0;
    
    // 玩家在 (300, 250),往右走(velocity 5)
    cam.set_target(Vec2::new(300.0, 250.0), Vec2::new(5.0, 0.0));
    println!("玩家位置 (300, 250), velocity (5, 0)");
    println!("lookahead factor = 5");
    println!("预期 target = (325, 250) (300 + 5*5)");
    println!("实际 target = {}", cam.target);
    
    cam.pos = Vec2::new(-100.0, -100.0);    // 故意在 bounds 外
    println!("\n初始 pos (-100, -100)(在 bounds 外)");
    cam.update(0.5);
    println!("update 后 pos = {}(应被 clamp 到 bounds)", cam.pos);
}

fn demo_screen_shake() {
    println!("\n=== Screen shake ===\n");
    
    let mut cam = Camera::new();

    }
}

            assert!((ease_in_out_cubic(t) - t).abs() < 0.001);
            assert!((ease_out_cubic(t) - t).abs() < 0.001);
        }

        // 任意正 rate*dt,factor 应在 [0, 1]

            for dt in [0.001, 0.01, 0.1, 1.0] {
                let f = exp_decay_factor(rate, dt);
                assert!(f >= 0.0 && f <= 1.0);
            }
        }
    }

    fn test_camera_approaches_target() {
        let mut cam = Camera::new();

        cam.smoothing = 5.0;
        
        for _ in 0..300 { cam.update(1.0 / 60.0); }
        
        // 5 秒后应非常接近

    }

        let mut cam = Camera::new();
