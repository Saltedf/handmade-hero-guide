# Day 572 · 滚动光照体素

> Cascade voxel grid 中心跟随玩家,玩家移动时 grid 整体"滚动"——某些 voxel 离开视野(释放),新 voxel 进入(分配)。Day 572 Casey 实现 **voxel scrolling**——内存高效管理滚动 grid。

## 0 · 为什么要有这一天

让我们把镜头贴近玩家。你跟着 Handmade Hero 走到 Day 567——Casey 实现了 cascade voxel grid,grid 中心跟随玩家。你跑游戏,玩家在长走廊跑动——**奇怪的事情发生了**:每次玩家走几步,游戏**卡顿一下**。GPU profiler 显示,卡顿瞬间 voxel grid 在"重新分配"——32³ voxel 数据全 copy,32K voxel × 4 byte = 128 KB,copy 一次几 ms,玩家感觉明显。

为什么会重新分配?**朴素实现**:玩家走 1 voxel,grid 中心移动,grid 内容要"跟着滚"。朴素做法是:**重新分配整个 grid**,把内容 copy 到新位置——这是 O(N³) 操作。32³ = 32768 voxel,每次玩家走 1 米就 32K voxel copy——慢。

**滚动优化(本日学的)**:grid 内存**不变**,只移动"逻辑中心"——把 voxel 索引映射到一个**循环 buffer**(类似 ring buffer)。玩家移动时,新 voxel 写入"最旧的"位置,逻辑上 grid 滚了。**复杂度从 O(N³) 降到 O(N²)**——只更新"新进入的那一列"。

让我把这件事具体化。32³ grid 中心跟随玩家,玩家向 +x 走 1 米:

- 朴素做法:重新分配整个 grid,所有 voxel 在新位置 copy——32768 voxel × memcpy
- 滚动做法:grid 内存不变,只是逻辑上 +x 方向出现一列新 voxel(32 × 32 = 1024 个),-x 方向"丢"一列。新 voxel 写入内存里"最旧的"位置——只有 1024 个 voxel 需要重新初始化(从 backing storage 读)

**这就是 32 倍优化**——从 32K 操作降到 1K 操作。工业 GI 必须这么做,否则玩家移动卡顿严重。

这就是 Day 558 学的 ring buffer 思路在 voxel grid 的应用——**同一个抽象,不同上下文**。Ring buffer 是计算机科学的基础数据结构,理解了它你能解释 Linux 内核的 circular kfifo、GPU 的 toroidal texture、网络栈的 packet ring。

完成这一天之后,你具备:

- 理解 circular buffer / toroidal buffer 的本质——"用 mod 运算让索引绕圈,避免物理数据移动"
- 能实现 voxel grid 滚动,把 O(N³) 重分配优化到 O(N²) 局部更新
- 知道 GPU 上 toroidal texture 的实现——wgpu 的 `address_mode: ClampToEdge` vs `Repeat`,以及为什么要手动 wrap
- 理解 sparse backing storage——无限世界的 chunk 按需加载,只有玩家附近的 chunk 在 voxel grid 里

## 2 · 心智模型

### 2.1 类比:老虎机和循环 conveyor

老虎机的滚轮:3 个滚轮转动,符号循环出现——你看到的是当前可见的 3 个,实际滚轮上有 20+ 个。**关键**:滚轮是**循环的**——符号绕一圈又出现。

Voxel grid 的"循环 buffer"类似:内存里固定 N³ voxel,但"逻辑位置"循环——玩家移动,voxel 索引绕一圈。**内存不动,只是"窗口"在内存里平移**。

或者想象 conveyor belt:货物在传送带上循环,你看到一段(视野),实际带子是循环的。新货物从一端进,旧货物从另一端"消失"——但带子本身不动,只是货物在带子上的位置变化。

**这个抽象的物理直觉**:**"逻辑"和"物理"分离**。逻辑上 voxel 在世界坐标 (100, 200, 50);物理上 voxel 在内存数组 [4, 7, 2]——映射函数把逻辑坐标"wrap"到物理索引。玩家移动,逻辑坐标变,但物理索引只是绕圈——避免了"复制数据"。

**Ring buffer 是计算机科学的基础抽象**,理解了它你能解释很多系统:

- **Linux 内核 kfifo**:`struct kfifo` 是循环 buffer,用于生产者-消费者队列
- **GPU texture wrapping**:`GL_REPEAT` / `VK_SAMPLER_ADDRESS_MODE_REPEAT`,UV 超过 1 绕回
- **Network ring buffer**:`AF_PACKET` 的 TPACKET_V3 ring,内核-用户态零拷贝
- **Audio ring buffer**:PortAudio、JACK 的循环 buffer,实时音频流

### 2.2 严谨展开:toroidal buffer

"toroidal"是拓扑学术语,字面意思是"甜甜圈形状"——把方形网格的对边"粘起来",形成甜甜圈。**内存上的 3D 数组,逻辑上是一个 3-torus**——x/y/z 各方向循环。

```rust
struct ToroidalVoxelGrid {
    data: Vec<Voxel>,    // 固定 N³ 元素
    dim: usize,
    offset: [i64; 3],    // 逻辑原点的内存索引(0..N)
    world_center: V3,    // 逻辑原点的世界坐标
}

impl ToroidalVoxelGrid {
    fn world_to_memory(&self, world: V3) -> [usize; 3] {
        let half = (self.dim as f32 * VOXEL_SIZE) * 0.5;
        let li = ((world[0] - self.world_center[0] + half) / VOXEL_SIZE) as i64;
        let lj = ((world[1] - self.world_center[1] + half) / VOXEL_SIZE) as i64;
        let lk = ((world[2] - self.world_center[2] + half) / VOXEL_SIZE) as i64;

        // Wrap to memory index——rem_euclid 处理负数,确保结果非负
        let mi = ((li + self.offset[0]).rem_euclid(self.dim as i64)) as usize;
        let mj = ((lj + self.offset[1]).rem_euclid(self.dim as i64)) as usize;
        let mk = ((lk + self.offset[2]).rem_euclid(self.dim as i64)) as usize;
        [mi, mj, mk]
    }

    fn scroll(&mut self, dx: i64, dy: i64, dz: i64) {
        self.offset[0] = (self.offset[0] + dx).rem_euclid(self.dim as i64);
        self.offset[1] = (self.offset[1] + dy).rem_euclid(self.dim as i64);
        self.offset[2] = (self.offset[2] + dz).rem_euclid(self.dim as i64);

        self.world_center[0] += dx as f32 * VOXEL_SIZE;
        self.world_center[1] += dy as f32 * VOXEL_SIZE;
        self.world_center[2] += dz as f32 * VOXEL_SIZE;

        // 新进入的 voxel 要初始化(从 backing 读)
        // ...
    }
}
```

**关键函数 `rem_euclid`**:Rust 的 `%` 操作符对负数返回负数(`-1 % 4 = -1`),而我们要的是"循环到正数"(`-1 % 4 = 3`)。`rem_euclid` 是欧几里得余数,保证非负结果。**这是 toroidal buffer 实现的关键细节**——用错 `%` 会有 off-by-one bug。

**注意 3 个 offset**:x/y/z 各方向独立循环——这就是 "3-torus"。如果只 x 循环(y/z 不循环)是"圆柱",只 x/y 循环(z 不循环)是"扁平环"。**Voxel grid 需要全 3 维循环**因为玩家任意方向移动。

### 2.3 Scroll 时的新 voxel 初始化

玩家向 +x 走 1 米,grid 中心也向 +x 走 1 米。grid 逻辑上:

- +x 边缘出现 1 列新 voxel(32 × 32 = 1024 个)
- -x 边缘的 1 列 voxel "离开"

这些新 voxel 在内存里覆盖最旧的位置(逻辑 -x 边缘的内存地址)。**初始化**它们:从 sparse backing storage 读 chunk,转换到 voxel。

```rust
fn scroll_and_init(
    grid: &mut ToroidalVoxelGrid,
    dx: i64, dy: i64, dz: i64,
    backing: &SparseVoxelStorage,
) {
    let new_origin = [
        grid.world_center[0] + dx as f32 * VOXEL_SIZE,
        grid.world_center[1] + dy as f32 * VOXEL_SIZE,
        grid.world_center[2] + dz as f32 * VOXEL_SIZE,
    ];

    // 找新进入的 voxel 范围
    let half = grid.dim as i64 / 2;
    if dx > 0 {
        // +x 方向进入 [half-dx+1, half] 这一段
        for k in 0..grid.dim as i64 {
            for j in 0..grid.dim as i64 {
                for di in 0..dx {
                    let i = half - di;
                    let world = [
                        new_origin[0] + i as f32 * VOXEL_SIZE,
                        // ...
                    ];
                    let voxel_data = backing.query(world);
                    let mem_idx = grid.world_to_memory(world);
                    grid.data[idx(mem_idx)] = voxel_data;
                }
            }
        }
    }
    // 类似处理 dy, dz(以及 dx<0 / dy<0 / dz<0)
}
```

**关键**:不是所有 voxel 都更新,只更新**新进入的薄片**(N² 个 voxel)。这是 32 倍优化——32³ voxel 中只更新 32² 的薄片。

### 2.4 GPU 上的 toroidal texture

GPU texture 默认是 ClampToEdge——UV 超出 [0,1] 截断到边缘。Toroidal texture 需要 Repeat 模式——UV 绕回。但 wgpu/Vulkan 的 `Repeat` 是给"小纹理平铺"用的(如砖墙纹理重复),不是给"toroidal grid 滚动"用的——两者语义略不同。

**实际工业做法**:**手动 wrap UV**——在 shader 里用 `frac(uv * dim) / dim` 把 UV 限制在 [0,1],而 grid 的 `offset` 用 uniform 传给 shader,shader 里加 offset 再 wrap。这样 GPU texture 在物理上是普通的 ClampToEdge,shader 自己处理 wrap。

```wgsl
@group(0) var<uniform> grid_offset: vec3<i32>;
@group(0) var<uniform> grid_dim: i32;

fn world_to_uv(world_pos: vec3<f32>) -> vec3<f32> {
    let logical = vec3<i32>(world_pos / voxel_size) + grid_offset;
    // Wrap to [0, dim)
    let mem = ((logical % grid_dim) + grid_dim) % grid_dim;  // 处理负数
    return vec3<f32>(mem) / f32(grid_dim);
}

fn sample_voxel(world_pos: vec3<f32>) -> vec4<f32> {
    let uv = world_to_uv(world_pos);
    return textureSample(voxel_tex, sampler, uv);
}
```

`((x % dim) + dim) % dim` 是 GLSL 的"非负 mod"惯用法——WGSL 未来会有更好的 `mod_euclid`,但目前这样写。**注意 GPU 整数 mod 的精度**——某些 GPU 上 `i32 % i32` 慢,用位运算 `& (dim - 1)` 替代(dim 是 2 的幂时)。

### 2.5 Sparse backing storage:无限世界

voxel grid 是固定大小(如 32³),只覆盖玩家附近。但游戏世界是"无限"的——玩家可以走到任何地方。**怎么存"无限"世界**?用 **sparse backing storage**——世界分成 chunks(如 16³ voxel),每个 chunk 独立存储。玩家附近的 chunk 加载进 voxel grid,远处的 chunk 在 sparse storage(磁盘、网络、按需生成)。

**Chunk 加载策略**:
- 玩家进入新区域,需要的 chunk 流式加载(从磁盘或网络)
- 玩家离开的 chunk,evict 出 voxel grid,保留在 sparse storage
- 玩家回到老区域,从 sparse storage 重新加载

**Minecraft 用这套**——chunks 是 16×16×256,玩家附近 ~10×10 chunks 加载,远处 unload。**Casey 这天用类似的 chunk 概念**——voxel grid 是"hot"数据,chunk storage 是"warm/cold"数据。

这就是 **hot-warm-cold storage pattern**——hot 在最快的存储(GPU texture)、warm 在主存(chunk cache)、cold 在磁盘(world save)。**数据随访问模式在层级间流动**。Linux 内核的 page cache、CPU 的 L1/L2/L3 cache 都是同一抽象。

### GPU toroidal texture

OpenGL / Vulkan texture 默认是 clamp / repeat 模式。Repeat 模式正好是 toroidal:

```glsl
// Fragment shader 用 wrap UV
vec3 uvw = (world_pos - grid_origin) / (voxel_size * dim);
uvw = mod(uvw, 1.0);  // wrap to [0, 1)
vec4 voxel = texture(voxel_tex, uvw);
```

GPU 硬件自动 wrap,无性能损失。

GPU 端 scroll 时:fragment shader 的 grid_origin 改一下,voxel 数据本身不动(只用 wrap addressing 读)。

但 **新进入的 voxel 要写入 texture**——CPU/GPU 端用 compute shader 算新 voxel,写入 texture 对应位置。

struct Ring<T> {
    data: Vec<T>,

impl<T: Clone + Default> Ring<T> {
    fn new(size: usize) -> Self {
        Ring { data: vec![T::default(); size], offset: 0 }

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:toroidal buffer 的 O(1) scroll 怎么实现?为什么不用 copy?

**参考解答**:`offset` 字段记录"逻辑原点对应的内存索引"。Scroll 时只更新 `offset`,不动 data。访问 voxel 时用 `(logical_idx + offset) % dim` 算内存索引。这样 scroll 几 ns(更新一个 int),没有 N³ copy(几十 μs)。代价:访问多一次模运算,但 modulo 在现代 CPU 几 ns,可忽略。

### Lv2 · 动手实践

**题**:实现 toroidal 1D buffer,验证 scroll。

要求:
- 长度 8 的 buffer,内容 [0, 1, 2, 3, 4, 5, 6, 7]
- offset = 0,逻辑上看到 [0, 1, ..., 7]
- scroll +2,逻辑上看到 [2, 3, 4, 5, 6, 7, ?, ?](最后两个要初始化)
- 验证逻辑索引 → 内存索引的映射

**参考解答**:

```rust
struct Toroidal1D {
    data: Vec<i32>,
    offset: usize,
}

impl Toroidal1D {
    fn new(data: Vec<i32>) -> Self {
        Toroidal1D { data, offset: 0 }
    }

    fn logical_to_memory(&self, logical_idx: usize) -> usize {
        (logical_idx + self.offset) % self.data.len()
    }

    fn get_logical(&self, logical_idx: usize) -> i32 {
        self.data[self.logical_to_memory(logical_idx)]
    }

    fn set_logical(&mut self, logical_idx: usize, value: i32) {
        let m = self.logical_to_memory(logical_idx);
        self.data[m] = value;
    }

    fn scroll(&mut self, delta: usize) {
        self.offset = (self.offset + delta) % self.data.len();
    }

    fn len(&self) -> usize { self.data.len() }
}

fn main() {
    let mut buf = Toroidal1D::new(vec![0, 1, 2, 3, 4, 5, 6, 7]);
    println!("Initial:");
    for i in 0..buf.len() {
        print!("{} ", buf.get_logical(i));
    }
    println!();

    // Scroll +2
    buf.scroll(2);
    println!("\nAfter scroll +2:");
    for i in 0..buf.len() {
        print!("{} ", buf.get_logical(i));
    }
    println!();
    // 期望:[2, 3, 4, 5, 6, 7, 5, 6]
    // 因为内存没变,只是 offset 变了
    // 逻辑 [0..6] = [2, 3, 4, 5, 6, 7]
    // 逻辑 [6, 7] = 内存 [0, 1] = [0, 1](要初始化为新数据)

    // 初始化新位置
    buf.set_logical(6, 100);
    buf.set_logical(7, 101);
    println!("\nAfter initialization:");
    for i in 0..buf.len() {
        print!("{} ", buf.get_logical(i));
    }
    println!();
    // 期望:[2, 3, 4, 5, 6, 7, 100, 101]
}
```

## 8 · Rust / Arch 落地代码

完整 3D toroidal voxel grid:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, Default, Debug)]
struct Voxel {
    light: V3,
    occupied: bool,
}

struct ToroidalVoxelGrid {
    data: Vec<Voxel>,
    dim: usize,
    voxel_size: f32,
    offset: [i64; 3],
    world_center: V3,
}

impl ToroidalVoxelGrid {
    fn new(dim: usize, voxel_size: f32) -> Self {
        ToroidalVoxelGrid {
            data: vec![Voxel::default(); dim*dim*dim],
            dim, voxel_size,
            offset: [0; 3],
            world_center: [0.0; 3],
        }
    }

    fn logical_to_memory(&self, li: i64, lj: i64, lk: i64) -> [usize; 3] {
        let dim = self.dim as i64;
        let mi = ((li + self.offset[0]).rem_euclid(dim)) as usize;
        let mj = ((lj + self.offset[1]).rem_euclid(dim)) as usize;
        let mk = ((lk + self.offset[2]).rem_euclid(dim)) as usize;
        [mi, mj, mk]
    }

    fn mem_idx(&self, mi: usize, mj: usize, mk: usize) -> usize {
        (mk * self.dim + mj) * self.dim + mi
    }

    fn get_logical(&self, li: i64, lj: i64, lk: i64) -> Voxel {
        let [mi, mj, mk] = self.logical_to_memory(li, lj, lk);
        self.data[self.mem_idx(mi, mj, mk)]
    }

    fn set_logical(&mut self, li: i64, lj: i64, lk: i64, v: Voxel) {
        let [mi, mj, mk] = self.logical_to_memory(li, lj, lk);
        let idx = self.mem_idx(mi, mj, mk);
        self.data[idx] = v;
    }

    fn scroll_by(&mut self, dx: i64, dy: i64, dz: i64) {
        self.offset[0] = (self.offset[0] + dx).rem_euclid(self.dim as i64);
        self.offset[1] = (self.offset[1] + dy).rem_euclid(self.dim as i64);
        self.offset[2] = (self.offset[2] + dz).rem_euclid(self.dim as i64);

        self.world_center[0] += dx as f32 * self.voxel_size;
        self.world_center[1] += dy as f32 * self.voxel_size;
        self.world_center[2] += dz as f32 * self.voxel_size;
    }

    // World coord → logical index(范围 [-dim/2, dim/2])
    fn world_to_logical(&self, world: V3) -> [i64; 3] {
        let half = (self.dim as f32 * self.voxel_size) * 0.5;
        let li = ((world[0] - self.world_center[0] + half) / self.voxel_size) as i64 - self.dim as i64 / 2;
        let lj = ((world[1] - self.world_center[1] + half) / self.voxel_size) as i64 - self.dim as i64 / 2;
        let lk = ((world[2] - self.world_center[2] + half) / self.voxel_size) as i64 - self.dim as i64 / 2;
        [li, lj, lk]
    }
}

// 模拟 sparse storage(外部世界)
fn external_world_sample(world: V3) -> Voxel {
    // 用 world 坐标作为 hash,生成 "稳定" voxel 数据
    let i = world[0] as i64;
    let j = world[1] as i64;
    let k = world[2] as i64;
    let light_val = ((i + j + k).abs() % 10) as f32 * 0.1;
    Voxel {
        light: [light_val; 3],
        occupied: (i + j + k) % 5 == 0,
    }
}

fn scroll_and_update(
    grid: &mut ToroidalVoxelGrid,
    dx: i64, dy: i64, dz: i64,
) {
    let dim = grid.dim as i64;
    let half = dim / 2;

    // 找新进入的 voxel 范围
    // 简化:dx > 0 时,+x 边缘进入 [half-dx, half) 这段
    if dx != 0 {
        let sign = if dx > 0 { 1 } else { -1 };
        let abs_dx = dx.abs();
        let edge_start = if sign > 0 { half - abs_dx } else { -half };
        for _ in 0..abs_dx {
            for k in -half..half {
                for j in -half..half {
                    let i = edge_start;
                    let world = [
                        grid.world_center[0] + i as f32 * grid.voxel_size,
                        grid.world_center[1] + j as f32 * grid.voxel_size,
                        grid.world_center[2] + k as f32 * grid.voxel_size,
                    ];
                    let v = external_world_sample(world);
                    grid.set_logical(i, j, k, v);
                }
            }
        }
    }
    // 类似 dy, dz(略)

    grid.scroll_by(dx, dy, dz);
}

fn main() {
    let mut grid = ToroidalVoxelGrid::new(8, 1.0);

    // 初始化:填充 voxel
    for k in -4..4 {
        for j in -4..4 {
            for i in -4..4 {
                let world = [i as f32, j as f32, k as f32];
                grid.set_logical(i, j, k, external_world_sample(world));
            }
        }
    }

    println!("Initial state:");
    println!("  Offset: {:?}", grid.offset);
    println!("  World center: {:?}", grid.world_center);
    println!("  Voxel at logical (0,0,0): {:?}", grid.get_logical(0, 0, 0));
    println!("  Voxel at logical (3,0,0): {:?}", grid.get_logical(3, 0, 0));

    // Scroll +2 along x
    println!("\nScrolling +2 along x...");
    scroll_and_update(&mut grid, 2, 0, 0);

    println!("After scroll:");
    println!("  Offset: {:?}", grid.offset);
    println!("  World center: {:?}", grid.world_center);
    println!("  Voxel at logical (0,0,0): {:?}", grid.get_logical(0, 0, 0));
    // 应该是新的 voxel(world_center 移动后,(0,0,0) 对应不同 world)

    // Scroll again
    println!("\nScrolling -3 along x...");
    scroll_and_update(&mut grid, -3, 0, 0);
    println!("  Offset: {:?}", grid.offset);
    println!("  World center: {:?}", grid.world_center);

    // 验证 toroidal wrapping
    println!("\nMemory layout verification:");
    for li in -4..4 {
        let [mi, _, _] = grid.logical_to_memory(li, 0, 0);
        println!("  logical {} -> memory {}", li, mi);
    }
}

GPU 实现(WGSL):

```wgsl
// Fragment shader with toroidal addressing
@group(0) @binding(0) var voxel_tex: texture_3d<f32>;
@group(0) @binding(1) var tex_sampler: sampler;
@group(0) @binding(2) var<uniform> grid_origin: vec3<f32>;
@group(0) @binding(3) var<uniform> grid_dim: u32;
@group(0) @binding(4) var<uniform> voxel_size: f32;

@fragment
fn fs_main(@location(0) world_pos: vec3<f32>) -> @location(0) vec4<f32> {
    // World → logical [0, 1)
    let half = f32(grid_dim) * voxel_size * 0.5;
    var uvw = (world_pos - grid_origin + vec3<f32>(half)) / (voxel_size * f32(grid_dim));

    // Wrap to [0, 1) - 硬件 repeat 模式自动处理
    // 但用 GL_REPEAT sampler,不用 mod

    let voxel = textureSample(voxel_tex, tex_sampler, uvw);
    return vec4<f32>(voxel.rgb, 1.0);
}
