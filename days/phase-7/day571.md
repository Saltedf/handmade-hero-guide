# Day 571 · 加光层次结构

> 场景里有几百个动态光源时,fragment shader 遍历所有光源(每个 +attenuation)慢——O(N) per pixel。Day 571 Casey 加 **light hierarchy(光层次结构)**——把光源按空间分组,fragment shader 只遍历影响当前像素的少数光源。

## 0 · 为什么要有这一天

回顾 Day 565 多光源:fragment shader 遍历所有光源,每个算 `falloff * color`,加起来。1000 光源 = 1000 次 / 像素 = 2M 像素 * 1000 = 20 亿次计算 / 帧。GPU 也吃不消。

但**大部分光源对大部分像素无影响**——100 米外的火把不影响我眼前的墙。我们只需要遍历"附近"光源。

**Light hierarchy** 思路:把光源按 3D 位置组织成树(BVH / octree)。fragment shader 拿到像素位置,query 树找"附近光源",只遍历这些。

```
场景:1000 光源
Fragment shader:1 像素在 (5, 5, 5)
查询:只影响 (5, 5, 5) 半径 10 米内的光源 → 找到 3 个
遍历:3 次(而非 1000)
```

加速 ~300 倍。

Day 567 用 cascade voxel grid 实现 multi-resolution,这天用 BVH 实现光层次结构。两者互补——voxel grid 处理"光照场",BVH 处理"光源集合"。

完成这一天之后,你具备:

## 1 · Casey 今天做了什么

Casey 的步骤:

第一步,他实现 BVH——把所有光源按 AABB(轴对齐包围盒)组织成树。叶子节点是单个光源,中间节点是子节点的 AABB union。

第二步,fragment shader query BVH:输入像素位置,递归下行 BVH,只访问与"该像素的有效范围"相交的节点。

第三步,只对叶子节点(光源)算 falloff,累加。

视频里他展示:1000 光源场景,fragment shader 时间从 30ms → 0.5ms,60 倍加速。

## 2 · 心智模型

### 类比:邮递员送信

邮递员有 1000 封信要送,送到城市的各家。

**朴素**:每封信,跑遍全城找收件人。1000 封 * 100 万户 = 10 亿次访问。

**层次**:城市分成区(区码),区分成街,街分成户。邮递员先按区码分信,再按街分,最后送到户。每封信只走"区→街→户",3 次访问。

Light BVH 也是——光源按空间分组成"区",query 时只走"自己所在区的光源",不访问其他区。

### 严谨展开:BVH 结构

```rust
struct BvhNode {
    aabb_min: V3,
    aabb_max: V3,
    left: Option<usize>,    // 内部节点有子节点
    right: Option<usize>,
    light_id: Option<usize>,  // 叶子节点有光源
}

struct Bvh {
    nodes: Vec<BvhNode>,
}

impl Bvh {
    fn build(lights: &[Light]) -> Self {
        if lights.is_empty() {
            return Bvh { nodes: vec![] };
        }

        // 递归 build
        let mut nodes = Vec::new();
        let root = build_node(lights, &mut nodes);
        let _ = root;
        Bvh { nodes }
    }
}

fn build_node(lights: &[Light], nodes: &mut Vec<BvhNode>) -> usize {
    // 算 AABB
    let mut aabb_min = V3::splat(f32::INFINITY);
    let mut aabb_max = V3::splat(f32::NEG_INFINITY);
    for l in lights {
        let r = l.radius;
        aabb_min = aabb_min.min(l.pos - r);
        aabb_max = aabb_max.max(l.pos + r);
    }

    let node_idx = nodes.len();
    nodes.push(BvhNode {
        aabb_min, aabb_max,
        left: None, right: None, light_id: None,
    });

    if lights.len() == 1 {
        // 叶子节点
        nodes[node_idx].light_id = Some(0);  // 简化:存 light_id
        return node_idx;
    }

    // 选最长轴,排序
    let extent = aabb_max - aabb_min;
    let axis = if extent.x > extent.y && extent.x > extent.z { 0 }
               else if extent.y > extent.z { 1 } else { 2 };

    let mut sorted = lights.to_vec();
    sorted.sort_by(|a, b| {
        a.pos[axis].partial_cmp(&b.pos[axis]).unwrap()
    });

    let mid = sorted.len() / 2;
    let left_lights = &sorted[..mid];
    let right_lights = &sorted[mid..];

    let left_idx = build_node(left_lights, nodes);
    let right_idx = build_node(right_lights, nodes);

    nodes[node_idx].left = Some(left_idx);
    nodes[node_idx].right = Some(right_idx);

    node_idx
}
```

### Query BVH

```rust
impl Bvh {
    fn query(&self, pos: V3, radius: f32, lights: &[Light], result: &mut Vec<usize>) {
        if self.nodes.is_empty() { return; }
        self.query_node(0, pos, radius, lights, result);
    }

    fn query_node(
        &self, node_idx: usize, pos: V3, radius: f32,
        lights: &[Light], result: &mut Vec<usize>,
    ) {
        let node = &self.nodes[node_idx];

        // AABB 相交测试
        let closest = pos.max(node.aabb_min).min(node.aabb_max);
        let dist2 = (pos - closest).length_squared();
        if dist2 > radius * radius {
            return;  // 不相交,cull
        }

        if let Some(lid) = node.light_id {
            result.push(lid);
            return;
        }

        if let Some(left) = node.left {
            self.query_node(left, pos, radius, lights, result);
        }
        if let Some(right) = node.right {
            self.query_node(right, pos, radius, lights, result);
        }
    }
}
```

### Cluster forward 的替代

工业更常用 **Cluster forward**:把屏幕 + 深度切成 3D cluster(2D tile + depth slice),每 cluster 算"影响它的光源列表"。fragment shader 查 cluster 的 light list。

Cluster forward 比 BVH 简单,且 GPU 友好。但 BVH 更通用(任意空间 query)。Casey 用 BVH 是教学考虑——展示 hierarchy 思想。

### 3.1 · 游戏编程视角

Light culling 的工业做法:

- **Tiled forward**(2010 Killzone):屏幕分 2D tile,每 tile 算光源列表
- **Cluster forward**(2015 Doom):屏幕 + 深度的 3D cluster

工业游戏常用 cluster forward,因为简单高效。Casey 的 BVH 是另一条路,展示不同思路。

Light culling 也用 BVH 思想——只是 query 是"球 vs AABB"而非"ray vs triangle"。

### Lv1 · 概念辨析

**题**:BVH query 是 O(log N),为什么 fragment shader 还要遍历光源?不应该是 O(1) 吗?

**参考解答**:BVH query 是 O(log N) 找到"附近光源集合"——query 时间取决于 BVH 深度(log N)。但**遍历**这个集合仍是 O(K),K 是集合大小。如果每像素附近光源平均 K=10 个,遍历 10 次。比 O(N=1000) 快 100 倍,但不是 O(1)。要做到真正 O(1),要 precompute 每像素的光源列表(类似 cluster forward),但那需要更多内存。BVH 是 memory-light + query-fast 的平衡。

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy)]
struct Light {
    id: usize,
    pos: V3,
    radius: f32,
    color: V3,
}

struct BvhNode {
    aabb_min: V3,
    aabb_max: V3,
    left: Option<usize>,
    right: Option<usize>,
    light_id: Option<usize>,
}

struct Bvh {
    nodes: Vec<BvhNode>,
}

impl Bvh {
    fn build(lights: &mut Vec<Light>) -> Self {
        let mut nodes = Vec::new();
        Self::build_node(lights, &mut nodes);
        Bvh { nodes }
    }

    fn build_node(lights: &mut Vec<Light>, nodes: &mut Vec<BvhNode>) -> usize {
        let mut aabb_min = [f32::INFINITY; 3];
        let mut aabb_max = [f32::NEG_INFINITY; 3];
        for l in lights.iter() {
            for c in 0..3 {
                aabb_min[c] = aabb_min[c].min(l.pos[c] - l.radius);
                aabb_max[c] = aabb_max[c].max(l.pos[c] + l.radius);
            }
        }

        let node_idx = nodes.len();
        nodes.push(BvhNode {
            aabb_min, aabb_max,
            left: None, right: None, light_id: None,
        });

        if lights.len() == 1 {
            nodes[node_idx].light_id = Some(lights[0].id);
            return node_idx;
        }

        // 找最长轴
        let extent = [
            aabb_max[0] - aabb_min[0],
            aabb_max[1] - aabb_min[1],
            aabb_max[2] - aabb_min[2],
        ];
        let axis = if extent[0] >= extent[1] && extent[0] >= extent[2] { 0 }
                   else if extent[1] >= extent[2] { 1 } else { 2 };

        lights.sort_by(|a, b| a.pos[axis].partial_cmp(&b.pos[axis]).unwrap());

        let mid = lights.len() / 2;
        let mut left = lights[..mid].to_vec();
        let mut right = lights[mid..].to_vec();

        let left_idx = Self::build_node(&mut left, nodes);
        let right_idx = Self::build_node(&mut right, nodes);

        nodes[node_idx].left = Some(left_idx);
        nodes[node_idx].right = Some(right_idx);

        node_idx
    }

    fn query(&self, pos: V3, radius: f32, result: &mut Vec<usize>) {
        if self.nodes.is_empty() { return; }
        self.query_node(0, pos, radius, result);
    }

    fn query_node(&self, idx: usize, pos: V3, radius: f32, result: &mut Vec<usize>) {
        let node = &self.nodes[idx];

        // AABB-sphere 相交
        let closest = [
            pos[0].max(node.aabb_min[0]).min(node.aabb_max[0]),
            pos[1].max(node.aabb_min[1]).min(node.aabb_max[1]),
            pos[2].max(node.aabb_min[2]).min(node.aabb_max[2]),
        ];
        let dx = pos[0] - closest[0];
        let dy = pos[1] - closest[1];
        let dz = pos[2] - closest[2];
        if dx*dx + dy*dy + dz*dz > radius * radius {
            return;  // 不相交
        }

        if let Some(lid) = node.light_id {
            result.push(lid);
            return;
        }
        if let Some(l) = node.left { self.query_node(l, pos, radius, result); }
        if let Some(r) = node.right { self.query_node(r, pos, radius, result); }
    }
}

fn main() {
    let mut lights = vec![
        Light { id: 0, pos: [0.0, 0.0, 0.0], radius: 2.0, color: [1.0; 3] },
        Light { id: 1, pos: [3.0, 0.0, 0.0], radius: 1.5, color: [1.0; 3] },
        Light { id: 2, pos: [10.0, 0.0, 0.0], radius: 3.0, color: [1.0; 3] },
        Light { id: 3, pos: [0.0, 5.0, 0.0], radius: 2.0, color: [1.0; 3] },
        Light { id: 4, pos: [0.0, 0.0, 8.0], radius: 1.0, color: [1.0; 3] },
        Light { id: 5, pos: [15.0, 15.0, 15.0], radius: 5.0, color: [1.0; 3] },
    ];

    let bvh = Bvh::build(&mut lights);

    // Query (1, 0, 0) 附近 5 米
    let mut result = Vec::new();
    bvh.query([1.0, 0.0, 0.0], 5.0, &mut result);
    println!("BVH query (1,0,0) r=5: light_ids = {:?}", result);

    // Brute force 对照
    let mut brute = Vec::new();
    for l in &lights {
        let dx = l.pos[0] - 1.0;
        let dy = l.pos[1] - 0.0;
        let dz = l.pos[2] - 0.0;
        if dx*dx + dy*dy + dz*dz <= 25.0 {
            brute.push(l.id);
        }
    }
    println!("Brute force: light_ids = {:?}", brute);

    // 两者应该相同(集合相同)
    let mut r_sorted = result.clone(); r_sorted.sort();
    let mut b_sorted = brute.clone(); b_sorted.sort();
    assert_eq!(r_sorted, b_sorted);
    println!("BVH 和 brute force 结果一致");
}
```

## 8 · Rust / Arch 落地代码

完整 light BVH + culling:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, Debug)]
struct Light {
    id: usize,
    pos: V3,
    radius: f32,
    color: V3,
}

#[derive(Clone, Debug)]
struct BvhNode {
    aabb_min: V3,
    aabb_max: V3,
    left: Option<usize>,
    right: Option<usize>,
    light_id: Option<usize>,
}

struct LightBvh {
    nodes: Vec<BvhNode>,
    lights: Vec<Light>,
}

impl LightBvh {
    fn build(mut lights: Vec<Light>) -> Self {
        let mut nodes = Vec::new();
        if !lights.is_empty() {
            Self::build_recursive(&mut lights, &mut nodes);
        }
        LightBvh { nodes, lights }
    }

    fn build_recursive(lights: &mut [Light], nodes: &mut Vec<BvhNode>) -> usize {
        let mut aabb_min = [f32::INFINITY; 3];
        let mut aabb_max = [f32::NEG_INFINITY; 3];
        for l in lights.iter() {
            for c in 0..3 {
                aabb_min[c] = aabb_min[c].min(l.pos[c] - l.radius);
                aabb_max[c] = aabb_max[c].max(l.pos[c] + l.radius);
            }
        }

        let node_idx = nodes.len();
        nodes.push(BvhNode {
            aabb_min, aabb_max,
            left: None, right: None, light_id: None,
        });

        if lights.len() <= 1 {
            if let Some(l) = lights.first() {
                nodes[node_idx].light_id = Some(l.id);
            }
            return node_idx;
        }

        let extent = [
            aabb_max[0] - aabb_min[0],
            aabb_max[1] - aabb_min[1],
            aabb_max[2] - aabb_min[2],
        ];
        let axis = if extent[0] >= extent[1] && extent[0] >= extent[2] { 0 }
                   else if extent[1] >= extent[2] { 1 } else { 2 };

        lights.sort_by(|a, b| a.pos[axis].partial_cmp(&b.pos[axis]).unwrap());

        let mid = lights.len() / 2;
        let (left_lights, right_lights) = lights.split_at_mut(mid);

        let left_idx = Self::build_recursive(left_lights, nodes);
        let right_idx = Self::build_recursive(right_lights, nodes);

        nodes[node_idx].left = Some(left_idx);
        nodes[node_idx].right = Some(right_idx);

        node_idx
    }

    fn query_near(&self, pos: V3, radius: f32) -> Vec<usize> {
        let mut result = Vec::new();
        if !self.nodes.is_empty() {
            self.query_recursive(0, pos, radius, &mut result);
        }
        result
    }

    fn query_recursive(&self, idx: usize, pos: V3, radius: f32, result: &mut Vec<usize>) {
        let node = &self.nodes[idx];

        let closest = [
            pos[0].max(node.aabb_min[0]).min(node.aabb_max[0]),
            pos[1].max(node.aabb_min[1]).min(node.aabb_max[1]),
            pos[2].max(node.aabb_min[2]).min(node.aabb_max[2]),
        ];
        let dx = pos[0] - closest[0];
        let dy = pos[1] - closest[1];
        let dz = pos[2] - closest[2];
        if dx*dx + dy*dy + dz*dz > radius * radius {
            return;
        }

        if let Some(lid) = node.light_id {
            // 进一步精确检查(光源的 radius)
            if let Some(light) = self.lights.iter().find(|l| l.id == lid) {
                let ldx = light.pos[0] - pos[0];
                let ldy = light.pos[1] - pos[1];
                let ldz = light.pos[2] - pos[2];
                let dist = (ldx*ldx + ldy*ldy + ldz*ldz).sqrt();
                if dist < radius + light.radius {
                    result.push(lid);
                }
            }
            return;
        }

        if let Some(l) = node.left { self.query_recursive(l, pos, radius, result); }
        if let Some(r) = node.right { self.query_recursive(r, pos, radius, result); }
    }

    fn get_light(&self, id: usize) -> Option<&Light> {
        self.lights.iter().find(|l| l.id == id)
    }
}

fn main() {
    // 模拟 100 个光源
    let mut seed = 42u32;
    let mut rng = || {
        seed ^= seed << 13;
        seed ^= seed >> 17;
        seed ^= seed << 5;
        seed
    };
    let lights: Vec<Light> = (0..100).map(|id| {
        let pos = [
            (rng() % 1000) as f32 / 10.0,
            (rng() % 1000) as f32 / 10.0,
            (rng() % 1000) as f32 / 10.0,
        ];
        Light {
            id,
            pos,
            radius: 1.0 + (rng() % 30) as f32 / 10.0,
            color: [1.0; 3],
        }
    }).collect();

    let bvh = LightBvh::build(lights.clone());

    // Query 几个点
    for query_pos in [[5.0, 5.0, 5.0], [50.0, 50.0, 50.0], [95.0, 95.0, 95.0]] {
        let nearby = bvh.query_near(query_pos, 20.0);

        // Brute force 对照
        let mut brute_count = 0;
        for l in &lights {
            let dx = l.pos[0] - query_pos[0];
            let dy = l.pos[1] - query_pos[1];
            let dz = l.pos[2] - query_pos[2];
            let d2 = dx*dx + dy*dy + dz*dz;
            if d2 < (20.0 + l.radius).powi(2) {
                brute_count += 1;
            }
        }

        println!("Query {:?} r=20: BVH found {}, brute force = {}",
            query_pos, nearby.len(), brute_count);
    }

    // 节点数
    println!("\nBVH 节点数: {} (lights = {})", bvh.nodes.len(), lights.len());
}
```

但 light BVH 不一定要 hardware ray tracing——可以用 compute shader 自己实现 BVH traversal:

```wgsl
@group(0) @binding(0) var<storage, read> nodes: array<BvhNode>;
@group(0) @binding(1) var<storage, read> lights: array<Light>;

fn traverse_bvh(pos: vec3<f32>, radius: f32) -> vec3<f32> {
    var stack: array<u32, 64>;
    var stack_ptr = 0;
    stack[stack_ptr] = 0u;  // root
    stack_ptr += 1;

    var total = vec3<f32>(0.0);

    while (stack_ptr > 0) {
        stack_ptr -= 1;
        let node_idx = stack[stack_ptr];
        let node = nodes[node_idx];

        if (!aabb_sphere_intersect(node.aabb_min, node.aabb_max, pos, radius)) {
            continue;
        }

        if (node.light_id >= 0) {
            let l = lights[node.light_id];
            let d = distance(l.pos, pos);
            if (d < radius + l.radius) {
                let falloff = 1.0 - d / l.radius;
                total += l.color * falloff;
            }
        } else {
            stack[stack_ptr] = node.left;
            stack_ptr += 1;
            stack[stack_ptr] = node.right;
            stack_ptr += 1;
        }
    }
    return total;
}
```

WGSL 用栈模拟递归(GPU shader 不能递归)。
