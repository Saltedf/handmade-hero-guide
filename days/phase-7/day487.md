# Day 487 · 3D 盒形命中测试

> Day 488 要做游戏内编辑器,编辑器需要"鼠标点中哪个 entity"。2D 命中测试是简单的矩形包含,3D 命中测试涉及射线-AABB 相交——更复杂。Day 487 先把这个数学基础打牢。

## 0 · 为什么要有这一天

编辑器核心交互:**鼠标点击屏幕 → 选中 3D 世界里的 entity**。这需要把"屏幕 2D 点击"翻译成"3D 世界射线",再检测这条射线和哪些 entity 的包围盒相交。

这个流程分三步:

第一,**屏幕坐标 → 世界射线**。鼠标点击位置 (screen_x, screen_y) 经过 view_proj 矩阵的逆变换,得到 3D 世界里的一条射线(起点 + 方向)。

第二,**射线 - AABB 相交测试**。每个 entity 有一个轴对齐包围盒(AABB,Axis-Aligned Bounding Box),检测射线是否穿过 AABB,以及穿过点(命中点)。

第三,**最近命中**。多个 entity 可能都被命中,选最近的(射线参数 t 最小的)。

这是所有 3D 编辑器的基础——Unity、Unreal、Blender 的点击选中都用这套算法。

完成这一天之后,你具备了:

- 屏幕坐标到世界射线的变换
- 射线-AABB 相交算法(Slab method)
- 3D 拾取(picking)的完整实现

## 2 · 心智模型

### 类比:激光笔照射物体

想象你站在房间中央,手持激光笔。激光从你的眼睛出发,经过屏幕上你点击的点,射向远方。激光击中的第一个物体就是你"选中"的物体。

Day 487 的射线测试完全对应:

- **眼睛位置** = 相机位置(射线起点)
- **激光方向** = 从眼睛穿过屏幕点击点(射线方向)
- **物体** = entity 的 AABB
- **第一个被击中** = 最近的 entity(选中)

### 屏幕 → 世界射线

鼠标点击屏幕位置 (sx, sy)(像素)。要变成 3D 世界射线:

第一步,**屏幕 → NDC**(Normalized Device Coordinates)。屏幕 (0, 0) 在左下或左上(看 API),NDC 是 [-1, 1] 范围:

```
ndc_x = (2 * sx / viewport_w) - 1
ndc_y = 1 - (2 * sy / viewport_h)   // y 翻转
```

注意 y 翻转——屏幕 y 通常朝下,NDC y 朝上。

第二步,**NDC → clip space**。NDC 是 2D,clip space 是 4D(vec4)。给 ndc 加 z=-1(near plane)和 w=1:

```
near_point_clip = (ndc_x, ndc_y, -1, 1)
far_point_clip  = (ndc_x, ndc_y,  1, 1)
```

第三步,**clip → world**。乘 view_proj 的逆矩阵:

```
near_point_world = view_proj_inv * near_point_clip
far_point_world  = view_proj_inv * far_point_clip
```

第四步,透视除法(w 除):

```
near_point_world /= near_point_world.w
far_point_world  /= far_point_world.w
```

第五步,**构造射线**:

```
ray_origin = near_point_world
ray_dir = normalize(far_point_world - near_point_world)
```

这就是射线。所有数学是图形学的标准推导,Casey 在 Day 487 实现。

### 射线-AABB 相交:Slab method

AABB 用 min/max 描述:

```
min = (xmin, ymin, zmin)
max = (xmax, ymax, zmax)
```

AABB 是 6 个平面(每轴一对)的交集。Slab method 的思想:**计算射线进/出每个轴 slab(板)的 t 值,取交集**。

对每轴 X:

```
t_x_min = (aabb.min.x - ray.origin.x) / ray.dir.x
t_x_max = (aabb.max.x - ray.origin.x) / ray.dir.x

if t_x_min > t_x_max: swap(t_x_min, t_x_max)
```

`t_x_min` 是射线进入 X-slab 的 t 值,`t_x_max` 是离开的 t 值。

同理算 Y、Z 的 t_min / t_max。

射线的"进入 AABB 时间" = max(t_x_min, t_y_min, t_z_min) ——所有 slab 都进入。
射线的"离开 AABB 时间" = min(t_x_max, t_y_max, t_z_max) ——任何 slab 离开。

如果"进入时间" < "离开时间" 且 "离开时间" > 0,射线穿过 AABB。

完整代码:

```rust
fn ray_aabb_intersect(origin: Vec3, dir: Vec3, aabb: AABB) -> Option<f32> {
    let mut t_min = f32::NEG_INFINITY;
    let mut t_max = f32::INFINITY;
    
    for axis in 0..3 {
        let o = origin[axis];
        let d = dir[axis];
        let min = aabb.min[axis];
        let max = aabb.max[axis];
        
        if d.abs() < 1e-6 {
            // 射线平行于这个轴 slab
            if o < min || o > max {
                // 但 origin 不在 slab 内,不相交
                return None;
            }
            // 否则这一轴不限制
        } else {
            let mut t1 = (min - o) / d;
            let mut t2 = (max - o) / d;
            if t1 > t2 { std::mem::swap(&mut t1, &mut t2); }
            
            t_min = t_min.max(t1);
            t_max = t_max.min(t2);
            
            if t_min > t_max {
                return None;
            }
        }
    }
    
    // t_min 是进入时间,t_max 是离开时间
    // 如果 t_min > 0,射线在 AABB 内开始(向外)
    // 如果 t_min < 0 < t_max,射线起点在 AABB 内
    // 如果 t_max < 0,AABB 在射线后方(不相交)
    
    let t = if t_min >= 0.0 { t_min } else { t_max };
    if t >= 0.0 {
        Some(t)
    } else {
        None
    }
}
```

时间复杂度 O(1)(常数个 if-else 和算术),极快。

### 多 entity 命中:最近 t

如果射线穿过多个 AABB,选 t 最小的——也就是射线先碰到的。

```rust
let mut closest: Option<(usize, f32)> = None;
for (i, e) in entities.iter().enumerate() {
    if let Some(t) = ray_aabb_intersect(origin, dir, e.aabb) {
        match closest {
            None => closest = Some((i, t)),
            Some((_, prev_t)) if t < prev_t => closest = Some((i, t)),
            _ => {}
        }
    }
}
```

如果 entity 多(几千个),全遍历慢。优化用 BVH(Bounding Volume Hierarchy)——层次包围盒,把 entity 分组,O(log N) 查询。Casey 在 HH 里 entity 数少,全遍历够。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

3D picking 是游戏开发的标准工具:

- **编辑器**:选中 entity 进行编辑
- **RTS 游戏**:鼠标点选单位
- **MMO**:点击 NPC 触发对话
- **VR/AR**:手势/视线选物体

工业级 picking 有几种实现:

- **Ray-AABB**(Casey 的方法):简单快,AABB 近似
- **Ray-mesh**(精确):射线和三角形求交,精确但慢
- **GPU picking**:把 entity id 渲染到 offscreen buffer,鼠标位置读像素得到 id。最快,但需要 GPU 资源
- **Color picking**:每 entity 渲染成独特颜色,读屏幕像素得颜色 → id。简单,但每帧渲染开销

Casey 选 Ray-AABB,简单且足够。工业游戏可能用 GPU picking 处理大量 entity。

游戏开发里 AABB 的延伸:

- **OBB**(Oriented Bounding Box):有方向的包围盒,比 AABB 紧但相交测试慢
- **Sphere**:球包围盒,最快但松
- **Capsule**:胶囊(角色常用),适合碰撞
- **Convex hull**:凸包,最紧但最复杂

不同场景用不同包围盒。Casey 用 AABB 因为 entity 是 sprite(本身就是矩形)。

### 3.2 · 🎨 图形学视角

射线-AABB 的 Slab method 是图形学的经典算法,在 ray tracer 里到处用。它的优雅在于**用 1D 区间交集表达 3D 相交**——把复杂的 3D 几何简化为 3 个独立的 1D 问题。

工业级 ray tracer(embree、optix、mitsuba)的 AABB 测试比 Slab method 更优化:

- **SIMD**:同时处理 4 或 8 条射线
- **Early exit**:t_min > t_max 时立即返回
- **Branchless**:用位运算替代 if

Casey 的简单版本 O(1),够 HH 用。

图形学还有几个相关概念:

- **BVH(Bounding Volume Hierarchy)**:层次 AABB,加速多 entity 场景的 ray cast
- **kd-tree**:另一种空间分割,ray cast 也快
- **Octree**:八叉树,3D 空间分割

### 3.3 · 🐧 Linux 系统编程视角

Linux 上的"hit testing"对应在几个地方。

**X11 / Wayland input**:鼠标事件经过 hit testing 决定哪个窗口接收。compositor 维护窗口的 z-order,鼠标位置 → 自顶向下遍历 → 第一个包含鼠标位置的窗口。

### 3.4 · 🦀 Rust 生态视角

Rust 里 ray-AABB 有几个 crate:`accel`(ray tracer 库)、`bv`(bounding volume)、`nalgebra`(数学库)。

Idiomatic Rust 实现:

```rust
use nalgebra::{Vector3, Matrix4, Point3};

#[derive(Copy, Clone, Debug)]
struct AABB {
    min: Point3<f32>,
    max: Point3<f32>,
}

impl AABB {
    fn intersect(&self, origin: Point3<f32>, dir: Vector3<f32>) -> Option<f32> {
        let mut t_min = f32::NEG_INFINITY;
        let mut t_max = f32::INFINITY;
        
        for i in 0..3 {
            let o = origin[i];
            let d = dir[i];
            let min = self.min[i];
            let max = self.max[i];
            
            if d.abs() < 1e-6 {
                if o < min || o > max {
                    return None;
                }
            } else {
                let (mut t1, mut t2) = ((min - o) / d, (max - o) / d);
                if t1 > t2 { std::mem::swap(&mut t1, &mut t2); }
                
                t_min = t_min.max(t1);
                t_max = t_max.min(t2);
                
                if t_min > t_max {
                    return None;
                }
            }
        }
        
        let t = if t_min >= 0.0 { t_min } else { t_max };
        (t >= 0.0).then_some(t)
    }
}
```

注意 `(t >= 0.0).then_some(t)` —— Rust 的 `bool::then_some` 返回 `Option`,比 `if ... Some else None` 简洁。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 Casey 用 Slab method 而不是逐三角形测试?

**参考解答**:三个理由:

第一,**速度**。Slab method 是 O(1)(3 个轴的几个算术)。逐三角形是 O(N)(N 是三角形数)。sprite 64×64 大概 2 个三角形(quad),100 个 entity 就是 200 三角形,比 100 个 AABB 慢。

第二,**精度**。对于编辑器,精度不重要——选中 AABB 内的任何点都算选中。逐三角形精度高但没必要。

第三,**简化**。AABB 是 min/max,容易算容易存。三角形要 3 个顶点,内存大。

逐三角形适合 ray tracer(图像质量),不适合编辑器(响应速度)。

#[derive(Copy, Clone, Debug)]
struct AABB {
    min: Vec3,
    max: Vec3,
}

impl AABB {
    fn from_center_size(center: Vec3, size: Vec3) -> Self {
        let half = Vec3::new(size.x * 0.5, size.y * 0.5, size.z * 0.5);
        Self {
            min: Vec3::new(center.x - half.x, center.y - half.y, center.z - half.z),
            max: Vec3::new(center.x + half.x, center.y + half.y, center.z + half.z),
        }
    }
    
    fn ray_intersect(&self, origin: Vec3, dir: Vec3) -> Option<f32> {
        let mut t_min = f32::NEG_INFINITY;
        let mut t_max = f32::INFINITY;
        
        for (o, d, min, max) in [
            (origin.x, dir.x, self.min.x, self.max.x),
            (origin.y, dir.y, self.min.y, self.max.y),
            (origin.z, dir.z, self.min.z, self.max.z),
        ] {
            if d.abs() < 1e-6 {
                if o < min || o > max {
                    return None;
                }
            } else {
                let (mut t1, mut t2) = ((min - o) / d, (max - o) / d);
                if t1 > t2 { std::mem::swap(&mut t1, &mut t2); }
                
                t_min = t_min.max(t1);
                t_max = t_max.min(t2);
                
                if t_min > t_max {
                    return None;
                }
            }
        }
        
        let t = if t_min >= 0.0 { t_min } else { t_max };
        (t >= 0.0).then_some(t)
    }
}

struct Camera {
    view_proj: Mat4,
    view_proj_inv: Mat4,
    viewport_w: f32,
    viewport_h: f32,
}

impl Camera {
    fn screen_to_ray(&self, screen_x: f32, screen_y: f32) -> (Vec3, Vec3) {
        // 1. 屏幕 → NDC
        let ndc_x = (2.0 * screen_x / self.viewport_w) - 1.0;
        let ndc_y = 1.0 - (2.0 * screen_y / self.viewport_h);   // y 翻转
        
        // 2. NDC → clip space(near 和 far 两个点)
        let near_clip = [ndc_x, ndc_y, -1.0, 1.0];
        let far_clip  = [ndc_x, ndc_y,  1.0, 1.0];
        
        // 3. clip → world(乘 view_proj_inv)
        let near_world = self.transform_point(&near_clip);
        let far_world  = self.transform_point(&far_clip);
        
        // 4. 构造射线
        let origin = near_world;
        let dir = far_world.sub(near_world).normalize();
        
        (origin, dir)
    }
    
    fn transform_point(&self, clip: &[f32; 4]) -> Vec3 {
        let m = &self.view_proj_inv;
        let mut out = [0f32; 4];
        for i in 0..4 {
            for j in 0..4 {
                out[i] += m[i][j] * clip[j];
            }
        }
        // 透视除法
        Vec3::new(out[0] / out[3], out[1] / out[3], out[2] / out[3])
    }
}

fn main() {
    // 简化:用单位 view_proj(假装 inverse 也是单位)
    // 实际工程需要正确的 inverse
    let cam = Camera {
        view_proj: mat4_identity(),
        view_proj_inv: mat4_identity(),
        viewport_w: 800.0,
        viewport_h: 600.0,
    };
    
    // 测试:屏幕中央点击
    let (origin, dir) = cam.screen_to_ray(400.0, 300.0);
    println!("Click at screen (400, 300) (中央):");
    println!("  ray_origin = ({}, {}, {})", origin.x, origin.y, origin.z);
    println!("  ray_dir    = ({}, {}, {})", dir.x, dir.y, dir.z);
    
    // 应该:ndc = (0, 0),near = (0, 0, -1),far = (0, 0, 1)
    // 射线方向 = (0, 0, 1) - (0, 0, -1) = (0, 0, 2),normalize → (0, 0, 1)
    // 但 OpenGL 相机看 -Z,所以反方向是 -Z(往屏幕里看)
    // 这里我们的"forward"是 +Z(因为 view_proj 是单位),所以射线 +Z
    
    // 测试 ray-AABB
    println!();
    println!("=== Ray-AABB 测试 ===");
    
    let aabb = AABB::from_center_size(
        Vec3::new(0.0, 0.0, 50.0),    // 在射线前方 50 单位
        Vec3::new(10.0, 10.0, 10.0),
    );
    
    let t = aabb.ray_intersect(origin, dir);
    println!("AABB at z=50, ray cast: t = {:?}", t);
    // 应该 t ≈ 45(z=50 进入,z=50+5=55 出,中心是 50)
    
    // 测试不相交
    let miss_aabb = AABB::from_center_size(
        Vec3::new(100.0, 100.0, 50.0),   // 远离射线
        Vec3::new(10.0, 10.0, 10.0),
    );
    let t_miss = miss_aabb.ray_intersect(origin, dir);
    println!("AABB at (100,100,50), ray cast: t = {:?}", t_miss);
    // 应该 None
    
    // 多 AABB 命中,选最近
    println!();
    println!("=== 最近 AABB 测试 ===");
    let aabbs = vec![
        AABB::from_center_size(Vec3::new(0.0, 0.0, 100.0), Vec3::new(10.0, 10.0, 10.0)),
        AABB::from_center_size(Vec3::new(0.0, 0.0, 50.0),  Vec3::new(10.0, 10.0, 10.0)),
        AABB::from_center_size(Vec3::new(0.0, 0.0, 200.0), Vec3::new(10.0, 10.0, 10.0)),
    ];
    
    let mut closest: Option<(usize, f32)> = None;
    for (i, aabb) in aabbs.iter().enumerate() {
        if let Some(t) = aabb.ray_intersect(origin, dir) {
            println!("  AABB[{}] hit at t={}", i, t);
            match closest {
                None => closest = Some((i, t)),
                Some((_, prev_t)) if t < prev_t => closest = Some((i, t)),
                _ => {}
            }
        }
    }
    
    println!("Closest: {:?}", closest);
    // 应该是 (1, ...),因为 AABB[1] 在 z=50 最近
}

// ========================================
// 数学库(简化)
// ========================================

#[derive(Copy, Clone, Debug)]
struct Vec3 { x: f32, y: f32, z: f32 }

impl Vec3 {
    const fn new(x: f32, y: f32, z: f32) -> Self { Self { x, y, z } }
    fn sub(self, o: Self) -> Self { Self::new(self.x - o.x, self.y - o.y, self.z - o.z) }
    fn dot(self, o: Self) -> f32 { self.x*o.x + self.y*o.y + self.z*o.z }
    fn length(self) -> f32 { self.dot(self).sqrt() }
    fn normalize(self) -> Self {
        let l = self.length();
        if l > 1e-6 { Self::new(self.x/l, self.y/l, self.z/l) } else { Self::new(0.0, 0.0, 0.0) }
    }
}

type Mat4 = [[f32; 4]; 4];

// ========================================
// AABB 和 ray 相交
// ========================================

#[derive(Copy, Clone, Debug)]
struct AABB {
    min: Vec3,
    max: Vec3,
}

impl AABB {
    fn from_center_size(center: Vec3, size: Vec3) -> Self {
        Self {
            min: Vec3::new(center.x - size.x*0.5, center.y - size.y*0.5, center.z - size.z*0.5),
            max: Vec3::new(center.x + size.x*0.5, center.y + size.y*0.5, center.z + size.z*0.5),
        }
    }
    
    fn ray_intersect(&self, origin: Vec3, dir: Vec3) -> Option<f32> {
        let mut t_min = f32::NEG_INFINITY;
        let mut t_max = f32::INFINITY;
        
        let axes = [
            (origin.x, dir.x, self.min.x, self.max.x),
            (origin.y, dir.y, self.min.y, self.max.y),
            (origin.z, dir.z, self.min.z, self.max.z),
        ];
        
        for (o, d, min, max) in axes {
            if d.abs() < 1e-6 {
                if o < min || o > max { return None; }
            } else {
                let (mut t1, mut t2) = ((min - o) / d, (max - o) / d);
                if t1 > t2 { std::mem::swap(&mut t1, &mut t2); }
                t_min = t_min.max(t1);
                t_max = t_max.min(t2);
                if t_min > t_max { return None; }
            }
        }
        
        let t = if t_min >= 0.0 { t_min } else { t_max };
        (t >= 0.0).then_some(t)
    }
}

// ========================================
// Entity
// ========================================

struct Entity {
    id: u32,
    world_pos: Vec3,
    aabb: AABB,
    name: String,
}

// ========================================
// Hit tester
// ========================================

struct HitTester {
    camera_pos: Vec3,
}

impl HitTester {
    fn new(cam: Vec3) -> Self { Self { camera_pos: cam } }
    
    /// 简化版射线生成:从相机指向世界某点
    fn make_ray_to(&self, target: Vec3) -> (Vec3, Vec3) {
        let dir = target.sub(self.camera_pos).normalize();
        (self.camera_pos, dir)
    }
    
    fn hit_test(&self, target: Vec3, entities: &[Entity]) -> Option<u32> {
        let (origin, dir) = self.make_ray_to(target);
        
        let mut closest: Option<(u32, f32)> = None;
        for e in entities {
            if let Some(t) = e.aabb.ray_intersect(origin, dir) {
                match closest {
                    None => closest = Some((e.id, t)),
                    Some((_, prev_t)) if t < prev_t => closest = Some((e.id, t)),
                    _ => {}
                }
            }
        }
        closest.map(|(id, _)| id)
    }
}

// ========================================
// 演示
// ========================================

fn main() {
    let camera = Vec3::new(0.0, 0.0, 100.0);  // 相机在 +Z 100
    
    let entities = vec![
        Entity {
            id: 1,
            world_pos: Vec3::new(0.0, 0.0, 0.0),
            aabb: AABB::from_center_size(Vec3::new(0.0, 0.0, 0.0), Vec3::new(20.0, 20.0, 20.0)),
            name: "hero".to_string(),
        },
        Entity {
            id: 2,
            world_pos: Vec3::new(50.0, 0.0, 0.0),
            aabb: AABB::from_center_size(Vec3::new(50.0, 0.0, 0.0), Vec3::new(15.0, 15.0, 15.0)),
            name: "goblin".to_string(),
        },
        Entity {
            id: 3,
            world_pos: Vec3::new(0.0, 50.0, 50.0),
            aabb: AABB::from_center_size(Vec3::new(0.0, 50.0, 50.0), Vec3::new(10.0, 10.0, 10.0)),
            name: "chest".to_string(),
        },

            name: "far_object".to_string(),
        },
    ];
    
    println!("=== Hit Test 演示 ===");
    println!("Camera at: {:?}", (camera.x, camera.y, camera.z));

    for e in &entities {
        println!("  [{}] {} at {:?}, size {:?}-{:?}",

    let tester = HitTester::new(camera);

                 (target.x, target.y, target.z), desc, hit_name);
    }
    
    // 测试 closest hit
    println!();
    println!("=== 最近命中 ===");
    // 假装两个 entity 都在射线方向上(在 z=0 和 z=50)
    let entities_overlapping = vec![
        Entity {
            id: 10,
