# Day 504 · 探索相机插值方案

> Day 503 用 exponential decay 做相机缓动。Day 504 探索其他方案:spring(弹簧)、critical damping(临界阻尼)、PID 控制、spline 插值。比较各方案的视觉效果和适用场景。

## 1 · Casey 今天做了什么

Casey 这一天做的是"探索"——不直接选方案,而是**实现多种方案,比较利弊**。具体 7 步。

**第一步,实现 spring 物理**。Hooke's law(胡克定律):`F = -k*x - c*v`(弹力 + 阻尼)。`k` 是 spring constant(刚度),`c` 是 damping coefficient(阻尼系数),`x` 是位移,`v` 是速度。

```rust
fn update_spring(pos: &mut f32, vel: &mut f32, target: f32, k: f32, c: f32, dt: f32) {
    let force = -k * (*pos - target) - c * *vel;
    let accel = force;    // 假设 mass = 1
    *vel += accel * dt;
    *pos += *vel * dt;
}
```

**第二步,做 spring 的数值积分**。Casey 用 semi-implicit Euler(半隐式 Euler):

```rust
*v += accel * dt;     // 先更新速度
*pos += *v * dt;      // 再用新速度更新位置
```

为什么不用显式 Euler(先 pos 再 vel)?显式 Euler 在弹簧系统**不稳定**——能量数值增加,导致 spring 越振越大,爆炸。Semi-implicit 是 symplectic(辛)积分器,保守能量,稳定。

**第三步,跑 demo,看 spring**。Casey 跑 demo,k = 100,c = 5(underdamped),从 pos=0 到 target=100。看到相机快速冲向 100,**过冲到 ~115**,然后回弹,**低于 100 到 ~90**,振动几次后稳定在 100。这种"过冲"是 spring 的"生动感"。

**第四步,发现 Euler 不稳定**。Casey 试了大 dt(1/30 而不是 1/60),spring **真的爆炸**——位置无限增长,游戏崩。他换 semi-implicit Euler,稳定性好。

**第五步,调参找 critical damping**。Critical damping 公式:`c_critical = 2 * sqrt(k * m)`(m=1 时 `c = 2*sqrt(k)`)。

- `c < c_critical`:**underdamped**(欠阻尼),过冲后振动几次,稳定
- `c = c_critical`:**critical**(临界),最快无过冲,稳定
- `c > c_critical`:**overdamped**(过阻尼),慢慢追,不过冲

Casey 试三种:
- underdamped(c=6):过冲 15%,生动
- critical(c=20):不过冲,最快到 100
- overdamped(c=40):慢慢到 100,不生动

**第六步,比较 lerp vs spring**。Casey 用同样的"从 0 到 100"测试:
- Lerp(Day 503):永远不过冲,平滑接近 100
- Spring underdamped:过冲 15%,生动
- Spring critical:不过冲,但比 lerp 快到 100
- Spring overdamped:比 lerp 更慢

Casey 最终选 **spring + 高 damping(c ≈ 0.8 * critical)**——轻微过冲,生动但不过分。

**第七步,试 PID 但放弃**。Casey 试 PID 控制(Kp=5, Ki=0.1, Kd=1)。能工作,但参数难调(Integral 容易 windup),且对相机过度精确(不需要积分项)。Casey 放弃 PID,选 spring。

**结论**:Day 504 探索 4 种方案,**Day 506 实施 spring**(具体 polish)。这一天的教学价值是"比较"——学会根据游戏风格选方案。

## 2 · 心智模型

### 类比:汽车悬挂 vs 弹簧秋千

**Lerp 缓动**(Day 503):像汽车豪华悬挂——减震器吸震,永远不"弹",平稳。

**Spring 物理**(Day 504):像弹簧秋千——用力推,过冲一下,再回弹。生动。

**Critical damping**:像精心调校的赛车悬挂——减震器和弹簧完美平衡,最快回到平衡,但不"弹"。

游戏相机的"感觉"对应:

- 教育游戏:lerp(稳定)
- 动作游戏:spring(生动)
- 精确平台游戏:critical damping(快速稳定)

### Hooke's Law(胡克定律)

弹簧的力 = -k * x。

`k` 是弹簧常数(刚度)。x 是位移(相对平衡点)。

负号:力方向和位移相反(弹簧拉回去)。

加阻尼:`F = -k*x - c*v`。`c` 是阻尼系数,`v` 是速度。阻尼对抗运动,让振动衰减。

### Critical Damping(临界阻尼)

数学:c_critical = 2 * sqrt(k * m)。m 是质量。

c < c_critical:underdamped(欠阻尼),过冲后振动几次。
c = c_critical:critical(临界),最快无过冲回到平衡。
c > c_critical:overdamped(过阻尼),慢慢回到平衡,不过冲。

游戏相机常用 underdamped(轻微过冲),感觉生动。

### 数值积分:为什么 Euler 不行,深入

显式 Euler 是最简单的数值积分:

```
v_new = v + a * dt;
x_new = x + v * dt;     // 用旧速度更新位置
```

对弹簧系统,**显式 Euler 在能量上不稳定**。理论上 spring 能量守恒(`E = 0.5*k*x² + 0.5*m*v²`),但显式 Euler 每步**注入**少量能量。多步累积,振幅越来越大,**爆炸**。

数学解释:显式 Euler 的特征值会跑出单位圆外(数值不稳定),semi-implicit 在单位圆内(稳定)。

**Semi-implicit Euler**(隐式 Euler 变种):

```
v_new = v + a * dt;     // 先更新速度
x_new = x + v_new * dt; // 用新速度更新位置
```

看似只交换顺序,实际数学性质完全不同。Semi-implicit 是 **symplectic integrator(辛积分器)**,保守能量。Spring 系统稳定,不爆炸。

**更高阶方法**(游戏不常用,但工业级物理引擎用):
- **Verlet integration**:分子动力学常用。位置基,无显式速度。
- **Velocity Verlet**:Verlet + 速度更新。最常用的"准确又稳定"方法。
- **Runge-Kutta 4 (RK4)**:每步 4 次函数评估,精度 O(dt⁴)。慢但准。
- **Position-Based Dynamics (PBD)**:基于位置约束,稳定,游戏物理常用。

游戏物理(布料、绳索、流体)常用 Verlet 或 PBD,因为稳定且足够准。

### PID 控制的工业级应用

PID(Proportional-Integral-Derivative)是工业控制理论的基石:

```
F = K_p * e + K_i * ∫e dt + K_d * de/dt
```

`e` 是 error(target - actual)。

- **P(比例)**:`K_p * e`。简单 proportional 控制,类似 lerp。误差大 → 输出大。
- **I(积分)**:`K_i * ∫e dt`。消除稳态误差。如果系统有摩擦 / 重力,P alone 永远差一点。I 累积误差,慢慢补偿。
- **D(微分)**:`K_d * de/dt`。预测误差变化,减少过冲。

PID 应用场景:
- **恒温器**:目标温度,实际温度,PID 调加热功率
- **无人机姿态**:目标角度,实际角度,PID 调电机转速
- **自动驾驶**:目标速度,实际速度,PID 调油门
- **机器人关节**:目标位置,实际位置,PID 调电机扭矩

游戏相机一般不用 I 项(积分容易 windup,且相机不需要"消除稳态误差"——spring 已经收敛)。Spring(=PD)就够了。

PID 调参是工程艺术,有完整理论(Ziegler-Nichols 方法等)。游戏开发不深入,但理解 P / I / D 帮助看 spring 和 PID 的关系。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么 semi-implicit Euler 比显式 Euler 稳定?

**参考解答**:显式 Euler:`x_new = x + v*dt; v_new = v + a*dt`(用旧速度更新位置,用旧加速度更新速度)。

Semi-implicit Euler:`v_new = v + a*dt; x_new = x + v_new*dt`(先更新速度,再用新速度更新位置)。

数学上,semi-implicit 是 symplectic integrator(辛积分器),保守能量。显式 Euler 不保守能量——数值误差累积,spring 的振幅会越来越大,最终爆炸。

具体:对弹簧系统,显式 Euler 的特征值会跑出单位圆外(不稳定);semi-implicit 在单位圆内(稳定)。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:实现 spring + 3 种 damping(under / critical / over),比较相机跟随效果。

完成标准:`cargo run` 输出 3 种 damping 下相机从 (0,0) 跟随到 (100,0) 的轨迹。

**参考解答**:

```rust
#[derive(Copy, Clone, Debug)]
struct Spring {
    pos: f32,
    vel: f32,
    target: f32,
    k: f32,
    c: f32,
}

impl Spring {
    fn update(&mut self, dt: f32) {
        let force = -self.k * (self.pos - self.target) - self.c * self.vel;
        let accel = force;    // mass = 1
        self.vel += accel * dt;       // semi-implicit Euler
        self.pos += self.vel * dt;
    }
}

fn simulate(name: &str, k: f32, c: f32, target: f32, frames: usize) {
    let mut s = Spring { pos: 0.0, vel: 0.0, target, k, c };
    println!("\n{}: k={}, c={}, target={}", name, k, c, target);
    for i in 0..frames {
        if i % 10 == 0 {
            println!("  frame {:2}: pos={:7.2} vel={:7.2}", i, s.pos, s.vel);
        }
        s.update(1.0 / 60.0);
    }
}

fn main() {
    let k = 100.0;
    let critical = 2.0 * k.sqrt();    // = 20
    
    println!("=== Underdamped(c < critical,有过冲)===");
    simulate("Underdamped", k, critical * 0.3, 100.0, 120);    // c=6
    
    println!("\n=== Critical damping(c = critical,最快无过冲)===");
    simulate("Critical", k, critical, 100.0, 120);    // c=20
    
    println!("\n=== Overdamped(c > critical,慢慢追)===");
    simulate("Overdamped", k, critical * 2.0, 100.0, 120);    // c=40
    
    // 显式 Euler 不稳定演示
    println!("\n=== 显式 Euler(不稳定,可能爆炸)===");
    let k = 100.0;
    let c = 5.0;    // underdamped
    let mut pos = 0.0_f32;
    let mut vel = 0.0_f32;
    let target = 100.0;
    let dt = 1.0 / 60.0;
    
    for i in 0..200 {
        let force = -k * (pos - target) - c * vel;
        let accel = force;
        // 显式 Euler:先用旧速度
        let new_pos_explicit = pos + vel * dt;
        vel += accel * dt;
        pos = new_pos_explicit;
        
        if i % 20 == 0 {
            println!("  frame {:3}: pos={:.2} vel={:.2}", i, pos, vel);
        }
    }
}
```

为什么这么写:`c = 2*sqrt(k)` 是临界阻尼公式。`<` 是 underdamped,`>` 是 overdamped。Semi-implicit Euler 用新速度更新位置。

// ============================================================
// Day 504 · 探索相机插值方案
// ============================================================

use std::fmt;

#[derive(Copy, Clone, Debug, PartialEq)]
struct Vec2 { x: f32, y: f32 }

impl Vec2 {
    const fn new(x: f32, y: f32) -> Self { Self { x, y } }
    const ZERO: Self = Self::new(0.0, 0.0);
}

impl std::ops::Add for Vec2 {
    type Output = Vec2;
    fn add(self, o: Vec2) -> Vec2 { Vec2::new(self.x + o.x, self.y + o.y) }
}

impl std::ops::Sub for Vec2 {
    type Output = Vec2;
    fn sub(self, o: Vec2) -> Vec2 { Vec2::new(self.x - o.x, self.y - o.y) }
}

impl std::ops::Mul<f32> for Vec2 {
    type Output = Vec2;
    fn mul(self, s: f32) -> Vec2 { Vec2::new(self.x * s, self.y * s) }
}

impl fmt::Display for Vec2 {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "({:.1},{:.1})", self.x, self.y)
    }
}

// ============================================================
// 方案 1:Lerp(指数衰减)
// ============================================================

struct LerpCamera {
    pos: Vec2,
    target: Vec2,
    smoothing: f32,
}

impl LerpCamera {
    fn update(&mut self, dt: f32) {
        let factor = 1.0 - (-self.smoothing * dt).exp();
        self.pos.x += (self.target.x - self.pos.x) * factor;
        self.pos.y += (self.target.y - self.pos.y) * factor;
    }
}

// ============================================================
// 方案 2:Spring
// ============================================================

struct SpringCamera {
    pos: Vec2,
    vel: Vec2,
    target: Vec2,
    k: f32,    // 刚度
    c: f32,    // 阻尼
}

impl SpringCamera {
    fn update(&mut self, dt: f32) {
        // Semi-implicit Euler
        let force_x = -self.k * (self.pos.x - self.target.x) - self.c * self.vel.x;
        let force_y = -self.k * (self.pos.y - self.target.y) - self.c * self.vel.y;
        
        self.vel.x += force_x * dt;
        self.vel.y += force_y * dt;
        
        self.pos.x += self.vel.x * dt;
        self.pos.y += self.vel.y * dt;
    }
}

// ============================================================
// 方案 3:PID 控制
// ============================================================

struct PidCamera {
    pos: Vec2,
    target: Vec2,
    prev_error: Vec2,
    integral: Vec2,
    kp: f32,
    ki: f32,
    kd: f32,
}

impl PidCamera {
    fn update(&mut self, dt: f32) {
        let error = Vec2::new(self.target.x - self.pos.x, self.target.y - self.pos.y);
        let derivative = Vec2::new(
            (error.x - self.prev_error.x) / dt,
            (error.y - self.prev_error.y) / dt,
        );
        self.integral.x += error.x * dt;
        self.integral.y += error.y * dt;
        
        // PID 输出 = 速度(对位置积分)
        let vel_x = self.kp * error.x + self.ki * self.integral.x + self.kd * derivative.x;
        let vel_y = self.kp * error.y + self.ki * self.integral.y + self.kd * derivative.y;
        
        self.pos.x += vel_x * dt;
        self.pos.y += vel_y * dt;
        self.prev_error = error;
    }
}

// ============================================================
// 方案 4:Critical Damping(解析解,无积分误差)
// ============================================================

struct CriticallyDampedCamera {
    pos: Vec2,
    vel: Vec2,
    target: Vec2,
    omega: f32,    // 角频率
}

impl CriticallyDampedCamera {
    fn update(&mut self, dt: f32) {
        // 解析解,基于 critical damping 公式
        let omega = self.omega;
        let exp_wdt = (omega * dt).exp();
        
        // 公式:pos(t+dt) = target + (pos - target + (vel + omega*(pos-target))*dt) * exp(-omega*dt)
        // 简化版近似
        for axis in 0..2 {
            let p = if axis == 0 { self.pos.x } else { self.pos.y };
            let v = if axis == 0 { self.vel.x } else { self.vel.y };
            let t = if axis == 0 { self.target.x } else { self.target.y };
            
            let offset = p - t;
            let new_offset = offset * (1.0 + omega * dt) / exp_wdt;
            let new_vel = (v - omega * offset * omega * dt) / exp_wdt;
            
            if axis == 0 {
                self.pos.x = t + new_offset;
                self.vel.x = new_vel;
            } else {
                self.pos.y = t + new_offset;
                self.vel.y = new_vel;
            }
        }
    }
}

fn compare() {
    let dt = 1.0 / 60.0;
    let frames = 120;
    
    println!("=== 4 种相机方案比较 ===");
    println!("(初始 pos=(0,0),target=(100,0),跑 120 帧)\n");
    
    // Lerp
    let mut lerp_cam = LerpCamera {
        pos: Vec2::ZERO, target: Vec2::new(100.0, 0.0), smoothing: 5.0,
    };
    print!("Lerp:           ");
    for i in 0..frames {
        if i % 30 == 0 { print!("{:6.1} ", lerp_cam.pos.x); }
        lerp_cam.update(dt);
    }
    println!("{:6.1}", lerp_cam.pos.x);
    
    // Spring underdamped
    let k = 100.0;
    let critical = 2.0 * k.sqrt();
    let mut spring_under = SpringCamera {
        pos: Vec2::ZERO, vel: Vec2::ZERO,
        target: Vec2::new(100.0, 0.0),
        k, c: critical * 0.3,
    };
    print!("Spring under:   ");
    for i in 0..frames {
        if i % 30 == 0 { print!("{:6.1} ", spring_under.pos.x); }
        spring_under.update(dt);
    }
    println!("{:6.1}", spring_under.pos.x);
    
    // Spring critical
    let mut spring_crit = SpringCamera {
        pos: Vec2::ZERO, vel: Vec2::ZERO,
        target: Vec2::new(100.0, 0.0),
        k, c: critical,
    };
    print!("Spring critical:");
    for i in 0..frames {
        if i % 30 == 0 { print!("{:6.1} ", spring_crit.pos.x); }
        spring_crit.update(dt);
    }
    println!("{:6.1}", spring_crit.pos.x);
    
    // PID
    let mut pid = PidCamera {
        pos: Vec2::ZERO, target: Vec2::new(100.0, 0.0),
        prev_error: Vec2::ZERO, integral: Vec2::ZERO,
        kp: 5.0, ki: 0.1, kd: 1.0,
    };
    print!("PID:            ");
    for i in 0..frames {
        if i % 30 == 0 { print!("{:6.1} ", pid.pos.x); }
        pid.update(dt);
    }
    println!("{:6.1}", pid.pos.x);
    
    println!("\n  (30, 60, 90, 120 帧的 pos.x,目标 100.0)");
}

    println!(" Day 504 · 探索相机插值方案\n");
    println!("=============================================\n");
    
    compare();

    println!("\n=== Spring underdamped 详细(显示过冲)===");
    let k = 100.0;

    let mut s = SpringCamera {

}
