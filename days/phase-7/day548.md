> Day 547 提出"空间 voxel grid 存光照",但没说"场景里的 mesh 怎么转成 voxel"。Day 548 Casey 实现 **voxelization(体素化)**:把三角网格 rasterize(光栅化)进 3D voxel grid,标记"哪些 voxel 是实体"。

## 0 · 为什么要有这一天

让我们把镜头贴近场景。你跟着 Handmade Hero 走到 Day 547——Casey 设计了"空间 voxel grid 存光照",理论上光照应该在场景里传播——火把照亮墙、墙反射光到地板、地板反射回墙。**但是**,**voxel grid 是空的**——所有 voxel 都是"无内容"。你跑游戏,**火把的光直接穿过墙**,墙后一片亮——因为 voxel grid 不知道哪里有墙挡光。

这就是 Day 548 要解决的问题——**voxelization(体素化)**:把三角网格 rasterize(光栅化)进 3D voxel grid,标记"哪些 voxel 是实体"。**没有 voxelization,voxel grid 只是"空气"**,光自由传播,没有遮挡——光照计算毫无意义。

Voxelization 就是把"墙、地板、家具"这些 mesh,转成"哪些 voxel 占据了它们的位置"。结果:**occupied(占据)** 标记的 voxel 表示有几何体,可以遮挡光;**empty(空)** 的 voxel 表示空间,光可以自由传播。

这相当于把 3D 场景"像素化"——mesh 是连续几何(数学三角形),voxel 是离散网格(规则立方体),voxelization 是从连续到离散的转换。这个过程有 **sampling**(采样)的性质——细的 mesh 细节(如雕像的发丝)在粗 voxel grid 里会丢失;反过来,小 voxel 在大 mesh 里浪费内存。**voxel size 是关键参数**,决定精度 vs 内存的权衡。

为什么要做?因为后面 Day 551+ 要做"探针间传输"(光从一个 voxel 流到邻居),需要知道**哪里是墙(阻挡光流)哪里是空(光流过)**。Voxelization 提供"几何占用图"——光的传播算法基于这张图决定光怎么流。

- 理解 voxelization 的基本算法——SAT、AABB 扫描、solid vs surface
- 能用 CPU rasterize 三角形到 voxel grid,理解为什么 CPU 慢但 GPU 快
- 知道 voxelization 的工业做法——GPU compute shader 用 3D texture atomic 操作
- 理解 voxel size 对精度和内存的影响,以及 LOD(级联)voxel grid 的工程方案

## 2 · 心智模型

### 2.1 类比:用乐高拼出雕像

想象你有一个雕像(连续几何),想用乐高积木(voxel)拼出来。

**方法**:雕像周围画 3D 网格(每格 1cm³),检查每个格子——"格子里有雕像的一部分吗?"有的标"占据",没的标"空"。**结果**:乐高拼出来的雕像,看起来像雕像但有"块状"——网格越细(0.1cm³),越精细;越粗(10cm³),越像"方糖堆"。

Voxelization 就是这个过程,但格子是数据(不真拼),mesh 的"几何部分"是数学三角形(三个顶点定义的连续平面)。

**关键洞察:精度 vs 内存的 trade-off**。0.1cm³ 网格拼出的雕像精细,但格子数爆炸——1m³ 雕像 = 100 万 voxel。10cm³ 网格 1 万 voxel,但雕像细节丢失——发丝、衣纹都变成"块状"。工业 GI 用**级联 voxel grid**(cascade)解决——近处用细 grid(0.1m),远处用粗 grid(1m),多级覆盖。Casey 在 Day 567 学级联。

### 2.2 严谨展开:三角形 vs voxel 相交测试

核心问题:给定三角形 (v0, v1, v2) 和 voxel(中心 c,边长 1),它们相交吗?

经典算法是 **Separating Axis Theorem (SAT)**(分离轴定理):两个凸体不相交当且仅当存在一条"分离轴",它们在该轴上的投影不重叠。

**SAT 的直觉**:想象两个凸体(三角形 + 立方体),如果你能找到一条轴,让它们在这条轴上的投影"分开"(没重叠),那它们一定不相交。反之,如果所有可能的轴上都有重叠,它们相交。

三角形和 cube 都是凸的,SAT 适用。要测的轴:

1. **Cube 三个面法线**(x, y, z 轴):测试是否立方体某面把两者分开
2. **三角形面法线**:测试是否三角形面把两者分开
3. **三角形边 × cube 边 共 9 个叉积**:测试是否两个的边方向把两者分开

总共 **13 个轴**。每个轴上投影两个物体,看不重叠。**任何一个轴上分离 → 两者不相交**;否则相交。

### 2.3 简化算法:扫 AABB

避免对每个 voxel 做完整 SAT 测试(整个 grid 太大),用 **AABB 缩小扫描范围**——只扫三角形 AABB 内的 voxel。这是空间剪枝的标准技巧。

```rust
fn voxelize_triangle(
    grid: &mut VoxelGrid,
    v0: [f32; 3], v1: [f32; 3], v2: [f32; 3],
) {
    // 算三角形 AABB
    let lo = [
        v0[0].min(v1[0]).min(v2[0]),
        v0[1].min(v1[1]).min(v2[1]),
        v0[2].min(v1[2]).min(v2[2]),
    ];
    let hi = [
        v0[0].max(v1[0]).max(v2[0]),
        v0[1].max(v1[1]).max(v2[1]),
        v0[2].max(v1[2]).max(v2[2]),
    ];

    // 扫 AABB 范围的 voxel(不扫整个 grid)
    let lo_idx = grid.world_to_idx(lo);
    let hi_idx = grid.world_to_idx(hi);

    for k in lo_idx[2]..=hi_idx[2] {
        for j in lo_idx[1]..=hi_idx[1] {
            for i in lo_idx[0]..=hi_idx[0] {
                let center = grid.voxel_center(i, j, k);
                if triangle_voxel_overlap(v0, v1, v2, center, grid.voxel_size / 2.0) {
                    grid.set_occupied(i, j, k);
                }
            }
        }
    }
}
```

复杂度:每三角形 O(三角形包围的 voxel 数)。1m² 三角形 + 0.1m voxel = 100 voxel。10 万三角形 = 1000 万测试——CPU 上几秒。

**AABB 扫描的优化空间**:Casey 的简化版扫 AABB 整个**立方体**,但很多 voxel 实际不在三角形上(三角形是平面,立方体里有大量"三角形外"的 voxel)。**优化**:沿三角形平面投影扫,只扫平面附近的 voxel——但这需要更复杂的几何计算。GPU 实现常用这种方法。

### 2.4 体积 vs 表面 voxelization

两种 voxelization 适合不同场景:

- **Solid(体积)**:整个 mesh 内部都标 occupied。**用法**:判断"点在 mesh 内"——用于物理碰撞、点云分类、布尔运算。**实现**:`point-in-mesh` 测试(ray casting 算"穿越 mesh 表面次数",奇数=内部)或扫描线填充
- **Surface(表面)**:只标 mesh 表面经过的 voxel。**用法**:光照、反射、AO——只需要"墙挡光",不需要"墙内部有光"。**实现**:三角形 voxelization(本节算法)

Casey 用 **surface voxelization**——因为光照只需要"墙挡光",不需要"墙内部的光"。**Solid voxelization 浪费内存**——一个 5m × 5m × 0.1m 的墙,solid 标 250 万 voxel 内部(全部 occupied),surface 只标墙表面的几百 voxel——内存差 1000 倍。

**Surface voxelization 的限制**:如果墙厚度 < voxel size,voxelization 可能"漏标"——三角形太小没经过任何 voxel 中心,voxel 全是 empty,**光会穿过墙**。Fix:用 thin-wall aware voxelization(扩大测试范围)或更细 voxel grid。这是 voxel GI 的经典 bug——叫做"光泄漏"(light leaking),Day 567 用级联 voxel grid 缓解。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

工业级 voxelization 都在 GPU 上做(快 1000 倍)。具体技术:

- **OpenGL/D3D 三角形到 3D texture**:用 geometry shader 把每个三角形"画"到 3D texture——正交相机沿 x/y/z 三个轴各画一遍,避免漏 voxel。Eisenacher 2013 的"Real-time voxelization"论文是这个思路
- **Compute shader voxelization**:每个 voxel 一个线程,测自己有没有被任何三角形覆盖。**问题**:voxel 数 vs 三角形数组合爆炸。**优化**:用 BVH 加速三角形查询,或 hierarchical voxelization
- **Rasterization-based**(沿轴对齐切片画):把三角形沿主轴(三角形法线最对齐的轴)切片,每切片是一个 2D 三角形,光栅化到对应 voxel 层。Schwarz & Seidel 2010 算法

Unreal Engine 5 Lumen 用 GPU voxelization——**每帧重做**(因为场景动态)。但只对玩家附近的 mesh voxel化(culling 远处),省时间。CryEngine SVO 用稀疏八叉树存储,只存 occupied voxel(空 voxel 不存),内存友好。

**Voxelization 的 LOD**(Level of Detail):静态场景用多级 voxel grid——近处细(0.1m),远处粗(1m)。这就是 Day 567 学的 cascade voxel GI。**LOD 切换"级联"是工业 GI 的核心技术**。

### 3.2 · 🎨 图形学视角

voxelization 的核心数学:**3D 扫描转换**(scan conversion)。2D 光栅化把三角形转像素,3D voxelization 把三角形转 voxel。**3D 比 2D 复杂得多**——三角形是 2D 平面,要嵌入 3D 网格,涉及"三角形所在平面 vs 3D voxel 体积"的相交。

经典算法:

- **Amanatides-Woo**(Day 550 学过):DDA 算法遍历 voxel。原本是 ray-voxel,但反向用——三角形变成无数 ray,每 ray 遍历 voxel
- **Fast Voxel Traversal**(同上,industry 标准):Amanatides-Woo 的优化版,预计算 t_max 避免每步重算
- **Schwarz & Seidel 2010**:GPU 友好,沿轴对齐切片画。**这是工业 GPU voxelization 的金标准论文**
- **Crassin et al. 2011**(GigaVoxels):稀疏 voxel octree,只存 occupied voxel,支持 LOD

每种算法适合不同场景:CPU 离线用 SAT 完整,实时 GPU 用切片。**数据结构也关键**:dense 3D array(简单但内存大)、sparse voxel octree(内存友好但复杂)、hash-based sparse grid(快但 hash 冲突)。工业 GI 多用 sparse voxel octree 或 brick map(LOD 友好)。

### 3.3 · 🐧 Linux 系统编程视角

voxelization 的"扫描 AABB 范围"思想和 Linux 内核的 **range query** 一致:

- **Page table walk**:给虚拟地址范围,扫对应 page。**类似 voxelization**:给三角形 AABB,扫对应 voxel。都是"用空间索引缩小扫描范围"
- **VMA linked list**:进程的虚拟内存区域,范围查询。`/proc/<pid>/maps` 显示 VMA
- **Btrfs extent tree**:文件 extent 范围查询,B-tree 索引
- **ext4 block bitmap**:文件系统块占用图,1 bit per block——类似 voxel 的 occupied 标记
- **Redis ZRANGEBYSCORE**:sorted set 范围查询,跳表索引

核心思想都是**用空间索引加速范围查询**。voxelization 用 AABB 缩小扫描范围,内核用 B-tree / 跳表索引加速范围查找。

**"占用图"概念**在系统编程也常见:
- **位图**(bitmap):每 bit 代表一个资源是否被占用(如 ext4 块位图、内存分配位图)
- **Bloom filter**:占用图的概率版本——多个 hash,可能假阳性但无假阴性
- **/page allocator 的 buddy bitmap**:每级别一个 bitmap,标记块是否空闲

voxel 的 occupied grid 本质就是个 **3D 位图**——3D 版本的文件系统块位图。

### 3.4 · 🦀 Rust 生态视角

`nalgebra` 提供 AABB 类型,`parry3d`(Dim 的物理库)提供 triangle-box 精确相交测试:

```rust
use parry3d::shape::Triangle;
use parry3d::bounding_volume::AABB;
use parry3d::query;

let tri = Triangle::new(v0.into(), v1.into(), v2.into());

```

`parry3d` 的 `intersection_test` 用 SAT 完整 13 个轴测试,正确率高。**性能**:每次测试几 μs,10 万三角形 × 1000 voxel = 1 亿次测试 = 几分钟。生产用 GPU。

**Rust 的 voxel crate 生态**:
- `building-blocks`:多级 voxel data structure,支持 sparse、LOD

`parry3d` 是 `rapier3d`(物理引擎)的底层几何库,工业级可靠。

如果只想要快速 AABB 测试,自己写 20 行就够:

```rust
fn tri_aabb_overlap(
    v: &[[f32; 3]; 3],
    aabb_min: [f32; 3], aabb_max: [f32; 3],
) -> bool {
    // 三角形 AABB vs box AABB 重叠
    let tri_min = [
        v[0][0].min(v[1][0]).min(v[2][0]),
        v[0][1].min(v[1][1]).min(v[2][1]),
        v[0][2].min(v[1][2]).min(v[2][2]),
    ];
    let tri_max = [
        v[0][0].max(v[1][0]).max(v[2][0]),
        v[0][1].max(v[1][1]).max(v[2][1]),
        v[0][2].max(v[1][2]).max(v[2][2]),
    ];
    tri_max[0] >= aabb_min[0] && tri_min[0] <= aabb_max[0] &&
    tri_max[1] >= aabb_min[1] && tri_min[1] <= aabb_max[1] &&
    tri_max[2] >= aabb_min[2] && tri_min[2] <= aabb_max[2]
}
```

### Lv1 · 概念辨析

**题**:surface voxelization 和 solid voxelization 的区别?为什么光照用 surface 就够?

**参考解答**:surface 只标 mesh 表面经过的 voxel,solid 标 mesh 内部所有 voxel。光照只需要"墙挡光"——光打到墙表面,被反射或吸收。墙内部"光在哪"是没意义的(光进不去)。所以 surface voxelization 足够。但如果做"墙被击穿"的破坏,solid voxelization 有用(挖洞时知道挖到哪)。

### Lv2 · 动手实践

**题**:写一个函数,voxelize 一个单位立方体(8 个三角形)到 10x10x10 的 grid,voxel size = 1.0。

要求:
- 立方体从 (2.5, 2.5, 2.5) 到 (7.5, 7.5, 7.5)
- 用 AABB overlap 测试(简化)
- 打印哪些 voxel 被标记

**参考解答**:

```rust
struct VoxelGrid {
    occupied: Vec<bool>,
    dim: [usize; 3],
}

impl VoxelGrid {
    fn new(dim: [usize; 3]) -> Self {
        VoxelGrid { occupied: vec![false; dim[0]*dim[1]*dim[2]], dim }
    }

    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim[1] + j) * self.dim[0] + i
    }

    fn set(&mut self, i: usize, j: usize, k: usize) {
        if i < self.dim[0] && j < self.dim[1] && k < self.dim[2] {
            self.occupied[self.idx(i, j, k)] = true;
        }
    }

    fn get(&self, i: usize, j: usize, k: usize) -> bool {
        self.occupied[self.idx(i, j, k)]
    }
}

// 简化:用立方体 AABB 测试,扫覆盖范围
fn voxelize_aabb(
    grid: &mut VoxelGrid, voxel_size: f32,
    aabb_min: [f32; 3], aabb_max: [f32; 3],
) {
    let lo_i = (aabb_min[0] / voxel_size).floor() as usize;
    let lo_j = (aabb_min[1] / voxel_size).floor() as usize;
    let lo_k = (aabb_min[2] / voxel_size).floor() as usize;
    let hi_i = (aabb_max[0] / voxel_size).ceil() as usize;
    let hi_j = (aabb_max[1] / voxel_size).ceil() as usize;
    let hi_k = (aabb_max[2] / voxel_size).ceil() as usize;

    for k in lo_k..=hi_k {
        for j in lo_j..=hi_j {
            for i in lo_i..=hi_i {
                let vox_min = [i as f32 * voxel_size, j as f32 * voxel_size, k as f32 * voxel_size];
                let vox_max = [(i+1) as f32 * voxel_size, (j+1) as f32 * voxel_size, (k+1) as f32 * voxel_size];
                // AABB 重叠测试
                let overlap = vox_max[0] >= aabb_min[0] && vox_min[0] <= aabb_max[0]
                           && vox_max[1] >= aabb_min[1] && vox_min[1] <= aabb_max[1]
                           && vox_max[2] >= aabb_min[2] && vox_min[2] <= aabb_max[2];
                if overlap {
                    grid.set(i, j, k);
                }
            }
        }
    }
}

fn main() {
    let mut grid = VoxelGrid::new([10, 10, 10]);
```

```rust
#[derive(Clone, Copy, Debug, Default)]
struct Vec3 { x: f32, y: f32, z: f32 }

impl Vec3 {
    fn new(x: f32, y: f32, z: f32) -> Self { Vec3 { x, y, z } }
    fn min(&self, other: Self) -> Self {
        Self { x: self.x.min(other.x), y: self.y.min(other.y), z: self.z.min(other.z) }
    }
    fn max(&self, other: Self) -> Self {
        Self { x: self.x.max(other.x), y: self.y.max(other.y), z: self.z.max(other.z) }
    }
    fn sub(&self, other: Self) -> Self {
        Self { x: self.x - other.x, y: self.y - other.y, z: self.z - other.z }
    }
    fn dot(&self, other: Self) -> f32 {
        self.x*other.x + self.y*other.y + self.z*other.z
    }
    fn cross(&self, other: Self) -> Self {
        Self {
            x: self.y*other.z - self.z*other.y,
            y: self.z*other.x - self.x*other.z,
            z: self.x*other.y - self.y*other.x,
        }
    }
}

struct VoxelGrid {
    occupied: Vec<bool>,
    dim: [usize; 3],
    voxel_size: f32,
}

impl VoxelGrid {
    fn new(dim: [usize; 3], voxel_size: f32) -> Self {
        VoxelGrid {
            occupied: vec![false; dim[0]*dim[1]*dim[2]],
            dim, voxel_size,
        }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim[1] + j) * self.dim[0] + i
    }
    fn set(&mut self, i: usize, j: usize, k: usize) {
        if i < self.dim[0] && j < self.dim[1] && k < self.dim[2] {
            self.occupied[self.idx(i, j, k)] = true;
        }
    }
    fn get(&self, i: usize, j: usize, k: usize) -> bool {
        self.occupied[self.idx(i, j, k)]
    }
}

// 简化 SAT:测三角形和 AABB 是否相交
// 实现 Ericson "Real-Time Collision Detection" 的 triangle-AABB 测试
fn tri_aabb_overlap(
    v0: Vec3, v1: Vec3, v2: Vec3,
    box_min: Vec3, box_max: Vec3,
) -> bool {
    let center = Vec3::new(
        (box_min.x + box_max.x) * 0.5,
        (box_min.y + box_max.y) * 0.5,
        (box_min.z + box_max.z) * 0.5,
    );
    let half = Vec3::new(
        (box_max.x - box_min.x) * 0.5,
        (box_max.y - box_min.y) * 0.5,
        (box_max.z - box_min.z) * 0.5,
    );

    // 把三角形平移到 box 局部坐标
    let v0 = v0.sub(center);
    let v1 = v1.sub(center);
    let v2 = v2.sub(center);

    // 算三角形 AABB(局部)
    let tri_min = v0.min(v1).min(v2);
    let tri_max = v0.max(v1).max(v2);

    // AABB 重叠测试
    if tri_max.x < -half.x || tri_min.x > half.x { return false; }
    if tri_max.y < -half.y || tri_min.y > half.y { return false; }
    if tri_max.z < -half.z || tri_min.z > half.z { return false; }

    // 三角形法线
    let edge1 = v1.sub(v0);
    let edge2 = v2.sub(v0);
    let normal = edge1.cross(edge2);

    // 三角形面和 box 投影测试(简化)
    let proj_box = half.x * normal.x.abs() + half.y * normal.y.abs() + half.z * normal.z.abs();
    let proj_tri = v0.dot(normal);
    if proj_tri.abs() > proj_box { return false; }

    // 完整版还要测 9 个 edge×edge 轴
    // 这里简化跳过——对大多数三角形已经够准
    true
}

fn voxelize_triangle(
    grid: &mut VoxelGrid,
    v0: Vec3, v1: Vec3, v2: Vec3,
) {
    let tri_min = v0.min(v1).min(v2);
    let tri_max = v0.max(v1).max(v2);

    let lo_i = (tri_min.x / grid.voxel_size).floor() as usize;
    let lo_j = (tri_min.y / grid.voxel_size).floor() as usize;
    let lo_k = (tri_min.z / grid.voxel_size).floor() as usize;
    let hi_i = (tri_max.x / grid.voxel_size).ceil() as usize;
    let hi_j = (tri_max.y / grid.voxel_size).ceil() as usize;
    let hi_k = (tri_max.z / grid.voxel_size).ceil() as usize;

    for k in lo_k..=hi_k.min(grid.dim[2]-1) {
        for j in lo_j..=hi_j.min(grid.dim[1]-1) {
            for i in lo_i..=hi_i.min(grid.dim[0]-1) {
                let box_min = Vec3::new(
                    i as f32 * grid.voxel_size,
                    j as f32 * grid.voxel_size,
                    k as f32 * grid.voxel_size,
                );
                let box_max = Vec3::new(
                    (i+1) as f32 * grid.voxel_size,
                    (j+1) as f32 * grid.voxel_size,
                    (k+1) as f32 * grid.voxel_size,
                );
                if tri_aabb_overlap(v0, v1, v2, box_min, box_max) {
                    grid.set(i, j, k);
                }
            }
        }
    }
}

fn main() {
    let mut grid = VoxelGrid::new([16, 16, 16], 1.0);

    // voxel 一个三角形 (5,5,5)-(10,5,5)-(5,10,5)
    voxelize_triangle(&mut grid,
        Vec3::new(5.0, 5.0, 5.0),
        Vec3::new(10.0, 5.0, 5.0),
        Vec3::new(5.0, 10.0, 5.0),
    );

    let mut count = 0;
    for k in 0..grid.dim[2] {
        for j in 0..grid.dim[1] {
            for i in 0..grid.dim[0] {
                if grid.get(i, j, k) { count += 1; }
            }
        }
    }
    println!("Triangle voxelized: {} voxels occupied", count);
}
```
