# Day 553 · 改进的球面分布

> Day 552 用 Fibonacci sphere 生成 64 个方向,够用但有改进空间——某些区域采样仍有缝隙。Day 553 Casey 试 **cosine-weighted**(余弦加权)和 **stratified**(分层)的变体,看哪个对光照最自然。

## 0 · 为什么要有这一天

### 真实场景:为什么均匀采样不够好

让我们把镜头贴近一个具体的着色场景。你跟着 Handmade Hero 走到 Day 552——Casey 用 Fibonacci sphere 生成 64 个均匀方向,voxel propagation 看起来"差不多对",但**某些区域光照偏暗,某些偏亮**,视觉不自然。你打开 debug overlay,看每次 propagation 的采样方向——发现 64 个方向在球面上**均匀分布**,但场景的"光照贡献"分布不均匀。

回忆 Day 547 的渲染方程:`L_o = ∫ f_r * L_i * cos(θ) dω`,有个 `cos(θ)` 因子——表面法线和入射方向的夹角余弦。**这个 cos 因子改变了"采样价值"的分布**。

**关键观察**:当 `θ` 接近 90 度(光从侧面来),`cos(θ)` 接近 0,贡献很小。所以"法线垂直方向"的采样**白浪费**——即使采样到也没贡献。

让我们具体化。假设你给一个表面着色,法线朝上 (+Y)。光照来自整个上半球。你在半球上均匀采 64 个方向。

这 64 个方向里:
- **顶部(θ≈0)**:5-10 个方向,贡献很大(cos≈1)
- **中间(θ≈45°)**:30 个方向,贡献中等(cos≈0.7)
- **边缘(θ≈90°)**:20-30 个方向,贡献极小(cos≈0.1)

但**实际**渲染贡献:顶部 cos=1,边缘 cos=0。意思是:**边缘那 20-30 个采样浪费了**——它们采到的光,在最终积分里权重极小。

如果改用 **cosine-weighted sampling**:让顶部密(贡献大,值得密集采),边缘稀(贡献小,稀疏采)。同样 64 个采样,**有效信息量提升 2-3 倍**。

这是图形学的 **importance sampling** —— 按重要性分布采样,而非均匀。

### 工业级算法:Fibonacci vs Cosine-weighted

**Cosine-weighted sampling**:让采样分布自然偏向法线方向(那里 cos 值大),减少边缘的浪费。同样 N 个采样,精度提升 2-3 倍。

Fibonacci 球面是**各向同性**的(均匀),cosine-weighted 是**各向异性**的(集中在某方向)。两者用途不同:

- Fibonacci:不知道光主要来自哪,均匀采样最安全(对 probe-to-probe 这种)
- Cosine-weighted:知道法线方向,集中采样(对 surface shading 这种)

Casey 在 Day 553 实验两种,看哪个适合 voxel propagation。

### Importance sampling 的工业应用

Importance sampling 不只用在光照。它是 **Monte Carlo 方法**的核心技术,工业级应用广泛:

**Path tracing**(电影渲染):每个像素采几千条光路,importance sampling 让光路集中在"贡献大"的方向。Pixar RenderMan、Arnold、Mitsuba 都用。

**金融建模**:Monte Carlo 期权定价,importance sampling 集中在"高赔付"区域。

**机器学习**:SGD 训练时,batch 不是随机选,而是"按梯度大小选"(importance sampling 加速训练)。

**物理模拟**:粒子输运(中子、光子),importance sampling 集中在高反应区域。

这些都是 Day 553 学的能力的**迁移应用**。Casey 用光照场景教学,但原理通用。

## 2 · 心智模型

### 2.1 类比:问卷的人群分布

想象你做民意调查,要采样 1000 人调查"对学校教育的看法":

- **均匀采样**(Fibonacci):全国 14 亿人按人口均匀抽 1000 人,每省按比例——但你抽到的很多人(退休老人、未婚青年)对这个话题没强意见,**他们的回答低信息量**
- **重要性采样**(cosine-weighted):你的问卷是"对学校教育的看法",所以多抽家长群体(他们关心,有强意见),少抽不相关人群——同样 200 人就能得到高信息量的结果

问卷结果:**均匀采样需要 1000 人达到某精度,重要性采样 200 人就够了**——因为精力用在"重要"的人身上。

球面采样也是这样:Lambertian 表面的光照主要来自法线方向(那里 cos = 1,贡献大),重要性采样把精力放那里,效率高。**采样的核心 insight**:**N 个样本的价值不同,把 N 个预算分配给"高价值"样本**。

### 2.2 严谨展开:Cosine-weighted hemisphere sampling

让我把 cosine-weighted sampling 的数学彻底推导。目标是生成球面上的随机方向,概率密度函数(PDF)正比于 cos(θ):

```
PDF(ω) = cos(θ) / π
```

这是 Lambertian 表面的"自然"采样——按 cos 加权分布。**数学上**:对随机方向 ω,采到 cos 大的方向(法线附近)概率高,采到 cos 小的方向(边缘)概率低。

具体生成算法:

```rust
// 给定法线 N(单位向量),生成 cosine-weighted 采样
fn cosine_weighted_sample(rng: &mut impl Rng, normal: [f32; 3]) -> [f32; 3] {
    // 1. 生成两个 [0, 1) 均匀随机数
    let r1: f32 = rng.gen();
    let r2: f32 = rng.gen();

    // 2. 球面坐标(在"up"坐标系)
    let phi = 2.0 * std::f32::consts::PI * r1;          // 方位角
    let cos_theta = (1.0 - r2).sqrt();                   // cos(极角)
    let sin_theta = (1.0 - cos_theta * cos_theta).sqrt();

    // 3. 局部坐标(z 朝上)
    let local_x = sin_theta * phi.cos();
    let local_y = sin_theta * phi.sin();
    let local_z = cos_theta;

    // 4. 把局部坐标旋转到法线方向
    let (tangent, bitangent) = orthonormal_basis(normal);
    let dir = [
        tangent[0]*local_x + bitangent[0]*local_y + normal[0]*local_z,
        tangent[1]*local_x + bitangent[1]*local_y + normal[1]*local_z,
        tangent[2]*local_x + bitangent[2]*local_y + normal[2]*local_z,
    ];
    dir
}

fn orthonormal_basis(n: [f32; 3]) -> ([f32; 3], [f32; 3]) {
    // 选一个和 n 不平行的辅助向量
    let helper = if n[0].abs() > 0.9 { [0.0, 1.0, 0.0] } else { [1.0, 0.0, 0.0] };
    // t = normalize(cross(n, helper))
    let t = normalize(cross(n, helper));
    // b = cross(n, t)
    let b = cross(n, t);
    (t, b)
}
```

**关键公式**:`cos_theta = sqrt(1 - r2)`。这个根号让采样偏向"上"(高 cos_theta 值)。如果用 `cos_theta = 1 - r2`(线性),分布是均匀的;用 sqrt 让小 cos_theta 出现得少(密集在大 cos_theta)。

### 为什么 sqrt?

PDF(概率密度函数)cosine-weighted 是 `p(ω) = cos(θ) / π`。要从均匀随机数 r2 反推 cos_theta:

```
CDF(θ) = ∫_0^θ 2 * cos(θ') * sin(θ') dθ' = sin²(θ)
       = 1 - cos²(θ)
```

设 CDF = r2:`r2 = 1 - cos²(θ)` → `cos(θ) = sqrt(1 - r2)`。

这就是为什么 sqrt 出现——它从均匀 r2 映射到符合 cos 分布的方向。

### Stratified vs Random

Day 552 的 Fibonacci sphere 是 stratified(分层),Day 553 cosine-weighted 也可以做成 stratified——把半球分成 N 个等面积区域,每区域采一个。

Cosine-weighted + stratified:每区域的方向按 cos 分布采。质量最好。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

Importance sampling 在游戏开发的工业应用远超单纯的"半球采样":

- **BRDF sampling**(Path tracing):按 BRDF 分布采——粗糙表面采大锥,光滑表面采小锥。GGX BRDF 的 importance sampling 是工业 PBR 的核心技术,NVIDIA、AMD 的 ray tracing SDK 都内置
- **Soft shadows**:从光源形状采——矩形光源采均匀 2D,圆采极坐标,复杂形状(unreal 的 area light)用专门分布。每像素 16-64 采,importance sampling 把误差降到 1/4
- **GI**(global illumination):按 cos 分布采半球(本节)。更多采可投到"亮的方向"(从 voxel grid 预估),做 bidirectional importance sampling
- **Image-based lighting**(IBL):按 HDR 的亮度分布采——亮的区域(太阳、灯)多采,暗的区域(暗影)少采。这就是 Unreal 的 `ImportanceSampleHDR` 函数
- **Multiple importance sampling**(MIS):Veach 1995 提出,组合多个 importance distribution,取最优——既按 BRDF 采、又按 light 采,加权平均。这是现代 path tracer 的核心

Unreal 的 Lumen 用 importance sampling,所以低 sample 数也能高质量。**MIS 是 Unreal、Unity、Godot 的 GI 系统的共同基础**——没 MIS,GI 噪声严重。

### 3.2 · 🎨 图形学视角

Importance sampling 的数学:`E[f(X)] = ∫ f(x) p(x) dx`。如果采样分布是 p(x),估计 `f(X_i)/p(X_i)` 的平均。

如果 p ∝ |f|(p 跟 f 同形状),方差最小。这就是 "importance" 的意思——把采样"重点"放在 f 大的地方。

Lambertian BRDF 是常数,但 rendering equation 有 cos 因子,所以 p = cos/π 是最优的。

### 3.3 · Linux 系统编程视角

Importance sampling 在性能分析也用:

- **perf**:默认采每 100k cycles,如果想看热点,在热点函数加密采样
- **strace**:可以只 filter 特定 syscall(只看 open,忽略其他)
- **火焰图**:按 CPU 时间"采样",自动集中到热点

都是"把精力放在重要部分"的思想。

### Lv1 · 概念辨析

**题**:为什么 cosine-weighted 采样用 `cos(θ) = sqrt(1 - r2)` 而不是 `cos(θ) = 1 - r2`?

**参考解答**:`1 - r2` 是均匀分布(每个 cos 值出现概率相等)。`sqrt(1 - r2)` 是 cosine 分布(高 cos 值出现多)。要 cosine 分布是因为:在 Lambertian 渲染里,光从某方向来的"有效贡献"是 `cos(θ)`,所以采样分布应匹配 cos——这就是 importance sampling。直接积分 CDF 反推得到 sqrt。

### Lv2 · 动手实践

**题**:实现 cosine-weighted hemisphere sampling,验证分布。

要求:
- 法线 N = (0, 0, 1)
- 生成 10000 个采样
- 统计:有多少比例落在 cos(θ) > 0.7(法线附近)区域
- 预期:约 70%(cos > 0.7 对应 θ < 45°,半球面积占比约 (1 - cos(45)) / 1 = 0.29,但 cosine-weighted 下比例是 1 - 0.7² = 0.51)

**参考解答**:

```rust
struct Rng { state: u32 }
impl Rng {
    fn new(seed: u32) -> Self { Rng { state: if seed == 0 { 1 } else { seed } } }
    fn next_u32(&mut self) -> u32 {
        let mut x = self.state;
        x ^= x << 13; x ^= x >> 17; x ^= x << 5;
        self.state = x;
        x
    }
    fn gen_f32(&mut self) -> f32 {
        (self.next_u32() >> 8) as f32 / (1u32 << 24) as f32
    }
}

fn cosine_sample(rng: &mut Rng, normal: [f32; 3]) -> [f32; 3] {
    let r1 = rng.gen_f32();
    let r2 = rng.gen_f32();
    let phi = 2.0 * std::f32::consts::PI * r1;
    let cos_theta = (1.0 - r2).sqrt();
    let sin_theta = (1.0 - cos_theta * cos_theta).sqrt();

    let local_x = sin_theta * phi.cos();
    let local_y = sin_theta * phi.sin();
    let local_z = cos_theta;

    // 法线 = (0,0,1),所以 local 坐标直接是 world
    if normal == [0.0, 0.0, 1.0] {
        [local_x, local_y, local_z]
    } else {
        // 简化:假设法线就是 z 轴
        [local_x, local_y, local_z]
    }
}

fn main() {
    let mut rng = Rng::new(42);
    let normal = [0.0, 0.0, 1.0];

    let n = 10000;
    let mut near_normal = 0;
    for _ in 0..n {
        let dir = cosine_sample(&mut rng, normal);
        let cos_theta = dir[2];  // 因为 normal = (0,0,1)
        if cos_theta > 0.7 {
            near_normal += 1;
        }
    }
    println!("Samples with cos > 0.7: {} / {} ({:.1}%)",
        near_normal, n, near_normal as f32 * 100.0 / n as f32);
    // 理论值:1 - 0.7^2 = 0.51,所以约 51%
}
```

## 8 · Rust / Arch 落地代码

完整的 cosine-weighted + Fibonacci 对比:

```rust
struct Rng { state: u32 }
impl Rng {
    fn new(seed: u32) -> Self { Rng { state: if seed == 0 { 1 } else { seed } } }
    fn next_u32(&mut self) -> u32 {
        let mut x = self.state;
        x ^= x << 13; x ^= x >> 17; x ^= x << 5;
        self.state = x; x
    }
    fn gen_f32(&mut self) -> f32 {
        (self.next_u32() >> 8) as f32 / (1u32 << 24) as f32
    }
}

// Fibonacci 球面:均匀分布
fn fibonacci_sphere(n: usize) -> Vec<[f32; 3]> {
    let mut pts = Vec::with_capacity(n);
    let golden = (1.0_f32 + 5.0_f32.sqrt()) / 2.0;
    let angle_inc = std::f32::consts::TAU * golden;
    for i in 0..n {
        let t = i as f32 / n as f32;
        let inc = (1.0 - 2.0 * t).acos();
        let az = angle_inc * i as f32;
        pts.push([inc.sin()*az.cos(), inc.sin()*az.sin(), inc.cos()]);
    }
    pts
}

// Cosine-weighted hemisphere(法线 = +Z)
fn cosine_weighted(n: usize, rng: &mut Rng) -> Vec<[f32; 3]> {
    (0..n).map(|_| {
        let r1 = rng.gen_f32();
        let r2 = rng.gen_f32();
        let phi = 2.0 * std::f32::consts::PI * r1;
        let cos_theta = (1.0 - r2).sqrt();
        let sin_theta = (1.0 - cos_theta * cos_theta).sqrt();
        [sin_theta*phi.cos(), sin_theta*phi.sin(), cos_theta]
    }).collect()
}

// 计算平均 cos(theta):对 Lambertian 渲染,值越大表示采样越"有效"
fn mean_cos(pts: &[[f32; 3]]) -> f32 {
    pts.iter().map(|p| p[2].abs()).sum::<f32>() / pts.len() as f32
}

// 计算方差(模拟渲染的方差,值小表示采样质量好)
fn render_variance(pts: &[[f32; 3]]) -> f32 {
    // 假设光来自 (0,0,1) 方向,强度 1
    // Lambertian:每方向贡献 = cos(theta) / N
    // 真实积分 = π/2(半球积分 cos = π/2 ≈ 1.57)
    let n = pts.len() as f32;
    // 单采样贡献(对 cos 积分,要乘 2π/N,但比较时相对):
    let contributions: Vec<f32> = pts.iter()
        .map(|p| p[2].max(0.0))
        .collect();
    let mean = contributions.iter().sum::<f32>() / n;
    let var = contributions.iter().map(|c| (c - mean).powi(2)).sum::<f32>() / n;
    var
}

fn main() {
    let mut rng = Rng::new(42);
    let n = 64;

    let fib = fibonacci_sphere(n);
    let cos = cosine_weighted(n, &mut rng);

    println!("Fibonacci (uniform):");
    println!("  Mean |cos|: {:.4}", mean_cos(&fib));
    println!("  Variance:   {:.4}", render_variance(&fib));

    println!("Cosine-weighted:");
    println!("  Mean |cos|: {:.4}", mean_cos(&cos));
    println!("  Variance:   {:.4}", render_variance(&cos));

    // Variance 越小越好——cosine 应该比 fib 小很多
}
```

### 附录:Importance sampling 的"工业实战"

#### Path tracing 中的多 BRDF sampling

工业级 path tracer(Pixar RenderMan、Arnold、Blender Cycles)用 importance sampling,但**比 Day 553 复杂得多**。具体:

对每个像素,发射 N 条光路。每条光路在每次弹射时,选择下一个方向。选择策略:

- **Cosine-weighted**(Lambertian 漫反射):Day 553 学的。
- **GGX sampling**(微表面 BRDF):对粗糙表面,集中采"高光方向"。
- **Light sampling**:直接采"光源方向",避免错过光源(直接照明)。
- **Multiple Importance Sampling (MIS)**:结合 BRDF sampling 和 light sampling,取各自优势。

MIS 是工业级金标。具体:对每个方向,用两种方法采样(BRDF-based 和 light-based),结果用"启发式权重"结合,避免两种方法的偏差。

这是图形学 PhD 论文级别的复杂度。Day 553 是简化版,但**核心思想相同**:**按贡献分布采样**。

#### Machine Learning 中的 importance sampling

训练神经网络时,SGD 选 batch:

- **随机 SGD**:从训练集随机选 N 个样本
- **Importance sampling**:按"梯度大小"选样本——梯度大(难学)的多选,梯度小(已学会)的少选

实践证明 importance sampling 加速训练 2-3 倍。论文 "Accelerating SGD using Predictive Importance Sampling"(Needham, 2018)有详细推导。

#### 物理模拟中的 importance sampling

中子输运(核反应堆设计)、光子输运(医学成像)用 Monte Carlo 方法。Importance sampling:

- 在"高反应概率"区域(如燃料棒)密集采样
- 在"低反应"区域(如冷却剂)稀疏采样

这是核工程的核心技术。

#### 金融建模的 importance sampling

期权定价(Black-Scholes 模型)用 Monte Carlo。Importance sampling:

- 在"价内"(option 有价值)区域密集采样
- 在"价外"区域稀疏采样

这是 quantitative finance 的核心技术。
