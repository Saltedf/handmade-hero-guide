# Day 570 · 区分光源与遮挡物

> Voxel grid 里有两类 occupied voxel:光源(发光)和遮挡物(墙,不发光)。Day 569 raycast 把它们都当"挡光",结果光源被错误遮挡。Day 570 Casey 加 **light vs occluder 区分**——raycast 撞光源时,光源的颜色贡献给 ray,不立刻停。

## 0 · 为什么要有这一天

回顾 Day 569 raycast:ray 沿方向走,撞 occupied voxel 就停。但光源 voxel 也是 occupied(因为它有几何形状,比如灯泡模型)——撞到光源时立刻停,ray 没记录"看到光源的颜色"。

错误结果:

- 玩家看向光源方向,raycast 撞光源立刻停,probe 没记录光源颜色 → 玩家附近 voxel 是黑的(没收到光源光)
- 实际玩家眼睛看到的是光源(亮)

正确做法:撞光源时,**记录光源颜色**,然后 ray **继续走**(看光源后面有没有更远的光 / 墙)。

更准确做法:撞任何 occupied voxel 都记录 albedo * light,但只有"完全遮挡"的(墙)才停 ray。光源是"部分透明"的——光从光源出,自身也"被看见"。

完成这一天之后,你具备:

- 理解 voxel 类别(light / occluder / 空气)的区分
- 能在 raycast 里正确处理 light voxel
- 知道 visibility 的精确语义

## 1 · Casey 今天做了什么

Casey 的步骤:

第一步,他给 Voxel 加 `kind` 字段——枚举 `Air / Light / Occluder`。

第二步,raycast 逻辑:

- 撞 Air:继续走,累加 light
- 撞 Light:记录 light color,**继续走**(不停)
- 撞 Occluder:记录 albedo * light,**停**

第三步,光源在场景里是 Light voxel,墙是 Occluder。

视频里他演示:玩家看向火把,反射 ray 撞火把(光源),正确记录火把颜色;ray 继续走,撞火把后面的墙(occluder),记录墙的反射,然后停。最终颜色 = 火把光 + 墙反射。

## 2 · 心智模型

### 类比:玻璃窗 vs 砖墙

你站在街上,沿某方向看:

- **空气**:看穿,什么都没有
- **玻璃窗**(光源):窗后有光进来,你看到窗,但也能看到窗后的(部分透明)
- **砖墙**(遮挡):看不穿,墙就是你看到的终点

Raycast 也是:撞空气继续走,撞"玻璃"(光源)记录看到的光但不停止(它透明),撞"砖墙"停止。

但要注意——如果光太强(火把),它后面的东西会"看不清"(强光眩目)。Raycast 简化处理:光源后东西仍记录,但被光源亮度"压倒"——视觉合理。

更新 raycast:

```rust
fn ray_march(
    grid: &VoxelGrid,
    origin: V3,
    dir: V3,
    max_steps: usize,
) -> V3 {
    let mut sum = [0.0; 3];
    let mut attenuation = 1.0;

    for step in 1..=max_steps {
        let t = step as f32;
        let p = [
            origin[0] + dir[0] * t,
            origin[1] + dir[1] * t,
            origin[2] + dir[2] * t,
        ];
        let i = p[0] as i64;
        let j = p[1] as i64;
        let k = p[2] as i64;
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            break;
        }

        let voxel = grid.get(i as usize, j as usize, k as usize);

        // 累加(不论 kind)
        sum[0] += voxel.light[0] * attenuation;
        sum[1] += voxel.light[1] * attenuation;
        sum[2] += voxel.light[2] * attenuation;

        // 决定是否停
        match voxel.kind {
            VoxelKind::Air => {
                attenuation *= 0.95;
            }
            VoxelKind::Light => {
                // 不停,继续看光源后
                attenuation *= 0.5;  // 但衰减快(光后看不太清)
            }
            VoxelKind::Occluder => {
                break;  // 撞墙,停
            }
        }
    }
    sum
}
```

### Albedo 对反射的影响

更细致:Occluder 的反射光应该被其 albedo 染色——白墙反射白光,红墙反射红光。

```rust
let contribution = [
    voxel.light[0] * voxel.albedo[0],
    voxel.light[1] * voxel.albedo[1],
    voxel.light[2] * voxel.albedo[2],
];
sum[0] += contribution[0] * attenuation;
// ...
```

光源的 albedo 是 [1,1,1](不染色),墙的 albedo 是其颜色。

## 3 · 四域深入

### 3.1 · 游戏编程视角

工业 voxel GI 的 voxel 分类:

- **Air**:empty,只传播光
- **Geometry**:mesh surface,反射光
- **Light emitter**:发光(灯、火)
- **Volumetric**:雾、烟(scattering,光散射)

Unreal Lumen 把 voxel 分多个属性(albedo / emissive / opacity),Casey 这天简化为 3 种。

### 3.2 · 图形学视角

Voxel 类别对应物理:

- **Air**:transmittance = 1(完全透明)
- **Light**:emissive surface(发光但半透明,如灯泡)
- **Occluder**:transmittance = 0(完全遮挡)

更精细的体渲染(volume rendering)用 optical depth:

```
T(s) = exp(-∫ σ(t) dt)  (透射率)
```

σ 是衰减系数。Air σ=0,Light σ≈小,Occluder σ→∞。

Casey 用离散近似(三档),够游戏用。

### 3.3 · Linux 系统编程视角

"分类 / tagging"模式:

- **Linux 文件类型**:regular / directory / socket / device / pipe
- **Process state**:R / S / D / Z / T
- **Memory page**:active / inactive / dirty / locked

都是"用 kind 字段区分行为"的设计。

### 3.4 · Rust 生态视角

Rust enum 是表达 voxel kind 的天然方式:

```rust
enum VoxelKind {
    Air,
    Light { intensity: f32 },
    Occluder { material: MaterialId },
}

match voxel.kind {
    VoxelKind::Air => /* ... */,
    VoxelKind::Light { intensity } => /* ... */,
    VoxelKind::Occluder { material } => /* ... */,
}
```

Rust enum 带 payload,可以每 kind 存不同数据。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么光源 voxel 是 occupied 但 ray 不停?如果不停,会不会"看到"光源后面的太多细节?

**参考解答**:光源 voxel 有几何形状(灯泡模型),所以 occupied = true。但物理上光源本身"发光",光从它出来——ray 撞它时**应该**记录它的颜色(这是玩家眼睛看到光源的方式)。如果立刻停,probe 没记录光源 → 玩家附近 voxel 黑(因为没收到光)。不停的话:ray 继续看光源后,但 attenuation 衰减快(0.5 每步),所以光源后的东西很快模糊。视觉上:光源 + 模糊的光源后景——合理。如果 attenuation=1.0(不衰减),ray 看到光源后所有细节,不真实(光应该"眩目"挡住后面的)。

### Lv2 · 动手实践

**题**:实现 VoxelKind enum,验证光源不被错误遮挡。

要求:
- 8³ voxel grid
- (4,4,4) 是 Light(发光)
- (6,4,4) 是 Occluder(墙)

- 验证 ray 同时记录光源和墙

**参考解答**:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, PartialEq)]
enum VoxelKind { Air, Light, Occluder }

#[derive(Clone, Copy)]
struct Voxel {
    light: V3,
    albedo: V3,
    kind: VoxelKind,
}

impl Default for Voxel {
    fn default() -> Self {
        Voxel { light: [0.0; 3], albedo: [1.0; 3], kind: VoxelKind::Air }
    }
}

struct VoxelGrid {
    data: Vec<Voxel>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![Voxel::default(); dim*dim*dim], dim }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim + j) * self.dim + i
    }
    fn get(&self, i: usize, j: usize, k: usize) -> Voxel { self.data[self.idx(i, j, k)] }
    fn set(&mut self, i: usize, j: usize, k: usize, v: Voxel) {
        self.data[self.idx(i, j, k)] = v;
    }
}

fn ray_march(grid: &VoxelGrid, origin: V3, dir: V3, max_steps: usize) -> (V3, Vec<(usize, VoxelKind, V3)>) {
    let mut sum = [0.0; 3];
    let mut attenuation = 1.0;
    let mut path = Vec::new();

    for step in 1..=max_steps {
        let t = step as f32;
        let p = [
            origin[0] + dir[0] * t,
            origin[1] + dir[1] * t,
            origin[2] + dir[2] * t,
        ];
        let i = p[0] as i64;
        let j = p[1] as i64;
        let k = p[2] as i64;
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            break;
        }
        let voxel = grid.get(i as usize, j as usize, k as usize);

        sum[0] += voxel.light[0] * attenuation;
        sum[1] += voxel.light[1] * attenuation;
        sum[2] += voxel.light[2] * attenuation;

        path.push((i as usize, voxel.kind, voxel.light));

        match voxel.kind {
            VoxelKind::Air => { attenuation *= 0.95; }
            VoxelKind::Light => { attenuation *= 0.5; }
            VoxelKind::Occluder => break,
        }
    }
    (sum, path)
}

fn main() {
    let mut grid = VoxelGrid::new(8);
    grid.set(4, 4, 4, Voxel {
        light: [10.0, 8.0, 6.0], albedo: [1.0; 3], kind: VoxelKind::Light,
    });
    grid.set(6, 4, 4, Voxel {
        light: [0.0; 3], albedo: [0.7, 0.5, 0.3], kind: VoxelKind::Occluder,
    });

    let (sum, path) = ray_march(&grid, [0.0, 4.0, 4.0], [1.0, 0.0, 0.0], 10);

    println!("Ray path:");
    for (i, kind, light) in &path {
        let kind_str = match kind {
            VoxelKind::Air => "Air",
            VoxelKind::Light => "Light",
            VoxelKind::Occluder => "Occluder",
        };
        println!("  voxel {}: {} light=({:.2},{:.2},{:.2})", i, kind_str, light[0], light[1], light[2]);
    }
    println!("\nFinal sum: ({:.2}, {:.2}, {:.2})", sum[0], sum[1], sum[2]);
}
```

## 8 · Rust / Arch 落地代码

完整 raycast with voxel kind:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, PartialEq, Debug)]
enum VoxelKind { Air, Light, Occluder, Transparent }  // Transparent = 玻璃(部分透光)

#[derive(Clone, Copy)]
struct Voxel {
    light: V3,
    albedo: V3,
    kind: VoxelKind,
    transmittance: f32,  // 透射率(Transparent 用)
}

impl Default for Voxel {
    fn default() -> Self {
        Voxel {
            light: [0.0; 3],
            albedo: [1.0; 3],
            kind: VoxelKind::Air,
            transmittance: 1.0,
        }
    }
}

struct VoxelGrid {
    data: Vec<Voxel>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![Voxel::default(); dim*dim*dim], dim }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim + j) * self.dim + i
    }
    fn get(&self, i: usize, j: usize, k: usize) -> Voxel { self.data[self.idx(i, j, k)] }
    fn set(&mut self, i: usize, j: usize, k: usize, v: Voxel) {
        self.data[self.idx(i, j, k)] = v;
    }
}

fn ray_march(
    grid: &VoxelGrid,
    origin: V3,
    dir: V3,
    max_steps: usize,
) -> V3 {
    let mut sum = [0.0; 3];
    let mut attenuation = 1.0;

    for step in 1..=max_steps {
        let t = step as f32;
        let p = [
            origin[0] + dir[0] * t,
            origin[1] + dir[1] * t,
            origin[2] + dir[2] * t,
        ];
        let i = p[0] as i64;
        let j = p[1] as i64;
        let k = p[2] as i64;
        if i < 0 || j < 0 || k < 0 ||
           i as usize >= grid.dim || j as usize >= grid.dim || k as usize >= grid.dim {
            break;
        }
        let voxel = grid.get(i as usize, j as usize, k as usize);

        // 累加(被 albedo 染色)
        let contribution = [
            voxel.light[0] * voxel.albedo[0],
            voxel.light[1] * voxel.albedo[1],
            voxel.light[2] * voxel.albedo[2],
        ];
        sum[0] += contribution[0] * attenuation;
        sum[1] += contribution[1] * attenuation;
        sum[2] += contribution[2] * attenuation;

        // 根据 kind 决定下一步 attenuation
        match voxel.kind {
            VoxelKind::Air => attenuation *= 0.95,
            VoxelKind::Light => attenuation *= 0.5,  // 光源眩目,后面看不清
            VoxelKind::Occluder => break,
            VoxelKind::Transparent => attenuation *= voxel.transmittance,
        }

        if attenuation < 0.01 { break; }  // 完全衰减,停
    }
    sum
}

fn main() {
    let mut grid = VoxelGrid::new(16);

    // 太阳光(远处光源)
    grid.set(0, 12, 0, Voxel {
        light: [10.0, 9.0, 7.0],
        albedo: [1.0; 3],
        kind: VoxelKind::Light,
        transmittance: 1.0,
    });

    // 窗户(透明)
    grid.set(5, 5, 5, Voxel {
        light: [0.0; 3],
        albedo: [0.8; 3],
        kind: VoxelKind::Transparent,
        transmittance: 0.7,  // 70% 光过
    });

    // 墙(遮挡)
    grid.set(10, 5, 5, Voxel {
        light: [0.0; 3],
        albedo: [0.7, 0.5, 0.3],
        kind: VoxelKind::Occluder,
        transmittance: 0.0,
    });

    // 从某点沿 +x 方向看
    let sum = ray_march(
        &grid,
        [0.0, 5.0, 5.0],
        [1.0, 0.0, 0.0],
        20,
    );

    println!("Ray from (0,5,5) along +x:");
    println!("  Sum: ({:.2}, {:.2}, {:.2})", sum[0], sum[1], sum[2]);
    println!("  Expected: 撞窗户(transmittance 0.7),部分光过,撞墙停止");

    // 玩家朝太阳看
    let sum = ray_march(
        &grid,
        [5.0, 5.0, 5.0],
        // 归一化方向 (-5, 7, -5)/length
        {
            let mut d = [-5.0, 7.0, -5.0];
            let mag = (25.0 + 49.0 + 25.0).sqrt();
            d[0] /= mag; d[1] /= mag; d[2] /= mag;
            d
        },
        20,
    );
    println!("\nRay toward sun:");
    println!("  Sum: ({:.2}, {:.2}, {:.2})", sum[0], sum[1], sum[2]);
    println!("  Expected: 撞太阳光源,记录高亮度");
}
```
