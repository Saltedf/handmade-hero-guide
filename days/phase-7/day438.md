# Day 438 · 切换到余弦加权 Poisson 采样

> 昨天 Casey 预计算了 64 个均匀分布在半球上的方向。今天他发现"均匀"不是最优——Lambert 漫反射的天性让"余弦加权"成为数学上的最优分布。这一步看似抽象,实则是把 Monte Carlo 方差降低 50% 以上的关键技巧。

## 0 · 为什么要有这一天

如果你跟了 Day 436-437,你现在有一个 64 个均匀半球方向的预计算数组。打开游戏,渲染一帧,你会看到画面比 Day 435 之前干净很多。但如果你放大阴影边缘、放大柔和的反射高光,你会发现**仍有颗粒噪点**——只是比纯随机少。

为什么?因为"均匀半球采样"和"Lambert 漫反射积分"不是最优匹配。

Lambert 漫反射的积分是 `∫ L_in(ω) cos(θ) dω`。`cos(θ)` 在 θ=0(正上方)是 1,在 θ=π/2(地平线)是 0。也就是说**正上方的方向贡献大,接近水平的方向贡献小**。均匀半球采样让 64 个方向贡献等量"积分权重",意味着大量计算花在贡献小的水平方向上,贡献大的正上方反而采样不足。

**余弦加权采样(cosine-weighted sampling)** 是数学上的最优解:让采样密度 ∝ `cos(θ)`。这样正上方多采,水平少采,每个采样的"积分权重"刚好相等。**结果是相同 N 下,噪点降低 50% 以上**——这是免费的画质提升。

**Poisson 采样**则是一种"看似随机但保持最小间距"的分布生成方法,保证采样点不会过分聚集。Casey 把余弦加权 + Poisson 圆盘思想结合,得到今天的最终方案。

完成这一天你能做到:用一张单位圆盘上的 Poisson 点集,通过余弦加权映射到半球,得到一组数学上最优的采样方向。你还能解释"重要性采样"和"低差异性序列"的本质差别——前者匹配函数形状,后者均匀填充空间。

## 2 · 心智模型

### 类比:民意调查的"分层抽样"

想象你要预测全国选举结果。**均匀采样**(Day 437 做法)相当于全国随机打 1000 个电话——但农村人口稀疏,你会大量采样到城市居民,而农村样本不足。

**余弦加权采样**(Day 438 做法)相当于按人口密度分层抽样——城市多采、农村少采,但每个样本"代表的选民数"刚好相等。

映射到光照:城市 = 正上方(贡献大),农村 = 水平(贡献小)。**正上方多采,水平少采**。这是统计学的**重要性采样(importance sampling)**,1940 年代由 Nicholas Metropolis 提出(曼哈顿计划里算中子扩散)。

### 严谨原理:Malley 法

要把单位圆盘上的点变成余弦加权的半球点,有个极巧的公式:

```
单位圆盘上的 (x, y)
↓ Malley 法
半球上的 (x, y, sqrt(1 - x² - y²))
```

**为什么这个映射自然产生余弦加权?**

球面上一点 `(x, y, z)`,它和北极的夹角 θ 满足 `cos(θ) = z`。Malley 法把 `z = sqrt(1 - x² - y²)`,所以 `cos(θ) = sqrt(1 - r²)`,其中 `r = sqrt(x² + y²)` 是圆盘半径。

如果原圆盘是均匀分布(PDF = 1/π 在单位圆盘内),那么半球上对应点的 PDF:

```
PDF_hemisphere(θ, φ) ∝ sin(θ) / cos(θ) * d(cos(θ)) = sin(θ) (Jacobian 推导)
```

具体推导涉及面积元素 `dω = sin(θ) dθ dφ` 和链式法则。结果令人愉悦:**半球上的 PDF = cos(θ) / π**,正好是 Lambert 漫反射需要的!

**直觉再回顾**:圆盘上 r 等分会挤压圆心(面积 ∝ r²)。Malley 法自动把"圆盘均匀"映射成"半球余弦加权"——因为越靠近圆心的点(r 小)对应越靠近北极的半球点(z 大、cos(θ) 大),密度大。

### Poisson 圆盘采样

Poisson 圆盘(Poisson disk)是一种"任意两点距离不小于阈值 d"的随机分布。它和蓝噪声是亲戚——区别是 Poisson 圆盘有严格最小距离约束,蓝噪声是统计性质。

**为什么用 Poisson 而不是螺旋?** 螺旋是确定性的,适合 debug。但螺旋在某些角度会产生莫尔条纹(规则的拍频)。Poisson 圆盘的随机性破除了规则性,视觉上更"自然"。

生成 Poisson 圆盘的经典算法:**Bridson 算法**(2007,Robert Bridson)。核心思想:
1. 维护一个"候选点"队列
2. 从队列取一点,在它周围 r 到 2r 距离环上撒 k 个候选(通常 k=30)
3. 检查每个候选:周围 r 距离内有没有已存在的点?没有就接受
4. 接受的点加入队列,重复
5. 队列空时结束

这个算法 O(N) 时间,非常快。Casey 在 HH 不用 Bridson(他直接预生成纹理),但 Rust 工程化版本可以用。

### 把这些写成 Rust

```rust
// 假设 disk_points 是预计算的 N 个圆盘上的点
// (px, py) ∈ [-1, 1]² 且 px²+py² <= 1
fn malley_to_hemisphere(px: f32, py: f32) -> (f32, f32, f32) {
    let z = (1.0_f32 - px * px - py * py).max(0.0).sqrt();
    (px, py, z)
}

// 整体流程:从圆盘 Poisson 点集生成半球 Poisson 点集
fn build_cosine_weighted_hemisphere(disk_points: &[(f32, f32)]) -> Vec<(f32,f32,f32)> {
    disk_points.iter()
        .map(|&(px, py)| malley_to_hemisphere(px, py))
        .collect()
}
```

每行解释:
- `(1 - px² - py²).max(0).sqrt()` 算 z 坐标。`.max(0)` 是浮点防御——理论上 px²+py² ≤ 1,但预计算时可能有微小误差导致负数。
- `.iter().map().collect()` 是 Rust 函数式风格。它等价于 for 循环,但更简洁。生成的 `Vec` 拥有所有数据。

### 为什么 Poisson 而不是蓝噪声

Casey 选 Poisson 圆盘(明确最小距离)而不是严格蓝噪声(频谱特性),原因有二:

第一,**生成简单**:Bridson 算法 20 行 C/Rust。蓝噪声通常要 Lloyd 松弛或 void-and-cluster,代码量大。

第二,**等价性**:在 N=64 这种小规模下,Poisson 圆盘的视觉表现和蓝噪声几乎不可区分。蓝噪声的优势在大规模像素采样(N=1000+ per pixel),那不是 Casey 当前场景。

## 3 · 四域深入

### 3.1 · 游戏编程视角

重要性采样是 AAA 游戏引擎的核心技术。每个现代引擎都用:

- **Unreal Engine Lumen**(GI):对每个像素的入射光按 BRDF 形状重要性采样
- **Unity HDRP**: ray-traced reflection 用 BRDF 重要性采样
- **Decima Engine**(Horizon):在 path tracer 里做 MIS

工业坑:**重要性采样失败的场景**。如果你的 BRDF 是 diffuse,重要性采样 (cosine-weighted) 完美。但如果 BRDF 是 glossy(镜面反射),你要按 BRDF 形状采样——这复杂得多,需要 inverse-CDF 方法。

**多重重要性采样(Multiple Importance Sampling, MIS)** 是终极解法:同时用几个分布采样,按"平衡启发式(balance heuristic)"加权。Casey 在 HH 后期 GI 系统会用。今天的 cosine-weighted 是 MIS 的一个分量。

### 3.2 · 图形学视角

数学上,重要性采样改写 Monte Carlo:

```
原版:    ∫ f(ω) dω ≈ (1/N) Σ f(ω_i)              ω_i 均匀采样
重要性:  ∫ f(ω) dω ≈ (1/N) Σ f(ω_i) / p(ω_i)     ω_i ~ p(ω)
```

`p(ω)` 是采样分布的 PDF。如果 `p ∝ f`(完美匹配),方差为 0,一次采样就够。如果 `p` 和 `f` 完全无关(均匀),方差最大。

Lambert 漫反射:`f(ω) = albedo/π * cos(θ)`。让 `p(ω) = cos(θ)/π`,那么 `f/p = albedo`,每个采样贡献相同,**方差=0(对纯 Lambert,完美重要性采样)**。

这就是为什么 Casey 切到 cosine-weighted 后画面"几乎无噪点"——Lambert 部分数学上完美。

进阶术语:
- **Inverse CDF sampling**:已知目标 PDF,通过累计分布函数(CDF)的反函数生成采样
- **Malley 法**:cosine-weighted 的特例,用圆盘到半球几何映射
- **Balance heuristic**:MIS 的标准加权方案
- **Path space regularization**:避免奇异样本(镜面方向的"光斑"伪影)

```bash
R -e "
samples <- read.table('/tmp/samples.tsv', header=TRUE);

# 直方图看 z 分布(应该 ∝ z 即 cos(θ))
hist(z, breaks=20, main='cosine-weighted z histogram');

```

或者用 Python:

```bash
python3 -c "
import numpy as np
import matplotlib.pyplot as plt
data = np.loadtxt('/tmp/samples.tsv', skiprows=1)
z = data[:, 2]
plt.hist(z, bins=20, density=True)
# 理论曲线 PDF(z) = 2z (cosine-weighted 半球上 z 的边缘分布)
```

### 3.4 · Rust 生态视角

Rust 实现余弦加权 + Poisson 圆盘非常简洁。几个特性值得专门讲:

**A. Iterator 链式生成**

```rust
let disk_points: Vec<(f32, f32)> = (0..n)
    .map(|_| random_disk_point(&mut rng))
    .collect();

let hemisphere: Vec<(f32, f32, f32)> = disk_points.iter()
    .map(|&(px, py)| malley_to_hemisphere(px, py))
    .collect();
```

Iterator 是 Rust 零成本抽象——编译器把这条链展开成等价的 for 循环,没有运行时开销。

**B. 拒绝采样(rejection sampling)**

生成单位圆盘上的均匀点:

```rust
fn random_disk_point(rng: &mut impl Rng) -> (f32, f32) {
    loop {
        let x: f32 = rng.gen_range(-1.0..1.0);
        let y: f32 = rng.gen_range(-1.0..1.0);
        if x*x + y*y <= 1.0 {
            return (x, y);
        }
        // 拒绝,重采
    }
}
```

这是经典的"拒绝采样":在正方形 [-1,1]² 上均匀采样,丢弃圆外的点。**期望迭代次数**:`4/π ≈ 1.273` 次(正方形面积 4,圆面积 π)。

**C. Bridson 算法**

工业级 Poisson 圆盘生成。Rust 实现 30 行,但需要 `HashMap<(i32,i32), ()>` 加速邻域查询。crate `poisson` 已经实现好了。

**D. SIMD 友好的批量 Malley**

```rust
fn malley_batch(disk: &[(f32, f32)]) -> Vec<(f32, f32, f32)> {
    disk.iter().map(|&(x, y)| {
        let z = (1.0 - x*x - y*y).max(0.0).sqrt();
        (x, y, z)
    }).collect()
}
```

这里 `sqrt` 是热点。SIMD 化:`_mm256_sqrt_ps` 一次算 8 个 f32。但 N=64 太小,看不出差别。N=1000+ 才值得 SIMD 化。

**真实 crate**:
- `rand`:Rust 标准随机数库
- `poisson`:Bridson 算法实现
- `blue-noise`:Christoph Peters 的工业级蓝噪声
- `rendology::sampling`:封装常见的图形学采样

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 Malley 法(`(x, y, sqrt(1-x²-y²))`)自然产生 cosine-weighted?用 Jacobian 推导解释。

**参考解答**:设圆盘上的均匀密度 `p_disk = 1/π`(单位圆盘内)。Malley 映射 `F: (x, y) -> (x, y, sqrt(1-x²-y²))` 是 1-1 的。半球上的密度:

```
p_hemisphere(x,y,z) = p_disk(x,y) / |Jac(F)|
```

但更直接的方式是用球面坐标。设圆盘上点 (r cos φ, r sin φ),对应半球 (r cos φ, r sin φ, sqrt(1-r²))。半球的立体角元素 `dω = sin(θ) dθ dφ`,其中 `cos(θ) = sqrt(1-r²)`,即 `sin(θ) dθ = r dr`(链式法则,d(cos θ) = -sin θ dθ)。

圆盘面积元素 `dA = r dr dφ`。所以 `dA = sin(θ) dθ dφ = dω * cos(θ)`(因为 dω = sin θ dθ dφ,且我们关心 cos θ = z)。这意味着 `dω = dA / cos(θ)`,即圆盘上密度 1/π 对应半球上密度 `cos(θ) / π`,正好是 cosine-weighted。

### Lv2 · 动手实践

**题**:在 Rust 里实现 Bridson 算法生成 Poisson 圆盘,然后用 Malley 法转成半球,验证 z 分布近似 `2z`(cosine-weighted 边缘 PDF)。

**参考解答**:

```rust
// 简化版 Bridson 算法
use std::collections::HashMap;

fn bridson_poisson_disk(radius: f32, k: u32, seed: u32) -> Vec<(f32, f32)> {
    let cell_size = radius / std::f32::consts::SQRT_2;
    let grid_w = (2.0 / cell_size).ceil() as i32;
    let grid_h = grid_w;
    let mut grid: HashMap<(i32, i32), (f32, f32)> = HashMap::new();
    let mut process: Vec<(f32, f32)> = Vec::new();
    let mut result: Vec<(f32, f32)> = Vec::new();

    let mut rng = seed;
    let next_rand = |r: &mut u32| -> f32 {
        *r ^= *r << 13; *r ^= *r >> 17; *r ^= *r << 5;
        (*r as f32) / (u32::MAX as f32)
    };

    // 第一个点
    let p0 = (next_rand(&mut rng) * 2.0 - 1.0, next_rand(&mut rng) * 2.0 - 1.0);
    let cell0 = ((p0.0 + 1.0) / cell_size, (p0.1 + 1.0) / cell_size);
    grid.insert((cell0.0 as i32, cell0.1 as i32), p0);
    process.push(p0);
    result.push(p0);

    while let Some(p) = process.pop() {
        for _ in 0..k {
            let angle = next_rand(&mut rng) * 2.0 * std::f32::consts::PI;
            let r = radius * (1.0 + next_rand(&mut rng));
            let new_p = (p.0 + r * angle.cos(), p.1 + r * angle.sin());
            if new_p.0 < -1.0 || new_p.0 > 1.0 || new_p.1 < -1.0 || new_p.1 > 1.0 {
                continue;
            }
            if new_p.0*new_p.0 + new_p.1*new_p.1 > 1.0 {
                continue;
            }
            let cell = ((new_p.0 + 1.0) / cell_size, (new_p.1 + 1.0) / cell_size);
            let mut too_close = false;
            for dx in -2..=2 {
                for dy in -2..=2 {
                    if let Some(&neighbor) = grid.get(&(cell.0 as i32 + dx, cell.1 as i32 + dy)) {
                        let d2 = (neighbor.0 - new_p.0).powi(2) + (neighbor.1 - new_p.1).powi(2);
                        if d2 < radius * radius {
                            too_close = true;
                            break;
                        }
                    }
                }
                if too_close { break; }
            }
            if !too_close {
                grid.insert((cell.0 as i32, cell.1 as i32), new_p);
                process.push(new_p);
                result.push(new_p);
            }
        }
    }
    result
}

fn malley(px: f32, py: f32) -> (f32, f32, f32) {
    let z = (1.0_f32 - px * px - py * py).max(0.0).sqrt();
    (px, py, z)
}

fn main() {
    let disk = bridson_poisson_disk(0.15, 30, 42);
    println!("Generated {} Poisson disk points", disk.len());
    let hemisphere: Vec<_> = disk.iter().map(|&(x,y)| malley(x,y)).collect();
    // dump z for histogram
    for (_,_,z) in &hemisphere {
        println!("{}", z);
    }
}
```

### Lv3 · 迁移设计

**题**:把 Malley 法推广到**余弦指数加权**——即 PDF ∝ cos^n(θ) 对任意 n > 0。Lambert 是 n=1,但 glossy 材质 n 可能 5、20、100。提示:需要修改圆盘采样——`(r, φ)` 上 `r = sqrt(u^(2/(n+1)))` 而不是 `r = sqrt(u)`。

**提示**:
- Lambert 圆盘:r = sqrt(u),u 均匀
- 通用:让 r 的 CDF = u,反解出 r
- cos^n(θ) 在 (θ, φ) 空间 PDF 是 (n+1)/(2π) * cos^n(θ)
- CDF = (cos^(n+1)(θ) - 0) / 1,逆:`cos(θ) = u^(1/(n+1))`
- 然后 `r = sin(θ) = sqrt(1 - cos²(θ)) = sqrt(1 - u^(2/(n+1)))`

### Rust 完整可跑示例

把 Lv2 扩展,加上方差对比测试:

```rust
use std::f32::consts::PI;

fn uniform_hemisphere(i: usize, n: usize) -> (f32, f32, f32) {
    // Day 437 公式:z 从 1 到 0 线性
    let z = 1.0 - (i as f32 + 0.5) / n as f32;
    let r = (1.0 - z * z).max(0.0).sqrt();
    let phi = PI * (1.0 + 5.0_f32.sqrt()) * i as f32;
    let (sp, cp) = phi.sin_cos();
    (r * cp, r * sp, z)
}

fn cosine_weighted(i: usize, n: usize) -> (f32, f32, f32) {
    // 把圆盘上等距分布的点 (u, v) 用 Malley 法提升
    // 这里用斐波那契圆盘近似 Poisson
    let r = ((i as f32 + 0.5) / n as f32).sqrt();  // r² 均匀
    let phi = PI * (1.0 + 5.0_f32.sqrt()) * i as f32;
    let x = r * phi.cos();
    let y = r * phi.sin();
    let z = (1.0 - x*x - y*y).max(0.0).sqrt();
    (x, y, z)
}

// 模拟 Lambert 积分:环境贴图常量 1.0
fn lambert_integral(samples: &[(f32,f32,f32)]) -> (f32, f32) {
    // 估计 mean 和 variance
    let n = samples.len() as f32;
    let mut sum = 0.0;
    let mut sum2 = 0.0;
    for &(_, _, z) in samples {
        // Lambert 项 = cos(θ) = z(半球坐标系下)
        let v = z;
        sum += v;
        sum2 += v * v;
    }
    let mean = sum / n;
    let variance = (sum2 / n) - mean * mean;
    (mean, variance)
}

fn main() {
    let n = 64;
    let uniform: Vec<_> = (0..n).map(|i| uniform_hemisphere(i, n)).collect();
    let cosine: Vec<_> = (0..n).map(|i| cosine_weighted(i, n)).collect();

    let (u_mean, u_var) = lambert_integral(&uniform);
    let (c_mean, c_var) = lambert_integral(&cosine);

    println!("Uniform sampling:   mean={:.5}, variance={:.6}", u_mean, u_var);
    println!("Cosine-weighted:    mean={:.5}, variance={:.6}", c_mean, c_var);
    println!("理论值: mean=π/4 ≈ 0.7854 (来自 ∫_hemisphere cos(θ) dω = π)");
    println!("Variance ratio: cosine 应该接近 0(理论为 0)");
}
```

每行解释:
- `uniform_hemisphere` — Day 437 的版本。
- `cosine_weighted` — 圆盘上斐波那契分布,r² 均匀(用 `sqrt`),然后 Malley 法提升。
- `lambert_integral` 计算 `cos(θ)` 的样本均值和方差,理论值 `mean = π/4 ≈ 0.785` (因为 cos 在半球上均值是 π/(2π) = 1/2... 你自己算验证!)。**实际理论 mean 是 1/2**(cos 均匀分布积分),variance 是 `1/3 - 1/4 = 1/12` 对均匀半球。
- 对 cosine-weighted,**每个样本的 Lambert 项都是常数** `1`(因为 `cos(θ) / PDF = cos(θ) / (cos(θ)/π) = π`),所以 variance = 0。
