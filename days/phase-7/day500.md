# Day 500 · 保存在游戏编辑器里修改的 HHA

> Day 500 是里程碑——Casey 用了 500 天从空白项目到这里。今天的具体工作:让 in-game editor 修改的 entity(对齐点、位置等)能保存回 HHA(Handmade Hero Asset)文件,下次启动游戏时加载修改后的内容。

## 0 · 为什么要有这一天

到 Day 499,你的 in-game editor 能:选中 entity、编辑 piece、调整 alignment point。但**改完之后呢?**

如果不保存,改的所有数据在退出游戏时丢失。下次启动又是原始的。这等于没用。

Day 500 解决"保存"问题:把编辑器里改的数据**序列化**回 HHA 文件。这是 Casey 的"工具流"完整闭环:

```
读 HHA → 渲染 → 编辑器修改 → 保存 HHA → 下次启动读新 HHA
```

为什么这件事很难?

第一,**数据格式双向**。HHA 是 HH 自己的二进制资产格式。读它不容易(各种 offset、字段),写回更难(要保持格式正确,不破坏其他数据)。

第二,**热重载兼容**。游戏在跑,你保存 HHA,这时另一个进程在 mmap 这个文件——会发生什么?需要协调。

第三,**版本兼容**。改了 HHA 格式(加字段),旧文件还能读吗?需要 versioning。

第四,**原子性**。保存到一半崩溃,文件可能损坏。需要 atomic write(写临时文件,然后 rename)。

完成这一天,你能:

- 设计二进制文件格式的读写双向
- 实现 atomic write(避免数据损坏)
- 处理版本兼容(migration)
- 理解 mmap 热重载的协调

## 2 · 心智模型

### 类比:Word 文档的保存

Word 文档:你打字 → 文档内存改 → 点保存 → 写硬盘。下次打开 → 读硬盘 → 显示。

如果保存到一半断电,文件损坏——所以 Word 有"临时文件"机制:写 `.docx.tmp`,完成后 rename 成 `.docx`。这就是 atomic write。

Casey Day 500 做的就是 HHA 的"保存"机制,和 Word 同构。

### Atomic Write 的本质

Atomic = 不可分割。要么全部完成,要么完全没做。没有中间状态。

Linux `rename(2)` 系统调用在同一个文件系统内是原子的——内核保证要么旧文件存在,要么新文件存在,不会两者都不存在或都损坏。

利用这个:

```
1. 写新内容到 path.tmp
2. fsync path.tmp(确保磁盘写)
3. rename path.tmp → path
4. fsync path 所在目录(确保 rename 持久)
```

如果任何一步崩溃:

- 步骤 1 崩溃:path 没变,内容是旧的,path.tmp 是部分写的(下次清理)
- 步骤 2 崩溃:同上
- 步骤 3 崩溃:path 可能是旧的或新的(取决于具体时点),但不会损坏

这就是数据库 WAL、git 的 pack file、所有"重要数据"写入的标准做法。

### HHA 文件格式

HH 的二进制资产格式(HHA):

```
+----------------------+
| Magic: "HHA\0"        |   4 bytes
+----------------------+
| Version: u32          |   4 bytes
+----------------------+
| Asset count: u32      |   4 bytes
+----------------------+
| Asset table           |   N * sizeof(AssetEntry)
|  - AssetEntry[0]      |
|  - AssetEntry[1]      |
|  ...                  |
+----------------------+
| Asset data blobs      |
|  - blob[0]            |
|  - blob[1]            |
|  ...                  |
+----------------------+
```

AssetEntry 包含:type、id、offset(指向 blob)、size、metadata。

读 HHA:open file → read header → read asset table → on-demand read blob(用 offset)。

写 HHA:写 header → 写 asset table → 写所有 blob。要保证 offset 正确。

### 序列化的两个方向

**Deserialize(反序列化)**:byte → struct。读文件。

**Serialize(序列化)**:struct → byte。写文件。

这两个必须对称——同一个字段,读时按 type T,写时也按 type T。改了一边忘了另一边,数据损坏。

Rust 用 serde 自动生成两边:

```rust
#[derive(Serialize, Deserialize)]
struct AssetEntry {
    id: u32,
    offset: u64,
    size: u64,
}
```

Casey 手写两边(HH 是 C 项目),因为要精确控制字节布局。

### 版本兼容

文件格式随时间演变。Version 1 → Version 2 加了字段。读老文件怎么办?

```rust
fn read_hha(reader: &mut Reader) -> HhaFile {
    let magic = reader.read_magic();
    let version = reader.read_u32();
    
    match version {
        1 => migrate_v1_to_v2(read_v1(reader)),
        2 => read_v2(reader),
        _ => panic!("unsupported version"),
    }
}
```

Migration(迁移):老版本读入内存,补默认值,变新版本。

工业级格式(SQLite、PostgreSQL)有完整 migration 系统,支持任意版本到任意版本。

```c
int fd = open("file.tmp", O_WRONLY);
write(fd, buf, len);
fsync(fd);        // 数据落盘
```

**rename(2)**:原子改名。

```rust
fn save_atomic<T: Serialize>(path: &Path, data: &T) -> anyhow::Result<()> {

}
```

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么必须用 atomic write,不能直接 `fs::write(path, data)`?

**参考解答**:`fs::write` 直接覆盖目标文件。如果在写的过程中崩溃(断电、kill -9),文件可能:

- 写了一部分,剩字节是旧数据(混合)
- 写了一部分,剩字节是 0(未初始化)
- 完全损坏(文件系统元数据不一致)

任何一种都让文件不可用,下次读失败。如果是关键资产(角色模型、关卡数据),游戏无法启动。

Atomic write 保证:要么文件完整新内容,要么完整旧内容,不会混合。

Linux `rename(2)` 在同文件系统内是原子的——内核用锁保证。所以"写临时文件 → rename" 模式给出原子性。

数据库 WAL、git pack、所有"重要数据"都用这个模式。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:实现最小 HHA-like 格式的 atomic save/load。HHA 包含 header(magic + version)+ N 条 AssetEntry(id + offset + size)。实现 save_atomic 和 load,然后测试 round-trip。

完成标准:`cargo run` 后,save → load → 比对,数据一致。

**参考解答**:

```rust
use std::fs;
use std::io::{Read, Write};
use std::path::Path;

const MAGIC: &[u8; 4] = b"HHA1";
const VERSION: u32 = 1;

#[derive(Debug, PartialEq)]
struct AssetEntry {
    id: u32,
    offset: u64,
    size: u64,
}

#[derive(Debug, PartialEq)]
struct HhaFile {
    version: u32,
    entries: Vec<AssetEntry>,
    blobs: Vec<Vec<u8>>,
}

impl HhaFile {
    fn serialize(&self) -> Vec<u8> {
        let mut buf = Vec::new();
        buf.extend_from_slice(MAGIC);
        buf.extend_from_slice(&self.version.to_le_bytes());
        buf.extend_from_slice(&(self.entries.len() as u32).to_le_bytes());
        
        // 计算每个 blob 的 offset
        let table_size = self.entries.len() * (4 + 8 + 8);
        let data_start = 4 + 4 + 4 + table_size;
        
        let mut current_offset = data_start;
        let mut entries_with_offset = Vec::new();
        for (i, entry) in self.entries.iter().enumerate() {
            entries_with_offset.push(AssetEntry {
                id: entry.id,
                offset: current_offset,
                size: self.blobs[i].len() as u64,
            });
            current_offset += self.blobs[i].len() as u64;
        }
        
        for entry in &entries_with_offset {
            buf.extend_from_slice(&entry.id.to_le_bytes());
            buf.extend_from_slice(&entry.offset.to_le_bytes());
            buf.extend_from_slice(&entry.size.to_le_bytes());
        }
        
        for blob in &self.blobs {
            buf.extend_from_slice(blob);
        }
        
        buf
    }
    
    fn deserialize(data: &[u8]) -> Result<Self, String> {
        if data.len() < 12 { return Err("too short".into()); }
        if &data[0..4] != MAGIC { return Err("bad magic".into()); }
        
        let version = u32::from_le_bytes(data[4..8].try_into().unwrap());
        if version != VERSION { return Err(format!("unsupported version {}", version)); }
        
        let count = u32::from_le_bytes(data[8..12].try_into().unwrap()) as usize;
        let table_size = count * 20;
        
        if data.len() < 12 + table_size { return Err("table truncated".into()); }
        
        let mut entries = Vec::with_capacity(count);
        let mut blobs = Vec::with_capacity(count);
        
        for i in 0..count {
            let base = 12 + i * 20;
            let id = u32::from_le_bytes(data[base..base+4].try_into().unwrap());
            let offset = u64::from_le_bytes(data[base+4..base+12].try_into().unwrap());
            let size = u64::from_le_bytes(data[base+12..base+20].try_into().unwrap());
            
            entries.push(AssetEntry { id, offset, size });
            
            let off = offset as usize;
            let end = off + size as usize;
            if data.len() < end { return Err("blob truncated".into()); }
            blobs.push(data[off..end].to_vec());
        }
        
        Ok(Self { version, entries, blobs })
    }
}

fn save_atomic(path: &Path, file: &HhaFile) -> std::io::Result<()> {
    let data = file.serialize();
    let tmp_path = path.with_extension("hha.tmp");
    
    {
        let mut f = fs::File::create(&tmp_path)?;
        f.write_all(&data)?;
        f.sync_all()?;    // fsync
    }
    
    fs::rename(&tmp_path, path)?;
    
    Ok(())
}

fn load(path: &Path) -> std::io::Result<HhaFile> {
    let mut f = fs::File::open(path)?;
    let mut data = Vec::new();
    f.read_to_end(&mut data)?;
    HhaFile::deserialize(&data).map_err(|e| std::io::Error::new(std::io::ErrorKind::InvalidData, e))
}

fn main() {
    let original = HhaFile {
        version: 1,
        entries: vec![
            AssetEntry { id: 1, offset: 0, size: 0 },  // offset/size 在 serialize 时算
            AssetEntry { id: 2, offset: 0, size: 0 },
        ],
        blobs: vec![
            vec![0xDE, 0xAD, 0xBE, 0xEF],
            vec![0x01, 0x02, 0x03, 0x04, 0x05, 0x06],
        ],
    };
    
    println!("=== Original ===");
    println!("{:?}", original);
    
    let path = std::path::Path::new("/tmp/test.hha");
    save_atomic(path, &original).expect("save");
    println!("\nSaved to {:?}", path);
    
    // hex dump
    let bytes = std::fs::read(path).unwrap();
    print!("Hex dump (first 40 bytes): ");
    for b in bytes.iter().take(40) {
        print!("{:02x} ", b);
    }
    println!();
    
    let loaded = load(path).expect("load");
    println!("\n=== Loaded ===");
    println!("{:?}", loaded);
    
    // Round-trip 验证
    assert_eq!(original.version, loaded.version);
    assert_eq!(original.blobs, loaded.blobs);
    
    println!("\nRound-trip OK!");
}

#[cfg(test)]
mod tests {
    use super::*;
    
    #[test]
    fn test_round_trip() {
        let original = HhaFile {
            version: 1,
            entries: vec![
                AssetEntry { id: 1, offset: 0, size: 0 },
            ],
            blobs: vec![vec![1, 2, 3, 4, 5]],
        };
        
        let bytes = original.serialize();
        let loaded = HhaFile::deserialize(&bytes).unwrap();
        
        assert_eq!(original.version, loaded.version);
        assert_eq!(original.blobs, loaded.blobs);
    }
    
    #[test]
    fn test_bad_magic() {
        let result = HhaFile::deserialize(b"XXXX....");
        assert!(result.is_err());
    }
    
    #[test]
    fn test_atomic_save_to_temp() {
        let path = std::env::temp_dir().join("test_atomic.hha");
        let file = HhaFile {
            version: 1,
            entries: vec![AssetEntry { id: 1, offset: 0, size: 0 }],
            blobs: vec![vec![0xAA; 100]],
        };
        
        save_atomic(&path, &file).unwrap();
        assert!(path.exists());
        // 临时文件应被 rename,不再存在
        let tmp = path.with_extension("hha.tmp");
        assert!(!tmp.exists());
        
        let loaded = load(&path).unwrap();
        assert_eq!(loaded.blobs[0], vec![0xAA; 100]);
        
        std::fs::remove_file(path).ok();
    }
}
```

为什么这么写:`serialize` / `deserialize` 对称。`save_atomic` 用 tempfile + rename + fsync 模式。round-trip 测试确保两边一致。

## 8 · Rust / Arch 落地代码

下面是 Day 500 完整的 HHA atomic save 系统。

```rust
// ============================================================
// Day 500 · 保存在游戏编辑器里修改的 HHA
// ============================================================

use std::fs;
use std::io::{Read, Write};
use std::path::{Path, PathBuf};
use std::fmt;

// ============================================================
// HHA 格式
// ============================================================

const MAGIC: &[u8; 4] = b"HHA2";
const VERSION_CURRENT: u32 = 2;

#[derive(Debug, Clone, PartialEq)]
enum AssetType {
    Bitmap,
    Audio,
    Font,
    Entity,
}

impl AssetType {
    fn to_u32(&self) -> u32 {
        match self {
            AssetType::Bitmap => 1,
            AssetType::Audio => 2,
            AssetType::Font => 3,
            AssetType::Entity => 4,
        }
    }
    
    fn from_u32(v: u32) -> Option<Self> {
        match v {
            1 => Some(AssetType::Bitmap),
            2 => Some(AssetType::Audio),
            3 => Some(AssetType::Font),
            4 => Some(AssetType::Entity),
            _ => None,
        }
    }
}

#[derive(Debug, Clone, PartialEq)]
struct AssetEntry {
    id: u32,
    asset_type: AssetType,
    name: String,
    offset: u64,
    size: u64,
}

#[derive(Debug, Clone, PartialEq)]
struct Vec2 { x: f32, y: f32 }

#[derive(Debug, Clone, PartialEq)]

    name: String,

struct EntityPiece {
    name: String,
    sprite_id: u32,
    offset: Vec2,
    alignment_points: Vec<AlignmentPoint>,
    parent: Option<(u32, String)>,    // (parent index, point name)
}

#[derive(Debug, Clone, PartialEq)]
struct EntityAsset {
    name: String,

    pieces: Vec<EntityPiece>,
}

#[derive(Debug, Clone)]
struct HhaFile {

    entries: Vec<AssetEntry>,
    blobs: Vec<Vec<u8>>,    // 原始 blob,Entity 类型可以解析

// ============================================================
// 序列化 helpers
// ============================================================

trait Writer {
    fn write_u32(&mut self, v: u32);
    fn write_u64(&mut self, v: u64);
    fn write_f32(&mut self, v: f32);
    fn write_string(&mut self, s: &str);
    fn write_bytes(&mut self, b: &[u8]);
}

impl Writer for Vec<u8> {
    fn write_u32(&mut self, v: u32) { self.extend_from_slice(&v.to_le_bytes()); }
    fn write_u64(&mut self, v: u64) { self.extend_from_slice(&v.to_le_bytes()); }
    fn write_f32(&mut self, v: f32) { self.extend_from_slice(&v.to_le_bytes()); }
    fn write_string(&mut self, s: &str) {
        self.write_u32(s.len() as u32);
        self.extend_from_slice(s.as_bytes());
    }
    fn write_bytes(&mut self, b: &[u8]) { self.extend_from_slice(b); }
}

struct Reader<'a> { data: &'a [u8], pos: usize }

impl<'a> Reader<'a> {
    fn new(data: &'a [u8]) -> Self { Self { data, pos: 0 } }
    
    fn read_u32(&mut self) -> Result<u32, String> {
        if self.pos + 4 > self.data.len() { return Err("eof".into()); }
        let v = u32::from_le_bytes(self.data[self.pos..self.pos+4].try_into().unwrap());
        self.pos += 4;
        Ok(v)
    }
    
    fn read_u64(&mut self) -> Result<u64, String> {
        if self.pos + 8 > self.data.len() { return Err("eof".into()); }
        let v = u64::from_le_bytes(self.data[self.pos..self.pos+8].try_into().unwrap());
        self.pos += 8;
        Ok(v)
    }
    
    fn read_f32(&mut self) -> Result<f32, String> {
        if self.pos + 4 > self.data.len() { return Err("eof".into()); }
        let v = f32::from_le_bytes(self.data[self.pos..self.pos+4].try_into().unwrap());
        self.pos += 4;
        Ok(v)
    }
    
    fn read_string(&mut self) -> Result<String, String> {
        let len = self.read_u32()? as usize;
        if self.pos + len > self.data.len() { return Err("string eof".into()); }
        let s = String::from_utf8(self.data[self.pos..self.pos+len].to_vec())
            .map_err(|e| e.to_string())?;
        self.pos += len;
        Ok(s)
    }
    
    fn read_bytes(&mut self, len: usize) -> Result<Vec<u8>, String> {
        if self.pos + len > self.data.len() { return Err("bytes eof".into()); }
        let b = self.data[self.pos..self.pos+len].to_vec();
        self.pos += len;
        Ok(b)
    }
}

fn serialize_entity(entity: &EntityAsset) -> Vec<u8> {
    let mut buf = Vec::new();
    buf.write_string(&entity.name);
    buf.write_f32(entity.world_offset.x);
    buf.write_f32(entity.world_offset.y);
    buf.write_u32(entity.pieces.len() as u32);
    
    for piece in &entity.pieces {
        buf.write_string(&piece.name);
        buf.write_u32(piece.sprite_id);
        buf.write_f32(piece.offset.x);
        buf.write_f32(piece.offset.y);
        buf.write_u32(piece.alignment_points.len() as u32);
        for ap in &piece.alignment_points {
            buf.write_string(&ap.name);
            buf.write_f32(ap.offset.x);
            buf.write_f32(ap.offset.y);
        }
        match &piece.parent {
            None => { buf.write_u32(0); }
            Some((idx, name)) => {
                buf.write_u32(*idx + 1);    // 1-based,0 = none
                buf.write_string(name);
            }
        }
    }
    
    buf
}

fn deserialize_entity(data: &[u8]) -> Result<EntityAsset, String> {
    let mut r = Reader::new(data);
    let name = r.read_string()?;
    let wx = r.read_f32()?;
    let wy = r.read_f32()?;
    let piece_count = r.read_u32()?;
    
    let mut pieces = Vec::with_capacity(piece_count as usize);
    for _ in 0..piece_count {
        let pname = r.read_string()?;
        let sprite_id = r.read_u32()?;
        let px = r.read_f32()?;
        let py = r.read_f32()?;
        let ap_count = r.read_u32()?;
        let mut aps = Vec::with_capacity(ap_count as usize);
        for _ in 0..ap_count {
            let ap_name = r.read_string()?;
            let ax = r.read_f32()?;
            let ay = r.read_f32()?;
            aps.push(AlignmentPoint { name: ap_name, offset: Vec2 { x: ax, y: ay } });
        }
        let parent_idx = r.read_u32()?;
        let parent = if parent_idx == 0 {
            None
        } else {
            let parent_name = r.read_string()?;
            Some((parent_idx - 1, parent_name))
        };
        pieces.push(EntityPiece {
            name: pname, sprite_id, offset: Vec2 { x: px, y: py },
            alignment_points: aps, parent,
        });
    }
    
    Ok(EntityAsset { name, world_offset: Vec2 { x: wx, y: wy }, pieces })
}

// HHA 文件 serialize / deserialize
// ============================================================

impl HhaFile {
    fn serialize(&self) -> Vec<u8> {
        let mut buf = Vec::new();
        buf.extend_from_slice(MAGIC);
        buf.write_u32(self.version);
        buf.write_u32(self.entries.len() as u32);
        
        // 算 offset
        let table_size = self.entries.len() * (4 + 4 + 4 + 8 + 8);    // id + type + name_len + name + offset + size
        // 简化:每个 entry 名字 100 字节,实际应动态
        let mut name_bufs = Vec::new();
        for e in &self.entries {
            let mut nb = Vec::new();
            nb.write_string(&e.name);
            name_bufs.push(nb);
        }
        
        let table_total: usize = self.entries.iter().enumerate()
            .map(|(i, _)| 4 + 4 + name_bufs[i].len() + 8 + 8)
            .sum();
        
        let data_start = 4 + 4 + 4 + table_total;
        let mut current_offset = data_start as u64;
        
        for (i, e) in self.entries.iter().enumerate() {
            buf.write_u32(e.id);
            buf.write_u32(e.asset_type.to_u32());
            buf.extend_from_slice(&name_bufs[i]);
            buf.write_u64(current_offset);
            buf.write_u64(self.blobs[i].len() as u64);
            current_offset += self.blobs[i].len() as u64;
        }
        
        for blob in &self.blobs {
            buf.extend_from_slice(blob);
        }
        
        buf
    }
    
    fn deserialize(data: &[u8]) -> Result<Self, String> {
        let mut r = Reader::new(data);
        
        if r.data.len() < 4 || &r.data[0..4] != MAGIC {
            return Err("bad magic".into());
        }
        r.pos = 4;
        
        let version = r.read_u32()?;
        if version != VERSION_CURRENT {
            return Err(format!("unsupported version: {} (current: {})", version, VERSION_CURRENT));
        }
        
        let count = r.read_u32()? as usize;
        let mut entries = Vec::with_capacity(count);
        
        for _ in 0..count {
            let id = r.read_u32()?;
            let type_u = r.read_u32()?;
            let asset_type = AssetType::from_u32(type_u).ok_or_else(|| format!("bad asset type: {}", type_u))?;
            let name = r.read_string()?;
            let offset = r.read_u64()?;
            let size = r.read_u64()?;
            entries.push(AssetEntry { id, asset_type, name, offset, size });
        }
        
        // 读 blobs
        let mut blobs = Vec::with_capacity(count);
        for e in &entries {
            let off = e.offset as usize;
            let sz = e.size as usize;
            if off + sz > data.len() {
                return Err(format!("blob for id {} out of range", e.id));
            }
            blobs.push(data[off..off+sz].to_vec());
        }
        
        Ok(Self { version, entries, blobs })
    }
}

// ============================================================
// Atomic save
// ============================================================

fn save_atomic(path: &Path, file: &HhaFile) -> std::io::Result<()> {
    let data = file.serialize();
    
    // 步骤 1:写临时文件
    let tmp_path = path.with_extension("hha.tmp");
    {
        let mut f = fs::File::create(&tmp_path)?;
        f.write_all(&data)?;
        f.sync_all()?;    // 步骤 2:fsync
    }
    
    // 步骤 3:原子 rename
    fs::rename(&tmp_path, path)?;
    
    // 步骤 4:fsync 父目录(确保 rename 持久化)
    if let Some(parent) = path.parent() {
        if let Ok(dir) = fs::File::open(parent) {
            let _ = dir.sync_all();
        }
    }
    
    Ok(())
}

fn load(path: &Path) -> std::io::Result<HhaFile> {
    let data = fs::read(path)?;
    HhaFile::deserialize(&data).map_err(|e| std::io::Error::new(std::io::ErrorKind::InvalidData, e))
}

fn main() {
    println!("=============================================\n");

    let hha = make_test_hha();
    println!("=== Original HHA ===");
    for e in &hha.entries {
        println!("  entry id={} type={:?} name={}", e.id, e.asset_type, e.name);
    }
    
    let path = Path::new("/tmp/day500_test.hha");
    save_atomic(path, &hha).expect("save failed");
    println!("\nSaved to {:?}", path);

    let bytes = fs::read(path).unwrap();
    print!("Hex (first 60 bytes): ");
    for b in bytes.iter().take(60) {
        print!("{:02x} ", b);
    }
    println!("...");
    
    let loaded = load(path).expect("load failed");
    println!("\n=== Loaded HHA ===");
    println!("version: {}", loaded.version);
    for (e, blob) in loaded.entries.iter().zip(&loaded.blobs) {
        println!("  entry id={} type={:?} name={} blob_size={}",
                 e.id, e.asset_type, e.name, blob.len());
        if matches!(e.asset_type, AssetType::Entity) {
            let entity = deserialize_entity(blob).unwrap();
            println!("    entity: name={} pieces={}", entity.name, entity.pieces.len());
            for p in &entity.pieces {
                println!("      piece: {}", p.name);
            }
        }
    }
    
    // Round-trip 验证
    println!("\n=== Round-trip 验证 ===");
    let original_entity = deserialize_entity(&hha.blobs[0]).unwrap();
    let loaded_entity = deserialize_entity(&loaded.blobs[0]).unwrap();
    if original_entity == loaded_entity {
        println!("OK: entity 数据 round-trip 一致");
    } else {
        println!("FAIL: 数据不一致");
    }
    
    // 模拟"编辑器修改" → 保存
    println!("\n=== 模拟编辑器修改 → 保存 ===\n");
    let mut modified_entity = deserialize_entity(&loaded.blobs[0]).unwrap();
    // 修改:把 neck 的 offset 从 (0,-20) 改到 (0,-30)
    modified_entity.pieces[0].alignment_points[0].offset.y = -30.0;
    let new_blob = serialize_entity(&modified_entity);
    
    let mut new_hha = loaded.clone();
    new_hha.blobs[0] = new_blob;
    save_atomic(path, &new_hha).expect("save 2");
    println!("Saved modified HHA (neck 从 -20 改到 -30)");
    
    // 重读验证
    let reloaded = load(path).unwrap();
    let reloaded_entity = deserialize_entity(&reloaded.blobs[0]).unwrap();
    let neck_y = reloaded_entity.pieces[0].alignment_points[0].offset.y;
    println!("Reloaded: neck.y = {} (预期 -30)", neck_y);
    
    // 模拟崩溃测试(简化:不真崩,演示临时文件清理)
    println!("\n=== Atomic write 演示 ===");
    println!("临时文件路径: {:?}", path.with_extension("hha.tmp"));
    println!("保存后临时文件存在: {}",
             path.with_extension("hha.tmp").exists());
    
    fs::remove_file(path).ok();
}
```
