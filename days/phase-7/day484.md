### Spritesheet 的标准结构

Spritesheet 是一张大 PNG,内部按网格切分:

```
+------+------+------+------+
| 0,0  | 0,1  | 0,2  | 0,3  |   ← row 0
+------+------+------+------+
| 1,0  | 1,1  | 1,2  | 1,3  |   ← row 1
+------+------+------+------+
| 2,0  | 2,1  | 2,2  | 2,3  |   ← row 2
+------+------+------+------+
```

每个格子是一个 sprite,大小 tile_size × tile_size。像素位置:

```
sprite (row, col) 在大图中的位置:
x = col * tile_size
y = row * tile_size
w = tile_size
h = tile_size
```

这是 **row-major**(行优先)布局——同一行的 sprite 在内存里连续。OpenGL 的纹理也是 row-major。

### 切瓦片的代码

```rust
fn extract_tile(
    src: &[[u8; 4]],
    src_width: usize,
    tile_size: usize,
    row: usize,
    col: usize,
) -> Vec<[u8; 4]> {
    let mut tile = vec![[0u8; 4]; tile_size * tile_size];
    for ly in 0..tile_size {
        for lx in 0..tile_size {
            let sx = col * tile_size + lx;
            let sy = row * tile_size + ly;
            tile[ly * tile_size + lx] = src[sy * src_width + sx];
        }
    }
    tile
}
```

注意 `(col, row)` 不要写反。Casey 在 Day 484 第一次写反了,出现"行 2 列 3 显示成行 3 列 2"。

### Row-major vs Column-major

二维数据在内存里是线性存储,有两种方式:

**Row-major**(行优先,C 风格):

```
矩阵 [3][4]:
[a b c d][e f g h][i j k l]
 ↑ 第 0 行 ↑ ↑ 第 1 行 ↑ ↑ 第 2 行 ↑
```

`a[i][j]` 地址 = `base + i * 4 + j`。同一行的元素连续。

**Column-major**(列优先,Fortran/OpenGL 风格):

```
矩阵 [3][4]:
[a e i][b f j][c g k][d h l]
 ↑ 第 0 列 ↑ ↑ 第 1 列 ↑ ...
```

`a[i][j]` 地址 = `base + j * 3 + i`。同一列的元素连续。

OpenGL 矩阵是 column-major(历史原因),所以 `mat4` 的内存布局是先存第 0 列再存第 1 列。Casey 在 Day 473 改屏幕坐标时遇到过这个坑。

HH 的 spritesheet 用 row-major(像素数据是 row-major),所以 `tile_idx = row * tiles_per_row + col`。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

Spritesheet 是游戏开发的标配。Unity 的 Sprite Atlas、Unreal 的 Paper2D Sprite Sheet、Godot 的 AtlasTexture 都做这件事。

工业级 spritesheet 处理:

- **自动切片**:不固定 tile_size,基于透明像素边界自动识别每个 sprite 的位置(TexturePacker 工具)
- **多分辨率**:同一 spritesheet 输出多份(SD/HD/4K)
- **压缩**:spheresheet 用 ASTC/ETC2 压缩,GPU 直接采样
- **图集打包**:多个小 spritesheet 自动拼成一个大图(基于 bin-packing 算法)

Casey 的固定网格切分是最简版本。理解它,你看 TexturePacker 工具的功能能秒懂。

### 3.2 · 🎨 图形学视角

图形学里 spritesheet / texture atlas 有几个微妙点。

**Padding**:每个 sprite 在 atlas 里留 1-2 像素 padding,避免 linear filter 在 sprite 边缘采样到邻居 sprite 的像素(出现彩色边)。工业 atlas 工具(TexturePacker)默认加 padding。

**Mipmap**:atlas 的 mipmap 难做——不同 sprite 在 mipmap level 2 可能被合并,导致采到错的 sprite。解决:不用 mipmap,或把同类型 sprite 放一起。

**Premultiplied alpha**:atlas 的 alpha 处理。如果某些 sprite 用 pre-alpha,某些不用,渲染会有 seam。统一所有 sprite 用同一种 alpha 处理。

Casey 简化处理,不加 padding,不用 mipmap。后面 Day 480 调试时如果发现 seam,再加 padding。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:Casey 在 Day 484 为什么用 row-major 而不是 column-major 存 spritesheet?

**参考解答**:三个理由:

第一,**像素数据本身就是 row-major**。PNG 文件存储是按行扫描的(第一行像素 → 第二行 → ...),CPU/GPU 内存里也是 row-major。用 row-major index 直接对应像素布局,零转换。

第二,**OpenGL 纹理上传是 row-major**。`glTexImage2D` 期望的像素顺序是 row-major。Casey 的 spritesheet 切分后直接上传,坐标计算和 GL 一致。

第三,**直觉一致**。读 spritesheet 时,人脑也是按行读(行 0 → 行 1 → ...)。row-major 的 `idx = row * cols + col` 符合直觉。

Column-major 适合矩阵运算(OpenGL matrix),不适合 spritesheet。这种"不同场景用不同 layout"是工程权衡。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:实现一个最小 spritesheet importer。给定一张 256×256 假装的大图(用 `[u8; 4]` 数组),tile_size 64,4×4 = 16 个瓦片。提取每个瓦片,给每个瓦片关联 tag(行号决定 group tag,列号决定 frame tag)。

完成标准:`cargo run` 输出 16 个 asset,每个 asset 有正确的 tag。验证:asset (2, 3) 的 tag 是 ["row_2", "col_3", "frame"]。

**参考解答**:

```rust
const SRC_W: usize = 256;
const SRC_H: usize = 256;
const TILE_SIZE: usize = 64;
const COLS: usize = 4;
const ROWS: usize = 4;

#[derive(Debug)]
struct Asset {
    name: String,
    row: usize,
    col: usize,
    tags: Vec<String>,
    pixels: Vec<[u8; 4]>,    // 简化:直接存像素(实际只存 data_offset)
}

// 生成假的大图:每像素颜色按位置编码
fn make_big_image() -> Vec<[u8; 4]> {
    let mut img = vec![[0u8; 4]; SRC_W * SRC_H];
    for y in 0..SRC_H {
        for x in 0..SRC_W {
            img[y * SRC_W + x] = [
                (x % 256) as u8,
                (y % 256) as u8,
                128,
                255,
            ];
        }
    }
    img
}

// 从大图提取瓦片
fn extract_tile(src: &[[u8; 4]], row: usize, col: usize) -> Vec<[u8; 4]> {
    let mut tile = vec![[0u8; 4]; TILE_SIZE * TILE_SIZE];
    for ly in 0..TILE_SIZE {
        for lx in 0..TILE_SIZE {
            let sx = col * TILE_SIZE + lx;
            let sy = row * TILE_SIZE + ly;
            tile[ly * TILE_SIZE + lx] = src[sy * SRC_W + sx];
        }
    }
    tile
}

// 多瓦片导入
fn import_spritesheet(src: &[[u8; 4]]) -> Vec<Asset> {
    let mut assets = Vec::with_capacity(ROWS * COLS);
    
    for row in 0..ROWS {
        for col in 0..COLS {
            let pixels = extract_tile(src, row, col);
            
            // 给瓦片关联 tag
            let tags = vec![
                format!("row_{}", row),
                format!("col_{}", col),
                "frame".to_string(),
                // 第 0 行特殊:加 "idle" tag
                if row == 0 { "idle".to_string() } else { "action".to_string() },
            ];
            
            assets.push(Asset {
                name: format!("tile_{}_{}", row, col),
                row,
                col,
                tags,
                pixels,
            });
        }
    }
    
    assets
}

fn main() {
    let big_img = make_big_image();
    let assets = import_spritesheet(&big_img);
    
    println!("Imported {} assets from spritesheet", assets.len());
    println!();
    
    // 打印前几个 asset
    for a in assets.iter().take(4) {
        println!("Asset {:?}: row={}, col={}, tags={:?}",
                 a.name, a.row, a.col, a.tags);
        // 打印第一个像素,验证提取对
        println!("  first pixel: {:?}", a.pixels[0]);
    }
    println!("...");
    
    // 验证特定 asset
    println!();
    println!("=== 验证 asset (2, 3) ===");
    let asset_2_3 = assets.iter().find(|a| a.row == 2 && a.col == 3).unwrap();
    println!("name = {:?}", asset_2_3.name);
    println!("tags = {:?}", asset_2_3.tags);
    
    // 验证 tag 正确
    assert!(asset_2_3.tags.contains(&"row_2".to_string()));
    assert!(asset_2_3.tags.contains(&"col_3".to_string()));
    assert!(asset_2_3.tags.contains(&"frame".to_string()));
    assert!(asset_2_3.tags.contains(&"action".to_string()));  // row != 0
    println!("All tags verified ✓");
    
    // 模拟 tag 查询
    println!();
    println!("=== 模拟 tag 查询 ===");
    let idle_assets: Vec<&Asset> = assets.iter()
        .filter(|a| a.tags.contains(&"idle".to_string()))
        .collect();
    println!("idle assets: {}", idle_assets.len());   // 应该 4(整个 row 0)
    
    let row_2_assets: Vec<&Asset> = assets.iter()
        .filter(|a| a.tags.contains(&"row_2".to_string()))
        .collect();
    println!("row_2 assets: {}", row_2_assets.len());  // 应该 4
}
```

为什么这么写:`import_spritesheet` 是一个纯函数——输入大图,输出 asset 列表。便于测试。每瓦片关联 tag 时基于位置(`row`、`col`),不需要外部 meta 文件——这是简化。实际工业用 meta 文件描述每瓦片的 tag。

## 8 · Rust / Arch 落地代码

下面是 Day 484 完整的多瓦片导入器 + 调试工具。

```rust
use std::collections::HashMap;
use std::fs;

// ========================================
// Spritesheet 描述文件(meta)解析
// ========================================

#[derive(Debug)]
struct SpritesheetMeta {
    tile_size: usize,
    cols: usize,
    rows: usize,
    tiles: Vec<TileMeta>,
}

#[derive(Debug)]
struct TileMeta {
    row: usize,
    col: usize,
    tags: Vec<String>,
}

impl SpritesheetMeta {
    fn parse(text: &str) -> Result<Self, String> {
        let mut tile_size = 0;
        let mut cols = 0;
        let mut rows = 0;
        let mut tiles = Vec::new();
        
        for line in text.lines() {
            let line = line.trim();
            
            // 跳过空行和注释
            if line.is_empty() || line.starts_with('#') {
                continue;
            }
            
            // 解析 key:value
            if let Some((key, value)) = line.split_once(':') {
                let key = key.trim();
                let value = value.trim();
                
                match key {
                    "tile_size" => tile_size = value.parse()
                        .map_err(|e| format!("tile_size parse: {}", e))?,
                    "cols" => cols = value.parse()
                        .map_err(|e| format!("cols parse: {}", e))?,
                    "rows" => rows = value.parse()
                        .map_err(|e| format!("rows parse: {}", e))?,
                    _ => return Err(format!("unknown key: {}", key)),
                }
            } else if let Some((pos, tags)) = line.split_once(' ') {
                // 格式:row,col: tag1 tag2 tag3
                let pos = pos.trim_end_matches(':');
                let (row_str, col_str) = pos.split_once(',')
                    .ok_or("invalid tile position")?;
                let row: usize = row_str.trim().parse()
                    .map_err(|e| format!("row parse: {}", e))?;
                let col: usize = col_str.trim().parse()
                    .map_err(|e| format!("col parse: {}", e))?;
                
                let tags: Vec<String> = tags.split_whitespace()
                    .map(|s| s.to_string())
                    .collect();
                
                tiles.push(TileMeta { row, col, tags });
            }
        }
        
        if tile_size == 0 || cols == 0 || rows == 0 {
            return Err("missing required fields".to_string());
        }
        
        Ok(SpritesheetMeta { tile_size, cols, rows, tiles })
    }
}

// 多瓦片导入器

#[derive(Debug)]
struct Asset {
    name: String,
    row: usize,
    col: usize,
    tile_idx: usize,           // 在 texture array 的 layer index
    tags: Vec<String>,
}

struct ImportResult {
    assets: Vec<Asset>,
    tile_size: usize,
}

fn import(
    src_width: usize,
    src_height: usize,
    meta: &SpritesheetMeta,
    first_tile_layer: u32,
) -> Result<ImportResult, String> {
    // 验证大图尺寸
    let expected_w = meta.tile_size * meta.cols;
    let expected_h = meta.tile_size * meta.rows;
    if src_width < expected_w || src_height < expected_h {
        return Err(format!(
            "source too small: {}x{} < {}x{}",
            src_width, src_height, expected_w, expected_h
        ));
    }
    
    let mut assets = Vec::new();
    
    for (i, tile_meta) in meta.tiles.iter().enumerate() {
        // 验证 row/col 在范围内
        if tile_meta.row >= meta.rows || tile_meta.col >= meta.cols {
            return Err(format!(
                "tile {} position ({},{}) out of range ({},{})",
                i, tile_meta.row, tile_meta.col, meta.rows, meta.cols
            ));
        }
        
        // tile_idx = row * cols + col(row-major)
        let tile_idx = tile_meta.row * meta.cols + tile_meta.col;
        let layer = first_tile_layer + tile_idx as u32;
        
        assets.push(Asset {
            name: format!("tile_{}_{}", tile_meta.row, tile_meta.col),
            row: tile_meta.row,
            col: tile_meta.col,
            tile_idx: layer as usize,
            tags: tile_meta.tags.clone(),
        });
    }
    
    Ok(ImportResult {
        assets,
        tile_size: meta.tile_size,
    })
}

fn debug_dump_import(result: &ImportResult) {
    println!("=== Import result ===");
    println!("tile_size: {}", result.tile_size);
    println!("asset count: {}", result.assets.len());
    println!();
    
    println!("Assets (first 5):");
    for a in result.assets.iter().take(5) {
        println!("  {:?}: row={}, col={}, layer={}, tags={:?}",
                 a.name, a.row, a.col, a.tile_idx, a.tags);
    }
    if result.assets.len() > 5 {
        println!("  ... and {} more", result.assets.len() - 5);
    }
    
    // 验证:asset 数量应该等于 meta 描述的 tile 数
    println!();
    println!("Sanity check:");
    let unique_positions: std::collections::HashSet<(usize, usize)> = 
        result.assets.iter().map(|a| (a.row, a.col)).collect();
    println!("  unique (row, col) pairs: {}", unique_positions.len());
    println!("  total assets: {}", result.assets.len());
    if unique_positions.len() != result.assets.len() {
        println!("  ⚠ WARNING: duplicate positions detected!");
    }
}

mod tests {
    use super::*;
    
    #[test]
    fn test_meta_parse() {
        let text = "tile_size: 32\ncols: 4\nrows: 2\n0,0: a b\n1,3: c d e\n";
        let meta = SpritesheetMeta::parse(text).unwrap();
        assert_eq!(meta.tile_size, 32);
        assert_eq!(meta.cols, 4);
        assert_eq!(meta.rows, 2);
        assert_eq!(meta.tiles.len(), 2);
        assert_eq!(meta.tiles[0].row, 0);
        assert_eq!(meta.tiles[0].col, 0);
        assert_eq!(meta.tiles[0].tags, vec!["a", "b"]);
        assert_eq!(meta.tiles[1].row, 1);
        assert_eq!(meta.tiles[1].col, 3);
    }
    
    #[test]
    fn test_row_major_index() {
        let meta_text = "tile_size: 8\ncols: 4\nrows: 4\n";
        let meta = SpritesheetMeta::parse(meta_text).unwrap();
        let result = import(32, 32, &meta, 0).unwrap();
        // 没 tile meta,assets 是空
        assert_eq!(result.assets.len(), 0);
    }
    
    #[test]
    fn test_import_with_tiles() {
        let meta_text = "tile_size: 8\ncols: 4\nrows: 4\n0,0: t1\n0,1: t2\n";
        let meta = SpritesheetMeta::parse(meta_text).unwrap();
        let result = import(32, 32, &meta, 100).unwrap();
        
        assert_eq!(result.assets.len(), 2);
        // tile_idx = row * cols + col
        assert_eq!(result.assets[0].tile_idx, 100);  // (0,0) → idx 0 + 100
        assert_eq!(result.assets[1].tile_idx, 101);  // (0,1) → idx 1 + 100
    }
    
    #[test]
    fn test_out_of_range() {
        let meta_text = "tile_size: 8\ncols: 4\nrows: 4\n5,5: x\n";
        let meta = SpritesheetMeta::parse(meta_text).unwrap();
        let result = import(32, 32, &meta, 0);
        assert!(result.is_err());
    }
```
