# Day 574 · 实验体素滤镜

> Day 573 接通管线后,光照有些"噪声"——单 voxel 跳变、propagation 锯齿。Day 574 Casey 试**体素滤镜(voxel filters)**——blur / bilateral / median,平滑光照。

## 0 · 为什么要有这一天

voxel grid 的噪声来源:

- **propagation 累积误差**:每步 propagation 用邻居平均,但邻居 6 个 vs 26 个(只用面邻居 vs 含边/角邻居)选择不同,产生方格 pattern
- **光源边界**:光源 voxel 边界 abrupt,采样新 voxel 时颜色跳
- **raycast 随机性**:probe raycast 用伪随机方向,帧间抖动

视觉表现:墙上出现"棋盘格"光照 / 光源附近闪烁 / 移动相机时反射抖。

修复:**filter**(滤镜)voxel grid——平滑数据。

几种 filter:

- **Box blur**:平均邻居(简单,模糊)
- **Gaussian blur**:加权平均(平滑,自然)
- **Bilateral filter**:平均 + 保边(去噪但保边界)
- **Median filter**:取中位数(去椒盐噪声)

每种适用不同噪声。Casey 这天试几个,选最适合 GI 的。

完成这一天之后,你具备:

- 理解 image / voxel filtering
- 能实现 bilateral / median filter
- 知道 filter 在 GI 里的应用

## 1 · Casey 今天做了什么

Casey 的实验:

第一步,实现 **3D box blur**——每 voxel 取 3³ = 27 邻居平均。简单但模糊光源。

## 2 · 心智模型

### 类比:照片的"美颜滤镜"

你拍的自拍有"颗粒"(噪声),用美颜滤镜:

- **简单 blur**:把所有像素平均,皮肤光滑——但眼睛也模糊(失细节)
- **保边 blur**(bilateral):皮肤平均,眼睛边界保留——既光滑又清晰
- **时序累积**(多帧合成):用 N 帧照片平均,随机噪声相互抵消

voxel filter 完全一样。Box blur 模糊一切,bilateral 保边,temporal 去抖。

### 严谨展开:3D box blur

```rust
fn box_blur_3d(grid: &mut VoxelGrid, radius: usize) {
    let dim = grid.dim;
    let snapshot = grid.data.clone();

    for k in 0..dim {
        for j in 0..dim {
            for i in 0..dim {
                let mut sum = [0.0f32; 3];
                let mut count = 0;
                for dk in -(radius as i64)..=(radius as i64) {
                    for dj in -(radius as i64)..=(radius as i64) {
                        for di in -(radius as i64)..=(radius as i64) {
                            let ni = (i as i64 + di) as usize;
                            let nj = (j as i64 + dj) as usize;
                            let nk = (k as i64 + dk) as usize;
                            if ni < dim && nj < dim && nk < dim {
                                let v = snapshot[(nk * dim + nj) * dim + ni];
                                sum[0] += v.light[0];
                                sum[1] += v.light[1];
                                sum[2] += v.light[2];
                                count += 1;
                            }
                        }
                    }
                }
                let idx = (k * dim + j) * dim + i;
                grid.data[idx].light = [
                    sum[0] / count as f32,
                    sum[1] / count as f32,
                    sum[2] / count as f32,
                ];
            }
        }
    }
}
```

3x3x3 box blur = 27 邻居平均。简单但模糊。

### Bilateral filter(保边)

加权平均,权重 = 空间邻近性 * 颜色相似性:

```rust
fn bilateral_filter(
    grid: &mut VoxelGrid,
    spatial_radius: usize,
    color_sigma: f32,
) {
    let dim = grid.dim;
    let snapshot = grid.data.clone();

    for k in 0..dim {
        for j in 0..dim {
            for i in 0..dim {
                let center = snapshot[(k * dim + j) * dim + i];
                let mut sum_w = [0.0f32; 3];
                let mut total_w = 0.0;

                for dk in -(spatial_radius as i64)..=(spatial_radius as i64) {
                    for dj in -(spatial_radius as i64)..=(spatial_radius as i64) {
                        for di in -(spatial_radius as i64)..=(spatial_radius as i64) {
                            let ni = (i as i64 + di) as usize;
                            let nj = (j as i64 + dj) as usize;
                            let nk = (k as i64 + dk) as usize;
                            if ni >= dim || nj >= dim || nk >= dim { continue; }
                            let n = snapshot[(nk * dim + nj) * dim + ni];

                            // 颜色相似性(差异大 → 权重小)
                            let color_diff = (
                                (n.light[0] - center.light[0]).abs() +
                                (n.light[1] - center.light[1]).abs() +
                                (n.light[2] - center.light[2]).abs()
                            ) / 3.0;
                            let weight = (-color_diff * color_diff / (2.0 * color_sigma * color_sigma)).exp();

                            sum_w[0] += n.light[0] * weight;
                            sum_w[1] += n.light[1] * weight;
                            sum_w[2] += n.light[2] * weight;
                            total_w += weight;
                        }
                    }
                }

                let idx = (k * dim + j) * dim + i;
                grid.data[idx].light = [
                    sum_w[0] / total_w,
                    sum_w[1] / total_w,
                    sum_w[2] / total_w,
                ];
            }
        }
    }
}
```

`color_sigma` 控制颜色容忍度——sigma 大,容忍大差异(更模糊);sigma 小,只平均相似颜色(保边强)。

### Temporal filter

```rust
fn temporal_filter(
    current: &mut VoxelGrid,
    previous: &VoxelGrid,
    alpha: f32,  // 0..1,当前帧权重
) {
    for i in 0..current.data.len() {
        let c = current.data[i].light;
        let p = previous.data[i].light;
        current.data[i].light = [
            c[0] * alpha + p[0] * (1.0 - alpha),
            c[1] * alpha + p[1] * (1.0 - alpha),
            c[2] * alpha + p[2] * (1.0 - alpha),
        ];
    }
}
```

`alpha = 0.2`:当前帧 20%,上一帧 80%——平滑,但响应慢。`alpha = 0.5`:平衡。`alpha = 1.0`:不用 temporal(纯当前帧)。

## 3 · 四域深入

### 3.1 · 游戏编程视角

Filter 在游戏:

- **TAA(Temporal AA)**:时序 filter 抗锯齿
- **Bloom**:blur 高亮区域
- **SSAO / SSAO denoising**:filter 噪声
- **GI denoising**(SVGF):spatial + temporal + bilateral

工业 GI 几乎都加 denoising filter——raycast 输出噪声,filter 后干净。

### 3.2 · 图形学视角

Filter 的数学:**convolution(卷积)**。

```
(f * g)(x) = ∫ f(y) g(x - y) dy
```

Box blur 的 kernel:`g(x) = 1/N`(均匀)。Gaussian: `g(x) = exp(-x² / 2σ²)`。Bilateral: `g` 依赖 f 值(非线性)。

3D voxel filter 是 2D image filter 的扩展——卷积核是 3D。

### 3.3 · Linux 系统编程视角

Filter 在 OS / 信号处理:

- **Low-pass filter**(DSP):去高频
- **EMA(exponential moving average)**:时序数据平滑
- **Kalman filter**:最优估计(控制理论)
- **Median filter**:统计去噪

EMA 是 temporal filter 的特例(`alpha` 是衰减系数)。

### 3.4 · Rust 生态视角

Rust image filter:

### Lv1 · 概念辨析

**题**:box blur 和 bilateral 的区别?bilateral 为什么"保边"?

**参考解答**:Box blur 平均所有邻居,权重均匀——包括"边界另一侧"的 voxel(颜色不同)。结果边界被平均,模糊。Bilateral 额外乘"颜色相似性"权重——邻居颜色差异大(说明它在边界另一侧),权重低,不参与平均。结果只有"同侧"邻居参与平均,边界保留。

## 8 · Rust / Arch 落地代码

完整 voxel filter + temporal:

```rust
type V3 = [f32; 3];

#[derive(Clone, Copy, Default, Debug)]
struct Voxel { light: V3, occupied: bool }

struct VoxelGrid {
    data: Vec<Voxel>,
    dim: usize,
}

impl VoxelGrid {
    fn new(dim: usize) -> Self {
        VoxelGrid { data: vec![Voxel::default(); dim*dim*dim], dim }
    }
    fn idx(&self, i: usize, j: usize, k: usize) -> usize {
        (k * self.dim + j) * self.dim + i
    }
    fn get(&self, i: usize, j: usize, k: usize) -> Voxel { self.data[self.idx(i, j, k)] }
    fn set(&mut self, i: usize, j: usize, k: usize, v: Voxel) {
        self.data[self.idx(i, j, k)] = v;
    }
    fn clone_data(&self) -> Self {
        VoxelGrid { data: self.data.clone(), dim: self.dim }
    }
}

// Box blur(spatial)
fn box_blur(grid: &mut VoxelGrid, radius: usize) {
    let dim = grid.dim;
    let snapshot = grid.data.clone();
    for k in 0..dim { for j in 0..dim { for i in 0..dim {
        let mut sum = [0.0f32; 3];
        let mut count = 0;
        for dk in -(radius as i64)..=(radius as i64) {
            for dj in -(radius as i64)..=(radius as i64) {
                for di in -(radius as i64)..=(radius as i64) {
                    let ni = (i as i64 + di) as usize;
                    let nj = (j as i64 + dj) as usize;
                    let nk = (k as i64 + dk) as usize;
                    if ni < dim && nj < dim && nk < dim {
                        let v = snapshot[(nk * dim + nj) * dim + ni];
                        if !v.occupied {  // 不 blur 墙
                            sum[0] += v.light[0];
                            sum[1] += v.light[1];
                            sum[2] += v.light[2];
                            count += 1;
                        }
                    }
                }
            }
        }
        let idx = (k * dim + j) * dim + i;
        if count > 0 && !grid.data[idx].occupied {
            grid.data[idx].light = [
                sum[0] / count as f32,
                sum[1] / count as f32,
                sum[2] / count as f32,
            ];
        }
    }}}
}

// Bilateral filter(保边)
fn bilateral(grid: &mut VoxelGrid, radius: usize, sigma: f32) {
    let dim = grid.dim;
    let snapshot = grid.data.clone();
    for k in 0..dim { for j in 0..dim { for i in 0..dim {
        let center_idx = (k * dim + j) * dim + i;
        let center = snapshot[center_idx];
        if center.occupied { continue; }  // 不处理墙

        let mut sum = [0.0f32; 3];
        let mut total_w = 0.0;
        for dk in -(radius as i64)..=(radius as i64) {
            for dj in -(radius as i64)..=(radius as i64) {
                for di in -(radius as i64)..=(radius as i64) {
                    let ni = (i as i64 + di) as usize;
                    let nj = (j as i64 + dj) as usize;
                    let nk = (k as i64 + dk) as usize;
                    if ni >= dim || nj >= dim || nk >= dim { continue; }
                    let n = snapshot[(nk * dim + nj) * dim + ni];
                    if n.occupied { continue; }
                    let diff = ((n.light[0] - center.light[0]).abs()
                              + (n.light[1] - center.light[1]).abs()
                              + (n.light[2] - center.light[2]).abs()) / 3.0;
                    let weight = (-diff * diff / (2.0 * sigma * sigma)).exp();
                    sum[0] += n.light[0] * weight;
                    sum[1] += n.light[1] * weight;
                    sum[2] += n.light[2] * weight;
                    total_w += weight;
                }
            }
        }
        if total_w > 0.0 {
            grid.data[center_idx].light = [
                sum[0] / total_w,
                sum[1] / total_w,
                sum[2] / total_w,
            ];
        }
    }}}
}

// Temporal filter(帧间混合)
fn temporal_filter(
    current: &mut VoxelGrid,
    previous: &VoxelGrid,
    alpha: f32,
) {
    for i in 0..current.data.len() {
        let c = current.data[i].light;
        let p = previous.data[i].light;
        current.data[i].light = [
            c[0] * alpha + p[0] * (1.0 - alpha),
            c[1] * alpha + p[1] * (1.0 - alpha),
            c[2] * alpha + p[2] * (1.0 - alpha),
        ];
    }
}

fn main() {
    let mut grid = VoxelGrid::new(8);
    // 放一些 voxel 光照(模拟 propagation 后)
    grid.set(4, 4, 4, Voxel { light: [10.0; 3], occupied: false });
    grid.set(5, 4, 4, Voxel { light: [8.0; 3], occupied: false });
    grid.set(4, 5, 4, Voxel { light: [7.0; 3], occupied: false });
    grid.set(6, 6, 6, Voxel { light: [1.0; 3], occupied: false });
    // 墙
    grid.set(0, 4, 4, Voxel { light: [0.0; 3], occupied: true });

    println!("Before filter:");
    for pos in [(4, 4, 4), (5, 4, 4), (4, 5, 4), (3, 4, 4), (6, 6, 6)] {
        let v = grid.get(pos.0, pos.1, pos.2);
        println!("  {:?}: light=({:.2},{:.2},{:.2}) occupied={}",
            pos, v.light[0], v.light[1], v.light[2], v.occupied);
    }

    // Box blur
    let mut g1 = grid.clone_data();
    box_blur(&mut g1, 1);
    println!("\nAfter box blur:");
    for pos in [(4, 4, 4), (5, 4, 4), (3, 4, 4)] {
        let v = g1.get(pos.0, pos.1, pos.2);
        println!("  {:?}: light=({:.2},{:.2},{:.2})", pos, v.light[0], v.light[1], v.light[2]);
    }

    // Bilateral
    let mut g2 = grid.clone_data();
    bilateral(&mut g2, 1, 2.0);
    println!("\nAfter bilateral:");
    for pos in [(4, 4, 4), (5, 4, 4), (3, 4, 4)] {
        let v = g2.get(pos.0, pos.1, pos.2);
        println!("  {:?}: light=({:.2},{:.2},{:.2})", pos, v.light[0], v.light[1], v.light[2]);
    }

    // Temporal
    let previous = grid.clone_data();
    let mut g3 = grid.clone_data();
    temporal_filter(&mut g3, &previous, 0.5);
    println!("\nAfter temporal (alpha=0.5, 自身 = 应不变):");
    for pos in [(4, 4, 4)] {
        let v = g3.get(pos.0, pos.1, pos.2);
        println!("  {:?}: light=({:.2},{:.2},{:.2})", pos, v.light[0], v.light[1], v.light[2]);
    }
}
```

GPU filter shader:

```wgsl
// Bilateral filter compute shader
@group(0) @binding(0) var voxel_tex: texture_3d<f32>;
@group(0) @binding(1) var output_tex: texture_storage_3d<rgba8unorm, write>;

@compute @workgroup_size(4, 4, 4)
fn bilateral_cs(
    @builtin(global_invocation_id) gid: vec3<u32>,
) {
    let center = textureLoad(voxel_tex, gid, 0);
    var sum = vec4<f32>(0.0);
    var total_w = 0.0;

    for (var dk = -1; dk <= 1; dk = dk + 1) {
        for (var dj = -1; dj <= 1; dj = dj + 1) {
            for (var di = -1; di <= 1; di = di + 1) {
                let offset = vec3<i32>(di, dj, dk);
                let n = textureLoad(voxel_tex, vec3<i32>(gid) + offset, 0);
                let diff = abs(n.rgb - center.rgb);
                let weight = exp(-dot(diff, diff) / (2.0 * 2.0 * 2.0));
                sum += n * vec4(weight, weight, weight, 1.0);
                total_w += weight;
            }
        }
    }

    textureStore(output_tex, gid, sum / total_w);
}
```
