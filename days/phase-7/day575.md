## 2 · 心智模型

### 类比:网页开发的 "live reload"

前端开发有 "live reload"——你改 .css / .js,浏览器自动刷新。这把"改代码 → 切到浏览器 → 刷新"循环从几秒变成"眨眼"。

游戏开发的 hot reload 类似——改游戏代码或 asset,游戏立刻反映。开发节奏 10 倍快。

Casey 这天把"只热重载代码"扩展到"热重载一切",实现完整 hot reload 体验。

### 严谨展开:Linux inotify

Linux 用 inotify(inode notify)监控文件变化:

```rust
use inotify::{Inotify, EventMask, WatchMask};

let mut inotify = Inotify::init()?;
let watch_handle = inotify.watches().add(
    "assets/textures/",
    WatchMask::MODIFY | WatchMask::CLOSE_WRITE | WatchMask::CREATE,
)?;

let mut buffer = [0u8; 4096];
loop {
    let events = inotify.read_events_blocking(&mut buffer)?;
    for event in events {
        if event.mask.contains(EventMask::CLOSE_WRITE) {
            println!("File changed: {:?}", event.name);
            // 触发 reload
            reload_asset(&event.name.unwrap());
        }
    }
}
```

inotify 在内核里维护 watch list,文件变化时内核把事件放入 queue,用户态 read。零开销,实时。

### Asset reload 状态机

每个 asset 有状态:

```rust
enum AssetState {
    Unloaded,
    Loaded(AssetData),
    Outdated,  // 文件变了,需要 reload
}

struct Asset {
    path: PathBuf,
    state: AssetState,
    last_mtime: SystemTime,
}

impl Asset {
    fn check_reload(&mut self) {
        let mtime = std::fs::metadata(&self.path).unwrap().modified().unwrap();
        if mtime != self.last_mtime {
            self.state = AssetState::Outdated;
            self.last_mtime = mtime;
        }
    }

    fn reload(&mut self) {
        if let AssetState::Outdated = self.state {
            let data = load_asset(&self.path);
            self.state = AssetState::Loaded(data);
        }
    }
}
```

每帧 check_reload 所有 asset,如果 outdated,异步 reload。

### Shader reload

Shader reload 比较麻烦——GPU pipeline state 不能直接替换。需要:

```rust
struct Shader {
    source_path: PathBuf,
    pipeline: Option<wgpu::RenderPipeline>,
}

impl Shader {
    fn reload(&mut self, device: &wgpu::Device) {
        // 读新源码
        let source = std::fs::read_to_string(&self.source_path).unwrap();
        let module = device.create_shader_module(wgpu::ShaderModuleDescriptor {
            source: wgpu::ShaderSource::Wgsl(source.into()),
            label: None,
        });
        // 重建 pipeline
        let new_pipeline = device.create_render_pipeline(&wgpu::RenderPipelineDescriptor {
            vertex: wgpu::VertexState {
                module: &module,
                entry_point: "vs_main",
                buffers: &[],
            },
            // ...
            label: None,
        });
        self.pipeline = Some(new_pipeline);
        // 老 pipeline 在 GPU 用完时自动 drop
    }
}
```

每帧检查 shader 文件 mtime,变了就 reload。

### 3.2 · 图形学视角

Shader hot reload 的难点:

- **Pipeline state**:GPU state 不能原子替换,要等当前帧完成
- **Bind group**:变了 shader,binding 可能不兼容
- **Specialization constants**:WGSL 的 const 改变要重 compile

解决:用 double-buffering shader——老 pipeline 用到完,新 pipeline 替换。

### 3.3 · Linux 系统编程视角

inotify 是 Linux 标准。其他 OS:

- **macOS**:FSEvents
- **Windows**:ReadDirectoryChangesW
- **BSD / cross-OS**:`notify` crate(Rust 跨平台)

`notify` crate 包装所有平台:

```rust
use notify::{Watcher, RecursiveMode, watcher};

let (tx, rx) = std::sync::mpsc::channel();
let mut watcher = watcher(tx, std::time::Duration::from_secs(1)).unwrap();
watcher.watch("assets/", RecursiveMode::Recursive).unwrap();

for event in rx {
    println!("{:?}", event);
}
```

跨平台 hot reload 用 notify 简单。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 shader hot reload 比 code hot reload 复杂?

**参考解答**:Code hot reload 是替换函数指针——简单。Shader hot reload 要重建 GPU pipeline state——pipeline 是不可变的(创建后不能改),要创建新 pipeline 替换旧。但旧 pipeline 可能正在被当前帧用,不能立刻 drop——要等帧结束。所以 shader hot reload 用 double-buffer:新 pipeline 准备好,等帧结束 swap。代码 hot reload 没这问题(代码可以原子替换)。

### Lv2 · 动手实践

**题**:用 notify crate 监控目录,实现 asset reload。

要求:
- 创建 /tmp/test_assets/ 目录
- 写一个文件 foo.txt
- 用 notify 监控
- 改 foo.txt 内容
- 验证 watcher 收到事件

**参考解答**:

```rust
// Cargo.toml: notify = "6"

use notify::{Watcher, RecursiveMode, EventKind, Config};
use std::sync::mpsc::channel;
use std::time::Duration;

fn main() {
    std::fs::create_dir_all("/tmp/test_assets").ok();
    std::fs::write("/tmp/test_assets/foo.txt", "initial content").unwrap();

    let (tx, rx) = channel();
    let mut watcher = notify::recommended_watcher(|res: Result<notify::Event, _>| {
        if let Ok(event) = res {
            tx.send(event).unwrap();
        }
    }).unwrap();

    watcher.watch(std::path::Path::new("/tmp/test_assets"), RecursiveMode::Recursive).unwrap();

    println!("Watching /tmp/test_assets/. Modify foo.txt to test.");
    println!("Press Ctrl+C to stop.\n");

    // 子线程:5 秒后修改文件
    std::thread::spawn(|| {
        std::thread::sleep(Duration::from_secs(2));
        std::fs::write("/tmp/test_assets/foo.txt", "modified content").unwrap();
        println!("[thread] Modified foo.txt");
    });

    for event in rx {
        match event.kind {
            EventKind::Modify(_) | EventKind::Create(_) | EventKind::Access(_) => {
                println!("Event: {:?} paths={:?}", event.kind, event.paths);
            }
            _ => {}
        }
    }
}
```

## 8 · Rust / Arch 落地代码

完整 hot reload 系统:

```rust
use std::collections::HashMap;
use std::path::{Path, PathBuf};
use std::time::SystemTime;

// Asset 类型
#[derive(Clone, Copy, PartialEq)]
enum AssetKind {
    Texture,
    Shader,
    Json,
    Mesh,
}

struct Asset {
    path: PathBuf,
    kind: AssetKind,
    last_mtime: SystemTime,
    // 实际还有 data / GPU handle,简化
}

struct AssetManager {
    assets: HashMap<PathBuf, Asset>,
    watch_dir: PathBuf,
}

impl AssetManager {
    fn new(watch_dir: &Path) -> Self {
        AssetManager {
            assets: HashMap::new(),
            watch_dir: watch_dir.to_path_buf(),
        }
    }

    fn register(&mut self, path: &Path, kind: AssetKind) {
        let mtime = std::fs::metadata(path)
            .and_then(|m| m.modified())
            .unwrap_or(SystemTime::UNIX_EPOCH);
        self.assets.insert(path.to_path_buf(), Asset {
            path: path.to_path_buf(),
            kind,
            last_mtime: mtime,
        });
    }

    fn check_reloads(&mut self) -> Vec<PathBuf> {
        let mut reloaded = Vec::new();
        for asset in self.assets.values_mut() {
            let current_mtime = std::fs::metadata(&asset.path)
                .and_then(|m| m.modified())
                .unwrap_or(SystemTime::UNIX_EPOCH);
            if current_mtime != asset.last_mtime {
                println!("[reload] {:?} (kind={:?})", asset.path, asset.kind);
                asset.last_mtime = current_mtime;
                reloaded.push(asset.path.clone());
                // 实际:根据 kind 调不同 reload 函数
                //   Texture → 重新 decode + update GPU texture
                //   Shader → 重新 compile + 重建 pipeline
                //   Json → 重新 parse + 更新 entity data
            }
        }
        reloaded
    }
}

// 简化版 inotify polling(实际用 notify crate 异步)
fn poll_files(manager: &mut AssetManager) {
    loop {
        let reloaded = manager.check_reloads();
        if !reloaded.is_empty() {
            println!("Reloaded {} assets", reloaded.len());
        }
        std::thread::sleep(std::time::Duration::from_millis(100));
    }
}

fn main() {
    // 演示用:创建临时 asset 目录
    let dir = std::env::temp_dir().join("handmade_hero_assets");
    std::fs::create_dir_all(&dir).unwrap();
    let tex_path = dir.join("texture.png");
    let shader_path = dir.join("shader.wgsl");
    let json_path = dir.join("level.json");

    std::fs::write(&tex_path, b"fake png").unwrap();
    std::fs::write(&shader_path, b"fake shader").unwrap();
    std::fs::write(&json_path, b"{}").unwrap();

    let mut manager = AssetManager::new(&dir);
    manager.register(&tex_path, AssetKind::Texture);
    manager.register(&shader_path, AssetKind::Shader);
    manager.register(&json_path, AssetKind::Json);

    println!("Asset manager watching {} files", manager.assets.len());

    // 模拟"另一线程"修改文件
    let tex_path_clone = tex_path.clone();
    let shader_path_clone = shader_path.clone();
    std::thread::spawn(move || {
        std::thread::sleep(std::time::Duration::from_millis(300));
        std::fs::write(&tex_path_clone, b"modified png content").ok();
        println!("[other thread] Modified texture");

        std::thread::sleep(std::time::Duration::from_millis(300));
        std::fs::write(&shader_path_clone, b"new shader code").ok();
        println!("[other thread] Modified shader");
    });

    // Poll 1 秒(模拟游戏主循环的 reload 检查)
    for _ in 0..10 {
        let reloaded = manager.check_reloads();
        if !reloaded.is_empty() {
            println!("Reloaded: {:?}", reloaded);
        }
        std::thread::sleep(std::time::Duration::from_millis(100));
    }

    // 清理
    let _ = std::fs::remove_dir_all(&dir);

    // === M8 总结 ===
    println!("\n=== M8 Milestone Summary ===");
    println!("Phase 7 (Day 436-575) - 140 days - complete:");
    println!();
    println!("  Day 436-440: Asset pipeline foundation (PNG, sampling)");
    println!("  Day 441-452: World generator (rooms, connections)");
    println!("  Day 453-462: Hand-written PNG decoder");
    println!("  Day 463-470: HHA asset format");
    println!("  Day 471-510: Asset loading & bitmap ops");
    println!("  Day 511-540: Editor UI (immediate mode, undo/redo)");
    println!("  Day 541-546: Memory viz & mipmap");
    println!("  Day 547-575: Light probe / Voxel GI (28 days)");
    println!();
    println!("  Final: light probes + editor + world generator");
    println!("  Hot reload generalized to all assets");
}
```
