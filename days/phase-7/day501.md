
# Day 501 · 导入孤立资产

> HHA 文件存了"标准"资产,但开发者硬盘上还有大量 .png / .wav 没被 HHA 索引——这些叫"orphans"(孤立资产)。Day 501 给编辑器加"导入 orphan"功能:扫描文件夹,自动把没在 HHA 的素材导入。

## 0 · 为什么要有这一天

HH 的资产管线:

```
原始素材(.png / .wav)
    ↓ 导入器(import)
HHA 文件(二进制)
    ↓ 加载器(load)
游戏运行时
```

问题:开发者放下一个新 sprite `hero.png`,但忘了运行 import 命令。这个 sprite 就是 **orphan**(孤儿)——在硬盘上但 HHA 不知道。

Day 501 解决:**编辑器自动扫描文件夹,找出 orphan,提供"导入"按钮**。一键把 orphan 加入 HHA。

为什么重要?

- 工作流加速:美术把文件丢进 assets/,游戏自动识别
- 减少错误:不会忘导入,游戏里突然缺资产
- 可视化:编辑器列出 orphan,选择导入哪些

工业级游戏引擎都有这功能。Unity 的 "Import New Asset",Unreal 的 "Reimport",Godot 的 "Import" 系统。

完成这一天,你能:

- 实现文件夹扫描(walk 目录)
- 对比两个集合找出"差集"
- 设计"批量导入"工作流
- 处理资产命名冲突

## 2 · 心智模型

### 类比:图书馆采购新书

图书馆(= HHA)有书单(= asset table)。新到的书(= orphan)还在大堂,没进书单。

图书管理员每天扫大堂,对比书单,把新书标记为"待入库"。

Casey 的 orphan import 就是这个过程。

### 集合运算:差集

数学定义:`A - B = { x in A | x not in B }`。

Orphan = 硬盘文件集 - HHA 资产集。

实现:用 HashSet,O(1) 查询。

```rust
let on_disk: HashSet<String> = scanned.into_iter().collect();
let in_hha: HashSet<String> = hha_entries.into_iter().collect();
let orphans: Vec<_> = on_disk.difference(&in_hha).collect();
```

### 文件夹扫描

Linux 文件夹扫描:`opendir(3)` / `readdir(3)`。

```c
DIR *d = opendir("assets");
struct dirent *e;
while ((e = readdir(d))) {
    printf("%s\n", e->d_name);
}
closedir(d);
```

递归扫描:对每个 entry,如果是目录,递归;否则加入文件列表。

Rust 的 `std::fs::read_dir` 是同步的:

```rust
fn scan_dir(path: &Path, out: &mut Vec<PathBuf>) -> io::Result<()> {
    for entry in fs::read_dir(path)? {
        let entry = entry?;
        let path = entry.path();
        if path.is_dir() {
            scan_dir(&path, out)?;    // 递归
        } else {
            out.push(path);
        }
    }
    Ok(())
}
```

高性能版用 `ignore` crate(基于 ripgrep 的库),自动跳 `.gitignore` 文件。

### 命名约定

orphan 的 asset 名通常用文件 stem(去掉扩展名):`hero.png` → `hero`。

冲突:如果 HHA 已有 `hero`,导入 `hero.png` 时怎么办?

- **覆盖**:HHA 的 `hero` 被替换(危险)
- **重命名**:新加 `hero_2`
- **跳过**:不导入,留给用户

工业级用 "skip + warn",让用户决定。

### Asset 类型识别

orphan 文件根据扩展名识别类型:

```rust
fn asset_type_from_ext(ext: &str) -> Option<AssetType> {

        "wav" | "ogg" | "mp3" => Some(AssetType::Audio),
        "ttf" | "otf" => Some(AssetType::Font),
        _ => None,
    }
}
```

### 3.4 · 🦀 Rust 生态视角

Rust 的文件扫描生态。

**`std::fs::read_dir`**:标准库,同步,简单。

**`walkdir` crate**:递归扫描,带 filter。

```rust
use walkdir::WalkDir;

for entry in WalkDir::new("assets").into_iter().filter_map(|e| e.ok()) {
    println!("{}", entry.path().display());
}
```

**`ignore` crate**:基于 ripgrep,支持 `.gitignore`,高性能。

**`notify` crate**:跨平台 inotify / fanotify / kqueue,文件事件。

**`rayon` crate**:并行扫描大文件夹。

Rust 写 orphan import 的典型模式:

```rust
use ignore::WalkBuilder;
use std::collections::HashSet;

fn find_orphans(asset_dir: &Path, hha_entries: &HashSet<String>) -> Vec<PathBuf> {
    let mut orphans = Vec::new();
    
    for result in WalkBuilder::new(asset_dir).build() {
        if let Ok(entry) = result {
            if entry.file_type().map_or(false, |t| t.is_file()) {
                let stem = entry.path().file_stem().unwrap().to_string_lossy().to_string();
                if !hha_entries.contains(&stem) {
                    orphans.push(entry.path().to_path_buf());
                }
            }
        }
    }
    
    orphans
}
```

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:为什么用 HashSet 存 HHA 资产名,而不是 Vec?

**参考解答**:HashSet 的查询是 O(1),Vec 是 O(n)。

orphan 检测:对每个磁盘文件,查"HHA 有没有这个名字"。如果 HHA 有 10000 个资产,磁盘 1000 个文件:

- Vec:1000 * 10000 = 10,000,000 次比较
- HashSet:1000 次 hash + 比较

差万倍。资产量大时 Vec 卡死。

HashSet 用空间换时间(hash 表),Rust 默认 SipHash(抗 HashDoS)。

### Lv2 · 动手实践(改/写 Rust 代码)

**题**:实现 orphan 扫描。给定 mock "磁盘文件"和 mock "HHA entries",找出 orphan。然后实现 import orphan(添加到 HHA)。

完成标准:`cargo run` 输出 orphan 列表,模拟 import 后 HHA 多了对应 entry。

**参考解答**:

```rust
use std::collections::HashSet;
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, PartialEq)]
enum AssetType { Bitmap, Audio, Font }

#[derive(Debug, Clone)]
struct AssetEntry {
    id: u32,
    name: String,
    asset_type: AssetType,
}

struct HhaFile {
    next_id: u32,
    entries: Vec<AssetEntry>,
}

impl HhaFile {
    fn new() -> Self { Self { next_id: 1, entries: Vec::new() } }
    
    fn names(&self) -> HashSet<String> {
        self.entries.iter().map(|e| e.name.clone()).collect()
    }
    
    fn import(&mut self, name: &str, asset_type: AssetType) -> u32 {
        let id = self.next_id;
        self.next_id += 1;
        self.entries.push(AssetEntry {
            id, name: name.into(), asset_type,
        });
        id
    }
    
    fn has(&self, name: &str) -> bool {
        self.entries.iter().any(|e| e.name == name)
    }
}

fn asset_type_from_ext(ext: &str) -> Option<AssetType> {
    match ext.to_lowercase().as_str() {
        "png" | "bmp" | "jpg" => Some(AssetType::Bitmap),
        "wav" | "ogg" => Some(AssetType::Audio),
        "ttf" | "otf" => Some(AssetType::Font),
        _ => None,
    }
}

fn find_orphans(disk_files: &[PathBuf], hha: &HhaFile) -> Vec<(PathBuf, AssetType)> {
    let hha_names = hha.names();
    
    disk_files.iter()
        .filter_map(|path| {
            let stem = path.file_stem()?.to_string_lossy().to_string();
            if hha_names.contains(&stem) {
                return None;    // 已在 HHA
            }
            let ext = path.extension()?.to_string_lossy().to_string();
            let asset_type = asset_type_from_ext(&ext)?;
            Some((path.clone(), asset_type))
        })
        .collect()
}

fn main() {
    let mut hha = HhaFile::new();
    hha.import("hero", AssetType::Bitmap);
    hha.import("sword", AssetType::Bitmap);
    hha.import("bgm", AssetType::Audio);
    
    println!("=== HHA 已有 ===");
    for e in &hha.entries {
        println!("  id={} {} {:?}", e.id, e.name, e.asset_type);
    }
    
    // 模拟磁盘文件
    let disk_files: Vec<PathBuf> = vec![
        "assets/hero.png".into(),       // 已在 HHA
        "assets/sword.png".into(),      // 已在 HHA
        "assets/goblin.png".into(),     // orphan
        "assets/step.wav".into(),       // orphan
        "assets/font.ttf".into(),       // orphan
        "assets/notes.txt".into(),      // 未知扩展名,忽略
        "assets/bg.png".into(),         // orphan
    ];
    
    let orphans = find_orphans(&disk_files, &hha);
    
    println!("\n=== Orphans ===");
    for (path, at) in &orphans {
        println!("  {} -> {:?}", path.display(), at);
    }
    
    println!("\n=== 模拟用户点 Import All ===");
    let to_import: Vec<_> = orphans.clone();
    for (path, asset_type) in &to_import {
        let stem = path.file_stem().unwrap().to_string_lossy();
        let id = hha.import(&stem, asset_type.clone());
        println!("  imported {} as id={} {:?}", stem, id, asset_type);
    }
    
    println!("\n=== HHA 导入后 ===");
    println!("entries: {}", hha.entries.len());
    for e in &hha.entries {
        println!("  id={} {} {:?}", e.id, e.name, e.asset_type);
    }
    
    // 验证:再扫,orphan 应为空
    let orphans_after = find_orphans(&disk_files, &hha);
    println!("\nOrphans 剩余: {} (预期 0)", orphans_after.len());
    
    // 处理冲突:磁盘新增同名文件
    println!("\n=== 冲突处理演示 ===");
    let disk_with_conflict: Vec<PathBuf> = vec![
        "assets/hero.png".into(),    // HHA 已有
        "assets/hero2.png".into(),   // 不同名,正常
    ];
    let orphans_conflict = find_orphans(&disk_with_conflict, &hha);
    println!("冲突场景 orphans: {}", orphans_conflict.len());
    println!("(hero 已存在,只 hero2 是 orphan)");
}
```

## 8 · Rust / Arch 落地代码

下面是 Day 501 完整的 orphan import 系统。

```rust
// ============================================================
// Day 501 · 导入孤立资产
// ============================================================

use std::collections::HashSet;
use std::path::{Path, PathBuf};
use std::fmt;

// ============================================================
// Asset types
// ============================================================

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
enum AssetType {
    Bitmap,
    Audio,
    Font,
    Entity,
    Unknown,
}

impl fmt::Display for AssetType {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            AssetType::Bitmap => write!(f, "Bitmap"),
            AssetType::Audio => write!(f, "Audio"),
            AssetType::Font => write!(f, "Font"),
            AssetType::Entity => write!(f, "Entity"),
            AssetType::Unknown => write!(f, "Unknown"),
        }
    }
}

fn asset_type_from_ext(ext: &str) -> AssetType {
    match ext.to_lowercase().as_str() {
        "png" | "bmp" | "jpg" | "jpeg" | "tga" => AssetType::Bitmap,
        "wav" | "ogg" | "mp3" | "flac" => AssetType::Audio,
        "ttf" | "otf" => AssetType::Font,
        "hha" => AssetType::Entity,
        _ => AssetType::Unknown,
    }
}

// ============================================================
// HHA
// ============================================================

#[derive(Debug, Clone)]
struct AssetEntry {
    id: u32,
    name: String,
    asset_type: AssetType,
    blob: Vec<u8>,    // 简化:blob 直接存
}

struct HhaFile {
    next_id: u32,
    entries: Vec<AssetEntry>,
}

impl HhaFile {
    fn new() -> Self { Self { next_id: 1, entries: Vec::new() } }
    
    fn names(&self) -> HashSet<String> {
        self.entries.iter().map(|e| e.name.clone()).collect()
    }
    
    fn has(&self, name: &str) -> bool {
        self.entries.iter().any(|e| e.name == name)
    }
    
    fn find(&self, name: &str) -> Option<&AssetEntry> {
        self.entries.iter().find(|e| e.name == name)
    }
    
    fn import(&mut self, name: &str, asset_type: AssetType, blob: Vec<u8>) -> Result<u32, String> {
        if self.has(name) {
            return Err(format!("name '{}' already exists", name));
        }
        let id = self.next_id;
        self.next_id += 1;
        self.entries.push(AssetEntry {
            id, name: name.into(), asset_type, blob,
        });
        Ok(id)
    }
    
    fn import_with_rename(&mut self, name: &str, asset_type: AssetType, blob: Vec<u8>) -> u32 {
        let mut final_name = name.to_string();
        let mut counter = 2;
        while self.has(&final_name) {
            final_name = format!("{}_{}", name, counter);
            counter += 1;
        }
        self.import(&final_name, asset_type, blob).unwrap()
    }
    
    fn overwrite(&mut self, name: &str, asset_type: AssetType, blob: Vec<u8>) -> u32 {
        if let Some(entry) = self.entries.iter_mut().find(|e| e.name == name) {
            entry.asset_type = asset_type;
            entry.blob = blob;
            entry.id
        } else {
            self.import(name, asset_type, blob).unwrap()
        }
    }
}

// ============================================================
// Orphan scanner
// ============================================================

struct Orphan {
    path: PathBuf,
    stem: String,
    asset_type: AssetType,
}

impl Orphan {
    fn from_path(path: PathBuf) -> Option<Self> {
        let stem = path.file_stem()?.to_string_lossy().to_string();
        let ext = path.extension()?.to_string_lossy().to_string();
        let asset_type = asset_type_from_ext(&ext);
        if asset_type == AssetType::Unknown {
            return None;
        }
        Some(Self { path, stem, asset_type })
    }
}

fn find_orphans(disk_files: &[PathBuf], hha: &HhaFile) -> Vec<Orphan> {
    let hha_names = hha.names();
    
    disk_files.iter()
        .filter_map(|p| Orphan::from_path(p.clone()))
        .filter(|o| !hha_names.contains(&o.stem))
        .collect()
}

// ============================================================
// 扫描目录
// ============================================================

fn scan_dir(path: &Path, files: &mut Vec<PathBuf>) -> std::io::Result<()> {
    if !path.exists() { return Ok(()); }
    for entry in std::fs::read_dir(path)? {
        let entry = entry?;
        let p = entry.path();
        if p.is_dir() {
            scan_dir(&p, files)?;
        } else {
            files.push(p);
        }
    }
    Ok(())
}

// ============================================================
// Importer
// ============================================================

enum ImportPolicy {
    Skip,
    Overwrite,
    Rename,
}

fn import_orphans(hha: &mut HhaFile, orphans: &[Orphan], policy: &ImportPolicy) -> Vec<(String, Result<u32, String>)> {
    let mut results = Vec::new();
    
    for orphan in orphans {
        // 模拟读文件:用 path 字符串当 blob
        let blob = format!("[blob from {}]", orphan.path.display()).into_bytes();
        
        let result = match policy {
            ImportPolicy::Skip => {
                if hha.has(&orphan.stem) {
                    Err(format!("skip: {} already exists", orphan.stem))
                } else {
                    hha.import(&orphan.stem, orphan.asset_type, blob)
                }
            }
            ImportPolicy::Overwrite => {
                let id = hha.overwrite(&orphan.stem, orphan.asset_type, blob);
                Ok(id)
            }
            ImportPolicy::Rename => {
                let id = hha.import_with_rename(&orphan.stem, orphan.asset_type, blob);
                Ok(id)
            }
        };
        
        results.push((orphan.stem.clone(), result));
    }
    
    results
}

    }
```
