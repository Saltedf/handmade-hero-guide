# Day 537 · 填充房间周围区域

> Day 446-452 Casey 写了世界生成器——放置房间、连接房间。但生成的世界有大量"空洞":房间之间的空隙没填东西。Day 537 他加一个填充系统——用石头/泥土/装饰物填满房间周围。本质是**程序化生成**(procedural generation)的经典问题:用规则填充空间。

## 0 · 为什么要有这一天

Day 446-452 生成的世界看起来像几栋房子在虚空中飘——房子之间的空白让世界显得稀疏、不真实。Day 537 修复:**在房间周围自动填充岩石/泥土/装饰物**,让世界看起来"扎实"。

填充不是随机乱填——Casey 用**规则驱动**的填充:

- 房间之间的空隙:石头(看起来像地下隧道的感觉)
- 房间上方:空气(可走)
- 房间下方:泥土(实心地面)
- 装饰物:在合适的地面放花、草、小石头

这种"规则驱动填充"是程序化生成的核心。简单规则 = 可预测结果;复杂规则 = 多样但难调。Casey 选简单规则,迭代调参。

工业级程序化生成:**Perlin noise**(柏林噪声)、**Wave Function Collapse**(波函数坍缩)、**Cellular Automata**(元胞自动机)。Minecraft 用 Perlin noise 生成地形,Dwarf Fortress 用大量规则生成历史。

#### 程序化生成三大流派

让我把程序化生成的主流方法对比一下,看 Casey 这一天的位置:

**Rule-based(规则驱动)**——Casey 的方法。手动写"如果 X 则 Y"规则。

- 优点:可控性强,bug 易定位
- 缺点:规则复杂时难维护,结果有限
- 例子:Dwarf Fortress(复杂 rule)、Spelunky(脚本化 layout)

**Noise-based(噪声驱动)**——用 Perlin/Simplex noise 生成连续变化的数据。

- 优点:自然、有机、无限多样性
- 缺点:不可控,调试困难
- 例子:Minecraft(地形)、No Man's Sky(星球)

**Grammar-based(语法驱动)**——用 shape grammar/Wave Function Collapse 等结构化算法。

- 优点:数学保证(无重叠、无 gap)
- 缺点:实现复杂
- 例子:Caves of Qud(城市生成)、Townscaper(WFC 建造)

Casey 的方法最接近 Rule-based,适合教学(每条规则明确)。工业级游戏用混合策略——核心结构用 Rule-based,细节填充用 Noise-based。

#### Perlin Noise:工业级程序化生成的基石

让我把 Perlin noise 讲一下,因为它是程序化生成的核心技术,Casey 后面会用。

Ken Perlin 1985 年发明(为电影 Tron),获 1997 年奥斯卡技术奖。核心思想:**生成平滑、连续、自然的随机数据**。

伪随机白噪声(`rand() % 256`)在邻接像素之间跳跃剧烈,看起来像电视雪花。Perlin noise 通过**插值梯度**生成连续数据:在网格点定义随机梯度,中间用 smoothstep 函数插值。结果是一团团"云"——既有随机性又有连续性。

```rust

    // 1. 找到 (x, y) 所在网格单元
    let x0 = x.floor() as i32;
    let y0 = y.floor() as i32;
    // 2. 在 4 个角点取随机梯度
    let grad00 = random_grad(x0, y0, seed);
    let grad10 = random_grad(x0+1, y0, seed);
    let grad01 = random_grad(x0, y0+1, seed);
    let grad11 = random_grad(x0+1, y0+1, seed);
    // 3. 计算每个角点的贡献(梯度 · 距离向量)
    // 4. 用 smoothstep 插值
    // (具体代码略,几十行)
}
```

工业级游戏**不会**自己实现 Perlin——用 `noise` crate(Rust)或 OpenSimplex / Simplex(Perlin 改进版)。但理解原理对调试噪声参数重要。

Perlin noise 的应用:
- 地形高度图(每个像素 = Perlin(x, y) * amplitude)
- 云层纹理(3D Perlin + 时间维)
- 生物群落分布(Perlin 决定湿度/温度)
- 纹理生成(大理石、木头纹理)

### 严谨展开:Voxel Grid

世界是 3D voxel 网格——每个 voxel 是一个立方体,有 type(空气、泥土、石头、装饰)。坐标 (x, y, z)。

```rust
enum VoxelType {
    Air,
    Dirt,
    Stone,
    DeepStone,
    Decoration(u32),  // 装饰物 ID
}

struct World {
    voxels: Vec<VoxelType>,  // [x][y][z] 索引
    width: u32, height: u32, depth: u32,
}
```

世界生成分两步:

#### Voxel Grid 的内存优化

工业级 voxel 游戏(Minecraft、Teardown)用大量内存优化。一个 64×64×64 的世界,直接存 enum 是 4 MB(每个 voxel 1 字节,enum 简化)。但 Minecraft 的世界是 64×384×64 = 1.5M voxels per chunk,数千 chunks,内存爆炸。

优化技术:

1. **Palette compression**:不存 enum 值,存"index into palette"。如果世界 90% 是 Air,palette 只有 Air/Dirt/Stone,每个 voxel 用 2 bit 而不是 8 bit。内存减少 4x。

2. **Run-length encoding (RLE)**:连续相同 voxel 压缩成 (count, type)。地下深处大量 Stone,一行 64 个 Stone 压成 (64, Stone)。Minecraft 1.13+ 用类似方案。

3. **Sparse storage**:不存 Air voxel,只存非 Air。HashMap<Vec3, VoxelType> 适合稀疏世界。

4. **Chunk-based**:世界分成 16×16×16 chunks,每个 chunk 独立压缩 + 按需加载。Minecraft、Minetest 都这样。

Casey 的 HH 简化用 dense Vec<VoxelType>——教学够用,但生产游戏必须用 palette + RLE。

#### 程序化生成的"层级"思维

Casey 的填充是分层的:

1. **Structure layer**:房间布局(Day 446-452)
2. **Fill layer**:房间周围的石头/泥土(Day 537)
3. **Decoration layer**:地面上的花/草/石头(Day 537 后半)
4. **Lighting layer**:光照计算(Day 555+)
5. **Collision layer**:每个 voxel 的碰撞形状(物理)

每一层都基于前一层的输出。这是工业级程序化生成的标准架构——**管道式生成**(pipeline generation)。

工业级例子:
- **Minecraft**:biome → terrain height → block placement → structures → lighting → spawn
- **Dwarf Fortress**:geology → elevation → civilizations → history → sites → current state
- **Caves of Qud**:terrain → ruins → items → monsters → dialogue

每层独立调试,层间接口明确。学会这种"管道思维",你将来设计任何生成器都能组织清晰。



1. **房间生成**(Day 446-452):某些 voxel 设为 Air(房间内),其他默认 Dirt。
2. **填充**(Day 537):根据规则,把"房间外但还 Dirt"的 voxel 改成更具体的类型。

### 填充规则的形式化

对每个 voxel `(x, y, z)`:

```
if room_contains(x, y, z):
    skip  # 已经填充
    
elif y < lowest_room_y:
    type = DeepStone
    
elif distance_to_nearest_room(x, y, z) < 5:
    type = Stone  # 房间周围 5 格内
    
elif y < ground_y:
    type = Dirt
    
else:
    type = Air
```

`distance_to_nearest_room` 是关键——它决定填充范围。可以用 BFS(breadth-first search)从每个房间扩展,标记距离。

### 装饰物放置

对每个地面 voxel(下方是 Dirt/Stone,自己是 Air):

    voxel = Decoration(weighted_random(&decorations, &weights))

`decoration_density` 是参数——0.05 表示 5% 地面有装饰。 Casey 试不同值,看视觉效果。

#### Greedy Meshing 的算法细节

让我把 greedy meshing 的核心思想讲清楚,因为它是 voxel 渲染的关键优化。

朴素渲染:每个 voxel 的每个可见面是一个 quad,6 个 quads per voxel。64×64×64 voxel = 25 万 voxel,假设 1/3 可见 = 50 万 quads。每个 quad 一个 draw call,GPU 撑不住。

Greedy meshing 思路:**把相邻同类型 voxel 的面合并成大 quad**。

算法(简化):
1. 对每个面方向(±X, ±Y, ±Z 共 6 个)
2. 对每个"切片"(沿该方向的 2D 平面)
3. 用 mask 标记哪些 voxel 该方向有可见面
4. 在 mask 上做"贪心矩形合并"——找最大的矩形覆盖,标记已合并,继续找下一个
5. 输出合并后的 quads

复杂度:O(N×M) 每切片,N×M×K 总切片。比朴素渲染快 10-100 倍。

效果:64×64×64 voxel,greedy meshing 后可能只有几千 quads(取决于世界密度)。从 50 万降到 5 千 = 100x 加速。

工业级 voxel 引擎:
- **Minecraft**:用 greedy meshing + face culling
- **Teardown**:Voxel ray tracing + greedy meshing
- **Veloren**(Rust 开源 MMO):block mesh + LOD

Rust 生态:`block-mesh`、`greedy-voxel-mesh` crate 提供实现。

### 3.3 · Linux 系统编程视角

Linux 内核的 page frame allocation 类似——内存是 voxel,allocator 用规则(空闲、大小、NUMA 节点)选择合适 page。

buddy allocator 是经典——把内存按 2 的幂分组,快速找合适大小。

#### Buddy Allocator vs Voxel Grid 的类比

Linux buddy allocator:
- 内存 = 大块(2^N pages)
- 分配:找最小的能装下请求的 2^k 块,必要时分裂
- 释放:把相邻同 size 块合并(buddy),递归合并

Voxel greedy meshing:
- 空间 = 大块(empty volume)
- 渲染:找最大矩形覆盖,递归
- 优化:相邻同类型合并

两者都是"贪心合并"算法,只是应用域不同(内存 vs 几何)。这种"算法跨域复用"是计算机科学的精髓——一组算法思想(贪心、动态规划、分治)在不同场景反复出现。

学会这种"抽象思维",你以后看到任何新问题都能映射到已知算法。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:Casey 用规则填充,而不是 Perlin noise。为什么?

**参考解答**:Casey 的世界是"房间式"——房间是人造结构,周围填充应该有"地下隧道"的感觉(石头),不是自然地形(noise)。Perlin noise 适合自然地形(山、海),不适合建筑周围。规则驱动让填充"贴合"建筑形状,而 noise 会"无视"建筑。游戏选择生成算法的关键是**匹配内容语义**——自然内容用 noise,人造内容用规则。

### Lv2 · 动手实践

**题**:用 Rust 实现一个简单的 2D voxel 填充。世界 32×32,初始全 Dirt。在 (10,10) 到 (20,20) 放一个"房间"(设为 Air)。填充规则:房间外、距离房间 < 3 的 voxel 改成 Stone。打印 ASCII 网格(D= Dirt, S = Stone, . = Air)。

**参考解答**:

```rust
const W: usize = 32;
const H: usize = 32;

#[derive(Clone, Copy, PartialEq, Debug)]
enum Tile { Dirt, Stone, Air }

fn distance_to_room(x: i32, y: i32, room: (i32, i32, i32, i32)) -> i32 {
    let (rx, ry, rw, rh) = room;
    let dx = (rx - x).max(0).max(x - (rx + rw - 1));
    let dy = (ry - y).max(0).max(y - (ry + rh - 1));
    dx.max(dy)  // Chebyshev 距离
}

fn main() {
    let mut grid = [[Tile::Dirt; W]; H];
    let room = (10, 10, 10, 10);  // x, y, w, h
    
    // 标记房间
    for y in room.1..room.1+room.3 {
        for x in room.0..room.0+room.2 {
            grid[y as usize][x as usize] = Tile::Air;
        }
    }
    
    // 填充:房间外、距离 < 3 是 Stone
    for y in 0..H {
        for x in 0..W {
            if grid[y][x] != Tile::Dirt { continue; }
            let dist = distance_to_room(x as i32, y as i32, room);
            if dist < 3 {
                grid[y][x] = Tile::Stone;
            }
        }
    }
    
    // 打印
    for y in 0..H {
        for x in 0..W {
            let c = match grid[y][x] {
                Tile::Dirt => 'D',
                Tile::Stone => 'S',
                Tile::Air => '.',
            };
            print!("{}", c);
        }
        println!();
    }
}
```

```bash
cargo run
# DDDDDDDDDSSSSSSSSSSSSSSSDDDDDDD
# DDDDDDDDDSSSSSSSSSSSSSSSDDDDDDD
# DDDDDDDDDSSSSSSSSSSSSSSSDDDDDDD
# ...
# DDDDDDDDDSSS.........SSSSDDDDDD
# ...
# (中间是房间,周围 Stone 环带,远处 Dirt)
```

为什么这么写:`distance_to_room` 用 Chebyshev 距离(chess king 距离),适合方形房间。`max(dx, dy)` 是核心——只看最大维度距离。`for y, for x` 嵌套循环是 2D 遍历标准模式。

### Lv3 · 迁移设计

**题**:用 Perlin noise(`noise-rs` crate)生成 64×64 高度图,高度 [0, 10]。把高度 < 3 的 voxel 设为水(Air),[3, 7] 设为草地,[8+] 设为雪。打印 ASCII 地图。提示:`noise.get([x, y])` 返回 [-1, 1],需要归一化。

**详细参考**:

```rust
use noise::{NoiseFn, Perlin};

fn generate_heightmap(seed: u32) -> Vec<Vec<u8>> {
    let perlin = Perlin::new(seed);
    let mut map = vec![vec![0u8; 64]; 64];
    
    for y in 0..64 {
        for x in 0..64 {
            // 用多个 octaves(分形布朗运动 fbm)
            let mut h = 0.0;
            let mut amp = 1.0;
            let mut freq = 0.05;
            for _ in 0..4 {
                h += amp * perlin.get([x as f64 * freq, y as f64 * freq]);
                amp *= 0.5;
                freq *= 2.0;
            }
            // 归一化到 [0, 10]
            let normalized = ((h + 1.0) * 5.0) as u8;
            map[y][x] = normalized.min(10);
        }
    }
    map
}

fn render_ascii(map: &Vec<Vec<u8>>) {
    for row in map {
        for &h in row {
            let c = match h {
                0..=2 => '~',  // 水
                3..=7 => '.',  // 草
                _ => '#',      // 雪
            };
            print!("{}", c);
        }
        println!();
    }
}
```

fbm(fractal Brownian motion)是 Perlin noise 的"分形叠加"——多个频率的 noise 叠加,产生更自然的"细节 + 大结构"。工业级地形生成几乎都用 fbm,不是单一 Perlin。

### Lv4 · 开源贡献

**题**:`noise-rs` 是 Rust 噪声库主力。去 GitHub 看它的源码,理解 Perlin 和 Simplex 的实现差别。如果你想贡献,看 issue 是否有"add new noise type"或 doc 改进。

// 完整的 3D voxel 填充系统

use std::collections::VecDeque;

#[derive(Clone, Copy, PartialEq, Debug)]
pub enum VoxelType {
    Air,
    Dirt,
    Stone,
    DeepStone,
    Decoration(u32),
}

pub struct VoxelWorld {
    pub voxels: Vec<VoxelType>,
    pub width: usize,
    pub height: usize,
    pub depth: usize,
}

impl VoxelWorld {
    pub fn new(width: usize, height: usize, depth: usize) -> Self {
        Self {
            voxels: vec![VoxelType::Dirt; width * height * depth],
            width, height, depth,
        }
    }
    
    fn idx(&self, x: usize, y: usize, z: usize) -> usize {
        (y * self.depth + z) * self.width + x
    }
    
    pub fn get(&self, x: usize, y: usize, z: usize) -> VoxelType {
        if x >= self.width || y >= self.height || z >= self.depth {
            return VoxelType::Air;  // 边界外是空气
        }
        self.voxels[self.idx(x, y, z)]
    }
    
    pub fn set(&mut self, x: usize, y: usize, z: usize, v: VoxelType) {
        if x < self.width && y < self.height && z < self.depth {
            self.voxels[self.idx(x, y, z)] = v;
        }
    }
    
    /// 标记一个长方体为 Air(房间)
    pub fn carve_room(&mut self, x0: usize, y0: usize, z0: usize, w: usize, h: usize, d: usize) {
        for y in y0..y0+h {
            for z in z0..z0+d {
                for x in x0..x0+w {
                    self.set(x, y, z, VoxelType::Air);
                }
            }
        }
    }
    
    /// BFS 计算每个 voxel 到最近 Air(房间)的距离
    /// 距离 > max_distance 时停止扩展
    pub fn distance_field(&self, max_distance: usize) -> Vec<usize> {
        let mut dist = vec![usize::MAX; self.voxels.len()];
        let mut queue: VecDeque<(usize, usize, usize)> = VecDeque::new();
        
        // 初始化:所有 Air voxel 距离 0
        for y in 0..self.height {
            for z in 0..self.depth {
                for x in 0..self.width {
                    if self.get(x, y, z) == VoxelType::Air {
                        let i = self.idx(x, y, z);
                        dist[i] = 0;
                        queue.push_back((x, y, z));
                    }
                }
            }
        }
        
        // BFS 扩展
        while let Some((x, y, z)) = queue.pop_front() {
            let i = self.idx(x, y, z);
            let d = dist[i];
            if d >= max_distance { continue; }
            
            // 6 个邻居
            let neighbors = [
                (x+1, y, z), (x.wrapping_sub(1), y, z),
                (x, y+1, z), (x, y.wrapping_sub(1), z),
                (x, y, z+1), (x, y, z.wrapping_sub(1)),
            ];
            
            for (nx, ny, nz) in neighbors {
                if nx >= self.width || ny >= self.height || nz >= self.depth {
                    continue;
                }
                let ni = self.idx(nx, ny, nz);
                if dist[ni] > d + 1 {
                    dist[ni] = d + 1;
                    queue.push_back((nx, ny, nz));
                }
            }
        }
        
        dist
    }
    
    /// 填充房间周围
    pub fn fill_around_rooms(&mut self) {
        let dist = self.distance_field(10);
        
        for y in 0..self.height {
            for z in 0..self.depth {
                for x in 0..self.width {
                    let i = self.idx(x, y, z);
                    if self.voxels[i] == VoxelType::Air { continue; }
                    
                    let d = dist[i];
                    if d == usize::MAX {
                        // 远离房间,根据深度填
                        if y < self.height / 4 {
                            self.voxels[i] = VoxelType::DeepStone;
                        } else {
                            self.voxels[i] = VoxelType::Dirt;
                        }
                    } else if d < 3 {
                        self.voxels[i] = VoxelType::Stone;
                    } else if d < 6 {
                        self.voxels[i] = VoxelType::Dirt;
                    } else if y < self.height / 4 {
                        self.voxels[i] = VoxelType::DeepStone;
                    }
                }
            }
        }
    }
    
    /// 在地面层放置装饰物
    pub fn place_decorations(&mut self, density: f32) {
        use rand::Rng;
        let mut rng = rand::thread_rng();
        
        for y in 1..self.height {
            for z in 0..self.depth {
                for x in 0..self.width {
                    // 当前是 Air,下方是 Dirt/Stone → 地面
                    if self.get(x, y, z) == VoxelType::Air
                        && (self.get(x, y-1, z) == VoxelType::Dirt
                            || self.get(x, y-1, z) == VoxelType::Stone) {
                        if rng.gen::<f32>() < density {
                            // 加权随机选装饰物
                            let dec_id = match rng.gen::<f32>() {
                                f if f < 0.5 => 1,  // 花
                                f if f < 0.8 => 2,  // 草
                                _ => 3,             // 小石头
                            };
                            self.set(x, y, z, VoxelType::Decoration(dec_id));
                        }
                    }
                }
            }
        }
    }
    
    /// 统计 voxel 分布
    pub fn stats(&self) -> (usize, usize, usize, usize, usize) {
        let mut air = 0; let mut dirt = 0;
        let mut stone = 0; let mut deep = 0; let mut dec = 0;
        for v in &self.voxels {
            match v {
                VoxelType::Air => air += 1,
                VoxelType::Dirt => dirt += 1,
                VoxelType::Stone => stone += 1,
                VoxelType::DeepStone => deep += 1,
                VoxelType::Decoration(_) => dec += 1,
            }
        }
        (air, dirt, stone, deep, dec)
    }
}

fn main() {
    let mut world = VoxelWorld::new(16, 16, 16);
    
    // 挖一个房间
    world.carve_room(4, 4, 4, 8, 4, 8);
    
    // 填充房间周围
    world.fill_around_rooms();
    
    // 放装饰物
    world.place_decorations(0.1);  // 10% 地面有装饰
    
    let (air, dirt, stone, deep, dec) = world.stats();
    println!("Voxel 分布:");
    println!("  Air:        {}", air);
    println!("  Dirt:       {}", dirt);
    println!("  Stone:      {}", stone);
    println!("  DeepStone:  {}", deep);
    println!("  Decoration: {}", dec);
    println!("  Total:      {}", world.voxels.len());
}

出错怎么办:

- **填充范围太大/小**:调 `distance_field(10)` 的 max_distance 参数。
- **装饰物太少/多**:调 `place_decorations(0.1)` 的 density。
- **BFS 慢**:确认 distance_field 只跑一次,不在循环里。
- **`usize::MAX` 比较错**:MAX 是"无穷",比较时小心 underflow。
