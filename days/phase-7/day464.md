# Day 464 · 为导入的 PNG 应用资产类型与标签

> Day 463 设计了 V1。今天 Casey 实现"PNG 导入器"——读一张 PNG,根据文件名/元数据推断资产类型(Bitmap/Sprite Atlas/...)和 tag(角色/敌人/道具),写入 HHA V1 格式。

## 0 · 为什么要有这一天

PNG 文件本身只是"像素数据",不带游戏语义。游戏要知道:
- 这张 PNG 是**纹理**还是**精灵表**?(影响 GPU 上传方式)
- 这张 PNG 是**角色**还是**道具**?(影响渲染顺序)
- 这张 PNG 的**标签**(tag)是什么?(便于代码查找)

Casey 的策略:**用文件名编码类型和标签**。例:
- `hero.png` → 角色 hero
- `goblin_walk_01.png` → 敌人 goblin 的走路动画第 1 帧
- `tile_dirt.png` → tile 类型 dirt

导入器扫描文件名,自动分配类型 + tag。这让美术不用手动写 metadata,工作流顺畅。

让我把"资产元数据策略"讲清楚,这是 Day 464 的设计核心。

**资产元数据从哪里来?** 几种工业方案:

**方案 A:文件名编码**(Casey HH Day 464)。文件名本身有结构,导入器解析:

```rust
fn parse_asset_metadata(filename: &str) -> AssetMetadata {
    // hero.png → { kind: Character, name: "hero" }
    // goblin_walk_01.png → { kind: Character, name: "goblin", animation: "walk", frame: 1 }
    // tile_dirt.png → { kind: Tile, name: "dirt" }
    
    let parts: Vec<&str> = filename.split('_').collect();
    match parts[0] {
        "hero" => AssetMetadata { kind: Character, name: "hero".into(), ..Default::default() },
        "tile" => AssetMetadata { kind: Tile, name: parts[1].into(), ..Default::default() },
        // ...
        _ => AssetMetadata { kind: Unknown, ..Default::default() },
    }
}
```

**优点**:简单,美术改文件名就能改类型。**缺点**:文件名长度受限,语义复杂时变长。

**方案 B:sidecar 文件**。每个 `asset.png` 旁边有 `asset.png.meta`:

```json
// hero.png.meta
{
  "kind": "Character",
  "name": "hero",
  "tags": ["player", "humanoid"],
  "animation": null,
  "scale": 1.0
}
```

**优点**:灵活,任意元数据。**缺点**:多文件管理。

**方案 C:目录约定**。目录结构表达类型:

```
assets/
  characters/
    hero.png
    goblin.png
  tiles/
    dirt.png
    grass.png
  ui/
    button.png
```

`characters/` 下都是 character,`tiles/` 下都是 tile。导入器扫描目录。

**优点**:最直观。**缺点**:跨类型资产不好放(如 UI character)。

**方案 D:中心 manifest**。一个 JSON / TOML 描述所有资产:

```toml
# assets.toml
[[assets]]
path = "characters/hero.png"
kind = "Character"
name = "hero"

[[assets]]
path = "tiles/dirt.png"
kind = "Tile"
name = "dirt"
```

**优点**:完整,易扩展。**缺点**:加资产要改 manifest。

**工业实践**:Unity/Unreal 用方案 B(sidecar)。开源游戏用方案 D(显式 manifest)。Casey HH 用方案 A(文件名)——教学简化。

**Tag 系统**。Casey HH 引入"tag"——资产可以被多个 tag 标记:

```rust
struct AssetEntry {
    id: AssetId,
    kind: AssetKind,
    tag_count: u32,
    tag_indices: [u32; MAX_TAGS],  // 指向 tag table
}

struct Tag {
    string_offset: u32,  // 字符串表里的 offset
    string_length: u32,
    first_asset_index: u32,  // 反向:tag 指向 asset
    one_past_last_asset_index: u32,
}
```

代码查找 tag:

```rust
let enemies = assets.query_tag("enemy");
for asset_id in enemies {
    let asset = assets.get(asset_id);
    render(&asset);
}
```

Tag 是**反向索引**——给个 tag 立刻找到所有 asset,不用遍历所有 asset。

**导入流程**。Day 464 完整流程:

1. 扫描 assets/ 目录,列出所有 .png
2. 对每个文件,parse 文件名 → metadata
3. 解码 PNG → 像素
4. 把像素写入 HHA V1 的 asset 数据段
5. 更新 asset table 和 tag table
6. 写出 HHA V1 文件

这是"资产管线"的核心——从源文件到打包文件的自动化转换。每次美术加新资产,运行 `import_assets`,生成新 HHA。

## 2 · 心智模型

### 类比:图书馆编目

图书馆员收到新书,按 ISBN 编号、按主题分类、写卡片目录。每本书都有规则:小说放 F 区,科学放 Q 区,儿童书放 J 区。

资产导入器同样:每个 PNG 文件按"规则"分类。规则用文件名表达,而不是 metadata 文件——简单、可见、版本控制友好。

### 文件名约定

```
hero.png              → type=Bitmap, tags=[character, hero]
hero_walk_01.png      → type=Sprite, tags=[character, hero, walk, frame=01]
goblin.png            → type=Bitmap, tags=[character, goblin]
tile_dirt.png         → type=Tile, tags=[environment, tile, dirt]
tile_dirt_grass.png   → type=Tile, tags=[environment, tile, dirt, grass]
icon_sword.png        → type=Icon, tags=[ui, icon, sword]
icon_potion_health.png → type=Icon, tags=[ui, icon, potion, health]
```

每行解释:
- 第一个下划线前是"大类"(hero/goblin/tile/icon)。
- 后续是 sub-tag。
- 数字编号(01)可能是动画帧。

### Rust 实现

```rust
use std::path::Path;

#[derive(Debug, Clone, PartialEq)]
enum AssetType {
    Bitmap,
    Sprite,
    Tile,
    Icon,
}

#[derive(Debug, Clone)]
struct AssetTag {
    key: String,
    value: Option<String>,
}

#[derive(Debug, Clone)]
struct AssetMeta {
    name: String,
    asset_type: AssetType,
    tags: Vec<AssetTag>,
}

fn parse_filename(filename: &str) -> Result<AssetMeta, String> {
    // 去掉扩展名
    let stem = Path::new(filename).file_stem()
        .and_then(|s| s.to_str())
        .ok_or("invalid filename")?;
    
    let parts: Vec<&str> = stem.split('_').collect();
    if parts.is_empty() { return Err("empty name".into()); }
    
    let (asset_type, tags) = match parts[0] {
        "hero" | "goblin" | "npc" => (AssetType::Bitmap, vec![
            AssetTag { key: "class".into(), value: Some("character".into()) },
            AssetTag { key: "name".into(), value: Some(parts[0].into()) },
        ]),
        "tile" => (AssetType::Tile, vec![
            AssetTag { key: "class".into(), value: Some("environment".into()) },
            AssetTag { key: "subtype".into(), value: Some("tile".into()) },
            AssetTag { key: "material".into(), value: Some(parts.get(1).unwrap_or(&"unknown").to_string()) },
        ]),
        "icon" => (AssetType::Icon, vec![
            AssetTag { key: "class".into(), value: Some("ui".into()) },
            AssetTag { key: "subtype".into(), value: Some("icon".into()) },
            AssetTag { key: "name".into(), value: Some(parts.get(1).unwrap_or(&"unknown").to_string()) },
        ]),
        _ => (AssetType::Bitmap, vec![
            AssetTag { key: "class".into(), value: Some("misc".into()) },
        ]),
    };
    
    Ok(AssetMeta {
        name: stem.to_string(),
        asset_type,
        tags,
    })
}

fn main() {
    let test_names = [
        "hero.png",
        "hero_walk_01.png",
        "tile_dirt.png",
        "tile_grass_dirt.png",
        "icon_sword.png",
        "icon_potion_health.png",
        "mystery_thing.png",
    ];
    
    for name in &test_names {
        let meta = parse_filename(name).unwrap();
        println!("{}:", name);
        println!("  type: {:?}", meta.asset_type);
        println!("  tags:");
        for tag in &meta.tags {
            if let Some(v) = &tag.value {
                println!("    {}: {}", tag.key, v);
            } else {
                println!("    {}", tag.key);
            }
        }
    }
}
```

每行解释:
- `split('_')` 切文件名为段。
- `parts[0]` 是"类前缀",决定 asset_type。
- 后续 parts 是 sub-tags。
- 默认 case(`_`)给未知类前缀。

### 完整导入器

```rust
use std::fs;

struct PngImporter {
    input_dir: String,
}

impl PngImporter {
    fn new(input_dir: &str) -> Self {
        Self { input_dir: input_dir.to_string() }
    }
    
    fn import_all(&self) -> Result<Vec<(AssetMeta, Vec<u8>)>, String> {
        let mut result = Vec::new();
        for entry in fs::read_dir(&self.input_dir).map_err(|e| e.to_string())? {
            let entry = entry.map_err(|e| e.to_string())?;
            let path = entry.path();
            
            // 只处理 PNG
            if path.extension().and_then(|e| e.to_str()) != Some("png") {
                continue;
            }
            
            let filename = path.file_name().and_then(|n| n.to_str()).unwrap();
            let meta = parse_filename(filename)?;
            
            // 读 PNG 数据
            let png_data = fs::read(&path).map_err(|e| e.to_string())?;
            
            result.push((meta, png_data));
        }
        Ok(result)
    }
}
```

每行解释:
- `fs::read_dir` 遍历目录。
- 过滤 `.png` 扩展。
- 解析文件名得 metadata。
- 读 PNG 字节,一起返回。

### 写入 HHA V1

```rust
fn write_hha_v1(
    assets: &[(AssetMeta, Vec<u8>)],
    output_path: &str,
) -> Result<(), String> {
    let mut out = Vec::new();
    
    // Header
    out.extend_from_slice(b"HHA1");
    out.extend_from_slice(&1u32.to_le_bytes());  // version
    out.extend_from_slice(&0u32.to_le_bytes());  // CRC placeholder
    
    // Tag count (total)
    let tag_count: u32 = assets.iter().map(|(m, _)| m.tags.len() as u32).sum();
    out.extend_from_slice(&tag_count.to_le_bytes());
    
    // Asset count
    out.extend_from_slice(&(assets.len() as u32).to_le_bytes());
    
    // Asset entries (simplified)
    for (meta, png_data) in assets {
        // name (length-prefixed)
        out.extend_from_slice(&(meta.name.len() as u32).to_le_bytes());
        out.extend_from_slice(meta.name.as_bytes());
        // type
        out.extend_from_slice(&(match meta.asset_type {
            AssetType::Bitmap => 0u16,
            AssetType::Sprite => 1,
            AssetType::Tile => 2,
            AssetType::Icon => 3,
        }).to_le_bytes());
        // tag count for this asset
        out.extend_from_slice(&(meta.tags.len() as u32).to_le_bytes());
        for tag in &meta.tags {
            out.extend_from_slice(&(tag.key.len() as u32).to_le_bytes());
            out.extend_from_slice(tag.key.as_bytes());
            if let Some(v) = &tag.value {
                out.extend_from_slice(&1u32.to_le_bytes());
                out.extend_from_slice(&(v.len() as u32).to_le_bytes());
                out.extend_from_slice(v.as_bytes());
            } else {
                out.extend_from_slice(&0u32.to_le_bytes());
            }
        }
        // PNG data length + bytes
        out.extend_from_slice(&(png_data.len() as u32).to_le_bytes());
        out.extend_from_slice(png_data);
    }
    
    // CRC over everything except CRC field itself
    let crc_offset = 8;
    let mut for_crc = out.clone();
    for_crc[crc_offset..crc_offset+4].copy_from_slice(&0u32.to_le_bytes());
    let crc = crc32_simple(&for_crc);
    out[crc_offset..crc_offset+4].copy_from_slice(&crc.to_le_bytes());
    
    fs::write(output_path, out).map_err(|e| e.to_string())?;
    Ok(())
}

fn crc32_simple(data: &[u8]) -> u32 {
    let mut crc: u32 = 0xFFFFFFFF;
    for &b in data {
        crc ^= b as u32;
        for _ in 0..8 {
            crc = if crc & 1 != 0 { 0xEDB88320 ^ (crc >> 1) } else { crc >> 1 };
        }
    }
    crc ^ 0xFFFFFFFF
}
```

每行解释:
- 每个 asset 写 metadata + tag list + PNG 数据。
- tag 用 length-prefixed key + 可选 value。
- CRC 最后算,覆盖全文件。

## 3 · 四域深入

### 3.1 · 游戏编程视角

资产命名约定的工业实践:

- **Unreal**:命名规则严格(`SM_` 静态网格、`T_` 纹理、`M_` 材质)
- **Unity**:松散,推荐前缀
- **AAA**:大型项目有"命名规范"文档,几十页

约定优于配置(CoC)的好处:
- 减少手工配置工作
- 一致性(所有 hero 类资产命名相似)
- 工具可推断(导入器自动分类)

工业坑:
- **重命名成本**:改文件名要更新所有引用,需要 refactor 工具
- **冲突**:两个美术同时用相同名字
- **国际化**:文件名只支持 ASCII(其他需转码)

### 3.2 · 图形学视角

资产类型影响 GPU 处理:

- **Bitmap**(普通纹理):单张,完整 mipmap
- **Sprite Atlas**(精灵表):无 mipmap(避免渗透),UV 切片
- **TileSheet**:无 mipmap,严格网格
- **IconSet**:通常无 mipmap(UI 用)

导入器根据类型选 GPU 参数:

```rust
fn gpu_params(asset_type: AssetType) -> GpuTextureParams {
    match asset_type {
        AssetType::Bitmap => GpuTextureParams { mipmaps: true, filter: Linear },
        AssetType::Sprite => GpuTextureParams { mipmaps: false, filter: Nearest },
        AssetType::Tile => GpuTextureParams { mipmaps: false, filter: Nearest },
        AssetType::Icon => GpuTextureParams { mipmaps: false, filter: Linear },
    }
}
```

### 3.3 · Linux 系统编程视角

Linux 文件系统约定:

- **目录结构**:`/usr/share/<app>/` 应用资源、`/etc/` 配置
- **文件名**:`/etc/passwd`、`/etc/fstab`,扩展名表达类型
- **magic + extension 双重识别**:`file` 命令两者都用

类似地,HHA 的 asset type 既看文件名约定,也看 PNG 内容(如果是 PNG 就一定是 Bitmap 子类)。

### 3.4 · Rust 生态视角

Rust 的资产导入生态:

- **`bevy_asset`**:运行时资产加载
- **`bevy_inspector_egui`**:编辑器看资产
- **`gltf`**:加载 glTF 模型
- **`image`**:多格式图像解码

```rust
// bevy 风格:asset type 由 Handle<T> 决定
fn load_hero(server: Res<AssetServer>) {
    let handle: Handle<Image> = server.load("hero.png");
    // Image 是 asset type,自动推断
}
```

Bevy 用 Rust type system 推断类型,不需要文件名约定。Casey HH 用文件名约定,教学清晰。

## 8 · Rust / Arch 落地代码

完整 PNG 导入器:

```rust
use std::fs;
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, PartialEq)]
enum AssetType {
    Bitmap,
    Sprite,
    Tile,
    Icon,
    Unknown,
}

#[derive(Debug, Clone)]
struct AssetTag {
    key: String,
    value: Option<String>,
}

#[derive(Debug, Clone)]
struct AssetMeta {
    name: String,
    asset_type: AssetType,
    tags: Vec<AssetTag>,
    source_path: PathBuf,
    png_data: Vec<u8>,
}

fn parse_filename(filename: &str) -> (AssetType, Vec<AssetTag>) {
    let stem = Path::new(filename).file_stem()
        .and_then(|s| s.to_str()).unwrap_or("");
    let parts: Vec<&str> = stem.split('_').collect();
    
    let (asset_type, base_tags) = match parts.first().copied().unwrap_or("") {
        "hero" | "goblin" | "npc" | "enemy" => (AssetType::Bitmap, vec![
            ("class", "character"), ("name", parts.first().unwrap()),
        ]),
        "tile" => (AssetType::Tile, vec![
            ("class", "environment"), ("subtype", "tile"),
            ("material", parts.get(1).unwrap_or(&"unknown")),
        ]),
        "icon" => (AssetType::Icon, vec![
            ("class", "ui"), ("subtype", "icon"),
            ("name", parts.get(1).unwrap_or(&"unknown")),
        ]),
        _ => (AssetType::Unknown, vec![("class", "misc")]),
    };
    
    let tags = base_tags.into_iter()
        .map(|(k, v)| AssetTag {
            key: k.to_string(),
            value: Some(v.to_string()),
        })
        .collect();
    
    (asset_type, tags)
}

fn import_dir(dir: &str) -> Result<Vec<AssetMeta>, String> {
    let mut assets = Vec::new();
    for entry in fs::read_dir(dir).map_err(|e| e.to_string())? {
        let entry = entry.map_err(|e| e.to_string())?;
        let path = entry.path();
        
        if path.extension().and_then(|e| e.to_str()) != Some("png") {
            continue;
        }
        
        let filename = path.file_name().unwrap().to_str().unwrap();
        let (asset_type, tags) = parse_filename(filename);
        let png_data = fs::read(&path).map_err(|e| e.to_string())?;
        
        assets.push(AssetMeta {
            name: Path::new(filename).file_stem().unwrap().to_str().unwrap().to_string(),
            asset_type,
            tags,
            source_path: path,
            png_data,
        });
    }
    Ok(assets)
}

fn crc32(data: &[u8]) -> u32 {
    let mut crc: u32 = 0xFFFFFFFF;
    for &b in data {
        crc ^= b as u32;
        for _ in 0..8 {
            crc = if crc & 1 != 0 { 0xEDB88320 ^ (crc >> 1) } else { crc >> 1 };
        }
    }
    crc ^ 0xFFFFFFFF
}

fn write_hha_v1(assets: &[AssetMeta], output: &str) -> Result<(), String> {
    let mut out = Vec::new();
    
    out.extend_from_slice(b"HHA1");
    out.extend_from_slice(&1u32.to_le_bytes());  // version
    out.extend_from_slice(&0u32.to_le_bytes());  // CRC placeholder
    
    // asset count
    out.extend_from_slice(&(assets.len() as u32).to_le_bytes());
    
    for asset in assets {
        // name length-prefixed
        out.extend_from_slice(&(asset.name.len() as u32).to_le_bytes());
        out.extend_from_slice(asset.name.as_bytes());
        
        // type
        let type_code = match asset.asset_type {
            AssetType::Bitmap => 0u16,
            AssetType::Sprite => 1,
            AssetType::Tile => 2,
            AssetType::Icon => 3,
            AssetType::Unknown => 99,
        };
        out.extend_from_slice(&type_code.to_le_bytes());
        
        // tags
        out.extend_from_slice(&(asset.tags.len() as u32).to_le_bytes());
        for tag in &asset.tags {
            out.extend_from_slice(&(tag.key.len() as u32).to_le_bytes());
            out.extend_from_slice(tag.key.as_bytes());
            if let Some(v) = &tag.value {
                out.extend_from_slice(&1u32.to_le_bytes());
                out.extend_from_slice(&(v.len() as u32).to_le_bytes());
                out.extend_from_slice(v.as_bytes());
            } else {
                out.extend_from_slice(&0u32.to_le_bytes());
            }
        }
        
        // PNG data
        out.extend_from_slice(&(asset.png_data.len() as u32).to_le_bytes());
        out.extend_from_slice(&asset.png_data);
    }
    
    // CRC
    let mut for_crc = out.clone();
    for_crc[8..12].copy_from_slice(&0u32.to_le_bytes());
    let crc = crc32(&for_crc);
    out[8..12].copy_from_slice(&crc.to_le_bytes());
    
    fs::write(output, out).map_err(|e| e.to_string())?;
    Ok(())
}

fn main() {
    // 创建测试目录(如果没有)
    let test_dir = "/tmp/test_assets";
    fs::create_dir_all(test_dir).unwrap();
    
    // 创建几个测试 PNG(简化,只是 magic + 数据)
    let png_magic = [0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A];
    for name in ["hero.png", "hero_walk_01.png", "tile_dirt.png", "icon_sword.png"] {
        let mut data = png_magic.to_vec();
        data.extend_from_slice(b"PNG data placeholder");
        fs::write(format!("{}/{}", test_dir, name), data).unwrap();
    }
    
    // 导入
    let assets = import_dir(test_dir).unwrap();
    println!("Imported {} assets:", assets.len());
    for asset in &assets {
        println!("\n{}:", asset.name);
        println!("  type: {:?}", asset.asset_type);
        println!("  tags: {}", asset.tags.iter()
            .map(|t| format!("{}={}", t.key, t.value.as_deref().unwrap_or("")))
            .collect::<Vec<_>>().join(", "));
        println!("  png_data: {} bytes", asset.png_data.len());
    }
    
    // 写 HHA V1
    let hha_path = "/tmp/assets.hha";
    write_hha_v1(&assets, hha_path).unwrap();
    let hha_size = fs::metadata(hha_path).unwrap().len();
    println!("\nWrote {}: {} bytes", hha_path, hha_size);
    
    // 验证 CRC
    let hha = fs::read(hha_path).unwrap();
    let stored_crc = u32::from_le_bytes(hha[8..12].try_into().unwrap());
    let mut for_crc = hha.clone();
    for_crc[8..12].copy_from_slice(&0u32.to_le_bytes());
    let computed_crc = crc32(&for_crc);
    println!("Stored CRC: 0x{:08x}, Computed: 0x{:08x}, Match: {}",
        stored_crc, computed_crc, stored_crc == computed_crc);
}
```
