# Day 168 · 渲染文本行

> Day 167 把 glyph 数据准备好,放在 .hha。今天 Casey 写**运行时**的文本渲染:从 .hha 拿 glyph,blit 到屏幕,处理 advance / kerning / 行间距。这是"屏幕上画出 Hello World"的一天。

## 0 · 为什么要有这一天

字体渲染的"绘制"步骤:

1. 读字符串
2. 拿每个字符的 glyph info(从 .hha)
3. 算每个 glyph 在屏幕上的位置(累加 advance,加 kerning)
4. 对每个 glyph,从 atlas blit 像素到 framebuffer
5. 颜色 / alpha blending

这是 **sprite blit**(Day 30)的变种——sprite 是 alpha-only(grayscale),blit 时乘上文本颜色。

复杂的地方:

- **行布局**:多行文本,行间距、对齐(左 / 中 / 右)
- **换行**:超长自动换行
- **裁剪**:超出 viewport 不画
- **颜色**:文本颜色 + 可能的 gradient / 阴影

今天先做单行 + 单色,Day 169 加 baseline 对齐,Day 173 加精确对齐。

心理锚点:看完今天,你能在游戏 framebuffer 上画出彩色 "Hello, World" 字符串。

## 1 · Casey 今天做了什么

Casey 写 `DrawString(fb, text, x, y, color)`:

```c
void DrawString(framebuffer* fb, font_atlas* font, char* text, f32 x, f32 y, u32 color) {
    f32 cursor_x = x;
    f32 cursor_y = y;
    u32 prev_glyph = 0;
    for (char* p = text; *p; p++) {
        u32 c = *p;
        if (c == '\n') {
            cursor_x = x;
            cursor_y += font->line_height;
            prev_glyph = 0;
            continue;
        }
        glyph_info* g = &font->glyphs[c];
        // kerning
        if (prev_glyph) {
            cursor_x += font_kerning(font, prev_glyph, c);
        }
        // blit
        draw_glyph(fb, font, g, cursor_x, cursor_y, color);
        cursor_x += g->advance;
        prev_glyph = c;
    }
}
```

视频里 Casey 重点:

- **cursor** 累加 advance,不要每字符重算
- **kerning 在 advance 前**(prev 字符和当前)
- **newline**:cursor_x 重置,cursor_y 加 line_height
- **draw_glyph** = sprite blit + 颜色乘 alpha

## 2 · 心智模型

### 类比:打字机

打字机从左到右打字,每个字打完字车前进。换行字车回开头 + 纸往上移。

字体渲染就是数字版打字机:

- cursor = 打字头位置
- advance = 字车前进量
- newline = 字车回 + 纸移

### 严谨模型:渲染流程

#### 1. 准备数据

```rust
struct Glyph {
    char: u32,
    atlas_x: u32,
    atlas_y: u32,
    width: u32,
    height: u32,
    advance: f32,
    bearing_x: f32,
    bearing_y: f32,
}

struct FontAtlas {
    atlas: Vec<u8>,       // grayscale
    atlas_w: u32,
    atlas_h: u32,
    glyphs: Vec<Glyph>,   // 按 char index
    line_height: f32,
    kerning: HashMap<(u32, u32), f32>,
}
```

#### 2. 主渲染循环

```rust
fn draw_string(fb: &mut [u32], fb_w: u32, fb_h: u32,
               font: &FontAtlas, text: &str, x: f32, y: f32, color: [u8; 4]) {
    let mut cursor_x = x;
    let mut cursor_y = y;
    let mut prev_char: Option<u32> = None;

    for c in text.chars() {
        if c == '\n' {
            cursor_x = x;
            cursor_y += font.line_height;
            prev_char = None;
            continue;
        }

        let g = match font.glyphs.iter().find(|g| g.char == c as u32) {
            Some(g) => g,
            None => continue,  // 字符不在 atlas,跳过
        };

        // kerning
        if let Some(prev) = prev_char {
            if let Some(&k) = font.kerning.get(&(prev, c as u32)) {
                cursor_x += k;
            }
        }

        // blit
        let dst_x = (cursor_x + g.bearing_x) as i32;
        let dst_y = (cursor_y + g.bearing_y) as i32;
        blit_glyph(fb, fb_w, fb_h, font, g, dst_x, dst_y, color);

        cursor_x += g.advance;
        prev_char = Some(c as u32);
    }
}
```

#### 3. Blit

```rust
fn blit_glyph(fb: &mut [u32], fb_w: u32, fb_h: u32,
              font: &FontAtlas, g: &Glyph, dst_x: i32, dst_y: i32, color: [u8; 4]) {
    for y in 0..g.height as i32 {
        for x in 0..g.width as i32 {
            let sx = g.atlas_x as i32 + x;
            let sy = g.atlas_y as i32 + y;
            let alpha = font.atlas[(sy as u32 * font.atlas_w + sx as u32) as usize];
            if alpha == 0 { continue; }

            let px = dst_x + x;
            let py = dst_y + y;
            if px < 0 || px >= fb_w as i32 || py < 0 || py >= fb_h as i32 { continue; }

            let idx = (py as u32 * fb_w + px as u32) as usize;
            let a = alpha as f32 / 255.0;
            // source color (alpha-blended)
            let src_r = (color[0] as f32 * a) as u32;
            let src_g = (color[1] as f32 * a) as u32;
            let src_b = (color[2] as f32 * a) as u32;
            // 简单覆盖(没有 destination alpha 考虑)
            fb[idx] = (255 << 24) | (src_r << 16) | (src_g << 8) | src_b;
        }
    }
}
```

### 行布局

```rust
fn draw_text_lines(fb: &mut [u32], fb_w: u32, fb_h: u32,
                   font: &FontAtlas, lines: &[&str], x: f32, y: f32, color: [u8; 4]) {
    let mut cy = y;
    for line in lines {
        draw_string(fb, fb_w, fb_h, font, line, x, cy, color);
        cy += font.line_height;
    }
}
```

### 对齐

- **左对齐**:`x` 是行首
- **右对齐**:每行 `cursor_x = x - line_width`
- **居中**:`cursor_x = x - line_width / 2`

要预计算 line_width(对每字符累加 advance + kerning)。

## 3 · 四域深入

### 3.1 · 游戏编程视角

工业文本渲染:

- **immediate mode**(ImGui / Casey):每帧重新画
- **retained mode**(HTML / DOM):文本是节点,状态管理
- **distance field**(Valve):shader 算像素,任意缩放
- **vector**(Slant 3D):GPU 直接 Bezier

游戏 UI 通常 immediate,简单。Web 是 retained,复杂。

### 3.2 · 图形学视角

文本 blit 的优化:

- **SIMD**:同时算 4-8 像素 alpha
- **GPU**:把 atlas 当 texture,shader blit。GPU 上千核并行
- **instanced rendering**:每 glyph 一个 instance,一次 draw call 画几千字

GPU 路径是现代游戏标准。Casey 软渲染先,Day 235+ 切 OpenGL 后用 GPU。

### 3.3 · Rust 生态视角

Rust 文本渲染 crate:

- **`glyph_brush`**:cache + 批量
- **`wgpu_glyph`**:wgpu 后端
- **`bevy_text`**:Bevy 引擎集成

自己写文本渲染是教学目的,生产用 glyph_brush。

### 3.4 · 性能视角

每字符 ~32×32 = 1024 像素。每像素 alpha + blend = 5 op。

100 字符 × 1024 × 5 = 500 K op / frame。CPU 单核 ~10 G op/s,理论 20000 字符 / 帧。

实际:cache miss 拖累,典型 5000 字符 / 帧。够用。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:bearing_y 是什么?为什么需要它,不能直接用 cursor_y 作为 glyph 顶部?

**参考解答**:`bearing_y` 是 glyph 顶部相对 cursor(基线 baseline)的偏移。通常 glyph 不在 cursor 正上方,而是**基线**对齐——"A" 的底部在 baseline,顶部在 baseline - height。

不同 glyph 的 baseline 一致(都在 cursor_y),但顶部位置不同。`bearing_y` 告诉你 glyph 顶部相对 baseline 多远。

例:`'g'` 的下半部分(descender)在 baseline 之下。它的 bearing_y 是负数(因为顶部还在 baseline 之上,但底部在下面)。

## 8 · Rust / Arch 落地代码

```rust
// 一个最小文本渲染 demo,输出 PPM

struct Glyph {
    char: u32,
    bitmap: Vec<u8>,
    width: u32,
    height: u32,
    advance: f32,
    bearing_x: f32,
    bearing_y: f32,
}

struct Font {
    glyphs: Vec<Glyph>,  // 按 ASCII index
    line_height: f32,
}

impl Font {
    // 极简:从 hardcoded 数据建一个 demo font
    fn demo() -> Self {
        // 用简单 block 字符模拟
        let block = |w: u32, h: u32| Glyph {
            char: 0,
            bitmap: vec![255; (w * h) as usize],
            width: w,
            height: h,
            advance: w as f32 + 1.0,
            bearing_x: 0.0,
            bearing_y: 0.0,
        };
        let mut glyphs = vec![block(0, 0); 128];  // 占位
        // 'A'-'Z' 不同大小
        for (i, c) in (b'A'..=b'Z').enumerate() {
            let size = 8 + (i % 3) * 2;
            let mut g = block(size, size);
            g.char = c as u32;
            // 画字母(简化:用 i 作为图形种子)
            for y in 0..size as usize {
                for x in 0..size as usize {
                    let on = (x + y + i) % 3 == 0;
                    g.bitmap[y * size as usize + x] = if on { 200 } else { 50 };
                }
            }
            glyphs[c as usize] = g;
        }
        for c in b'a'..=b'z' {
            glyphs[c as usize] = glyphs[c.to_ascii_uppercase() as usize].clone();
            glyphs[c as usize].char = c as u32;
        }
        // space
        glyphs[b' ' as usize] = Glyph {
            char: ' ' as u32, bitmap: vec![], width: 0, height: 0,
            advance: 6.0, bearing_x: 0.0, bearing_y: 0.0,
        };
        // comma
        glyphs[b',' as usize] = Glyph {
            char: ',' as u32, bitmap: vec![200; 4], width: 2, height: 2,
            advance: 3.0, bearing_x: 0.0, bearing_y: -6.0,
        };
        Self { glyphs, line_height: 12.0 }
    }

    fn find(&self, c: u8) -> Option<&Glyph> {
        self.glyphs.get(c as usize).filter(|g| g.char == c as u32)
    }
}

impl Clone for Glyph {
    fn clone(&self) -> Self {
        Self {
            char: self.char,
            bitmap: self.bitmap.clone(),
            width: self.width,
            height: self.height,
            advance: self.advance,
            bearing_x: self.bearing_x,
            bearing_y: self.bearing_y,
        }
    }
}

fn draw_string(fb: &mut [u32], fb_w: u32, fb_h: u32,
               font: &Font, text: &str, x: f32, y: f32,
               color: [u8; 3]) {
    let mut cx = x;
    let cy = y;
    for c in text.bytes() {
        let g = match font.find(c) { Some(g) => g, None => continue };
        // blit
        for yy in 0..g.height {
            for xx in 0..g.width {
                let alpha = g.bitmap[(yy * g.width + xx) as usize];
                if alpha == 0 { continue; }
                let px = (cx + g.bearing_x + xx as f32) as i32;
                let py = (cy + g.bearing_y + yy as f32) as i32;
                if px < 0 || px >= fb_w as i32 || py < 0 || py >= fb_h as i32 { continue; }
                let idx = (py as u32 * fb_w + px as u32) as usize;
                let a = alpha as f32 / 255.0;
                let r = (color[0] as f32 * a) as u32;
                let gg = (color[1] as f32 * a) as u32;
                let b = (color[2] as f32 * a) as u32;
                fb[idx] = (255 << 24) | (r << 16) | (gg << 8) | b;
            }
        }
        cx += g.advance;
    }
}

fn write_ppm(path: &str, fb: &[u32], w: u32, h: u32) -> std::io::Result<()> {
    use std::io::Write;
    let mut f = std::fs::File::create(path)?;
    writeln!(f, "P3")?;
    writeln!(f, "{} {}", w, h)?;
    writeln!(f, "255")?;
    for y in 0..h {
        for x in 0..w {
            let p = fb[(y * w + x) as usize];
            let r = (p >> 16) & 0xFF;
            let g = (p >> 8) & 0xFF;
            let b = p & 0xFF;
            write!(f, "{} {} {}  ", r, g, b)?;
        }
        writeln!(f)?;
    }
    Ok(())
}

fn main() -> std::io::Result<()> {
    let fb_w = 256u32;
    let fb_h = 64u32;
    let mut fb = vec![0xFF000000u32; (fb_w * fb_h) as usize];  // 黑背景

    let font = Font::demo();
    draw_string(&mut fb, fb_w, fb_h, &font, "Hello, World", 10.0, 20.0, [255, 255, 255]);
    draw_string(&mut fb, fb_w, fb_h, &font, "Rust Lang", 10.0, 40.0, [255, 100, 100]);

    write_ppm("text.ppm", &fb, fb_w, fb_h)?;
    println!("wrote text.ppm ({}x{})", fb_w, fb_h);
    Ok(())
}
```

```rust
use std::collections::HashMap;
use std::sync::RwLock;

// Asset storage(引用计数 + 分桶锁)
pub struct AssetStorage<T> {
    shards: Vec<RwLock<HashMap<u32, Arc<T>>>>,
    loader: Box<dyn Fn(u32) -> T + Send + Sync>,
}

impl<T> AssetStorage<T> {
    pub fn new<F>(loader: F) -> Self 
    where F: Fn(u32) -> T + Send + Sync + 'static {
        let num_shards = 16;
        let mut shards = Vec::with_capacity(num_shards);
        for _ in 0..num_shards {
            shards.push(RwLock::new(HashMap::new()));
        }
        Self {
            shards,
            loader: Box::new(loader),
        }
    }
    
    pub fn get(&self, id: u32) -> Arc<T> {
        let shard_idx = (id as usize) % self.shards.len();
        
        // 读路径
        {
            let shard = self.shards[shard_idx].read().unwrap();
            if let Some(asset) = shard.get(&id) {
                return Arc::clone(asset);
            }
        }
        
        // 慢路径:加载
        let asset = Arc::new((self.loader)(id));
        
        // 写路径
        let mut shard = self.shards[shard_idx].write().unwrap();
        let entry = shard.entry(id).or_insert(Arc::clone(&asset));
        Arc::clone(entry)
    }
}

// 用法
fn main() {
    let storage: AssetStorage<String> = AssetStorage::new(|id| {
        format!("texture_{}.png", id)
    });
    
    let a = storage.get(1);
    let b = storage.get(1);
    assert!(Arc::ptr_eq(&a, &b));  // 同一 Arc
}
```

这是工业级 asset storage 的 Rust 骨架——分桶 RwLock + Arc + 加载闭包。

### A.10 内存管理的最佳实践

Phase 4 涉及大量内存管理。最佳实践:

**1. Ownership 清晰**:
- 每资源有明确 owner
- Owner drop → 资源释放
- 不共享 ownership(避免 cycle)

**2. Arena for 临时数据**:
```rust
use bumpalo::Bump;

let arena = Bump::new();
let temp_data: &mut [u32] = arena.alloc_slice_fill_with(1000, |_| 0);
// arena drop → temp_data 自动释放
```

**3. Arc for 长期共享**:
```rust
let shared = Arc::new(ExpensiveResource::new());
let cloned = Arc::clone(&shared);
// 两个 owner 都 drop → resource 释放
```

**4. Weak for cache**:
```rust
let weak: Weak<Resource> = Arc::downgrade(&strong);
// cache 不阻止 strong 释放
if let Some(strong) = weak.upgrade() {
    // 还在用
} else {
    // 已释放
}
```

**5. Pool for 高频 alloc**:
```rust
let pool = ObjectPool::new(|| ExpensiveObject::new());
let obj = pool.acquire();  // 复用
// ...
pool.release(obj);  // 不 drop,放回 pool
```

工业 Rust 代码综合用这些模式。
