
# Day 139 · 声音混音入门

> 多个声音同时播放:脚步声 + 背景音乐 + 玩家攻击声 + 怪物吼叫。怎么把它们"加起来"输出到一个声卡?混音(mixing)。今天讲混音的核心数学和工程,为 Day 140 完整实现铺路。

## 0 · 为什么要有这一天

游戏中,玩家走动(脚步声)+ 背景音乐在播 + 攻击声 + 怪物吼叫——多个声音源同时播放。声卡只有一个输出(立体声),怎么把所有声音"合成"成两路(left + right)?

**今天的核心:混音就是把多个声音信号相加**。但具体实现有一堆工程问题:

- **音量控制**:每个声音单独调音量(footsteps 0.3,BGM 0.7)
- **clip 防止**:多个声音加起来可能超过 [-1, 1] 范围,直接 clip 会失真,要 soft clip 或动态范围压缩
- **位置 / 速度**:声音位置(3D 空间音效)、速度(多普勒效应)影响左右声道和音量
- **效率**:每秒 44100 样本 × N 个声源 × 60 帧 / 秒,要 SIMD 加速

Casey 在 Day 139 引入混音的概念和数学,Day 140 完整实现。Day 141-146 逐步优化(streaming、pitch shift、SIMD)。

心理锚点:做完今天你能(1)实现一个最简混音器(`output = sum(sound * volume for sound in playing_sounds)`);(2)解释为什么 hard clip 失真,soft clip(tanh)更自然;(3)说出每秒混音需要的运算量;(4)用 Rust 写一个能并发播放多个 WAV 的混音器。

## 2 · 心智模型

### 类比:管弦乐团

混音器像管弦乐团指挥:

- 每个乐器(声源)同时演奏,产生声音波形
- 指挥(混音器)把所有乐器的波形"叠加"成总的声波
- 指挥还能控制每个乐器的音量(小提琴大点,大提琴小点)
- 输出到音箱(声卡)

物理上,真实声波叠加是**线性**的:`总压力 = 压力1 + 压力2 + ...`。混音器模拟这个数学。

### 严谨原理:数字音频信号

数字音频是离散 PCM 样本:

```
时间轴 →
0.0  0.5  1.0  0.5  0.0  -0.5  -1.0  -0.5  0.0  ...  ← 一个正弦波周期(8 样本)
```

每个数代表那一瞬间的声压(归一化 [-1, 1])。

**混音的本质**:两个声音的样本按位相加。

```
Sound A: 0.0  0.5  1.0  0.5  0.0  -0.5  -1.0  -0.5
Sound B: 0.3  0.3  0.3  0.3  0.3   0.3   0.3   0.3   ← 恒定噪音
Sum:     0.3  0.8  1.3  0.8  0.3  -0.2  -0.7  -0.2
                            ↑
                        超过 1.0!需要 clip
```

### 三个工程问题

#### 1. 音量控制

每个声源有独立音量:

```rust
output[i] = sum(sound.samples[i] * sound.volume for sound in playing_sounds);
```

音量 0.0 = 沉默,1.0 = 原音量,2.0 = 加倍(通常 clip)。

#### 2. Clip 防止

N 个声源叠加,振幅可能远超 [-1, 1]。两种处理:

**Hard clip**:简单截断
```rust
output[i] = output[i].max(-1.0).min(1.0);
```
超出范围的样本被"削顶"。听感像爆音,失真严重。

**Soft clip**(tanh):
```rust
output[i] = output[i].tanh();
```
tanh 函数平滑地把大值压缩到 [-1, 1] 内:
- 输入 0.5:输出 0.46(基本线性)
- 输入 1.0:输出 0.76(开始压缩)
- 输入 2.0:输出 0.96(强压缩)
- 输入 10:输出 1.0(饱和)

听感温暖自然,模拟电子管放大器的过载特性。游戏开发常用。

**Dynamic range compression**(动态范围压缩):
```rust
output[i] = output[i] * (1.0 + threshold / (output[i].abs() + threshold));
```
超过阈值后压缩,保留动态范围。专业音频用,游戏开发少用。

#### 3. 多声道(立体声)

每 sample frame 包含 N 声道。Mono:1 个样本。Stereo:2 个(L+R)。

混音时,每个声源有"位置",根据 listener 位置算 pan(左右平衡):

```rust
// 简化:声源在 (sx, sy), listener 在 (lx, ly)
let dx = sx - lx;
let pan = dx / max_distance;  // -1 (左) ~ 1 (右)
let left_volume = sound.volume * (1.0 - pan.max(0.0));
let right_volume = sound.volume * (1.0 + pan.min(0.0));
```

声源在 listener 正前方:pan = 0,L 和 R 同样音量。
声源在 listener 左侧:pan = -1,L 全音量,R 静音。

简单 Casey 版本只支持 stereo pan(不考虑距离衰减)。商业音频库(OpenAL、FMOD)支持完整 3D 音频。

### Rust 实现:标量混音器

```rust
struct PlayingSound {
    samples: Vec<f32>,    // PCM samples(交错 L, R, L, R, ... 或 mono)
    next_sample: usize,   // 当前播放位置
    volume: f32,
    looping: bool,
    is_stereo: bool,
}

impl PlayingSound {
    fn next_sample_pair(&mut self) -> (f32, f32) {
        if self.is_stereo {
            if self.next_sample + 1 >= self.samples.len() {
                if self.looping {
                    self.next_sample = 0;
                } else {
                    return (0.0, 0.0);  // 播完了
                }
            }
            let l = self.samples[self.next_sample] * self.volume;
            let r = self.samples[self.next_sample + 1] * self.volume;
            self.next_sample += 2;
            (l, r)
        } else {
            // mono:同一样本给 L 和 R
            if self.next_sample >= self.samples.len() {
                if self.looping { self.next_sample = 0; }
                else { return (0.0, 0.0); }
            }
            let s = self.samples[self.next_sample] * self.volume;
            self.next_sample += 1;
            (s, s)
        }
    }

    fn done(&self) -> bool {
        !self.looping && self.next_sample >= self.samples.len()
    }
}

struct Mixer {
    sounds: Vec<PlayingSound>,
}

impl Mixer {
    fn new() -> Self { Self { sounds: Vec::new() } }

    fn play(&mut self, sound: PlayingSound) {
        self.sounds.push(sound);
    }

    fn mix(&mut self, output: &mut [f32]) {
        // output 长度 = sample_frames * 2(stereo 交错)
        for chunk in output.chunks_exact_mut(2) {
            let (mut left, mut right) = (0.0f32, 0.0f32);
            // 收集 done 的 sound 的索引
            let mut to_remove = Vec::new();
            for (i, sound) in self.sounds.iter_mut().enumerate() {
                let (l, r) = sound.next_sample_pair();
                left += l;
                right += r;
                if sound.done() { to_remove.push(i); }
            }
            // 移除播完的(从后往前,保持索引)
            for &i in to_remove.iter().rev() {
                self.sounds.remove(i);
            }
            // Soft clip
            chunk[0] = left.tanh();
            chunk[1] = right.tanh();
        }
    }
}
```

### 性能:每秒混音运算量

假设:
- 44100 Hz stereo 输出
- 4 个声源同时播放
- 每样本 1 次乘加(volume)+ 1 次累加

每秒:
- output 样本数:44100 × 2 = 88200
- 每样本操作:4 声源 × (1 取样本 + 1 乘 + 1 累加) = 12 操作
- 总:88200 × 12 = 1,058,400 操作 / 秒

CPU 1 GHz,每秒 10 亿操作,占用 0.1% CPU。极轻量。

如果声源 100 个(开放世界),10 × = 1% CPU。仍很轻。

SIMD 优化(Day 144-145)可以再快 4 倍(用 __m128)。

### 3.3 · 🎨 信号处理视角

混音属于数字信号处理(DSP)的入门:

- **混音**:信号相加(线性组合)
- **滤波**:频率域调整(EQ、低通、高通)
- **混响(reverb)**:模拟房间反射,卷积或反馈延迟网络
- **失真(distortion)**:非线性变换(tanh、cubic)
- **压缩(compression)**:动态范围控制

数字音频基础概念:

| 概念 | 含义 |
|---|---|
| Sample | 离散振幅值 |
| Frame | 所有声道的同时刻样本(stereo frame = L + R = 2 samples) |
| Sample rate | 每秒 frame 数(44100 Hz) |
| Nyquist 频率 | sample_rate / 2,信号最高频率(22050 Hz 是 CD 的上限) |
| Dynamic range | 最大最小信号比,bit depth 决定(16-bit ≈ 96 dB) |
| Frequency | 信号周期(440 Hz = A4 音符) |

Casey Day 139 只用基础混音(相加),不做 DSP 滤波。后续 Day 142-143 加 volume interpolation 和 pitch shift。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:

1. 4 个声源,每个音量 0.5,加起来最大值是多少?需要 clip 吗?
2. hard clip 和 soft clip(tanh)在听感上差别是什么?
3. 为什么混音用 f32 而不是 i16?
4. 每秒 44100 样本 stereo 4 声源,每秒混音运算多少次?

**参考解答**:
1. 最大值 = 4 × 0.5 = 2.0,超过 1.0。需要 clip(否则声卡会输出失真)。
2. hard clip 直接截断,高频谐波产生"嘶嘶"声(削顶失真)。soft clip 平滑压缩,谐波更柔和,听感温暖(像电子管过载)。
3. f32 累加不会溢出(范围 [-1e38, 1e38]),i16 累加会溢出(-32768~32767)。混音需要中间值超过单个 sample 范围,所以用 f32 累加,最后 clip。i16 用于存储 PCM 样本(节省空间),不用于混音中间值。
4. 44100 × 2 声道 × 4 声源 × (1 乘 + 1 加 + 1 取样本) = 1,058,400 操作 / 秒。CPU 几 GHz,占用 < 0.1% CPU。

### Lv2 · 动手实践

**题**:Rust 实现完整混音器,生成 4 个 sine wave 同时播放,输出 WAV 文件验证。

要求:
1. `PlayingSound { samples: Vec<f32>, next_sample: usize, volume: f32, looping: bool }`
2. `Mixer { sounds: Vec<PlayingSound> }`
3. `Mixer::play(sound)`
4. `Mixer::mix(&mut self, output: &mut [f32])` —— stereo 交错
5. main:生成 4 个不同频率(220 / 330 / 440 / 550 Hz)的 sine wave,混音,输出 2 秒

完成标准:`cargo run` 生成 `mixed.wav`,播放听混音效果。

**参考解答**:

```rust
use std::fs::File;
use std::io::Write;

struct PlayingSound {
    samples: Vec<f32>,    // mono samples
    next_sample: usize,
    volume: f32,
    looping: bool,
}

impl PlayingSound {
    fn next_sample(&mut self) -> f32 {
        if self.next_sample >= self.samples.len() {
            if self.looping { self.next_sample = 0; }
            else { return 0.0; }
        }
        let s = self.samples[self.next_sample] * self.volume;
        self.next_sample += 1;
        s
    }

    fn done(&self) -> bool {
        !self.looping && self.next_sample >= self.samples.len()
    }
}

struct Mixer {
    sounds: Vec<PlayingSound>,
}

impl Mixer {
    fn new() -> Self { Self { sounds: Vec::new() } }
    fn play(&mut self, sound: PlayingSound) { self.sounds.push(sound); }

    fn mix(&mut self, output: &mut [f32]) {
        // output 是 stereo 交错:[L0, R0, L1, R1, ...]
        // mono sound 复制到 L 和 R
        for chunk in output.chunks_exact_mut(2) {
            let mut sum = 0.0f32;
            // 收集待删除索引
            let mut done_idx = vec![];
            for (i, s) in self.sounds.iter_mut().enumerate() {
                sum += s.next_sample();
                if s.done() { done_idx.push(i); }
            }
            for &i in done_idx.iter().rev() {
                self.sounds.remove(i);
            }
            // Soft clip
            let clipped = sum.tanh();
            chunk[0] = clipped;
            chunk[1] = clipped;
        }
    }
}

fn generate_sine(freq: f32, duration_s: f32, sample_rate: u32) -> Vec<f32> {
    let n = (duration_s * sample_rate as f32) as usize;
    (0..n).map(|i| {
        (2.0 * std::f32::consts::PI * freq * i as f32 / sample_rate as f32).sin()
    }).collect()
}

fn write_wav_mono(filename: &str, samples: &[f32], sample_rate: u32) -> std::io::Result<()> {
    let mut f = File::create(filename)?;
    let n = samples.len();
    let data_size = n * 2;
    let file_size = 44 + data_size;
    // RIFF header
    f.write_all(b"RIFF")?;
    f.write_all(&(file_size - 8).to_le_bytes())?;
    f.write_all(b"WAVE")?;
    // fmt chunk
    f.write_all(b"fmt ")?;
    f.write_all(&16u32.to_le_bytes())?;
    f.write_all(&1u16.to_le_bytes())?;       // PCM
    f.write_all(&1u16.to_le_bytes())?;       // mono
    f.write_all(&sample_rate.to_le_bytes())?;
    f.write_all(&(sample_rate * 2).to_le_bytes())?;  // byte_rate
    f.write_all(&2u16.to_le_bytes())?;       // block_align
    f.write_all(&16u16.to_le_bytes())?;      // bits_per_sample
    // data chunk
    f.write_all(b"data")?;
    f.write_all(&(data_size as u32).to_le_bytes())?;
    for &s in samples {
        let v = (s * 32767.0).max(-32768.0).min(32767.0) as i16;
        f.write_all(&v.to_le_bytes())?;
    }
    Ok(())
}

fn main() {
    let sample_rate = 44100u32;
    let duration = 2.0f32;

    let mut mixer = Mixer::new();
    // 4 个 sine wave(和弦 A minor)
    for &freq in &[220.0, 261.63, 329.63, 440.0] {  // A3 C4 E4 A4
        let samples = generate_sine(freq, duration, sample_rate);
        mixer.play(PlayingSound {
            samples,
            next_sample: 0,
            volume: 0.2,  // 4 声源 × 0.2 = 0.8 max,留余量
            looping: false,
        });
    }

    let total_samples = (duration * sample_rate as f32) as usize;
    let mut output = vec![0.0f32; total_samples * 2];  // stereo 交错
    mixer.mix(&mut output);

    // 转回 mono 写文件(简化)
    let mono: Vec<f32> = output.chunks_exact(2).map(|c| c[0]).collect();
    write_wav_mono("mixed.wav", &mono, sample_rate).unwrap();
    println!("Wrote mixed.wav ({} samples, {:.1}s)", mono.len(), duration);
    println!("Play: aplay mixed.wav");
}
```

## 10 · 深度推导:混音的工程细节

今天 Casey 教音频混音。看起来简单("两个 sample 加一起"),但有大量工程陷阱。这一节走通。

### 10.1 起点:两路 sample 相加

最朴素的混音:

```rust
fn mix(a: i16, b: i16) -> i16 {
    a + b  // 直接相加
}
```

问题:**overflow**。a = 30000, b = 30000,和 = 60000,但 i16 最大 32767。overflow 到 -5536,听感是爆音。

### 10.2 修复 1:饱和加法

```rust
fn mix_saturating(a: i16, b: i16) -> i16 {
    let sum = a as i32 + b as i32;
    sum.max(-32768).min(32767) as i16
}
```

总和超过 32767 截到 32767。听感是"软 clip",可接受。但失真严重——多路混音时音量被压扁。

### 10.3 修复 2:平均

```rust
fn mix_average(a: i16, b: i16) -> i16 {
    (a as i32 + b as i32) / 2
}
```

不会 overflow,但每路声音被减半。听起来"安静"——10 路混音每路只剩 1/10。

### 10.4 修复 3:浮点混音

```rust
fn mix_f32(sources: &[f32], gains: &[f32]) -> f32 {
    let mut sum = 0.0f32;
    for (s, g) in sources.iter().zip(gains) {
        sum += s * g;
    }
    sum
}
```

f32 表示样本(-1.0 到 1.0)。gain 控制每路音量。混音时把每路乘 gain,累加。最后用 soft clip(tanh 函数)压回 -1 到 1。

这是工业音频标准。Wwise / FMOD / Core Audio / ALSA 都用 f32(或 f64)内部混音。

### 10.5 Rust 完整混音器代码

```rust
pub struct Mixer {
    voices: Vec<Voice>,
    output_buffer: Vec<f32>,
}

pub struct Voice {
    samples: Vec<f32>,    // 当前播放的样本
    position: usize,      // 播放到第几个 sample
    gain: f32,            // 0.0 = 静音,1.0 = 原音量
    looping: bool,
    active: bool,
}

impl Mixer {
    pub fn new() -> Self {
        Self { voices: Vec::new(), output_buffer: Vec::new() }
    }

    pub fn play(&mut self, samples: Vec<f32>, gain: f32, looping: bool) {
        self.voices.push(Voice {
            samples, position: 0, gain, looping, active: true,
        });
    }

    /// 渲染 num_samples 个 sample 到 output_buffer
    pub fn render(&mut self, num_samples: usize) -> &[f32] {
        self.output_buffer.clear();
        self.output_buffer.resize(num_samples, 0.0);

        // 对每个 voice,把它当前的 sample 累加到 output
        for voice in &mut self.voices {
            if !voice.active { continue; }
            for i in 0..num_samples {
                if voice.position >= voice.samples.len() {
                    if voice.looping {
                        voice.position = 0;
                    } else {
                        voice.active = false;
                        break;
                    }
                }
                if voice.position < voice.samples.len() {
                    self.output_buffer[i] += voice.samples[voice.position] * voice.gain;
                    voice.position += 1;
                }
            }
        }

        // soft clip 防止爆音
        for s in &mut self.output_buffer {
            *s = s.tanh();  // tanh 是 soft clip 函数
        }

        // 清理 inactive voices
        self.voices.retain(|v| v.active);

        &self.output_buffer
    }
}

fn main() {
    let mut mixer = Mixer::new();

    // 加一路"枪声"(模拟:锯齿波 100 个 sample)
    let gunshot: Vec<f32> = (0..1000).map(|i| {
        let t = i as f32 / 44100.0;
        (t * 440.0 * 2.0 * std::f32::consts::PI).sin() * (1.0 - t)  // 衰减正弦
    }).collect();
    mixer.play(gunshot, 0.5, false);

    // 加一路"背景音乐"(模拟:持续正弦波)
    let bgm: Vec<f32> = (0..44100).map(|i| {
        let t = i as f32 / 44100.0;
        (t * 220.0 * 2.0 * std::f32::consts::PI).sin() * 0.3
    }).collect();
    mixer.play(bgm, 0.3, true);

    // 渲染 1000 个 sample
    let output = mixer.render(1000);
    println!("Rendered {} samples, peak = {:.3}",
        output.len(),
        output.iter().fold(0.0f32, |a, &b| a.max(b.abs())));
}
```


### 10.6 混音的工业级考量

#### 音量单位

人类听觉是对数尺度。所以音量控制用 dB(分贝):

```
volume_db = 20 * log10(amplitude)
```

- 0 dB = 原音量(1.0)
- -6 dB = 一半音量(0.5)
- -20 dB = 1/10 音量(0.1)

UI 上"音量条"通常是 dB 尺度(0 到 -60),而不是线性。

#### 立体声 vs 单声道

立体声 = 2 channel(左 / 右),单声道 = 1 channel。混音时每 channel 独立:

```rust
struct StereoVoice { left: Vec<f32>, right: Vec<f32> }

// 立体声混音:左右独立
for i in 0..num_samples {
    output_left[i] += voice.left[voice.position] * voice.gain;
    output_right[i] += voice.right[voice.position] * voice.gain;
}
```

立体声 sample 通常交错存储(L R L R L R...),混音时要解交错。

#### 空间音频(3D sound)

3D 游戏:音源在 3D 空间,玩家位置 + 朝向决定左右声道音量。计算:

```rust
let direction = source_pos - listener_pos;
let distance = direction.length();
let attenuation = 1.0 / (1.0 + distance);  // 距离衰减

// 左右声道(简化:假设 listener 朝 Z+ 方向)
let right_volume = direction.x.atan2(direction.z).cos() * attenuation;
let left_volume = -direction.x.atan2(direction.z).cos() * attenuation;
```

OpenAL / FMOD / Wwise 内置这套。Casey HH 是 2D,不做。

#### Sample rate 转换

44.1 kHz 的声音在 48 kHz 设备播放,要 resample。Day 143 详细讨论。

### 10.7 Linux 音频栈

Linux 音频栈分四层:

```
Application (你写的游戏)
    ↓
Library: cpal / rodio / kira / ALSA lib
    ↓
Sound server: PulseAudio / PipeWire (用户态)
    ↓
Kernel: ALSA driver
    ↓
Hardware: HDA / USB DAC
```

`cpal` 是跨平台音频库,Rust 生态最常用。在 Linux 上默认走 ALSA,但可以通过 PipeWire 走 server 模式。

```bash
# 看音频设备

pw-cli list-objects      # PipeWire

# 测试音频
speaker-test -c 2 -t sine -f 440  # 播 440Hz 正弦
```

工业游戏用 PipeWire(现代标准),老系统用 ALSA 直接。Casey 在 Windows 用 WASAPI,在 Linux 假设 ALSA。
