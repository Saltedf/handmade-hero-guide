### 严谨模型:边界情况

#### 空格

```
char ' ' (0x20):
  glyph 没轮廓,没像素
  metrics.advance = 字号 / 4
```

不能用 `GetGlyphOutline(GGO_GRAY8_BITMAP)`,返回空 bitmap。要用 `GGO_METRICS` 只拿 metrics。

#### 缺字符

字体不含某 Unicode 字符(`glyph_id` 返回 0 或 0xFFFF):

- 显示 `□`（豆腐块）
- 或 fallback 到另一字体
- 或完全跳过(advance = 0)

#### Kerning

字母对间距:

```
'A' advance = 12
'V' advance = 11
"A" + "V" = "AV" 间距 = 12 + 11 - 3(kerning) = 20
"A" + "A" = "AA" 间距 = 12 + 12 - 0 = 24
```

kerning 让"A"和"V"贴近(对角对齐)。

Rust FreeType:

```rust
let kerning = face.get_kerning(left_glyph_id, right_glyph_id, KerningMode::Default)?;
// 返回 26.6 fixed point,除以 64
```

#### 多字号

每个字符 × 每个字号:

- 字符集 256(扩展 ASCII)
- 字号 4 个(12, 16, 24, 32)
- 总 glyph = 1024
- 每 glyph 平均 24×24 = 576 像素
- 总像素 = 590 KB → atlas 1024×1024 grayscale

合理。

### 错误处理

每个 GDI / FreeType 调用检查错误:

```rust
match face.load_char(c as usize, LoadFlag::RENDER) {
    Ok(()) => { /* use glyph */ }
    Err(e) => {
        eprintln!("glyph for {} failed: {}", c, e);
        // 使用 fallback glyph 或跳过
    }
}
```

不要 unwrap,字体可能损坏 / 不支持某字符。

```rust
use freetype::{Library, Face, face::LoadFlag};

struct Glyph {
    char: u32,
    width: u32,
    height: u32,
    advance: f32,
    bitmap: Vec<u8>,  // 空 if no outline(如 space)
}

fn extract_glyphs(path: &str, size: u32) -> Vec<Glyph> {
    let lib = Library::init().expect("freetype");
    let mut face: Face = lib.new_face(path, 0).expect("font");
    face.set_pixel_sizes(0, size).expect("size");

    let mut glyphs = Vec::new();
    for c in 32u32..256u32 {
        let char = char::from_u32(c).unwrap_or('\u{FFFD}');
        let result = face.load_char(c as usize, LoadFlag::RENDER);

        match result {
            Ok(()) => {
                let glyph = face.glyph();
                let bitmap = glyph.bitmap();
                let w = bitmap.width() as u32;
                let h = bitmap.rows() as u32;
                let advance = glyph.metrics().horiAdvance as f32 / 64.0;
                glyphs.push(Glyph {
                    char: c,
                    width: w,
                    height: h,
                    advance,
                    bitmap: if w > 0 && h > 0 {
                        bitmap.buffer().to_vec()
                    } else {
                        Vec::new()  // space 等
                    },
                });
            }
            Err(e) => {
                eprintln!("[warn] char {} (U+{:04X}): {}", char, c, e);
                // fallback: tofu block(简单方块)
                let dim = (size / 2) as usize;
                glyphs.push(Glyph {
                    char: c,
                    width: dim as u32,
                    height: dim as u32,
                    advance: dim as f32,
                    bitmap: vec![200u8; dim * dim],
                });
            }
        }
    }
    glyphs
}

fn main() {
    let path = "/usr/share/fonts/TTF/DejaVuSans.ttf";
    let glyphs = extract_glyphs(path, 16);
    println!("extracted {} glyphs", glyphs.len());

    // 找空格
    if let Some(space) = glyphs.iter().find(|g| g.char == ' ' as u32) {
        println!("' ': advance={}, bitmap={}", space.advance, space.bitmap.len());
    }
    // 找 A
    if let Some(a) = glyphs.iter().find(|g| g.char == 'A' as u32) {
        println!("'A': advance={}, {}x{}", a.advance, a.width, a.height);
    }
}
```

## 8 · Rust / Arch 落地代码

```rust
// Cargo.toml: freetype = "0.7"

use freetype::{Library, Face, face::LoadFlag};

#[derive(Debug)]
pub struct Glyph {
    pub char_code: u32,
    pub width: u32,
    pub height: u32,
    pub advance: f32,
    pub bearing_x: i32,
    pub bearing_y: i32,
    pub bitmap: Vec<u8>,
    pub is_missing: bool,
}

pub struct FontSet {
    pub glyphs: Vec<Glyph>,
    pub size: u32,
    pub kerning_pairs: Vec<(u32, u32, f32)>,  // (left, right, kerning)
    pub stats: Stats,
}

#[derive(Default, Debug)]
pub struct Stats {
    pub ok_count: u32,
    pub missing_count: u32,
    pub total_pixels: usize,
}

impl FontSet {
    pub fn extract(path: &str, size: u32, char_range: std::ops::Range<u32>) -> Self {
        let lib = Library::init().expect("freetype");
        let mut face: Face = lib.new_face(path, 0).expect("font");
        face.set_pixel_sizes(0, size).expect("size");

        let mut glyphs = Vec::new();
        let mut stats = Stats::default();
        let mut kerning_pairs = Vec::new();

        for c in char_range {
            let result = face.load_char(c as usize, LoadFlag::RENDER);
            let (bitmap, w, h, advance, bx, by, is_missing) = match result {
                Ok(()) => {
                    let glyph = face.glyph();
                    let bm = glyph.bitmap();
                    let w = bm.width() as u32;
                    let h = bm.rows() as u32;
                    let m = glyph.metrics();
                    let advance = m.horiAdvance as f32 / 64.0;
                    let bx = m.horiBearingX as i32;
                    let by = m.horiBearingY as i32;
                    let buf = if w > 0 && h > 0 { bm.buffer().to_vec() } else { Vec::new() };
                    stats.ok_count += 1;
                    stats.total_pixels += buf.len();
                    (buf, w, h, advance, bx, by, false)
                }
                Err(e) => {
                    eprintln!("[warn] U+{:04X}: {}", c, e);
                    let dim = (size / 2) as usize;
                    stats.missing_count += 1;
                    stats.total_pixels += dim * dim;
                    (vec![200u8; dim * dim], dim as u32, dim as u32, dim as f32, 0, 0, true)
                }
            };

            glyphs.push(Glyph {
                char_code: c,
                width: w,
                height: h,
                advance,
                bearing_x: bx,
                bearing_y: by,
                bitmap,
                is_missing,
            });
        }

        // kerning:常见字母对
        for &(l, r) in &[(b'A', b'V'), (b'A', b'W'), (b'T', b'o'), (b'Y', b'a'), (b'f', b'i')] {
            let lgi = face.get_char_index(l as u64);
            let rgi = face.get_char_index(r as u64);
            if let Ok(k) = face.get_kerning(lgi, rgi, freetype::face::KerningMode::Default) {
                let k_f = k.x as f32 / 64.0;
                if k_f.abs() > 0.01 {
                    kerning_pairs.push((l as u32, r as u32, k_f));
                }
            }
        }

        Self { glyphs, size, kerning_pairs, stats }
    }

    pub fn find(&self, c: u32) -> Option<&Glyph> {
        self.glyphs.iter().find(|g| g.char_code == c)
    }

    pub fn kerning(&self, left: u32, right: u32) -> f32 {
        self.kerning_pairs.iter()
            .find(|(l, r, _)| *l == left && *r == right)
            .map(|(_, _, k)| *k)
            .unwrap_or(0.0)
    }
}

fn main() {
    let path = "/usr/share/fonts/TTF/DejaVuSans.ttf";
    let set = FontSet::extract(path, 16, 32..256);

    println!("size: {}", set.size);
    println!("glyphs: {}", set.glyphs.len());
    println!("stats: {:?}", set.stats);
    println!("kerning pairs: {}", set.kerning_pairs.len());
    for (l, r, k) in &set.kerning_pairs {
        println!("  '{}' + '{}' : kerning = {:.2}", *l as u8 as char, *r as u8 as char, k);
    }

    // 模拟 draw_text
    let text = "AVATAR";
    let mut cursor_x = 0.0;
    let mut prev_char: Option<u32> = None;
    for c in text.chars() {
        let g = set.find(c as u32);
        if let Some(g) = g {
            if let Some(p) = prev_char {
                cursor_x += set.kerning(p, c as u32);
            }
            println!("'{}' advance {} cursor {:.1}", c, g.advance, cursor_x);
            cursor_x += g.advance;
            prev_char = Some(c as u32);
        }
    }
    println!("total width with kerning: {:.1}", cursor_x);
}
```

### A.4 性能优化的工业实践

**L1:算法选择**

- 选择合适数据结构

**L2:数据布局**
- AoS vs SoA
- Cache line alignment
- Branchless code

**L3:并行化**
- multi-threading
- SIMD(单指令多数据)
- GPU compute

**L4:架构调整**
- streaming 替代 load-all
- 增量计算替代全量

**L5:硬件利用**
- GPU 加速
- RTX 核心
- NPU(AI 加速)

每层收益递减但难度递增。Casey 的 phase-4 主要在 L1-L3。

### A.5 Phase 4 的核心 Rust 模式

Phase 4 演示了几个核心 Rust 模式:

**1. Ownership + borrowing**:
- 资源生命周期清晰
- 编译时保证无 use-after-free

**4. Error handling(Result)**:
- 显式错误,无异常
- 类型安全

**5. Atomic / Arc**:
- 多线程安全
- 零开销抽象

这些模式是 Rust 工业级代码的标志。

```rust
use std::sync::Arc;
use std::collections::HashMap;
use std::sync::RwLock;

// Asset storage(引用计数 + 分桶锁)
pub struct AssetStorage<T> {
    shards: Vec<RwLock<HashMap<u32, Arc<T>>>>,
    loader: Box<dyn Fn(u32) -> T + Send + Sync>,
}

impl<T> AssetStorage<T> {
    pub fn new<F>(loader: F) -> Self 
    where F: Fn(u32) -> T + Send + Sync + 'static {
        let num_shards = 16;
        let mut shards = Vec::with_capacity(num_shards);
        for _ in 0..num_shards {
            shards.push(RwLock::new(HashMap::new()));
        }
        Self {
            shards,
            loader: Box::new(loader),
        }
    }
    
    pub fn get(&self, id: u32) -> Arc<T> {
        let shard_idx = (id as usize) % self.shards.len();
        
        // 读路径
        {
            let shard = self.shards[shard_idx].read().unwrap();
            if let Some(asset) = shard.get(&id) {
                return Arc::clone(asset);
            }
        }
        
        // 慢路径:加载
        let asset = Arc::new((self.loader)(id));
        
        // 写路径
        let mut shard = self.shards[shard_idx].write().unwrap();
        let entry = shard.entry(id).or_insert(Arc::clone(&asset));
        Arc::clone(entry)
    }
}

// 用法
fn main() {
    let storage: AssetStorage<String> = AssetStorage::new(|id| {
        format!("texture_{}.png", id)
    });
    
    let a = storage.get(1);
    let b = storage.get(1);
    assert!(Arc::ptr_eq(&a, &b));  // 同一 Arc
}
```

这是工业级 asset storage 的 Rust 骨架——分桶 RwLock + Arc + 加载闭包。

### A.10 内存管理的最佳实践

Phase 4 涉及大量内存管理。最佳实践:

**1. Ownership 清晰**:
- 每资源有明确 owner
- Owner drop → 资源释放
- 不共享 ownership(避免 cycle)

**2. Arena for 临时数据**:
```rust
use bumpalo::Bump;

let arena = Bump::new();
let temp_data: &mut [u32] = arena.alloc_slice_fill_with(1000, |_| 0);
// arena drop → temp_data 自动释放
```

**3. Arc for 长期共享**:
```rust
let shared = Arc::new(ExpensiveResource::new());
let cloned = Arc::clone(&shared);
// 两个 owner 都 drop → resource 释放
```

**4. Weak for cache**:
```rust
let weak: Weak<Resource> = Arc::downgrade(&strong);
// cache 不阻止 strong 释放
if let Some(strong) = weak.upgrade() {
    // 还在用
} else {
    // 已释放
}
```

**5. Pool for 高频 alloc**:
```rust
let pool = ObjectPool::new(|| ExpensiveObject::new());
let obj = pool.acquire();  // 复用
// ...
pool.release(obj);  // 不 drop,放回 pool
```

工业 Rust 代码综合用这些模式。
