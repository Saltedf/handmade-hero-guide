
# Day 156 · 拉格朗日 vs 欧拉模拟

> 粒子系统有两种"看待"流体的方式:**拉格朗日**(跟着粒子走)和**欧拉**(盯着格子看)。Casey 今天对比两者——前者适合稀疏物体(火花、烟),后者适合稠密场(流体、烟柱)。这是计算物理的入门题,游戏里两种都用。

## 0 · 为什么要有这一天

想象你想模拟一片烟从烟囱冒出来。两种思路:

**拉格朗日**(Lagrangian):把烟看作 1 万个小颗粒,每个粒子有自己的位置和速度,**跟着粒子运动**。每帧更新每个粒子。

**欧拉**(Eulerian):把空间切成网格,每格记录"这格的烟密度"、"这格的烟速度"。**网格不动,烟流过网格**。每帧更新每格的状态。

两者数学等价(在连续极限下),但实现、性能、视觉风格完全不同:

| | 拉格朗日 | 欧拉 |
|---|---|---|
| 数据 | N 个粒子 | M 个网格点 |
| 适合 | 稀疏、自由 | 稠密、受限 |
| 边界 | 自然(粒子在哪都行) | 要特殊处理(网格边界) |
| 内存 | 与粒子数成比例 | 与空间体积成比例 |
| 经典例子 | 烟雾、火花、爆炸 | 水流、烟雾柱 |

游戏里:

- 爆炸碎片:拉格朗日
- 水流:欧拉(或混合 SPH)
- 火焰:拉格朗日(视觉)+ 欧拉(物理)
- 烟柱:欧拉

Casey 教学先讲拉格朗日(粒子系统就是),今天讨论欧拉的网格方法。

心理锚点:看完今天,你能解释为什么水模拟用网格、火花用粒子,知道 SPH / FLIP / PIC 这些混合方法是怎么回事。

## 1 · Casey 今天做了什么

Casey 在白板上对比两种方法:

1. **拉格朗日**:每个粒子独立运动,跟随物质
2. **欧拉**:固定网格,跟踪每格的物质属性

具体到代码:

```rust
// 拉格朗日
for p in &mut particles {
    p.pos += p.vel * dt;
    p.vel += gravity * dt;
}

// 欧拉
for cell in grid.iter_mut() {
    cell.density = advect(cell.density, cell.velocity, dt);
    cell.velocity += gravity * dt;
}
```

Casey 讨论:

- **拉格朗日自然处理大位移**:粒子飞出网格外仍能模拟
- **欧拉自然处理不可压缩性**:压力 Poisson 方程在网格上离散求解
- **混合(FLIP/PIC)**:用粒子存数据 + 用网格算力,兼得两者优点
- 游戏:大部分用拉格朗日(简单 + 视觉好),流体模拟用欧拉或 SPH

## 2 · 心智模型

### 类比:看河水

你想描述河水流动。两种观察方式:

**拉格朗日**:你扔一片树叶到河里,**跟着树叶走**,记录它的轨迹。每片树叶一个轨迹,合起来是水流。

**欧拉**:你站在桥上,**盯着水面下的某点**,记录这点的流速。每个观测点是固定坐标,合起来是流场。

两种描述水流的物理本质一样(纳维-斯托克斯方程),但视角不同。

### 严谨模型:数学

拉格朗日:用 `x_p(t)` 表示粒子 p 在时刻 t 的位置。运动方程:

```
dx_p/dt = v_p(t)
dv_p/dt = a_p(x_p, v_p, t)    // 受力
```

每个 p 一组 ODE,Euler 积分即可(粒子的常规做法)。

欧拉:用 `v(x, t)` 表示位置 x 在时刻 t 的速度。运动方程:

```
∂v/∂t + (v · ∇)v = -∇p/ρ + ν ∇²v   // Navier-Stokes
∂ρ/∂t + ∇·(ρv) = 0                  // 连续性
```

PDE,要在网格上离散化。

**为什么欧拉有 `(v · ∇)v` 这项?** 这是"对流"(advection)项——固定点上速度变化不仅因为本地加速,还因为"别处的速度流过来"。拉格朗日没有这项(因为跟着物质走,本地=物质)。

### 网格离散

欧拉方法的网格:

```
+---+---+---+---+
|   |   |   |   |   y
+---+---+---+---+
|   |   |   |   |   ↑
+---+---+---+---+
|   |   |   |   |
+---+---+---+---+
    → x
```

每格存 `(density, vx, vy, pressure)`。N × M 格,4 × 4 字节 = 16 字节/格,1M 格 = 16 MB。

每帧 update:

1. **advection**:速度场把自己"流走"(半拉格朗日法)
2. **force**:加重力、外力
3. **projection**:解压力 Poisson 方程,保证不可压缩

这是流体模拟的标准三步。游戏工业的流体模拟都基于这套。

### 混合方法:PIC / FLIP

混合思想:

- 用粒子存数据(质量、速度)
- 用网格算力(压力 Poisson)
- 力算完后,grid → particles 反插值

PIC(Particle-in-Cell):粒子只存速度,格做计算,结果插值回粒子。
FLIP(Fluid-Implicit-Particle):粒子存速度增量(更精确,但有噪声)。

工业级流体模拟(Houdini、Nucleus)用 FLIP。游戏里像素风暴、Houdini engine 用 PIC。

### 性能对比

| | 拉格朗日 | 欧拉 |
|---|---|---|
| 10K 粒子 | 0.5 ms | — |
| 100K 粒子 | 5 ms | — |
| 1K 网格点 | — | 0.3 ms |
| 100K 网格点(317×317 2D) | — | 5 ms |

网格密度等于分辨率。粒子数等于细节量。100K 粒子和 100K 网格点性能近似。

自己写欧拉网格:

```rust
struct Grid {
    nx: usize,
    ny: usize,
    density: Vec<f32>,   // [ny][nx]
    vx: Vec<f32>,
    vy: Vec<f32>,
}

impl Grid {
    fn idx(&self, x: usize, y: usize) -> usize { y * self.nx + x }

    fn step(&mut self, dt: f32) {
        // 1. advection(简化:半拉格朗日)
        let old_density = self.density.clone();
        let old_vx = self.vx.clone();
        let old_vy = self.vy.clone();
        for y in 1..self.ny-1 {
            for x in 1..self.nx-1 {
                let i = self.idx(x, y);
                // 反向 trace
                let px = x as f32 - old_vx[i] * dt;
                let py = y as f32 - old_vy[i] * dt;
                // 双线性插值
                self.density[i] = bilinear(&old_density, self.nx, self.ny, px, py);
            }
        }
        // 2. force(重力)
        for v in &mut self.vy { *v += 9.8 * dt; }
        // 3. projection(省略,要解 Poisson)
    }
}
```

### 3.4 · 数据结构视角

网格存储选项:

- **`Vec<f32>`**(本日):flat 一维,2D 时索引 `y * nx + x`

- **`ndarray`** crate:numpy 风格多维数组
- **`rgsl`**:Blas 后端,科学计算

工业推荐 `ndarray` 或 `nalgebra`(矩阵操作)。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么拉格朗日方法不需要 `(v · ∇)v` 项,而欧拉需要?

**参考解答**:拉格朗日跟粒子走,粒子的"本地"就是粒子本身,所以"本地加速度"就是粒子加速度 `dv/dt`。

欧拉盯固定点,固定点速度变化两部分:

1. 本地物理变化(力作用):`∂v/∂t`
2. 别处的物质流过来:`(v · ∇)v`

第 2 项是 advection。欧拉代码必须显式算 advection;拉格朗日代码天然包含(因为粒子自己动)。

### Lv2 · 动手实践

**题**:实现一个最简单的 2D 欧拉网格,64 × 64 cells,模拟一个"密度点"被向右风吹动。每 10 帧打印密度的可视化(ASCII)。

**参考解答**:

```rust
const N: usize = 32;

struct Grid {
    density: Vec<f32>,
    vx: Vec<f32>,
}

impl Grid {
    fn new() -> Self {
        let mut g = Self {
            density: vec![0.0; N * N],
            vx: vec![1.0; N * N],   // 整体向右风
        };
        // 初始密度点
        for y in 10..20 {
            for x in 5..10 {
                g.density[y * N + x] = 1.0;
            }
        }
        g
    }

    fn step(&mut self, dt: f32) {
        // 简化 advection:每 cell 从右边取 density(向右风)
        let old = self.density.clone();
        for y in 0..N {
            for x in 0..N {
                let i = y * N + x;
                let src_x = x as f32 - self.vx[i] * dt;
                let xi = src_x.floor() as isize;
                let xf = src_x - xi as f32;
                let x0 = xi.clamp(0, (N - 1) as isize) as usize;
                let x1 = (x0 + 1).min(N - 1);
                let d = old[y * N + x0] * (1.0 - xf) + old[y * N + x1] * xf;
                self.density[i] = d;
            }
        }
    }

    fn dump(&self) {
        for y in (0..N).step_by(1) {
            let mut row = String::new();
            for x in 0..N {
                let d = self.density[(N - 1 - y) * N + x];
                let c = if d > 0.7 { '#' }
                    else if d > 0.3 { '*' }
                    else if d > 0.05 { '.' }
                    else { ' ' };
                row.push(c);
            }
            println!("{}", row);
        }
    }
}

fn main() {
    let mut g = Grid::new();
    for frame in 0..30 {
        g.step(0.5);
        if frame % 10 == 0 {
            println!("\n=== frame {} ===", frame);
            g.dump();
        }
    }
}
```

应该看到密度点逐渐向右移动、扩散。

## 8 · Rust / Arch 落地代码

```rust
const N: usize = 64;

struct Grid {
    density: Vec<f32>,
    vx: Vec<f32>,
    vy: Vec<f32>,
}

impl Grid {
    fn new() -> Self {
        Self {
            density: vec![0.0; N * N],
            vx: vec![0.0; N * N],
            vy: vec![0.0; N * N],
        }
    }

    fn idx(x: usize, y: usize) -> usize { y * N + x }

    /// 双线性插值
    fn bilinear(field: &[f32], fx: f32, fy: f32) -> f32 {
        let x0 = fx.floor() as isize;
        let y0 = fy.floor() as isize;
        let xf = fx - x0 as f32;
        let yf = fy - y0 as f32;
        let x0 = x0.clamp(0, (N - 1) as isize) as usize;
        let y0 = y0.clamp(0, (N - 1) as isize) as usize;
        let x1 = (x0 + 1).min(N - 1);
        let y1 = (y0 + 1).min(N - 1);
        let v00 = field[y0 * N + x0];
        let v01 = field[y0 * N + x1];
        let v10 = field[y1 * N + x0];
        let v11 = field[y1 * N + x1];
        let a = v00 * (1.0 - xf) + v01 * xf;
        let b = v10 * (1.0 - xf) + v11 * xf;
        a * (1.0 - yf) + b * yf
    }

    fn step(&mut self, dt: f32) {
        // 1. advection(半拉格朗日)
        let old_density = self.density.clone();
        let old_vx = self.vx.clone();
        let old_vy = self.vy.clone();
        for y in 0..N {
            for x in 0..N {
                let i = y * N + x;
                let px = x as f32 - old_vx[i] * dt;
                let py = y as f32 - old_vy[i] * dt;
                self.density[i] = Self::bilinear(&old_density, px, py);
                self.vx[i] = Self::bilinear(&old_vx, px, py);
                self.vy[i] = Self::bilinear(&old_vy, px, py);
            }
        }
        // 2. 重力
        for v in &mut self.vy { *v += 0.5 * dt; }
    }

    fn add_source(&mut self, x: usize, y: usize, density: f32, vx: f32, vy: f32) {
        let i = Self::idx(x, y);
        self.density[i] = density;
        self.vx[i] = vx;
        self.vy[i] = vy;
    }

    fn dump(&self) {
        for y in (0..N).rev() {
            let mut row = String::new();
            for x in 0..N {
                let d = self.density[y * N + x];
                let c = if d > 0.7 { '#' }
                    else if d > 0.3 { '*' }
                    else if d > 0.05 { '.' }
                    else { ' ' };
                row.push(c);
            }
            println!("{}", row);
        }
    }
}

fn main() {
    let mut g = Grid::new();
    // 持续源
    for _ in 0..60 {
        g.add_source(N/2, N-1, 1.0, 0.0, -5.0);
        g.step(0.1);
    }
    g.dump();
}
```

**预期**:底部中心源喷出"烟柱"向上飘,可视化成 ASCII 图。

### A.7 工业 Rust 代码示例

让我提供一个具体的工业 Rust 代码示例,综合 phase-4 的概念:

```rust
use std::sync::Arc;
use std::sync::RwLock;
use std::collections::HashMap;
use std::path::Path;

/// Asset storage with sharded locking and async loading.
pub struct AssetStorage<T> {
    shards: Vec<RwLock<HashMap<u32, Arc<T>>>>,
    loader: Box<dyn Fn(u32) -> Result<T, AssetError> + Send + Sync>,
}

impl<T: Send + Sync + 'static> AssetStorage<T> {
    pub fn new<F>(loader: F) -> Self
    where
        F: Fn(u32) -> Result<T, AssetError> + Send + Sync + 'static,
    {
        let num_shards = 16;
        let mut shards = Vec::with_capacity(num_shards);
        for _ in 0..num_shards {
            shards.push(RwLock::new(HashMap::new()));
        }
        Self {
            shards,
            loader: Box::new(loader),
        }
    }
    
    pub fn get(&self, id: u32) -> Result<Arc<T>, AssetError> {
        let shard_idx = (id as usize) % self.shards.len();
        
        // Fast path: read lock
        {
            let shard = self.shards[shard_idx].read().unwrap();
            if let Some(asset) = shard.get(&id) {
                return Ok(Arc::clone(asset));
            }
        }
        
        // Slow path: load and insert
        let asset = (self.loader)(id)?;
        let arc = Arc::new(asset);
        
        let mut shard = self.shards[shard_idx].write().unwrap();
        let entry = shard.entry(id).or_insert(Arc::clone(&arc));
        Ok(Arc::clone(entry))
    }
    
    pub fn evict_unused(&self) {
        for shard in &self.shards {
            let mut shard = shard.write().unwrap();
            shard.retain(|_, arc| Arc::strong_count(arc) > 1);
        }
    }
}

#[derive(Debug)]
pub enum AssetError {
    NotFound(u32),
    Io(std::io::Error),
    Invalid(String),
}

// 用法
fn main() {
    let storage: AssetStorage<Vec<u8>> = AssetStorage::new(|id| {
        Ok(vec![id as u8; 100])
    });
    
    let a = storage.get(42).unwrap();
    let b = storage.get(42).unwrap();
    assert!(Arc::ptr_eq(&a, &b));
}
```

这是工业级 Rust asset storage 的完整骨架——分桶 RwLock + Arc + lazy loading + eviction。

use std::sync::{Arc, RwLock};
use std::collections::HashMap;
use std::path::{Path, PathBuf};

// === Arena allocator ===
pub struct Arena {
    buffer: Vec<u8>,
    offset: usize,
}

impl Arena {
    pub fn new(capacity: usize) -> Self {
        Self {
            buffer: vec![0u8; capacity],
            offset: 0,
        }
    }
    
    pub fn alloc<T>(&mut self, value: T) -> &mut T {
        let size = std::mem::size_of::<T>();
        let align = std::mem::align_of::<T>();
        
        // Align offset
        let aligned_offset = (self.offset + align - 1) & !(align - 1);
        self.offset = aligned_offset + size;
        
        assert!(self.offset <= self.buffer.len(), "arena overflow");
        
        let ptr = unsafe { self.buffer.as_mut_ptr().add(aligned_offset) as *mut T };
        unsafe { ptr.write(value) };
        unsafe { &mut *ptr }
    }
    
    pub fn reset(&mut self) {
        self.offset = 0;
    }
}

// === Asset Storage ===
pub struct AssetStorage<T: Send + Sync + 'static> {
    shards: Vec<RwLock<HashMap<u32, Arc<T>>>>,
    loader: Box<dyn Fn(u32) -> Result<T, AssetError> + Send + Sync>,
}

impl<T: Send + Sync + 'static> AssetStorage<T> {
    pub fn new<F>(loader: F) -> Self
    where F: Fn(u32) -> Result<T, AssetError> + Send + Sync + 'static {
        let mut shards = Vec::with_capacity(16);
        for _ in 0..16 {
            shards.push(RwLock::new(HashMap::new()));
        }
        Self { shards, loader: Box::new(loader) }
    }
    
    pub fn get(&self, id: u32) -> Result<Arc<T>, AssetError> {
        let shard_idx = (id as usize) % self.shards.len();
        {
            let shard = self.shards[shard_idx].read().unwrap();
            if let Some(a) = shard.get(&id) {
                return Ok(Arc::clone(a));
            }
        }
        let asset = (self.loader)(id)?;
        let arc = Arc::new(asset);
        let mut shard = self.shards[shard_idx].write().unwrap();
        let entry = shard.entry(id).or_insert(Arc::clone(&arc));
        Ok(Arc::clone(entry))
    }
}

#[derive(Debug)]
pub enum AssetError {
    NotFound(u32),
    Io(std::io::Error),
}

// === Particle system (parallel) ===
use rayon::prelude::*;

pub struct Particle {
    pub pos: [f32; 3],
    pub vel: [f32; 3],
    pub life: f32,
}

pub fn update_particles(particles: &mut [Particle], dt: f32, gravity: [f32; 3]) {
    particles.par_iter_mut().for_each(|p| {
        p.vel[0] += gravity[0] * dt;
        p.vel[1] += gravity[1] * dt;
        p.vel[2] += gravity[2] * dt;
        p.pos[0] += p.vel[0] * dt;
        p.pos[1] += p.vel[1] * dt;
        p.pos[2] += p.vel[2] * dt;
        p.life -= dt;
    });
}

// === Main ===
fn main() {
    let mut arena = Arena::new(1024);
    let x: &mut u32 = arena.alloc(42);
    println!("Arena allocated: {}", x);
    
    let storage: AssetStorage<String> = AssetStorage::new(|id| {
        Ok(format!("asset_{}", id))
    });
    let a = storage.get(1).unwrap();
    println!("Asset: {}", a);
    
    let mut particles: Vec<Particle> = (0..1000).map(|_| Particle {
        pos: [0.0; 3], vel: [0.0, 0.0, 1.0], life: 5.0,
    }).collect();
    update_particles(&mut particles, 0.016, [0.0, -9.8, 0.0]);
    println!("Updated {} particles", particles.len());
}
