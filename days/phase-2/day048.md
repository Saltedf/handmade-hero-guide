**核心算法**:把两条线段参数化(L1(t) = P1 + t(D1),L2(s) = P3 + s(D2)),解方程组找 t 和 s。如果 t 和 s 都在 [0, 1] 范围内,相交。算法用 2D 叉积(标量,ax\*by - ay\*bx)处理,简洁高效。

2. 解释为什么 2D 叉积是标量(不是向量),几何意义是"平行四边形面积"
3. 用线段相交判断"剑砍到怪没有"

这是计算几何的基础,后面所有"线 vs X"算法的母题。

## 2 · 心智模型

### 费曼类比:两根铅笔相交吗

桌上有两根铅笔。你怎么知道它们相交?

**目测**(几何直觉):看一根铅笔的两端在另一根铅笔的"两侧"——如果两侧(左/右),且反之也成立,两根相交。

**代数**(数学公式):把两根铅笔表示为参数化线段(从起点 + 方向 × 参数),解方程组找参数。

两种方法等价,但**目测**(基于"两侧"判断)在代码里更高效。我们今天讲两种,看你能在脑子里切换。

### 严谨定义:线段参数方程

**线段 L1 从 P1 到 P2**:

```
L1(t) = P1 + t * (P2 - P1), t ∈ [0, 1]
```

- t = 0:L1(0) = P1(起点)
- t = 1:L1(1) = P2(终点)
- t = 0.5:L1(0.5) = P1 + 0.5 * (P2 - P1) = 中点

**线段 L2 从 P3 到 P4**:

```
L2(s) = P3 + s * (P4 - P3), s ∈ [0, 1]
```

**相交条件**:存在 t, s ∈ [0, 1] 使 L1(t) = L2(s)。

### 推导:解方程组

设 D1 = P2 - P1(L1 方向),D2 = P4 - P3(L2 方向)。方程:

```
P1 + t * D1 = P3 + s * D2
```

移项:

```
t * D1 - s * D2 = P3 - P1
```

设 Diff = P3 - P1。这是二维向量方程(两个分量),展开:

```
t * D1.x - s * D2.x = Diff.x
t * D1.y - s * D2.y = Diff.y
```

2 个未知数(t, s),2 个方程,标准线性方程组。用 Cramer 法则或消元法解。

**用 Cramer 法则**(行列式):

主行列式 `det = D1.x * (-D2.y) - (-D2.x) * D1.y = -D1.x * D2.y + D2.x * D1.y = -(D1 × D2)`

其中 D1 × D2 是 2D 叉积(标量):`D1.x * D2.y - D1.y * D2.x`。

所以 `det = -(D1 × D2)`。

如果 det = 0(D1 × D2 = 0):**D1 和 D2 平行**,无解或无穷解(线段共线)。返回 false(或单独处理共线情况)。

否则:

```
t = (Diff.x * (-D2.y) - (-D2.x) * Diff.y) / det
  = -(Diff.x * D2.y - D2.x * Diff.y) / det
  = -(Diff × D2) / det
  = (Diff × D2) / (D1 × D2)

s = (D1.x * Diff.y - D1.y * Diff.x) / det
  = (D1 × Diff) / det
  = -(D1 × Diff) / (D1 × D2)
```

简化后:

```
denom = D1 × D2 = (P2.x - P1.x) * (P4.y - P3.y) - (P2.y - P1.y) * (P4.x - P3.x)
t = ((P3.x - P1.x) * (P4.y - P3.y) - (P3.y - P1.y) * (P4.x - P3.x)) / denom
s = ((P3.x - P1.x) * (P2.y - P1.y) - (P3.y - P1.y) * (P2.x - P1.x)) / denom
```

**相交 ⟺ t ∈ [0, 1] 且 s ∈ [0, 1]**。

### 2D 叉积的几何意义

2D 叉积 `a × b = a.x * b.y - a.y * b.x`,结果是**标量**(不是向量)。

**几何意义**:这是向量 a 和 b 构成的**平行四边形的有符号面积**。

```
    b
   ↗
  /
 /
●─────►  a
a × b > 0(b 在 a 的逆时针方向)
```

- a × b > 0:b 在 a 的**逆时针方向**(数学正向)
- a × b < 0:b 在 a 的**顺时针方向**
- a × b = 0:a 和 b **平行**(或其中一个为零)

**为什么是平行四边形面积?** 看 |a × b| = |a| |b| sin(θ)。这是平行四边形面积公式(底 × 高)。

**用叉积判断"点在直线哪一侧"**:有向线段 AB,点 P,算 `(B - A) × (P - A)`:

- > 0:P 在 AB 的左侧
- < 0:P 在 AB 的右侧
- = 0:P 在 AB 上

这是计算几何的瑞士军刀,后面所有"哪边"、"内外"问题都用。

### 线段相交的叉积判定法

**经典算法**:两条线段 AB 和 CD 相交 ⟺ "A 和 B 在 CD 两侧" 且 "C 和 D 在 AB 两侧"。

```
A 和 B 在 CD 两侧 ⟺ (CD × CA) 和 (CD × CB) 符号不同
                     ⟺ (CD × CA) * (CD × CB) < 0
```

代码:

```rust
fn cross(o: Vec2, a: Vec2, b: Vec2) -> f32 {
    // (a - o) × (b - o),o 是角点
    (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x)
}

fn segments_intersect(p1: Vec2, p2: Vec2, p3: Vec2, p4: Vec2) -> bool {
    let d1 = cross(p3, p4, p1);  // p1 相对于线段 p3-p4
    let d2 = cross(p3, p4, p2);  // p2 相对于线段 p3-p4
    let d3 = cross(p1, p2, p3);  // p3 相对于线段 p1-p2
    let d4 = cross(p1, p2, p4);  // p4 相对于线段 p1-p2

    // p1 和 p2 在 p3-p4 两侧,且 p3 和 p4 在 p1-p2 两侧
    ((d1 > 0.0 && d2 < 0.0) || (d1 < 0.0 && d2 > 0.0)) &&
    ((d3 > 0.0 && d4 < 0.0) || (d3 < 0.0 && d4 > 0.0))
}
```

**4 个叉积 + 4 个比较**,无 sqrt,无除法。极快。

**边界情况**:如果 d1 = 0(p1 在 p3-p4 直线上),需要单独判断 p1 是否在线段 p3-p4 上。这里简化,假设一般情况(任一端点都不在线上)。

### 完整代码(带边界处理)

```rust
impl Vec2 {
    pub fn cross(self, other: Self) -> f32 {
        self.x * other.y - self.y * other.x
    }
}

/// 检查点 P 是否在线段 AB 上(假设 P 已经在直线 AB 上)
fn on_segment(a: Vec2, b: Vec2, p: Vec2) -> bool {
    p.x >= a.x.min(b.x) && p.x <= a.x.max(b.x) &&
    p.y >= a.y.min(b.y) && p.y <= a.y.max(b.y)
}

/// 两线段相交
pub fn segments_intersect(p1: Vec2, p2: Vec2, p3: Vec2, p4: Vec2) -> bool {
    let d1 = (p3 - p4).cross(p1 - p3);  // p1 相对 p3-p4
    let d2 = (p3 - p4).cross(p2 - p3);  // p2 相对 p3-p4
    let d3 = (p1 - p2).cross(p3 - p1);  // p3 相对 p1-p2
    let d4 = (p1 - p2).cross(p4 - p1);  // p4 相对 p1-p2

    if ((d1 > 0.0 && d2 < 0.0) || (d1 < 0.0 && d2 > 0.0)) &&
       ((d3 > 0.0 && d4 < 0.0) || (d3 < 0.0 && d4 > 0.0)) {
        return true;  // 一般相交
    }

    // 边界:某点在另一直线上且在线段上
    if d1 == 0.0 && on_segment(p3, p4, p1) { return true; }
    if d2 == 0.0 && on_segment(p3, p4, p2) { return true; }
    if d3 == 0.0 && on_segment(p1, p2, p3) { return true; }
    if d4 == 0.0 && on_segment(p1, p2, p4) { return true; }

    false
}
```

`d1 == 0.0` 用浮点 `==` 有精度风险,工程代码用 `d1.abs() < 1e-6`。但教学演示用 `==` 直观。

### 应用:剑砍怪

```rust
pub struct Sword {
    pub start: Vec2,
    pub end: Vec2,
}

pub struct Monster {
    pub aabb_min: Vec2,
    pub aabb_max: Vec2,
}

impl Monster {
    pub fn hit_by(&self, sword: &Sword) -> bool {
        // 剑线段 vs AABB 的 4 条边
        let corners = [
            self.aabb_min,
            Vec2::new(self.aabb_max.x, self.aabb_min.y),
            self.aabb_max,
            Vec2::new(self.aabb_min.x, self.aabb_max.y),
        ];
        for i in 0..4 {
            let j = (i + 1) % 4;
            if segments_intersect(sword.start, sword.end, corners[i], corners[j]) {
                return true;
            }
        }
        // 还要检查剑是否完全在 AABB 内(没穿过边但可能内嵌)
        // 简化:假设剑总是从玩家位置向外挥,不会完全在 AABB 内
        false
    }
}
```

剑线段检查 AABB 的 4 条边,任一相交即砍中。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏里线段相交的应用:

**1. 攻击范围判定**(arc / cone attack):范围攻击不是单条线段,是"扇形"。把扇形近似成多个三角形,每个三角形是 3 条线段,逐个检查。

**2. AI 视野**(line of sight):NPC 到玩家是一条线段,中间所有障碍物的边都检查。任一相交 → 视线被挡。

**3. 抓钩 / 钩爪**:玩家发射钩爪,钩爪线段检查所有可抓物体。第一个相交的就是钩到的目标。

**4. 路径规划**(pathfinding):A* 算法的"直线段是否可走"用线段相交检查障碍物边。

**5. 碰撞响应**(sliding along wall):玩家撞墙后,沿墙滑行。滑行轨迹是新线段,要检查是否撞到其他墙。

#### 性能注意

1000 个怪物 × 4 条 AABB 边 × 60 FPS = 240000 次线段相交/秒。每次 ~50 ns,总 12 ms——可能占整个 update 的 50%+。

**优化**:

- 用空间网格(Day 057)先剔除远距离怪物
- 把剑的扇形近似成更少的线段(精度换性能)
- 用 AABB 的"快速剔除"先判断剑线段的 AABB 和怪物 AABB 是否重叠

### 3.2 · 🎨 图形学视角

图形学里线段相交是基础工具:

**1. 光线追踪**(ray tracing):每条射线和场景里所有三角形检查相交。Day 422+ 详细。

**2. 多边形裁剪**(polygon clipping):Sutherland-Hodgman 算法用线段相交处理多边形和多边形裁剪。

**3. 软阴影**(soft shadows):从光源发射多条射线,检查是否被挡。被挡 = 阴影。

**4. 屏幕空间反射**(SSR):从相机发射反射射线,在 depth buffer 上检查相交。

**5. 抗锯齿**(MSAA):三角形边的像素需要"部分覆盖"计算,内部用线段相交算覆盖率。

GPU shader 里线段相交用类似 CPU 的公式,但并行处理成千上万对线段。

### 3.4 · 🦀 Rust 生态视角

#### Rust 写法

```rust
impl Vec2 {
    pub fn cross(self, other: Self) -> f32 {
        self.x * other.y - self.y * other.x
    }
}

// 关联函数(自由函数)风格
pub fn segments_intersect(p1: Vec2, p2: Vec2, p3: Vec2, p4: Vec2) -> bool {
    let d1 = (p3 - p4).cross(p1 - p3);
    let d2 = (p3 - p4).cross(p2 - p3);
    let d3 = (p1 - p2).cross(p3 - p1);
    let d4 = (p1 - p2).cross(p4 - p1);

    ((d1 > 0.0) ^ (d2 > 0.0)) && ((d3 > 0.0) ^ (d4 > 0.0))
}
```

**用 XOR(`^`)** 优雅表达"符号不同":如果 d1 > 0 是 true,d2 > 0 是 false,XOR 为 true(符号不同)。比 `(d1 > 0 && d2 < 0) || (d1 < 0 && d2 > 0)` 简洁。

#### 测试

## 4 · 认知地图

### 4.1 上级

- **计算几何**(computational geometry) —— 用算法处理几何对象
- **线性方程组求解** —— Cramer 法则 / 高斯消元
- **2D 叉积 / 行列式** —— 平行四边形面积的代数表示
- **参数化几何对象** —— 用参数(t, s)表示线段 / 曲线

### 4.2 同级(并行方案对比)

| 算法 | 复杂度 | 用途 |
|---|---|---|
| 叉积判定法 | O(1) | 2D 线段 vs 线段,最快 |
| 参数方程 + Cramer | O(1) | 等价叉积法,公式形式 |
| 矩阵求交 | O(1) | 数学等价,代码冗长 |
| Bresenham 像素遍历 | O(L),L = 线段像素长度 | 像素级判定,慢 |
| Monte Carlo 采样 | O(N) | 教学用,不实用 |

叉积判定法最快,生产代码都用它。

### 4.3 下级

- **2D 叉积** —— a × b = ax\*by - ay\*bx(标量,平行四边形面积)
- **参数方程 L(t)** —— 线段的标准表示
- **denom = D1 × D2** —— 检测平行
- **t, s 范围检查** —— [0, 1] 表示在线段内
- **on_segment 边界处理** —— 共端点 / 内嵌情况

## 5 · 对照与变奏

### 2D vs 3D 线段相交

2D:叉积是标量,直接判断符号。

3D:叉积是向量,两条 3D 线段一般**不相交**(异面直线)。判断更复杂——需要先检查共面,再 2D 化。

但游戏里 3D 一般用"线段 vs 三角形"(ray-triangle),不是"线段 vs 线段"。Möller-Trumbore 算法是标准(Day 422+)。

### 不同"相交"定义

**严格相交**:有公共点。

**穿过**(cross):两条线段在某点交叉,不是端点。

**接触**(touch):只有端点公共。

**重叠**(overlap):两条共线线段部分覆盖。

游戏里通常关心"严格相交"或"穿过",端点接触和重叠单独处理。今天的代码处理一般情况,边界用 `on_segment` 补充。

### CPU 算法 vs GPU 算法

CPU:线段相交一次处理一对,O(1)。批量处理时遍历所有对。

GPU:shader 一次处理上千对(并行)。片段 shader 不太适合,但 compute shader 适合。

游戏开发 CPU 算游戏逻辑(剑砍怪),GPU 算光线追踪(射线 vs 三角形)。Day 235+ 切 OpenGL 后,GPU 端的 raycasting 会大量用类似算法。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:2D 叉积 `a × b = ax*by - ay*bx` 为什么是标量而不是向量?它的几何意义是什么?

**参考解答**:

**为什么是标量**:2D 叉积的"结果"是 z 方向的向量(垂直于 xy 平面)。但 2D 没有 z 维度,所以我们只取 z 分量(标量)。

数学上,3D 叉积 `(ax, ay, 0) × (bx, by, 0) = (0, 0, ax*by - ay*bx)`。z 分量就是 2D 叉积。所以我们说 2D 叉积"是标量",其实它是 3D 叉积的 z 分量。

**几何意义**:`|a × b| = |a| |b| sin(θ)`,这是 a 和 b 构成的**平行四边形的面积**(底 |a| × 高 |b| sin(θ))。

符号约定(右手坐标系,z 向上):

- a × b > 0:b 在 a 的**逆时针**方向(数学正向)
- a × b < 0:b 在 a 的**顺时针**方向
- a × b = 0:a 和 b **平行**

**应用**:判断点 P 在有向线段 AB 的哪一侧——`(B - A) × (P - A)` 的符号。这是计算几何的核心操作。

// math.rs
impl Vec2 {
    pub fn cross(self, other: Self) -> f32 {
        self.x * other.y - self.y * other.x
    }
}

pub fn segments_intersect(p1: Vec2, p2: Vec2, p3: Vec2, p4: Vec2) -> bool {
    let d1 = (p4 - p3).cross(p1 - p3);
    let d2 = (p4 - p3).cross(p2 - p3);
    let d3 = (p2 - p1).cross(p3 - p1);
    let d4 = (p2 - p1).cross(p4 - p1);

    let sign = |x: f32| if x > 0.0 { 1 } else if x < 0.0 { -1 } else { 0 };

    let s1 = sign(d1);
    let s2 = sign(d2);
    let s3 = sign(d3);
    let s4 = sign(d4);

    // 一般情况:符号不同
    if s1 != 0 && s2 != 0 && s3 != 0 && s4 != 0 {
        return s1 != s2 && s3 != s4;
    }

    // 边界:某点在线段上(on_segment 判断)
    let on_seg = |a: Vec2, b: Vec2, p: Vec2| -> bool {
        p.x >= a.x.min(b.x) - 1e-6 && p.x <= a.x.max(b.x) + 1e-6 &&
        p.y >= a.y.min(b.y) - 1e-6 && p.y <= a.y.max(b.y) + 1e-6
    };

    if s1 == 0 && on_seg(p3, p4, p1) { return true; }
    if s2 == 0 && on_seg(p3, p4, p2) { return true; }
    if s3 == 0 && on_seg(p1, p2, p3) { return true; }
    if s4 == 0 && on_seg(p1, p2, p4) { return true; }

    false
}

// monster.rs
use crate::math::Vec2;

pub struct Monster {
    pub aabb_min: Vec2,
    pub aabb_max: Vec2,
}

impl Monster {
    pub fn hit_by_sword(&self, sword_start: Vec2, sword_end: Vec2) -> bool {
        // 检查剑和 AABB 4 条边
        let corners = [
            self.aabb_min,
            Vec2::new(self.aabb_max.x, self.aabb_min.y),
            self.aabb_max,
            Vec2::new(self.aabb_min.x, self.aabb_max.y),
        ];
        for i in 0..4 {
            let j = (i + 1) % 4;
            if crate::math::segments_intersect(
                sword_start, sword_end, corners[i], corners[j],
            ) {
                return true;
            }
        }
        // 检查剑是否完全在 AABB 内(剑两端都在 AABB 内)
        if self.contains(sword_start) || self.contains(sword_end) {
            return true;
        }
        false
    }

    fn contains(&self, p: Vec2) -> bool {
        p.x >= self.aabb_min.x && p.x <= self.aabb_max.x &&
        p.y >= self.aabb_min.y && p.y <= self.aabb_max.y
    }
}

### Lv3 · 迁移设计

**题**:实现**射线 vs 圆**相交(ray-circle intersection):

- 射线 `R(t) = O + t * D`,t ≥ 0,O 是起点,D 是单位方向
- 圆 `(P - C)² = r²`,C 是圆心,r 是半径
- 算第一个 t > 0 的相交点(如果存在)

要求:

1. 推导公式(提示:代入射线方程到圆方程,解二次方程)
2. 实现 `ray_circle_intersect(origin, dir, center, radius) -> Option<f32>`(返回 t 或 None)
3. 测试:射线朝圆心射(必相交)、射线朝相反方向(不相交)、射线擦边(刚好相切)

**提示**:

- 把 R(t) 代入圆:`|O + tD - C|² = r²`
- 展开:`|D|²t² + 2(O-C)·D * t + |O-C|² - r² = 0`
- 因为 D 是单位向量,|D|² = 1
- 标准 2 次方程 at² + bt + c = 0,a=1, b=2(O-C)·D, c=|O-C|²-r²
- 判别式 Δ = b² - 4ac,Δ > 0 有解

为什么这个练习有价值?因为"射线 vs 形状"是光线追踪的基础。圆是最简单的形状(只有 2 次方程),后面三角形、AABB、球(3D 版圆)都是类似套路。做完这个,你就能学 ray-tracing。

### Troubleshooting

**问题 1**:测试用例相交,但函数返回 false

原因:可能叉积方向算错了。检查你的叉积公式:`a.x * b.y - a.y * b.x`(不是 `a.y * b.x - a.x * b.y`)。

修复:确认 cross 公式。如果是 `(p4 - p3).cross(p1 - p3)`,确保两个减法顺序对。

**问题 2**:共端点测试失败

原因:浮点精度让 d = 0 实际是 d = 1e-8。

修复:用 `sign` 函数,或者边界检查用 `|d| < 1e-6`。

**问题 3**:剑砍不到完全在 AABB 内的怪物

原因:剑线段和 AABB 4 条边都不相交(剑在 AABB 内),但代码没处理"剑完全在内"。

修复:加 `monster.contains(sword_start) || monster.contains(sword_end)` 检查(参考 Lv2)。

**问题 4**:性能比预期慢(每次 > 20 ns)

原因:可能没开 release,或者 on_segment 函数没 inline。

修复:`cargo run --release`,加 `#[inline]` 给 on_segment。
