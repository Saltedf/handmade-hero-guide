# Day 044 · 向量反射

> 一颗子弹打墙,弹起来该往哪飞?光打镜面,反射到眼睛是什么方向?玩家撞墙后速度怎么变?这三个问题,在数学上是同一个:已知入射向量 v 和墙的法线 n,反射向量 v' 是什么?Casey 在 Day 044 推导出 `v' = v - 2(v·n)n`,从此 HH 的所有碰撞反弹代码都基于它。

## 0 · 为什么要有这一天

Day 043 你让玩家动起来,有加速度、速度、位置。但玩家撞到墙时怎么办?最朴素的处理是"撞墙就停下"——但这样反弹球、台球、激光谜题全都做不出来。你需要让玩家在撞墙后**改变方向继续运动**。

这就要用到**向量反射**(vector reflection)。物理课学过"入射角 = 反射角"(光的镜面反射),但用代码表达这个规律需要把它转成向量公式。

Casey 在这集做了一件**纯数学推导**的事:在黑板上画一个向量 v 撞墙(法线 n),分解、重组,推出 `v' = v - 2(v·n)n`。这个公式看似简单(一行字),但背后的几何分解是向量代数的精华——把任意向量分解成"沿墙"和"垂直墙"两个分量,然后只翻转垂直分量。Day 044 之后,你会反复用到这个技巧(光照的 Phong 高光、声学回声、激光武器、粒子碰撞)。

心理锚点:做完今天,你应该能在白板上推 `v' = v - 2(v·n)n` 公式,知道 2 的来历(不是 1 也不是 3),知道为什么 n 必须归一化(不归一化会怎样)。这是判断"你懂反射"还是"你背了反射公式"的试金石。

## 1 · Casey 今天做了什么

Casey 在 day044 视频里做了三件事:

1. **画黑板推导**:`v` 撞墙(法线 `n`),分解 v 成"沿墙分量"(`v - (v·n)n`)和"垂直墙分量"(`(v·n)n`)。反射 = 翻转垂直分量 = `v' = v - 2(v·n)n`。Casey 反复强调 "2 来自翻转"(原分量减去 2 倍自己 = 反向)。
2. **写 Rust 函数**(C 原版是 C 函数):

   ```c
   v2 Reflect(v2 v, v2 n) {
       n = Normalize(n);
       float d = Dot(v, n);
       return v - 2.0f * d * n;
   }
   ```

3. **应用到玩家撞墙逻辑**:玩家撞墙时调用 `Reflect(player.vel, wall_normal)`,把反射后的速度赋回 `player.vel`。玩家就被弹开,而不是卡住。

Casey 在视频里花时间讨论"法线方向约定"——n 应该指向玩家还是指向墙内部?他选**指向玩家**(法线指向"墙外",即玩家来的一侧)。这个约定决定了 `(v·n)` 的符号,影响代码可读性。

## 2 · 心智模型

### 费曼类比:反弹球 vs 沿墙滑

想象一颗球以速度 v 撞墙。两种理想化处理:

**A. 完美反弹**(perfect bounce,台球):球沿原路反向回去。这要求 v 完全垂直于墙(正面撞)。但通常球是斜着撞的,所以这是特殊情况。

**B. 沿墙滑**(slide,无反弹):球失去垂直墙方向的速度,保留沿墙方向的速度。如果球斜着撞墙,撞完球贴着墙走。

**真实的反射是 A 和 B 的中间**:沿墙分量保留(像 B),垂直墙分量反向(像 A 的垂直部分)。

```
入射 v:        反射 v':
   \              /
    \            /
     \  ↑n     /
      \ |    /
       \|__/
     ───────── 墙
```

入射 v 斜向下右,撞墙(法线 n 向上)。沿墙分量(水平)保留,垂直墙分量(向下)反向(向上)。合成的 v' 是斜向上右。

### 严谨推导:为什么是 2(v·n)n

**第 1 步:分解 v 到两个正交方向**

任何向量 v 都能分解为"沿 n 方向"和"垂直 n 方向"两部分:

```
v = v_perp + v_para
```

- `v_perp` = v 沿 n 方向的分量 = `(v·n̂)n̂`(n̂ 是 n 的归一化)
- `v_para` = v 垂直 n 方向的分量 = `v - v_perp`

为什么 `v_perp = (v·n̂)n̂`?回忆 Day 042 学的点积:`v·n̂ = |v|·cos(θ)`,这是 v 在 n̂ 方向的**投影长度**(标量)。乘以 n̂(单位向量)就得到沿 n̂ 方向的**向量**。

**第 2 步:反射 = 翻转垂直分量**

反射定义:保留沿墙分量,翻转垂直墙分量。

```
v' = v_para - v_perp
   = (v - v_perp) - v_perp
   = v - 2 * v_perp
   = v - 2 * (v·n̂) * n̂
```

**为什么是 -2 倍?** 因为我们要把 `+ v_perp` 变成 `- v_perp`,差值是 `2 * v_perp`(从 +1 倍到 -1 倍,变 2 倍)。所以 `v' = v - 2*v_perp`。

如果你写成 `v - v_perp`(只减 1 倍),结果是 `v_para`——沿墙滑(没有反射)。如果写 `v - 3*v_perp`,过度反射(不是物理)。

### 一个完整数值例子

球速度 v = (3, -4)(斜向下右),地面法线 n = (0, 1)(向上,屏幕坐标 y 向下)。

**第 1 步:n 已经是单位向量**(0² + 1² = 1),不用归一化。

**第 2 步:算 d = v·n**:

```
d = 3*0 + (-4)*1 = -4
```

负值意味着 v 朝向 n 的反方向(球向下,n 向上,确实反方向)。

**第 3 步:反射**:

```
v' = v - 2*d*n
   = (3, -4) - 2*(-4)*(0, 1)
   = (3, -4) - (-8)*(0, 1)
   = (3, -4) - (0, -8)
   = (3, -4+8)
   = (3, 4)
```

反射后 v' = (3, 4):斜向上右。验证物理直觉:球斜向下右撞地,弹起斜向上右。正确。

**第 4 步:检查入射角 = 反射角**:

- 入射角度:atan2(-4, 3) ≈ -53°(相对 x 轴)
- 反射角度:atan2(4, 3) ≈ +53°

相对地面(法线垂直),入射 53° = 反射 53°。✓

### 为什么 n 必须归一化

如果 n 不是单位向量(比如 n = (0, 2),长度 2),`v·n = 3*0 + (-4)*2 = -8`,然后:

```
v' = (3, -4) - 2*(-8)*(0, 2)
   = (3, -4) - (-16)*(0, 2)
   = (3, -4) - (0, -32)
   = (3, 28)
```

这完全是错的!反射后 x 分量应该不变(3 → 3 ✓),但 y 分量从 -4 变成 +28,完全失真。

**根因**:反射公式 `v' = v - 2(v·n̂)n̂` 的几何意义是"投影 + 翻转",前提是 `n̂` 是单位向量。如果 n 不是单位,`v·n` 包含了 |n| 因子,公式失效。

**所以反射函数必须先 normalize**:

```rust
fn reflect(v: Vec2, n: Vec2) -> Vec2 {
    let n = n.normalize();  // 关键!
    let d = v.dot(n);
    v - n * (2.0 * d)
}
```

如果调用者保证传入单位向量,可以省略 normalize 提速(跳过 sqrt)。但 Casey 的风格是"防御式"——内部 normalize,API 安全。

### 反射 + 能量损失:弹性系数

真实球撞地会减速(能量损失)。加 **restitution**(弹性系数)e:

```
v' = v - (1 + e) * (v·n) * n
```

- e = 1:完全弹性(无能量损失,原公式)
- e = 0:完全非弹性(垂直分量归零,只沿墙滑)
- e = 0.5:中等弹性(垂直分量减半)

游戏里:

- 网球、弹球:e ≈ 0.8-0.9
- 雪球:e ≈ 0.1-0.2
- 卡在墙边的玩家:e = 0(不会弹)

代码:

```rust
fn reflect_with_restitution(v: Vec2, n: Vec2, e: f32) -> Vec2 {
    let n = n.normalize();
    let d = v.dot(n);
    v - n * ((1.0 + e) * d)
}
```

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏里反射的经典应用:

**Pong / Breakout**(弹球):球撞挡板 / 砖块,反射反弹。挡板的法线根据撞击位置稍微倾斜(中间垂直,边缘斜)——给玩家"控制方向"的手感。

**Portal**(传送门 / 激光谜题):激光打镜子反射。玩家调整镜子角度,让激光击中目标。

**弹球台**(Pinball):球撞各种障碍物反弹。需要精确反射 + 能量损失。

**赛车游戏**(撞墙):车撞墙后部分能量损失(`e < 1`),玩家被弹回但减速。

**马里奥的乌龟壳**:乌龟壳撞墙反射,沿水平方向反弹。

#### 实战坑点

**坑 1:连续碰撞触发多次反射**。玩家卡墙边,每帧都触发反射,速度反复正负跳变 → 抖动。修复:加 "epsilon 阈值",如果 `|v·n| < eps` 就把 v 沿墙方向投影(去掉垂直分量,只保留沿墙),避免抖动。

**坑 2:法线方向反了**。如果 n 指向墙内部(反方向),`(v·n)` 符号反转,反射变成"加速撞墙"。修复:约定 n 总是"指向玩家来的一侧"(指向墙外),代码检查 `(v·n) < 0`(玩家朝 n 反方向运动 = 朝墙运动)才反射。

**坑 3:浮点误差累积**。多次反射后,沿墙分量可能逐渐增加或减少(能量泄漏)。修复:定期归一化 / 校正。

### 3.2 · 🎨 图形学视角

反射在图形学里**无处不在**:

**Phong 高光**(specular highlight):

```glsl
// L = 指向光源的向量(从表面出发)
// N = 表面法线
// V = 指向相机的向量
vec3 R = reflect(-L, N);  // 反射向量
float spec = pow(max(0.0, dot(R, V)), shininess);
```

注意 GLSL 的 `reflect(I, N)` 函数签名:**I 是入射方向**(从光源指向表面),而我们今天推的公式用 v 是"出射方向"。GLSL 公式 `R = I - 2 * dot(I, N) * N`,和我们的 `v' = v - 2 * (v·n) n` 数学一致,但方向约定不同。

**环境反射**(environment reflection):立方体贴图(cube map)存环境,shader 用反射向量查 cube map,模拟镜面。高端 3D 游戏(赛车反光、水波反射)都用。

**屏幕空间反射**(SSR,Screen Space Reflection):后处理技术,用 depth buffer 反向追踪反射射线。性能贵但效果好。

**光线追踪**(ray tracing):

```
ray.dir = reflect(ray.dir, surface_normal);
ray.origin = hit_point + epsilon * surface_normal;  // 避免自相交
```

每次反射生成新射线,递归追踪。控制深度(深度太大爆炸,深度太小没效果)。

### 3.3 · 🐧 Linux 系统编程视角

PipeWire 的空间音频(spatial audio)模块计算声源到耳朵的反射路径,模拟房间几何。算法是射线追踪 + 反射公式(就是今天学的)。

### 3.4 · 🦀 Rust 生态视角

#### Rust 写反射的几种风格

**风格 A:方法**(推荐)

```rust
impl Vec2 {
    pub fn reflect(self, n: Vec2) -> Vec2 {
        let n_norm = n.normalize();
        let d = self.dot(n_norm);
        self - n_norm * (2.0 * d)
    }
}
```

调用 `v.reflect(n)`,链式可读。

**风格 B:自由函数**

```rust
pub fn reflect(v: Vec2, n: Vec2) -> Vec2 {
    let n_norm = n.normalize();
    v - n_norm * (2.0 * v.dot(n_norm))
}
```

调用 `reflect(v, n)`,函数式风格。

**风格 C:不归一化版本(性能优先)**

```rust
/// 调用者必须保证 n 是单位向量
pub fn reflect_unit(v: Vec2, n: Vec2) -> Vec2 {
    debug_assert!((n.length_sq() - 1.0).abs() < 1e-4, "n must be unit");
    v - n * (2.0 * v.dot(n))
}
```

跳过 normalize 的 sqrt,快一点。`debug_assert!` 在 debug 模式检查不变量,release 模式跳过(零开销)。

#### glam 的实现

```rust
// glam 的 Vec2::reflect(简化版)
pub fn reflect(self, n: Vec2) -> Vec2 {
    self - 2.0 * self.dot(n) * n
}
```

glam **不内部 normalize**——调用者必须传单位向量。这是性能优先的设计(每次反射少一个 sqrt)。如果你不知道这个约定,会出 bug。

读 glam doc:

> `reflect(vec, normal)`:Returns the reflection vector for a given incident vector `vec` and surface normal `normal`. **`normal` must be normalized.**

注意 doc 强调"must be normalized"。这是 API 设计的取舍——性能 vs 安全。

#### 测试反射的正确性

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_reflect_horizontal_wall() {
        // 球向下撞地,n 向上
        let v = Vec2::new(3.0, -4.0);
        let n = Vec2::new(0.0, 1.0);
        let r = v.reflect(n);
        assert!((r.x - 3.0).abs() < 1e-6, "x preserved: {}", r.x);
        assert!((r.y - 4.0).abs() < 1e-6, "y flipped: {}", r.y);
    }

    #[test]
    fn test_reflect_vertical_wall() {
        // 球向右撞右墙,n 向左
        let v = Vec2::new(5.0, 2.0);
        let n = Vec2::new(-1.0, 0.0);
        let r = v.reflect(n);
        assert!((r.x - (-5.0)).abs() < 1e-6);
        assert!((r.y - 2.0).abs() < 1e-6);
    }

    #[test]
    fn test_reflect_diagonal() {
        // 球斜向下右撞地
        let v = Vec2::new(1.0, -1.0);
        let n = Vec2::new(0.0, 1.0);
        let r = v.reflect(n);
        // 45° 入射 → 45° 反射
        assert!((r.x - 1.0).abs() < 1e-6);
        assert!((r.y - 1.0).abs() < 1e-6);
    }

    #[test]
    fn test_reflect_normalizes_n() {
        // n 没归一化,函数应该自己归一化
        let v = Vec2::new(0.0, -5.0);
        let n = Vec2::new(0.0, 3.0);  // 长度 3,但方向正确
        let r = v.reflect(n);
        assert!((r.y - 5.0).abs() < 1e-6, "reflect should normalize n");
    }

    #[test]
    fn test_reflect_perfect_bounce() {
        // 完美正面撞,v 与 n 反方向
        let v = Vec2::new(0.0, -10.0);
        let n = Vec2::new(0.0, 1.0);
        let r = v.reflect(n);
        // 反射后正好反向
        assert!((r.x - 0.0).abs() < 1e-6);
        assert!((r.y - 10.0).abs() < 1e-6);
    }
}
```

测试覆盖:水平墙、垂直墙、对角线、非归一化 n、正面撞。这样保证反射函数在各种场景都对。

## 4 · 认知地图

### 4.1 上级

- **向量分解**(vector decomposition)—— 把向量拆成正交分量,核心技巧
- **碰撞响应**(collision response)—— 物理引擎的核心子问题
- **光学 / 声学的反射定律** —— 物理学里的"入射角 = 反射角"
- **Householder 变换** —— 线性代数里,反射公式是 Householder 矩阵 H = I - 2vv^T 的几何意义

### 4.2 同级(并行方案对比)

| 方案 | 公式 | 何时用 |
|---|---|---|
| 完美反射(e=1) | `v' = v - 2(v·n)n` | 弹球、激光 |
| 带能量损失(e<1) | `v' = v - (1+e)(v·n)n` | 真实物理 |
| 沿墙滑(e=0) | `v' = v - (v·n)n` | 玩家撞墙 |
| 完全停止(e=-1?) | `v' = 0` | 死亡 / 抓住 |
| 沿法线推开(推力) | `v' = v + (penetration_depth) * n` | 物理引擎分离物体 |

注意 e=0 和"沿墙滑"公式一样:`v - (v·n)n = v_para`,即去掉垂直分量。这就是 Day 029 分轴碰撞的数学本质——x 撞墙时把 vx 置零等价于反射公式 e=0。

### 4.3 下级

- **n(法线)** —— 垂直于墙的单位向量,必须归一化
- **v·n(投影)** —— v 在 n 方向的投影长度
- **2 倍系数** —— 翻转的来源
- **restitution e** —— 弹性系数,控制能量损失
- **法线方向约定** —— n 指向 v 来的一侧(墙外)

## 5 · 对照与变奏

### 2D 反射 vs 3D 反射

2D:`v' = v - 2(v·n)n`,所有向量是 Vec2,n 是 2D 单位向量。

3D:同样的公式,但 v 和 n 是 Vec3。例如光线打镜面:

```rust
let incident = Vec3::new(1.0, -1.0, 0.0).normalize();
let normal = Vec3::new(0.0, 1.0, 0.0);
let reflected = incident - normal * (2.0 * incident.dot(normal));
// (1.0, 1.0, 0.0) —— 斜向上右
```

公式完全一样,只是维度不同。这是线性代数的统一美。

### CPU 反射 vs GPU 反射(shader)

GPU shader 用 GLSL 内置 `reflect(I, N)` 函数,底层硬件实现。CPU 用我们自己写的 Rust 函数。

| | CPU(Rust) | GPU(GLSL) |
|---|---|---|
| 函数 | `Vec2::reflect(v, n)` 或自写 | `reflect(I, N)` 内置 |
| 速度 | 每秒约 1 亿次(标量) | 每秒约 100 亿次(并行) |
| 用途 | 物理模拟、AI | 光照、光线追踪 |

游戏开发 CPU 算物理反射(球碰撞),GPU 算光照反射(高光)。Day 235 切 OpenGL 后,shader 里会用 reflect 大量算高光。

### Householder 变换:反射的线性代数视角

数学里,**Householder 矩阵** `H = I - 2nn^T`(n 是单位列向量)是一个反射矩阵。乘 `Hv` 等价于把 v 沿 n 反射。

这就是我们今天的公式 `v' = v - 2(v·n)n` 的矩阵形式:

```
v' = v - 2n(n^T v) = (I - 2nn^T) v = H v
```

Householder 变换在数值线性代数里很重要(QR 分解、特征值算法都用)。游戏开发不直接用矩阵形式(用向量公式更高效),但概念是同一个。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:反射公式 `v' = v - 2(v·n)n` 里的 "2" 改成 "1" 会怎样?改成 "3" 呢?给具体数字说明。

**参考解答**:

原公式 `v - 2(v·n)n` = 翻转垂直分量,正确反射。

**改成 1**:`v - (v·n)n = v_para`,只去掉垂直分量,保留沿墙分量。这就是**沿墙滑**(没有反射)。物理上对应"球完全非弹性撞墙,贴着墙走"。

例:v = (3, -4),n = (0, 1)。`v·n = -4`。`v - 1*(-4)*(0,1) = (3, -4) - (0, -4) = (3, 0)`。结果 (3, 0):水平方向 3,垂直 0。球贴地滑行。

**改成 3**:`v - 3(v·n)n = v_para - 2 v_perp`,过度反射(垂直分量不仅翻转还加倍)。物理上不存在。

例:`v - 3*(-4)*(0,1) = (3, -4) - (0, -12) = (3, 8)`。结果 (3, 8):水平 3,垂直 8。球的"出射速度"比"入射速度"大——能量凭空增加,违反能量守恒。

**直觉**:系数 k 的含义是"翻转 + 放大"。k=2 是"翻转 + 不放大"(标准反射),k=1 是"不翻转只去掉"(滑行),k>2 是"翻转 + 放大"(能量爆增,bug),k<1 是"部分去除"(能量损失)。

```rust
// math.rs 里加
impl Vec2 {
    pub fn reflect(self, n: Self) -> Self {
        let n_norm = n.normalize();
        let d = self.dot(n_norm);
        self - n_norm * (2.0 * d)
    }

    pub fn reflect_with_restitution(self, n: Self, e: f32) -> Self {
        let n_norm = n.normalize();
        let d = self.dot(n_norm);
        self - n_norm * ((1.0 + e) * d)
    }
}

// src/bouncing_ball.rs
use crate::math::Vec2;

const GRAVITY: f32 = 980.0;   // 像素/秒²(缩放后的重力)
const RESTITUTION: f32 = 0.7; // 70% 能量保留

pub struct Ball {
    pub pos: Vec2,
    pub vel: Vec2,
}

impl Ball {
    pub fn update(&mut self, dt: f32) {
        // 重力
        self.vel.y += GRAVITY * dt;
        // 位置
        self.pos += self.vel * dt;

        // 碰地(y >= 0 为地面)
        if self.pos.y >= 0.0 && self.vel.y > 0.0 {
            // 把球推回地面之上
            self.pos.y = 0.0;
            // 反射 + 能量损失
            self.vel = self.vel.reflect_with_restitution(
                Vec2::new(0.0, -1.0),  // n 指向球来的方向(向下)
                RESTITUTION,
            );
            // 如果速度太小,停下来
            if self.vel.y.abs() < 50.0 {
                self.vel = Vec2::ZERO;
                self.pos.y = 0.0;
            }
        }
    }
}

fn main() {
    let mut ball = Ball {
        pos: Vec2::new(0.0, -100.0),  // 屏幕坐标,y=-100 = 地面之上 100 像素
        vel: Vec2::ZERO,
    };

    let dt = 1.0 / 60.0;
    let mut sim_time = 0.0;
    let mut bounce_count = 0;
    let mut prev_height = 100.0_f32;

    for frame in 0..600 {  // 10 秒
        let was_falling = ball.vel.y > 0.0;
        ball.update(dt);
        sim_time += dt;

        // 检测反弹点(速度 y 从正变负)
        if was_falling && ball.vel.y < 0.0 {
            bounce_count += 1;
            let height = -ball.pos.y;  // 屏幕坐标,负值是高度
            println!("反弹 {}: 时间={:.2}s 高度={:.1} 像素",
                     bounce_count, sim_time, height);
        }

        // 每 30 帧打印一次高度
        if frame % 30 == 0 {
            let height = -ball.pos.y;
            if height.abs() > 0.5 {
                // 仍在运动
            }
        }

        // 球停下来了
        if ball.vel.length_sq() < 1.0 && ball.pos.y >= -0.1 {
            println!("球在 {:.2}s 停下,共反弹 {} 次", sim_time, bounce_count);
            break;
        }
    }
}
```

```rust
use std::ops::{Add, Sub, Mul, AddAssign};

#[derive(Copy, Clone, Debug, Default, PartialEq)]
pub struct Vec2 { pub x: f32, pub y: f32 }

impl Vec2 {
    pub const ZERO: Self = Self { x: 0.0, y: 0.0 };
    pub fn new(x: f32, y: f32) -> Self { Self { x, y } }
    pub fn dot(self, o: Self) -> f32 { self.x * o.x + self.y * o.y }
    pub fn length_sq(self) -> f32 { self.dot(self) }
    pub fn length(self) -> f32 { self.length_sq().sqrt() }
    pub fn normalize(self) -> Self {
        let len = self.length();
        if len > 1e-6 { self * (1.0 / len) } else { Self::ZERO }
    }
    pub fn reflect(self, n: Self) -> Self {
        let n = n.normalize();
        let d = self.dot(n);
        self - n * (2.0 * d)
    }
    pub fn reflect_with_restitution(self, n: Self, e: f32) -> Self {
        let n = n.normalize();
        let d = self.dot(n);
        self - n * ((1.0 + e) * d)
    }
}

impl Add for Vec2 {
    type Output = Vec2;
    fn add(self, o: Self) -> Self { Self { x: self.x + o.x, y: self.y + o.y } }
}
impl Sub for Vec2 {
    type Output = Vec2;
    fn sub(self, o: Self) -> Self { Self { x: self.x - o.x, y: self.y - o.y } }
}
impl Mul<f32> for Vec2 {
    type Output = Vec2;
    fn mul(self, k: f32) -> Self { Self { x: self.x * k, y: self.y * k } }
}
impl AddAssign for Vec2 {
    fn add_assign(&mut self, o: Self) { self.x += o.x; self.y += o.y; }
}
```

### Troubleshooting

**问题 1**:球穿过地面不停反弹

原因:dt 太大,球一帧移动距离 > 地面厚度,Euler 积分让球"嵌入"地面之下,然后又被推回去,反复抖动。

修复:加 sub-stepping(Day 045 主题),把 dt 拆小。或者在碰撞时把球推回地面之上(代码里的 `self.pos.y = 0.0`)。

**问题 2**:反射后球的速度比入射大

原因:n 没归一化(参考 §2 的数值例子)。

修复:reflect 函数内部 `n.normalize()`。

**问题 3**:球停在地面但还在抖动

原因:`vel.y.abs() < 50.0` 的阈值太小,球低速时仍然有微小速度。

修复:加大阈值,或在阈值下直接 `vel = ZERO`。

**问题 4**:球弹起来变方向(沿墙滑了)

原因:你用了 e=0(完全非弹性),垂直分量归零,只保留沿墙。

修复:用 e=1(完美反射)或 e=0.7(部分弹性)。
