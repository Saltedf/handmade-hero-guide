# Day 376 · 绘制调试体积

> 你的游戏有 100 个 entity,每个都有碰撞体。但你看不到碰撞体,**调碰撞 bug 时只能凭空想象**。今天 Casey 写 **debug volume rendering(调试体积渲染)**:用线框 / 半透明面渲染碰撞体、射线、传感器区域。这是开发期最重要的 debug 工具之一。

## 0 · 为什么要有这一天

你的玩家穿墙了。你看代码,看 collision 算法,看 entity 设置,完全不知道为什么。你打开 debug overlay,看到玩家在 (5, 0, 5),墙在 (5, 0, 7)——位置看起来不应该碰撞,但玩家就是穿过去了。

**真相**:你的 entity 系统**实际碰撞体**可能不是你以为的。玩家可能有个 1m × 2m × 1m 的盒子,你以为是个点;墙可能是 AABB 也可能是 OBB(定向包围盒),你以为只是个面。**没有可视化,你完全看不到实际几何**。

工业游戏开发的标准做法:**debug volume rendering**。所有碰撞体、射线、传感器区域都可以**画出来**(线框或半透明面),开发期实时观察。每个商业引擎都有这个功能:
- **Unity**:Gizmos + `OnDrawGizmos` 函数
- **Unreal**:DrawDebugBox / DrawDebugLine
- **Godot**:Draw 系列函数
- **Bevy**:`Gizmos` 资源

Casey 今天为 HH 写这个,具体覆盖:
1. **AABB 线框**:画 entity 的轴对齐包围盒
2. **球体线框**:球碰撞体
3. **射线**:鼠标射线、攻击射线
4. **平面 / 多边形**:floor / wall 几何
5. **文本标签**:每个 entity 的 ID / 状态

**为什么"调试体积"重要**?
- 调试 collision:看碰撞体实际形状
- 调试 AI:看 NPC 视野范围 / 路径
- 调试动画:看骨骼 hitbox
- 调试光照:看光源位置 / 范围

没有 debug volume,这些调试只能"凭空猜",效率极低。

心理锚点:今天之后,你能渲染线框 / 半透明面调试几何,理解 line rendering 和 wireframe mode,知道 debug overlay 怎么管理。

## 1 · Casey 今天做了什么(HH 脉络)

Day 375 加完 fog 后,Casey 决定**调试工具升级**。具体动作:

1. **写 line rendering shader**:专门画线段(用 `GL_LINES` mode)
2. **写 immediate-mode debug renderer**:类似 OpenGL 1.x 的 `glBegin/glEnd`,但用现代 API
3. **加各种 draw 函数**:`draw_aabb(aabb, color)`、`draw_line(start, end, color)`、`draw_sphere(center, radius, color)`
4. **加 wireframe mode**:`glPolygonMode(GL_FRONT_AND_BACK, GL_LINE)` 切到线框模式,3D 几何画成线框
5. **debug overlay 整合**:F2 切换调试几何显示

Casey 强调 immediate-mode debug renderer 的便利:

```rust
// 像这样在游戏代码里随手调用:
debug_renderer.draw_aabb(player.aabb, Color::GREEN);
debug_renderer.draw_line(mouse_ray.origin, mouse_ray.origin + mouse_ray.dir * 100.0, Color::RED);
debug_renderer.draw_sphere(npc.pos, npc.radius, Color::BLUE);
```

每帧重新画,**不需要管理资源**(不需要手动创 VBO / 删 VBO)。这叫 immediate mode(立即模式),区别于保留模式(retained mode,工业 mesh 系统)。

## 2 · 心智模型

### 类比:Debug volume 是"程序员眼镜"

你戴眼镜看清世界;游戏开发者用 debug volume "看清"游戏的内部状态。

正常游戏画面:玩家、墙、地板。你看不到碰撞体、射线、传感器。
开启 debug volume:画面叠加一层"X 光",看到所有不可见的几何——碰撞盒是绿色线框,射线是红色线,传感器是半透明蓝。

**核心思想**:debug volume 是**叠加在游戏画面上**的,不影响正常渲染。它用单独的 shader,通常在场景渲染之后画,深度测试可关闭(debug 几何不被墙挡住)。

### 三个层次的 debug volume

**1. Wireframe mode(线框模式)**

`glPolygonMode(GL_FRONT_AND_BACK, GL_LINE)` 让 GPU 把每个三角形画成边框(不填充)。整个 mesh 变成线框。

```rust
unsafe {
    gl::PolygonMode(gl::FRONT_AND_BACK, gl::LINE);
    mesh.draw();  // 画线框
    gl::PolygonMode(gl::FRONT_AND_BACK, gl::_FILL);  // 恢复填充
}
```

适合调试 mesh 几何(看顶点布局),不适合调试单个 entity 的碰撞盒(因为 mesh 太复杂)。

**2. Immediate-mode line renderer(立即模式线渲染)**

专门画线段(线框 AABB、射线、坐标轴),用 `GL_LINES` mode。简单高效。

```rust
let mut lines = LineBatch::new();
lines.add_line(aabb.min, aabb.max, GREEN);
lines.add_line(mouse_ray.origin, mouse_ray.origin + mouse_ray.dir * 100.0, RED);
lines.flush_to_gpu();
lines.draw();
```

每帧重新构建 line batch,适合"随时画几条线调试"。

**3. Solid debug(半透明面)**

画半透明面(如传感器区域),用 alpha blend。需要在透明物体之后画。

```rust
unsafe {
    gl::Enable(gl::BLEND);
    gl::BlendFunc(gl::SRC_ALPHA, gl::ONE_MINUS_SRC_ALPHA);
    // 画半透明面
    debug_solid.draw();
    gl::Disable(gl::BLEND);
}
```

### Line Renderer 详解

**数据布局**:每线段 2 顶点,顶点包含位置 + 颜色:

```rust
#[repr(C)]
#[derive(Copy, Clone)]
struct LineVertex {
    pos: [f32; 3],
    color: [f32; 4],  // RGBA
}
```

**Line batch**:

```rust
pub struct LineBatch {
    vertices: Vec<LineVertex>,
    vao: GLuint,
    vbo: GLuint,
    shader: GLuint,
}

impl LineBatch {
    pub fn new() -> Self {
        // 创建 VAO + VBO + shader
        // ...
    }

    pub fn add_line(&mut self, start: Vec3, end: Vec3, color: [f32; 4]) {
        self.vertices.push(LineVertex {
            pos: start.into(), color,
        });
        self.vertices.push(LineVertex {
            pos: end.into(), color,
        });
    }

    pub fn add_aabb(&mut self, min: Vec3, max: Vec3, color: [f32; 4]) {
        // AABB 12 条边
        let corners = [
            [min.x, min.y, min.z],
            [max.x, min.y, min.z],
            [max.x, max.y, min.z],
            [min.x, max.y, min.z],
            [min.x, min.y, max.z],
            [max.x, min.y, max.z],
            [max.x, max.y, max.z],
            [min.x, max.y, max.z],
        ];
        let edges = [
            (0,1), (1,2), (2,3), (3,0),  // 底面
            (4,5), (5,6), (6,7), (7,4),  // 顶面
            (0,4), (1,5), (2,6), (3,7),  // 竖边
        ];
        for (a, b) in edges {
            self.add_line(corners[a].into(), corners[b].into(), color);
        }
    }

    pub fn flush_and_draw(&mut self, view_proj: Mat4) {
        if self.vertices.is_empty() { return; }

        unsafe {
            gl::UseProgram(self.shader);
            // 上传 view_proj
            let loc = gl::GetUniformLocation(self.shader, b"u_view_proj\0".as_ptr() as *const _);
            gl::UniformMatrix4fv(loc, 1, gl::FALSE, view_proj.to_cols_array().as_ptr());

            // 上传顶点数据
            gl::BindVertexArray(self.vao);
            gl::BindBuffer(gl::ARRAY_BUFFER, self.vbo);
            gl::BufferData(
                gl::ARRAY_BUFFER,
                (self.vertices.len() * std::mem::size_of::<LineVertex>()) as isize,
                self.vertices.as_ptr() as *const _,
                gl::STREAM_DRAW,   // 每帧重新上传,STREAM 提示
            );

            // 画
            gl::DrawArrays(gl::LINES, 0, self.vertices.len() as i32);

            // 清空,准备下帧
        }
        self.vertices.clear();
    }
}
```

**关键点**:
- `gl::LINES` mode:每 2 顶点一组,画一条线段
- `gl::STREAM_DRAW`:数据每帧变,driver 优化为高速上传(不必保留旧数据)
- `vertices.clear()` 在 draw 后:每帧重新构建,这是 immediate mode 的本质

### Line Shader

```glsl
// line.vert
#version 330 core
layout(location = 0) in vec3 a_pos;
layout(location = 1) in vec4 a_color;

out vec4 v_color;

uniform mat4 u_view_proj;

void main() {
    gl_Position = u_view_proj * vec4(a_pos, 1.0);
    v_color = a_color;
}
```

```glsl
// line.frag
#version 330 core
in vec4 v_color;
out vec4 frag_color;

void main() {
    frag_color = v_color;
}
```

非常简单:vertex shader 应用 VP 矩阵,fragment shader 输出颜色。

### 深度测试的开关

Debug line 通常**关掉深度测试**,让线段始终可见(不被墙挡住):

```rust
unsafe {
    gl::Disable(gl::DEPTH_TEST);   // 关深度测试,debug 几何总在最上层
    line_batch.flush_and_draw(view_proj);
    gl::Enable(gl::DEPTH_TEST);    // 恢复
}
```

或者保留深度测试,但加 depth bias:

```rust
unsafe {
    gl::Enable(gl::POLYGON_OFFSET_LINE);
    gl::PolygonOffset(-1.0, -1.0);
    line_batch.flush_and_draw(view_proj);
    gl::Disable(gl::POLYGON_OFFSET_LINE);
}
```

 Casey 选关深度测试(简单)。

### 3.2 · 🎨 图形学视角

线渲染在图形学的几个概念:

**`GL_LINES` vs `GL_LINE_STRIP` vs `GL_LINE_LOOP`**

- `GL_LINES`:每 2 顶点一条线段
- `GL_LINE_STRIP`:相邻顶点连线(N 顶点 → N-1 线段)
- `GL_LINE_LOOP`:strip + 回到第一个顶点(N 顶点 → N 线段)

画一个矩形:`GL_LINE_LOOP` 4 顶点比 `GL_LINES` 8 顶点(4 边 × 2 顶点)省。

**Line width**

`glLineWidth(width)` 设置线宽(像素)。**但现代 GPU 普遍不支持 > 1 的线宽**,因为线段在 GPU 光栅化时复杂。NVIDIA 在某些驱动支持,AMD 通常忽略 > 1 的请求。

工业方案:画"粗线"用 quad(矩形)代替,沿屏幕方向铺开。

**Line antialiasing**

`glEnable(GL_LINE_SMOOTH)` 启用线段抗锯齿。但实现质量因 GPU 而异,工业通常关掉,改用 MSAA。

**Geometry shader 生成线**

更高级:用 geometry shader 从点生成线段(扩展成 quad),支持任意线宽和 antialiasing。但 geometry shader 性能差,现代引擎改用 screen-space 技术。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 debug volume 通常关闭深度测试?有什么副作用?

**参考解答**:关深度测试让 debug 几何(线框 / 半透明面)始终可见,不被场景几何挡住。否则玩家在墙后,看不到玩家的 collision box,调试困难。

副作用:debug 几何"穿过"所有场景几何,看起来像"漂浮"。如果你调试的恰好是"被遮挡的问题"(如 NPC 在墙后看不到玩家),关深度测试可能掩盖问题。

工业方案:提供两个模式,默认开深度测试,按键切到关。Casey 通常关掉,简单。

### Lv2 · 动手实践

**题**:实现 `LineBatch`,支持 `add_line`, `add_aabb`, `add_ray`。完成标准:
- 每帧调用任意次数 add_*
- 末尾调 flush_and_draw,一次性画所有线
- 第二帧的线不残留(每帧重新构建)
- 线段关深度测试,始终可见

**参考解答**:

```rust
use gl::types::*;
use std::mem;
use std::ptr;
use glam::{Mat4, Vec3};

#[repr(C)]
#[derive(Copy, Clone, bytemuck::Pod, bytemuck::Zeroable)]
struct LineVertex {
    pos: [f32; 3],
    color: [f32; 4],
}

pub struct LineBatch {
    vertices: Vec<LineVertex>,
    vao: GLuint,
    vbo: GLuint,
    shader_program: GLuint,
}

impl LineBatch {
    pub fn new(shader_program: GLuint) -> Self {
        let mut vao = 0;
        let mut vbo = 0;
        unsafe {
            gl::GenVertexArrays(1, &mut vao);
            gl::BindVertexArray(vao);
            gl::GenBuffers(1, &mut vbo);
            gl::BindBuffer(gl::ARRAY_BUFFER, vbo);

            // 初始空 buffer,后续BufferData更新
            gl::BufferData(gl::ARRAY_BUFFER, 0, ptr::null(), gl::STREAM_DRAW);

            let stride = mem::size_of::<LineVertex>() as GLsizei;
            gl::VertexAttribPointer(0, 3, gl::FLOAT, gl::FALSE, stride, ptr::null());
            gl::EnableVertexAttribArray(0);
            gl::VertexAttribPointer(1, 4, gl::FLOAT, gl::FALSE, stride,
                (3 * mem::size_of::<f32>()) as *const _);
            gl::EnableVertexAttribArray(1);

            gl::BindVertexArray(0);
        }
        Self {
            vertices: Vec::new(),
            vao, vbo, shader_program,
        }
    }

    pub fn add_line(&mut self, start: Vec3, end: Vec3, color: [f32; 4]) {
        self.vertices.push(LineVertex {
            pos: start.into(), color,
        });
        self.vertices.push(LineVertex {
            pos: end.into(), color,
        });
    }

    pub fn add_aabb(&mut self, min: Vec3, max: Vec3, color: [f32; 4]) {
        let corners: [[f32; 3]; 8] = [
            [min.x, min.y, min.z], [max.x, min.y, min.z],
            [max.x, max.y, min.z], [min.x, max.y, min.z],
            [min.x, min.y, max.z], [max.x, min.y, max.z],
            [max.x, max.y, max.z], [min.x, max.y, max.z],
        ];
        let edges = [
            (0, 1), (1, 2), (2, 3), (3, 0),  // 底面
            (4, 5), (5, 6), (6, 7), (7, 4),  // 顶面
            (0, 4), (1, 5), (2, 6), (3, 7),  // 竖边
        ];
        for (a, b) in edges {
            self.vertices.push(LineVertex {
                pos: corners[a], color,
            });
            self.vertices.push(LineVertex {
                pos: corners[b], color,
            });
        }
    }

    pub fn add_ray(&mut self, origin: Vec3, dir: Vec3, length: f32, color: [f32; 4]) {
        let end = origin + dir.normalize() * length;
        self.add_line(origin, end, color);
    }

    pub fn flush_and_draw(&mut self, view_proj: Mat4) {
        if self.vertices.is_empty() { return; }

        unsafe {
            gl::UseProgram(self.shader_program);

            // 上传 view_proj
            let c_name = std::ffi::CString::new("u_view_proj").unwrap();
            let loc = gl::GetUniformLocation(self.shader_program, c_name.as_ptr());
            if loc >= 0 {
                gl::UniformMatrix4fv(loc, 1, gl::FALSE, view_proj.to_cols_array().as_ptr());
            }

            // 上传顶点数据
            gl::BindVertexArray(self.vao);
            gl::BindBuffer(gl::ARRAY_BUFFER, self.vbo);
            gl::BufferData(
                gl::ARRAY_BUFFER,
                (self.vertices.len() * mem::size_of::<LineVertex>()) as isize,
                self.vertices.as_ptr() as *const _,
                gl::STREAM_DRAW,
            );

            // 关深度测试,debug 线总在前面
            let depth_was_enabled = gl::IsEnabled(gl::DEPTH_TEST) != 0;
            gl::Disable(gl::DEPTH_TEST);

            // 画
            gl::DrawArrays(gl::LINES, 0, self.vertices.len() as GLsizei);

            if depth_was_enabled {
                gl::Enable(gl::DEPTH_TEST);
            }

            gl::BindVertexArray(0);
        }

        self.vertices.clear();
    }
}
```

**关键解释**:
- 初始 VBO 为 0 字节,后续 `BufferData` 重新分配(每帧大小可能变)
- `STREAM_DRAW` 提示 driver:数据每帧变,优化上传路径
- `IsEnabled(DEPTH_TEST)` 记录原状态,恢复时不变更全局状态
- `gl::LINES` mode:每 2 顶点一条线段。`vertices.len()` 是顶点数,线段数是其一半

// Cargo.toml: gl = "0.14", glfw = "0.55", glam = "0.29", bytemuck = "1.14"

use gl::types::*;
use glam::{Mat4, Vec3};
use std::mem;
use std::ptr;

const LINE_VERT_SRC: &str = r#"
#version 330 core
layout(location = 0) in vec3 a_pos;
layout(location = 1) in vec4 a_color;
out vec4 v_color;
uniform mat4 u_view_proj;
void main() {
    gl_Position = u_view_proj * vec4(a_pos, 1.0);
    v_color = a_color;
}
"#;

const LINE_FRAG_SRC: &str = r#"
#version 330 core
in vec4 v_color;
out vec4 frag_color;
void main() {
    frag_color = v_color;
}
"#;

// (compile shaders, link program, see day368)

pub mod color {
    pub const WHITE: [f32; 4] = [1.0, 1.0, 1.0, 1.0];
    pub const RED: [f32; 4] = [1.0, 0.0, 0.0, 1.0];
    pub const GREEN: [f32; 4] = [0.0, 1.0, 0.0, 1.0];
    pub const BLUE: [f32; 4] = [0.0, 0.0, 1.0, 1.0];
    pub const YELLOW: [f32; 4] = [1.0, 1.0, 0.0, 1.0];
    pub const MAGENTA: [f32; 4] = [1.0, 0.0, 1.0, 1.0];
    pub const CYAN: [f32; 4] = [0.0, 1.0, 1.0, 1.0];
}

pub struct DebugRenderer {
    line_shader: GLuint,
    line_vao: GLuint,
    line_vbo: GLuint,
    line_vertices: Vec<LineVertex>,
    enabled: bool,
}

#[repr(C)]
#[derive(Copy, Clone, bytemuck::Pod, bytemuck::Zeroable)]
struct LineVertex {
    pos: [f32; 3],
    color: [f32; 4],
}

impl DebugRenderer {
    pub fn new() -> Self {
        // (compile shaders)
        let line_shader = /* link_program(LINE_VERT_SRC, LINE_FRAG_SRC) */ 0;

        let mut line_vao = 0;
        let mut line_vbo = 0;
        unsafe {
            gl::GenVertexArrays(1, &mut line_vao);
            gl::BindVertexArray(line_vao);
            gl::GenBuffers(1, &mut line_vbo);
            gl::BindBuffer(gl::ARRAY_BUFFER, line_vbo);
            gl::BufferData(gl::ARRAY_BUFFER, 0, ptr::null(), gl::STREAM_DRAW);

            let stride = mem::size_of::<LineVertex>() as GLsizei;
            gl::VertexAttribPointer(0, 3, gl::FLOAT, gl::FALSE, stride, ptr::null());
            gl::EnableVertexAttribArray(0);
            gl::VertexAttribPointer(
                1, 4, gl::FLOAT, gl::FALSE, stride,
                (3 * mem::size_of::<f32>()) as *const _,
            );
            gl::EnableVertexAttribArray(1);
            gl::BindVertexArray(0);
        }

        Self {
            line_shader,
            line_vao, line_vbo,
            line_vertices: Vec::new(),
            enabled: true,
        }
    }

    pub fn toggle(&mut self) {
        self.enabled = !self.enabled;
    }

    pub fn draw_line(&mut self, start: Vec3, end: Vec3, color: [f32; 4]) {
        if !self.enabled { return; }
        self.line_vertices.push(LineVertex { pos: start.into(), color });
        self.line_vertices.push(LineVertex { pos: end.into(), color });
    }

    pub fn draw_aabb(&mut self, min: Vec3, max: Vec3, color: [f32; 4]) {
        if !self.enabled { return; }
        let corners: [[f32; 3]; 8] = [
            [min.x, min.y, min.z], [max.x, min.y, min.z],
            [max.x, max.y, min.z], [min.x, max.y, min.z],
            [min.x, min.y, max.z], [max.x, min.y, max.z],
            [max.x, max.y, max.z], [min.x, max.y, max.z],
        ];
        let edges = [
            (0, 1), (1, 2), (2, 3), (3, 0),
            (4, 5), (5, 6), (6, 7), (7, 4),
            (0, 4), (1, 5), (2, 6), (3, 7),
        ];
        for (a, b) in edges {
            self.line_vertices.push(LineVertex { pos: corners[a], color });
            self.line_vertices.push(LineVertex { pos: corners[b], color });
        }
    }

    pub fn draw_grid(&mut self, center: Vec3, size: f32, divisions: i32, color: [f32; 4]) {
        let half = size / 2.0;
        let step = size / divisions as f32;
        for i in 0..=divisions {
            let t = -half + i as f32 * step;
            // X 方向的线
            self.draw_line(
                Vec3::new(center.x + t, center.y, center.z - half),
                Vec3::new(center.x + t, center.y, center.z + half),
                color,
            );
            // Z 方向的线
            self.draw_line(
                Vec3::new(center.x - half, center.y, center.z + t),
                Vec3::new(center.x + half, center.y, center.z + t),
                color,
            );
        }
    }

    pub fn draw_axes(&mut self, origin: Vec3, length: f32) {
        self.draw_line(origin, origin + Vec3::new(length, 0.0, 0.0), color::RED);
        self.draw_line(origin, origin + Vec3::new(0.0, length, 0.0), color::GREEN);
        self.draw_line(origin, origin + Vec3::new(0.0, 0.0, length), color::BLUE);
    }

    pub fn flush(&mut self, view_proj: Mat4) {
        if !self.enabled || self.line_vertices.is_empty() { return; }

        unsafe {
            gl::UseProgram(self.line_shader);

            // Upload view_proj
            let c_name = std::ffi::CString::new("u_view_proj").unwrap();
            let loc = gl::GetUniformLocation(self.line_shader, c_name.as_ptr());
            if loc >= 0 {
                gl::UniformMatrix4fv(loc, 1, gl::FALSE, view_proj.to_cols_array().as_ptr());
            }

            gl::BindVertexArray(self.line_vao);
            gl::BindBuffer(gl::ARRAY_BUFFER, self.line_vbo);
            gl::BufferData(
                gl::ARRAY_BUFFER,
                (self.line_vertices.len() * mem::size_of::<LineVertex>()) as isize,
                self.line_vertices.as_ptr() as *const _,
                gl::STREAM_DRAW,
            );

            // 关深度测试 + 关 cull(线不需要)
            let depth_was = gl::IsEnabled(gl::DEPTH_TEST) != 0;
            gl::Disable(gl::DEPTH_TEST);

            gl::DrawArrays(gl::LINES, 0, self.line_vertices.len() as GLsizei);

            if depth_was { gl::Enable(gl::DEPTH_TEST); }
            gl::BindVertexArray(0);
        }

        self.line_vertices.clear();
    }
}

impl Drop for DebugRenderer {
    fn drop(&mut self) {
        unsafe {
            gl::DeleteProgram(self.line_shader);
            gl::DeleteVertexArrays(1, [self.line_vao].as_ptr());
            gl::DeleteBuffers(1, [self.line_vbo].as_ptr());
        }
    }
}

fn main() {
    // (init GLFW + GL)

    let mut debug = DebugRenderer::new();

    // 模拟一些 entity

**Troubleshooting**:

- **线看不到** — 深度测试没关,或线被裁剪。debug shader 没问题?
- **线段不连续** — winding 错(线段顶点顺序错乱),或 winding 算错
- **debug 几何闪烁** — `vertices.clear()` 漏了,数据累积
- **`GL_LINES` 没绘制** — 顶点数是奇数,最后一个被丢
- **wireframe 模式画面变怪** — `glPolygonMode` 没恢复 FILL
