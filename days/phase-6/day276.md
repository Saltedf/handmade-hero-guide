
# Day 276 · 调整身体动画

> 有了 spring(Day 274)和 transform(Day 275),今天 Casey 把这些工具组合起来,**精调角色身体动画**:走路时身体微弹、撞墙时压扁回弹、攻击时身体前倾。这不是新概念,是前面 3 天的工程组合 + 参数调试。

## 0 · 为什么要有这一天

你的角色现在能:

- 用 spring 平滑移动(Day 274)
- 用 transform 旋转 / 缩放 / 剪切(Day 275)

但是动画"参数"还没调好。比如:

- 走路时身体应该有多大弹动?太大像抽搐,太小没生气
- 撞墙时压扁多少?0.7 太夸张,0.9 太弱
- 攻击时身体前倾角度?15 度太僵硬,45 度太夸张

这些数字决定角色"感觉"对不对。**调参是动画师的必备技能**——一个游戏角色的"手感"和"重量感"全靠这些数字微调。

今天的集子 Casey 主要在调参,没什么新概念。但这是真实游戏开发的日常:**80% 时间在调参,20% 写代码**。

Casey 在视频里反复试参数,展示每种参数的视觉效果:

- stiffness = 50:角色像"果冻",动作慢
- stiffness = 150:角色有"弹性",合适
- stiffness = 300:角色像"弹簧",过冲明显
- damping = 5:角色振荡不停
- damping = 15:角色快速稳定
- damping = 30:角色"沉重",无弹性

最终 Casey 选 stiffness=120, damping=12 作为身体 spring 参数。

心理锚点:做完这个,你的角色动画"感觉对了"——这是从 demo 到游戏的飞跃。

## 1 · Casey 今天做了什么

Casey 把前面几天的工具组合:

1. 角色身体有两个 spring:scale_x 和 scale_y(Day 274)
2. 角色朝向用 transform rotation(Day 275)

4. 撞墙状态时,scale_x 设为 0.7,scale_y 设为 1.3,然后弹回 1.0

2. **二分查找**:在极端值之间二分,找合理区间
3. **游戏内调参**:加 debug overlay 实时改参数,边玩边调
4. **多人 review**:让朋友试玩,反馈"手感如何"

## 2 · 心智模型

### 类比:乐器调音

调钢琴师把每个键的弦调到正确频率。如果某个键偏高 5 Hz,听众听不出;偏高 50 Hz,听众觉得"刺耳"。中间的"刚刚好"需要反复试。

游戏动画参数类似:stiffness 差 10 不易察觉,差 50 明显不对。Casey 反复试,找"刚刚好"。

### 严谨原理:参数空间的探索

每个 spring 有 2 个主要参数(stiffness + damping),两个 spring(scale_x + scale_y)有 4 个。加上:

- 走路状态的目标 scale 周期
- 撞墙状态的 squash 目标值
- 攻击状态的前倾角度

总共 10+ 个数字要调。每个数字都影响最终视觉效果。

#### 调参流程

```
1. 初始化所有参数为"默认值"(经验值)
2. 跑游戏,观察动画
3. 找到"最不对劲"的参数
4. 调整那个参数(极端值测试 → 二分)
5. 回到 step 2
6. 当所有参数都"差不多对"时,做整体微调
```

这是个迭代过程,通常需要几十轮才能调好。

#### Debug Overlay 实时调参

调参时反复改源代码 + 重新编译,效率低。现代游戏引擎都有"实时调参"——在游戏运行时通过 UI 改参数,立即看效果。

```rust
struct DebugSpringParams {
    stiffness: f32,
    damping: f32,
}

// 游戏运行时,加 debug overlay
if show_debug {
    ui.slider("stiffness", &mut params.stiffness, 10.0, 500.0);
    ui.slider("damping", &mut params.damping, 1.0, 50.0);
}

// 把 params 应用到 spring
player.scale_x_spring.stiffness = params.stiffness;
player.scale_x_spring.damping = params.damping;
```

这样调参效率高 10 倍。Casey 在 HH 加了类似机制,后面 Day 268+ 用到。

### 动画状态的参数集

```rust
struct AnimParams {
    // Idle 状态:轻微呼吸
    idle_breath_freq: f32,      // 0.3 Hz(每 3.3 秒一个周期)
    idle_breath_amplitude: f32, // 0.03(scale 在 0.97-1.03)

    // Moving 状态:走路弹动
    walk_freq: f32,             // 1.5 Hz(每 0.67 秒一步)
    walk_amplitude: f32,        // 0.05

    // Bumping 状态:撞墙压扁
    bump_scale_x_target: f32,   // 0.7
    bump_scale_y_target: f32,   // 1.3
    bump_duration: f32,         // 0.2 秒

    // Attacking 状态:前倾
    attack_angle: f32,          // 15 度
    attack_duration: f32,       // 0.3 秒
}

impl Default for AnimParams {
    fn default() -> Self {
        Self {
            idle_breath_freq: 0.3,
            idle_breath_amplitude: 0.03,
            walk_freq: 1.5,
            walk_amplitude: 0.05,
            bump_scale_x_target: 0.7,
            bump_scale_y_target: 1.3,
            bump_duration: 0.2,
            attack_angle: 15.0,
            attack_duration: 0.3,
        }
    }
}
```

这是动画参数的"集中管理"——所有可调的数字都在一个 struct 里,方便 debug overlay 引用。

### Spring 的 stiffness / damping 调参指南

| stiffness | damping | 感觉 | 适合 |
|---|---|---|---|
| 50 | 5 | 慢,软 | 大型怪物 |
| 100 | 10 | 中等弹性 | 角色身体 |
| 150 | 12 | 弹性明显 | 角色 UI |
| 200 | 15 | 强弹性 | 撞击效果 |
| 300 | 20 | 快速稳定 | UI 弹窗 |

这些是经验值,具体游戏要试。

### 临界阻尼的计算

临界阻尼 `c_crit = 2 * sqrt(k)`(mass=1 时):

- k=100,c_crit=20
- k=150,c_crit≈24.5
- k=200,c_crit≈28.3

如果想要"过冲 10%"的弹性感,damping ≈ c_crit * 0.6:
- k=100,damping ≈ 12
- k=150,damping ≈ 15
- k=200,damping ≈ 17

如果想要"过冲 30%"的强烈弹性,damping ≈ c_crit * 0.3:
- k=100,damping ≈ 6
- k=150,damping ≈ 7
- k=200,damping ≈ 8

Casey 选中等弹性:damping ≈ c_crit * 0.6,适合角色身体。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 Casey 把动画参数集中在 `AnimParams` struct 而不是分散在 Player 各字段?给出至少 3 个理由。

**参考解答**:
1. **可发现性**:集中 struct 一眼看到所有参数,分散字段要扫整个 Player 定义
2. **可保存 / 加载**:集中 struct 可以 serde 序列化到文件,分散字段要手动每个写
3. **可对比**:不同关卡的 AnimParams 可以 diff 看差异,分散字段难对比
4. **可共享**:多个 entity 用同一套 AnimParams(只需一份),分散字段每个 entity 都要存
5. **debug UI 友好**:一个 struct 直接喂给 slider UI,分散字段要每个加 slider
6. **修改成本**:加新参数只在 struct 加字段,分散要改 Player 定义

```rust
#[derive(Debug, Clone)]
struct AnimParams {
    walk_freq: f32,
    walk_amplitude: f32,
    idle_breath_freq: f32,
    idle_breath_amplitude: f32,
    bump_scale_x: f32,
    bump_scale_y: f32,
    attack_angle_deg: f32,
}

impl Default for AnimParams {
    fn default() -> Self {
        Self {
            walk_freq: 1.5,
            walk_amplitude: 0.05,
            idle_breath_freq: 0.3,
            idle_breath_amplitude: 0.03,
            bump_scale_x: 0.7,
            bump_scale_y: 1.3,
            attack_angle_deg: 15.0,
        }
    }
}

fn main() {
    let params = AnimParams::default();
    println!("Default AnimParams:");
    println!("  walk_freq = {:.2}", params.walk_freq);
    println!("  walk_amplitude = {:.3}", params.walk_amplitude);
    println!("  idle_breath_freq = {:.2}", params.idle_breath_freq);
    println!("  idle_breath_amplitude = {:.3}", params.idle_breath_amplitude);
    println!("  bump_scale = ({:.2}, {:.2})", params.bump_scale_x, params.bump_scale_y);
    println!("  attack_angle = {:.1} deg", params.attack_angle_deg);

    // 模拟"应用参数到 spring"
    let stiffness = 100.0 + params.walk_freq * 50.0;  // 走路越快,spring 越硬
    let damping = 10.0 + params.walk_amplitude * 50.0;
    println!("\nDerived spring params:");
    println!("  stiffness = {:.2}", stiffness);
    println!("  damping = {:.2}", damping);
}
```

**每行解释**:
- `#[derive(Debug)]` 让 println 能打印
- `Default` trait 提供 `AnimParams::default()`,统一默认值
- 集中 struct 让加新参数容易(只改一个 struct)
- 参数之间可以派生(如 stiffness 从 walk_freq 推)

### 完整可跑:角色身体动画 + 实时调参

```rust
// Cargo.toml:
// [dependencies]
// minifb = "0.27"

use minifb::{Key, KeyRepeat, MouseMode, MouseButton, Window, WindowOptions};
use std::time::Instant;

const WIDTH: usize = 800;
const HEIGHT: usize = 600;

#[derive(Clone, Debug)]
struct AnimParams {
    walk_freq: f32,
    walk_amplitude: f32,
    idle_breath_freq: f32,
    idle_breath_amplitude: f32,
    bump_scale_x: f32,
    bump_scale_y: f32,
    spring_stiffness: f32,
    spring_damping: f32,
}

impl Default for AnimParams {
    fn default() -> Self {
        Self {
            walk_freq: 1.5,
            walk_amplitude: 0.08,
            idle_breath_freq: 0.3,
            idle_breath_amplitude: 0.03,
            bump_scale_x: 0.7,
            bump_scale_y: 1.3,
            spring_stiffness: 120.0,
            spring_damping: 12.0,
        }
    }
}

#[derive(Clone, Copy, Debug)]
struct Spring {
    value: f32,
    velocity: f32,
    target: f32,
    stiffness: f32,
    damping: f32,
}

impl Spring {
    fn new(initial: f32, stiffness: f32, damping: f32) -> Self {
        Self {
            value: initial, velocity: 0.0, target: initial,
            stiffness, damping,
        }
    }
    fn set_target(&mut self, t: f32) { self.target = t; }
    fn update(&mut self, dt: f32) {
        let force = -self.stiffness * (self.value - self.target) - self.damping * self.velocity;
        let acceleration = force;
        self.velocity += acceleration * dt;
        self.value += self.velocity * dt;
    }
}

struct Player {
    pos_x: f32,
    pos_y: f32,
    scale_x: Spring,
    scale_y: Spring,
    is_walking: bool,
    bump_timer: f32,
}

impl Player {
    fn new(x: f32, y: f32, params: &AnimParams) -> Self {
        Self {
            pos_x: x, pos_y: y,
            scale_x: Spring::new(1.0, params.spring_stiffness, params.spring_damping),
            scale_y: Spring::new(1.0, params.spring_stiffness, params.spring_damping),
            is_walking: false,
            bump_timer: 0.0,
        }
    }

    fn trigger_bump(&mut self, params: &AnimParams) {
        self.scale_x.set_target(params.bump_scale_x);
        self.scale_y.set_target(params.bump_scale_y);
        self.bump_timer = 0.2;
    }

    fn update(&mut self, dt: f32, total_time: f32, params: &AnimParams) {
        // bump 计时
        if self.bump_timer > 0.0 {
            self.bump_timer -= dt;
            if self.bump_timer <= 0.0 {
                self.scale_x.set_target(1.0);
                self.scale_y.set_target(1.0);
            }
        } else {
            // 没在 bump:走路或呼吸
            let (freq, amp) = if self.is_walking {
                (params.walk_freq, params.walk_amplitude)
            } else {
                (params.idle_breath_freq, params.idle_breath_amplitude)
            };
            let phase = (total_time * 2.0 * std::f32::consts::PI * freq).sin();
            // X 和 Y 反向(一缩一伸),模拟走路 / 呼吸
            self.scale_x.set_target(1.0 + amp * phase);
            self.scale_y.set_target(1.0 - amp * phase);
        }

        self.scale_x.update(dt);
        self.scale_y.update(dt);
    }
}

fn draw_player_scaled(buf: &mut [u32], buf_w: usize, buf_h: usize,
                      cx: i32, cy: i32, sx: f32, sy: f32) {
    let base = 24.0;
    let w = (base * sx) as i32;
    let h = (base * sy) as i32;
    for py in (cy - h/2).max(0)..(cy + h/2).min(buf_h as i32) {
        for px in (cx - w/2).max(0)..(cx + w/2).min(buf_w as i32) {
            buf[(py as usize) * buf_w + (px as usize)] = 0xFFFF6040;
        }
    }
    // 眼睛
    for py in cy-3..cy {
        for px in cx-6..cx-3 {
            if px >= 0 && (px as usize) < buf_w && py >= 0 && (py as usize) < buf_h {
                buf[(py as usize) * buf_w + (px as usize)] = 0xFFFFFFFF;
            }
        }
        for px in cx+2..cx+5 {
            if px >= 0 && (px as usize) < buf_w && py >= 0 && (py as usize) < buf_h {
                buf[(py as usize) * buf_w + (px as usize)] = 0xFFFFFFFF;
            }
        }
    }
}

fn draw_rect(buf: &mut [u32], buf_w: usize, buf_h: usize, x: i32, y: i32, w: i32, h: i32, color: u32) {
    for py in y.max(0)..(y + h).min(buf_h as i32) {
        for px in x.max(0)..(x + w).min(buf_w as i32) {
            buf[(py as usize) * buf_w + (px as usize)] = color;
        }
    }
}

fn main() {
    let mut window = Window::new(
        "Tuning Body Animation", WIDTH, HEIGHT,
        WindowOptions::default(),
    ).expect("Failed to open window");

    let mut buffer = vec![0u32; WIDTH * HEIGHT];
    let mut last_time = Instant::now();
    let mut total_time = 0.0_f32;

    let mut params = AnimParams::default();
    let mut player = Player::new(400.0, 300.0, &params);

    let mut show_debug = false;
    let mut selected_param = 0;  // 0=walk_freq, 1=walk_amp, ...

    while window.is_open() && !window.is_key_down(Key::Escape) {
        let now = Instant::now();
        let dt = now.duration_since(last_time).as_secs_f32().min(0.05);
        last_time = now;
        total_time += dt;

        // 输入
        if window.is_key_pressed(Key::F1, KeyRepeat::No) {
            show_debug = !show_debug;
        }
        if window.is_key_pressed(Key::W, KeyRepeat::No) {
            player.is_walking = !player.is_walking;
        }
        if window.is_key_pressed(Key::B, KeyRepeat::No) {
            player.trigger_bump(&params);
        }
        if window.is_key_pressed(Key::Tab, KeyRepeat::No) {
            selected_param = (selected_param + 1) % 8;
        }

        // Debug overlay 调参(用键盘 +/- 调)
        let adjustment = if window.is_key_down(Key::Equal) { 1.0 }
                        else if window.is_key_down(Key::Minus) { -1.0 }
                        else { 0.0 };
        let speed = 0.5;  // 每秒变化 0.5
        let delta = adjustment * speed * dt;
        match selected_param {
            0 => params.walk_freq = (params.walk_freq + delta).max(0.1).min(5.0),
            1 => params.walk_amplitude = (params.walk_amplitude + delta * 0.01).max(0.0).min(0.3),
            2 => params.idle_breath_freq = (params.idle_breath_freq + delta).max(0.0).min(2.0),
            3 => params.idle_breath_amplitude = (params.idle_breath_amplitude + delta * 0.01).max(0.0).min(0.1),
            4 => params.bump_scale_x = (params.bump_scale_x + delta * 0.01).max(0.3).min(1.5),
            5 => params.bump_scale_y = (params.bump_scale_y + delta * 0.01).max(0.3).min(1.5),
            6 => params.spring_stiffness = (params.spring_stiffness + delta * 5.0).max(10.0).min(500.0),
            7 => params.spring_damping = (params.spring_damping + delta).max(1.0).min(50.0),
            _ => {}
        }

        // 更新 player
        // 同步 spring 参数(让实时调参生效)
        player.scale_x.stiffness = params.spring_stiffness;
        player.scale_x.damping = params.spring_damping;
        player.scale_y.stiffness = params.spring_stiffness;
        player.scale_y.damping = params.spring_damping;
        player.update(dt, total_time, &params);

        // 渲染
        for px in buffer.iter_mut() { *px = 0xFF101010; }

        // 画地面参考
        draw_rect(&mut buffer, WIDTH, HEIGHT, 0, 320, WIDTH as i32, 4, 0xFF404040);

        // 画 player
        draw_player_scaled(&mut buffer, WIDTH, HEIGHT,
                           player.pos_x as i32, player.pos_y as i32,
                           player.scale_x.value, player.scale_y.value);

        // 状态指示
        let state_color = if player.is_walking { 0xFF40FF40 } else { 0xFF4040FF };
        draw_rect(&mut buffer, WIDTH, HEIGHT, 10, 10, 100, 20, state_color);

        // Debug overlay
        if show_debug {
            draw_rect(&mut buffer, WIDTH, HEIGHT, 580, 50, 200, 250, 0xFF202020);

            let names = [
                "walk_freq", "walk_amp", "idle_freq", "idle_amp",
                "bump_sx", "bump_sy", "stiffness", "damping",
            ];
            let values = [
                params.walk_freq, params.walk_amplitude,
                params.idle_breath_freq, params.idle_breath_amplitude,
                params.bump_scale_x, params.bump_scale_y,
                params.spring_stiffness, params.spring_damping,
            ];

            // 简化的"文字"渲染(用色块代替字符)
            for (i, name) in names.iter().enumerate() {
                let y = 60 + i as i32 * 22;
                let highlight = if i == selected_param { 0xFFFFFF40 } else { 0xFF404040 };
                draw_rect(&mut buffer, WIDTH, HEIGHT, 590, y, 180, 18, highlight);
                // 数值进度条
                let val_progress = (values[i] / 5.0).min(1.0);
                draw_rect(&mut buffer, WIDTH, HEIGHT,
                          590, y + 6, (180.0 * val_progress) as i32, 6, 0xFF4080FF);
            }
        }

        let _ = window.get_mouse_pos(MouseMode::Discard);
        let _ = window.get_mouse_down(MouseButton::Left);

        window.update_with_buffer(&buffer, WIDTH, HEIGHT).unwrap();
    }
}
```

**关键 Rust 特性解释**:

- `AnimParams::default()` 集中管理所有可调参数
- `match selected_param` 根据 UI 焦点决定调哪个参数
- `clamp` 用 `.max().min()` 链式调用,防止参数跑出范围
- spring 的 stiffness/damping 每帧从 params 同步,让实时调参立即生效
- Debug overlay 用色块代替文字(简化),实际项目用字体渲染
