# Day 386 · 实现自定义多重采样解析

> 昨天发现 OpenGL 默认的 `glBlitFramebuffer` resolve 对深度剥离**不管用**(深度不能"盒式平均")。今天 Casey 写**自定义 resolve shader**——手动从 multisample 纹理读取每个采样,自己决定如何合并。这是 GPGPU 思维的经典应用:"标准 API 不够时,自己写 shader"。

## 0 · 为什么要有这一天

昨天留下的问题:multisample texture(每像素 4 个采样)需要变成 single-sample texture(每像素 1 个值),才能给后续 pass 用。`glBlitFramebuffer` 的默认 resolve 是**盒式平均**,对颜色 OK,对**深度**不 OK。

**为什么深度不能平均**?

考虑像素 P 的 4 个采样,深度分别是 `[0.1, 0.1, 0.9, 0.9]`。这表示:

- 采样 0,1 在不透明物体表面(深度 0.1)
- 采样 2,3 在玻璃后面(深度 0.9)

平均 = `(0.1 + 0.1 + 0.9 + 0.9) / 4 = 0.5`,但**没有物体在深度 0.5**。如果第二层 peel 用 0.5 做基准,得到错误的"第二层位置"。

**正确的 resolve**:不是平均,而是**取最小**(最近)或**取最大**(最远),取决于语义。深度剥离第一层 = "所有采样的最小深度",第二层 = "严格大于第一层的最小深度"。

这就是**自定义 resolve**——你写 shader,手动决定怎么合并采样。

**今天的产出**:

1. 一个 fullscreen shader,从 `sampler2DMS`(multisample sampler)读 4 个采样
2. 自己决定合并策略(取最小 / 取最大 / per-sample 比较)
3. 输出到 single-sample texture

这是个**重要工程模式**——很多 GPU 算法(reduce、scan、histogram)都需要"自定义合并多个值",今天的 resolve 是入门案例。

心理锚点:看完今天,你能(1)解释 `sampler2DMS` 和 `sampler2D` 的差别;(2)写一个简单的"取最小深度"resolve shader;(3)理解为什么 `glBlitFramebuffer` 不够灵活;(4)面对类似的"多值合并"问题时知道怎么写 shader。

## 2 · 心智模型

### 类比:考试改卷

想象你是老师,改一份试卷。试卷有 4 道大题,学生有 4 个不同的解法。

**默认 resolve**(盒式平均):每个学生的 4 个解法**取平均分**。这对"加权评分"OK,但对"判断学生是否能毕业"不 OK——学生可能 4 道题答得都不一样,平均分可能恰好是及格线,但实际没人答得正好这个分。

**自定义 resolve**:你来决定怎么合并。比如"4 道题的最高分"(学生最强项),"4 道题的最低分"(学生最弱项),"4 道题的中位数"——根据语义选。

GPU 上的 multisample resolve 就是这个过程:每个像素的 4 个采样,你怎么合并?

- 颜色平均:`avg(samples)` —— 这是"加权评分"
- 深度取最小:`min(samples)` —— 这是"最近物体"
- 深度取最大:`max(samples)` —— 这是"最远物体"
- Per-sample 比较:`each_sample_independently` —— 这是"每题独立判断"

### 严谨原理:`sampler2DMS` 和 `texelFetch`

GLSL 里普通纹理 sampler 是 `sampler2D`,采样用 `texture(sampler, uv)` 或 `texelFetch(sampler, ivec2(px, py), lod)`。

**Multisample texture** 用 `sampler2DMS`,采样**必须**用 `texelFetch`(因为需要指定采样 ID):

```glsl
uniform sampler2DMS ms_color;  // multisample 颜色纹理

void main() {
    ivec2 px = ivec2(gl_FragCoord.xy);
    // 读 4 个采样
    vec4 s0 = texelFetch(ms_color, px, 0);
    vec4 s1 = texelFetch(ms_color, px, 1);
    vec4 s2 = texelFetch(ms_color, px, 2);
    vec4 s3 = texelFetch(ms_color, px, 3);
    // 合并(取决于语义)
    vec4 result = (s0 + s1 + s2 + s3) / 4.0;  // 颜色平均
    frag_color = result;
}
```

**关键点**:

- `sampler2DMS` 没有 LOD(没 mipmap),所以 `texelFetch` 不需要 LOD 参数(对比 `sampler2D` 需要 `texelFetch(s, px, lod)`)
- `texelFetch(ms, px, sample_id)` 必须指定 sample_id(0..N-1)
- 采样数(`GL_SAMPLES`)在创建 multisample texture 时固定,shader 可以查 `gl_NumSamples`(GLSL 4.2+)

### 取最小深度 resolve

```glsl
#version 430  // 4.3+ for sampler2DMS in vertex shader

uniform sampler2DMS ms_depth;

out float out_depth;

void main() {
    ivec2 px = ivec2(gl_FragCoord.xy);
    float d0 = texelFetch(ms_depth, px, 0).r;
    float d1 = texelFetch(ms_depth, px, 1).r;
    float d2 = texelFetch(ms_depth, px, 2).r;
    float d3 = texelFetch(ms_depth, px, 3).r;
    out_depth = min(min(d0, d1), min(d2, d3));
}
```

**注意**:`min(min(a, b), min(c, d))` 是 4 个值取最小——两层 `min` 嵌套。GLSL 也支持 `min4`(某些 GPU 扩展),但标准 GLSL 没有。

### 颜色平均 resolve

```glsl
uniform sampler2DMS ms_color;
out vec4 frag_color;

void main() {
    ivec2 px = ivec2(gl_FragCoord.xy);
    vec4 sum = vec4(0.0);
    for (int i = 0; i < 4; ++i) {  // 4 个采样
        sum += texelFetch(ms_color, px, i);
    }
    frag_color = sum / 4.0;
}
```

这就是 `glBlitFramebuffer` 默认做的事——盒式平均。

### 为什么不能用 `texture()`?

`sampler2DMS` 不支持 `texture()` 采样,因为:

1. Multisample texture 没有"插值"语义——你不能"在两个像素之间插值",因为 multisample 是 per-pixel 内部的事。
2. `texture()` 默认用浮点坐标做双线性插值,对 multisample 没意义。
3. 必须用 `texelFetch` 指定整数像素坐标 + 采样 ID。

### 全屏 shader 工作流

自定义 resolve 用**全屏 shader**(fullscreen quad):

1. CPU 端:绘制一个覆盖屏幕的四边形
2. Vertex shader:输出 fullscreen 位置
3. Fragment shader:**每像素执行一次**,读取 multisample texture 的 N 个采样,合并,输出到 single-sample framebuffer

这相当于"用 fragment shader 做图像处理",每个像素独立计算。这是 post-processing 的标准模式。

### Per-sample 深度剥离(下一步,Day 387)

Casey 今天写的 resolve **合并**了 4 个采样为 1 个深度,这是 per-pixel resolve。但**真正的 MSAA 深度剥离**应该 per-sample:

- 第一层:每个采样有独立的"最近深度"
- 第二层:每个采样有独立的"第二层深度"

这意味着 multisample texture 的每个采样都做完整的深度剥离,合成时再合并。

实现复杂度大幅增加:multisample framebuffer 上做 N 层 peel,每层是 multisample,最后 resolve 时合并。Day 387-388 会做。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

自定义 resolve 在游戏开发的应用:

- **G-buffer resolve**(延迟渲染):MSAA G-buffer 需要自定义 resolve(每属性的合并策略不同——深度取 min、法线取平均、颜色取加权)
- **Shadow map resolve**:深度取 min(最近)
- **HDR resolve**:颜色按"曝光"加权,不是简单平均
- **TAA(Temporal AA)**:不是 multisample resolve,而是"跨帧 resolve",累积多帧的采样

**性能考虑**:自定义 resolve 是 fullscreen shader,1080p + 4 个采样 = 800 万次 fragment shader 执行,开销不小。GPU 上 fragment shader 一次执行几微秒,但 800 万次 = 几十毫秒。生产代码要优化(用 compute shader + shared memory 减少 bandwidth)。

### 3.2 · 🎨 图形学视角

**Multisample texture 在 OpenGL 3.2+ 引入**(ARB_texture_multisample)。比 multisample renderbuffer(OpenGL 3.0)更灵活——可以直接在 shader 里读。

**Sample positions**:OpenGL 不保证采样位置,各 GPU 厂商自定义。但有 `glGetMultisamplefv(GL_SAMPLE_POSITION, i, &pos)` 查询第 i 个采样的归一化位置(范围 [0, 1])。

**Per-sample shading**(`glMinSampleShadingARB`):让 fragment shader 每采样执行一次(而不是每像素一次)。开销 N 倍,但 shader 内的边缘也被抗锯齿。Casey 在 Day 387 用这个做 per-sample peel。

**Sample mask**:`glSampleMaski` 控制哪些采样被画。可以用来"只用采样 0"做 debug。

### 3.3 · 🐧 Linux 系统编程视角

Mesa 上的 multisample:

### 3.4 · 🦀 Rust 生态视角

Rust 端用 `gl` crate 直接调用 OpenGL:

```rust
use gl::types::*;

// 创建 multisample texture
let mut tex: GLuint = 0;
unsafe {
    gl::GenTextures(1, &mut tex);
    gl::BindTexture(gl::TEXTURE_2D_MULTISAMPLE, tex);
    gl::TexImage2DMultisample(
        gl::TEXTURE_2D_MULTISAMPLE,
        4,  // samples
        gl::RGBA32F,
        800, 600,
        gl::TRUE,  // fixed sample locations
    );
}

// 在 shader 里读
let fs_source = r#"#version 430
    uniform sampler2DMS ms_color;
    out vec4 frag;
    void main() {
        ivec2 px = ivec2(gl_FragCoord.xy);
        vec4 s = vec4(0);
        for (int i = 0; i < 4; ++i) {
            s += texelFetch(ms_color, px, i);
        }
        frag = s / 4.0;
    }
"#;
```

**关键 Rust 概念**:

- `GLuint` = OpenGL 的"无符号整数"类型,在 `gl` crate 中定义
- `unsafe { gl::XXX(...) }` — 所有 GL call 是 unsafe,因为 Rust 不知道 OpenGL context 是 current 的
- Raw pointer / FFI:OpenGL 是 C API,Rust 通过 `extern "C"` 调用

**glium 的封装**:glium 提供 `Texture2DMultisample` 类型,内部封装 `TexImage2DMultisample`,API 安全。但 fragment shader 里仍然要写 `sampler2DMS` + `texelFetch`(GLSL 部分 glium 不抽象)。

## 5 · 对照与变奏

### 同一问题在不同语境下的变体

**问题**:把多个值合并为一个。

| 语境 | 合并策略 |
|---|---|
| MSAA 颜色 resolve | 盒式平均 |
| MSAA 深度 resolve | 取最小(min) |
| Shadow map blur | 取最大(max,模拟 soft shadow) |
| G-buffer normal resolve | 角度平均(球面插值) |
| TAA | 加权平均(按距离 / 运动) |
| 神经网络 pooling | max / avg pooling |

**核心模式**:**Reduce**(归约)——N 个值合并为 1 个,合并函数取决于语义。

### 历史演化

- **1990s**:MSAA 在 SGI 工作站引入,硬件 resolve
- **2000s**:`glBlitFramebuffer` 提供 API(OpenGL 3.0)
- **2010s**:Multisample texture(OpenGL 3.2)+ 自定义 resolve 流行
- **2020s**:Compute shader + bindless texture 让 resolve 更灵活,但 MSAA 本身被 TAA 取代

### CPU vs GPU Resolve

| | CPU | GPU |
|---|---|---|
| 实现 | Rust for loop | GLSL shader |
| 速度 | 慢(内存传输) | 快(并行) |
| 灵活性 | 最高 | 受 shader 模型限制 |
| 适合 | 小尺寸 / 测试 | 全屏 |

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 `sampler2DMS` 不支持 `texture()` 函数,只能用 `texelFetch`?

**参考解答**:

`sampler2D` 的 `texture(sampler, uv)` 做的是"采样 + 双线性插值"——给定浮点 uv,在 4 个最近像素间插值。

`sampler2DMS` 没有"插值"语义:

1. **Multisample 是 per-pixel 内部的事**:每像素有 N 个采样,采样位置固定(在像素内部)。两个像素之间没有"中间状态"。
2. **必须指定采样 ID**:`texelFetch(ms, px, sample_id)` 需要 sample_id,告诉 GPU 读哪个采样。`texture()` 没有 sample_id 参数,无法表达。
3. **没有 mipmap**:multisample texture 没 mipmap(因为 mipmap 是降采样,multisample 本身就是"超高采样")。

所以 multisample texture 必须用 `texelFetch`,这是设计决定。

### Lv2 · 动手实践

**题**:写一个"取最小深度"resolve shader,在 Rust + glium 项目里跑。要求:

- 创建一个 multisample depth texture(4 samples)
- 渲染一个三角形到它
- 自定义 resolve 到 single-sample depth texture(取最小)
- 显示 resolve 后的深度(灰度图)

完成标准:屏幕显示深度灰度图,边缘平滑。

**参考解答**:

```rust
use glium::{glutin, Surface, implement_vertex, program, index, texture, framebuffer};

#[derive(Copy, Clone)]
struct Vertex { position: [f32; 3] }
implement_vertex!(Vertex, position);

fn main() {
    let event_loop = glutin::event_loop::EventLoop::new();
    let wb = glutin::window::WindowBuilder::new()
        .with_inner_size(glutin::dpi::LogicalSize::new(800, 600));
    let cb = glutin::ContextBuilder::new();
    let display = glium::Display::new(wb, cb, &event_loop).unwrap();

    let (w, h) = (800u32, 600u32);
    // Multisample depth texture
    let depth_ms = texture::DepthTexture2DMultisample::new(
        &display, texture::DepthFormat::F32, w, h, 4, true).unwrap();
    // Multisample color texture(用 alpha 占位,只为 FBO 完整)
    let color_ms = texture::Texture2DMultisample::new(
        &display, texture::UncompressedFloatFormat::F32F32F32F32,
        w, h, 4, true).unwrap();
    // Single-sample depth texture(resolve 目标)
    let depth_ss = texture::DepthTexture2d::empty_with_format(
        &display, texture::DepthFormat::F32,
        texture::MipmapsOption::NoMipmap, w, h).unwrap();
    // Single-sample color texture(显示用)
    let color_ss = texture::Texture2d::empty_with_format(
        &display, texture::UncompressedFloatFormat::F32F32F32F32,
        texture::MipmapsOption::NoMipmap, w, h).unwrap();

    // MS FBO(渲染目标)
    let mut fbo_ms = framebuffer::SimpleFrameBuffer::with_depth_texture(
        &display, &color_ms, &depth_ms).unwrap();
    // SS FBO(resolve 目标)
    let mut fbo_ss = framebuffer::SimpleFrameBuffer::with_depth_texture(
        &display, &color_ss, &depth_ss).unwrap();

    // 三角形
    let verts = vec![
        Vertex { position: [-0.5, -0.5, 0.2] },
        Vertex { position: [ 0.5, -0.5, 0.8] },
        Vertex { position: [ 0.0,  0.5, 0.5] },
    ];
    let vbuf = glium::VertexBuffer::new(&display, &verts).unwrap();
    let indices = index::NoIndices(index::PrimitiveType::TrianglesList);

    let render_program = program!(&display,
        330 es => {
            vertex: r#"#version 330
                in vec3 position;
                void main() { gl_Position = vec4(position.xy, position.z, 1.0); }
            "#,
            fragment: r#"#version 330
                out vec4 frag;
                void main() { frag = vec4(1.0, 0.0, 0.0, 1.0); }
            "#,
        }).unwrap();

    // Resolve shader:从 ms_depth 读 4 个采样,取最小
    let resolve_program = program!(&display,
        430 core => {
            vertex: r#"#version 430
                out vec2 v_uv;
                void main() {
                    vec2 p = vec2((gl_VertexID == 1) ? 3.0 : -1.0,
                                  (gl_VertexID == 2) ? 3.0 : -1.0);
                    gl_Position = vec4(p, 0.0, 1.0);
                    v_uv = p * 0.5 + 0.5;
                }
            "#,
            fragment: r#"#version 430
                in vec2 v_uv;
                out vec4 frag;
                uniform sampler2DMS ms_depth;
                uniform vec2 resolution;
                void main() {
                    ivec2 px = ivec2(v_uv * resolution);
                    float d0 = texelFetch(ms_depth, px, 0).r;
                    float d1 = texelFetch(ms_depth, px, 1).r;
                    float d2 = texelFetch(ms_depth, px, 2).r;
                    float d3 = texelFetch(ms_depth, px, 3).r;
                    float min_d = min(min(d0, d1), min(d2, d3));
                    // 把深度映射到 [0, 1] 显示
                    frag = vec4(vec3(min_d), 1.0);
                }
            "#,
        }).unwrap();

    event_loop.run(move |event, _, control_flow| {
        use glutin::event::{Event, WindowEvent};
        use glutin::event_loop::ControlFlow;
        *control_flow = ControlFlow::Wait;

        if let Event::RedrawRequested(_) = event {
            // Pass 1:渲染到 multisample FBO
            fbo_ms.clear_color(0., 0., 0., 1.);
            fbo_ms.clear_depth(1.);
            let params = glium::DrawParameters {
                depth: glium::Depth {
                    test: glium::draw_parameters::DepthTest::IfLess,
                    write: true, ..Default::default()
                },
                ..Default::default()
            };
            fbo_ms.draw(&vbuf, &indices, &render_program,
                &glium::uniforms::EmptyUniforms, &params).unwrap();

            // Pass 2:resolve 到 ss FBO
            fbo_ss.clear_color(0., 0., 0., 1.);
            fbo_ss.clear_depth(1.);
            // 注意:gl_VertexID trick 生成 fullscreen triangle without VBO
            let empty_vbo: glium::VertexBuffer<Vertex> = glium::VertexBuffer::empty(&display, 0).unwrap();
            let uniforms = glium::uniform! {
                ms_depth: &depth_ms,
                resolution: [w as f32, h as f32],
            };
            fbo_ss.draw(&empty_vbo, &index::NoIndices(index::PrimitiveType::TrianglesList),
                &resolve_program, &uniforms,
                &glium::DrawParameters {
                    depth: glium::Depth {
                        test: glium::draw_parameters::DepthTest::Overwrite,
                        write: false, ..Default::default()
                    },
                    ..Default::default()
                }).unwrap();

            // Pass 3:显示 color_ss 到屏幕
            let mut target = display.draw();
            target.clear_color(0.1, 0.1, 0.1, 1.0);
            // 简化:直接画 color_ss 到 target
            // 实际:另一个 fullscreen shader
            target.finish().unwrap();
        }

        if let Event::WindowEvent { event: WindowEvent::CloseRequested, .. } = event {
            *control_flow = ControlFlow::Exit;
        }
    });
}
```

**关键技巧**:

- `gl_VertexID` trick:用 vertex shader 的内置 vertex ID 生成 fullscreen triangle,**不需要 VBO**。3 个顶点硬编码,覆盖整个屏幕。性能更好(无 vertex fetch)。
- `DepthTest::Overwrite` — resolve pass 不做深度测试,直接覆盖
- `texelFetch(ms_depth, px, i)` — 必须用整数像素坐标,从 v_uv 转换:`ivec2(v_uv * resolution)`

### 完整自定义 resolve demo

```toml
[package]
name = "custom_resolve"
version = "0.1.0"
edition = "2021"
[dependencies]
glium = "0.34"
```

```rust
// src/main.rs
use glium::{glutin, Surface, program, index, texture, framebuffer, implement_vertex, uniform};

#[derive(Copy, Clone)]
struct Vertex { position: [f32; 2] }
implement_vertex!(Vertex, position);

fn main() {
    let event_loop = glutin::event_loop::EventLoop::new();
    let wb = glutin::window::WindowBuilder::new()
        .with_inner_size(glutin::dpi::LogicalSize::new(800, 600))
        .with_title("Custom Resolve Demo");
    let cb = glutin::ContextBuilder::new();
    let display = glium::Display::new(wb, cb, &event_loop).unwrap();

    let (w, h) = (800u32, 600u32);
    let msaa_samples = 4u32;

    // MS 纹理
    let color_ms = texture::Texture2DMultisample::new(
        &display, texture::UncompressedFloatFormat::F32F32F32F32,
        w, h, msaa_samples, true).unwrap();
    let depth_ms = texture::DepthTexture2DMultisample::new(
        &display, texture::DepthFormat::F32, w, h, msaa_samples, true).unwrap();

    // SS 纹理(resolve 目标)
    let color_ss = texture::Texture2d::empty_with_format(
        &display, texture::UncompressedFloatFormat::F32F32F32F32,
        texture::MipmapsOption::NoMipmap, w, h).unwrap();

    let mut fbo_ms = framebuffer::SimpleFrameBuffer::with_depth_texture(
        &display, &color_ms, &depth_ms).unwrap();
    let mut fbo_ss = framebuffer::SimpleFrameBuffer::new(&display, &color_ss).unwrap();

    // 场景:两个三角形
    let verts = vec![
        Vertex { position: [-0.7, -0.7] },
        Vertex { position: [ 0.7, -0.7] },
        Vertex { position: [ 0.0,  0.7] },
    ];
    let vbuf = glium::VertexBuffer::new(&display, &verts).unwrap();
    let indices = index::NoIndices(index::PrimitiveType::TrianglesList);

    let scene_program = program!(&display,
        330 es => {
            vertex: r#"#version 330
                in vec2 position;
                uniform float z;
                void main() { gl_Position = vec4(position, z, 1.0); }
            "#,
            fragment: r#"#version 330
                out vec4 frag;
                uniform vec3 color;
                void main() { frag = vec4(color, 0.7); }
            "#,
        }).unwrap();

    // 自定义 resolve shader(颜色平均)
    let resolve_program = program!(&display,
        430 core => {
            vertex: r#"#version 430
                out vec2 v_uv;
                void main() {
                    vec2 p = vec2((gl_VertexID == 1) ? 3.0 : -1.0,
                                  (gl_VertexID == 2) ? 3.0 : -1.0);
                    gl_Position = vec4(p, 0.0, 1.0);
                    v_uv = p * 0.5 + 0.5;
                }
            "#,
            fragment: r#"#version 430
                in vec2 v_uv;
                out vec4 frag;
                uniform sampler2DMS ms_color;
                uniform vec2 resolution;
                void main() {
                    ivec2 px = ivec2(v_uv * resolution);
                    vec4 sum = vec4(0.0);
                    for (int i = 0; i < 4; ++i) {
                        sum += texelFetch(ms_color, px, i);
                    }
                    frag = sum / 4.0;
                }
            "#,
        }).unwrap();

    event_loop.run(move |event, _, control_flow| {
        use glutin::event::{Event, WindowEvent};
        use glutin::event_loop::ControlFlow;
        *control_flow = ControlFlow::Wait;

        if let Event::RedrawRequested(_) = event {
            // Pass 1:渲染到 MS FBO
            fbo_ms.clear_color(0., 0., 0., 1.);
            fbo_ms.clear_depth(1.);
            let params = glium::DrawParameters {
                depth: glium::Depth {
                    test: glium::draw_parameters::DepthTest::IfLess,
                    write: true, ..Default::default()
                },
                ..Default::default()
            };
            let uniforms = uniform! { z: 0.3f32, color: [1.0f32, 0.0, 0.0] };
            fbo_ms.draw(&vbuf, &indices, &scene_program, &uniforms, &params).unwrap();

            // Pass 2:自定义 resolve
            fbo_ss.clear(None);
            let empty_vbo: glium::VertexBuffer<Vertex> = glium::VertexBuffer::empty(&display, 0).unwrap();
            let resolve_uniforms = uniform! {
                ms_color: &color_ms,
                resolution: [w as f32, h as f32],
            };
            fbo_ss.draw(&empty_vbo,
                &index::NoIndices(index::PrimitiveType::TrianglesList),
                &resolve_program, &resolve_uniforms,
                &Default::default()).unwrap();

            // Pass 3:显示
            let mut target = display.draw();
            target.clear_color(0.1, 0.1, 0.1, 1.0);
            // 简化:直接画 color_ss(实际应该有第三个 shader)
            // 这里假设用简单 sampler 显示
            target.finish().unwrap();
        }

        if let Event::WindowEvent { event: WindowEvent::CloseRequested, .. } = event {
            *control_flow = ControlFlow::Exit;
        }
    });
}
```

### Arch Linux 工具链命令

```bash
# 1. 跑 demo
cargo run --release

# 2. 看 GLSL 编译错(如果有)
# glium 默认打印 shader 编译错到 stderr
# 常见错:
#   "sampler2DMS requires GLSL 4.2+" — 把 #version 330 改成 #version 430
#   "texelFetch not declared" — 检查 GLSL 版本

# 3. RenderDoc 看 multisample texture
renderdoc &
# 抓帧 → Texture Viewer → 选 ms_color → 点 "Sample 0/1/2/3" 看每个采样

# 4. 性能 profiling
sudo pacman -S perf
perf stat -e instructions,cycles,L1-dcache-load-misses ./target/release/custom_resolve
# 看 cache miss(MSAA 增加 cache 压力)

# 5. Mesa 调试
MESA_DEBUG=1 ./target/release/custom_resolve 2>&1 | head
```

**Troubleshooting**:

- "sampler2DMS not supported" — GLSL 版本 < 420,改成 `#version 420` 或更高
- `texelFetch` 返回 0 — 检查 ms texture 是否真的创建了(`glGetTexLevelParameteriv(GL_TEXTURE_2D_MULTISAMPLE, 0, GL_TEXTURE_SAMPLES, &samples)`)
- Resolve 后画面全黑 — 检查 v_uv 计算:`v_uv = p * 0.5 + 0.5` 把 [-1, 1] 映射到 [0, 1],再 `* resolution` 转像素
