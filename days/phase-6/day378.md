
# Day 378 · 加更多相机行为

> Day 377 的相机只支持第三人称跟随。今天 Casey 扩展相机:**第一人称(FPS)视角**、**自由飞行(noclip)视角**、**环绕轨道(orbit)视角**——多种模式,运行时切换。

## 0 · 为什么要有这一天

你的游戏开始需要"不同镜头"。**关卡编辑器**需要自由飞行(无视碰撞,任意移动)看场景;**调试模式**需要第一人称(精确视角检查);**演示视频**需要 orbit(自动旋转展示)。

每种视角有不同需求:
- **第一人称(FPS)**:相机在玩家头部,跟随玩家旋转,鼠标控制视角
- **第三人称(TPS)**:相机在玩家后方上方,跟随玩家位置,鼠标控制绕玩家旋转
- **自由飞行(Noclip)**:相机独立移动,WASD + 鼠标,无碰撞
- **Orbit**:相机绕固定点旋转,半径固定

实现这些"相机模式"看似简单(就是不同的 view matrix 计算),但**实际坑多**:
1. **模式切换平滑**:从第三人称切到第一人称,不能瞬间跳,要平滑过渡
2. **每种模式的输入响应不同**:FPS 鼠标直接转视角,TPS 鼠标绕玩家转
3. **碰撞处理不同**:FPS 无碰撞(头在角色里),TPS 有碰撞(避免穿墙)

工业游戏(如 GTA, Cyberpunk)支持多种相机,玩家随时切换。Casey 今天实现 HH 的多相机系统。

更深层:**相机模式架构**(state pattern)。不同相机行为对应不同 state,有共同接口,运行时切换。这是 Rust enum + trait 的经典应用。

心理锚点:今天之后,你能实现多种相机模式,理解 Rust enum + trait object 在状态管理上的应用,知道怎么避免模式切换的"跳变"。

## 1 · Casey 今天做了什么(HH 脉络)

Day 377 完成第三人称相机后,Casey 决定扩展到多种模式。具体:

1. 定义 `enum CameraMode { FirstPerson, ThirdPerson, Free, Orbit }`
2. 每种 mode 有自己的 update 函数
3. 按 C 键循环切换模式
4. 切换时做 0.5 秒平滑过渡(`lerp` 旧位置到新位置)

Casey 强调**输入响应**:
- FirstPerson:鼠标直接转 yaw/pitch
- ThirdPerson:鼠标转"绕玩家的偏移角度"
- Free:WASD + 鼠标(像 Minecraft creative)
- Orbit:自动绕固定点旋转,鼠标可选 zoom

Casey 的架构:

```rust
pub struct Camera {
    pub mode: CameraMode,
    pub pos: Vec3,            // 当前实际位置
    pub target_pos: Vec3,     // 模式期望位置(lerp 目标)
    pub yaw: f32,
    pub pitch: f32,
    // ... 各种模式的参数
}

impl Camera {
    pub fn update(&mut self, dt: f32, player_pos: Vec3) {
        // 根据模式算 target_pos
        self.target_pos = match self.mode {
            CameraMode::FirstPerson => player_pos + Vec3::new(0.0, 1.7, 0.0),
            CameraMode::ThirdPerson => /* orbit 算法 */,
            CameraMode::Free => /* 不依赖 player */,
            CameraMode::Orbit => /* 自动旋转 */,
        };

        // 平滑 lerp
        let alpha = 1.0 - (-8.0 * dt).exp();
        self.pos = self.pos.lerp(self.target_pos, alpha);
    }
}
```

## 2 · 心智模型

### 类比:相机模式像"摄像机角色"

想象你是电影导演,有一台摄像机。这台摄像机有不同"性格"(模式):
- **跟拍**(第三人称):在演员后上方,跟着演员
- **主观镜头**(第一人称):贴在演员脸上,看演员看的方向
- **摇臂**(自由飞行):独立运动,你想去哪就去哪
- **环绕**(orbit):绕固定点旋转,展示全景

每种性格有自己的"行为规则",导演喊"切换",摄像机换性格。但**位置不能瞬移**(观众晕),要平滑过渡。

### 每种模式的数学

**第一人称(FPS)**

相机位置 = 玩家头部位置。视角直接是玩家的 yaw/pitch。

```
camera_pos = player_pos + Vec3(0, eye_height, 0)
camera_yaw = player_yaw
camera_pitch = player_pitch
view_matrix = look_at(camera_pos, camera_pos + forward, up)
```

`forward = (cos(pitch)*sin(yaw), sin(pitch), cos(pitch)*cos(yaw))`

**第三人称(TPS)**

相机在玩家后上方,看玩家。鼠标控制"绕玩家的角度"。

```
// 计算相机在玩家周围的偏移
offset = Vec3(
    distance * cos(pitch) * sin(yaw),
    distance * sin(pitch),
    distance * cos(pitch) * cos(yaw)
);
camera_pos = player_pos + offset;
view_matrix = look_at(camera_pos, player_pos + Vec3(0, 1.5, 0), up);
```

**自由飞行(Free / Noclip)**

相机独立运动。WASD 移动,鼠标控制视角。

```rust
// 鼠标改 yaw/pitch
// WASD 改 pos
if W pressed: pos += forward * speed * dt
if S pressed: pos -= forward * speed * dt
if A pressed: pos -= right * speed * dt
if D pressed: pos += right * speed * dt
if Space pressed: pos += up * speed * dt
if Ctrl pressed: pos -= up * speed * dt
```

**Orbit**

自动绕固定点旋转。

```
yaw_auto += orbit_speed * dt
camera_pos = orbit_center + Vec3(
    orbit_radius * sin(yaw_auto),
    orbit_height,
    orbit_radius * cos(yaw_auto)
);
view_matrix = look_at(camera_pos, orbit_center, up);
```

### 模式切换的平滑

```rust
pub fn switch_mode(&mut self, new_mode: CameraMode) {
    if self.mode == new_mode { return; }
    self.mode = new_mode;
    // 记录切换开始时间,用于平滑过渡
    self.transition_t = 0.0;
    self.transition_from_pos = self.pos;
    self.transition_duration = 0.5;  // 0.5 秒
}

pub fn update(&mut self, dt: f32, player_pos: Vec3) {
    self.transition_t += dt;
    let alpha = (self.transition_t / self.transition_duration).min(1.0);
    let eased_alpha = smooth_step(alpha);  // 平滑曲线,不是线性

    self.target_pos = self.compute_target_pos(player_pos);
    self.pos = self.transition_from_pos.lerp(self.target_pos, eased_alpha);
}

fn smooth_step(t: f32) -> f32 {
    t * t * (3.0 - 2.0 * t)  // smoothstep 函数
}
```

`smooth_step(t) = t² × (3 - 2t)`:t=0 时 = 0,t=1 时 = 1,中间平滑曲线。比线性 lerp 更"自然",避免突变。

### Rust 视角:enum + match

```rust
#[derive(Copy, Clone, Debug, PartialEq, Eq)]
pub enum CameraMode {
    FirstPerson,
    ThirdPerson,
    Free,
    Orbit,
}

impl CameraMode {
    pub fn next(self) -> Self {
        match self {
            Self::FirstPerson => Self::ThirdPerson,
            Self::ThirdPerson => Self::Free,
            Self::Free => Self::Orbit,
            Self::Orbit => Self::FirstPerson,
        }
    }
}
```

`enum + match` 是 Rust 表达"状态"的标准方式。编译器强制每个变体都处理,不会漏。

### Rust 视角:trait object 替代

更复杂的相机模式(每个有不同字段),用 trait:

```rust
pub trait CameraBehavior {
    fn compute_target_pos(&self, ctx: &CameraContext) -> Vec3;
    fn process_input(&mut self, input: &Input);
}

pub struct FirstPersonCamera { /* ... */ }
impl CameraBehavior for FirstPersonCamera { /* ... */ }

pub struct ThirdPersonCamera { /* ... */ }
impl CameraBehavior for ThirdPersonCamera { /* ... */ }

pub struct Camera {
    behavior: Box<dyn CameraBehavior>,
}

// 切换时:
camera.behavior = Box::new(FirstPersonCamera::new());
```

`Box<dyn Trait>` 是动态分派。优点:加新模式不修改 enum。缺点:运行时多一层间接,模式切换可能涉及 heap 分配。

Casey 用 enum 简单清晰,够用。

### 3.2 · 🎨 图形学视角

相机在图形学的几个概念:

**View Matrix 的不同表达**

```rust
// 方法 1:look_at
let view = Mat4::look_at_lh(eye, target, up);

// 方法 2:from yaw / pitch / position
let view = Mat4::from_rotation_x(pitch)
         * Mat4::from_rotation_y(yaw)
         * Mat4::from_translation(-pos);

// 方法 3:from quaternion + position
let view = Mat4::from_quat(rotation) * Mat4::from_translation(-pos);
```

FPS 用 yaw/pitch 方便(Euler 角直观),TPS 用 look_at 方便(指哪打哪),Free 可以用 quaternion(避免万向锁)。

**Quaternions(四元数)**

四元数是表达 3D 旋转的数学结构,避免 Euler 角的万向锁问题。

```rust
use glam::Quat;
let rotation = Quat::from_euler(EulerRot::YXZ, yaw, pitch, 0.0);
let forward = rotation * Vec3::Z;  // 旋转 Z 方向得到 forward
```

工业游戏用四元数存相机旋转,Casey 用 Euler 简化。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:第三人称相机和第一人称相机的输入响应有何不同?为什么 FPS 不能直接用第三人称的输入逻辑?

**参考解答**:

第三人称:鼠标移动改变"相机绕玩家的角度",玩家本身的朝向可能不变(或跟随相机方向)。WASD 是相对玩家朝向。

第一人称:鼠标移动直接改变玩家的 yaw/pitch,相机贴在玩家头部,自然跟随。WASD 是相对玩家朝向(=相机朝向)。

关键区别:**鼠标的"角度"是相机自己 vs 玩家 + 相机**。在 TPS 里,鼠标改变相机绕玩家的角度,玩家可以不动(只看视角变);在 FPS 里,鼠标改变玩家朝向,玩家和相机一起转。

不能复用原因:TPS 玩家"原地不动只看相机绕"是合理的(玩家想看身后),但 FPS 玩家头部是相机,头部转 = 玩家转,玩家不可能"原地不动只转视角"(头部固定在身上)。

### Lv2 · 动手实践

**题**:实现 `enum CameraMode` + 4 种模式 + 平滑切换。完成标准:
- C 键循环切换模式
- 切换时相机位置 0.5 秒平滑过渡(smoothstep)
- 每种模式都能正确响应输入
- F2 debug overlay 显示当前模式

**参考解答**:

```rust
use glam::{Mat4, Vec3};
use glfw::Window;

#[derive(Copy, Clone, Debug, PartialEq, Eq)]
pub enum CameraMode {
    FirstPerson,
    ThirdPerson,
    Free,
    Orbit,
}

impl CameraMode {
    pub fn next(self) -> Self {
        match self {
            Self::FirstPerson => Self::ThirdPerson,
            Self::ThirdPerson => Self::Free,
            Self::Free => Self::Orbit,
            Self::Orbit => Self::FirstPerson,
        }
    }
}

pub struct Camera {
    pub mode: CameraMode,
    pub pos: Vec3,
    pub yaw: f32,
    pub pitch: f32,

    // 第三人称参数
    pub third_person_distance: f32,

    // Orbit 参数
    pub orbit_center: Vec3,
    pub orbit_radius: f32,
    pub orbit_height: f32,
    pub orbit_auto_yaw: f32,

    // 切换平滑
    pub transition_t: f32,
    pub transition_from: Vec3,
    pub transition_duration: f32,

    // 共用
    pub sensitivity: f32,
    pub follow_speed: f32,
    pub free_fly_speed: f32,
}

impl Camera {
    pub fn new() -> Self {
        Self {
            mode: CameraMode::ThirdPerson,
            pos: Vec3::new(0.0, 5.0, -10.0),
            yaw: 0.0,
            pitch: 0.3,
            third_person_distance: 8.0,
            orbit_center: Vec3::ZERO,
            orbit_radius: 15.0,
            orbit_height: 5.0,
            orbit_auto_yaw: 0.0,
            transition_t: 1.0,    // 1.0 表示过渡完成
            transition_from: Vec3::ZERO,
            transition_duration: 0.5,
            sensitivity: 0.003,
            follow_speed: 10.0,
            free_fly_speed: 5.0,
        }
    }

    pub fn switch_mode(&mut self) {
        self.mode = self.mode.next();
        self.transition_t = 0.0;
        self.transition_from = self.pos;
        println!("Camera mode: {:?}", self.mode);
    }

    pub fn process_mouse(&mut self, dx: f64, dy: f64) {
        match self.mode {
            CameraMode::Orbit => {} // Orbit 不响应鼠标
            _ => {
                self.yaw += dx as f32 * self.sensitivity;
                self.pitch -= dy as f32 * self.sensitivity;
                let max_pitch = std::f32::consts::FRAC_PI_2 - 0.1;
                self.pitch = self.pitch.clamp(-max_pitch, max_pitch);
            }
        }
    }

    pub fn process_keyboard(&mut self, window: &Window, dt: f32) {
        if self.mode != CameraMode::Free { return; }

        let forward = self.forward();
        let right = self.right();
        let mut move_dir = Vec3::ZERO;

        if window.get_key(glfw::Key::W) == glfw::Action::Press {
            move_dir += forward;
        }
        if window.get_key(glfw::Key::S) == glfw::Action::Press {
            move_dir -= forward;
        }
        if window.get_key(glfw::Key::A) == glfw::Action::Press {
            move_dir -= right;
        }
        if window.get_key(glfw::Key::D) == glfw::Action::Press {
            move_dir += right;
        }
        if window.get_key(glfw::Key::Space) == glfw::Action::Press {
            move_dir += Vec3::Y;
        }
        if window.get_key(glfw::Key::LeftShift) == glfw::Action::Press {
            move_dir -= Vec3::Y;
        }

        if move_dir.length_squared() > 0.0 {
            self.pos += move_dir.normalize() * self.free_fly_speed * dt;
        }
    }

    pub fn update(&mut self, dt: f32, player_pos: Vec3) {
        // 计算理想位置
        let target_pos = match self.mode {
            CameraMode::FirstPerson => {
                player_pos + Vec3::new(0.0, 1.7, 0.0)
            }
            CameraMode::ThirdPerson => {
                let offset = Vec3::new(
                    self.third_person_distance * self.pitch.cos() * self.yaw.sin(),
                    self.third_person_distance * self.pitch.sin(),
                    self.third_person_distance * self.pitch.cos() * self.yaw.cos(),
                );
                player_pos + offset
            }
            CameraMode::Free => {
                self.pos   // Free 模式由键盘控制 pos,不依赖 player
            }
            CameraMode::Orbit => {
                self.orbit_auto_yaw += dt * 0.5;  // 自动旋转
                Vec3::new(
                    self.orbit_center.x + self.orbit_radius * self.orbit_auto_yaw.sin(),
                    self.orbit_center.y + self.orbit_height,
                    self.orbit_center.z + self.orbit_radius * self.orbit_auto_yaw.cos(),
                )
            }
        };

        // 切换平滑
        self.transition_t = (self.transition_t + dt / self.transition_duration).min(1.0);
        let alpha = smooth_step(self.transition_t);

        if self.mode == CameraMode::Free {
            // Free 模式不 lerp,直接键盘控制
        } else {
            let blended = self.transition_from.lerp(target_pos, alpha);
            let follow_alpha = 1.0 - (-self.follow_speed * dt).exp();
            self.pos = self.pos.lerp(blended, follow_alpha);
        }
    }

    pub fn forward(&self) -> Vec3 {
        Vec3::new(
            self.pitch.cos() * self.yaw.sin(),
            self.pitch.sin(),
            self.pitch.cos() * self.yaw.cos(),
        ).normalize()
    }

    pub fn right(&self) -> Vec3 {
        self.forward().cross(Vec3::Y).normalize()
    }

    pub fn look_target(&self, player_pos: Vec3) -> Vec3 {
        match self.mode {
            CameraMode::FirstPerson => self.pos + self.forward(),
            CameraMode::ThirdPerson => player_pos + Vec3::new(0.0, 1.5, 0.0),
            CameraMode::Free => self.pos + self.forward(),
            CameraMode::Orbit => self.orbit_center,
        }
    }

    pub fn view_matrix(&self, player_pos: Vec3) -> Mat4 {
        Mat4::look_at_lh(self.pos, self.look_target(player_pos), Vec3::Y)
    }
}

fn smooth_step(t: f32) -> f32 {
    t * t * (3.0 - 2.0 * t)
}

fn main() {
    let mut camera = Camera::new();
    let player_pos = Vec3::ZERO;

    // 模拟更新
    let dt = 1.0 / 60.0;
    camera.update(dt, player_pos);
    println!("Camera mode: {:?}, pos: {:?}", camera.mode, camera.pos);
}
```

**关键解释**:
- `next(self)` — Rust 枚举方法,返回下一个变体(循环)
- `match self.mode { ... }` — Rust 模式匹配,每个变体独立分支
- `transition_t = 1.0` 初始化为"完成"状态,避免开局有过渡
- `smooth_step(t)` 是 smooth Hermite 插值,比线性 lerp 更自然
- Free 模式特例:键盘直接改 pos,不走 lerp 路径

### Lv3 · 迁移设计

**题**:加一个**Cinematic 模式**——相机按脚本路径移动(几个关键点之间插值)。提示:用 `Vec<Vec3>` 存关键点,在它们之间 Catmull-Rom 样条插值。完成标准:相机沿样条平滑移动,循环回到第一个点。

**提示**:
- Catmull-Rom:在 4 个点 p0 p1 p2 p3 之间插值,结果过 p1 p2
- 公式:`p = 0.5 * ((2*p1) + (-p0 + p2) * t + (2*p0 - 5*p1 + 4*p2 - p3) * t² + (-p0 + 3*p1 - 3*p2 + p3) * t³)`
- 累加 t,超过 1 切到下一段

```rust
// Cargo.toml: gl = "0.14", glfw = "0.55", glam = "0.29"

use glam::{Mat4, Vec3};
use glfw::{Action, Context, FailOnError, Glfw, Key, Window, WindowEvent};
use std::sync::mpsc::Receiver;

#[derive(Copy, Clone, Debug, PartialEq, Eq)]
pub enum CameraMode {
    FirstPerson,
    ThirdPerson,
    Free,
    Orbit,
}

impl CameraMode {
    pub fn next(self) -> Self {
        match self {
            Self::FirstPerson => Self::ThirdPerson,
            Self::ThirdPerson => Self::Free,
            Self::Free => Self::Orbit,
            Self::Orbit => Self::FirstPerson,
        }
    }

    pub fn label(self) -> &'static str {
        match self {
            Self::FirstPerson => "First Person",
            Self::ThirdPerson => "Third Person",
            Self::Free => "Free Fly",
            Self::Orbit => "Orbit",
        }
    }
}

pub struct Camera {
    pub mode: CameraMode,
    pub pos: Vec3,
    pub yaw: f32,
    pub pitch: f32,
    pub third_person_distance: f32,
    pub orbit_center: Vec3,
    pub orbit_radius: f32,
    pub orbit_height: f32,
    pub orbit_auto_yaw: f32,
    pub transition_t: f32,
    pub transition_from: Vec3,
    pub sensitivity: f32,
    pub follow_speed: f32,
    pub free_fly_speed: f32,
}

impl Camera {
    pub fn new() -> Self {
        Self {
            mode: CameraMode::ThirdPerson,
            pos: Vec3::new(0.0, 5.0, -10.0),
            yaw: 0.0,
            pitch: 0.3,
            third_person_distance: 8.0,
            orbit_center: Vec3::ZERO,
            orbit_radius: 15.0,
            orbit_height: 5.0,
            orbit_auto_yaw: 0.0,
            transition_t: 1.0,
            transition_from: Vec3::ZERO,
            sensitivity: 0.003,
            follow_speed: 10.0,
            free_fly_speed: 5.0,
        }
    }

    pub fn switch_mode(&mut self) {
        self.mode = self.mode.next();
        self.transition_t = 0.0;
        self.transition_from = self.pos;
        println!("Switched to: {}", self.mode.label());
    }

    pub fn process_mouse(&mut self, dx: f64, dy: f64) {
        if self.mode == CameraMode::Orbit { return; }
        self.yaw += dx as f32 * self.sensitivity;
        self.pitch -= dy as f32 * self.sensitivity;
        let max_pitch = std::f32::consts::FRAC_PI_2 - 0.1;
        self.pitch = self.pitch.clamp(-max_pitch, max_pitch);
    }

    pub fn process_keyboard(&mut self, window: &Window, dt: f32) {
        if self.mode != CameraMode::Free { return; }
        let forward = self.forward();
        let right = self.right();
        let mut move_dir = Vec3::ZERO;

        if window.get_key(Key::W) == Action::Press { move_dir += forward; }
        if window.get_key(Key::S) == Action::Press { move_dir -= forward; }
        if window.get_key(Key::A) == Action::Press { move_dir -= right; }
        if window.get_key(Key::D) == Action::Press { move_dir += right; }
        if window.get_key(Key::Space) == Action::Press { move_dir += Vec3::Y; }
        if window.get_key(Key::LeftShift) == Action::Press { move_dir -= Vec3::Y; }

        if move_dir.length_squared() > 0.0 {
            self.pos += move_dir.normalize() * self.free_fly_speed * dt;
        }
    }

    pub fn update(&mut self, dt: f32, player_pos: Vec3) {
        let target_pos = match self.mode {
            CameraMode::FirstPerson => player_pos + Vec3::new(0.0, 1.7, 0.0),
            CameraMode::ThirdPerson => {
                let offset = Vec3::new(
                    self.third_person_distance * self.pitch.cos() * self.yaw.sin(),
                    self.third_person_distance * self.pitch.sin(),
                    self.third_person_distance * self.pitch.cos() * self.yaw.cos(),
                );
                player_pos + offset
            }
            CameraMode::Free => self.pos,
            CameraMode::Orbit => {
                self.orbit_auto_yaw += dt * 0.5;
                Vec3::new(
                    self.orbit_center.x + self.orbit_radius * self.orbit_auto_yaw.sin(),
                    self.orbit_center.y + self.orbit_height,
                    self.orbit_center.z + self.orbit_radius * self.orbit_auto_yaw.cos(),
                )
            }
        };

        self.transition_t = (self.transition_t + dt / 0.5).min(1.0);

        if self.mode != CameraMode::Free {
            let alpha = smooth_step(self.transition_t);
            let blended = self.transition_from.lerp(target_pos, alpha);
            let follow_alpha = 1.0 - (-self.follow_speed * dt).exp();
            self.pos = self.pos.lerp(blended, follow_alpha);
        }
    }

    pub fn forward(&self) -> Vec3 {
        Vec3::new(
            self.pitch.cos() * self.yaw.sin(),
            self.pitch.sin(),
            self.pitch.cos() * self.yaw.cos(),
        ).normalize()
    }

    pub fn right(&self) -> Vec3 {
        self.forward().cross(Vec3::Y).normalize()
    }

    pub fn look_target(&self, player_pos: Vec3) -> Vec3 {
        match self.mode {
            CameraMode::FirstPerson | CameraMode::Free => self.pos + self.forward(),
            CameraMode::ThirdPerson => player_pos + Vec3::new(0.0, 1.5, 0.0),
            CameraMode::Orbit => self.orbit_center,
        }
    }

    pub fn view_matrix(&self, player_pos: Vec3) -> Mat4 {
        Mat4::look_at_lh(self.pos, self.look_target(player_pos), Vec3::Y)
    }
}

fn smooth_step(t: f32) -> f32 {
    t * t * (3.0 - 2.0 * t)
}

fn main() {
    let mut glfw = glfw::init(FailOnError).unwrap();
    // (window hints)

    let (mut window, events) = glfw.create_window(1920, 1080, "Multi Camera", glfw::WindowMode::Windowed).unwrap();
    window.make_current();
    window.set_cursor_pos_polling(true);
    window.set_cursor_mode(glfw::CursorMode::Disabled);
    window.set_key_polling(true);
    gl::load_with(|s| window.get_proc_address(s) as *const _);

    let mut camera = Camera::new();
    let player_pos = Vec3::ZERO;
    let mut last_time = std::time::Instant::now();

    while !window.should_close() {
        let now = std::time::Instant::now();
        let dt = (now - last_time).as_secs_f32();
        last_time = now;

        glfw.poll_events();
        for (_, event) in events.try_iter() {
            match event {
                WindowEvent::CursorPos(x, y) => camera.process_mouse(x, y),
                WindowEvent::Key(Key::Escape, _, Action::Press, _) => window.set_should_close(true),
                WindowEvent::Key(Key::C, _, Action::Press, _) => camera.switch_mode(),
                _ => {}
            }
        }

        camera.process_keyboard(&window, dt);
        camera.update(dt, player_pos);

        let view = camera.view_matrix(player_pos);
        let proj = Mat4::perspective_lh(std::f32::consts::FRAC_PI_4, 1920.0/1080.0, 0.1, 100.0);
        let view_proj = proj * view;

        unsafe {
            gl::ClearColor(0.1, 0.1, 0.15, 1.0);
            gl::Clear(gl::COLOR_BUFFER_BIT | gl::DEPTH_BUFFER_BIT);
            // (rendering)
        }

        window.swap_buffers();
    }
}
```

**Troubleshooting**:

- **模式切换跳跃** — `transition_t` 初始化为 1.0(完成),避免开局过渡
- **Free 模式相机漂** — `update` 里 Free 模式跳过 lerp,直接用 pos
- **Orbit 模式方向错** — 自动 yaw 增量方向(`+dt` vs `-dt`)决定旋转方向
- **pitch 反向** — 鼠标 dy > 0 通常表示向下移动,期望 pitch 减小(看下方),`self.pitch -= dy * sens`
- **right 方向错** — forward × Y 在右手系和左手系不同,验证
