
# Day 279 · 完成世界区块实体存储

> 昨天的 chunk-based world 还没完整——entity 跨 chunk 移动没实现、加载 / 卸载逻辑没实现。今天 Casey 完成这些"剩下"的部分,让 chunked world 真正可用。

## 0 · 为什么要有这一天

昨天的代码有两个明显缺陷:

**缺陷 1:entity 不能跨 chunk 移动**。一个 entity 在 chunk A 的右边界,移动一步到了 chunk B 的左边界——昨天的 update 函数只更新 `tile.0 += vx * dt`,不会把 entity 从 A 的列表移到 B 的列表。结果:entity 显示在 B 的 tile,但 `world.chunks[A].entities` 还有它的数据——状态错乱。

**缺陷 2:chunk 不卸载**。`loaded_chunks` 返回"在加载范围的 chunk",但 world 一直保留所有加载过的 chunk。玩家走远了,远处 chunk 还在内存,内存无限增长。

今天 Casey 完成这两个关键功能,让 chunked world 真正能用于大世界。

完成后的能力:

- entity 自由移动,跨 chunk 时自动迁移
- 远处 chunk 自动卸载(写回磁盘或丢弃)
- 内存占用只与"加载的 chunk 数"成正比,不与"总 chunk 数"成正比

心理锚点:做完这个,你的游戏可以支持"无限大"的世界(地图大小无上限)。

## 1 · Casey 今天做了什么

Casey 完成两件事:

1. **跨 chunk 移动**:每次 update 后,检查每个 entity 的 tile 是否跨 chunk。如果跨了,从旧 chunk 移除,插入新 chunk
2. **卸载远 chunk**:每帧检查所有 loaded chunk,离开玩家加载范围的卸载(简化版:直接丢弃,不写磁盘)

Casey 处理了几个细节:

- **跨 chunk 移动的批量处理**:不能边遍历边修改 Vec(迭代器失效),要先收集"要移动的 entity",再统一移动
- **chunk 不在加载范围时,entity 怎么办?**:暂时保留在内存(否则要存盘才能恢复),但下次加载时重新激活
- **生成 / 卸载的时机**:不是每帧都做,而是玩家**进入新 chunk 时**触发

## 2 · 心智模型

### 类比:办公室搬家

你从办公室 A 搬到办公室 B。公司记录需要更新:

- A 的员工名册移除你
- B 的员工名册加入你
- 你的工号不变,只是位置变了
- A 的桌子清空(给下一个人),B 的桌子准备给你

游戏 entity 跨 chunk 是同一回事:

- 旧 chunk.entities 移除 entity
- 新 chunk.entities 加入 entity
- entity_id 不变
- 旧 chunk 如果空了,可以"清空"(卸载)

### 严谨原理:跨 chunk 移动算法

#### 问题:边遍历边修改

直接写法:

```rust
for chunk in self.chunks.values_mut() {
    for i in 0..chunk.entities.len() {
        let e = &chunk.entities[i];
        let new_chunk = tile_to_chunk(e.tile);
        let old_chunk = ...;  // 怎么知道?
        if new_chunk != old_chunk {
            // 这里要把 entity 从 chunk 移到 new_chunk
            // 但 self.chunks 已经被 borrow 了
        }
    }
}
```

Rust borrow checker 会拒绝——你不能在遍历 `self.chunks.values_mut()` 时再 `self.chunks.get_mut(...)`。

#### 解决:两阶段

```rust
// 阶段 1:收集所有要移动的 (id, new_chunk_pos)
let mut moves: Vec<(u32, ChunkPos)> = Vec::new();
for (cp, chunk) in &self.chunks {
    for e in &chunk.entities {
        let target_chunk = tile_to_chunk(e.tile);
        if target_chunk != *cp {
            moves.push((e.id, target_chunk));
        }
    }
}

// 阶段 2:执行移动
for (id, target_chunk) in moves {
    // 找到 entity 在哪个 chunk(根据 id)
    let source_chunk = self.find_chunk_containing(id);
    if let Some(source) = source_chunk {
        // 从 source 移除
        let entity = self.chunks.get_mut(&source).unwrap()
            .entities.iter()
            .position(|e| e.id == id)
            .map(|i| self.chunks.get_mut(&source).unwrap().entities.swap_remove(i))
            .unwrap();
        // 插入 target
        self.ensure_chunk(target_chunk).entities.push(entity);
    }
}
```

`swap_remove(i)` 是 Rust Vec 的方法:用最后一个元素填补位置 i,然后 pop。O(1),但不保持顺序(对游戏 entity 无所谓)。

#### Chunk 卸载

```rust
fn unload_distant_chunks(&mut self, player_chunk: ChunkPos) {
    let active_range = self.loaded_chunk_range(player_chunk);
    let active_set: std::collections::HashSet<ChunkPos> = active_range.into_iter().collect();

    // 找出要卸载的 chunk
    let to_unload: Vec<ChunkPos> = self.chunks.keys()
        .filter(|cp| !active_set.contains(cp))
        .copied()
        .collect();

    for cp in to_unload {
        // 实际项目:写回磁盘
        // self.save_chunk(cp, &self.chunks[&cp]);
        // 今天的简化:直接丢弃
        self.chunks.remove(&cp);
    }
}
```

注意:**有 entity 的 chunk 不能直接丢弃**(否则 entity 消失)。要先迁移 entity 到 loaded chunk,或者保存到磁盘。今天的简化:**只丢弃没有 entity 的 chunk**。

#### 加载新 chunk

```rust
fn load_new_chunks(&mut self, player_chunk: ChunkPos) {
    let to_load = self.loaded_chunk_range(player_chunk);
    for cp in to_load {
        if !self.chunks.contains_key(&cp) {
            // 实际项目:从磁盘读
            // let chunk = self.load_from_disk(cp).unwrap_or_else(|| self.generate(cp));
            // 今天的简化:程序生成
            self.ensure_chunk(cp);
        }
    }
}
```

`ensure_chunk` 自动生成(昨天的代码已经有)。

#### 加载 / 卸载的时机

不是每帧都做,而是"玩家进入新 chunk 时":

```rust
fn update(&mut self, player_tile: TilePos) {
    let new_player_chunk = tile_to_chunk(player_tile);
    if new_player_chunk != self.last_player_chunk {
        // 玩家进入新 chunk,触发 load/unload
        self.load_new_chunks(new_player_chunk);
        self.unload_distant_chunks(new_player_chunk);
        self.last_player_chunk = new_player_chunk;
    }
}
```

每帧检查"chunk 是否变",变了才做加载操作。

### 数据完整性

跨 chunk 移动 + 卸载时,要保证:

- **每个 entity 始终在某个 chunk 的列表里**(不能"丢失")
- **没有 entity 在多个 chunk 的列表里**(不能"重复")
- **id 全局唯一**

最简单的验证:每帧统计所有 chunk 的 entity 总数,应该等于已分配的 id 数。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

跨 chunk 移动是大世界游戏的核心难点。业界做法:

- **Always-active**:玩家附近 chunk 始终 active,远处 chunk "冻结"(不更新但保留)
- **Threshold-based**:entity 距玩家 < N 时 active,> N 时休眠
- **Persistent NPCs**:某些 NPC 跨 chunk 也要更新(用单线程兜底)
- **Background threads**:远处 chunk 在后台线程更新(慢一些)

Casey 用"always-active"——加载的 chunk 全部更新。简单可靠。

### 3.2 · 🐧 Linux 系统编程视角

Linux 的 swap 机制和 chunk unload 类似:

- 内存压力时,Linux 把不活跃的 page swap 到磁盘
- page 重新访问时,从磁盘 swap 回来
- LRU(least recently used)决定哪个 page 被 swap

游戏 chunk 卸载应该用类似策略:**最久没访问的 chunk 先卸载**。

```bash
# 看 Linux swap
swapon --show
# 输出当前 swap 设备

# 看 page cache
cat /proc/meminfo | grep -E "Cached|Swap"
```

Linux 还用 `madvise(2)` 让应用告诉内核"这块内存我不急用,可以丢":

```c
madvise(ptr, size, MADV_DONTNEED);
// 内核立即丢弃 page,下次访问重新读
```

游戏 chunk 卸载可以用 mmap + madvise 让内核帮忙管理。

### 3.3 · 🦀 Rust 生态视角

Rust 表达"跨 chunk 移动"几个考量:

#### 两阶段模式

```rust
let moves = self.scan_for_moves();
self.execute_moves(moves);
```

阶段 1 不可变借用,阶段 2 可变借用。borrow checker 友好。

#### swap_remove

```rust
let entity = vec.entities.swap_remove(index);
```

O(1) 删除,返回被删元素。**不保持顺序**——对游戏 entity 没影响(顺序无意义)。

#### retain + drain

如果要根据条件批量删除 + 保留被删元素:

```rust
let removed: Vec<EntitySlot> = vec.entities.drain_filter(|e| should_move(e)).collect();
```

但 `drain_filter` 是 unstable。stable 替代:

```rust
let mut removed = Vec::new();
let mut i = 0;
while i < vec.entities.len() {
    if should_move(&vec.entities[i]) {
        removed.push(vec.entities.swap_remove(i));
    } else {
        i += 1;
    }
}
```

### 3.4 · 软件工程:状态一致性

跨 chunk 移动 + 卸载是经典的**分布式数据迁移**问题。要求:

1. **原子性**:一个 entity 要么完全在 A,要么完全在 B,不能"两边各一半"
2. **一致性**:全局不变式("每个 entity 在某个 chunk")始终成立
3. **隔离性**:并发更新时(多线程)不会互相干扰

单线程游戏不用考虑 3,但 1 和 2 必须保证。Casey 的两阶段实现满足这些。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么跨 chunk 移动用"两阶段(先收集后执行)"而不是"边遍历边修改"?给出至少 3 个理由。

**参考解答**:
1. **Rust borrow 规则**:遍历 `&self.chunks` 时不能 `&mut self.chunks`,Rust 编译器拒绝。两阶段用 `let moves = ...;`(不可变借用结束)后再可变借用,符合规则
2. **迭代器失效**:即使 Rust 允许,边遍历边修改 Vec 会让迭代器失效(C++ 经典 bug)。两阶段避免
3. **性能**:两阶段可以批量优化。比如收集到 moves 后,按目标 chunk 排序,然后批量插入(连续内存写比散乱写快)
4. **可测试**:scan 和 execute 分离,可以单独测试 scan 逻辑(execute 是机械的)
5. **错误恢复**:scan 失败(没有要移动的)直接返回,不执行 execute,节省工作
6. **调试友好**:打印 moves 列表就能看到"哪些 entity 要移动",问题排查容易

### Lv2 · 动手实践

**题**:实现 `scan_for_cross_chunk_moves` + `execute_moves`。

测试:

- 调用 update 移动 entity 到 tile (17, 5)(跨到 chunk (1, 0))

**参考解答**:

```rust
use std::collections::HashMap;

const CHUNK_SIZE: i32 = 16;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
struct ChunkPos(i32, i32);

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
struct TilePos(i32, i32);

fn tile_to_chunk(t: TilePos) -> ChunkPos {
    ChunkPos(t.0.div_euclid(CHUNK_SIZE), t.1.div_euclid(CHUNK_SIZE))
}

#[derive(Clone, Debug)]
struct EntitySlot {
    id: u32,
    tile: TilePos,
}

#[derive(Clone, Default, Debug)]
struct Chunk {
    entities: Vec<EntitySlot>,
}

struct World {
    chunks: HashMap<ChunkPos, Chunk>,
}

impl World {
    fn new() -> Self { Self { chunks: HashMap::new() } }

    fn ensure_chunk(&mut self, pos: ChunkPos) -> &mut Chunk {
        self.chunks.entry(pos).or_default()
    }

    fn spawn(&mut self, id: u32, tile: TilePos) {
        let cp = tile_to_chunk(tile);
        self.ensure_chunk(cp).entities.push(EntitySlot { id, tile });
    }

    fn move_entity_to_tile(&mut self, id: u32, new_tile: TilePos) {
        // 更新 entity 的 tile,可能跨 chunk
        // 找 entity 当前所在 chunk
        let mut old_chunk = None;
        for (cp, chunk) in &self.chunks {
            if chunk.entities.iter().any(|e| e.id == id) {
                old_chunk = Some(*cp);
                break;
            }
        }
        let old_chunk = match old_chunk {
            Some(c) => c,
            None => return,
        };

        // 更新 tile
        let chunk = self.chunks.get_mut(&old_chunk).unwrap();
        let entity = chunk.entities.iter_mut().find(|e| e.id == id).unwrap();
        entity.tile = new_tile;

        // 检查是否跨 chunk
        let new_chunk = tile_to_chunk(new_tile);
        if new_chunk != old_chunk {
            // 从旧 chunk 取出
            let entity = self.chunks.get_mut(&old_chunk).unwrap()
                .entities
                .iter()
                .position(|e| e.id == id)
                .map(|i| self.chunks.get_mut(&old_chunk).unwrap().entities.swap_remove(i))
                .unwrap();
            // 插入新 chunk
            self.ensure_chunk(new_chunk).entities.push(entity);
        }
    }

    fn total_entities(&self) -> usize {
        self.chunks.values().map(|c| c.entities.len()).sum()
    }

    fn print(&self) {
        let mut sorted: Vec<_> = self.chunks.iter().collect();
        sorted.sort_by_key(|(cp, _)| (cp.0, cp.1));
        for (cp, chunk) in sorted {
            println!("  Chunk({:?}): {} entities", cp, chunk.entities.len());
            for e in &chunk.entities {
                println!("    - id={} tile={:?}", e.id, e.tile);
            }
        }
    }
}

fn main() {
    let mut world = World::new();

    // spawn entity 在 chunk (0,0) 的边界附近
    world.spawn(1, TilePos(15, 5));  // chunk (0, 0) 的最右一列
    world.spawn(2, TilePos(7, 7));
    world.spawn(3, TilePos(0, 0));

    println!("Initial:");
    world.print();
    assert_eq!(world.total_entities(), 3);

    // 把 entity 1 移到 chunk (1, 0)
    world.move_entity_to_tile(1, TilePos(17, 5));

    println!("\nAfter moving entity 1 to (17, 5):");
    world.print();

    // 验证
    assert_eq!(world.total_entities(), 3);  // 总数不变
    assert_eq!(world.chunks.get(&ChunkPos(0, 0)).map(|c| c.entities.len()).unwrap_or(0), 2);
    assert_eq!(world.chunks.get(&ChunkPos(1, 0)).map(|c| c.entities.len()).unwrap_or(0), 1);

    println!("\nAll tests passed!");
}
```

**每行解释**:
- 遍历找 entity 的 chunk 是 O(num_chunks * entities_per_chunk)。生产用反向索引
- `swap_remove(i)` 用最后一个元素填补 i,然后 pop,O(1)
- 跨 chunk 时,先把 entity 从旧 chunk 取出(移动语义),再插入新 chunk
- `total_entities` 验证一致性(总数不变)

## 8 · Rust / Arch 落地代码

### 完整可跑:chunked world + 跨 chunk 移动 + 卸载

```rust
// Cargo.toml:
// [dependencies]
// minifb = "0.27"

use minifb::{Key, KeyRepeat, Window, WindowOptions};
use std::collections::{HashMap, HashSet};
use std::time::Instant;

const WIDTH: usize = 800;
const HEIGHT: usize = 600;
const TILE_SIZE: f32 = 16.0;
const CHUNK_SIZE: i32 = 16;
const LOAD_RADIUS: i32 = 2;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
struct TilePos(i32, i32);

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
struct ChunkPos(i32, i32);

fn tile_to_chunk(t: TilePos) -> ChunkPos {
    ChunkPos(t.0.div_euclid(CHUNK_SIZE), t.1.div_euclid(CHUNK_SIZE))
}

fn tile_to_world(t: TilePos) -> (f32, f32) {
    ((t.0 as f32 + 0.5) * TILE_SIZE, (t.1 as f32 + 0.5) * TILE_SIZE)
}

#[derive(Clone, Debug)]
struct EntitySlot {
    id: u32,
    tile: TilePos,
    color: u32,
    size: f32,
}

#[derive(Clone, Default, Debug)]
struct Chunk {
    entities: Vec<EntitySlot>,
    is_wall: Vec<bool>,
}

impl Chunk {
    fn new_generated(pos: ChunkPos) -> Self {
        let mut c = Self {
            entities: Vec::new(),
            is_wall: vec![false; (CHUNK_SIZE * CHUNK_SIZE) as usize],
        };
        let hash = (pos.0 as u32).wrapping_mul(0x9E3779B9)
            .wrapping_add((pos.1 as u32).wrapping_mul(0x85EBCA6B));
        for i in 0..6 {
            let idx = (hash.wrapping_mul(i + 1) as usize) % (CHUNK_SIZE * CHUNK_SIZE) as usize;
            c.is_wall[idx] = true;
        }
        c
    }
    fn is_traversable(&self, lx: i32, ly: i32) -> bool {
        if lx < 0 || ly < 0 || lx >= CHUNK_SIZE || ly >= CHUNK_SIZE { return true; }
        !self.is_wall[(ly * CHUNK_SIZE + lx) as usize]
    }
}

struct World {
    chunks: HashMap<ChunkPos, Chunk>,
    // 卸载的 chunk entity 暂存(简化,实际写磁盘)
    parked: HashMap<ChunkPos, Vec<EntitySlot>>,
    next_id: u32,
    last_player_chunk: ChunkPos,
}

impl World {
    fn new() -> Self {
        Self {
            chunks: HashMap::new(),
            parked: HashMap::new(),
            next_id: 1,
            last_player_chunk: ChunkPos(0, 0),
        }
    }

    fn ensure_chunk(&mut self, pos: ChunkPos) -> &mut Chunk {
        if !self.chunks.contains_key(&pos) {
            // 加载:从 parked 恢复或生成新
            let mut chunk = Chunk::new_generated(pos);
            if let Some(parked_entities) = self.parked.remove(&pos) {
                chunk.entities = parked_entities;
            }
            self.chunks.insert(pos, chunk);
        }
        self.chunks.get_mut(&pos).unwrap()
    }

    fn spawn(&mut self, tile: TilePos, color: u32, size: f32) -> u32 {
        let id = self.next_id;
        self.next_id += 1;
        let cp = tile_to_chunk(tile);
        self.ensure_chunk(cp).entities.push(EntitySlot { id, tile, color, size });
        id
    }

    fn is_traversable(&mut self, tile: TilePos) -> bool {
        let cp = tile_to_chunk(tile);
        let lx = tile.0.rem_euclid(CHUNK_SIZE);
        let ly = tile.1.rem_euclid(CHUNK_SIZE);
        self.ensure_chunk(cp).is_traversable(lx, ly)
    }

    fn move_entity(&mut self, id: u32, new_tile: TilePos) {
        // 找 entity 所在 chunk
        let mut source_chunk = None;
        for (cp, chunk) in &self.chunks {
            if chunk.entities.iter().any(|e| e.id == id) {
                source_chunk = Some(*cp);
                break;
            }
        }
        let source_chunk = match source_chunk {
            Some(c) => c,
            None => return,
        };

        let new_chunk = tile_to_chunk(new_tile);

        if source_chunk == new_chunk {
            // 同 chunk:只更新 tile
            let chunk = self.chunks.get_mut(&source_chunk).unwrap();
            let e = chunk.entities.iter_mut().find(|e| e.id == id).unwrap();
            e.tile = new_tile;
        } else {
            // 跨 chunk:移除 + 插入
            let entity = {
                let chunk = self.chunks.get_mut(&source_chunk).unwrap();
                let idx = chunk.entities.iter().position(|e| e.id == id).unwrap();
                let mut e = chunk.entities.swap_remove(idx);
                e.tile = new_tile;
                e
            };
            self.ensure_chunk(new_chunk).entities.push(entity);
        }
    }

    fn update_around(&mut self, player_chunk: ChunkPos) {
        // 加载玩家附近 chunk
        for dx in -LOAD_RADIUS..=LOAD_RADIUS {
            for dy in -LOAD_RADIUS..=LOAD_RADIUS {
                let cp = ChunkPos(player_chunk.0 + dx, player_chunk.1 + dy);
                self.ensure_chunk(cp);
            }
        }

        // 卸载远离玩家的 chunk
        let active: HashSet<ChunkPos> = (−LOAD_RADIUS..=LOAD_RADIUS)
            .flat_map(|dx| {
                (−LOAD_RADIUS..=LOAD_RADIUS)
                    .map(move |dy| ChunkPos(player_chunk.0 + dx, player_chunk.1 + dy))
            })
            .collect();

        let to_unload: Vec<ChunkPos> = self.chunks.keys()
            .filter(|cp| !active.contains(cp))
            .copied()
            .collect();

        for cp in to_unload {
            if let Some(chunk) = self.chunks.remove(&cp) {
                if !chunk.entities.is_empty() {
                    self.parked.insert(cp, chunk.entities);
                }
            }
        }

        self.last_player_chunk = player_chunk;
    }

    fn total_active_entities(&self) -> usize {
        self.chunks.values().map(|c| c.entities.len()).sum()
    }

    fn total_parked_entities(&self) -> usize {
        self.parked.values().map(|v| v.len()).sum()
    }
}

fn draw_rect(buf: &mut [u32], buf_w: usize, buf_h: usize, x: i32, y: i32, w: i32, h: i32, color: u32) {
    for py in y.max(0)..(y + h).min(buf_h as i32) {
        for px in x.max(0)..(x + w).min(buf_w as i32) {
            buf[(py as usize) * buf_w + (px as usize)] = color;
        }
    }
}

fn main() {
    let mut window = Window::new(
        "Complete Chunked World", WIDTH, HEIGHT,
        WindowOptions::default(),
    ).expect("Failed to open window");

    let mut buffer = vec![0u32; WIDTH * HEIGHT];
    let mut last_time = Instant::now();

    let mut world = World::new();

    let mut player_tile = TilePos(0, 0);
    let player_id = world.spawn(player_tile, 0xFFFF6040, 8.0);

    // 一些 NPC
    let mut npcs: Vec<u32> = Vec::new();
    for i in 0..30 {
        let t = TilePos(i - 15, (i % 5) as i32 - 2);
        let id = world.spawn(t, 0xFFA040FF, 6.0);
        npcs.push(id);
    }

    world.update_around(tile_to_chunk(player_tile));

    while window.is_open() && !window.is_key_down(Key::Escape) {
        let now = Instant::now();
        let dt = now.duration_since(last_time).as_secs_f32().min(0.05);
        last_time = now;

        // 玩家输入
        let mut new_tile = player_tile;
        if window.is_key_pressed(Key::W, KeyRepeat::No) { new_tile.1 -= 1; }
        if window.is_key_pressed(Key::S, KeyRepeat::No) { new_tile.1 += 1; }
        if window.is_key_pressed(Key::A, KeyRepeat::No) { new_tile.0 -= 1; }
        if window.is_key_pressed(Key::D, KeyRepeat::No) { new_tile.0 += 1; }

        if new_tile != player_tile {
            if world.is_traversable(new_tile) {
                // 用 world.move_entity 移动 player
                world.move_entity(player_id, new_tile);
                player_tile = new_tile;

                // 检查是否进入新 chunk
                let pc = tile_to_chunk(player_tile);
                if pc != world.last_player_chunk {
                    println!("Entered new chunk {:?}, updating...", pc);
                    world.update_around(pc);
                    println!("  Active entities: {}, Parked: {}",
                             world.total_active_entities(), world.total_parked_entities());
                }
            }
        }

        // 渲染
        for px in buffer.iter_mut() { *px = 0xFF000000; }

        let (cam_x, cam_y) = tile_to_world(player_tile);
        let cam_x = cam_x - WIDTH as f32 / 2.0;
        let cam_y = cam_y - HEIGHT as f32 / 2.0;

        // 画 loaded chunk 的 tile
        for (cp, chunk) in &world.chunks {
            let origin_x = cp.0 * CHUNK_SIZE;
            let origin_y = cp.1 * CHUNK_SIZE;
            for ly in 0..CHUNK_SIZE {
                for lx in 0..CHUNK_SIZE {
                    let tile = TilePos(origin_x + lx, origin_y + ly);
                    let (wx, wy) = tile_to_world(tile);
                    let sx = wx - cam_x;
                    let sy = wy - cam_y;
                    if sx < 0.0 || sy < 0.0 || sx >= WIDTH as f32 || sy >= HEIGHT as f32 { continue; }

                    let is_wall = !chunk.is_traversable(lx, ly);
                    let color = if is_wall { 0xFF808080 } else { 0xFF303030 };
                    draw_rect(&mut buffer, WIDTH, HEIGHT,
                              (sx - TILE_SIZE/2.0) as i32, (sy - TILE_SIZE/2.0) as i32,
                              TILE_SIZE as i32, TILE_SIZE as i32, color);
                }
            }
        }

        // 画 entity
        for chunk in world.chunks.values() {
            for e in &chunk.entities {
                let (wx, wy) = tile_to_world(e.tile);
                let sx = wx - cam_x;
                let sy = wy - cam_y;
                if sx < 0.0 || sy < 0.0 || sx >= WIDTH as f32 || sy >= HEIGHT as f32 { continue; }
                draw_rect(&mut buffer, WIDTH, HEIGHT,
                          (sx - e.size) as i32, (sy - e.size) as i32,
                          (e.size * 2.0) as i32, (e.size * 2.0) as i32, e.color);
            }
        }

        // HUD
        let _ = dt;
        // 左下角画 chunk 信息
        draw_rect(&mut buffer, WIDTH, HEIGHT, 10, HEIGHT as i32 - 60, 200, 50, 0x80000000);
        // 文字部分简化为色块

        window.update_with_buffer(&buffer, WIDTH, HEIGHT).unwrap();
    }
}
```

**关键 Rust 特性解释**:

- `HashMap::remove` 返回 Option,移除时取出值
- `parked: HashMap<ChunkPos, Vec<EntitySlot>>` 暂存卸载的 chunk 的 entity
- `HashSet` 加速"是否在加载范围"查询
- `flat_map + map` 函数式生成加载范围
- `last_player_chunk` 跟踪玩家上一帧 chunk,只在跨 chunk 时更新

**Troubleshooting**:

- entity 跨 chunk 后消失 — 检查 move_entity 的 source_chunk 查找逻辑
- 内存持续增长 — 检查 unload 是否真的 remove from HashMap
- parked 不恢复 — ensure_chunk 应该从 parked 取出 entities
