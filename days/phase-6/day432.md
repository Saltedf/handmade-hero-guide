## 2 · 心智模型

### 类比:工厂流水线

想象家具工厂。原材料 → 切割 → 打磨 → 上漆 → 装配 → 包装。每个环节都是流水线的一部分。

如果切割环节用高速机器(快),但打磨还是手工(慢),整条流水线慢——瓶颈在打磨。

SIMD 优化完全同构。`ray4_vs_aabb` 是切割环节(快),但 BVH 遍历、采样、结果解码如果还是标量,整条流水线被慢环节拖累。

**系统集成**要求所有环节一致 SIMD,流水线才能整体快。

### 严谨原理:端到端 SIMD

完整流程的 SIMD 数据:

```rust
// 4 个样本打包
let samples_4: [(f32, f32); 4] = [
    halton(i, 2, 3), halton(i+1, 2, 3),
    halton(i+2, 2, 3), halton(i+3, 2, 3),
];

// 4 条光线打包(SoA)
let rays_4 = Ray4 {
    origin_x: _mm_set_ps(...),
    origin_y: _mm_set_ps(...),
    origin_z: _mm_set_ps(...),
    dir_x: _mm_set_ps(...),
    dir_y: _mm_set_ps(...),
    dir_z: _mm_set_ps(...),
};

// BVH 遍历 4-wide
let mut hits = [Vec::new(); 4];  // 4 条光线的命中列表
traverse_ray4(&rays_4, &bvh_root, &mut hits);

// 解码 + 光照累加
let mut lighting_4 = Vec3::ZERO;  // 累加 4 条光线的光照
for ray_idx in 0..4 {
    for obj_idx in &hits[ray_idx] {
        let contribution = compute_lighting_from_obj(obj_idx, &rays[ray_idx]);
        // 这里标量,因为是 per-ray 解码
        // SIMD 化需要把 contribution 也打包,但 gain 不大
    }
}
```

最后一步的"per-ray 解码"是必要的——BVH 遍历是 SIMD,但每条光线的最终光照依赖**命中的具体物体**,这些物体可能不同。完全 SIMD 化需要"shader bundle"——把 4 条光线的命中物体也对齐,工业 ray tracer 用。

Casey 的简化:**BVH 遍历 SIMD,光照解码标量**。已经能获得大部分性能(70-80%)。

### BVH 遍历 4-wide

```rust
pub fn traverse_ray4(
    rays: &Ray4,
    node: &BvhNode,
    aabbs: &[AABB],
    hits: &mut [Vec<u32>; 4],  // 4 条光线各自的命中
) {
    // SIMD 测试当前节点
    let mask = unsafe { ray4_vs_aabb(rays, &node.bounds()) };
    if mask == 0 {
        return;  // 4 条光线都不相交,跳过整个子树
    }

    match node {
        BvhNode::Leaf { objects, .. } => {
            for obj_id in objects {
                let aabb = &aabbs[*obj_id as usize];
                let obj_mask = unsafe { ray4_vs_aabb(rays, aabb) };
                for i in 0..4 {
                    if obj_mask & (1 << i) != 0 {
                        hits[i].push(*obj_id);
                    }
                }
            }
        }
        BvhNode::Internal { left, right, .. } => {
            traverse_ray4(rays, left, aabbs, hits);
            traverse_ray4(rays, right, aabbs, hits);
        }
    }
}
```

关键优化:**`if mask == 0` 早退**。如果 4 条光线都不命中当前节点,跳过整个子树。这是 SIMD 的"批量剔除"红利——4 条光线一起决定"都不需要看这里"。

如果 4 条光线发散(有的命中有的不命中),无法早退,但要继续遍历子树。BVH4(4-wide BVH,每个内部节点 4 个子节点)进一步优化,但实现复杂,Casey 不做。

### Rust 视角:批量打包

```rust
pub fn compute_primitive_lighting_simd(
    primitive: &Primitive,
    light: &LightSource,
    bvh: &Bvh,
    aabbs: &[AABB],
    sample_base: u32,
) -> Vec3 {
    // 4 个样本
    let samples: [(f32, f32); 4] = [
        (halton(sample_base, 2), halton(sample_base, 3)),
        (halton(sample_base + 1, 2), halton(sample_base + 1, 3)),
        (halton(sample_base + 2, 2), halton(sample_base + 2, 3)),
        (halton(sample_base + 3, 2), halton(sample_base + 3, 3)),
    ];

    // 4 条光线(SoA)
    let rays: [Ray; 4] = samples.map(|(u, v)| {
        let light_p = light.sample(u, v);
        let dir = light_p - primitive.center;
        let dir_n = dir.normalize();
        Ray { origin: primitive.center, dir: dir_n }
    });
    let ray4 = Ray4::from_rays(&rays);

    // BVH 遍历 4-wide
    let mut hits = [Vec::new(), Vec::new(), Vec::new(), Vec::new()];
    traverse_ray4(&ray4, &bvh.root, aabbs, &mut hits);

    // 解码 + 光照(标量)
    let mut accum = Vec3::ZERO;
    for ray_idx in 0..4 {
        let visible = hits[ray_idx].is_empty();  // 无命中 = 可见
        if visible {
            let (u, v) = samples[ray_idx];
            let light_p = light.sample(u, v);
            let dist2 = (light_p - primitive.center).length_squared();
            let n_dot_l = primitive.normal.dot(
                (light_p - primitive.center).normalize()
            ).max(0.0);
            let att = 1.0 / (dist2 + 0.01);
            accum += light.color * light.intensity * n_dot_l * att;
        }
    }
    accum / 4.0
}
```

注意:**`is_empty()` 是可见判定**——如果 BVH 遍历没命中任何 AABB,光线没被遮挡。但如果命中 AABB 但 AABB 不是真正的遮挡物(只是包围盒),需要进一步测试。Casey 假设 AABB = 遮挡物(简化)。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

工业的系统级 SIMD:

- **Frostbite (DICE)**:ray tracing、物理、粒子全部 SIMD
- **Unity Burst**:C# → SIMD,自动
- **Unreal Mass**:ECS + SIMD,大数据并行
- **embree**:Intel 出的 SIMD ray tracer 库

工业的 ray tracer 把整个数据流(SoA layout、BVH4、SIMD shader)统一设计。Casey 的简化版本是教学版,实际工程更复杂。

### 3.2 · 🎨 图形学视角

完整 SIMD ray tracer 的关键:

- **SoA primitive storage**:顶点数据 SoA
- **Packet traversal**:多光线一起走 BVH
- **SIMD shading**:着色计算 SIMD
- **Coherent rays**:光线方向相近(像 primary rays),packet 效率高

Coherent 是关键——如果光线发散,packet 退化(SIMD lane 利用率低)。Primary rays(相机发射)coherent,shadow rays(到光源)部分 coherent,reflection/refraction rays 不 coherent。

### 3.3 · 🐧 Linux 系统编程视角

Linux 的"系统级"优化:

- **epoll**:不是单个 socket 快,而是大量 socket 一起管理
- **io_uring**:批量 IO 提交,系统调用一次处理多个
- **cgroup-bpf**:批量过滤,不是单包

"批量"是系统设计的核心。SIMD 是 CPU 指令级的批量。

### 3.4 · 🦀 Rust 生态视角

Rust 系统级 SIMD:

- `wide` crate:`f32x4` 等抽象类型
- `glam`:`Vec3A`(SIMD 友好的 Vec3)
- `packed_simd_2`(nightly)
- `std::simd`(nightly, portable)

未来 `std::simd` 稳定后,代码会更易读,跨平台自动。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么"单点 SIMD"(只优化 ray-AABB)加速有限?系统集成后能多加速多少?

**参考解答**:单点 SIMD 只优化一个函数。如果调用它的代码(BVH 遍历、采样、结果解码)还是标量,**总时间被这些标量代码拖累**。

具体数字(假设):

- 标量全流程:50ms
  - 采样:5ms(标量)
  - BVH 遍历 + ray-AABB:35ms(标量)
  - 结果解码 + 光照:10ms(标量)
- 单点 SIMD(ray-AABB 4x):35ms → 9ms,总 = 5+9+10 = 24ms
- 全流程 SIMD:每部分都 4x,总 = 1.25+9+2.5 = 12.75ms

单点加速 50→24ms(2x),全流程加速 50→13ms(4x)。差异显著。

工业更激进:**采样也 SIMD**(4 个 halton 一起算)、**光照累加也 SIMD**(4 个贡献一起加)。总加速 6-10x。

#[derive(Copy, Clone)]
pub struct Ray { pub origin: Vec3, pub dir: Vec3 }

#[derive(Copy, Clone)]
pub struct Ray4 {
    pub origin_x: __m128, pub origin_y: __m128, pub origin_z: __m128,
    pub dir_x: __m128, pub dir_y: __m128, pub dir_z: __m128,
}

#[derive(Copy, Clone)]
pub struct AABB { pub min: Vec3, pub max: Vec3 }

impl Ray4 {
    pub fn from_rays(rays: &[Ray; 4]) -> Self {
        unsafe {
            Self {
                origin_x: _mm_set_ps(rays[3].origin.x, rays[2].origin.x, rays[1].origin.x, rays[0].origin.x),
                origin_y: _mm_set_ps(rays[3].origin.y, rays[2].origin.y, rays[1].origin.y, rays[0].origin.y),
                origin_z: _mm_set_ps(rays[3].origin.z, rays[2].origin.z, rays[1].origin.z, rays[0].origin.z),
                dir_x: _mm_set_ps(rays[3].dir.x, rays[2].dir.x, rays[1].dir.x, rays[0].dir.x),
                dir_y: _mm_set_ps(rays[3].dir.y, rays[2].dir.y, rays[1].dir.y, rays[0].dir.y),
                dir_z: _mm_set_ps(rays[3].dir.z, rays[2].dir.z, rays[1].dir.z, rays[0].dir.z),
            }
        }
    }
}

#[target_feature(enable = "sse2")]
pub unsafe fn ray4_vs_aabb(rays: &Ray4, aabb: &AABB) -> u8 {
    let min_x = _mm_set1_ps(aabb.min.x);
    let min_y = _mm_set1_ps(aabb.min.y);
    let min_z = _mm_set1_ps(aabb.min.z);
    let max_x = _mm_set1_ps(aabb.max.x);
    let max_y = _mm_set1_ps(aabb.max.y);
    let max_z = _mm_set1_ps(aabb.max.z);
    let one = _mm_set1_ps(1.0);
    let zero = _mm_set1_ps(0.0);
    let neg_inf = _mm_set1_ps(f32::NEG_INFINITY);
    let pos_inf = _mm_set1_ps(f32::INFINITY);

    let mut t_min = neg_inf;
    let mut t_max = pos_inf;

    let inv_dx = one / rays.dir_x;
    let t1x = (min_x - rays.origin_x) * inv_dx;
    let t2x = (max_x - rays.origin_x) * inv_dx;
    t_min = _mm_max_ps(t_min, _mm_min_ps(t1x, t2x));
    t_max = _mm_min_ps(t_max, _mm_max_ps(t1x, t2x));

    let inv_dy = one / rays.dir_y;
    let t1y = (min_y - rays.origin_y) * inv_dy;
    let t2y = (max_y - rays.origin_y) * inv_dy;
    t_min = _mm_max_ps(t_min, _mm_min_ps(t1y, t2y));
    t_max = _mm_min_ps(t_max, _mm_max_ps(t1y, t2y));

    let inv_dz = one / rays.dir_z;
    let t1z = (min_z - rays.origin_z) * inv_dz;
    let t2z = (max_z - rays.origin_z) * inv_dz;
    t_min = _mm_max_ps(t_min, _mm_min_ps(t1z, t2z));
    t_max = _mm_min_ps(t_max, _mm_max_ps(t1z, t2z));

    let hit = _mm_cmple_ps(t_min, t_max);
    let in_front = _mm_cmpge_ps(t_max, zero);
    let mask = _mm_and_ps(hit, in_front);
    _mm_movemask_ps(mask) as u8 & 0x0F
}

#[derive(Debug)]
pub enum BvhNode {
    Leaf { bounds: AABB, objects: Vec<u32> },
    Internal { bounds: AABB, left: Box<BvhNode>, right: Box<BvhNode> },
}

impl BvhNode {
    pub fn bounds(&self) -> AABB {
        match self {
            BvhNode::Leaf { bounds, .. } => *bounds,
            BvhNode::Internal { bounds, .. } => *bounds,
        }
    }

    pub fn traverse_ray4(
        &self,
        rays: &Ray4,
        aabbs: &[AABB],
        hits: &mut [Vec<u32>; 4],
    ) {
        // 早退:所有 4 条光线都不命中当前节点
        let mask = unsafe { ray4_vs_aabb(rays, &self.bounds()) };
        if mask == 0 {
            return;
        }

        match self {
            BvhNode::Leaf { objects, .. } => {
                for obj_id in objects {
                    let aabb = &aabbs[*obj_id as usize];
                    let obj_mask = unsafe { ray4_vs_aabb(rays, aabb) };
                    for i in 0..4 {
                        if obj_mask & (1 << i) != 0 {
                            hits[i].push(*obj_id);
                        }
                    }
                }
            }
            BvhNode::Internal { left, right, .. } => {
                left.traverse_ray4(rays, aabbs, hits);
                right.traverse_ray4(rays, aabbs, hits);
            }
        }
    }
}

use core::arch::x86_64::*;
use glam::Vec3;

#[derive(Copy, Clone)]
pub struct Ray { pub origin: Vec3, pub dir: Vec3 }

#[derive(Copy, Clone)]
pub struct Ray4 {
    pub origin_x: __m128, pub origin_y: __m128, pub origin_z: __m128,
    pub dir_x: __m128, pub dir_y: __m128, pub dir_z: __m128,
}

#[derive(Copy, Clone)]
pub struct AABB { pub min: Vec3, pub max: Vec3 }

impl Ray4 {
    pub fn from_rays(rays: &[Ray; 4]) -> Self {
        unsafe {
            Self {
                origin_x: _mm_set_ps(rays[3].origin.x, rays[2].origin.x, rays[1].origin.x, rays[0].origin.x),
                origin_y: _mm_set_ps(rays[3].origin.y, rays[2].origin.y, rays[1].origin.y, rays[0].origin.y),
                origin_z: _mm_set_ps(rays[3].origin.z, rays[2].origin.z, rays[1].origin.z, rays[0].origin.z),
                dir_x: _mm_set_ps(rays[3].dir.x, rays[2].dir.x, rays[1].dir.x, rays[0].dir.x),
                dir_y: _mm_set_ps(rays[3].dir.y, rays[2].dir.y, rays[1].dir.y, rays[0].dir.y),
                dir_z: _mm_set_ps(rays[3].dir.z, rays[2].dir.z, rays[1].dir.z, rays[0].dir.z),
            }
        }
    }

    pub fn extract(&self, i: usize) -> Ray {
        // 从 SoA 取出第 i 条 ray
        unsafe {
            let mut buf = [0.0_f32; 4];
            _mm_storeu_ps(buf.as_mut_ptr(), self.origin_x);
            let ox = buf[i];
            _mm_storeu_ps(buf.as_mut_ptr(), self.origin_y);
            let oy = buf[i];
            _mm_storeu_ps(buf.as_mut_ptr(), self.origin_z);
            let oz = buf[i];
            _mm_storeu_ps(buf.as_mut_ptr(), self.dir_x);
            let dx = buf[i];
            _mm_storeu_ps(buf.as_mut_ptr(), self.dir_y);
            let dy = buf[i];
            _mm_storeu_ps(buf.as_mut_ptr(), self.dir_z);
            let dz = buf[i];
            Ray {
                origin: Vec3::new(ox, oy, oz),
                dir: Vec3::new(dx, dy, dz),
            }
        }
    }
}

#[target_feature(enable = "sse2")]
pub unsafe fn ray4_vs_aabb(rays: &Ray4, aabb: &AABB) -> u8 {
    let min_x = _mm_set1_ps(aabb.min.x);
    let min_y = _mm_set1_ps(aabb.min.y);
    let min_z = _mm_set1_ps(aabb.min.z);
    let max_x = _mm_set1_ps(aabb.max.x);
    let max_y = _mm_set1_ps(aabb.max.y);
    let max_z = _mm_set1_ps(aabb.max.z);
    let one = _mm_set1_ps(1.0);
    let zero = _mm_set1_ps(0.0);
    let mut t_min = _mm_set1_ps(f32::NEG_INFINITY);
    let mut t_max = _mm_set1_ps(f32::INFINITY);

    let inv_dx = one / rays.dir_x;
    let t1x = (min_x - rays.origin_x) * inv_dx;
    let t2x = (max_x - rays.origin_x) * inv_dx;
    t_min = _mm_max_ps(t_min, _mm_min_ps(t1x, t2x));
    t_max = _mm_min_ps(t_max, _mm_max_ps(t1x, t2x));

    let inv_dy = one / rays.dir_y;
    let t1y = (min_y - rays.origin_y) * inv_dy;
    let t2y = (max_y - rays.origin_y) * inv_dy;
    t_min = _mm_max_ps(t_min, _mm_min_ps(t1y, t2y));
    t_max = _mm_min_ps(t_max, _mm_max_ps(t1y, t2y));

    let inv_dz = one / rays.dir_z;
    let t1z = (min_z - rays.origin_z) * inv_dz;
    let t2z = (max_z - rays.origin_z) * inv_dz;
    t_min = _mm_max_ps(t_min, _mm_min_ps(t1z, t2z));
    t_max = _mm_min_ps(t_max, _mm_max_ps(t1z, t2z));

    let hit = _mm_cmple_ps(t_min, t_max);
    let in_front = _mm_cmpge_ps(t_max, zero);
    let mask = _mm_and_ps(hit, in_front);
    _mm_movemask_ps(mask) as u8 & 0x0F
}

#[derive(Debug)]
pub enum BvhNode {
    Leaf { bounds: AABB, objects: Vec<u32> },
    Internal { bounds: AABB, left: Box<BvhNode>, right: Box<BvhNode> },
}

impl BvhNode {
    pub fn bounds(&self) -> AABB {
        match self {
            BvhNode::Leaf { bounds, .. } => *bounds,
            BvhNode::Internal { bounds, .. } => *bounds,
        }
    }

    pub fn traverse_ray4(&self, rays: &Ray4, aabbs: &[AABB], hits: &mut [Vec<u32>; 4]) {
        let mask = unsafe { ray4_vs_aabb(rays, &self.bounds()) };
        if mask == 0 { return; }  // 4-wide early exit

        match self {
            BvhNode::Leaf { objects, .. } => {
                for obj_id in objects {
                    let aabb = &aabbs[*obj_id as usize];
                    let obj_mask = unsafe { ray4_vs_aabb(rays, aabb) };
                    for i in 0..4 {
                        if obj_mask & (1 << i) != 0 {
                            hits[i].push(*obj_id);
                        }
                    }
                }
            }
            BvhNode::Internal { left, right, .. } => {
                left.traverse_ray4(rays, aabbs, hits);
                right.traverse_ray4(rays, aabbs, hits);
            }
        }
    }
}

fn main() {
    if !is_x86_feature_detected!("sse2") {
        eprintln!("SSE2 required");
        return;
    }
    let aabbs = vec![
        AABB { min: Vec3::new(-1.0, -1.0, -1.0), max: Vec3::new(1.0, 1.0, 1.0) },
        AABB { min: Vec3::new(3.0, -1.0, -1.0), max: Vec3::new(5.0, 1.0, 1.0) },
        AABB { min: Vec3::new(-1.0, -1.0, 3.0), max: Vec3::new(1.0, 1.0, 5.0) },
    ];
    let bvh = BvhNode::Leaf {
        bounds: AABB { min: Vec3::new(-1.0, -1.0, -1.0), max: Vec3::new(5.0, 1.0, 5.0) },
        objects: vec![0, 1, 2],
    };

    let rays: [Ray; 4] = [
        Ray { origin: Vec3::new(-10.0, 0.0, 0.0), dir: Vec3::new(1.0, 0.0, 0.0) },
        Ray { origin: Vec3::new(-10.0, 5.0, 0.0), dir: Vec3::new(1.0, 0.0, 0.0) },
        Ray { origin: Vec3::new(-10.0, 0.0, 4.0), dir: Vec3::new(1.0, 0.0, 0.0) },
        Ray { origin: Vec3::new(-10.0, 0.0, 0.0), dir: Vec3::new(1.0, 0.0, 0.0) },
    ];

    let ray4 = Ray4::from_rays(&rays);
    let mut hits = [Vec::new(), Vec::new(), Vec::new(), Vec::new()];
    bvh.traverse_ray4(&ray4, &aabbs, &mut hits);

    for (i, h) in hits.iter().enumerate() {
        println!("Ray {}: hit {} objects {:?}", i, h.len(), h);
    }

    let n = 100_000;
    let start = std::time::Instant::now();
    for _ in 0..n {
        let mut hits = [Vec::new(), Vec::new(), Vec::new(), Vec::new()];
        bvh.traverse_ray4(&ray4, &aabbs, &mut hits);
        std::hint::black_box(hits);
    }
    let elapsed = start.elapsed();
    println!("\n{} SIMD BVH traversals (4 rays each): {:?}", n, elapsed);
    println!("Per traversal: {:?}", elapsed / n as u32);
}

**Troubleshooting**:

- **早退失效** — 检查 `mask == 0` 判断,确保 4 条光线都不命中才退
- **hits 累积过多** — 4 条光线发散,无法早退,改用单光线模式
- **alloc 拖累** — `Vec::new()` 每 ray 都分配,实际用 `SmallVec` 或 pre-allocated
- **mask 解码错** — `(1 << i) & mask` 检查第 i 位,从 0 开始
- **debug 模式慢** — SIMD 必须用 `--release`,debug 不优化 intrinsics
