# Day 275 · 向渲染器传递旋转与剪切

> 昨天 spring 让角色能"压扁"和"弹回"——但只是水平和垂直方向(scale_x, scale_y)。今天 Casey 给渲染器加**旋转**和**剪切**能力,让角色能朝任意方向看、做斜身等动作。这背后是 2D 仿射变换矩阵的引入。

## 0 · 为什么要有这一天

你现在的渲染器只支持:

```rust
fn draw_sprite(buf: &mut [...], x: i32, y: i32, sprite: &Sprite) { ... }
fn draw_sprite_scaled(buf: &mut [...], x: i32, y: i32, sprite: &Sprite, scale: f32) { ... }
```

只有位置 + 缩放,没有旋转。这意味着:

- 角色面朝右移动时,精灵不能"扭头看右",只能换 sprite(预先画好的右朝向版本)
- 子弹不能"沿轨迹方向旋转",只能用预渲染的 8 方向子弹图
- 撞墙时角色只能水平 / 垂直压扁,不能"斜着压"

要支持旋转,需要在渲染时做**仿射变换**:

```
新坐标 = M * 原坐标 + 平移
```

M 是 2x2 矩阵,可以表达旋转 / 缩放 / 剪切。今天 Casey 给渲染器加这个能力,从底层(像素绘制)开始改。

实现工程难点:

1. **像素绘制要支持变换**:对每个 sprite 像素,应用 M 算出目标位置
2. **反向映射**:渲染时遍历目标像素,反推源像素(否则有"空洞")
3. **抗锯齿**:旋转产生非整数坐标,简单最近邻会锯齿
4. **API 设计**:渲染器接收什么参数?单独的旋转 / 缩放,还是统一矩阵?

心理锚点:做完这个,你的角色可以面朝任意方向,子弹可以旋转飞行,UI 元素可以倾斜显示。

## 1 · Casey 今天做了什么

Casey 给渲染器加 2x2 矩阵变换:

1. 定义 `Transform2D`:`{ pos: Vec2, m: [f32; 4] }`,m 是 2x2 矩阵(展平成 4 元素数组)
2. 渲染函数 `draw_sprite_transformed(buf, transform, sprite)`:对每个 sprite 像素,应用 transform 算目标位置,画到 buffer
3. 加辅助函数构造变换:`translation(x, y)`、`rotation(angle)`、`scale(sx, sy)`、`shear(kx, ky)`
4. 把角色渲染改成 transform 驱动:旋转角度 + spring 控制的 scale + 剪切
5. 演示:角色面朝鼠标方向(算 angle),子弹旋转飞行

Casey 处理了**反向映射**(避免空洞):对每个目标像素,用矩阵的逆算源像素位置,采样 sprite。

最后 Casey 提到了**抗锯齿**:最近邻采样边缘锯齿明显,实际项目应该用双线性插值。今天简化为最近邻,Day 270+ 切到 OpenGL 后用 GPU 双线性。

## 2 · 心智模型

### 类比:Photoshop 的"自由变换"

你用过 Photoshop 的 Ctrl+T(自由变换)吗?选中图层,拖动控制点可以**移动 + 缩放 + 旋转 + 倾斜**。背后的数学就是 2D 仿射变换。

今天 Casey 给渲染器加的能力,等价于"用代码做 Photoshop 的自由变换"。每个 sprite 渲染时,先应用一个变换,再画到屏幕。

### 严谨原理:2D 仿射变换

#### 数学定义

2D 仿射变换是:

```
[x']   [a b] [x]   [tx]
[y'] = [c d] [y] + [ty]
```

其中 `(a, b, c, d)` 是 2x2 矩阵 M 的元素,`(tx, ty)` 是平移。M 可以表达:

- **缩放**:`a = sx, d = sy, b = c = 0`
- **旋转(角度 θ)**:`a = cos θ, b = -sin θ, c = sin θ, d = cos θ`
- **剪切**:`a = d = 1, b = kx, c = ky`(kx, ky 是剪切因子)
- **任意线性变换**:M 任意

#### Rust 实现

```rust
#[derive(Clone, Copy, Debug)]
struct Mat2 {
    m: [f32; 4],  // [a, b, c, d] row-major
}

impl Mat2 {
    fn identity() -> Self {
        Self { m: [1.0, 0.0, 0.0, 1.0] }
    }
    fn scale(sx: f32, sy: f32) -> Self {
        Self { m: [sx, 0.0, 0.0, sy] }
    }
    fn rotation(angle: f32) -> Self {
        let (s, c) = angle.sin_cos();
        Self { m: [c, -s, s, c] }
    }
    fn shear(kx: f32, ky: f32) -> Self {
        Self { m: [1.0, kx, ky, 1.0] }
    }
    fn transform(&self, x: f32, y: f32) -> (f32, f32) {
        let (a, b, c, d) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        (a * x + b * y, c * x + d * y)
    }
}
```

注意 `[a, b, c, d]` 是 row-major(行优先):a, b 是第一行,c, d 是第二行。`transform(x, y)` 返回 `(a*x + b*y, c*x + d*y)`。

#### Transform struct(含平移)

```rust
#[derive(Clone, Copy, Debug)]
struct Transform2D {
    translation: Vec2,
    matrix: Mat2,
}

impl Transform2D {
    fn new(translation: Vec2, matrix: Mat2) -> Self {
        Self { translation, matrix }
    }
    fn transform_point(&self, p: Vec2) -> Vec2 {
        let (x, y) = self.matrix.transform(p.x, p.y);
        Vec2::new(x + self.translation.x, y + self.translation.y)
    }
}
```

#### 反向映射(避免空洞)

如果直接对 sprite 的每个像素应用 transform 算目标位置,会出现"空洞"——某些目标像素没有源像素映射到。

正确做法:**遍历目标像素**,反推源像素。但需要矩阵的逆。

对于仿射变换,逆变换是:

```
M^-1 = (1/det) * [d -b]
                 [-c a]
det = ad - bc
```

如果 det = 0(退化矩阵),没有逆。游戏里这种情况很少(角色不会缩到 0)。

```rust
impl Mat2 {
    fn inverse(&self) -> Option<Self> {
        let (a, b, c, d) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        let det = a * d - b * c;
        if det.abs() < 1e-6 { return None; }
        let inv_det = 1.0 / det;
        Some(Self { m: [d * inv_det, -b * inv_det, -c * inv_det, a * inv_det] })
    }
}
```

#### 反向映射的渲染算法

```rust
fn draw_sprite_transformed(
    buf: &mut [u32], buf_w: usize, buf_h: usize,
    transform: &Transform2D,
    sprite: &[u32], sprite_w: usize, sprite_h: usize,
) {
    // 算 sprite 在屏幕上的边界框(transform 后)
    let corners = [
        transform.transform_point(Vec2::new(0.0, 0.0)),
        transform.transform_point(Vec2::new(sprite_w as f32, 0.0)),
        transform.transform_point(Vec2::new(0.0, sprite_h as f32)),
        transform.transform_point(Vec2::new(sprite_w as f32, sprite_h as f32)),
    ];
    let min_x = corners.iter().map(|p| p.x).fold(f32::INFINITY, f32::min).floor() as i32;
    let max_x = corners.iter().map(|p| p.x).fold(f32::NEG_INFINITY, f32::max).ceil() as i32;
    let min_y = corners.iter().map(|p| p.y).fold(f32::INFINITY, f32::min).floor() as i32;
    let max_y = corners.iter().map(|p| p.y).fold(f32::NEG_INFINITY, f32::max).ceil() as i32;

    // 算逆变换
    let inv_matrix = match transform.matrix.inverse() {
        Some(m) => m,
        None => return,
    };

    // 遍历目标像素,反推源像素
    for py in min_y.max(0)..max_y.min(buf_h as i32) {
        for px in min_x.max(0)..max_x.min(buf_w as i32) {
            // 反向变换:目标 -> 源
            let dx = px as f32 - transform.translation.x;
            let dy = py as f32 - transform.translation.y;
            let (sx, sy) = inv_matrix.transform(dx, dy);

            if sx >= 0.0 && sx < sprite_w as f32 && sy >= 0.0 && sy < sprite_h as f32 {
                // 最近邻采样
                let src_x = sx as usize;
                let src_y = sy as usize;
                let src_color = sprite[src_y * sprite_w + src_x];
                if src_color != 0 {  // 0 = 透明
                    buf[(py as usize) * buf_w + (px as usize)] = src_color;
                }
            }
        }
    }
}
```

#### 复合变换

多个变换可以串联(矩阵乘法):

```rust
impl Mat2 {
    fn mul(&self, other: &Mat2) -> Mat2 {
        let (a1, b1, c1, d1) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        let (a2, b2, c2, d2) = (other.m[0], other.m[1], other.m[2], other.m[3]);
        Mat2 { m: [
            a1*a2 + b1*c2, a1*b2 + b1*d2,
            c1*a2 + d1*c2, c1*b2 + d1*d2,
        ] }
    }
}

// 复合:先缩放,再旋转
let m = Mat2::rotation(angle).mul(&Mat2::scale(sx, sy));
```

注意矩阵乘法**不交换**:`rotation * scale != scale * rotation`(先缩放再旋转 vs 先旋转再缩放,效果不同)。

#### 旋转方向:朝向鼠标

角色面朝鼠标,需要算 angle:

```rust
let to_mouse = mouse_pos.sub(player_pos);
let angle = to_mouse.y.atan2(to_mouse.x);  // atan2 返回 -π 到 π
```

`atan2(y, x)` 是 Rust 的 `f32::atan2(y)`,返回相对 X 轴正方向的角度(弧度)。注意参数顺序:`y.atan2(x)` 不是 `x.atan2(y)`。

旋转矩阵用 `Mat2::rotation(angle)`,sprite 朝向 X 正方向(角度 0)时,旋转 angle 弧度后朝鼠标方向。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

旋转 / 剪切在游戏里大量用:

- **角色朝向**(今天做的):角色面朝鼠标 / 移动方向
- **子弹 / 投射物**:沿轨迹方向旋转
- **车辆**:车轮转向 + 车身倾斜(剪切)
- **UI 弹窗**:从屏幕外滑入时旋转 / 倾斜
- **粒子**:火焰粒子旋转随机角度,避免重复

业界优化:

- **预渲染 8 / 16 / 32 方向**:不实时算旋转,而是预先生成多个方向的 sprite,运行时按 angle 选最接近的
- **GPU shader**:现代游戏用 GPU vertex shader 做变换,CPU 不参与
- **SDF(signed distance field)**:文字旋转 / 缩放用 SDF,任意缩放保持锐利

Casey 用 CPU 实时旋转(教学),生产项目用预渲染或 GPU。

### 3.2 · 🎨 图形学视角

仿射变换是图形学的 ABC。完整渲染管线:

1. **Model transform**:模型空间 → 世界空间(用 model matrix)
2. **View transform**:世界空间 → 相机空间(view matrix)
3. **Projection transform**:相机空间 → 裁剪空间(projection matrix)
4. **Viewport transform**:裁剪空间 → 屏幕空间

每步都是一个矩阵,串联成 MVP(model-view-projection)矩阵。GPU vertex shader 接收 MVP,对每个顶点应用。

3D 用 4x4 矩阵(齐次坐标),2D 用 3x3 矩阵(也是齐次坐标)。Casey 简化为 2x2 + 平移,够 2D 用。

#### 齐次坐标

为什么 3D 用 4x4 而不是 3x3?因为 3x3 矩阵不能表达平移。引入第 4 维(w):

```
[x']   [a b c tx] [x]
[y'] = [d e f ty] [y]
[z']   [g h i tz] [z]
[1 ]   [0 0 0 1 ] [1]
```

w=1 时,tx, ty, tz 就是平移。这就是齐次坐标(homogeneous coordinates)。2D 同理用 3x3。

Casey 的 `Transform2D { translation: Vec2, matrix: Mat2 }` 是手动展开齐次坐标——把平移和线性部分分开,等价于 3x3 矩阵但内存紧凑。

#### 抗锯齿

最近邻采样边缘锯齿。改进:

- **双线性插值(bilinear)**:4 个邻居加权平均,边缘平滑
- **双三次插值(bicubic)**:16 个邻居,更平滑但更慢
- **超级采样(SSAA)**:渲染到大 buffer 再降采样,完美但 4 倍开销
- **MSAA**:GPU 标准抗锯齿

Casey 今天用最近邻,简化代码。生产用双线性。

### 3.4 · 🦀 Rust 生态视角

Rust 表达矩阵几个风格:

#### 手写(Casey 风格)

```rust
struct Mat2 { m: [f32; 4] }
```

简单,完全控制。Casey 选这个。

#### glam::Mat2 / Mat3

```rust
use glam::{Mat2, Vec2};
let m = Mat2::from_angle(angle);
let v = m * Vec2::new(1.0, 0.0);
```

工业级,SIMD 优化。Phase 6 之后可以切。

#### nalgebra::Matrix2

```rust
use nalgebra::Matrix2;
let m = Matrix2::new(1.0, 2.0, 3.0, 4.0);
```

泛型,科学计算用,游戏不推荐(性能开销)。

#### Transform trait

```rust
trait Transform {
    fn apply(&self, p: Vec2) -> Vec2;
    fn inverse(&self) -> Self;
    fn combine(&self, other: &Self) -> Self;
}

struct Translation(Vec2);
struct Rotation(f32);
struct Scale(Vec2);

impl Transform for Translation { ... }
impl Transform for Rotation { ... }
```

类型安全,每个 transform 是独立类型。但代码量大,适合复杂场景。

### 3.5 · 数学:线性代数复习

2D 仿射变换的线性代数基础:

- **矩阵**:2D 数组,这里 2x2
- **向量**:1D 数组,这里 2 元素
- **矩阵 × 向量**:2x2 矩阵乘 2 元素向量,得新 2 元素向量
- **行列式 det**:衡量矩阵"面积缩放因子"。det = 0 不可逆,det < 0 包含翻转
- **逆矩阵**:M * M^-1 = I(单位矩阵)

这些是计算机图形学的入门数学,后面 Day 280+ 进入 3D 时会大量用 3x3 / 4x4 矩阵。

## 5 · 对照与变奏

### 2D vs 3D 变换

| 维度 | 矩阵大小 | 自由度 |
|---|---|---|
| 2D | 2x2 + 平移 = 3x3 | 6(scale 2 + rotation 1 + shear 2 + translation 2) |
| 3D | 3x3 + 平移 = 4x4 | 12(scale 3 + rotation 3 + shear ? + translation 3) |
| 3D + 透视 | 4x4 任意 | 16 |

3D 旋转用四元数(quaternion)更稳定(避免 gimbal lock),今天不涉及。

### 不同插值的旋转

| 方法 | 优点 | 缺点 |
|---|---|---|
| 欧拉角(xyz) | 直观 | gimbal lock |
| 四元数 | 稳定,可 slerp | 不直观 |
| 轴-角 | 简单 | 不易组合 |
| 旋转矩阵 | 直接用 | 累积误差 |

游戏 3D 几乎都用四元数。Casey 的 HH 是 2D,用欧拉角(单一角度)足够。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么渲染时用"反向映射"(目标 → 源)而不是"正向映射"(源 → 目标)?给出至少 3 个理由。

**参考解答**:
1. **避免空洞**:正向映射时,某些目标像素可能没有源像素映射到(因为旋转后像素稀疏),产生空洞。反向映射保证每个目标像素都查到源
2. **简洁**:反向映射的循环边界是目标边界框,直接对应屏幕 buffer。正向映射要算"源像素变换后的位置",可能在屏幕外
3. **过滤**:反向映射可以方便地做 clip(只算屏幕内的目标像素),正向映射要算完再 clip
4. **采样灵活**:反向映射拿到源坐标后,可以做任意采样(最近邻 / 双线性 / 三线性),正向映射做不到
5. **GPU 友好**:GPU 的光栅化器本质是反向映射——遍历屏幕像素,采样纹理

### Lv2 · 动手实践

**题**:实现 `Mat2` + `Transform2D`,以及 `draw_sprite_transformed` 函数(反向映射)。

测试:

- 创建一个 4x4 的 sprite(全是红色)
- 用 `Mat2::rotation(PI/4)` 旋转 45 度
- 渲染到 16x16 buffer,验证中心区域有红色像素

**参考解答**:

```rust
#[derive(Clone, Copy, Debug)]
struct Mat2 { m: [f32; 4] }

impl Mat2 {
    fn identity() -> Self { Self { m: [1.0, 0.0, 0.0, 1.0] } }
    fn rotation(angle: f32) -> Self {
        let (s, c) = angle.sin_cos();
        Self { m: [c, -s, s, c] }
    }
    fn scale(sx: f32, sy: f32) -> Self {
        Self { m: [sx, 0.0, 0.0, sy] }
    }
    fn transform(&self, x: f32, y: f32) -> (f32, f32) {
        let (a, b, c, d) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        (a * x + b * y, c * x + d * y)
    }
    fn inverse(&self) -> Option<Self> {
        let (a, b, c, d) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        let det = a * d - b * c;
        if det.abs() < 1e-6 { return None; }
        let inv_det = 1.0 / det;
        Some(Self { m: [d * inv_det, -b * inv_det, -c * inv_det, a * inv_det] })
    }
}

#[derive(Clone, Copy, Debug)]
struct Vec2 { x: f32, y: f32 }

#[derive(Clone, Copy, Debug)]
struct Transform2D {
    translation: Vec2,
    matrix: Mat2,
}

impl Transform2D {
    fn new(translation: Vec2, matrix: Mat2) -> Self {
        Self { translation, matrix }
    }
}

fn draw_sprite_transformed(
    buf: &mut [u32], buf_w: usize, buf_h: usize,
    transform: &Transform2D,
    sprite: &[u32], sprite_w: usize, sprite_h: usize,
) {
    // 算 sprite 边界框
    let corners = [
        transform.matrix.transform(0.0, 0.0),
        transform.matrix.transform(sprite_w as f32, 0.0),
        transform.matrix.transform(0.0, sprite_h as f32),
        transform.matrix.transform(sprite_w as f32, sprite_h as f32),
    ];
    let tx = transform.translation.x;
    let ty = transform.translation.y;
    let min_x = (corners.iter().map(|p| p.0).fold(f32::INFINITY, f32::min) + tx).floor() as i32;
    let max_x = (corners.iter().map(|p| p.0).fold(f32::NEG_INFINITY, f32::max) + tx).ceil() as i32;
    let min_y = (corners.iter().map(|p| p.1).fold(f32::INFINITY, f32::min) + ty).floor() as i32;
    let max_y = (corners.iter().map(|p| p.1).fold(f32::NEG_INFINITY, f32::max) + ty).ceil() as i32;

    let inv = match transform.matrix.inverse() {
        Some(m) => m,
        None => return,
    };

    for py in min_y.max(0)..max_y.min(buf_h as i32) {
        for px in min_x.max(0)..max_x.min(buf_w as i32) {
            let dx = px as f32 - tx;
            let dy = py as f32 - ty;
            let (sx, sy) = inv.transform(dx, dy);

            if sx >= 0.0 && sx < sprite_w as f32 && sy >= 0.0 && sy < sprite_h as f32 {
                let color = sprite[sy as usize * sprite_w + sx as usize];
                if color != 0 {
                    buf[py as usize * buf_w + px as usize] = color;
                }
            }
        }
    }
}

fn main() {
    let buf_w = 16;
    let buf_h = 16;
    let mut buf = vec![0u32; buf_w * buf_h];

    // 4x4 红色 sprite
    let sprite_w = 4;
    let sprite_h = 4;
    let sprite = vec![0xFFFF0000u32; sprite_w * sprite_h];

    // 旋转 45 度,中心放在 (8, 8)
    let transform = Transform2D {
        translation: Vec2 { x: 6.0, y: 6.0 },  // sprite (0,0) 映射到这里
        matrix: Mat2::rotation(std::f32::consts::PI / 4.0),
    };

    draw_sprite_transformed(&mut buf, buf_w, buf_h, &transform,
                            &sprite, sprite_w, sprite_h);

    // 打印 buffer
    let painted = buf.iter().filter(|p| **p != 0).count();
    println!("Painted {} pixels (旋转后菱形)", painted);

    // 文本可视化
    for y in 0..buf_h {
        let mut line = String::new();
        for x in 0..buf_w {
            line.push(if buf[y * buf_w + x] != 0 { '#' } else { '.' });
        }
        println!("{}", line);
    }
    // 应该看到菱形形状(45 度旋转的正方形)
}
```

**每行解释**:
- 算边界框:遍历 sprite 的 4 个角,transform 后取 min/max
- 反向映射:对每个目标像素,减 translation,用矩阵逆变换回源坐标
- `if color != 0` 跳过透明像素(0 = ARGB 全透明)
- 45 度旋转后正方形看起来像菱形

### 完整可跑:角色朝向鼠标 + 旋转

```rust
// Cargo.toml:
// [dependencies]
// minifb = "0.27"

use minifb::{Key, MouseMode, Window, WindowOptions};
use std::time::Instant;

const WIDTH: usize = 800;
const HEIGHT: usize = 600;

#[derive(Clone, Copy, Debug)]
struct Mat2 { m: [f32; 4] }

impl Mat2 {
    fn identity() -> Self { Self { m: [1.0, 0.0, 0.0, 1.0] } }
    fn rotation(angle: f32) -> Self {
        let (s, c) = angle.sin_cos();
        Self { m: [c, -s, s, c] }
    }
    fn scale(sx: f32, sy: f32) -> Self {
        Self { m: [sx, 0.0, 0.0, sy] }
    }
    fn shear(kx: f32, ky: f32) -> Self {
        Self { m: [1.0, kx, ky, 1.0] }
    }
    fn mul(&self, other: &Mat2) -> Mat2 {
        let (a1, b1, c1, d1) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        let (a2, b2, c2, d2) = (other.m[0], other.m[1], other.m[2], other.m[3]);
        Mat2 { m: [
            a1*a2 + b1*c2, a1*b2 + b1*d2,
            c1*a2 + d1*c2, c1*b2 + d1*d2,
        ] }
    }
    fn transform(&self, x: f32, y: f32) -> (f32, f32) {
        let (a, b, c, d) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        (a * x + b * y, c * x + d * y)
    }
    fn inverse(&self) -> Option<Self> {
        let (a, b, c, d) = (self.m[0], self.m[1], self.m[2], self.m[3]);
        let det = a * d - b * c;
        if det.abs() < 1e-6 { return None; }
        let inv_det = 1.0 / det;
        Some(Self { m: [d * inv_det, -b * inv_det, -c * inv_det, a * inv_det] })
    }
}

#[derive(Clone, Copy, Debug)]
struct Vec2 { x: f32, y: f32 }

impl Vec2 {
    fn new(x: f32, y: f32) -> Self { Self { x, y } }
    fn sub(self, o: Self) -> Self { Self::new(self.x - o.x, self.y - o.y) }
}

#[derive(Clone, Copy, Debug)]
struct Transform2D {
    translation: Vec2,
    matrix: Mat2,
}

fn draw_sprite_transformed(
    buf: &mut [u32], buf_w: usize, buf_h: usize,
    transform: &Transform2D,
    sprite: &[u32], sprite_w: usize, sprite_h: usize,
    origin_x: f32, origin_y: f32,  // sprite 的"中心点"
) {
    let corners = [
        transform.matrix.transform(-origin_x, -origin_y),
        transform.matrix.transform(sprite_w as f32 - origin_x, -origin_y),
        transform.matrix.transform(-origin_x, sprite_h as f32 - origin_y),
        transform.matrix.transform(sprite_w as f32 - origin_x, sprite_h as f32 - origin_y),
    ];
    let tx = transform.translation.x;
    let ty = transform.translation.y;
    let min_x = (corners.iter().map(|p| p.0).fold(f32::INFINITY, f32::min) + tx).floor() as i32;
    let max_x = (corners.iter().map(|p| p.0).fold(f32::NEG_INFINITY, f32::max) + tx).ceil() as i32;
    let min_y = (corners.iter().map(|p| p.1).fold(f32::INFINITY, f32::min) + ty).floor() as i32;
    let max_y = (corners.iter().map(|p| p.1).fold(f32::NEG_INFINITY, f32::max) + ty).ceil() as i32;

    let inv = match transform.matrix.inverse() {
        Some(m) => m,
        None => return,
    };

    for py in min_y.max(0)..max_y.min(buf_h as i32) {
        for px in min_x.max(0)..max_x.min(buf_w as i32) {
            let dx = px as f32 - tx;
            let dy = py as f32 - ty;
            let (sx, sy) = inv.transform(dx, dy);
            // 加 origin 偏移
            let sx = sx + origin_x;
            let sy = sy + origin_y;

            if sx >= 0.0 && sx < sprite_w as f32 && sy >= 0.0 && sy < sprite_h as f32 {
                let color = sprite[sy as usize * sprite_w + sx as usize];
                if color != 0 {
                    buf[py as usize * buf_w + px as usize] = color;
                }
            }
        }
    }
}

fn make_player_sprite() -> (Vec<u32>, usize, usize) {
    // 16x16 sprite:箭头朝右
    let w = 16;
    let h = 16;
    let mut sprite = vec![0u32; w * h];
    // 箭头形状
    let arrow_pixels = [
        (8, 7), (8, 8),
        (9, 6), (9, 7), (9, 8), (9, 9),
        (10, 5), (10, 6), (10, 7), (10, 8), (10, 9), (10, 10),
        (11, 4), (11, 5), (11, 6), (11, 7), (11, 8), (11, 9), (11, 10), (11, 11),
        (12, 7), (12, 8),  // 箭头尖端
        (13, 7), (13, 8),
        (14, 7), (14, 8),
        // 三角尾翼
        (10, 4), (10, 11),
        (11, 3), (11, 12),
    ];
    for &(x, y) in &arrow_pixels {
        if x < w && y < h {
            sprite[y * w + x] = 0xFFFF6040;
        }
    }
    (sprite, w, h)
}

fn main() {
    let mut window = Window::new(
        "Rotation + Shear Demo", WIDTH, HEIGHT,
        WindowOptions::default(),
    ).expect("Failed to open window");

    let mut buffer = vec![0u32; WIDTH * HEIGHT];
    let mut last_time = Instant::now();
    let mut total_time = 0.0_f32;

    let (sprite, sw, sh) = make_player_sprite();
    let player_pos = Vec2::new(WIDTH as f32 / 2.0, HEIGHT as f32 / 2.0);

    while window.is_open() && !window.is_key_down(Key::Escape) {
        let now = Instant::now();
        let dt = now.duration_since(last_time).as_secs_f32();
        last_time = now;
        total_time += dt;

        // 鼠标位置
        let (mx, my) = window.get_mouse_pos(MouseMode::Discard).unwrap_or((WIDTH as f32 / 2.0, HEIGHT as f32 / 2.0));
        let mouse_pos = Vec2::new(mx, my);

        // 算朝向鼠标的角度
        let to_mouse = mouse_pos.sub(player_pos);
        let angle = to_mouse.y.atan2(to_mouse.x);

        // 清屏
        for px in buffer.iter_mut() { *px = 0xFF101010; }

        // 画 sprite:旋转到鼠标方向,shear 加微动
        let wobble = (total_time * 5.0).sin() * 0.1;  // 微小剪切波动
        let transform = Transform2D {
            translation: player_pos,
            matrix: Mat2::rotation(angle).mul(&Mat2::shear(wobble, 0.0)),
        };
        draw_sprite_transformed(&mut buffer, WIDTH, HEIGHT, &transform,
                                &sprite, sw, sh, sw as f32 / 2.0, sh as f32 / 2.0);

        // 第二个 sprite:固定旋转 + 缩放动画
        let scale_anim = 1.0 + (total_time * 2.0).sin() * 0.2;
        let transform2 = Transform2D {
            translation: Vec2::new(200.0, 150.0),
            matrix: Mat2::rotation(total_time).mul(&Mat2::scale(scale_anim, scale_anim)),
        };
        draw_sprite_transformed(&mut buffer, WIDTH, HEIGHT, &transform2,
                                &sprite, sw, sh, sw as f32 / 2.0, sh as f32 / 2.0);

        // 第三个 sprite:垂直剪切(模拟"侧倾")
        let shear_anim = (total_time * 1.5).sin() * 0.3;
        let transform3 = Transform2D {
            translation: Vec2::new(600.0, 150.0),
            matrix: Mat2::shear(0.0, shear_anim),
        };
        draw_sprite_transformed(&mut buffer, WIDTH, HEIGHT, &transform3,
                                &sprite, sw, sh, sw as f32 / 2.0, sh as f32 / 2.0);

        window.update_with_buffer(&buffer, WIDTH, HEIGHT).unwrap();
    }
}
```

**关键 Rust 特性解释**:

- `Mat2` 的 4 个元素 `[a, b, c, d]` 表达旋转 / 缩放 / 剪切
- `mul` 复合变换,顺序敏感
- `inverse` 反向映射需要
- `origin_x / origin_y` 让 sprite 围绕中心旋转(默认是左上角)
- `atan2` 算朝向角度,注意参数顺序

**Troubleshooting**:

- sprite 翻转方向不对 — atan2 参数顺序错误,应该是 `y.atan2(x)`
