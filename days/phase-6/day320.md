
# Day 320 · 手算 2×2 矩阵求逆

> 昨天 Casey 给了 4×4 矩阵的逆公式,但理解这个公式需要先理解 2×2 矩阵的逆。今天 Casey 回到最简单的情况——2×2 矩阵,手算推导,把抽象概念具象化。

## 0 · 为什么要有这一天

昨天引入了 4×4 矩阵的逆,代码是 80 行 closed-form 公式,看着像"魔法"。直接背公式不是好工程师——你需要理解**为什么这个公式对**。

最简单的理解路径:**从 2×2 矩阵开始**。2×2 矩阵的逆只有 4 个元素,公式简洁,可以手算推导。理解了 2×2,3×3 和 4×4 的逆只是"展开更繁琐",思路完全一样。

```
2×2 矩阵的逆:
M = ┌ a b ┐     M⁻¹ = (1 / det) × ┌  d -b ┐
    │ c d │                        │ -c  a │
    └    ┘                        └       ┘

det(M) = ad - bc
```

公式很美——主对角线元素互换,副对角线元素取反,然后除以行列式。但为什么是这样?今天 Casey 一行一行推导。

更深一层的动机:**Casey 接下来要用 2×2 矩阵做"屏幕 → UV"的反向变换**。比如鼠标点击屏幕,要知道点到了哪个纹理像素,这是一个 2D 仿射变换(2×2 + 平移),需要 2×2 矩阵的逆。

心理锚点:今天之后你能"看到 2×2 矩阵的逆就秒懂",不再死记公式。这种"直觉优先"的数学能力是工程师的核心竞争力。

1. 从逆的定义出发:`M × M⁻¹ = I`
2. 设 `M⁻¹ = ┌ p q ┐`,解方程组

## 2 · 心智模型

### 类比:兑换钱币

把 2×2 矩阵想象成"货币兑换"。

- M 是"美元 → 欧元"的兑换汇率(2×2 因为有美元现金和美元支票两种)
- M⁻¹ 是"欧元 → 美元"的反向兑换

正反向兑换必须满足 `M⁻¹ × M = I`(兑换过去再兑换回来 = 没动)。如果某个兑换"亏本到把所有钱变 0"(det=0),就没有反向兑换——钱没了。

行列式 det 是"兑换的总量缩放"——det=2 表示兑换后钱变 2 倍,det=0.5 表示变一半。det=0 表示全亏光(降维),没有逆。

### 严谨原理:从定义推导

#### 第 1 步:定义

矩阵 M 的逆 M⁻¹ 满足:`M × M⁻¹ = I`(I 是单位矩阵)。

设 M 和 M⁻¹ 都是 2×2:

```
M = ┌ a b ┐    M⁻¹ = ┌ p q ┐
    │ c d │           │ r s │
    └    ┘           └     ┘
```

#### 第 2 步:写出方程

`M × M⁻¹ = I` 展开:

```
┌ a b ┐ × ┌ p q ┐ = ┌ 1 0 ┐
│ c d │   │ r s │   │ 0 1 │
└    ┘   └     ┘   └     ┘
```

矩阵乘法:`(M × M⁻¹)[i][j] = Σ M[i][k] × M⁻¹[k][j]`

逐元素展开:

```
(0,0): ap + br = 1
(0,1): aq + bs = 0
(1,0): cp + dr = 0
(1,1): cq + ds = 1
```

4 个方程,4 个未知数(p, q, r, s)。

#### 第 3 步:解方程

从 (0,1) 和 (1,0):

```
aq + bs = 0  →  q = -bs/a  (假设 a≠0)
cp + dr = 0  →  r = -cp/d  (假设 d≠0)
```

把 q 和 r 代入 (0,0) 和 (1,1):

```
ap + b(-cp/d) = 1
→ p(ad - bc) = d
→ p = d / (ad - bc)

a(-bs/a) + b(s) = ... wait, 我用 (1,1)
cq + ds = 1
→ c(-bs/a) + ds = 1
→ s(-bc/a + d) = 1
→ s(ad - bc)/a = 1
→ s = a / (ad - bc)
```

类似地:

```
q = -bs/a = -b/a × a/(ad-bc) = -b/(ad-bc)
r = -cp/d = -c/d × d/(ad-bc) = -c/(ad-bc)
```

所以:

```
M⁻¹ = ┌  d/(ad-bc)  -b/(ad-bc) ┐
      │ -c/(ad-bc)   a/(ad-bc) │
      └                        ┘

     = (1 / (ad - bc)) × ┌  d  -b ┐
                          │ -c   a │
                          └        ┘
```

设 `det = ad - bc`(行列式),公式简化:

```
M⁻¹ = (1 / det) × ┌  d  -b ┐
                  │ -c   a │
                  └        ┘
```

这就是经典的 2×2 矩阵求逆公式。

#### 第 4 步:为什么 det=0 时无逆

如果 `det = ad - bc = 0`,公式里除以 0,无定义。

几何意义:det 是矩阵变换的"面积缩放因子"。det=0 表示矩阵把 2D 空间压成 1D(一条线)或 0D(一个点)。压扁之后无法"还原"——多个不同的输入对应同一个输出,信息丢失。

具体例子:

```
M = ┌ 1 2 ┐    M 把 (x, y) → (x+2y, 2x+4y)
    │ 2 4 │
    └    ┘
det = 1×4 - 2×2 = 0

M × (1, 0) = (1, 2)
M × (2, -0.5) = (2 - 1, 4 - 2) = (1, 2)
两个不同输入 → 同一输出,信息丢失,无逆
```

#### 第 5 步:几何直觉

公式 `┌ d -b ┐` 的几何意义:
       `│ -c a │`
       `└    ┘`

- 主对角线 d 和 a:**互换**(本来 (a, d),变 (d, a))
- 副对角线 -b 和 -c:**取反**

为什么"互换 + 取反"?直觉:矩阵 M 的列向量是变换后的基向量。逆矩阵的列向量要"还原"这些基向量。2D 空间的还原 = "旋转 90° + 缩放 1/det"。旋转 90° 对应"主对角线互换、副对角线取反"。

```
M = ┌ a b ┐ 的列向量是 (a, c) 和 (b, d)。
    │ c d │
    └    ┘
M 把 (1,0) → (a, c),把 (0,1) → (b, d)。

M⁻¹ 的列向量要"把 (a, c) 还原回 (1, 0)":
┌  d -b ┌ × (a, c) = (da-bc, 0) = det × (1, 0) ✓
│ -c  a │
└      ┘
```

所以除以 det 是"补偿缩放",取反和互换是"旋转 90°"。整个公式有清晰几何意义,不是魔法。

### 3×3 和 4×4 推广

3×3 矩阵的逆也用类似公式,但展开后项数多。思路:

1. 算每个元素的"余子式"(cofactor):去掉该元素所在行列后剩余的 2×2 矩阵的行列式
2. 把所有余子式排成矩阵,加上正负号"棋盘格"(+ - + / - + - / + - +)
3. 转置,得到伴随矩阵(adjugate)
4. 除以 3×3 行列式

4×4 同理,只是余子式是 3×3 行列式(每个要再展开),计算量大但思路一致。Casey 昨天的 4×4 公式就是这样得来。

### Rust 实现

```rust
#[derive(Clone, Copy, Debug)]
struct Mat2 { m: [[f32; 2]; 2] }

impl Mat2 {
    fn det(&self) -> f32 {
        self.m[0][0] * self.m[1][1] - self.m[0][1] * self.m[1][0]
    }
    
    fn inverse(&self) -> Option<Self> {
        let d = self.det();
        if d.abs() < 1e-9 { return None; }
        let inv_d = 1.0 / d;
        Some(Mat2 {
            m: [
                [ self.m[1][1] * inv_d, -self.m[0][1] * inv_d],
                [-self.m[1][0] * inv_d,  self.m[0][0] * inv_d],
            ],
        })
    }
}
```

直接对应公式,易读。

### 3.4 · 🦀 Rust 生态视角

Rust 表达 2×2 矩阵:

```rust
// 用 newtype 区分 Mat2 和 [[f32; 2]; 2]
struct Mat2([[f32; 2]; 2]);

impl Mat2 {
    fn det(&self) -> f32 {
        let [[a, b], [c, d]] = self.0;
        a * d - b * c
    }
    
    fn inverse(&self) -> Option<Self> {
        let [[a, b], [c, d]] = self.0;
        let det = a * d - b * c;
        if det.abs() < 1e-9 { return None; }
        let inv_det = 1.0 / det;
        Some(Self([
            [ d * inv_det, -b * inv_det],
            [-c * inv_det,  a * inv_det],
        ]))
    }
}
```

注意 destructuring 模式匹配 `let [[a, b], [c, d]] = self.0` —— Rust 的模式匹配让矩阵代码非常清晰。这种写法在 C 里没有,是 Rust 的优势。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:2×2 矩阵的逆公式中,为什么副对角线元素要取反(b → -b, c → -c),而主对角线只是互换(a ↔ d)?

**参考解答**:

几何直觉:逆矩阵对应"反向变换"。2D 旋转 90° 把 (x, y) → (-y, x),这种"互换 + 取反"对应到矩阵上就是"主对角线互换、副对角线取反"。

代数证明:从 `M × M⁻¹ = I` 解方程,得到 `M⁻¹[i][j]` 的表达式。具体:
- `M⁻¹[0][0] = d/det`,即 `M[1][1]` 除以 det
- `M⁻¹[0][1] = -b/det`,即 `-M[0][1]` 除以 det(取反)
- 等等

主对角线互换是"位置变化",副对角线取反是"符号变化"——这是 2D 旋转的固有性质。

### Lv2 · 动手实践

**题**:在 Rust 里手写 2×2 矩阵求逆,验证多个例子。

**参考解答**:

```rust
#[derive(Clone, Copy, Debug, PartialEq)]
struct Mat2 { m: [[f32; 2]; 2] }

impl Mat2 {
    fn new(a: f32, b: f32, c: f32, d: f32) -> Self {
        Self { m: [[a, b], [c, d]] }
    }
    
    fn det(&self) -> f32 {
        let [[a, b], [c, d]] = self.m;
        a * d - b * c
    }
    
    fn inverse(&self) -> Option<Self> {
        let [[a, b], [c, d]] = self.m;
        let det = a * d - b * c;
        if det.abs() < 1e-9 { return None; }
        let inv_det = 1.0 / det;
        Some(Self::new(
             d * inv_det, -b * inv_det,
            -c * inv_det,  a * inv_det,
        ))
    }
    
    fn mul(&self, other: &Self) -> Self {
        let [[a, b], [c, d]] = self.m;
        let [[e, f], [g, h]] = other.m;
        Self::new(a*e + b*g, a*f + b*h, c*e + d*g, c*f + d*h)
    }
}

fn approx_eq(a: f32, b: f32) -> bool { (a - b).abs() < 1e-4 }

fn main() {
    // 测试 1:单位矩阵的逆 = 单位矩阵
    let i = Mat2::new(1.0, 0.0, 0.0, 1.0);
    let inv = i.inverse().unwrap();
    assert_eq!(inv.m, i.m);
    println!("✓ 单位矩阵的逆是自身");
    
    // 测试 2:旋转矩阵(45°)
    let s = std::f32::consts::FRAC_PI_4.sin();
    let c = std::f32::consts::FRAC_PI_4.cos();
    let rot = Mat2::new(c, -s, s, c);
    let inv = rot.inverse().unwrap();
    let prod = rot.mul(&inv);
    assert!(approx_eq(prod.m[0][0], 1.0) && approx_eq(prod.m[1][1], 1.0));
    assert!(approx_eq(prod.m[0][1], 0.0) && approx_eq(prod.m[1][0], 0.0));
    println!("✓ 旋转矩阵 × 逆 = 单位矩阵");
    
    // 测试 3:奇异矩阵无逆
    let singular = Mat2::new(1.0, 2.0, 2.0, 4.0);
    assert!(singular.inverse().is_none());
    println!("✓ 奇异矩阵正确返回 None");
    
    // 测试 4:缩放矩阵
    let scale = Mat2::new(2.0, 0.0, 0.0, 3.0);
    let inv = scale.inverse().unwrap();
    // 应该是 (1/2, 0; 0, 1/3)
    assert!(approx_eq(inv.m[0][0], 0.5));
    assert!(approx_eq(inv.m[1][1], 1.0/3.0));
    println!("✓ 缩放矩阵的逆 = 1/scale");
}
```

## 8 · Rust / Arch 落地代码

### Rust:2×2 矩阵完整 demo

```rust
// Cargo.toml: 无依赖
// src/main.rs

#[derive(Clone, Copy, Debug)]
struct Mat2 { m: [[f32; 2]; 2] }

impl Mat2 {
    fn new(a: f32, b: f32, c: f32, d: f32) -> Self {
        Self { m: [[a, b], [c, d]] }
    }
    
    fn det(&self) -> f32 {
        let [[a, b], [c, d]] = self.m;
        a * d - b * c
    }
    
    fn inverse(&self) -> Option<Self> {
        let [[a, b], [c, d]] = self.m;
        let det = a * d - b * c;
        if det.abs() < 1e-9 { return None; }
        let inv_det = 1.0 / det;
        Some(Self::new(
             d * inv_det, -b * inv_det,
            -c * inv_det,  a * inv_det,
        ))
    }
    
    fn mul(&self, other: &Self) -> Self {
        let [[a, b], [c, d]] = self.m;
        let [[e, f], [g, h]] = other.m;
        Self::new(a*e + b*g, a*f + b*h, c*e + d*g, c*f + d*h)
    }
    
    fn mul_vec(&self, x: f32, y: f32) -> (f32, f32) {
        let [[a, b], [c, d]] = self.m;
        (a*x + b*y, c*x + d*y)
    }
    
    fn pretty(&self, name: &str) {
        println!("{} = ┌ {:8.4} {:8.4} ┐", name, self.m[0][0], self.m[0][1]);
        println!("     │ {:8.4} {:8.4} │",       self.m[1][0], self.m[1][1]);
    }
}

fn main() {
    println!("=== 2×2 矩阵求逆演示 ===\n");
    
    // 例 1:简单矩阵
    let m = Mat2::new(4.0, 7.0, 2.0, 6.0);
    m.pretty("M   ");
    println!("det(M) = {}\n", m.det());
    
    let inv = m.inverse().expect("可逆");
    inv.pretty("M⁻¹ ");
    
    let prod = m.mul(&inv);
    prod.pretty("M×M⁻¹");
    println!("(应该是单位矩阵)\n");
    
    // 例 2:旋转 45°
    let theta = std::f32::consts::FRAC_PI_4;
    let rot = Mat2::new(theta.cos(), -theta.sin(), 
                        theta.sin(),  theta.cos());
    rot.pretty("Rot(45°)");
    println!("det(Rot) = {} (旋转保面积,det=1)\n", rot.det());
    
    // 应用:把向量 (1, 0) 旋转 45°
    let (rx, ry) = rot.mul_vec(1.0, 0.0);
    println!("Rot(45°) × (1, 0) = ({:.4}, {:.4})", rx, ry);
    println!("(应该是 (cos 45°, sin 45°) = ({:.4}, {:.4}))\n", 
             theta.cos(), theta.sin());
    
    // 反向:用逆把 (cos 45°, sin 45°) 还原到 (1, 0)
    let inv = rot.inverse().unwrap();
    let (ox, oy) = inv.mul_vec(rx, ry);
    println!("Rot⁻¹ × ({:.4}, {:.4}) = ({:.4}, {:.4})", rx, ry, ox, oy);
    println!("(应该是 (1, 0))\n");
    
    // 例 3:奇异矩阵
    let singular = Mat2::new(1.0, 2.0, 2.0, 4.0);
    singular.pretty("Sing");
    println!("det(Sing) = {} (det=0, 奇异)", singular.det());
    println!("Sing⁻¹ = {:?}", singular.inverse());
}
```

## 11 · 延伸讨论

数学推导的工程价值:从定义出发推导公式是数学家的方法,但工程师从'理解几何意义'出发往往更快。2x2 矩阵的逆:几何上是'反向变换'。旋转的逆 = 反向旋转;缩放的逆 = 1/scale;剪切的逆 = 反向剪切。这种直觉让你一眼看出'某个变换的逆是什么',不用算。
