# Day 377 · 改进碰撞体与相机

> Day 376 的 debug volume 暴露了一个问题:**玩家碰撞体太大,墙缝太窄**,玩家卡住。同时相机视角僵硬,转角看不清。今天 Casey 改进 collision volume 的精度(从 AABB 切到胶囊),并升级相机行为(平滑跟随 + 碰撞回避)。

## 0 · 为什么要有这一天

你跑 Day 376 的游戏,看 debug overlay。绿色的玩家 AABB 是个 1×2×1 的大盒子,蓝色的墙是 1×3×1 的盒子。玩家在转角处反复**撞墙、卡住、抖动**。问题:**AABB(轴对齐包围盒)对角色不合适**——角色是"有头有脚的胶囊",碰撞时应该让脚先撞,头能钻进矮檐;但 AABB 把整个角色当一个方盒子,转角时角的顶点先碰到墙,主角卡住。

工业游戏用 **capsule collider(胶囊碰撞体)**:一个圆柱 + 两个半球盖,形如药丸。胶囊的好处:
1. **无角**:转角不会卡(圆形截面平滑)
2. **上下 stairs 友好**:球盖部分能滑上楼梯
3. **物理正确**:近似人体(躯干 + 头 + 脚)

但**胶囊碰撞算法比 AABB 复杂**:capsule vs capsule、capsule vs plane、capsule vs AABB 都要专门写。Casey 今天会写核心几个。

第二个改进:**相机**。此前相机硬性跟随玩家(每帧 camera_pos = player_pos + offset),看起来"僵硬"。相机应该:
1. **平滑跟随**:位置滞后一点点,有惯性
2. **碰撞回避**:不穿墙
3. **自由旋转**:鼠标右键转视角

工业游戏的"第三人称相机"是个大话题。Casey 今天实现**平滑跟随 + 简单碰撞回避**,够用于教学。

心理锚点:今天之后,你能实现 capsule collider 和平滑第三人称相机,理解游戏工业的 collision / camera 标准做法。

## 2 · 心智模型

### 类比:胶囊像"瑜伽球 + 圆柱"

想象你抱瑜伽球(球)和长形抱枕(圆柱),拼成一个"药丸"形状——这就是 capsule。

球的好处:**任何方向接触都平滑**(球面任意点法线都是径向)。圆柱的好处:**沿轴向有长度**。组合 = 胶囊:沿轴是圆柱(等长),两端是半球(平滑盖)。

碰撞算法:把另一个物体"投影"到胶囊的轴上,看投影距离 vs 半径。

### 胶囊的几何

胶囊由两个端点 + 半径定义:

```
       ◢━━━━◣
      ╱      ╲
     │   a    │   ← 端点 a
     │   │    │
     │   │    │   ← 圆柱段
     │   │    │
     │   b    │   ← 端点 b
      ╲      ╱
       ◥━━━━◤

胶囊 = { 端点 a, b, 半径 r }
轴 line = (b - a) 的线段
```

碰撞:点到胶囊的最近距离 = 点到胶囊**轴线段**的距离 - 半径。如果 ≤ 0,碰撞。

### Capsule vs Point

```rust
fn capsule_vs_point(capsule: &Capsule, point: Vec3) -> bool {
    let closest = closest_point_on_segment(capsule.a, capsule.b, point);
    let dist_sq = (closest - point).length_squared();
    dist_sq <= capsule.radius * capsule.radius
}

fn closest_point_on_segment(a: Vec3, b: Vec3, p: Vec3) -> Vec3 {
    let ab = b - a;
    let t = (p - a).dot(ab) / ab.dot(ab);
    let t = t.clamp(0.0, 1.0);  // 钳制到 [0, 1],因为是线段
    a + ab * t
}
```

### Capsule vs Plane

平面方程:`normal · p = distance`。胶囊和平面相交 ⟺ 端点到平面的距离最小值 ≤ 半径。

```rust
fn capsule_vs_plane(capsule: &Capsule, plane: &Plane) -> bool {
    let d_a = plane.normal.dot(capsule.a) - plane.distance;
    let d_b = plane.normal.dot(capsule.b) - plane.distance;

    // 端点 a / b 到平面的有符号距离
    // 如果任一端点距离 < 半径,碰撞
    d_a.abs() <= capsule.radius || d_b.abs() <= capsule.radius
}
```

### Capsule vs AABB

最复杂。算法:

1. 找胶囊轴线段上离 AABB 最近的点
2. 找 AABB 上离那个点最近的点(AABB 上的最近点)
3. 计算两点距离,≤ 半径则碰撞

```rust
fn capsule_vs_aabb(capsule: &Capsule, aabb: &Aabb) -> bool {
    // 胶囊轴上离 AABB 最近的点
    let closest_on_capsule = closest_point_on_segment_to_aabb(
        capsule.a, capsule.b, aabb
    );
    // AABB 上离 closest_on_capsule 最近的点
    let closest_on_aabb = aabb.closest_point(closest_on_capsule);
    let dist_sq = (closest_on_capsule - closest_on_aabb).length_squared();
    dist_sq <= capsule.radius * capsule.radius
}

impl Aabb {
    fn closest_point(&self, p: Vec3) -> Vec3 {
        Vec3::new(
            p.x.clamp(self.min.x, self.max.x),
            p.y.clamp(self.min.y, self.max.y),
            p.z.clamp(self.min.z, self.max.z),
        )
    }
}
```

### Capsule vs Capsule

两个胶囊:各自找端点最近点,距离比较。

```rust
fn capsule_vs_capsule(c1: &Capsule, c2: &Capsule) -> bool {
    // 两个线段(c1.a-c1.b 和 c2.a-c2.b)的最近距离
    let (p1, p2) = closest_points_segment_segment(
        c1.a, c1.b, c2.a, c2.b
    );
    let dist_sq = (p1 - p2).length_squared();
    let r = c1.radius + c2.radius;
    dist_sq <= r * r
}
```

`closest_points_segment_segment` 是 3D 线段到线段最近点,涉及一些线性代数。

### 平滑跟随相机

```rust
pub struct FollowCamera {
    pub pos: Vec3,
    pub target_pos: Vec3,         // 相机的"理想"位置
    pub follow_lerp: f32,         // 0~1,越大越快跟
    pub look_target: Vec3,        // 相机看向哪里(通常是 player_pos)
}

impl FollowCamera {
    pub fn update(&mut self, dt: f32, player_pos: Vec3) {
        // 1. 计算 ideal target(player_pos + offset)
        let offset = Vec3::new(0.0, 5.0, -8.0);
        self.target_pos = player_pos + offset;

        // 2. 平滑插值
        let alpha = 1.0 - (-self.follow_lerp * dt * 60.0).exp();
        self.pos = self.pos.lerp(self.target_pos, alpha);

        // 3. 碰撞回避:从 player 到 camera_target 的射线
        let ray_dir = (self.pos - player_pos).normalize();
        let ray_dist = (self.pos - player_pos).length();
        if let Some(hit) = ray_vs_world(player_pos, ray_dir, ray_dist) {
            self.pos = player_pos + ray_dir * (hit.distance - 0.1);
        }
    }
}
```

`lerp` 的 `alpha` 用指数衰减(`1 - exp(-k*dt)`)而不是线性:`1 - (1-k)^dt` 让相机行为**帧率独立**(不同 dt 时跟随速度一致)。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏工业的碰撞体:

| 形状 | 适用 | 性能 | Casey 用 |
|---|---|---|---|
| AABB | 静态几何(墙) | 极快 | ✅ 用于墙 |
| OBB(定向盒) | 可旋转物体(车辆) | 中等 | ✕ |
| Sphere | 简单物体(球) | 极快 | ✕ |
| Capsule | 人形角色 | 中等 | ✅ 角色 |
| Convex hull | 精确碰撞 | 慢 | ✕ |
| Triangle mesh | 静态精确几何 | 慢 | ✕ |
| Heightfield | 地形 | 快 | ✕ |

**多形状组合**:复杂物体用多个简单形状组合。例如马匹 = 大胶囊(身躯)+ 4 小球(腿)。Unity / Unreal 支持多 collider 组合。

**碰撞检测的层次**:

```
Broad Phase(粗略)
  ↓ 用 BVH / 网格快速排除远距离对象
Narrow Phase(精确)
  ↓ 用具体形状求交
Response(响应)
  ↓ 推开 / 反弹
```

Broad phase 用 AABB 包裹所有物体快速过滤,Narrow phase 用真实形状精确算。Casey 在 Phase 8 做 BVH。

### 3.2 · 🎨 图形学视角

碰撞算法的图形学概念:

**GJK(Gilbert-Johnson-Keerthi)**

通用凸包 vs 凸包求交,通过 simplex 演化找最近点。物理引擎(Box2D, Bullet)默认算法。

**SAT(Separating Axis Theorem)**

两个凸包如果存在分离轴(投影不重叠),则不相交。OBB vs OBB 常用。3D OBB 最多 15 条候选轴(3+3+9)。

**Sphere-sphere**(最快)

```rust
fn sphere_vs_sphere(c1: Vec3, r1: f32, c2: Vec3, r2: f32) -> bool {
    let r = r1 + r2;
    (c2 - c1).length_squared() <= r * r
}
```

无 sqrt(用 length_squared),极快。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 capsule 比 AABB 更适合人形角色?AABB 在什么场景下更好?

**参考解答**:

Capsule 优势:
1. **无角**:转角处 capsule 截面是圆,平滑滑过;AABB 有角,转角处角顶点先碰墙,卡住
2. **踏步友好**:capsule 底部半球能"滑上"楼梯台阶;AABB 底部平,撞到台阶边缘卡住
3. **近似人形**:躯干圆柱 + 头部半球盖,合理近似人
4. **旋转自由**:capsule 沿轴旋转不影响碰撞(对称);AABB 转后碰撞盒变(OBB)

AABB 优势场景:
1. **静态几何**:墙、箱子、家具,不需要旋转,AABB 最快
2. **方形物体**:箱子、砖块,形状本来是 AABB
3. **空间划分**:BVH / 网格用 AABB 包裹,AABB 最简洁
4. **极高性能需求**:AABB 算法最少指令

工业做法:**静态世界 AABB + 角色 capsule + 投射物 sphere**,各取所长。

### Lv2 · 动手实践

**题**:实现 `Capsule` 结构 + `capsule_vs_aabb` / `capsule_vs_plane` / `closest_point_on_segment`。完成标准:
- 单元测试:点到线段最近点的精度 1e-5
- capsule_vs_aabb:已知碰撞 / 不碰撞场景测试通过
- capsule_vs_plane:站立在地板上(y=0),胶囊底部正好接触地板

**参考解答**:

```rust
use glam::Vec3;

#[derive(Copy, Clone, Debug)]
pub struct Capsule {
    pub a: Vec3,    // 端点 a(底部球盖中心)
    pub b: Vec3,    // 端点 b(顶部球盖中心)
    pub radius: f32,
}

impl Capsule {
    pub fn new(center: Vec3, half_height: f32, radius: f32) -> Self {
        let up = Vec3::new(0.0, 1.0, 0.0);
        Self {
            a: center - up * half_height,
            b: center + up * half_height,
            radius,
        }
    }

    pub fn center(&self) -> Vec3 {
        (self.a + self.b) * 0.5
    }
}

#[derive(Copy, Clone, Debug)]
pub struct Plane {
    pub normal: Vec3,
    pub distance: f32,
}

#[derive(Copy, Clone, Debug)]
pub struct Aabb {
    pub min: Vec3,
    pub max: Vec3,
}

impl Aabb {
    pub fn closest_point(&self, p: Vec3) -> Vec3 {
        Vec3::new(
            p.x.clamp(self.min.x, self.max.x),
            p.y.clamp(self.min.y, self.max.y),
            p.z.clamp(self.min.z, self.max.z),
        )
    }
}

pub fn closest_point_on_segment(a: Vec3, b: Vec3, p: Vec3) -> Vec3 {
    let ab = b - a;
    let ab_len_sq = ab.dot(ab);
    if ab_len_sq < 1e-10 {
        return a;  // 退化情况:a == b
    }
    let t = (p - a).dot(ab) / ab_len_sq;
    let t = t.clamp(0.0, 1.0);  // 限制到线段
    a + ab * t
}

pub fn capsule_vs_plane(capsule: &Capsule, plane: &Plane) -> bool {
    let d_a = plane.normal.dot(capsule.a) - plane.distance;
    let d_b = plane.normal.dot(capsule.b) - plane.distance;
    // 端点 a 和 b 到平面的距离(有符号)
    // 任一端点距离 ≤ 半径,即碰撞
    d_a.abs() <= capsule.radius || d_b.abs() <= capsule.radius
}

pub fn capsule_vs_aabb(capsule: &Capsule, aabb: &Aabb) -> bool {
    // 胶囊轴上离 AABB 中心最近的点(简化:用 AABB center 作为参考点)
    let aabb_center = (aabb.min + aabb.max) * 0.5;
    let closest_on_capsule_axis = closest_point_on_segment(capsule.a, capsule.b, aabb_center);

    // AABB 上离那个点最近的点
    let closest_on_aabb = aabb.closest_point(closest_on_capsule_axis);

    // 距离比较
    let diff = closest_on_capsule_axis - closest_on_aabb;
    let dist_sq = diff.dot(diff);
    dist_sq <= capsule.radius * capsule.radius
}

    fn test_capsule_vs_plane_standing() {
        let capsule = Capsule::new(Vec3::new(0.0, 1.0, 0.0), 0.5, 0.5);
        let floor = Plane { normal: Vec3::new(0.0, 1.0, 0.0), distance: 0.0 };
        assert!(capsule_vs_plane(&capsule, &floor));
        // 胶囊底部 a = (0, 0.5, 0),距离 floor = 0.5 = radius,正好接触
    }

    #[test]
    fn test_capsule_vs_aabb_overlap() {
        let capsule = Capsule::new(Vec3::new(0.0, 1.0, 0.0), 1.0, 0.5);
        let aabb = Aabb {
            min: Vec3::new(-1.0, 0.0, -1.0),
            max: Vec3::new(1.0, 2.0, 1.0),
        };
        assert!(capsule_vs_aabb(&capsule, &aabb));
    }
}
```

**关键解释**:
- `ab_len_sq < 1e-10` 检查退化(a 和 b 重合,线段是点),避免除零
- `t.clamp(0.0, 1.0)` 限制参数 t 到 [0, 1],因为线段(不是无限直线)
- `dist_sq <= radius²` 用距离平方比较,避免 sqrt

### Rust:胶囊 + 平滑跟随相机

```rust
// Cargo.toml: gl = "0.14", glfw = "0.55", glam = "0.29"

use glam::{Mat4, Vec3};
use glfw::{Context, Glfw, Window, WindowEvent};

// Capsule, Plane, Aabb 同 Lv2

pub struct Player {
    pub pos: Vec3,
    pub capsule: Capsule,
    pub velocity: Vec3,
}

impl Player {
    pub fn new(pos: Vec3) -> Self {
        Self {
            pos,
            capsule: Capsule::new(pos, 0.9, 0.4),
            velocity: Vec3::ZERO,
        }
    }

    pub fn update_capsule_position(&mut self) {
        self.capsule = Capsule::new(self.pos, 0.9, 0.4);
    }
}

pub struct FollowCamera {
    pub pos: Vec3,
    pub yaw: f32,
    pub pitch: f32,
    pub distance: f32,
    pub target_distance: f32,
    pub follow_speed: f32,
    pub sensitivity: f32,
}

impl FollowCamera {
    pub fn new() -> Self {
        Self {
            pos: Vec3::new(0.0, 5.0, -10.0),
            yaw: 0.0,
            pitch: 0.3,
            distance: 10.0,
            target_distance: 10.0,
            follow_speed: 8.0,
            sensitivity: 0.005,
        }
    }

    pub fn target_pos(&self, player_pos: Vec3) -> Vec3 {
        // 球面坐标:player + distance * direction
        let dir = Vec3::new(
            self.pitch.cos() * self.yaw.sin(),
            self.pitch.sin(),
            self.pitch.cos() * self.yaw.cos(),
        );
        player_pos - dir * self.distance
    }

    pub fn update(&mut self, dt: f32, player_pos: Vec3) {
        let target = self.target_pos(player_pos);

        // 帧率独立 lerp:alpha = 1 - exp(-k*dt)
        let alpha = 1.0 - (-self.follow_speed * dt).exp();
        self.pos = self.pos.lerp(target, alpha);

        // 碰撞回避(简化版)
        // 实际应该 raycast 检查,这里跳过
    }

    pub fn view_matrix(&self, player_pos: Vec3) -> Mat4 {
        Mat4::look_at_lh(self.pos, player_pos + Vec3::new(0.0, 1.5, 0.0), Vec3::Y)
    }

    pub fn process_mouse(&mut self, dx: f64, dy: f64) {
        self.yaw += dx as f32 * self.sensitivity;
        self.pitch -= dy as f32 * self.sensitivity;
        // 钳制 pitch 避免 gimbal lock
        let max_pitch = std::f32::consts::FRAC_PI_2 - 0.1;
        self.pitch = self.pitch.clamp(-max_pitch, max_pitch);
    }
}

pub fn process_input(
    window: &Window,
    player: &mut Player,
    camera: &mut FollowCamera,
    dt: f32,
) {
    let mut move_dir = Vec3::ZERO;

    let forward = Vec3::new(camera.yaw.sin(), 0.0, camera.yaw.cos());
    let right = Vec3::new(camera.yaw.cos(), 0.0, -camera.yaw.sin());

    if window.get_key(glfw::Key::W) == glfw::Action::Press {
        move_dir += forward;
    }
    if window.get_key(glfw::Key::S) == glfw::Action::Press {
        move_dir -= forward;
    }
    if window.get_key(glfw::Key::A) == glfw::Action::Press {
        move_dir -= right;
    }
    if window.get_key(glfw::Key::D) == glfw::Action::Press {
        move_dir += right;
    }

    if move_dir.length_squared() > 0.0 {
        move_dir = move_dir.normalize() * 5.0 * dt;
        player.pos += move_dir;
        player.update_capsule_position();
    }
}

fn main() {
    let mut glfw = glfw::init(glfw::FailOnError).unwrap();
    // (window hints, see day372)

    let (mut window, events) = glfw.create_window(1920, 1080, "Capsule + Camera", glfw::WindowMode::Windowed).unwrap();
    window.make_current();
    window.set_cursor_pos_polling(true);
    window.set_key_polling(true);
    // 隐藏鼠标,做 pointer lock
    window.set_cursor_mode(glfw::CursorMode::Disabled);

    let mut player = Player::new(Vec3::new(0.0, 1.0, 0.0));
    let mut camera = FollowCamera::new();

    let mut last_time = std::time::Instant::now();

    while !window.should_close() {
        let now = std::time::Instant::now();
        let dt = (now - last_time).as_secs_f32();
        last_time = now;

        glfw.poll_events();
        for (_, event) in events.try_iter() {
            if let WindowEvent::CursorPos(dx, dy) = event {
                camera.process_mouse(dx, dy);
            }
            if let WindowEvent::Key(glfw::Key::Escape, _, _, _) = event {
                window.set_should_close(true);
            }
        }

        process_input(&window, &mut player, &mut camera, dt);
        camera.update(dt, player.pos);

        let view = camera.view_matrix(player.pos);
        let proj = Mat4::perspective_lh(
            std::f32::consts::FRAC_PI_4,
            1920.0 / 1080.0,
            0.1, 100.0,
        );
        let view_proj = proj * view;

        // (rendering with view_proj)
        // (debug renderer: draw_aabb / draw_capsule)

        window.swap_buffers();
    }
}
```

**关键 Rust 特性解释**:
- `Vec3::ZERO` — glam 的常量,零向量
- `Vec3::Y` — glam 的常量,(0,1,0)
- `Vec3::lerp(self, other, t)` — glam 内置线性插值
- `1.0 - (-k * dt).exp()` — 指数衰减,alpha 在 dt 大时仍合理
- `CursorMode::Disabled` — pointer lock,鼠标锁定到窗口,FPS 视角用

**Troubleshooting**:

- **转角仍卡** — capsule 半径太大,调小。或者胶囊方向错(a/b 端点交换)
- **相机穿墙** — 没做碰撞回避。加 raycast 检查
- **鼠标逃出窗口** — pointer lock 没启用,`set_cursor_mode(Disabled)`
- **pitch 翻转** — 万向锁,pitch clamp 漏了
- **camera 跳跃** — dt 极大时(如断点暂停后),alpha 可能 > 1,clamp 一下
