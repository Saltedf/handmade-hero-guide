
# Day 402 · 给光照加光线投射

> Day 400 实现了 AO(Ambient Occlusion),Day 401 调试光照。今天 Casey 把 raycasting 技术复用到**新应用**——光照可见性。具体来说:从体素到光源发射射线,如果射线被挡,该体素**在阴影里**,直接光(diffuse + specular)被屏蔽,只剩 ambient + GI。这是**体素阴影**(voxel-based shadow)的实现——用同一套 DDA raycasting 代码,产出两种视觉效果(AO 和 shadow)。

## 0 · 为什么要有这一天

让我先描述一个真实场景。你跟着 Handmade Hero 走到 Day 401。你的渲染已经有 Phong 光照(ambient + diffuse + specular)+ AO。但打开游戏一看,**物体看起来"漂浮"**——球放在地面上,但球的下方地面没有黑色阴影,光好像穿过球照到了正下方。

这种"漂浮感"是**没有阴影**的标志。阴影是 3D 渲染最关键的视觉线索之一——它告诉人眼"物体真的站在地面上,不是悬空"。心理学实验证实:没有阴影的物体,人眼识别为"漂浮";有正确阴影的物体,人眼识别为"扎根"。**阴影是空间感的核心**。

**阴影的物理本质**:光从光源 L 出发,如果**在到达物体表面 P 前被其他物体 O 挡住**,该表面 P 在阴影里。换句话说,**L 和 P 之间不能有线段连接**(线段被几何挡住)。

**算法**(voxel 版本):

1. 对每个有几何的体素 V,从 V 中心向光源 L 发射射线
2. 用 DDA 在体素网格里步进,每步检查"是否进入非空体素"
3. 如果**到达 L 之前**撞到非空体素 → 被挡 → V 在阴影
4. 否则 → 可见 → V 在直接光下
5. 应用到光照公式:`shadow_factor = visible ? 1.0 : 0.0`
6. `final_color = ambient + (diffuse + specular) * shadow_factor + gi * ao`

**Hard shadow vs Soft shadow**:

- **Hard shadow**(今天实现):射线 binary(挡 / 不挡),阴影边界锐利
- **Soft shadow**(扩展):面光源(多个采样点)或多采样射线,边界渐变

Casey Day 402 只做 hard shadow(简单),后续 Day 403+ 可以扩展 soft(用 PCF:Percentage-Closer Filtering)。

**学完今天,你应该能**:

- 解释阴影的物理本质:光被几何挡住的部分
- 实现 voxel-based shadow:DDA raycasting 从体素到光源
- 区分直接光(diffuse + specular,需要 shadow)和间接光(ambient + GI,不需要 shadow)
- 处理**自遮挡**(self-occlusion)问题:射线起点偏移防"自己挡自己"
- 处理**漏光**(light leaking):体素分辨率不足导致的视觉错乱
- 对比工业阴影算法:shadow mapping、shadow volume、ray-traced shadows、voxel shadow
- 理解 ambient 不受 shadow 影响的原因——全局环境光来自四面八方
- 调试 shadow bug:漏光、阴影痤疮(acne,自遮挡)、Peter-panning(阴影离物体太远)

**今天的核心**:**复用已有算法到新应用**——Day 400 的 raycasting 用在 AO,今天同样的 raycasting 用在 shadow。**一次写,两次用**——这是工程效率的精髓。

### 为什么 ambient 和 GI 不受 shadow 影响

这是新人在写光照时常犯的错误。让我把原因讲透。

光照公式分**直接光**和**间接光**两类:

**直接光**:
- **Diffuse**:从光源 L 直接打到表面的光,被漫反射。如果 L 被挡,diffuse 消失。
- **Specular**:从光源 L 直接打到表面的光,被镜面反射(高光)。同样,如果 L 被挡,specular 消失。

**间接光**:
- **Ambient**:全局环境光。来自**四面八方的散射**——光打到墙壁、地面、天空,多次反射后到处都是。**没有明确的光源方向**,所以不能被"挡"——挡哪个方向?所有方向都有贡献。
- **GI(Global Illumination)**:间接光的精确版本。算法本身(如 voxel GI)已经基于可见性计算——光从其他体素到当前体素,被挡的部分已经被排除。再加 shadow 会**重复衰减**。

所以 shadow 只调制直接光(diffuse + specular),不调制间接光(ambient + GI)。AO 调制间接光,不调制直接光。两者职责分开:

```
final = ambient * (1 - ao)          // 间接光被 AO 调制
      + (diffuse + specular) * shadow  // 直接光被 shadow 调制
      + gi * ao                        // GI 也受 AO 调制
```

**真实物理的对应**:你站在树下,太阳光被树叶挡——你失去 diffuse 和 specular(没有高光、没有明亮面)。但你仍然看到周围环境——ambient 和 GI 保留(空气中的散射光)。

## 2 · 心智模型

### 2.1 类比:太阳和树

想象太阳下的树。树的影子投在地面。如果你站在树下:

- **光线**(从太阳到地面):被树挡
- **观察者**(你):同样被树挡——你看不见太阳

3D 阴影就是模拟"光被挡"——从光源出发的射线,被物体挡的部分,该位置在阴影。

更精确的物理:光是粒子流(光子)。被挡住 = 没有光子到达 = 暗。**没有"半挡"**(除非考虑衍射,可见光波长太短,宏观可忽略)。所以 hard shadow(二值:挡 / 不挡)对点光源是物理正确的。**Soft shadow** 来自面光源——太阳不是点,是有视角的圆盘,不同位置看挡得不一样,边界渐变。

### 2.2 Voxel Shadow 算法(完整 Rust)

```rust
use glam::Vec3;

pub struct VoxelGrid {
    pub voxels: Vec<bool>,        // 体素是否非空
    pub dims: (usize, usize, usize),
    pub voxel_size: f32,
    pub origin: Vec3,
}

/// 计算单个体素是否在阴影里
pub fn compute_shadow_at(
    grid: &VoxelGrid,
    position: Vec3,    // 体素世界坐标
    normal: Vec3,      // 体素法线(用于 bias)
    light_pos: Vec3,   // 光源位置
) -> f32 {
    let dir = (light_pos - position).normalize();
    // 关键 1: 起点偏移,防自遮挡
    let origin = position + normal * grid.voxel_size * 0.5;
    let distance = (light_pos - position).length();

    // 关键 2: DDA raycasting
    if ray_hits_voxel(grid, origin, dir, distance) {
        0.0  // 被挡,完全阴影
    } else {
        1.0  // 可见,完全直接光
    }
}

/// DDA 射线步进:从 origin 沿 dir 步进,检测是否撞到非空体素
fn ray_hits_voxel(
    grid: &VoxelGrid,
    origin: Vec3,
    dir: Vec3,
    max_dist: f32,
) -> bool {
    let mut p = origin;
    let mut t = 0.0;
    let step = grid.voxel_size * 0.5;  // 半体素步长

    while t < max_dist {
        p += dir * step;
        t += step;

        // 世界坐标 → 体素坐标
        let rel = (p - grid.origin) / grid.voxel_size;
        let (x, y, z) = (rel.x as i32, rel.y as i32, rel.z as i32);

        // 越界检查
        let (dx, dy, dz) = grid.dims;
        if x < 0 || x >= dx as i32 ||
           y < 0 || y >= dy as i32 ||
           z < 0 || z >= dz as i32 {
            break;  // 出网格,没撞
        }

        // 检查体素
        let idx = (z as usize * dx * dy + y as usize * dx + x as usize) as usize;
        if grid.voxels[idx] {
            return true;  // 撞到非空体素
        }
    }
    false
}
```

**关键参数**:

- **射线方向**:从体素到光源(`(light - pos).normalize()`)
- **起点偏移**:防自遮挡(`pos + normal * voxel_size * 0.5`)
- **最大距离**:到光源的距离(超出无意义)
- **步长**:半体素(`voxel_size * 0.5`),保证不漏体素

**优化**:步长可以是 1 体素而不是半体素(用 DDA 算法精确步进,每步进入新体素),性能提升 2 倍。Casey 在 Day 400 用 Amanatides-Woo DDA 算法。简化版用半体素步长,代码简单但慢 2 倍。

### 2.3 应用到光照(fragment shader)

```glsl
#version 450
uniform sampler3D shadow_texture;
uniform vec3 grid_min;
uniform vec3 grid_extent;
uniform vec3 light_pos;
uniform vec3 light_color;
uniform vec3 ambient_color;
uniform vec3 albedo;

in vec3 world_position;
in vec3 world_normal;
out vec4 frag_color;

void main() {
    vec3 N = normalize(world_normal);
    vec3 L = normalize(light_pos - world_position);

    // Phong components
    vec3 ambient = albedo * ambient_color;
    float diff = max(dot(N, L), 0.0);
    vec3 diffuse = albedo * light_color * diff;
    vec3 V = normalize(-world_position);
    vec3 R = reflect(-L, N);
    float spec = pow(max(dot(V, R), 0.0), 32.0);
    vec3 specular = vec3(0.8) * light_color * spec;

    // 采样 shadow grid
    vec3 shadow_uvw = (world_position - grid_min) / grid_extent;
    float shadow = texture(shadow_texture, shadow_uvw).r;

    // 应用:diffuse + specular 被 shadow 调制
    vec3 final = ambient + (diffuse + specular) * shadow;

    // (假设还有 AO 和 GI)
    // final += gi * ao;

    // Tone map (Reinhard)
    final = final / (final + vec3(1.0));

    // Gamma
    final = pow(final, vec3(1.0 / 2.2));

    frag_color = vec4(final, 1.0);
}
```

**关键步骤**:

- `world_position` 通过 unif 到 grid 坐标 → 采样 shadow_texture
- shadow 是 0 或 1(今天 hard shadow)
- diffuse 和 specular 乘以 shadow,ambient 不变
- Tone map(Reinhard)防过亮
- Gamma 校正输出

### 2.4 自遮挡问题(Self-occlusion)

**问题**:射线起点 = 体素中心。如果直接朝光源方向发射,**第一个体素是自己**(非空),立刻"撞",**所有像素都在阴影**。

**这是阴影渲染的经典 bug**,叫 **shadow acne**(阴影痤疮)——阴影表面有黑白斑点,像皮肤痤疮。

**修法**:

**方法 1:起点偏移**(Casey 用):

```glsl
vec3 origin = world_pos + normal * voxel_size * 0.5;
```

沿法线方向偏移半体素,跳出自己的体素。

**方法 2:跳过第一个体素**:DDA 步进时跳过起点体素。代码稍复杂。

**方法 3:bias 角度**:射线方向偏离 normal 一点,避免直接朝自己。但可能造成阴影错位。

工业级 shadow mapping 用方法 1 + depth bias(更精细)。

### 2.5 阴影漏光(Light Leaking)

**问题**:体素网格的分辨率有限,细小几何(如薄板)可能"漏"——射线穿过应该挡的体素。

**修法**:

- **更细体素**:64³ → 128³。但显存 8 倍。
- **Conservative voxelization**:三角形覆盖的所有体素都标(更准确)。Casey 在 Day 400+ 用了。
- **Shadow bias**:射线起点偏移更远。但可能错过真实遮挡。

工业级引擎(Unreal、Unity)用 sparse voxel octree(稀疏八叉树)——只在有几何的地方细化,既准确又省内存。

### 2.6 Hard vs Soft Shadow

**Hard shadow**(今天实现):

- 单点光源
- 射线 binary(0 或 1)
- 阴影边界锐利

**Soft shadow**(扩展):

- 面光源(N 个采样点,模拟太阳的圆盘形状)
- 每采样点算 hard shadow,平均
- 阴影边界渐变

```rust
pub fn compute_soft_shadow(
    grid: &VoxelGrid,
    position: Vec3,
    normal: Vec3,
    light_center: Vec3,
    light_radius: f32,
) -> f32 {
    let mut visible = 0;
    let n_samples = 8;
    for i in 0..n_samples {
        // 在光源圆盘上随机采样
        let offset = random_in_disk(i) * light_radius;
        let light_pos = light_center + offset;
        if compute_shadow_at(grid, position, normal, light_pos) > 0.5 {
            visible += 1;
        }
    }
    visible as f32 / n_samples as f32
}
```

**PCF**(Percentage-Closer Filtering):在 shadow map 上做滤波,类似 soft shadow 但成本更低。Casey Day 402 只做 hard。

工业级 soft shadow:

- **PCSS**(Percentage-Closer Soft Shadows):根据距离动态调整 PCF 核大小,近处清晰远处模糊。NVIDIA 2005。
- **VSM**(Variance Shadow Maps):用统计滤波,快但精度低。
- **Ray-traced shadows**(RTX):GPU 光线追踪,完美但需 RTX 显卡。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

工业界阴影算法谱系:

**Shadow mapping**(1978):光源视角渲染深度纹理,主视角采样,比较深度。经典但分辨率有限——远离光源的阴影锯齿严重。

**Shadow volume**(1991, Heidmann;也叫 stencil shadow):几何构造阴影体积(从物体轮廓拉伸到无穷远),stencil test 决定像素是否在体积内。质量高(像素精度)但复杂(轮廓提取、 stencil 操作)。**DOOM 3** 用这个,质量惊艳。

**PCF / PCSS**:shadow map + 滤波,soft shadow。现代引擎默认。

**Voxel shadow**(今天):用体素网格做 raycasting。**复用 voxel GI 的网格**,一石二鸟。CryEngine 的 SVOTI(Sparse Voxel Octree GI)就是这样。

**Ray-traced shadows**(RTX 2018+):GPU 光线追踪,完美但慢。Cyberpunk 2077 用。

**Shadow map vs Voxel shadow**:

| | Shadow map | Voxel shadow |
|---|---|---|
| 准确性 | 高(像素精度) | 中(体素精度) |
| 显存 | 一张 2D 纹理(8 MB) | 体素网格(64MB-1GB) |
| 适合 | 直接光 | GI + 阴影统一 |
| Soft shadow | PCF / PCSS | 多采样(贵) |
| 动态更新 | 每帧重渲 | 体素稀疏更新 |

Casey 选 voxel shadow 因为 voxel GI 已经存在,**复用网格**几乎免费。如果项目没 voxel GI,选 shadow map 更简单。

### 3.2 · 🎨 图形学视角

**阴影的物理**:光是粒子(光子),被挡住就是挡住。**没有"半挡"**(除非衍射,可见光波长短,宏观忽略)。

**Shadow ray** 在 path tracing 里就是从片元到光源的射线,被挡 = 在阴影。这是物理最忠实的实现,RTX 用这个。

**Voxel shadow** 是 voxel GI 的副产品——体素网格已存在,直接复用 raycasting。**优势**:统一了 GI 和 shadow 计算,**劣势**:精度受体素分辨率限制。

**Soft shadow 的物理本质**:真实光源不是点,是有面积的(太阳视角圆盘)。从物体边缘不同位置看,挡的部分不同——所以边界渐变。模拟方法:对光源采样多次,每次算 hard shadow,平均。

**Ambient occlusion vs Shadow**:

- **AO**:模拟 ambient 光的遮挡(全局光被几何挡)。
- **Shadow**:模拟直接光的遮挡(点光源被几何挡)。

两者算法相似(都是 raycasting 检测遮挡),但**应用的光照项不同**——AO 调制 ambient,Shadow 调制 diffuse + specular。

### 3.3 · 🐧 Linux 系统编程视角

Voxel shadow 性能分析:

```bash
# 64³ 体素 = 262144 体素
# 每非空体素 1 射线 × 平均 30 DDA 步 = 30 操作
# 非空率 ~10% = 26000 体素
# 总操作 = 262144 × 0.1 × 30 = 786432 ≈ 0.8M
# GPU <1ms,可接受

# 测性能
sudo pacman -S perf
perf stat -e instructions,cache-misses ./your_game

# CPU 版本(测试床)慢 100 倍
# 0.8M 操作 × 5 ns/op = 4 ms
# 一帧 16ms 预算,够 4 个光源

# GPU 版本(compute shader)
# 一帧 1ms,够 16 个光源
```

**GPU 优化**:

- **Early-exit**:射线撞到非空体素立即返回
- **Coherent rays**:相邻体素的射线方向接近,可 SIMD
- **Hierarchical DDA**:用稀疏八叉树,粗步进先找大致区域

### 3.4 · 🦀 Rust 生态视角

Rust 端 shadow 计算(测试床):

```rust
pub fn compute_shadow_grid(
    voxel_grid: &VoxelGrid,
    light_pos: Vec3,
) -> Vec<f32> {
    let mut shadow = vec![1.0; voxel_grid.voxels.len()];
    let (dx, dy, dz) = voxel_grid.dims;

    // 三重循环遍历所有体素
    for k in 0..dz {
        for j in 0..dy {
            for i in 0..dx {
                let idx = k * dx * dy + j * dx + i;
                if !voxel_grid.voxels[idx] { continue; }  // 空体素跳过

                let pos = voxel_grid.origin
                    + Vec3::new(i as f32, j as f32, k as f32)
                    * voxel_grid.voxel_size;
                let normal = Vec3::new(0.0, 1.0, 0.0);  // 简化:固定 up
                let origin = pos + normal * voxel_grid.voxel_size * 0.5;

                let dir = (light_pos - pos).normalize();
                let dist = (light_pos - pos).length();
                let visible = !ray_hits_voxel(voxel_grid, origin, dir, dist);
                shadow[idx] = if visible { 1.0 } else { 0.0 };
            }
        }
    }
    shadow
}
```

**Rust 优化**:

- 用 `rayon` 并行化外层循环
- 用 `ndarray` 替代 Vec<Vec<Vec>>,提升 cache locality
- 用 `glam::Vec3` 而不是 `[f32; 3]`,启用 SIMD

**Rust GPU 集成**:用 `wgpu` compute shader。Casey 用 OpenGL 4.3 compute shader(Rust 用 `glam` + `wgpu` 等价)。

## 7 · 变式训练

### Lv1 · 概念辨析(读懂)

**题**:shadow 调制 diffuse 和 specular,不调制 ambient 和 GI。为什么?

**参考解答**:

- **Diffuse + Specular** 来自**直接光**(明确光源)。如果光被挡,这两项消失。
- **Ambient** 是全局环境散射,来自所有方向,不能"挡"(挡哪个方向?)
- **GI** 是间接光,**已经考虑了遮挡**(GI 算法本身基于可见性)。再加 shadow 会**重复衰减**。

所以 shadow 只调制直接光(diffuse + specular)。AO 调制间接光(ambient + GI)。两者职责分开。

公式上:

```
final = ambient * (1 - ao)               // AO 调制 ambient
      + (diffuse + specular) * shadow    // Shadow 调制直接光
      + gi * ao                          // AO 也调制 GI
```

AO 和 Shadow 是**正交的两类遮挡**——AO 是间接光的遮挡,Shadow 是直接光的遮挡。两者都要算,但不互相调制。

### Lv2 · 动手实践

**题**:在 Day 400 AO 基础上加 shadow 计算。从每体素到固定光源发射射线,输出 shadow grid。

完成标准:shadow grid 大小 = voxel grid 大小,值域 [0, 1]。能可视化(把 shadow 作为颜色画出来)。

**完整代码**(简化版):

```rust
use glam::Vec3;

pub struct VoxelGrid {
    pub voxels: Vec<bool>,
    pub dims: usize,  // 立方体网格,dims × dims × dims
    pub voxel_size: f32,
    pub origin: Vec3,
}

pub fn compute_shadow_at(
    grid: &VoxelGrid,
    position: Vec3,
    normal: Vec3,
    light_pos: Vec3,
) -> f32 {
    let dir = (light_pos - position).normalize();
    let origin = position + normal * grid.voxel_size * 0.5;  // 防自遮挡
    let dist = (light_pos - position).length();
    if ray_hits_voxel(grid, origin, dir, dist) { 0.0 } else { 1.0 }
}

fn ray_hits_voxel(grid: &VoxelGrid, origin: Vec3, dir: Vec3, max_dist: f32) -> bool {
    let mut p = origin;
    let mut t = 0.0;
    let step = grid.voxel_size * 0.5;
    while t < max_dist {
        p += dir * step;
        t += step;
        let rel = (p - grid.origin) / grid.voxel_size;
        let (x, y, z) = (rel.x as i32, rel.y as i32, rel.z as i32);
        if x < 0 || x >= grid.dims as i32 ||
           y < 0 || y >= grid.dims as i32 ||
           z < 0 || z >= grid.dims as i32 { break; }
        let idx = (z as usize * grid.dims * grid.dims
            + y as usize * grid.dims + x as usize) as usize;
        if grid.voxels[idx] { return true; }
    }
    false
}

pub fn compute_shadow_grid(grid: &VoxelGrid, light_pos: Vec3) -> Vec<f32> {
    let mut shadow = vec![1.0; grid.voxels.len()];
    for k in 0..grid.dims {
        for j in 0..grid.dims {
            for i in 0..grid.dims {
                let idx = k * grid.dims * grid.dims + j * grid.dims + i;
                if !grid.voxels[idx] { continue; }
                let pos = grid.origin
                    + Vec3::new(i as f32, j as f32, k as f32)
                    * grid.voxel_size;
                let normal = Vec3::new(0.0, 1.0, 0.0);  // 简化
                shadow[idx] = compute_shadow_at(grid, pos, normal, light_pos);
            }
        }
    }
    shadow
}
```

mod tests {
    use super::*;

    #[test]
    fn light_above_no_block_is_lit() {
        let mut grid = VoxelGrid {

            voxel_size: 1.0,
            origin: Vec3::new(0.0, 0.0, 0.0),

    }

### Lv3 · 迁移设计

**题**:shadow raycasting 思路迁移到**AI 视野**——NPC 判断"能否看到玩家"。

需求:

- NPC 位置 = 体素(简化)
- 玩家位置 = "光源"
- 射线被挡 = 看不见(玩家在 NPC 视觉阴影里)

```rust
pub struct Npc {
    pos: Vec3,
    view_distance: f32,
    field_of_view: f32,  // 视野张角,弧度
}

impl Npc {
    pub fn can_see(&self, target: Vec3, grid: &VoxelGrid) -> bool {
        let to_target = target - self.pos;
        let dist = to_target.length();
        if dist > self.view_distance { return false; }

        // FOV 检查:玩家在 NPC 前方?
        let forward = Vec3::new(0.0, 0.0, 1.0);  // 简化:NPC 永远朝 +Z
        let dir_to_target = to_target.normalize();
        let cos_angle = forward.dot(dir_to_target);
        if cos_angle < (self.field_of_view / 2.0).cos() { return false; }

        // 视线遮挡检查
        let normal = forward;  // bias
        let origin = self.pos + normal * grid.voxel_size * 0.5;
        !ray_hits_voxel(grid, origin, dir_to_target, dist)
    }
}
```

// src/main.rs
use glam::Vec3;

pub struct VoxelGrid {
    pub voxels: Vec<bool>,
    pub dims: usize,
    pub voxel_size: f32,
    pub origin: Vec3,
}

pub fn compute_shadow_at(
    grid: &VoxelGrid,
    position: Vec3,
    normal: Vec3,
    light_pos: Vec3,
) -> f32 {
    let dir = (light_pos - position).normalize();
    let origin = position + normal * grid.voxel_size * 0.5;
    let dist = (light_pos - position).length();
    if ray_hits_voxel(grid, origin, dir, dist) { 0.0 } else { 1.0 }
}

fn ray_hits_voxel(grid: &VoxelGrid, origin: Vec3, dir: Vec3, max_dist: f32) -> bool {
    let mut p = origin;
    let mut t = 0.0;
    let step = grid.voxel_size * 0.5;
    while t < max_dist {
        p += dir * step;
        t += step;
        let rel = (p - grid.origin) / grid.voxel_size;
        let (x, y, z) = (rel.x as i32, rel.y as i32, rel.z as i32);
        if x < 0 || x >= grid.dims as i32 ||
           y < 0 || y >= grid.dims as i32 ||
           z < 0 || z >= grid.dims as i32 { break; }
        let idx = z as usize * grid.dims * grid.dims
            + y as usize * grid.dims + x as usize;
        if grid.voxels[idx] { return true; }
    }
    false
}

pub fn compute_shadow_grid(grid: &VoxelGrid, light_pos: Vec3) -> Vec<f32> {
    let mut shadow = vec![1.0; grid.voxels.len()];
    for k in 0..grid.dims {
        for j in 0..grid.dims {
            for i in 0..grid.dims {
                let idx = k * grid.dims * grid.dims + j * grid.dims + i;
                if !grid.voxels[idx] { continue; }
                let pos = grid.origin
                    + Vec3::new(i as f32, j as f32, k as f32)
                    * grid.voxel_size;
                let normal = Vec3::new(0.0, 1.0, 0.0);
                shadow[idx] = compute_shadow_at(grid, pos, normal, light_pos);
            }
        }
    }
    shadow
}

fn main() {
    let dims = 16usize;
    let mut grid = VoxelGrid {
        voxels: vec![false; dims * dims * dims],
        dims,
        voxel_size: 0.1,
        origin: Vec3::new(-0.8, -0.8, -0.8),
    };

    // 地面:y=0 平面所有 (x, z) 都填充
    for x in 0..dims {
        for z in 0..dims {
            grid.voxels[0 * dims * dims + 0 * dims + x] = true;
            grid.voxels[0 * dims * dims + z * dims + 0] = true;
        }
    }
    // 地面整体填充 y=0
    for x in 0..dims {
        for z in 0..dims {
            grid.voxels[0 * dims * dims + z * dims + x] = true;
        }
    }
    // 球:中心 (8, 5, 8),简化为几个体素
    grid.voxels[5 * dims * dims + 8 * dims + 8] = true;
    grid.voxels[5 * dims * dims + 7 * dims + 8] = true;
    grid.voxels[5 * dims * dims + 9 * dims + 8] = true;
    grid.voxels[5 * dims * dims + 8 * dims + 7] = true;
    grid.voxels[5 * dims * dims + 8 * dims + 9] = true;

    let light = Vec3::new(0.5, 1.0, 0.5);  // 斜上方
    let shadow = compute_shadow_grid(&grid, light);

    let shadowed = shadow.iter().filter(|&&s| s < 0.5).count();
    let lit = shadow.iter().filter(|&&s| s > 0.5).count();
    println!("=== Voxel Shadow Demo ===");
    println!("Voxels: {} total", grid.voxels.len());
    println!("Non-empty: {}", grid.voxels.iter().filter(|&&v| v).count());
    println!("Shadowed: {}", shadowed);
    println!("Lit: {}", lit);
    println!("Light pos: {:?}", light);

    // 可视化:打印 y=0 平面的 shadow
    println!("\nShadow map at y=0 (X = shadowed, . = lit):");
    for z in 0..dims {
        let mut line = String::new();
        for x in 0..dims {
            let idx = 0 * dims * dims + z * dims + x;
            line.push(if shadow[idx] < 0.5 { 'X' } else { '.' });
        }
        println!("  {}", line);
    }
}

### 8.4 Troubleshooting

**问题1**:所有体素都在阴影(self-occlusion)。
解决:加 origin 偏移:`origin = position + normal * voxel_size * 0.5`。

**问题2**:某些应该阴影的位置漏光。
解决:体素分辨率不够。增大 `dims`(64 → 128),或用 conservative voxelization。

**问题3**:阴影边界锯齿(hard shadow 的本质)。
解决:实现 soft shadow(多采样)或 PCF 滤波。

**问题4**:性能慢(CPU 版本 > 10ms)。
解决:并行化(rayon)、SIMD(glam)、GPU compute shader。
