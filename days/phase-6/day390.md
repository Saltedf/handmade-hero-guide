
# Day 390 · 加简单 Phong 光照

> Lambert 漫反射让球有"立体感",但物体表面**没有高光**(specular highlight)。今天 Casey 加 **Phong 光照模型**——在 Lambert 基础上加 specular 项,模拟镜面反射。这是 1975 年的经典模型,简单但实用,是 99% 的 3D 游戏光照基础。

## 0 · 为什么要有这一天

Lambert 漫反射只描述了"粗糙表面"——光线从某个方向来,**均匀散射**到所有方向。但真实物体不全是粗糙的:

- **金属**(钥匙、车漆)有镜面反射——光从一个方向来,从另一个特定方向反射出去,看起来是亮闪闪的高光
- **塑料**(玩具)也有镜面反射,但比金属弱
- **木头 / 布**几乎没有镜面反射,主要是漫反射
- **镜子**(玻璃)几乎全是镜面反射

**Phong 光照模型**(Bui Tuong Phong, 1975)在 Lambert 基础上加了 **specular 项**:

```
final = ambient + diffuse + specular
      = albedo × ambient_color
      + albedo × light_color × max(0, dot(N, L))
      + specular_color × light_color × max(0, dot(R, V))^shininess
```

其中:

- **R** = 反射向量(光从 L 方向来,从 R 方向反射出去)
- **V** = 视线方向(从片元指向相机)
- **shininess** = 光泽度(越大,高光越小越尖锐)

**为什么 `dot(R, V)^shininess`**?

镜面反射的物理:**光从 L 方向来,以 N 为法线反射到 R 方向**(根据反射定律:入射角 = 反射角)。如果你眼睛(V 方向)正好在 R 方向,你看到完全反射的高光。如果你偏离 R 方向,看到的反射弱(因为光不是完美镜面,有散射)。

**Phong 用 `dot(R, V)^shininess`** 模拟"偏离 R 的衰减":

- shininess 小(如 1):衰减慢,高光大而模糊
- shininess 大(如 100):衰减快,高光小而尖锐
- shininess 无穷大:完美镜面,只有 R=V 时才看到高光

**Blinn-Phong 优化**(1977, Jim Blinn):用 **半向量 H**(half vector)代替 R:

- `H = normalize(L + V)`(光方向和视线方向的中间方向)
- `dot(N, H)^shininess` 代替 `dot(R, V)^shininess`
- 数学等价但计算更快(避免算反射向量 R)
- shininess 数值要 ×4 才和 Phong 等价

工业界**几乎全用 Blinn-Phong**(因为快),但教学先讲 Phong(因为直观)。

今天的产出:**球有镜面高光**——右上角一个亮斑,随着相机移动高光位置变化。这是 3D 渲染"质感"的关键。

心理锚点:看完今天,你能(1)推导反射向量公式 `R = 2(N·L)N - L`;(2)实现 Phong 和 Blinn-Phong shader;(3)理解 shininess 参数的物理意义;(4)解释为什么 Phong 比 Lambert 更"真实"。

## 2 · 心智模型

### 类比:镜子 vs 哑光墙

想象一面镜子和一面哑光墙,都面对同一个光源。

- **镜子**:光从 L 来,严格按反射定律反射到 R 方向。你站在 R 方向看到光源的像(亮)。站在其他方向看不到(暗)。
- **哑光墙**:光从 L 来,均匀散射到所有方向。从任何角度看都差不多亮。

**真实物体在两者之间**——主要是漫反射,但有一点点镜面反射。Phong 模型 = Lambert(漫反射) + 镜面项。

**Shininess(光泽度)**控制"镜面反射的尖锐程度":

- shininess = 1:像哑光金属(高光散射,大模糊斑点)
- shininess = 32:像塑料(中等高光)
- shininess = 128:像镜面不锈钢(尖锐亮点)
- shininess = 1024:像镜子(只有完美反射方向才看到)

### 严谨推导:反射向量

光从 L 方向**射向**表面。入射向量(从光指向表面)是 `-L`(假设 L 是从表面指向光源)。反射后,光沿 R 方向**离开**表面。

**反射定律**:入射角 = 反射角(都是相对法线的角度)。

**推导**:

```
入射向量 I = -L(从光指向表面)
法线 N(垂直于表面)

把 I 分解成"沿 N"和"垂直 N"两个分量:
I = I_parallel + I_perp
其中 I_parallel = (I · N) N  (沿 N)
     I_perp = I - I_parallel  (垂直 N)

反射时:
- 平行分量反向(像球撞地反弹)
- 垂直分量不变

R = -I_parallel + I_perp
  = -(I · N) N + (I - (I · N) N)
  = I - 2(I · N) N

把 I = -L 代入:
R = -L - 2(-L · N) N
  = -L + 2(L · N) N
  = 2(N · L) N - L
```

所以**反射向量**:`R = 2(N · L) N - L`。

GLSL 提供 `reflect(I, N)` 内置函数,但要注意 `reflect` 的 I 是"从光指向表面"(即 `-L`)。

```glsl
vec3 R = reflect(-L, N);  // 等价于 2 * dot(N, L) * N - L
```

### Phong Specular 公式

```
specular = specular_color × light_color × max(0, dot(R, V))^shininess
```

其中:

- **R** = 反射向量(光反射后的方向)
- **V** = 视线方向(从片元指向相机)
- **shininess** = 光泽度

**为什么是 dot(R, V)**?如果你眼睛正好在 R 方向(V = R),`dot(R, V) = dot(R, R) = |R|^2 = 1`(单位向量),`specular = specular_color × light_color × 1`(最大)。如果你偏离 R,`dot(R, V)` 减小,specular 减弱。

**为什么 `^shininess`**?`dot(R, V)` 在 [0, 1],平方让它更快衰减——shininess=32 时,`dot=0.9` 给出 `0.9^32 ≈ 0.034`(基本黑)。这让高光"尖锐"。

shininess 越大,高光越尖锐。

**为什么 `max(0, ...)`**?如果 R 和 V 夹角 > 90°(眼睛在反射背后),dot 是负,clamp 到 0。

### Blinn-Phong 优化

Blinn-Phong 用 **half vector** H 代替 R:

```
H = normalize(L + V)  // L 和 V 的中间方向
specular = specular_color × light_color × max(0, dot(N, H))^shininess_blinn
```

**数学等价**:Blinn-Phong 的 `dot(N, H)` 等价于 Phong 的 `dot(R, V)` 的某种变换。具体:角度关系 `dot(N, H) = cos(α)`,`dot(R, V) = cos(2α)`,所以 `dot(N, H)^shininess_blinn ≈ dot(R, V)^(shininess_blinn / 2)`。

**结论**:Blinn-Phong 的 shininess 大约是 Phong 的 4 倍,得到相同视觉效果的"尖锐度"。

**为什么 Blinn-Phong 更快**?

- Phong 需要算 R(向量运算 + dot + 乘法,约 6 次乘加)
- Blinn-Phong 算 H 只需要 L + V + normalize(约 4 次乘加)

差距不大,但每像素节省几纳秒,1080p × 数百万像素累加,差别显著。工业界用 Blinn-Phong。

** specular_color 的物理意义**:

- **绝缘体**(塑料、玻璃)的 specular_color 是白色的(`(1, 1, 1)`)——所有波长的光都同样反射
- **金属**(铜、金)的 specular_color 是金属色的——金子的 specular 是金黄(`(1, 0.7, 0.3)`),铜是铜色
- 物体的"金属感"来自 specular_color 是否 = albedo(金属)还是白色(非金属)

PBR 把这个简化为 "metallic" 参数(0 = 绝缘,1 = 金属),自动计算 specular_color。

### Phong 完整公式

```
final = ambient + diffuse + specular

ambient = albedo * ambient_color
diffuse = albedo * light_color * max(0, dot(N, L))
specular = specular_color * light_color * pow(max(0, dot(R, V)), shininess)
```

注意:

- ambient 和 diffuse 用 **albedo**(漫反射颜色)
- specular 用 **specular_color**(独立颜色)
- 三项加起来,可能超过 1.0(HDR),需要 tone map

GLSL 实现:

```glsl
#version 330

in vec3 v_world_normal;
in vec3 v_world_position;
in vec2 v_uv;

uniform sampler2D albedo_tex;
uniform vec3 light_dir;        // 指向光源
uniform vec3 light_color;
uniform vec3 ambient_color;
uniform vec3 camera_pos;       // 相机世界坐标
uniform vec3 specular_color;
uniform float shininess;

out vec4 frag_color;

void main() {
    // Albedo
    vec3 albedo = texture(albedo_tex, v_uv).rgb;
    albedo = pow(albedo, vec3(2.2));  // sRGB → Linear

    // 法线和光源方向
    vec3 N = normalize(v_world_normal);
    vec3 L = normalize(light_dir);

    // Ambient + Diffuse
    float diff = max(0.0, dot(N, L));
    vec3 ambient = albedo * ambient_color;
    vec3 diffuse = albedo * light_color * diff;

    // Specular
    vec3 V = normalize(camera_pos - v_world_position);  // 视线方向
    vec3 R = reflect(-L, N);  // 反射向量(注意 reflect 的入参方向)
    float spec = pow(max(0.0, dot(R, V)), shininess);
    vec3 specular = specular_color * light_color * spec;

    // 合成
    vec3 final = ambient + diffuse + specular;
    // Tone map(简化 Reinhard)
    final = final / (final + vec3(1.0));
    // Linear → sRGB
    final = pow(final, vec3(1.0 / 2.2));

    frag_color = vec4(final, 1.0);
}
```

**每段解释**:

- `camera_pos - v_world_position`:从片元指向相机,即 V 方向
- `reflect(-L, N)`:`reflect(I, N)` 中 I 是"指向表面的入射方向",所以是 `-L`(L 指向光源,-L 指向表面)
- `pow(max(0, dot(R, V)), shininess)`:高光强度。`shininess=32` 时典型塑料,`shininess=128` 时典型金属
- 三项加起来 + tone map + sRGB 转换,最终输出

### Blinn-Phong 完整公式

```glsl
// Blinn-Phong 版本(替换上面的 Specular 部分)
vec3 H = normalize(L + V);
float spec_blinn = pow(max(0.0, dot(N, H)), shininess * 4.0);  // ×4 调整
vec3 specular = specular_color * light_color * spec_blinn;
```

注意 shininess × 4 的调整(否则 Blinn 的高光比 Phong 大)。

### Shininess 的物理意义

shininess 对应"表面微观粗糙度":

- shininess 高 = 表面平滑 = 微表面都对齐 = 镜面反射强 = 高光尖锐
- shininess 低 = 表面粗糙 = 微表面随机 = 反射散射 = 高光模糊

PBR 用 "roughness" 参数(0..1,1 = 完全粗糙,0 = 完全平滑)代替 shininess,转换公式:`shininess = pow(2.0 / (roughness^4 + 0.0001), 2.0)`(某种近似)。

### Fresnel 效应(进阶)

真实金属在掠射角(视线和法线夹角接近 90°)时反射率增大。这叫 **Fresnel 效应**。Phong 不模拟 Fresnel,所以**掠射角的金属看起来不够"金属"**。PBR 加 Fresnel(Schlick 近似)修这个。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏里 Phong / Blinn-Phong 的应用:

- **角色 / 道具**:Blinn-Phong 主导,加 normal map 增加细节
- **环境 / 建筑**:Blinn-Phong + lightmap(预计算)
- **金属表面**:shininess 高(128+),specular_color 是金属色
- **皮肤**:shininess 低(8-16),specular_color 偏白色(油脂)
- **水面**:shininess 极高(256+),specular_color 白色

**shininess 的工程值**:

| 材质 | shininess |
|---|---|
| 粉笔 / 哑光漆 | 2-8 |
| 皮肤 | 8-20 |
| 木头 | 16-32 |
| 塑料 | 32-64 |
| 抛光金属 | 64-256 |
| 玻璃 / 镜子 | 256-1024 |

**多光源 Phong**:每个光源算一次 Phong,加起来。光源多时性能差,工业界用 deferred shading(把 Phong 放到 lighting pass)。

### 3.2 · 🎨 图形学视角

**Phong vs Blinn-Phong vs PBR**:

| | Phong(1975) | Blinn-Phong(1977) | PBR Cook-Torrance |
|---|---|---|---|
| Diffuse | Lambert | Lambert | Lambert / Oren-Nayar |
| Specular | `dot(R, V)^n` | `dot(N, H)^n` | Cook-Torrance BRDF |
| Fresnel | 无 | 无 | Schlick 近似 |
| 微表面 | 无 | 无 | GGX / Beckmann |
| 能量守恒 | 不严格 | 不严格 | 严格 |

PBR 是 Phong 的"物理精确版"。但 Phong 仍然广泛使用(手游、低端硬件、教学)。

**Microfacet theory**(微表面理论):真实表面是无数微小镜面的集合,每个镜面单独反射。Phong 的 `dot(R, V)^n` 是个近似——把"微表面集合"的反射简化为"一个等效高光"。

### 3.4 · 🦀 Rust 生态视角

Rust 端 Phong 光照的数据结构:

```rust
use glam::Vec3;

#[derive(Copy, Clone, Debug)]
pub struct PhongMaterial {
    pub albedo: Vec3,
    pub specular_color: Vec3,
    pub shininess: f32,
    pub ambient: f32,
}

impl PhongMaterial {
    pub fn plastic(albedo: Vec3) -> Self {
        Self {
            albedo,
            specular_color: Vec3::ONE,  // 白色 specular(塑料)
            shininess: 32.0,
            ambient: 0.1,
        }
    }

    pub fn metal(albedo: Vec3) -> Self {
        Self {
            albedo,
            specular_color: albedo,  // 金属 specular = albedo
            shininess: 128.0,
            ambient: 0.05,
        }
    }

    pub fn rough(albedo: Vec3) -> Self {
        Self {
            albedo,
            specular_color: Vec3::ZERO,  // 无 specular
            shininess: 1.0,
            ambient: 0.3,
        }
    }
}

/// 计算片元的 Phong 光照(在 Rust 端,用于测试)
pub fn phong_shading(
    normal: Vec3,
    position: Vec3,
    camera_pos: Vec3,
    light: &DirectionalLight,
    material: &PhongMaterial,
) -> Vec3 {
    let n = normal.normalize();
    let l = light.direction.normalize();
    let v = (camera_pos - position).normalize();
    let r = 2.0 * n.dot(l) * n - l;  // 反射向量

    let ambient = material.albedo * material.ambient;
    let diff = n.dot(l).max(0.0);
    let diffuse = material.albedo * light.color * diff;
    let spec = r.dot(v).max(0.0).powf(material.shininess);
    let specular = material.specular_color * light.color * spec;

    ambient + diffuse + specular
}
```

**用途**:Rust 端实现用于**单元测试**(给一组输入,验证输出数值),GPU shader 实现**实际渲染**。Rust 端和 GPU 端用相同公式,可以对照验证。

## 5 · 对照与变奏

### 同一问题在不同语境下的变体

**问题**:描述"光在表面的反射"。

| 语境 | 模型 |
|---|---|
| 实时图形 | Phong / Blinn-Phong / PBR |
| 离线渲染(电影) | 完整 BRDF + ray tracing |
| 雷达反射 | Radar cross section(RCS)模型 |
| 声学反射 | Acoustic BRDF |
| 计算摄影 | Camera response function |

**核心模式**:**入射角 + 表面性质 → 反射强度**。

### 历史演化

- **1960s**:简单 Lambert(无 specular)
- **1973**:Phong 完成博士论文,引入 specular 项
- **1977**:Blinn 简化为 half-vector 形式
- **1980s**:Cook-Torrance(1981)引入微表面
- **1990s**:Precomputed radiance transfer(PRT)
- **2000s**:Real-time PBR(Goal of offline-rendering look)
- **2014**:Disney Principled BRDF,统一参数
- **2020s**:实时光线追踪(RTX)+ PBR

Phong 是 50 年前的算法,至今仍在教学和低端硬件使用。PBR 是 Phong 的物理精确化。

### Phong 在 CPU vs GPU

| | CPU(软渲染) | GPU |
|---|---|---|
| 实现 | Rust for loop | GLSL |
| 速度 | 慢(每像素几十纳秒,1080p 总和几百毫秒) | 快(并行,1080p 60fps) |

### Lv1 · 概念辨析

**题**:Phong 和 Blinn-Phong 的根本差别是什么?Blinn-Phong 为什么"等价但更快"?

**参考解答**:

**根本差别**:计算 specular 用的向量不同。

- **Phong**:`specular = max(0, dot(R, V))^shininess_phong`,R 是反射向量
- **Blinn-Phong**:`specular = max(0, dot(N, H))^shininess_blinn`,H 是半向量

**等价性**:几何上,`dot(R, V) = cos(2α)` 和 `dot(N, H) = cos(α)`,其中 α 是 N-H 角度。所以 `dot(R, V)^n = cos(2α)^n`,`dot(N, H)^m = cos(α)^m`。当 `m = 2n` 时两者形状接近(不完全相同,但视觉上类似)。

**为什么 Blinn-Phong 更快**:

- Phong 算 R 需要 `2(N·L)N - L`:1 dot + 1 vector-scalar-mul + 1 vector-sub = 大约 6 次乘加
- Blinn-Phong 算 H 需要 `normalize(L + V)`:1 vector-add + 1 length + 1 vector-div = 大约 5 次乘加

差距小,但 Blinn-Phong 还有其他优势:

- `reflect()` 在某些 GPU 上慢(可能不是单指令)
- `pow(cos(α), m)` 比 `pow(cos(2α), n)` 数值稳定性更好(更小的角度范围)

工业界默认 Blinn-Phong。

### Lv2 · 动手实践

**题**:在 Day 389 的 Lambert demo 基础上加 Phong specular。F1 / F2 增加 / 减少 shininess(范围 1-256),F3 切换 specular_color(白色 / 红色)。

完成标准:按键立即生效,球的亮斑大小 / 颜色变化。

**参考解答**:

```rust
use std::cell::Cell;

#[derive(Copy, Clone)]
struct Settings {
    shininess: f32,
    specular_white: bool,
}
impl Default for Settings {
    fn default() -> Self { Self { shininess: 32.0, specular_white: true } }
}

// 在 event loop 里:
let settings = Cell::new(Settings::default());

match key {
    VirtualKeyCode::F1 => {
        let mut s = settings.get();
        s.shininess = (s.shininess * 1.5).min(256.0);
        settings.set(s);
        println!("shininess: {}", s.shininess);
    }
    VirtualKeyCode::F2 => {
        let mut s = settings.get();
        s.shininess = (s.shininess / 1.5).max(1.0);
        settings.set(s);
        println!("shininess: {}", s.shininess);
    }
    VirtualKeyCode::F3 => {
        let mut s = settings.get();
        s.specular_white = !s.specular_white;
        settings.set(s);
        println!("specular white: {}", s.specular_white);
    }
    _ => {}
}

// 渲染:
let s = settings.get();
let specular_color = if s.specular_white {
    [1.0f32, 1.0, 1.0]
} else {
    [1.0f32, 0.0, 0.0]  // 红色 specular
};
let uniforms = uniform! {
    shininess: s.shininess,
    specular_color: specular_color,
    // ... 其他 uniform
};
```

GLSL fragment shader:

```glsl
#version 330
in vec3 v_world_normal;
in vec3 v_world_position;
uniform vec3 light_dir;
uniform vec3 light_color;
uniform vec3 albedo;
uniform vec3 ambient_color;
uniform vec3 camera_pos;
uniform vec3 specular_color;
uniform float shininess;
out vec4 frag;

void main() {
    vec3 N = normalize(v_world_normal);
    vec3 L = normalize(light_dir);
    vec3 V = normalize(camera_pos - v_world_position);
    vec3 R = reflect(-L, N);

    float diff = max(0.0, dot(N, L));
    vec3 ambient = albedo * ambient_color;
    vec3 diffuse = albedo * light_color * diff;

    float spec = pow(max(0.0, dot(R, V)), shininess);
    vec3 specular = specular_color * light_color * spec;

    vec3 final = ambient + diffuse + specular;
    final = final / (final + vec3(1.0));  // tone map
    frag = vec4(final, 1.0);
}
```

Vertex shader 多输出一个 world position:

```glsl
#version 330
in vec3 position;
in vec3 normal;
uniform mat4 mvp;
uniform mat4 model;
out vec3 v_world_normal;
out vec3 v_world_position;

void main() {
    v_world_normal = mat3(model) * normal;  // 假设无非均匀缩放
    v_world_position = (model * vec4(position, 1.0)).xyz;
    gl_Position = mvp * vec4(position, 1.0);
}
```

**关键点**:

- `v_world_position` 用于算 `V = camera - position`
- `mat3(model)` 取 model matrix 的 3x3 部分(忽略平移),变换法线
- 实际项目用 `normal_matrix = transpose(inverse(model))`,这里简化

### 完整 Phong 光照 demo

```toml
[package]
name = "phong_lighting"

[dependencies]
glium = "0.34"

```

```rust
// src/main.rs
use glium::{glutin, Surface, implement_vertex, program, index, uniform};
use glam::{Vec3, Mat4};
use std::cell::Cell;

#[derive(Copy, Clone)]
struct Vertex {
    position: [f32; 3],
    normal: [f32; 3],
}
implement_vertex!(Vertex, position, normal);

#[derive(Copy, Clone)]
struct Material {
    albedo: [f32; 3],
    specular: [f32; 3],
    shininess: f32,
    ambient: f32,
}

impl Material {
    fn plastic_red() -> Self {
        Self {
            albedo: [0.8, 0.2, 0.2],
            specular: [1.0, 1.0, 1.0],
            shininess: 32.0,
            ambient: 0.1,
        }
    }

    fn metal_gold() -> Self {
        Self {
            albedo: [1.0, 0.7, 0.3],
            specular: [1.0, 0.7, 0.3],  // 金属:specular = albedo
            shininess: 128.0,
            ambient: 0.05,
        }
    }
}

// 生成 UV 球(同 Day 389)
fn make_sphere(radius: f32, segments: usize, rings: usize) -> Vec<Vertex> {
    let mut verts = Vec::new();
    for i in 0..rings {
        let theta1 = (i as f32 / rings as f32) * std::f32::consts::PI;
        let theta2 = ((i + 1) as f32 / rings as f32) * std::f32::consts::PI;
        for j in 0..segments {
            let phi1 = (j as f32 / segments as f32) * 2.0 * std::f32::consts::PI;
            let phi2 = ((j + 1) as f32 / segments as f32) * 2.0 * std::f32::consts::PI;
            let p = |t, p| {
                let v = Vec3::new(
                    radius * t.sin() * p.cos(),
                    radius * t.cos(),
                    radius * t.sin() * p.sin(),
                );
                Vertex { position: v.to_array(), normal: v.normalize().to_array() }
            };
            let v1 = p(theta1, phi1);
            let v2 = p(theta1, phi2);
            let v3 = p(theta2, phi2);
            let v4 = p(theta2, phi1);
            verts.extend_from_slice(&[v1, v2, v3, v1, v3, v4]);
        }
    }
    verts
}

fn main() {
    let event_loop = glutin::event_loop::EventLoop::new();
    let wb = glutin::window::WindowBuilder::new()
        .with_inner_size(glutin::dpi::LogicalSize::new(800, 600))
        .with_title("Phong Lighting (F1=F2 Shininess, F3=Material)");
    let cb = glutin::ContextBuilder::new().with_depth_buffer(24);
    let display = glium::Display::new(wb, cb, &event_loop).unwrap();

    let sphere_verts = make_sphere(0.7, 32, 16);
    let vbuf = glium::VertexBuffer::new(&display, &sphere_verts).unwrap();
    let indices = index::NoIndices(index::PrimitiveType::TrianglesList);

    let aspect = 800.0 / 600.0;
    let projection = Mat4::perspective_rh(std::f32::consts::PI / 4.0, aspect, 0.1, 100.0);
    let camera_pos = Vec3::new(0.0, 0.0, 3.0);
    let view = Mat4::look_at_rh(camera_pos, Vec3::ZERO, Vec3::new(0.0, 1.0, 0.0));
    let model = Mat4::IDENTITY;
    let mvp = projection * view * model;

    let light_dir = Vec3::new(1.0, 1.0, 1.0).normalize();
    let light_color = Vec3::new(1.0, 1.0, 1.0);

    let material_idx = Cell::new(0usize);  // 0=plastic, 1=metal

    let program = program!(&display,
        330 es => {
            vertex: r#"#version 330
                in vec3 position;
                in vec3 normal;
                uniform mat4 mvp;
                uniform mat4 model;
                out vec3 v_world_normal;
                out vec3 v_world_position;
                void main() {
                    v_world_normal = mat3(model) * normal;
                    v_world_position = (model * vec4(position, 1.0)).xyz;
                    gl_Position = mvp * vec4(position, 1.0);
                }
            "#,
            fragment: r#"#version 330
                in vec3 v_world_normal;
                in vec3 v_world_position;
                uniform vec3 light_dir;
                uniform vec3 light_color;
                uniform vec3 albedo;
                uniform vec3 ambient_color;
                uniform vec3 camera_pos;
                uniform vec3 specular_color;
                uniform float shininess;
                out vec4 frag;
                void main() {
                    vec3 N = normalize(v_world_normal);
                    vec3 L = normalize(light_dir);
                    vec3 V = normalize(camera_pos - v_world_position);
                    vec3 R = reflect(-L, N);

                    float diff = max(0.0, dot(N, L));
                    vec3 ambient = albedo * ambient_color;
                    vec3 diffuse = albedo * light_color * diff;

                    float spec = pow(max(0.0, dot(R, V)), shininess);
                    vec3 specular = specular_color * light_color * spec;

                    vec3 final_color = ambient + diffuse + specular;
                    // Reinhard tone map
                    final_color = final_color / (final_color + vec3(1.0));
                    frag = vec4(final_color, 1.0);
                }
            "#,
        }).unwrap();

    event_loop.run(move |event, _, control_flow| {
        use glutin::event::{Event, WindowEvent, KeyboardInput, ElementState, VirtualKeyCode};
        use glutin::event_loop::ControlFlow;
        *control_flow = ControlFlow::Wait;

        match event {
            Event::WindowEvent { event: WindowEvent::KeyboardInput {
                input: KeyboardInput { state: ElementState::Pressed,
                                       virtual_keycode: Some(key), .. }, ..
            }, .. } => {
                match key {
                    VirtualKeyCode::F3 => {
                        let mut idx = material_idx.get();
                        idx = (idx + 1) % 2;
                        material_idx.set(idx);
                        println!("Material: {}", if idx == 0 { "plastic red" } else { "metal gold" });
                    }
                    _ => {}
                }
            }
            Event::RedrawRequested(_) => {
                let material = match material_idx.get() {
                    0 => Material::plastic_red(),
                    _ => Material::metal_gold(),
                };

                let mut target = display.draw();
                target.clear_color_and_depth((0.05, 0.05, 0.1, 1.0), 1.0);

                let uniforms = uniform! {
                    mvp: mvp.to_cols_array_2d(),
                    model: model.to_cols_array_2d(),
                    light_dir: light_dir.to_array(),
                    light_color: light_color.to_array(),
                    albedo: material.albedo,
                    ambient_color: [material.ambient; 3],
                    camera_pos: camera_pos.to_array(),
                    specular_color: material.specular,
                    shininess: material.shininess,
                };

                let params = glium::DrawParameters {
                    depth: glium::Depth {
                        test: glium::draw_parameters::DepthTest::IfLess,
                        write: true,
                        ..Default::default()
                    },
                    ..Default::default()
                };

                target.draw(&vbuf, &indices, &program, &uniforms, &params).unwrap();
                target.finish().unwrap();
            }
            Event::WindowEvent { event: WindowEvent::CloseRequested, .. } => {
                *control_flow = ControlFlow::Exit;
            }
            _ => {}
        }
    });
}
```

**Troubleshooting**:

- 球没有高光 — 检查 camera_pos 是否正确传入,和 v_world_position 同一空间
- 高光在错误位置 — 检查 light_dir 方向(是指向光源,不是从光源指向表面)
- 颜色过曝 — 加 tone map,或减少 light_color
- shininess 没效果 — 检查是不是传了整数(`shininess: 32`)还是浮点(`shininess: 32.0f32`),GLSL uniform float 需要浮点
