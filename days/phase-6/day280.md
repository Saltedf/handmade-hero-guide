# Day 280 · 清理流式实体模拟

> 昨天完成了 chunk 加载 / 卸载 / 跨 chunk 移动。今天 Casey 不加新功能,做一次纯重构——把"流式模拟"(streaming simulation)的代码理顺,提取 helper,加注释,补测试。这是 Day 265 / 269 之后第三次大规模重构。

## 0 · 为什么要有这一天

你的 chunked world 代码现在能跑,但内部一团乱麻:

- `update_around` 函数 80 行,做 5 件事(算范围、加载、卸载、跨 chunk 移动、统计)
- 多处重复的"算 chunk 范围"代码
- 错误处理散落(找不到 entity 时 panic?返回?)
- 没有测试——加新功能时容易破坏旧的

这是典型的"功能完成但代码不优雅"状态。继续在这种代码上加功能,bug 率会飙升。

今天的重构目标:

1. **拆分大函数**:`update_around` 拆成 5 个小函数,每个单一职责
2. **消除重复**:`chunk_range(player_chunk, radius)` 函数复用
3. **错误处理统一**:用 `Result` 或 `Option` 替代 panic
4. **加测试**:对每个 helper 函数加单元测试

重构后代码量略增(加了测试 + 注释),但**逻辑清晰**,未来加功能更安全。

心理锚点:做完这个,你能轻松给 chunked world 加新功能(异步加载、多线程更新、网络同步),因为基础稳固。

## 2 · 心智模型

### 类比:工厂流水线重组

工厂的某条流水线初期是"一个工人做所有事"——高效但难扩展。规模大了之后,把流水线拆成多步,每步一个工人专门做。重组时:

- 每步独立可测(测试单个工人)
- 每步可换(用机器替代人工)
- 每步可扩展(加并行)

代码重构同理:大函数拆成小函数,每个小函数单一职责、可测、可替换。

### 严谨原理:重构的步骤

#### 步骤 1:加测试

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_chunk_range_center() {
        let range = chunk_range(ChunkPos(0, 0), 1);
        assert_eq!(range.len(), 9);  // 3x3 = 9
        assert!(range.contains(&ChunkPos(0, 0)));
        assert!(range.contains(&ChunkPos(-1, -1)));
        assert!(range.contains(&ChunkPos(1, 1)));
    }

    #[test]
    fn test_chunk_range_negative() {
        let range = chunk_range(ChunkPos(-5, -5), 0);
        assert_eq!(range, vec![ChunkPos(-5, -5)]);
    }

    #[test]
    fn test_tile_to_chunk_negative() {
        assert_eq!(tile_to_chunk(TilePos(-1, -1)), ChunkPos(-1, -1));
        assert_eq!(tile_to_chunk(TilePos(-16, -16)), ChunkPos(-1, -1));
        assert_eq!(tile_to_chunk(TilePos(-17, -17)), ChunkPos(-2, -2));
    }

    #[test]
    fn test_spawn_and_find() {
        let mut world = World::new();
        let id = world.spawn(TilePos(5, 5), 0xFFFF0000, 8.0).unwrap();
        assert!(world.find_entity(id).is_some());
    }

    #[test]
    fn test_cross_chunk_move() {
        let mut world = World::new();
        let id = world.spawn(TilePos(15, 0), 0xFFFF0000, 8.0).unwrap();
        world.move_entity(id, TilePos(17, 0));
        // entity 现在应该在 chunk (1, 0)
        let chunk = world.chunks.get(&ChunkPos(1, 0)).unwrap();
        assert!(chunk.entities.iter().any(|e| e.id == id));
    }
}
```

每个测试覆盖一个具体场景。运行 `cargo test` 验证全部通过——这是重构的 baseline。

#### 步骤 2:拆分函数

原 `update_around`:

```rust
fn update_around(&mut self, player_chunk: ChunkPos) {
    // 1. 算加载范围
    let active: HashSet<ChunkPos> = ...;
    // 2. 加载
    for cp in &active { self.ensure_chunk(*cp); }
    // 3. 卸载
    let to_unload: Vec<ChunkPos> = self.chunks.keys()
        .filter(|cp| !active.contains(cp))
        .copied().collect();
    for cp in to_unload { ... }
    self.last_player_chunk = player_chunk;
}
```

拆分后:

```rust
fn update_around(&mut self, player_chunk: ChunkPos) {
    let active = self.compute_active_chunks(player_chunk);
    self.load_missing_chunks(&active);
    self.unload_distant_chunks(&active);
    self.last_player_chunk = player_chunk;
}

fn compute_active_chunks(&self, player_chunk: ChunkPos) -> HashSet<ChunkPos> {
    chunk_range(player_chunk, LOAD_RADIUS).into_iter().collect()
}

fn load_missing_chunks(&mut self, active: &HashSet<ChunkPos>) {
    for cp in active {
        if !self.chunks.contains_key(cp) {
            self.ensure_chunk(*cp);
        }
    }
}

fn unload_distant_chunks(&mut self, active: &HashSet<ChunkPos>) {
    let to_unload: Vec<ChunkPos> = self.chunks.keys()
        .filter(|cp| !active.contains(cp))
        .copied().collect();
    for cp in to_unload {
        if let Some(chunk) = self.chunks.remove(&cp) {
            if !chunk.entities.is_empty() {
                self.parked.insert(cp, chunk.entities);
            }
        }
    }
}
```

每个函数单一职责,可单独测试。

#### 步骤 3:统一错误处理

```rust
// 重构前:panic
fn spawn(&mut self, tile: TilePos, ...) -> u32 {
    if self.next_id == u32::MAX { panic!("id overflow"); }
    // ...
}

// 重构后:Result
fn spawn(&mut self, tile: TilePos, ...) -> Result<u32, SpawnError> {
    if self.next_id == u32::MAX { return Err(SpawnError::IdOverflow); }
    // ...
    Ok(id)
}

#[derive(Debug)]
enum SpawnError {
    IdOverflow,
    ChunkCapacityExceeded,
}
```

错误用 enum 表达,调用方用 `?` 或 match 处理。

#### 步骤 4:文档注释

```rust
/// 算玩家周围 `radius` 范围内的所有 chunk 坐标
///
/// 例如 `chunk_range(ChunkPos(0, 0), 1)` 返回 9 个 chunk:
/// `(-1,-1), (-1,0), (-1,1), (0,-1), (0,0), (0,1), (1,-1), (1,0), (1,1)`
fn chunk_range(center: ChunkPos, radius: i32) -> Vec<ChunkPos> {
    let mut result = Vec::with_capacity(((2*radius+1) as usize).pow(2));
    for dx in -radius..=radius {
        for dy in -radius..=radius {
            result.push(ChunkPos(center.0 + dx, center.1 + dy));
        }
    }
    result
}
```

`///` 是 Rust 的 doc comment,IDE 会显示,`cargo doc` 生成 HTML 文档。

### 3.3 · 🦀 Rust 生态视角

Rust 的几个特性让重构更安全:

#### Cargo test

```bash
cargo test
# 自动运行所有 #[test] 函数
```

#### Doc test

```rust
/// 算两个数的和
///
/// # Example
/// ```
/// assert_eq!(my_crate::add(2, 3), 5);
/// ```

```

`cargo test --doc` 自动运行 doc comment 里的代码块作为测试。Rust 独有,保证文档和代码同步。

#### Clippy lints

```bash
cargo clippy
# 自动检测代码异味,如"函数过长"、"重复代码"
```

clippy 是 Rust 的 linter,几百条规则,能发现潜在重构点。

#### Refactoring with types

Rust 的类型系统让"接口变更"被编译器立即捕获:

- 改函数签名 → 所有调用处编译错误
- 改 enum 变体 → 所有 match 处编译错误
- 改 struct 字段 → 所有访问处编译错误

这让重构**安全**:编译器帮你找所有需要改的地方。

### 3.4 · 软件工程:重构纪律

Martin Fowler《Refactoring》的核心原则:

1. **小步前进**:每次一个改动
2. **测试驱动**:重构前确保有测试
3. **行为不变**:外部观察行为一致
4. **频繁提交**:每个小重构一个 commit

今天 Casey 遵守这些。重构后跑游戏,行为和之前完全一致(只是代码更清晰)。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么"重构前必须先加测试"?给出至少 3 个理由。

**参考解答**:
1. **验证行为不变**:测试是"行为契约"。重构前后测试都通过,说明行为不变。没测试无法验证
2. **回归检测**:重构可能意外破坏边界 case。测试能立即发现("昨天能跑的 case 今天挂了")
3. **给重构勇气**:有测试兜底,你敢做大刀阔斧的改动。没测试时只能小修小补,代码腐烂
4. **测试是文档**:测试用例就是"这个函数应该做什么"的具体说明。重构时读测试就能理解意图
5. **未来价值**:下次加新功能时,先看测试覆盖了什么,避免破坏既有
6. **CI 自动化**:测试加入 CI,每次 PR 跑测试,防止新代码破坏重构成果

**题**:把下面的 `update_around` 函数拆成 3 个小函数,每个单一职责。

```rust

完成标准:拆成 `compute_active` / `load_missing` / `unload_distant` 三个函数,主函数变成 4 行。

**参考解答**:

```rust
use std::collections::HashSet;

const LOAD_RADIUS: i32 = 2;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
struct ChunkPos(i32, i32);

impl World {
    fn update_around(&mut self, player_chunk: ChunkPos) {
        let active = self.compute_active(player_chunk);
        self.load_missing(&active);
        self.unload_distant(&active);
        self.last_player_chunk = player_chunk;
    }

    fn compute_active(&self, player_chunk: ChunkPos) -> HashSet<ChunkPos> {
        chunk_range(player_chunk, LOAD_RADIUS).into_iter().collect()
    }

    fn load_missing(&mut self, active: &HashSet<ChunkPos>) {
        for cp in active {
            if !self.chunks.contains_key(cp) {
                self.ensure_chunk(*cp);
            }
        }
    }

    fn unload_distant(&mut self, active: &HashSet<ChunkPos>) {
        let to_unload: Vec<ChunkPos> = self.chunks.keys()
            .filter(|cp| !active.contains(cp))
            .copied()
            .collect();
        for cp in to_unload {
            if let Some(chunk) = self.chunks.remove(&cp) {
                if !chunk.entities.is_empty() {
                    self.parked.insert(cp, chunk.entities);
                }
            }
        }
    }
}

fn chunk_range(center: ChunkPos, radius: i32) -> Vec<ChunkPos> {
    let mut result = Vec::with_capacity(((2*radius + 1) as usize).pow(2));
    for dx in -radius..=radius {
        for dy in -radius..=radius {
            result.push(ChunkPos(center.0 + dx, center.1 + dy));
        }
    }
    result
}

#[derive(Default)]
struct World {
    chunks: std::collections::HashMap<ChunkPos, Chunk>,
    parked: std::collections::HashMap<ChunkPos, Vec<u32>>,
    last_player_chunk: ChunkPos,
}

#[derive(Default)]
struct Chunk {
    entities: Vec<u32>,
}

impl World {
    fn ensure_chunk(&mut self, pos: ChunkPos) {
        self.chunks.entry(pos).or_default();
    }
}

fn main() {
    let mut world = World::default();
    world.update_around(ChunkPos(0, 0));
    println!("Loaded {} chunks", world.chunks.len());
    // 应该是 5x5 = 25
}
```

**每行解释**:
- `compute_active` 是纯函数(无副作用),返回数据
- `load_missing` 和 `unload_distant` 各自只做一件事
- `chunk_range` 抽出复用,以后其他地方需要"算 N*N 范围"也能用
- `update_around` 主函数只协调,逻辑极简

## 8 · Rust / Arch 落地代码

### 完整可跑:重构后的 chunked world(带测试)

```rust
// Cargo.toml:
// [dependencies]
// minifb = "0.27"

use minifb::{Key, KeyRepeat, Window, WindowOptions};
use std::collections::{HashMap, HashSet};
use std::time::Instant;

const WIDTH: usize = 800;
const HEIGHT: usize = 600;
const TILE_SIZE: f32 = 16.0;
const CHUNK_SIZE: i32 = 16;
const LOAD_RADIUS: i32 = 2;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
struct TilePos(i32, i32);

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
struct ChunkPos(i32, i32);

fn tile_to_chunk(t: TilePos) -> ChunkPos {
    ChunkPos(t.0.div_euclid(CHUNK_SIZE), t.1.div_euclid(CHUNK_SIZE))
}

fn tile_to_world(t: TilePos) -> (f32, f32) {
    ((t.0 as f32 + 0.5) * TILE_SIZE, (t.1 as f32 + 0.5) * TILE_SIZE)
}

/// 算 center 周围 radius 范围内的所有 chunk 坐标。
///
/// 例如 `chunk_range(ChunkPos(0, 0), 1)` 返回 9 个 chunk
/// (中心 + 上下左右 + 四角)。
fn chunk_range(center: ChunkPos, radius: i32) -> Vec<ChunkPos> {
    let mut result = Vec::with_capacity(((2*radius + 1) as usize).pow(2));
    for dx in -radius..=radius {
        for dy in -radius..=radius {
            result.push(ChunkPos(center.0 + dx, center.1 + dy));
        }
    }
    result
}

#[derive(Clone, Debug)]
struct EntitySlot {
    id: u32,
    tile: TilePos,
    color: u32,
    size: f32,
}

#[derive(Clone, Debug, Default)]
struct Chunk {
    entities: Vec<EntitySlot>,
    is_wall: Vec<bool>,
}

impl Chunk {
    fn new_generated(pos: ChunkPos) -> Self {
        let mut c = Self::default();
        c.is_wall = vec![false; (CHUNK_SIZE * CHUNK_SIZE) as usize];
        let hash = (pos.0 as u32).wrapping_mul(0x9E3779B9)
            .wrapping_add((pos.1 as u32).wrapping_mul(0x85EBCA6B));
        for i in 0..6 {
            let idx = (hash.wrapping_mul(i + 1) as usize) % (CHUNK_SIZE * CHUNK_SIZE) as usize;
            c.is_wall[idx] = true;
        }
        c
    }
    fn is_traversable(&self, lx: i32, ly: i32) -> bool {
        if lx < 0 || ly < 0 || lx >= CHUNK_SIZE || ly >= CHUNK_SIZE { return true; }
        !self.is_wall[(ly * CHUNK_SIZE + lx) as usize]
    }
}

#[derive(Debug)]
enum SpawnError {
    IdOverflow,
}

struct World {
    chunks: HashMap<ChunkPos, Chunk>,
    parked: HashMap<ChunkPos, Vec<EntitySlot>>,
    next_id: u32,
    last_player_chunk: ChunkPos,
}

impl World {
    fn new() -> Self {
        Self {
            chunks: HashMap::new(),
            parked: HashMap::new(),
            next_id: 1,
            last_player_chunk: ChunkPos(0, 0),
        }
    }

    fn ensure_chunk(&mut self, pos: ChunkPos) -> &mut Chunk {
        if !self.chunks.contains_key(&pos) {
            let mut chunk = Chunk::new_generated(pos);
            if let Some(parked_entities) = self.parked.remove(&pos) {
                chunk.entities = parked_entities;
            }
            self.chunks.insert(pos, chunk);
        }
        self.chunks.get_mut(&pos).unwrap()
    }

    fn spawn(&mut self, tile: TilePos, color: u32, size: f32) -> Result<u32, SpawnError> {
        if self.next_id == u32::MAX {
            return Err(SpawnError::IdOverflow);
        }
        let id = self.next_id;
        self.next_id += 1;
        let cp = tile_to_chunk(tile);
        self.ensure_chunk(cp).entities.push(EntitySlot { id, tile, color, size });
        Ok(id)
    }

    fn is_traversable(&mut self, tile: TilePos) -> bool {
        let cp = tile_to_chunk(tile);
        let lx = tile.0.rem_euclid(CHUNK_SIZE);
        let ly = tile.1.rem_euclid(CHUNK_SIZE);
        self.ensure_chunk(cp).is_traversable(lx, ly)
    }

    fn move_entity(&mut self, id: u32, new_tile: TilePos) {
        // 找 source chunk
        let source_chunk = self.chunks.iter()
            .find(|(_, c)| c.entities.iter().any(|e| e.id == id))
            .map(|(cp, _)| *cp);
        let source_chunk = match source_chunk {
            Some(c) => c,
            None => return,
        };

        let new_chunk = tile_to_chunk(new_tile);
        if source_chunk == new_chunk {
            let chunk = self.chunks.get_mut(&source_chunk).unwrap();
            let e = chunk.entities.iter_mut().find(|e| e.id == id).unwrap();
            e.tile = new_tile;
        } else {
            let entity = {
                let chunk = self.chunks.get_mut(&source_chunk).unwrap();
                let idx = chunk.entities.iter().position(|e| e.id == id).unwrap();
                let mut e = chunk.entities.swap_remove(idx);
                e.tile = new_tile;
                e
            };
            self.ensure_chunk(new_chunk).entities.push(entity);
        }
    }

    fn update_around(&mut self, player_chunk: ChunkPos) {
        let active = self.compute_active(player_chunk);
        self.load_missing(&active);
        self.unload_distant(&active);
        self.last_player_chunk = player_chunk;
    }

    fn compute_active(&self, player_chunk: ChunkPos) -> HashSet<ChunkPos> {
        chunk_range(player_chunk, LOAD_RADIUS).into_iter().collect()
    }

    fn load_missing(&mut self, active: &HashSet<ChunkPos>) {
        for cp in active {
            if !self.chunks.contains_key(cp) {
                self.ensure_chunk(*cp);
            }
        }
    }

    fn unload_distant(&mut self, active: &HashSet<ChunkPos>) {
        let to_unload: Vec<ChunkPos> = self.chunks.keys()
            .filter(|cp| !active.contains(cp))
            .copied()
            .collect();
        for cp in to_unload {
            if let Some(chunk) = self.chunks.remove(&cp) {
                if !chunk.entities.is_empty() {
                    self.parked.insert(cp, chunk.entities);
                }
            }
        }
    }
}

fn draw_rect(buf: &mut [u32], buf_w: usize, buf_h: usize, x: i32, y: i32, w: i32, h: i32, color: u32) {
    for py in y.max(0)..(y + h).min(buf_h as i32) {
        for px in x.max(0)..(x + w).min(buf_w as i32) {
            buf[(py as usize) * buf_w + (px as usize)] = color;
        }
    }
}

fn main() {
    let mut window = Window::new(
        "Refactored Streaming World", WIDTH, HEIGHT,
        WindowOptions::default(),
    ).expect("Failed to open window");

    let mut buffer = vec![0u32; WIDTH * HEIGHT];
    let mut last_time = Instant::now();

    let mut world = World::new();
    let mut player_tile = TilePos(0, 0);
    let player_id = world.spawn(player_tile, 0xFFFF6040, 8.0).unwrap();

    for i in 0..30 {
        let t = TilePos(i - 15, (i % 5) as i32 - 2);
        let _ = world.spawn(t, 0xFFA040FF, 6.0);
    }

    world.update_around(tile_to_chunk(player_tile));

    while window.is_open() && !window.is_key_down(Key::Escape) {
        let now = Instant::now();
        let _dt = now.duration_since(last_time).as_secs_f32().min(0.05);
        last_time = now;

        let mut new_tile = player_tile;
        if window.is_key_pressed(Key::W, KeyRepeat::No) { new_tile.1 -= 1; }
        if window.is_key_pressed(Key::S, KeyRepeat::No) { new_tile.1 += 1; }
        if window.is_key_pressed(Key::A, KeyRepeat::No) { new_tile.0 -= 1; }
        if window.is_key_pressed(Key::D, KeyRepeat::No) { new_tile.0 += 1; }

        if new_tile != player_tile {
            if world.is_traversable(new_tile) {
                world.move_entity(player_id, new_tile);
                player_tile = new_tile;
                let pc = tile_to_chunk(player_tile);
                if pc != world.last_player_chunk {
                    world.update_around(pc);
                }
            }
        }

        for px in buffer.iter_mut() { *px = 0xFF000000; }

        let (cam_x, cam_y) = tile_to_world(player_tile);
        let cam_x = cam_x - WIDTH as f32 / 2.0;
        let cam_y = cam_y - HEIGHT as f32 / 2.0;

        for (cp, chunk) in &world.chunks {
            let ox = cp.0 * CHUNK_SIZE;
            let oy = cp.1 * CHUNK_SIZE;
            for ly in 0..CHUNK_SIZE {
                for lx in 0..CHUNK_SIZE {
                    let tile = TilePos(ox + lx, oy + ly);
                    let (wx, wy) = tile_to_world(tile);
                    let sx = wx - cam_x;
                    let sy = wy - cam_y;
                    if sx < 0.0 || sy < 0.0 || sx >= WIDTH as f32 || sy >= HEIGHT as f32 { continue; }

                    let is_wall = !chunk.is_traversable(lx, ly);
                    let color = if is_wall { 0xFF808080 } else { 0xFF303030 };
                    draw_rect(&mut buffer, WIDTH, HEIGHT,
                              (sx - TILE_SIZE/2.0) as i32, (sy - TILE_SIZE/2.0) as i32,
                              TILE_SIZE as i32, TILE_SIZE as i32, color);
                }
            }
        }

        for chunk in world.chunks.values() {
            for e in &chunk.entities {
                let (wx, wy) = tile_to_world(e.tile);
                let sx = wx - cam_x;
                let sy = wy - cam_y;
                if sx < 0.0 || sy < 0.0 || sx >= WIDTH as f32 || sy >= HEIGHT as f32 { continue; }
                draw_rect(&mut buffer, WIDTH, HEIGHT,
                          (sx - e.size) as i32, (sy - e.size) as i32,
                          (e.size * 2.0) as i32, (e.size * 2.0) as i32, e.color);
            }
        }

        window.update_with_buffer(&buffer, WIDTH, HEIGHT).unwrap();
    }
}

**关键 Rust 特性解释**:
- `#[cfg(test)] mod tests` 是 Rust 标准的测试模块组织
- `#[test]` 标记测试函数,`cargo test` 自动运行
- `Result<u32, SpawnError>` 替代 panic,调用方决定怎么处理错误
- doc comment `///` 生成 API 文档
- 每个小函数单一职责,可独立测试

**Troubleshooting**:

- 测试失败 — 仔细看测试期望的值,可能算法有 bug(正好暴露 bug,这是测试的价值)
- cargo doc 打不开 — 端口被占用,`cargo doc --no-deps` 减少生成
