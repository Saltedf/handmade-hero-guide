# Day 078 · 每个实体多个碰撞体

> 你 Phase 2 写的玩家是一个 AABB——一个矩形碰撞体。但游戏里的 Boss 不是矩形——它有头、身、尾、翅膀,每部分都不一样。头被攻击伤害 ×2(弱点),尾被攻击减伤(护甲),身体正常。Casey 今天给你的 entity 加上**多个碰撞体积**,每个 part 独立判定。这让 Boss 战、复杂角色、精细碰撞成为可能。

## 0 · 为什么要有这一天

你的玩家撞一只普通怪:用一个 AABB 矩形,简单。

但你的游戏现在有个 **Boss——一只巨龙**。龙有:
- 头部:弱点,被攻击伤害 ×2
- 颈部:正常
- 身体:正常
- 翅膀:可被攻击但伤害 ×0.5
- 尾巴:被攻击击退玩家

一个 AABB 怎么表达这些?**做不到**。龙有 5 个部位,每个不同响应。Casey 今天给的解法:**每个 entity 有多个 collision volume**,每个 volume 独立判定 + 类型标签。

这个抽象还让你能做:
- **头部击杀**(射击游戏:爆头伤害 ×5)
- **关节攻击**(Monster Hunter:断尾需要专门打尾巴)
- **Aoe 范围**(法术的爆炸体积,作为 entity 的一部分)
- **触手**(克苏鲁怪的多臂,每个独立)

心理锚点:看完今天,你能用 Rust 写出有 N 个 part 的 entity。你能解释「单个 AABB vs 多 AABB」的取舍。你知道 Monster Hunter、Dark Souls 等游戏的复杂 Boss 怎么做。

## 1 · Casey 今天做了什么

Casey 今天做的事情:

1. **Entity 加 volumes 字段**:`Vec<Volume>` 而不是单个 `half: Vec3`。
2. **Volume 结构**:`{ offset: Vec3, half: Vec3, type: VolumeType }`——每个 part 有偏移、尺寸、类型。
3. **VolumeType enum**:`Body`(正常)、`WeakPoint`(弱点,被攻击 ×2)、`Armor`(护甲,被攻击 ×0.5)等。
4. **碰撞测试升级**:两层循环——entity 之间遍历,内部 volume 之间遍历。
5. **简化决策**:大多数 entity 仍用单个 volume(性能),只有 Boss 等复杂 entity 用多 volume。

Casey 强调「按需复杂化」——不要一开始就给所有 entity 多 volume,90% 的 entity 一个 volume 就够,只在需要时升级。

## 2 · 心智模型

### 费曼类比:人体解剖

人不是「一个矩形」——人有头、脖子、躯干、四肢。每部分功能不同:头被攻击致命,躯干中等,手脚轻伤。医生看病、武术家攻击、运动锻炼——都基于「人的不同部位有不同特性」。

游戏里的 Boss 也是这样。一个 AABB 表达「整体范围」,但具体判定要看部位。多 volume 就是给 Boss 加上「解剖学」——每个部位有自己的体积和属性。

### 严谨原理

#### 2.1 数据结构

```rust
#[derive(Copy, Clone, Debug)]
enum VolumeType {
    Body,         // 普通,正常伤害
    WeakPoint,    // 弱点,伤害 ×2
    Armor,        // 护甲,伤害 ×0.5
    Invulnerable, // 无敌(部分时候)
}

#[derive(Copy, Clone, Debug)]
struct Volume {
    offset: Vec3,  // 相对 entity pos 的偏移
    half: Vec3,    // 半尺寸
    vtype: VolumeType,
}

#[derive(Clone, Debug)]
struct Entity {
    pos: Vec3,
    height: f32,
    volumes: Vec<Volume>,  // 多个 part
}
```

每个 volume 的**实际中心** = `entity.pos + offset`。比如龙的头在 pos 上方 200,offset = (0, 0, 200)。

#### 2.2 多 volume 的碰撞测试

```rust
fn entities_collide_volumes(a: &Entity, b: &Entity) -> Option<(usize, usize)> {
    for (i, va) in a.volumes.iter().enumerate() {
        let a_center = a.pos.add(va.offset);
        for (j, vb) in b.volumes.iter().enumerate() {
            let b_center = b.pos.add(vb.offset);
            if aabb3_overlap_at(a_center, va.half, b_center, vb.half) {
                return Some((i, j));  // 返回哪些 part 撞了
            }
        }
    }
    None
}
```

**返回值**:撞了哪两个 part 的索引(对调用者重要,因为不同 part 有不同伤害)。

#### 2.3 简化:大多数 entity 一个 volume

```rust
impl Entity {

        Self {

    }

    fn new_dragon(pos: Vec3) -> Self {

                Volume { offset: Vec3::new(0., 0., 180.), half: Vec3::new(24., 24., 32.),
                         vtype: VolumeType::Body },         // 颈
                Volume { offset: Vec3::new(0., 0., 120.), half: Vec3::new(64., 32., 64.),
                         vtype: VolumeType::Body },         // 身
                Volume { offset: Vec3::new(80., 0., 140.), half: Vec3::new(48., 16., 32.),
                         vtype: VolumeType::Armor },        // 右翼
                Volume { offset: Vec3::new(-80., 0., 140.), half: Vec3::new(48., 16., 32.),
                         vtype: VolumeType::Armor },        // 左翼
```

#### 2.4 攻击伤害计算

```rust
fn apply_attack(
    attacker: &Entity,
    target: &Entity,
    target_volume_idx: usize,
    base_damage: f32,
) -> f32 {
    let vol = &target.volumes[target_volume_idx];
    let damage = match vol.vtype {
        VolumeType::Body => base_damage,
        VolumeType::WeakPoint => base_damage * 2.0,
        VolumeType::Armor => base_damage * 0.5,
        VolumeType::Invulnerable => 0.0,
    };
    damage
}
```

玩家攻击时,先做碰撞测试,得到撞了哪个 part,再根据 part type 算伤害。

#### 2.5 性能考量

N 个 entity,每个有 M 个 volume,复杂度是 O((NM)²)——平方爆炸。一个 entity 5 个 volume,4 个 entity 互相判定就是 4² × 5² = 400 次 AABB 测试。

Casey 的优化:**先用 entity 级 AABB 粗筛**——如果两个 entity 的整体 AABB 不重叠,跳过 volume 级测试。

```rust
fn entities_collide(a: &Entity, b: &Entity) -> Option<(usize, usize)> {
    // 1. 粗筛:entity 整体 AABB
    let a_bounds = entity_overall_aabb(a);
    let b_bounds = entity_overall_aabb(b);
    if !aabb3_overlap(a_bounds, b_bounds) {
        return None;
    }
    // 2. 精筛:volume 级
    entities_collide_volumes(a, b)
}

fn entity_overall_aabb(e: &Entity) -> AABB3 {
    // 包围所有 volume 的最小 AABB
    let mut min = Vec3::new(f32::INFINITY, f32::INFINITY, f32::INFINITY);
    let mut max = Vec3::new(f32::NEG_INFINITY, f32::NEG_INFINITY, f32::NEG_INFINITY);
    for v in &e.volumes {
        let c = e.pos.add(v.offset);
        min.x = min.x.min(c.x - v.half.x);
        // ... 类似
    }
    AABB3 {
        center: min.add(max).mul(0.5),
        half: max.sub(min).mul(0.5),
    }
}
```

这种「粗筛 + 精筛」是工业碰撞检测的标配——**Broad Phase**(粗)+ **Narrow Phase**(精)。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

多 volume 在游戏里到处都是:

**FPS 爆头**:玩家 character 有头、身、腿三个 volume,头部中弹伤害 ×5。CS、Valorant、Apex 都用。

**Monster Hunter 斩尾**:龙有可切断的尾巴 volume,被砍到一定伤害后断尾(尾巴 volume 移除)。

**Dark Souls 弹反**:敌人的盾 volume,玩家在精确时间攻击盾,触发弹反。

**塞尔达 BOSS 弱点**:Boss 通常有一个发光的弱点 volume,被攻击 ×5 伤害 + 眩晕。

**格斗游戏 hitbox/hurtbox**:攻击有 hitbox(造成伤害的体积),角色有 hurtbox(受伤害的体积)。每个动画帧 hitbox 不同。

#### Hitbox / Hurtbox 抽象

更高级的抽象:
- **Hurtbox**:entity 的身体,被攻击会受伤
- **Hitbox**:攻击的范围,主动伤害别人
- **Clank box**:两个 hitbox 相撞,互相抵消(格斗游戏)

每个 animation frame,这些 box 都可能变化。Casey HH 简化用 volume_type,但工业格斗游戏更复杂。

### 3.2 · 🎨 图形学视角

多 volume 在图形学里的应用:

**Skinning / 骨骼动画**:3D 角色的 mesh 由骨骼驱动。每个 bone 关联一部分 mesh。骨骼动画 = bone 变换,自动驱动 mesh。每个 bone 可以视作一个「volume」。

**碰撞 mesh**:3D mesh 本身就是碰撞体积,精确但慢。工业引擎用简化版(convex hull、AABB 树)。

**物理仿真**:布料、绳索、流体用「particle + spring」模型,每个 particle 是一个碰撞点。

#### 法线贴图 vs 多 volume

法线贴图(Day 097)让一个平面看起来凹凸不平,但**碰撞仍然是平面**(单 volume)。多 volume 是真的不同碰撞体,法线贴图是视觉欺骗。两者结合:大多数 entity 用法线贴图(便宜),Boss 用多 volume(贵但精确)。

### 3.3 · 🐧 Linux 系统编程视角

跟 Linux 没直接关系。但「**树形层次包围**」是 Linux 文件系统的核心:

- **目录树**:每个目录包含文件和子目录。找文件时,先从根目录开始,逐层深入。
- **/proc 文件系统**:每个进程一个目录,目录里有 fd/、maps、status 等子项。
- **cgroup hierarchy**:进程组层次结构,每个组有资源限制。

碰撞检测的「Broad Phase + Narrow Phase」类似——**先粗定位,再精细查**。

### 3.4 · 🦀 Rust 生态视角

#### Rust 写多 volume 系统

```rust
#[derive(Copy, Clone, Debug)]
struct Volume {
    offset: Vec3,
    half: Vec3,
    vtype: VolumeType,
}

#[derive(Clone, Debug)]
struct Entity {
    pos: Vec3,
    height: f32,
    volumes: Vec<Volume>,
}

impl Entity {
    // 返回所有 volume 的世界 AABB
    fn volume_aabbs(&self) -> impl Iterator<Item = (usize, AABB3)> + '_ {
        self.volumes.iter().enumerate().map(move |(i, v)| {
            let center = self.pos.add(v.offset);
            (i, AABB3 { center, half: v.half })
        })
    }
}

// 暴力两两测试
fn collide_all(entities: &[Entity]) -> Vec<(usize, usize, usize, usize)> {
    let mut result = Vec::new();
    for i in 0..entities.len() {
        for j in (i+1)..entities.len() {
            for (vi, va) in entities[i].volume_aabbs() {
                for (vj, vb) in entities[j].volume_aabbs() {
                    if aabb3_overlap(va, vb) {
                        result.push((i, vi, j, vj));
                    }
                }
            }
        }
    }
    result
}
```

`impl Iterator + '_` 是 Rust 的**迭代器组合**——返回一个迭代器,生命周期绑定到 &self。

#### Rust 的 smallvec

如果大多数 entity 只有 1-3 个 volume,用 `Vec<Volume>` 浪费(每次堆分配)。用 `smallvec::SmallVec<[Volume; 4]>`——栈上 4 个,超出才堆:

```rust
use smallvec::SmallVec;
type VolumeList = SmallVec<[Volume; 4]>;

struct Entity {
    pos: Vec3,
    height: f32,
    volumes: VolumeList,  // 通常栈上,极少堆
}
```

游戏循环零分配,关键优化。

#### Rust 的 enum dispatch

如果想避免虚函数调用,用 enum dispatch:

```rust
enum Shape {
    Aabb(AABB3),
    Sphere(Sphere),
    // 加新形状只需加 variant
}

fn collide(a: &Shape, b: &Shape) -> bool {
    match (a, b) {
        (Shape::Aabb(a), Shape::Aabb(b)) => aabb3_overlap(*a, *b),
        (Shape::Sphere(a), Shape::Sphere(b)) => sphere_overlap(*a, *b),
        (Shape::Aabb(a), Shape::Sphere(s)) => aabb_sphere_overlap(*a, *s),
        (Shape::Sphere(s), Shape::Aabb(a)) => aabb_sphere_overlap(*a, *s),
    }
}
```

C++ 用虚函数 + dynamic_cast,Rust 用 enum + match。Rust 编译器保证穷尽性。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 90% 的 entity 应该用单 volume,而不是统一用多 volume?

**参考解答**:性能 + 简洁。

性能:多 volume 需要 Vec(堆分配),每个 entity 一个 Vec 是大开销。1000 个 entity × 平均 1 volume,单 volume 方案零额外开销,多 volume 方案 1000 次堆分配。

简洁:单 volume 代码简单——直接 aabb3_overlap,不用迭代。逻辑清晰。

Casey 的策略:**默认单 volume,需要时升级**。一个 entity 一开始单 volume,后期发现需要多 part(比如 Boss 战),才改成多 volume。**按需复杂化**是工程的核心思想。

### Lv2 · 动手实践

**题**:实现 Dragon entity(6 个 volume)+ 玩家(单 volume)。写一个攻击系统,玩家攻击位置 (0, 0, 250),算出撞到龙的哪个 part,根据 type 算伤害。

**参考解答**:

```rust
#[derive(Copy, Clone, Debug)]
struct Vec3 { x: f32, y: f32, z: f32 }
impl Vec3 {
    fn new(x: f32, y: f32, z: f32) -> Self { Self { x, y, z } }
    fn add(self, o: Self) -> Self { Self::new(self.x+o.x, self.y+o.y, self.z+o.z) }
}

#[derive(Copy, Clone, Debug)]
enum VT { Body, WeakPoint, Armor }

#[derive(Copy, Clone, Debug)]
struct Volume { offset: Vec3, half: Vec3, vtype: VT }

fn dragon() -> Vec<Volume> {
    vec![
        Volume { offset: Vec3::new(0., 0., 240.), half: Vec3::new(32., 32., 16.), vtype: VT::WeakPoint },
        Volume { offset: Vec3::new(0., 0., 180.), half: Vec3::new(24., 24., 32.), vtype: VT::Body },
        Volume { offset: Vec3::new(0., 0., 120.), half: Vec3::new(64., 32., 64.), vtype: VT::Body },
        Volume { offset: Vec3::new(80., 0., 140.), half: Vec3::new(48., 16., 32.), vtype: VT::Armor },
        Volume { offset: Vec3::new(-80., 0., 140.), half: Vec3::new(48., 16., 32.), vtype: VT::Armor },
        Volume { offset: Vec3::new(0., 80., 80.), half: Vec3::new(16., 48., 16.), vtype: VT::Body },
    ]
}

fn aabb_overlap_at(ac: Vec3, ah: Vec3, bc: Vec3, bh: Vec3) -> bool {
    let d = ac.add(Vec3::new(-bc.x, -bc.y, -bc.z));
    d.x.abs() < ah.x + bh.x && d.y.abs() < ah.y + bh.y && d.z.abs() < ah.z + bh.z
}

fn main() {
    let dragon_pos = Vec3::new(0., 0., 0.);
    let dragon_volumes = dragon();

    // 玩家攻击位置
    let attack_pos = Vec3::new(0., 0., 250.);
    let attack_half = Vec3::new(8., 8., 8.);

    let base_damage = 10.0;

    for (i, v) in dragon_volumes.iter().enumerate() {
        let vol_center = dragon_pos.add(v.offset);
        if aabb_overlap_at(attack_pos, attack_half, vol_center, v.half) {
            let dmg = match v.vtype {
                VT::Body => base_damage,
                VT::WeakPoint => base_damage * 2.0,
                VT::Armor => base_damage * 0.5,
            };
            println!("击中 part {}: {:?},伤害 = {:.1}", i, v.vtype, dmg);
        }
    }
}
```

```
击中 part 0: WeakPoint,伤害 = 20.0
```

## 8 · Rust / Arch 落地代码

```rust
#[derive(Copy, Clone, Debug)]
struct Vec3 { x: f32, y: f32, z: f32 }
impl Vec3 {
    fn new(x: f32, y: f32, z: f32) -> Self { Self { x, y, z } }
    fn add(self, o: Self) -> Self { Self::new(self.x+o.x, self.y+o.y, self.z+o.z) }
    fn sub(self, o: Self) -> Self { Self::new(self.x-o.x, self.y-o.y, self.z-o.z) }
    fn abs(self) -> Self { Self::new(self.x.abs(), self.y.abs(), self.z.abs()) }
}

#[derive(Copy, Clone, Debug, PartialEq)]
enum VT { Body, WeakPoint, Armor, Invuln }

#[derive(Copy, Clone, Debug)]
struct Volume { offset: Vec3, half: Vec3, vtype: VT }

#[derive(Clone, Debug)]
struct Entity {
    pos: Vec3,
    height: f32,
    volumes: Vec<Volume>,
}

impl Entity {
    fn player(pos: Vec3) -> Self {
        Self {
            pos,
            height: 64.0,
            volumes: vec![Volume {
                offset: Vec3::new(0., 0., 32.),
                half: Vec3::new(16., 16., 32.),
                vtype: VT::Body,
            }],
        }
    }

    fn dragon(pos: Vec3) -> Self {
        Self {
            pos,
            height: 256.0,
            volumes: vec![
                Volume { offset: Vec3::new(0., 0., 240.), half: Vec3::new(32., 32., 16.), vtype: VT::WeakPoint },
                Volume { offset: Vec3::new(0., 0., 180.), half: Vec3::new(24., 24., 32.), vtype: VT::Body },
                Volume { offset: Vec3::new(0., 0., 120.), half: Vec3::new(64., 32., 64.), vtype: VT::Body },
                Volume { offset: Vec3::new(80., 0., 140.), half: Vec3::new(48., 16., 32.), vtype: VT::Armor },
                Volume { offset: Vec3::new(-80., 0., 140.), half: Vec3::new(48., 16., 32.), vtype: VT::Armor },
            ],
        }
    }
}

fn aabb_overlap(ac: Vec3, ah: Vec3, bc: Vec3, bh: Vec3) -> bool {
    let d = ac.sub(bc).abs();
    d.x < ah.x + bh.x && d.y < ah.y + bh.y && d.z < ah.z + bh.z
}

fn entities_collide_volumes(a: &Entity, b: &Entity) -> Option<(usize, usize)> {
    for (i, va) in a.volumes.iter().enumerate() {
        let ac = a.pos.add(va.offset);
        for (j, vb) in b.volumes.iter().enumerate() {
            let bc = b.pos.add(vb.offset);
            if aabb_overlap(ac, va.half, bc, vb.half) {
                return Some((i, j));
            }
        }
    }
    None
}

fn damage_for(vtype: VT, base: f32) -> f32 {
    match vtype {
        VT::Body => base,
        VT::WeakPoint => base * 2.0,
        VT::Armor => base * 0.5,
        VT::Invuln => 0.0,
    }
}

fn main() {
    let player = Entity::player(Vec3::new(0., 0., 256.));  // 玩家在龙头上方
    let dragon = Entity::dragon(Vec3::new(0., 0., 0.));

    let base_dmg = 10.0;
    if let Some((i, j)) = entities_collide_volumes(&player, &dragon) {
        let vt = dragon.volumes[j].vtype;
        let dmg = damage_for(vt, base_dmg);
        println!("玩家 vol {} 撞到 龙 vol {}({:?}),伤害 = {:.1}", i, j, vt, dmg);
    } else {
        println!("没撞");
    }
}
```
