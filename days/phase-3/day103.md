## 1 · Casey 今天做了什么

Casey 这天是整合工作,让我把步骤拆开。

**第一步,设计 Material struct**。统一材质属性容器:

```rust
struct Material {
    diffuse_color: Color,
    shininess: f32,
    reflectivity: f32,
    f0: f32,  // Fresnel 垂直入射反射率
}
```

每种 sprite 有自己的 Material——金属徽章 reflectivity 高 F0 高,木箱 reflectivity 低 F0 低。这是 industrial 引擎的标配抽象。

**第二步,整合 shade_card 函数**。一个函数完成所有光照:

```rust
fn shade_card(normal, view, light, material, env, ambient) -> Color {
    let phong = ambient + diffuse * ndotl + specular * pow(ndoth, shininess);
    let r = reflect_view(view, normal);
    let env_color = env.sample_reflection(r);
    let fresnel = schlick(material.f0, view.dot(normal));
    let refl = material.reflectivity * fresnel;
    return phong * (1 - refl) + env_color * refl;
}
```

一个函数 ~20 行,包含 Phong + env + Fresnel。每像素调用一次。

**第三步,测试不同材质**。三种典型材质:
- **金属徽章**:reflectivity=0.5, f0=0.7, shininess=80
- **木箱**:reflectivity=0.05, f0=0.04, shininess=5
- **玻璃瓶**:reflectivity=0.5, f0=0.04, shininess=200 + alpha 低

每种材质的视觉效果不同——金属高反射低 Fresnel 变化,木箱低反射强 diffuse,玻璃强 Fresnel 强反射。

**第四步,微调 shader 公式**。`final = ambient + diffuse + specular + env * reflectivity * fresnel`。具体顺序很关键——env 反射和 phong 的混合公式决定最终视觉。

**第五步,处理 Fresnel**(掠射角反射增强)。简单 Schlick 近似,不严格 PBR。Casey 强调这是"Phase 3 的整合日",PBR 是 Day 200+ 的工作。

## 2 · 心智模型

### 2.1 费曼类比:游戏集换卡

我打个比方。想象一张 Pokémon 集换卡——平面卡片,但表面有**全息图案**(holofoil)。光从不同角度照,全息图案反射出不同颜色,跟随角度变化。这是 1990 年代 Pokémon 卡的标志性效果。

游戏 sprite 是类似的:
- 卡片本身 = sprite 矩形(2D)
- 全息图案 = 法线贴图 + 环境反射(2D 表面 + 3D 反射效果)
- 跟随角度 = 跟随法线和相机

这就是「**card-like reflection**」的来源——2D 卡片,但表面反射像 3D 物体。Hollow Knight、Stardew Valley、Hyper Light Drifter 等 2.5D 游戏都用这种技术。

**关键洞察**:**视觉真实感 ≠ 几何复杂度**。一个简单的 2D sprite,只要光照 / 法线 / 反射正确,看起来比简单 3D 模型还真实。这是 stylized 风格游戏(2.5D 渲染)的核心——用 2D 美术 + 3D 光照模拟立体感。

### 2.2 完整光照公式:五项叠加

让我把完整光照公式拆开,你会看到每项的物理意义。

```
final_color = ambient
            + diffuse_intensity * light_color * surface_color * max(0, N · L)
            + specular_intensity * light_color * pow(max(0, R · V), shininess)
            + reflectivity * env_color * fresnel
```

每项的作用:

**ambient**(环境光项):间接光的常数近似,防止背光面纯黑。物理上,真实世界的"间接光"是光在环境中多次散射的结果——技术叫 global illumination (GI)。完整 GI 计算复杂(路径追踪、photon mapping),ambient 是简化版——一个固定颜色加到所有像素。

**diffuse**(漫反射项):直接光的漫反射(Lambert 模型)。表面颜色 × 光强 × 法线点积。物理上,粗糙表面把入射光均匀散射——所有方向看亮度相同。Lambert 公式 `N · L` 描述这个。

**specular**(镜面反射项):直接光的镜面反射(Phong 模型)。`pow(R · V, shininess)`——R 是反射向量,V 是视线。shininess 越大,高光越尖锐(金属感);越小,高光越模糊(塑料感)。

**env_color * reflectivity**(环境反射项):环境贴图采样,模拟周围环境的反射。这是金属感来源——金属反射率高,diffuse 弱。

**fresnel**(Fresnel 项):反射强度随入射角变化。掠射角(视线擦过表面)反射增强,直射角反射弱。这是水、玻璃、塑料的视觉特征来源。

**这五项的物理意义**:模拟"光从各种来源到达眼睛"的过程——ambient 是间接,diffuse + specular 是直接,env 是反射。它们**叠加**(add),不是混合(lerp)——每项独立贡献亮度。

### 2.3 Schlick Fresnel 近似:数学和直觉

Fresnel 方程描述「反射强度随入射角变化」。物理正确公式涉及光的偏振(S / P polarizations),复杂。Schlick 1994 给出近似:

```
F = F0 + (1 - F0) * (1 - V·N)^5
```

**F0**(垂直入射时的反射率):每种材料有固有 F0。金属 ~0.7-0.9,水 0.02,塑料 0.04-0.05,玻璃 0.04。这是 PBR 的"material parameter"之一。

**V·N**(视线和法线的夹角余弦):视线垂直表面时(V·N=1),F=F0(材料固有反射率);视线掠射(V·N=0),F=1(全反射)。这模拟"擦边角反射增强"的物理现象——你站在水边看远处水面,反射强(看到天空);你看正下方水面,反射弱(看到水底)。

**为什么 5 次方**:Schlick 用 5 次方拟合物理 Fresnel 曲线。F0+(1-F0)·x^5 在 x=0 时 = F0,x=1 时 = F0+(1-F0)=1。中间是 5 次曲线——开始平,接近 1 时陡增。这符合物理 Fresnel 曲线形状。

**Schlick Fresnel 让金属徽章边缘反射强**(因为视线掠射),中心反射弱(直射)。这是水、玻璃、塑料、金属共有的视觉特征。

### 2.4 完整 Rust 实现

让我把完整 shade 函数写出来:

```rust
#[derive(Copy, Clone)]
struct Material {
    diffuse_color: Color,
    shininess: f32,
    reflectivity: f32,
    f0: f32,  // Fresnel 垂直入射反射率
}

fn shade_card(
    surface_normal: Vec3,
    view_dir: Vec3,
    light: Light,
    material: Material,
    env: &EnvMap,
    ambient: Color,
) -> Color {
    let n = surface_normal;
    let v = view_dir;
    let l = light.direction;
    let h = l.add(v).normalized();  // half vector,Blinn-Phong 用

    let ndotl = n.dot(l).max(0.0);  // diffuse 强度
    let ndoth = n.dot(h).max(0.0);  // specular 强度(Blinn-Phong)
    let ndotv = n.dot(v).max(0.0);  // Fresnel 用

    // Schlick Fresnel:掠射角反射增强
    let fresnel = material.f0 + (1.0 - material.f0) * (1.0 - ndotv).powi(5);

    // Phong specular (用 Blinn-Phong half vector)
    let specular = ndoth.powf(material.shininess);

    // Phong diffuse + specular
    let diffuse_intensity = light.intensity * ndotl;
    let phong = Color {
        r: ambient.r + diffuse_intensity * light.color.r * (material.diffuse_color.r + specular),
        g: ambient.g + diffuse_intensity * light.color.g * (material.diffuse_color.g + specular),
        b: ambient.b + diffuse_intensity * light.color.b * (material.diffuse_color.b + specular),
    };

    // 环境反射(精确反射向量 R = 2(V·N)N - V)
    let r = reflect_view(v, n);
    let env_color = env.sample_reflection(r);

    // Fresnel-modulated reflectivity
    let refl = material.reflectivity * fresnel;
    Color {
        r: phong.r * (1.0 - refl) + env_color.r * refl,
        g: phong.g * (1.0 - refl) + env_color.g * refl,
        b: phong.b * (1.0 - refl) + env_color.b * refl,
    }
}
```

注意几个细节:

- **Blinn-Phong vs Phong**:经典 Phong 用 `pow(R·V, shininess)`,Blinn-Phong 用 `pow(N·H, shininess)`。Blinn-Phong 更准确(half vector H = (L+V)/|L+V|),且计算更快(不算 R)。Casey HH 用 Blinn-Phong。
- **`.max(0.0)`**:点积可能负(背光面),`max(0.0)` 截断,防止负亮度(物理无意义)。
- **env 和 phong 混合公式**:`phong * (1 - refl) + env_color * refl`。refl 高时(env 反射强)phong 弱,refl 低时(金属 diffuse 强)env 弱。这是工业 PBR 的 lerp 公式。
- **Fresnel modulated reflectivity**:`refl = reflectivity * fresnel`。reflectivity 是材料属性,fresnel 是角度修正。两者乘起来是"实际反射强度"。

### 2.5 完整 sprite 渲染流程

```rust
fn render_card(
    fb: &mut LinearFramebuffer,
    sprite: &Sprite,
    env: &EnvMap,
    model: Mat3,
    origin: Vec2,
    light: Light,
    view: Vec3,
    material: Material,
    config: RenderConfig,
) {
    let inv_model = model.inverse().expect("Model must be invertible");
    let normal_matrix = inv_model.transpose();  // (M⁻¹)ᵀ
    let (min_x, max_x, min_y, max_y) = compute_aabb(&origin, &model, fb.width, fb.height);

    for py in min_y..=max_y {
        for px in min_x..=max_x {
            let (u, v) = match pixel_to_uv(PixelCoord { px, py }, origin, model.inverse().unwrap()) {
                Some(uv) => uv,
                None => continue,
            };
            let sample = sprite.sample_surface(u, v);
            if sample.alpha < config.alpha_threshold { continue; }

            // 关键:用 (M⁻¹)ᵀ 变换法线
            let world_normal = normal_matrix.mul_vec(sample.normal).normalized();

            // 完整光照(包含 env 反射 + Fresnel)
            let mut mat = material;
            mat.diffuse_color = sample.color;  // 用 sprite 自己的 diffuse
            let lit = shade_card(world_normal, view, light, mat, env, config.ambient);

            // alpha 混合(预乘 alpha)
            let bg = fb.pixels[py * fb.width + px];
            fb.pixels[py * fb.width + px] = blend_premul_linear(bg, lit, sample.alpha);
        }
    }
}
```

整个 Phase 3 的渲染管线就在这里——从 sprite 数据到 framebuffer 像素,每像素 ~100 纳秒(CPU)。

**坑:Fresnel 在 2D 的特殊性**。3D 物体边缘自然掠射(视线擦过),Fresnel 增强反射。但 2D sprite 是平的(法线 = (0,0,1)),所有像素的 V·N 都一样(=1,如果视线垂直),Fresnel = F0,看不到掠射效果。**修复**:让法线贴图引入 V·N 变化,或用 sprite 边缘 mask。

卡片式反射是 PBR 的**子集**——所有 PBR 概念都用,但简化:

| 概念 | 完整 PBR | 卡片式 |

| Specular | Cook-Torrance microfacet | Phong |

## 5 · 对照与变奏

### 2D 卡片 vs 3D 模型

卡片式反射本质是「**3D 渲染,但几何是平的**」。优点:
- 美术只需画 2D 图(diffuse + normal)
- 渲染量小(平面而非曲面)
- 适合 2.5D 游戏和 stylized 风格

缺点:
- 不能从侧面看(平的会穿帮)
- 复杂几何(球、立方体)需要多张卡片拼接

### 集成 vs 分层

Casey HH 的渲染管线是「**集成式**」——所有光照在一次 pixel shader 里完成。另一种方式是「**分层式**」:
1. 先画 diffuse
2. 加 normal 光照
3. 加 specular
4. 加 env 反射

分层式更适合 post-processing(bloom、SSAO),但内存开销大(多个 framebuffer)。Casey HH 用集成式,简单高效。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 2D sprite 的 Fresnel 效果不明显?

**参考解答**:Fresnel 依赖 `V·N`(视线和法线的夹角余弦)。2D sprite 是平的,所有像素的法线都是 `(0, 0, 1)`(朝相机),视线也是 `(0, 0, 1)`(假设相机正对屏幕),所以 `V·N = 1` 全屏一致。Fresnel = F0 + (1-F0)(1-1)^5 = F0,所有像素 Fresnel 相同,看不出掠射效果。

**修复**:用法线贴图引入 V·N 变化(法线扰动让 V·N 在不同像素不同)。但即使这样,效果也有限——sprite 没有真正的 3D 边缘。

### Lv3 · 迁移设计

**题**:你想做**玻璃瓶** sprite。玻璃特性:
- 透明(低 alpha,高 env 反射)
- 折射(背景看起来扭曲)

## 9 · 性能与工业实践补充

### 9.1 完整光照管线的工业实现

完整 shade_card 在 CPU 上的开销分析(64x64 tile, 4096 像素):

- Vec3 dot/normalize:~10ns/像素 × 几次 = 50ns
- powf(shininess):~20ns/像素(specular)
- env sample(纹理查找):~30ns/像素
- Fresnel 计算:~10ns/像素
- 总计:~120ns/像素 × 4096 = 500μs/tile

60 FPS 帧时间 16.67ms,可渲染 ~30 个 tile。游戏一般有几百个 tile,所以 CPU 渲染不够——切 GPU。

GPU 上同样代码用 GLSL/WGSL,fragment shader 并行执行几千个像素,64x64 tile ~1μs。1000 tile = 1ms。**1000 倍加速**。

### 9.2 工业引擎的卡片式反射

- **Stardew Valley**:Unity 引擎,sprite + normal map + env reflection,简单 PBR-Lite
- **Hollow Knight**:Unity + 自定义 shader,环境光 + 法线扰动 + hand-painted 风格
- **Hyper Light Drifter**:GameMaker + 自定义 shader,2D sprite + 强烈光照对比
- **Dead Cells**:Unity + 自定义 shader,2D 平面 + 3D 光照混合

这些 2.5D 游戏都遵循 Casey HH Day 103 的模式——**2D 美术 + 3D 光照**。

## 11 · 完整 Rust 工业代码示例

```rust
// 工业级卡片式反射完整实现(整合所有概念)

use std::f32::consts::PI;

#[derive(Copy, Clone, Debug)]
struct Color { r: f32, g: f32, b: f32 }

#[derive(Copy, Clone)]
struct Vec3 { x: f32, y: f32, z: f32 }

impl Vec3 {
    fn new(x: f32, y: f32, z: f32) -> Self { Self { x, y, z } }
    fn dot(self, o: Self) -> f32 { self.x*o.x + self.y*o.y + self.z*o.z }
    fn add(self, o: Self) -> Self { Self::new(self.x+o.x, self.y+o.y, self.z+o.z) }
    fn sub(self, o: Self) -> Self { Self::new(self.x-o.x, self.y-o.y, self.z-o.z) }
    fn scale(self, k: f32) -> Self { Self::new(self.x*k, self.y*k, self.z*k) }
    fn normalized(self) -> Self {
        let len = (self.x*self.x + self.y*self.y + self.z*self.z).sqrt();
        if len > 1e-6 { Self::new(self.x/len, self.y/len, self.z/len) } else { self }
    }
}

#[derive(Copy, Clone)]
struct Light {
    direction: Vec3,  // 单位向量
    color: Color,
    intensity: f32,
}

#[derive(Copy, Clone)]
struct Material {
    diffuse_color: Color,
    shininess: f32,
    reflectivity: f32,
    f0: f32,
}

fn reflect_view(v: Vec3, n: Vec3) -> Vec3 {
    let d = v.dot(n);
    n.scale(2.0 * d).sub(v)
}

fn sample_env(env: &[u8], env_w: u32, env_h: u32, r: Vec3) -> Color {
    // Blinn-Newell sphere map
    let denom = 2.0 * (1.0 + r.z).max(1e-6);
    let u = (r.x / denom + 0.5).clamp(0.0, 1.0);
    let v = (r.y / denom + 0.5).clamp(0.0, 1.0);
    let tx = (u * (env_w - 1) as f32) as u32;
    let ty = (v * (env_h - 1) as f32) as u32;
    let idx = ((ty * env_w + tx) * 3) as usize;
    Color {
        r: env[idx] as f32 / 255.0,
        g: env[idx+1] as f32 / 255.0,
        b: env[idx+2] as f32 / 255.0,
    }
}

fn shade_card(
    n: Vec3, v: Vec3, light: Light, mat: Material,
    env: &[u8], env_w: u32, env_h: u32, ambient: Color,
) -> Color {
    let l = light.direction;
    let h = l.add(v).normalized();
    let ndotl = n.dot(l).max(0.0);
    let ndoth = n.dot(h).max(0.0);
    let ndotv = n.dot(v).max(0.0);

    // Schlick Fresnel
    let fresnel = mat.f0 + (1.0 - mat.f0) * (1.0 - ndotv).powi(5);
    let specular = ndoth.powf(mat.shininess);

    // Phong diffuse + specular
    let di = light.intensity * ndotl;
    let phong = Color {
        r: ambient.r + di * light.color.r * (mat.diffuse_color.r + specular),
        g: ambient.g + di * light.color.g * (mat.diffuse_color.g + specular),
        b: ambient.b + di * light.color.b * (mat.diffuse_color.b + specular),
    };

    // 精确反射
    let r = reflect_view(v, n);
    let env_color = sample_env(env, env_w, env_h, r);

    // Fresnel-modulated reflectivity
    let refl = mat.reflectivity * fresnel;
    Color {
        r: phong.r * (1.0 - refl) + env_color.r * refl,
        g: phong.g * (1.0 - refl) + env_color.g * refl,
        b: phong.b * (1.0 - refl) + env_color.b * refl,
    }
}

fn main() {
    // 金属徽章
    let metal = Material {
        diffuse_color: Color { r: 0.7, g: 0.7, b: 0.75 },
        shininess: 80.0,
        reflectivity: 0.5,
        f0: 0.7,
    };
    // 木箱
    let wood = Material {
        diffuse_color: Color { r: 0.5, g: 0.3, b: 0.15 },
        shininess: 5.0,
        reflectivity: 0.05,
        f0: 0.04,
    };
    // 玻璃
    let glass = Material {
        diffuse_color: Color { r: 0.9, g: 0.9, b: 0.95 },
        shininess: 200.0,
        reflectivity: 0.5,
        f0: 0.04,
    };

    let light = Light {
        direction: Vec3::new(0.7, 0.5, 0.5).normalized(),
        color: Color { r: 1.0, g: 1.0, b: 0.9 },
        intensity: 1.2,
    };
    let view = Vec3::new(0.0, 0.0, 1.0);
    let normal = Vec3::new(0.3, 0.0, 0.95).normalized();
    let ambient = Color { r: 0.1, g: 0.1, b: 0.12 };

    // 模拟 env map (gradient: 蓝顶绿底)
    let env_w = 64u32;
    let env_h = 64u32;
    let env: Vec<u8> = (0..(env_w * env_h)).flat_map(|i| {
        let y = i / env_w;
        let t = y as f32 / env_h as f32;
        // 顶部蓝,底部绿
        [(100.0 + 100.0 * (1.0 - t)) as u8,
         (150.0 + 50.0 * t) as u8,
         (50.0 + 50.0 * t) as u8]
    }).collect();

    let lit_metal = shade_card(normal, view, light, metal, &env, env_w, env_h, ambient);
    let lit_wood = shade_card(normal, view, light, wood, &env, env_w, env_h, ambient);
    let lit_glass = shade_card(normal, view, light, glass, &env, env_w, env_h, ambient);

    println!("Metal lit: r={:.2}, g={:.2}, b={:.2}", lit_metal.r, lit_metal.g, lit_metal.b);
    println!("Wood lit:  r={:.2}, g={:.2}, b={:.2}", lit_wood.r, lit_wood.g, lit_wood.b);
    println!("Glass lit: r={:.2}, g={:.2}, b={:.2}", lit_glass.r, lit_glass.g, lit_glass.b);

    // 金属应该最亮(reflectivity 高,Fresnel 高)
    // 木箱最暗(reflectivity 低,diffuse 主导)
    // 玻璃反射强但 diffuse 弱,Fresnel 变化大
}
```

预期输出会显示金属 lit 值最高(反射 + Fresnel),木箱中等(diffuse),玻璃有强环境反射但 diffuse 弱。
