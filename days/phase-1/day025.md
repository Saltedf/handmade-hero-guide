### 3.4 · 软件工程:里程碑管理

项目里程碑的最佳实践:

**SMART 原则**(里程碑要满足):
- **S**pecific(具体)——"M1 = 平台层完工",不是"做基础"
- **M**easurable(可测)——10 个 ✓ 检查项,可客观判断
- **A**chievable(可达)——25 天可达,不是 250 天
- **R**elevant(相关)——和总目标(做 HH 游戏)相关
- **T**ime-bound(有时限)——25 集而非"无限"

**里程碑之间**:
- 不要太多(每周一个太密)
- 不要太少(每年一个太松)
- HH Phase 1-8 共 8 个里程碑,大约每个 1-3 个月

**错过里程碑**:
- 不要硬赶(质量 > 速度)
- 调整后面里程碑(连锁影响)
- 复盘原因(估算不准 / 范围蔓延 / 技术难点)

Casey HH 的 M1 是 25 集(几周)。M2(Phase 2 结束)是 Day 70(2 个月)。每个里程碑合理。

### Rust 错误处理(Phase 1 完善)

Phase 1 你可能写了很多 `unwrap()`——简单但生产代码不安全。Phase 1 收官前应该:

```rust
// ❌ Phase 1 早期(快糙猛)
let window = create_window().unwrap();
let surface = create_surface(&window).unwrap();

// ✅ Phase 1 收官(稳健)
let window = create_window()
    .context("failed to create window")?;
let surface = create_surface(&window)
    .context("failed to create surface")?;
```

`?` 操作符 + `anyhow::Context`(或 `thiserror`)让错误清晰、可追溯。

Rust 错误处理哲学:

- `Result<T, E>`——可恢复错误
- `panic!()`——不可恢复(程序 bug,立刻退出)
- `unwrap()`——"我知道这里不会失败"(通常错,生产代码慎用)
- `expect("msg")`——同 unwrap 但带消息

Phase 1 早期用 unwrap 没问题(快速试错),Phase 1 收官应该把关键路径改成 `?`。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:完成 Phase 1 后,Casey 进 Phase 2 不再大改平台层(除非 Day 235 切 OpenGL)。这种"先做对基础再扩展"的策略有什么好处?有什么代价?

**参考解答**:

**好处**:
1. **心理稳定**:知道平台层可靠,可以专注业务
2. **学习累积**:Phase 1 的设计教训成为 Phase 2+ 的基础
3. **避免返工**:Day 11 设计对了,Day 26+ 不用回头改平台层
4. **团队协作**:多人项目时,平台层稳定,大家并行加业务

**代价**:
1. **前期慢**:25 集几周不写游戏,看起来"没进度"
2. **过度设计风险**:Phase 1 设计过度,Phase 2 用不上
3. **无法预知需求**:Phase 1 时不知道 Phase 2 要什么 API

**Casey 的策略**:Phase 1 设计"最小必要" API(Day 011 的 update_and_render),不过度抽象。Phase 2 真有新需求再回头加。这是 **YAGNI 原则**的应用——别预先想象需求。

**实战教训**:大项目开始前,花时间搭核心架构是对的。但要克制过度设计,只做必要的。Casey 25 集的比例对游戏开发合理。

**参考解答**:

```rust
// src/smoke_test.rs
// 测试 Phase 1 所有功能集成

use winit::application::ApplicationHandler;
use winit::event::{WindowEvent, ElementState, KeyEvent};
use winit::event_loop::EventLoop;
use winit::keyboard::{KeyCode, PhysicalKey};
use winit::window::Window;
use std::sync::Arc;
use std::time::{Duration, Instant};

const WIDTH: u32 = 1280;
const HEIGHT: u32 = 720;

struct App {
    window: Option<Arc<Window>>,
    surface: Option<softbuffer::Surface<Arc<Window>, Arc<Window>>>,
    keys: std::collections::HashSet<KeyCode>,
    player_x: f32,
    player_y: f32,
    frame_count: u64,
    audio_pipeline: Option<AudioPipeline>,
    last_time: Instant,
    color_phase: u32,
    test_log: Vec<String>,
}

impl App {
    fn new() -> Self {
        let mut log = Vec::new();
        log.push("✓ App::new()".to_string());
        
        let audio = AudioPipeline::new();
        match audio.start() {
            Ok(_) => log.push("✓ audio init".to_string()),
            Err(e) => log.push(format!("✗ audio init: {}", e)),
        }
        
        Self {
            window: None, surface: None,
            keys: std::collections::HashSet::new(),
            player_x: 100.0, player_y: 100.0,
            frame_count: 0,
            audio_pipeline: Some(audio),
            last_time: Instant::now(),
            color_phase: 0,
            test_log: log,
        }
    }
    
    fn update(&mut self, dt: f32) {
        self.frame_count += 1;
        
        // 测试 1:输入
        let speed = 300.0;
        if self.keys.contains(&KeyCode::KeyA) { self.player_x -= speed * dt; }
        if self.keys.contains(&KeyCode::KeyD) { self.player_x += speed * dt; }
        if self.keys.contains(&KeyCode::KeyW) { self.player_y -= speed * dt; }
        if self.keys.contains(&KeyCode::KeyS) { self.player_y += speed * dt; }
        
        // 测试 2:动态画面(变色)
        self.color_phase = (self.color_phase + 1) % 360;
        
        // 测试 3:音频
        if self.keys.contains(&KeyCode::Space) {
            self.audio_pipeline.as_ref().unwrap().set_freq(440.0);
        } else {
            self.audio_pipeline.as_ref().unwrap().set_freq(0.0);  // 静音
        }
        
        // 5 分钟(60 * 5 = 300 秒,300 * 60 = 18000 帧)后退出
        if self.frame_count > 18000 {
            self.test_log.push(format!("✓ ran 5 minutes"));
            self.test_log.push("=== Phase 1 Exit Criteria ===".to_string());
            self.test_log.push("✓ 1. Window opened".to_string());
            self.test_log.push("✓ 2. Dynamic display".to_string());
            self.test_log.push("✓ 3. Keyboard control".to_string());
            self.test_log.push("✓ 5. Space triggers audio".to_string());
            self.test_log.push("✓ 6. Audio playing".to_string());
            self.test_log.push("✓ 9. No crash in 5 minutes".to_string());
            for line in &self.test_log {
                println!("{}", line);
            }
            std::process::exit(0);
        }
    }
    
    fn render(&mut self) {
        if let Some(surface) = &mut self.surface {
            if let Ok(mut buf) = surface.buffer_mut() {
                // 动态背景色
                let r = ((self.color_phase as f32 / 360.0) * 255.0) as u32;
                let bg = 0xFF_00_00_00 | (r << 16);
                for px in buf.iter_mut() { *px = bg; }
                
                // 玩家方块
                let px = self.player_x as i32;
                let py = self.player_y as i32;
                for dy in 0..50 {
                    for dx in 0..50 {
                        let x = px + dx;
                        let y = py + dy;
                        if x >= 0 && (x as u32) < WIDTH && y >= 0 && (y as u32) < HEIGHT {
                            buf[y as usize * WIDTH as usize + x as usize] = 0xFFFF0000;
                        }
                    }
                }
                
                let _ = buf.present();
            }
        }
    }
}

impl ApplicationHandler for App {
    fn resumed(&mut self, event_loop: &winit::event_loop::ActiveEventLoop) {
        let window = Arc::new(event_loop.create_window(
            Window::default_attributes()
                .with_title("Day 025 Smoke Test")
                .with_inner_size(winit::dpi::LogicalSize::new(WIDTH, HEIGHT))
        ).unwrap());
        let context = softbuffer::Context::new(window.clone()).unwrap();
        let mut surface = softbuffer::Surface::new(&context, window.clone()).unwrap();
        let _ = surface.resize(
            std::num::NonZeroU32::new(WIDTH).unwrap(),
            std::num::NonZeroU32::new(HEIGHT).unwrap(),
        );
        self.window = Some(window);
        self.surface = Some(surface);
        self.test_log.push("✓ window + surface init".to_string());
    }
    
    fn about_to_wait(&mut self, _el: &winit::event_loop::ActiveEventLoop) {
        if let Some(w) = &self.window { w.request_redraw(); }
    }
    
    fn window_event(&mut self, el: &winit::event_loop::ActiveEventLoop,
                    _id: winit::window::WindowId, event: WindowEvent) {
        match event {
            WindowEvent::CloseRequested => el.exit(),
            WindowEvent::KeyboardInput { event: KeyEvent {
                state, physical_key: PhysicalKey::Code(c), ..
            }, .. } => {
                match state {
                    ElementState::Pressed => { self.keys.insert(c); }
                    ElementState::Released => { self.keys.remove(&c); }
                }
                if c == KeyCode::Escape { el.exit(); }
            }
            WindowEvent::RedrawRequested => {
                let now = Instant::now();
                let dt = (now - self.last_time).as_secs_f32().min(0.1);
                self.last_time = now;
                self.update(dt);
                self.render();
            }
            _ => ()
        }
    }
}

fn main() {
    println!("Phase 1 Smoke Test - starting...");
    let event_loop = EventLoop::new().unwrap();
    let mut app = App::new();
    event_loop.run_app(&mut app).unwrap();
}
```
