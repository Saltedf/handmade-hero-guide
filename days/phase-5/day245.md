
# Day 245 · 使用 wglChoosePixelFormatARB

> Day 242 你创建了 3.3 Core context,但 pixel format 是 driver 默认选的——可能没 sRGB、没 multisample、没 stereo。今天 Casey 用 `wglChoosePixelFormatARB`(Linux 等价:`glXChooseFBConfig` / `eglChooseConfig`)显式选 pixel format,精确控制 framebuffer 属性。

## 0 · 为什么要有这一天

**pixel format(像素格式)** —— framebuffer 的"属性集",包括:

- 颜色位深(24 位 RGB / 30 位 RGB / 16 位)
- alpha 位深(0 / 8)
- 深度 buffer 位深(0 / 16 / 24 / 32)
- stencil buffer 位深(0 / 8)
- multisample(0 / 2 / 4 / 8)x MSAA
- sRGB capable(true / false)
- 双缓冲(true / false)
- stereo(双目立体渲染,true / false)

Day 242 的 glutin 帮你选了默认值,可能不完全符合需求。Day 245 用 ARB 扩展**精确**指定,要什么选什么。

**为什么需要精确控制**:

- **2D 游戏** 不需要深度 / stencil / multisample,只要 RGBA8 + sRGB + double buffer。pixel format 越简单,driver 越快
- **3D 游戏** 要 24 位深度 + 8 位 stencil + 4x MSAA
- **HDR 游戏** 要 fp16 颜色 + sRGB capable + 可能 stereo

Windows 上 Day 241 的 sRGB 在某些 driver 默认 pixel format 下不工作。Casey 在 Day 245 显式请求 sRGB capable,确保跨机器一致。

**心理锚点**:看完今天,你能用 `eglChooseConfig` 或 `glXChooseFBConfig` 列出系统支持的所有 pixel format,挑最合适的。

## 1 · Casey 今天做了什么

Casey 重写 context 创建:

1. 用 `wglChoosePixelFormatARB` 替代 `ChoosePixelFormat`(Windows 旧 API)
2. 列出想要的属性数组:`WGL_DRAW_TO_WINDOW_ARB | WGL_SUPPORT_OPENGL_ARB | WGL_DOUBLEBUFFER_ARB | WGL_PIXEL_TYPE_RGBA_ARB | WGL_COLOR_BITS_ARB 24 | WGL_SRGB_CAPABLE_ARB true`
3. 选 driver 返回的最佳匹配
4. 用这个 pixel format 创建 context

Linux 等价:glutin 默认用 `glXChooseFBConfig` / `eglChooseConfig`,API 类似。

**关键决策**:列出**要求**和**优先**两组属性。要求不满足就 fail,优先用于排序多个候选。

## 2 · 心智模型

### 类比:买房时的需求清单

你买房列需求:

- **必须**(hard requirements):3 室、有停车、近地铁
- **想要**(preferences):朝南、楼层 5-10、有电梯

中介找符合"必须"的,按"想要"排序,推荐最好的。

### 2.1 属性列表格式

Windows ARB API 用"属性数组":

```c
int attrs[] = {
    WGL_DRAW_TO_WINDOW_ARB, GL_TRUE,
    WGL_SUPPORT_OPENGL_ARB, GL_TRUE,
    WGL_DOUBLEBUFFER_ARB, GL_TRUE,
    WGL_PIXEL_TYPE_ARB, WGL_TYPE_RGBA_ARB,
    WGL_COLOR_BITS_ARB, 24,
    WGL_ALPHA_BITS_ARB, 8,
    WGL_DEPTH_BITS_ARB, 24,
    WGL_STENCIL_BITS_ARB, 8,
    WGL_SRGB_CAPABLE_ARB, GL_TRUE,
    WGL_SAMPLE_BUFFERS_ARB, GL_TRUE,  // MSAA
    WGL_SAMPLES_ARB, 4,                // 4x MSAA
    0  // 终止
};
int pixel_format;
UINT num_formats;
wglChoosePixelFormatARB(hdc, attrs, NULL, 1, &pixel_format, &num_formats);
```

每个属性是 (key, value) 对,以 0 结尾。

### 2.3 glutin 0.30+ 的 API

glutin 把上面跨平台差异藏起来:

```rust
use glutin::config::ConfigTemplateBuilder;

let template = ConfigTemplateBuilder::new()
    .with_alpha_size(8)
    .with_depth_size(24)
    .with_stencil_size(8)
    .with_srgb_capable(true)  // sRGB capable
    .with_transparency(false)
    .with_multisampling(4)  // 4x MSAA
    .with_stereo(false)
    .with_double_buffer(true);

let configs = gl_display.find_configs(template.build());
let best_config = configs
    .filter(|c| c.srgb_capable())
    .max_by_key(|c| c.num_samples())  // 选 MSAA 最多的
    .expect("找不到合适 config");
```

glutin 内部调 `eglChooseConfig` / `glXChooseFBConfig`,你写一次跑全平台。

### 2.4 fallback 策略

某些 driver 不支持你想要的全部(老 GPU 没 MSAA)。fallback:

```rust
let template = ConfigTemplateBuilder::new()
    .with_alpha_size(8)
    .with_depth_size(24)
    .with_stencil_size(8)
    .with_srgb_capable(true);

let mut chosen = None;

// 优先尝试 MSAA 4x
if chosen.is_none() {
    let t = template.clone().with_multisampling(4).build();
    chosen = find_best(&gl_display, t);
}

// fallback MSAA 2x
if chosen.is_none() {
    let t = template.clone().with_multisampling(2).build();
    chosen = find_best(&gl_display, t);
}

// 最后 fallback 无 MSAA
if chosen.is_none() {
    chosen = find_best(&gl_display, template.build());
}

let config = chosen.expect("找不到任何 config");
```

这是"渐进降级":优先满足所有要求,不行就退而求其次。

### 2.6 MSAA(多重采样抗锯齿)

**MSAA(Multi-Sample Anti-Aliasing)** —— 每像素采多个点,边缘平滑。

```
普通:每像素 1 个采样点
MSAA 4x:每像素 4 个采样点(在子像素位置)
```

边缘三角形覆盖部分子像素,平均得最终颜色。开销:内存 4 倍,fill rate 4 倍。

跟 HH 学的 2D 游戏不太需要 MSAA(边缘是 quad 边界,本来就对齐像素),3D 大量用。Day 245 加上 MSAA 支持是为 Phase 6 准备。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

**pixel format 选错的代价**:

- 没 sRGB capable → Day 241 sRGB 失效,颜色错
- MSAA 0 → 3D 边缘锯齿
- 没 depth buffer → 3D 渲染排序错乱

游戏启动时打印 pixel format 信息,方便用户报 bug:"我看不到光照" → 看 log 是 sRGB false,告诉用户更新驱动。

**现代游戏设置菜单**有"质量"选项,允许用户选 MSAA on/off / sRGB on/off。这些其实是切换 pixel format 或 framebuffer 配置。

### 3.2 · 🎨 图形学视角

**深度 buffer / stencil buffer**:

- **深度 buffer(depth buffer, z-buffer)** —— 每像素存最近物体深度。光栅化时,新像素比较深度,新的近才画。Day 261+ 3D 渲染必备
- **stencil buffer** —— 每像素 8 位标志,用于"挡板"效果(阴影体积、轮廓、反射)

MSAA 和深度 buffer 的关系:

```
每像素 4 个子样本(subpixel)
深度 buffer 也是 4 倍大小:每子样本一个深度值
fragment shader 只跑一次(像素中心)
但深度测试 4 次,4 个子样本独立决定 write
```

这就是为什么 MSAA 比 SSAA(超采样)便宜——SSAA 每子样本都跑 shader。

## 5 · 对照与变奏

### MSAA vs SSAA vs FXAA

| | MSAA | SSAA | FXAA |
|---|---|---|---|
| 原理 | 多采样子像素,shader 跑一次 | 多采样整像素,shader 跑多次 | 后处理:smart blur |
| 内存 | N 倍 | N² 倍 | 0 |
| shader 调用 | 1x | N² x | 1x(全屏 pass) |
| 质量 | 边缘好,shader aliasing 仍存在 | 最好 | 中等(可能糊) |
| 现代 GPU | 主流 | 太贵,不用 | 后处理替代 |

跟 HH 用 MSAA,平衡。

### pixel format 选择策略

| | 严格 | 渐进降级 | 自动(driver 选) |
|---|---|---|---|
| 灵活性 | 低 | 中 | 高 |
| 一致性 | 高 | 中 | 低(因 driver 而异) |
| 兼容性 | 差(老硬件 fail) | 好 | 最好 |
| 推荐 | 不推荐 | ✅ | 简单 demo |

Day 245 的渐进降级最适合生产。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:MSAA 4x 比 FXAA 好在哪?为什么不用 SSAA 4x?

**参考解答**:

- **MSAA 4x vs FXAA** —— MSAA 是几何边缘抗锯齿,sharp 边缘平滑;FXAA 是后处理 smart blur,可能糊纹理细节。MSAA 质量更高
- **不用 SSAA 4x** —— SSAA 4x 每像素跑 4 次 fragment shader,4 倍 GPU 计算开销。MSAA 4x 只 depth test 4 次,shader 跑 1 次,开销 1/4。MSAA 是"聪明版 SSAA"——只在边缘做反锯齿

## 8 · Rust / Arch 落地代码

### Rust 完整 pixel format 选择

```rust
use glutin::config::{ConfigTemplateBuilder, GlConfig};
use glutin::context::{ContextApi, ContextAttributesBuilder, GlProfile, Version};
use glutin::display::GetGlDisplay;
use glutin::prelude::*;

fn choose_best_config(gl_display: &glutin::display::Display) -> glutin::config::Config {
    let base = ConfigTemplateBuilder::new()
        .with_alpha_size(8)
        .with_depth_size(24)
        .with_stencil_size(8)
        .with_srgb_capable(true)
        .with_double_buffer(true);

    let mut attempts = vec![
        base.clone().with_multisampling(8).build(),  // 最优先:8x MSAA
        base.clone().with_multisampling(4).build(),
        base.clone().with_multisampling(2).build(),
        base.build(),  // 最后:无 MSAA
    ];

    for template in attempts.drain(..) {
        let configs: Vec<_> = unsafe { gl_display.find_configs(template) }
            .ok()
            .map(|i| i.collect())
            .unwrap_or_default();
        if !configs.is_empty() {
            return configs.into_iter()
                .max_by_key(|c| c.num_samples())
                .unwrap();
        }
    }
    panic!("找不到任何 GL config");
}

fn main() {
    let event_loop = winit::event_loop::EventLoop::new().unwrap();

    let window_builder = winit::window::WindowBuilder::new()
        .with_title("Day 245 pixel format")
        .with_inner_size(winit::dpi::PhysicalSize::new(800, 600));

    let (window, gl_config, window_context) = glutin::GlutinWindowBuilder::new(window_builder)
        .with_gl_api(glutin::config::GlApi::OpenGl)
        .with_gl_profile(GlProfile::Core)
        .with_gl_version(Version::new(3, 3))
        // glutin 自动选 config,但你可以用 with_gl_config 覆盖
        .build(&event_loop)
        .unwrap()
        .split();

    let display = gl_config.display();

    println!("==== Pixel Format ====");
    println!("color bits: R{} G{} B{} A{}",
        gl_config.red_size(), gl_config.green_size(),
        gl_config.blue_size(), gl_config.alpha_size());
    println!("depth: {}", gl_config.depth_size());
    println!("stencil: {}", gl_config.stencil_size());
    println!("sRGB capable: {}", gl_config.srgb_capable());
    println!("MSAA samples: {}", gl_config.num_samples());
    println!("double buffer: {}", gl_config.double_buffer());

    // ... 后续创建 context,同 Day 242
}
```

## 10 · 深入:pixel format 选择的高级话题

casey 在 day245 用 `wglChoosePixelFormatARB`——更现代的像素格式选择 API。让我把它讲透。

### 10.1 ChoosePixelFormat vs wglChoosePixelFormatARB

两个 API:

**ChoosePixelFormat**(老):基于 PIXELFORMATDESCRIPTOR struct,功能有限。

**wglChoosePixelFormatARB**(新):基于 attribute 列表,支持 MSAA、float、sRGB 等。

```rust
let attrs = [
    wgl::DRAW_TO_WINDOW_ARB, true as i32,
    wgl::SUPPORT_OPENGL_ARB, true as i32,
    wgl::DOUBLE_BUFFER_ARB, true as i32,
    wgl::PIXEL_TYPE_ARB, wgl::TYPE_RGBA_ARB,
    wgl::COLOR_BITS_ARB, 32,
    wgl::DEPTH_BITS_ARB, 24,
    wgl::STENCIL_BITS_ARB, 8,
    wgl::SAMPLE_BUFFERS_ARB, 1,  // MSAA
    wgl::SAMPLES_ARB, 4,         // 4x MSAA
    wgl::FRAMEBUFFER_SRGB_CAPABLE_ARB, true as i32,
    0,
];

let mut format_id = 0;
let mut num_formats = 0;
wglChoosePixelFormatARB(hdc, attrs, ptr::null(), 1, &mut format_id, &mut num_formats);
```

### 10.2 MSAA(多重采样抗锯齿)

MSAA = Multi-Sample Anti-Aliasing。每个 pixel 多次采样,平滑边缘。

- 2x MSAA:每像素 2 个采样,~10% 性能损失
- 4x MSAA:每像素 4 个采样,~25% 性能损失
- 8x MSAA:每像素 8 个采样,~50% 性能损失

casey HH 用 4x MSAA,质量 vs 性能平衡。

### 10.3 sRGB capable framebuffer

sRGB framebuffer 自动 gamma 校正:

```rust
let attrs = [
    // ...
    wgl::FRAMEBUFFER_SRGB_CAPABLE_ARB, true as i32,
    0,
];

// 启用
gl.enable(glow::FRAMEBUFFER_SRGB);
```

### 10.4 HDR / float pixel format

现代 GPU 支持 float pixel format:

- R16F / R32F:16-bit / 32-bit float channel
- RGBA16F / RGBA32F
- 用于 HDR 渲染

```rust
let attrs = [
    wgl::PIXEL_TYPE_ARB, wgl::TYPE_RGBA_FLOAT_ARB,  // float pixel
```

### 10.5 driver 兼容性

不同 driver 对 pixel format 支持不一致:

- **NVIDIA**:全 feature 支持,stable
- **AMD**:大部分支持,偶尔 bug
- **Intel**:基础支持,高级 feature(MSAA 8x、HDR)可能缺失
- **llvmpipe**(软件):仅基础,性能慢

casey HH 在 day245 测试多 driver,确保兼容。

### 10.6 fallback 策略

如果用户 driver 不支持要求 format,fallback:

```rust
fn choose_pixel_format_with_fallback(hdc, attrs_high: &[i32]) -> i32 {
    // 1. 试 high spec
    let mut id = 0;
    let mut n = 0;
    wglChoosePixelFormatARB(hdc, attrs_high, ptr::null(), 1, &mut id, &mut n);
    if n > 0 { return id; }
    
    // 2. Fallback:去掉 MSAA
    let attrs_med = remove_msaa(attrs_high);
    wglChoosePixelFormatARB(hdc, attrs_med, ptr::null(), 1, &mut id, &mut n);
    if n > 0 { return id; }
    
    // 3. Fallback:基础格式
    let attrs_low = [/* 最基础 */];
    wglChoosePixelFormatARB(hdc, attrs_low, ptr::null(), 1, &mut id, &mut n);
    id
}
```

casey HH 简化版没有 fallback(假设 driver 支持)。生产项目要 graceful degrade。

```rust
        WGL_STENCIL_BITS_ARB, 8,

        WGL_SAMPLES_ARB, 4,

        wglChoosePixelFormatARB(

        );

    if num_formats == 0 {
        // Fallback: 无 MSAA
        // ...
    }
    
    format_id
}
```
