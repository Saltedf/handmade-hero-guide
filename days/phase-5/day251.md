### 2.1 immediate mode UI 回顾

Day 196 你学了 immediate mode:

```rust
// 每帧调用,函数返回当前状态
fn update(ui: &mut Ui) {
    if ui.button("Click me") {  // 每帧"声明"按钮
        // 点击时返回 true
    }

```

每帧 UI 从头重建,控件不是持久对象。状态(展开 / 输入文字)用 **GUI ID** 关联记忆:

```rust
struct UiState {
    expanded: HashMap<GuiId, bool>,    // 哪些节点展开
    search_text: String,                // 搜索框文字
    selected: Option<GuiId>,            // 当前选中节点
}
```

`GuiId` 用 Day 250 的 GUID(64 位 hash),确定性,跨帧一致。

### 2.2 展开状态持久化

```rust
fn draw_hierarchy(ui: &mut Ui, state: &mut UiState, node: &TreeNode, depth: usize) {
    if depth > ui.max_depth { return; }

    let id = node.guid;
    let is_expanded = state.expanded.entry(id).or_insert(false);

    let header = if node.children.is_empty() {
        format!("{}: {}", node.name, node.value)
    } else {
        format!("{}{} {}", if *is_expanded { "[-]" } else { "[+]" }, node.name, ...)
    };

    if ui.button(&header, id) {
        *is_expanded = !*is_expanded;  // 切换
    }

    if *is_expanded {
        for child in &node.children {
            draw_hierarchy(ui, state, child, depth + 1);
        }
    }
}
```

**关键**:`state.expanded.entry(id).or_insert(false)` 用 entry API,既查又改,一次操作。

```rust
}
```

- 不匹配的节点隐藏

### 2.5 键盘导航

```rust
fn handle_keyboard(ui: &mut Ui, state: &mut UiState, hierarchy: &TreeNode) {
    if ui.key_pressed(Key::Down) {
        state.selected = next_visible_node(hierarchy, state.selected);
    } else if ui.key_pressed(Key::Up) {
        state.selected = prev_visible_node(hierarchy, state.selected);
    } else if ui.key_pressed(Key::Right) {
        if let Some(id) = state.selected {
            state.expanded.insert(id, true);
        }
    } else if ui.key_pressed(Key::Left) {
        if let Some(id) = state.selected {
            state.expanded.insert(id, false);
        }
    }
}
```

**节点遍历**:用前序遍历 DFS 把所有 visible 节点排成 list,上下选就 list 里前后移。

### 2.6 immediate mode 的代价

每帧重建 UI 的代价:

- CPU 算 UI 布局,几万控件时占 5-10% 帧时间
- 哈希查找(GUID → state)频繁

好处:

- 状态自动同步(没有"忘记更新控件")
- 简单(没有 retained mode 的对象生命周期)
- 易调试(每帧独立,不依赖历史)

跟 HH 用 immediate mode,够用。Day 200-203 详细讲过这个 tradeoff。

```rust
use egui::{Context, Ui};

fn debug_hierarchy(ctx: &Context, state: &mut UiState, hierarchy: &TreeNode) {
    egui::SidePanel::left("debug").show(ctx, |ui| {
        // 搜索框
        ui.text_edit_singleline(&mut state.search_text);

        // 滚动区域
        egui::ScrollArea::vertical().show(ui, |ui| {
            draw_node(ui, state, hierarchy, 0);
        });
    });
}

fn draw_node(ui: &mut Ui, state: &mut UiState, node: &TreeNode, depth: usize) {
    if depth > 4 { return; }

    // 搜索过滤
    if !state.search_text.is_empty()
        && !node.name.contains(&state.search_text) {
        return;
    }

    let id = ui.make_persistent_id(node.guid);
    let header = egui::CollapsingHeader::new(&node.name)
        .id_source(id)
        .show(ui, |ui| {
            for child in &node.children {
                draw_node(ui, state, child, depth + 1);
            }
        });

    // 值显示
    ui.label(format!("{:?}", node.value));
}
```

## 5 · 对照与变奏

### Immediate vs Retained

| | Immediate | Retained |
|---|---|---|
| 控件对象 | 每帧新建 | 持久存在 |
| 状态管理 | ID 关联(显式) | 对象属性(隐式) |
| 同步 | 自动 | 手动 |
| 性能 | 中(每帧重建) | 高(增量更新) |
| 代码量 | 少 | 多 |
| 调试 | 易(每帧独立) | 难(状态多) |

游戏 / 实时工具用 immediate,桌面应用用 retained。

### 历史演化

- **1980s**:GUI 起步,retained mode(Smalltalk / Mac OS Classic)
- **1990s**:retained 主流(Windows / Motif / Qt)
- **2000s**:immediate mode 出现,游戏采用(casey+.sol HTML 时代)
- **2010s**:Dear ImGui 普及,游戏工业标配
- **2020s**:egui(Rust)成熟

跟 HH 手写 immediate,理解原理。后期可用 egui 加速。

```rust
fn button(ui: &Ui, label: &str, id: GuiId) -> bool {
    let rect = ui.layout.next();
```

### Lv2 · 动手实践

**题**:扩展 Day 250 的 debug UI,加展开状态持久化 + 深度限制。完成标准:展开一个节点,松开鼠标下一帧仍展开。

**参考解答**:

```rust
use std::collections::HashMap;

#[derive(Debug)]
pub struct TreeNode {
    pub name: String,
    pub value: Option<String>,
    pub children: Vec<TreeNode>,
}

pub struct UiState {
    pub expanded: HashMap<String, bool>,  // name -> expanded
    pub max_depth: usize,
}

impl UiState {
    pub fn new() -> Self {
        Self { expanded: HashMap::new(), max_depth: 4 }
    }

    pub fn is_expanded(&self, name: &str) -> bool {
        *self.expanded.get(name).unwrap_or(&false)
    }

    pub fn toggle(&mut self, name: &str) {
        let e = self.expanded.entry(name.to_string()).or_insert(false);
        *e = !*e;
    }
}

pub fn print_tree(node: &TreeNode, state: &UiState, depth: usize, prefix: String) {
    if depth > state.max_depth {
        println!("{}{}...", prefix, node.name);
        return;
    }

    let marker = if node.children.is_empty() {
        " "
    } else if state.is_expanded(&node.name) {
        "[-]"
    } else {
        "[+]"
    };

    let value_str = node.value.as_ref()
        .map(|v| format!(" = {}", v))
        .unwrap_or_default();
    println!("{}{} {}{}", prefix, marker, node.name, value_str);

    if state.is_expanded(&node.name) {
        for child in &node.children {
            print_tree(child, state, depth + 1, format!("{}  ", prefix));
        }
    }
}
```

### Rust 完整 debug 层级

```rust
use std::collections::HashMap;
use std::io::{self, Write};

#[derive(Debug)]
pub struct TreeNode {
    pub name: String,
    pub value: Option<String>,
    pub children: Vec<TreeNode>,
}

impl TreeNode {
    pub fn leaf(name: &str, value: &str) -> Self {
        Self {
            name: name.to_string(),
            value: Some(value.to_string()),
            children: vec![],
        }
    }

    pub fn parent(name: &str, children: Vec<TreeNode>) -> Self {
        Self {
            name: name.to_string(),
            value: None,
            children,
        }
    }
}

pub struct UiState {
    pub expanded: HashMap<String, bool>,
    pub max_depth: usize,
    pub search: String,
}

impl UiState {
    pub fn new() -> Self {
        Self {
            expanded: HashMap::new(),
            max_depth: 4,
            search: String::new(),
        }
    }

    fn matches_search(&self, name: &str) -> bool {
        self.search.is_empty() || name.contains(&self.search)
    }
}

pub fn render(node: &TreeNode, state: &mut UiState, depth: usize, prefix: &str) {
    if depth > state.max_depth {
        println!("{}{}...", prefix, node.name);
        return;
    }

    // 搜索过滤:不匹配且无后代匹配 → 跳过
    let self_matches = state.matches_search(&node.name);
    let descendant_matches = !state.search.is_empty() &&
        node.children.iter().any(|c| subtree_matches(c, &state.search));

    if !state.search.is_empty() && !self_matches && !descendant_matches {
        return;
    }

    let marker = if node.children.is_empty() {
        " "
    } else if *state.expanded.get(&node.name).unwrap_or(&false) || !state.search.is_empty() {
        "[-]"
    } else {
        "[+]"
    };

    let value_str = node.value.as_ref()
        .map(|v| format!(" = {}", v))
        .unwrap_or_default();
    println!("{}{} {}{}", prefix, marker, node.name, value_str);

    let is_expanded = state.expanded.get(&node.name).copied().unwrap_or(false)
        || !state.search.is_empty();

    if is_expanded {
        let child_prefix = format!("{}  ", prefix);
        for child in &node.children {
            render(child, state, depth + 1, &child_prefix);
        }
    }
}

fn subtree_matches(node: &TreeNode, search: &str) -> bool {
    if search.is_empty() { return true; }
    node.name.contains(search) || node.children.iter().any(|c| subtree_matches(c, search))
}

fn main() {
    let tree = TreeNode::parent("game", vec![
        TreeNode::parent("player", vec![
            TreeNode::leaf("health", "100"),
            TreeNode::leaf("pos", "(50, 30)"),
            TreeNode::parent("inventory", vec![
                TreeNode::leaf("sword", "1"),
                TreeNode::leaf("shield", "1"),
                TreeNode::leaf("arrows", "42"),
            ]),
        ]),
        TreeNode::parent("enemies", vec![
            TreeNode::leaf("count", "5"),
            TreeNode::leaf("alive", "3"),
        ]),
        TreeNode::parent("render", vec![
            TreeNode::leaf("draw_calls", "247"),
            TreeNode::leaf("frame_time", "16.3ms"),
        ]),
    ]);

    let mut state = UiState::new();

    loop {
        println!("\n=== Debug Hierarchy ===");
        render(&tree, &mut state, 0, "");

        print!("\n命令 [空=刷新 / e=展开 / c=折叠 / s=搜索 / q=退出]: ");
        io::stdout().flush().unwrap();
        let mut input = String::new();
        io::stdin().read_line(&mut input).unwrap();
        let input = input.trim();

        if input == "q" { break; }
        else if input == "e" {
            print!("展开节点名: ");
            io::stdout().flush().unwrap();
            let mut name = String::new();
            io::stdin().read_line(&mut name).unwrap();
            state.expanded.insert(name.trim().to_string(), true);
        }
        else if input == "c" {
            print!("折叠节点名: ");
            io::stdout().flush().unwrap();
            let mut name = String::new();
            io::stdin().read_line(&mut name).unwrap();
            state.expanded.insert(name.trim().to_string(), false);
        }
        else if input == "s" {
            print!("搜索文字: ");
            io::stdout().flush().unwrap();
            state.search.clear();
            io::stdin().read_line(&mut state.search).unwrap();
            state.search = state.search.trim().to_string();
        }
    }
}
```

### 10.3 collapse 状态的实现

```rust
struct DebugHierarchy {
    root: TreeNode,
    collapsed: HashSet<u64>,  // guid 集合,折叠的 node
}

impl DebugHierarchy {
    fn is_collapsed(&self, guid: u64) -> bool {
        self.collapsed.contains(&guid)
    }
    
    fn toggle(&mut self, guid: u64) {
        if self.collapsed.contains(&guid) {
            self.collapsed.remove(&guid);
        } else {
            self.collapsed.insert(guid);
        }
    }
}
```

`collapsed` 是 HashSet,存储所有折叠的 node guid。每帧渲染时检查。

### 10.4 immediate mode UI 的状态保留

immediate mode UI 每帧从头渲染,但状态需要保留。casey 的方案:

```rust
fn draw_node(ui: &mut Ui, hierarchy: &mut DebugHierarchy, node: &TreeNode) {
    let guid = node.guid;
    let is_collapsed = hierarchy.is_collapsed(guid);
    
    if ui.button(if is_collapsed { "+" } else { "-" }) {
        hierarchy.toggle(guid);
    }
    ui.label(&node.name);
    
    if !is_collapsed {
        for child in &node.children {
            ui.indent();
            draw_node(ui, hierarchy, child);
            ui.unindent();
        }
    }
}
```

immediate mode 每帧调用 `draw_node`,但 `hierarchy.collapsed` 跨帧保留。状态正确。

### 10.5 search filter 的实现

```rust
fn draw_filtered(ui: &mut Ui, hierarchy: &DebugHierarchy, filter: &str) {
    let filter_lower = filter.to_lowercase();
    let matching_guids: HashSet<u64> = hierarchy.all_nodes()
        .filter(|n| n.name.to_lowercase().contains(&filter_lower))
        .map(|n| n.guid)
        .collect();
    
    draw_node_filtered(ui, hierarchy, &hierarchy.root, &matching_guids);
}

fn draw_node_filtered(ui, hierarchy, node, matching) {
    // 如果当前 node 匹配,或任何子节点匹配,显示
    let any_match = matching.contains(&node.guid) 
        || node.children.iter().any(|c| subtree_contains(c, matching));
    if !any_match { return; }
    
    // 如果搜索激活,所有 node 强制展开
    let force_expand = !matching.is_empty();
    draw_node_with_force_expand(ui, hierarchy, node, force_expand);
}
```

搜索激活时,所有包含匹配的子树强制展开,显示所有匹配项。
