### 2.2 删 fallback 路径

Day 245 的 fallback:

```rust
let template = base_template.clone();
let configs: Vec<_> = unsafe { display.find_configs(template) }?.collect();
if configs.is_empty() {
    // fallback 1: MSAA 2x
    let template = base_template.clone().with_multisampling(2);
    let configs: Vec<_> = unsafe { display.find_configs(template) }?.collect();
    if configs.is_empty() {
        // fallback 2: 无 MSAA
        let template = base_template.clone();
        // ...
    }
}
```

Day 257 简化:

```rust
let template = base_template.with_srgb_capable(true);
let config: Config = unsafe { display.find_configs(template) }?
    .next()
    .expect("GPU 不支持 OpenGL 3.3 sRGB capable,请更新驱动");
```

**简洁,要求明确**。老 GPU 直接 fail with 错误信息,不悄悄降级。

### 2.4 平台抽象层

Linux 平台层清理:

```rust
// 之前:多套平台代码

mod linux_x11 {
    pub fn create_context() -> ... { /* GLX */ }
}

#[cfg(target_os = "linux")]

    pub fn create_context() -> ... { /* EGL */ }
}

// 之后:统一用 glutin

    }

```

glutin 抽象 X11/Wayland 差异,你不用关心。

### 2.5 删 deprecated API 调用

```rust
// 之前(Day 235 时代,旧 glutin)
```

API 演化,旧 API 删,只留新。

### 10.11 Rust 跨平台实践

Rust 跨平台代码的标准实践:

```rust
// 平台抽象
#[cfg(target_os = "windows")]
mod windows;

#[cfg(target_os = "linux")]
mod linux;

#[cfg(target_os = "macos")]

pub fn create_window() -> Window {

    #[cfg(target_os = "linux")]
    { linux::create_window() }
    #[cfg(not(any(target_os = "windows", target_os = "linux")))]
```
