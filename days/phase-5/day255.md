# Day 255 · 构建性能分析树

> Day 254 你能测 CPU + GPU 时间,但数据是平的 list("update: 2ms", "draw_player: 0.5ms")。看不出**调用层次**——update 包含什么?draw_player 又包含什么?今天 Casey 把 profiler 数据组织成**调用树**,像火焰图(flame graph)。

## 0 · 为什么要有这一天

Day 254 的输出:

```
CPU update: 2.1 ms
CPU draw: 0.8 ms
GPU frame: 9.3 ms
```

平铺,看不出 update 内部哪个函数慢。Day 255 改成树:

```
frame (12.4ms)
├── update (2.1ms)
│   ├── input (0.1ms)
│   ├── physics (1.5ms)
│   │   ├── collide_player (0.8ms)
│   │   └── collide_enemies (0.7ms)
│   └── ai (0.5ms)
├── render (0.8ms)
│   ├── enqueue_sprites (0.3ms)
│   └── sort (0.5ms)
└── gpu_frame (9.3ms)
    ├── vertex_shader (2.1ms)
    └── fragment_shader (6.8ms)
```

一眼看出 fragment shader 是瓶颈(6.8ms),不是 game_update。

**为什么这件事重要**:树形 profile 把"哪个函数慢"变成"哪条调用路径慢"。优化路径上的关键节点,帧时间立降。

**心理锚点**:看完今天,你的 profiler 像商业工具(chrome://tracing / Optick)一样展示调用树。

## 1 · Casey 今天做了什么

Casey 把 profiler 改成"begin/end 嵌套":

1. `profiler.begin("frame")`
2. `profiler.begin("update")` —— frame 的子节点
3. `profiler.begin("physics")` —— update 的子节点
4. `profiler.end()` —— physics 结束
5. 重复
6. `profiler.end()` —— frame 结束
7. 构建 ProfileTree

**关键决策**:**栈式 begin/end**——begin 入栈,end 出栈。栈顶是当前 active scope,end 关闭当前。这样调用嵌套关系自动建立。

## 2 · 心智模型

### 类比:Git commit history

Git commit 是树形,每个 commit 有 parent。`git log --graph` 可视化树。

Profile 一样:每个 begin 是 commit,end 关闭 commit。最后整个 frame 是一棵树。

### 2.1 栈式 profiler

```rust
pub struct Profiler {
    stack: Vec<NodeId>,  // 当前嵌套栈
    nodes: Vec<Node>,     // 所有节点
}

struct Node {
    name: &'static str,
    start_ns: u64,
    end_ns: u64,
    parent: Option<NodeId>,
    children: Vec<NodeId>,
}

impl Profiler {
    pub fn begin(&mut self, name: &'static str) {
        let parent = self.stack.last().copied();
        let node_id = NodeId(self.nodes.len());
        self.nodes.push(Node {
            name, start_ns: now_ns(),
            end_ns: 0, parent, children: vec![],
        });
        if let Some(p) = parent {
            self.nodes[p.0].children.push(node_id);
        }
        self.stack.push(node_id);
    }

    pub fn end(&mut self) {
        let id = self.stack.pop().expect("unbalanced end");
        self.nodes[id.0].end_ns = now_ns();
    }
}

fn now_ns() -> u64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap().as_nanos() as u64
}
```

**关键**:`stack.last()` 拿当前 parent,新节点入栈前记录 parent。end 时 pop 栈顶。

### 2.2 用法

```rust
profiler.begin("frame");

profiler.begin("update");
profiler.begin("physics");

// ... 物理代码 ...
profiler.end();  // collide_player
profiler.begin("collide_enemies");
// ...

profiler.end();  // physics

profiler.begin("ai");
// ... AI 代码 ...
profiler.end();  // ai
profiler.end();  // update

profiler.begin("render");
// ... 渲染 ...
profiler.end();  // render
profiler.end();  // frame

profiler.print_tree();
```

### 2.3 树形打印

```rust
impl Profiler {
    pub fn print_tree(&self) {
        // 找根节点(parent = None)
        for (i, node) in self.nodes.iter().enumerate() {
            if node.parent.is_none() {
                self.print_node(NodeId(i), 0);
            }
        }
    }

    fn print_node(&self, id: NodeId, depth: usize) {
        let node = &self.nodes[id.0];
        let indent = "  ".repeat(depth);
        let duration = node.end_ns - node.start_ns;
        let duration_ms = duration as f64 / 1e6;
        println!("{}{} ({:.2}ms)", indent, node.name, duration_ms);
        for child in &node.children {
            self.print_node(*child, depth + 1);
        }
    }
}
```

### 2.4 RAII guard

Rust 风格用 Drop guard 自动 end:

```rust
pub struct ScopeGuard<'a> {
    profiler: &'a mut Profiler,
}

impl<'a> Drop for ScopeGuard<'a> {
    fn drop(&mut self) {
        self.profiler.end();
    }
}

impl Profiler {
    pub fn scope(&mut self, name: &'static str) -> ScopeGuard<'_> {
        self.begin(name);
        ScopeGuard { profiler: self }
    }
}

// 用法
fn game_update(profiler: &mut Profiler) {
    let _g = profiler.scope("game_update");

    {
        let _g = profiler.scope("physics");
        // ... 物理代码 ...
    }  // _g drop,自动 end physics

    {
        let _g = profiler.scope("ai");
        // ... AI ...
    }
}  // _g drop,自动 end game_update
```

RAII 防漏 end,panic 也安全(unwind 调 drop)。

### Lv1 · 概念辨析

**题**:为什么 profiler 用栈式 begin/end,而不是给每个 begin 一个 parent 参数?

**参考解答**:栈式自动反映调用嵌套,代码自然。如果显式传 parent:

```rust
profiler.begin("frame", None);
profiler.begin("update", Some(frame_id));
profiler.begin("physics", Some(update_id));
```

每个函数要知道自己的 parent id,繁琐易错。栈式直接反映调用关系,调用栈本身就是 parent 来源。

```rust
profiler.begin("frame");
profiler.begin("update");  // 自动 parent = frame
profiler.begin("physics"); // 自动 parent = update
```

简洁,自动正确。

## 8 · Rust / Arch 落地代码

### Rust 完整栈式 profiler

```rust
use std::time::Instant;

#[derive(Copy, Clone, Debug, PartialEq, Eq)]
pub struct NodeId(pub usize);

pub struct Node {
    pub name: &'static str,
    pub start: Instant,
    pub end: Option<Instant>,
    pub parent: Option<NodeId>,
    pub children: Vec<NodeId>,
}

pub struct Profiler {
    nodes: Vec<Node>,
    stack: Vec<NodeId>,
    roots: Vec<NodeId>,
}

impl Profiler {
    pub fn new() -> Self {
        Self { nodes: vec![], stack: vec![], roots: vec![] }
    }

    pub fn begin(&mut self, name: &'static str) {
        let parent = self.stack.last().copied();
        let id = NodeId(self.nodes.len());
        self.nodes.push(Node {
            name, start: Instant::now(), end: None,
            parent, children: vec![],
        });
        if let Some(p) = parent {
            self.nodes[p.0].children.push(id);
        } else {
            self.roots.push(id);
        }
        self.stack.push(id);
    }

    pub fn end(&mut self) {
        let id = self.stack.pop().expect("unbalanced end");
        self.nodes[id.0].end = Some(Instant::now());
    }

    pub fn scope(&mut self, name: &'static str) -> ScopeGuard<'_> {
        self.begin(name);
        ScopeGuard { profiler: self }
    }

    pub fn print_tree(&self) {
        for root in &self.roots {
            self.print_node(*root, 0);
        }
    }

    fn print_node(&self, id: NodeId, depth: usize) {
        let node = &self.nodes[id.0];
        let duration = node.end.map(|e| e.duration_since(node.start));
        let indent = "  ".repeat(depth);
        let dur_str = duration
            .map(|d| format!("({:.2}ms)", d.as_secs_f64() * 1000.0))
            .unwrap_or_default();
        println!("{}{} {}", indent, node.name, dur_str);
        for child in &node.children {
            self.print_node(*child, depth + 1);
        }
    }

    pub fn reset(&mut self) {
        self.nodes.clear();
        self.stack.clear();
        self.roots.clear();
    }
}

pub struct ScopeGuard<'a> {
    profiler: &'a mut Profiler,
}

impl<'a> Drop for ScopeGuard<'a> {
    fn drop(&mut self) {
        self.profiler.end();
    }
}

#[macro_export]
macro_rules! profile_scope {
    ($p:expr, $name:literal) => {
        let _guard = $p.scope($name);
    };
}

fn main() {
    let mut profiler = Profiler::new();

    profiler.begin("frame");
    std::thread::sleep(std::time::Duration::from_micros(100));

    profiler.begin("update");
    std::thread::sleep(std::time::Duration::from_micros(50));

    {
        profile_scope!(profiler, "physics");
        std::thread::sleep(std::time::Duration::from_micros(30));

        profile_scope!(profiler, "collide_player");
        std::thread::sleep(std::time::Duration::from_micros(20));
        // _guard drop,自动 end
    }
    profiler.end();  // update

    {
        let _g = profiler.scope("ai");
        std::thread::sleep(std::time::Duration::from_micros(40));
    }

    {
        let _g = profiler.scope("render");
        std::thread::sleep(std::time::Duration::from_micros(60));
    }

    profiler.end();  // frame

    println!("=== Profile Tree ===");
    profiler.print_tree();
}
```

预期输出:

```
=== Profile Tree ===
frame (250.5ms)
  update (121.2ms)
    physics (51.3ms)
      collide_player (20.5ms)
    ai (40.3ms)
  render (60.6ms)
```

## 10 · 深入:构建 profiler 树

casey 在 day255 构建 profiler 树——把 flat 的 profile 数据组织成调用层级树。

### 10.1 profiler 数据的原始形式

```rust
struct ProfileEvent {
    guid: u64,
    thread_id: u32,
    begin_time: u64,
    end_time: u64,
}
```

每条 event 是 begin/end 对,需要组织成树。

### 10.2 树构建算法

```rust
fn build_tree(events: &[ProfileEvent]) -> ProfileTree {
    let mut stack: Vec<TreeNode> = vec![];
    let mut roots: Vec<TreeNode> = vec![];
    
    for event in events {
        let node = TreeNode {
            event: event.clone(),
            children: vec![],
        };
        
        // 推入栈,如果栈非空,作为栈顶的子节点
        if let Some(parent) = stack.last_mut() {
            parent.children.push(node.clone());
        }
        stack.push(node);
        
        // 检查栈顶是否可以弹出(end_time 到达)
        while let Some(top) = stack.last() {
            if top.event.end_time <= event.end_time {
                let popped = stack.pop().unwrap();
                if stack.is_empty() {
                    roots.push(popped);
                }
            } else {
                break;
            }
        }
    }
    
    ProfileTree { roots }
}
```

casey 在 day255 实现类似算法。

### 10.5 flame graph 渲染

```rust
fn render_flame_graph(ui: &mut Ui, tree: &ProfileTree) {
    fn render_node(ui: &mut Ui, node: &TreeNode, depth: usize, total: f32) {
        let width = (node.duration() / total) * ui.available_width();
        let rect = ui.allocate_rect(width, 16.0);
        ui.painter().rect_filled(rect, color(depth));
        ui.label(&format!("{}", node.event.name()));
        
        for child in &node.children {
            render_node(ui, child, depth + 1, node.duration());
        }
    }
    
    for root in &tree.roots {
        render_node(ui, root, 0, root.duration());
    }
}
```
