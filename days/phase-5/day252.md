# Day 252 · 允许调试值编辑

> Day 247 简化 debug value,加了 `editable: bool` 字段但没真用。Day 251 完善层级显示。今天 Casey 加**运行时编辑**——在 debug UI 里点击值,弹编辑框,改完游戏立刻看到效果。这是 debug 系统的杀手锏功能。

## 0 · 为什么要有这一天

游戏开发痛点:**调参慢**。例:

- 把角色速度从 5.0 调到 5.2 看效果
- 改代码 → 编译 → 启动 → 进入游戏 → 测试 → 不对再来

每个循环 30 秒到 1 分钟,几十次循环浪费一小时。

Day 252 你做的事:**F2 弹出 debug UI → 找到 player_speed → 点编辑 → 输入 5.2 → 回车**。游戏立刻用新值,**0 重启**。调参从 30 秒到 1 秒。

**为什么这件事重要**:**反馈循环**决定开发效率。短反馈 = 快迭代 = 多试验 = 更好游戏。Casey 整个 Phase 5 的 debug 系统就是为这一刻——能运行时编辑游戏参数。

**心理锚点**:看完今天,你的游戏能像商业引擎(Unreal / Unity)那样运行时调参,迭代速度翻倍。

## 1 · Casey 今天做了什么

Casey 加 debug 值编辑:

1. debug UI 双击值,弹编辑框(immediate mode)
2. 编辑框支持 f32 / bool / Vec3 / Color / String
3. 回车提交 / Esc 取消
4. 提交后:`DEBUG_STORE.set(guid, new_value)` → 游戏代码立刻读到新值
5. 加快捷键:F2 切 debug UI,F4 编辑选中项

**关键决策**:**编辑值实时生效**——每次 set 后游戏下一帧就用新值,不等"提交"。这样滑动数字时立刻看到效果。

## 2 · 心智模型

### 类比:汽车的实时调整

赛车手开赛车,工程师在 garage 调悬挂硬度 / 引擎参数。这是**实时调整**——不停引擎改设置,跑一圈回来再调。

### 2.1 immediate mode 编辑框

```rust
struct UiState {
    editing: Option<GuiId>,     // 正在编辑的项
    edit_buffer: String,         // 编辑框文字
}

fn draw_value(ui: &Ui, state: &mut UiState, value: &mut Value, id: GuiId) {
    if state.editing == Some(id) {
        // 显示编辑框
        ui.text_input(&mut state.edit_buffer);
        if ui.enter_pressed() {
            // 解析并写入
            if let Ok(new_value) = parse_value(&state.edit_buffer, value) {
                *value = new_value;
            }
            state.editing = None;
        }
        if ui.escape_pressed() {
            state.editing = None;
        }
    } else {
        // 显示值,双击开始编辑
        let display = format!("{:?}", value);
        if ui.label_double_clicked(&display, id) {
            state.editing = Some(id);
            state.edit_buffer = display;
        }
    }
}
```

**关键**:immediate mode 下编辑状态用 `state.editing: Option<GuiId>` 记忆,不创建持久控件对象。

### 2.2 多类型支持

```rust
fn parse_value(s: &str, target: &Value) -> Result<Value, String> {
    match target {
        Value::F32(_) => {
            let v: f32 = s.parse().map_err(|e: std::num::ParseFloatError| e.to_string())?;
            Ok(Value::F32(v))
        }
        Value::Bool(_) => {
            let b = match s.to_lowercase().as_str() {
                "true" | "1" | "yes" => true,
                "false" | "0" | "no" => false,
                _ => return Err("invalid bool".into()),
            };
            Ok(Value::Bool(b))
        }
        Value::Vec3(_) => {
            // 解析 "(x, y, z)"
            let s = s.trim_start_matches('(').trim_end_matches(')');
            let parts: Vec<&str> = s.split(',').map(|s| s.trim()).collect();
            if parts.len() != 3 { return Err("expect 3 numbers".into()); }
            Ok(Value::Vec3([
                parts[0].parse().map_err(|e: std::num::ParseFloatError| e.to_string())?,
                parts[1].parse().map_err(|e: std::num::ParseFloatError| e.to_string())?,
                parts[2].parse().map_err(|e: std::num::ParseFloatError| e.to_string())?,
            ]))
        }
        Value::Color(_) => {
            // 解析 "#RRGGBBAA"
            // ...
        }
        Value::String(_) => Ok(Value::String(Box::from(s))),
    }
}
```

### 2.5 撤销 / 重做

进阶:记录每次编辑,支持 Ctrl+Z 撤销:

```rust
struct EditHistory {
    edits: Vec<(Guid, Value)>,  // (GUID, 旧值)
    redo_stack: Vec<(Guid, Value)>,
}

fn apply_edit(history: &mut EditHistory, store: &mut DebugStore,
              guid: Guid, new_value: Value) {
    if let Some(old) = store.get(guid) {
        history.edits.push((guid, old.clone()));
    }
    store.set(guid, new_value);
    history.redo_stack.clear();
}

fn undo(history: &mut EditHistory, store: &mut DebugStore) {
    if let Some((guid, old)) = history.edits.pop() {
        if let Some(current) = store.get(guid) {
            history.redo_stack.push((guid, current.clone()));
        }
        store.set(guid, old);
    }
}
```

跟 HH 学不做 undo(超范围),记笔记。

### Lv2 · 动手实践

**题**:在 Day 251 的层级 UI 加编辑功能。完成标准:双击值,变成输入框,输入新值回车,值更新。

**参考解答**:

```rust
use std::io::{self, Write};

pub struct UiState {
    pub editing: Option<String>,  // 正在编辑的路径
    pub edit_buffer: String,
    pub values: HashMap<String, f32>,
}

impl UiState {
    pub fn new() -> Self {
        let mut values = HashMap::new();
        values.insert("game.player.speed".to_string(), 5.0);
        values.insert("game.player.health".to_string(), 100.0);
        values.insert("game.gravity".to_string(), 9.8);
        Self {
            editing: None,
            edit_buffer: String::new(),
            values,
        }
    }

    pub fn edit(&mut self, path: &str) {
        if let Some(v) = self.values.get(path) {
            self.editing = Some(path.to_string());
            self.edit_buffer = format!("{}", v);
        }
    }

    pub fn commit(&mut self) {
        if let Some(path) = self.editing.take() {
            if let Ok(v) = self.edit_buffer.parse::<f32>() {
                self.values.insert(path, v);
                println!("已更新");
            } else {
                println!("解析失败");
            }
        }
    }

    pub fn cancel(&mut self) {
        self.editing = None;
    }
}

fn main() {
    let mut state = UiState::new();

    loop {
        println!("\n=== Debug Values ===");
        for (path, value) in &state.values {
            if state.editing.as_deref() == Some(path.as_str()) {
                print!("{} = [{}] ", path, state.edit_buffer);
            } else {
                println!("{} = {}", path, value);
            }
        }

        print!("\n命令 [e=编辑 / q=退出]: ");
        io::stdout().flush().unwrap();
        let mut input = String::new();
        io::stdin().read_line(&mut input).unwrap();
        let cmd = input.trim();

        if cmd == "q" { break; }
        else if cmd == "e" {
            print!("编辑路径: ");
            io::stdout().flush().unwrap();
            let mut path = String::new();
            io::stdin().read_line(&mut path).unwrap();
            state.edit(path.trim());
            if state.editing.is_some() {
                print!("新值 [{}]: ", state.edit_buffer);
                io::stdout().flush().unwrap();
                let mut new_val = String::new();
                io::stdin().read_line(&mut new_val).unwrap();
                let new_val = new_val.trim();
                if !new_val.is_empty() {
                    state.edit_buffer = new_val.to_string();
                }
                state.commit();
            }
        }
    }
}
```

### Rust 完整 debug 编辑

```rust
use std::collections::HashMap;
use std::io::{self, Write};

#[derive(Clone, Debug)]
pub enum Value {
    F32(f32),
    Bool(bool),
    Vec3([f32; 3]),
    String(Box<str>),
}

impl std::fmt::Display for Value {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        match self {
            Value::F32(v) => write!(f, "{:.3}", v),
            Value::Bool(b) => write!(f, "{}", b),
            Value::Vec3(v) => write!(f, "({:.2}, {:.2}, {:.2})", v[0], v[1], v[2]),
            Value::String(s) => write!(f, "{}", s),
        }
    }
}

impl Value {
    fn parse(s: &str, target: &Value) -> Result<Value, String> {
        match target {
            Value::F32(_) => Ok(Value::F32(s.parse().map_err(|e: std::num::ParseFloatError| e.to_string())?)),
            Value::Bool(_) => {
                let b = match s.to_lowercase().as_str() {
                    "true" | "1" | "yes" => true,
                    "false" | "0" | "no" => false,
                    _ => return Err(format!("invalid bool: {}", s)),
                };
                Ok(Value::Bool(b))
            }
            Value::Vec3(_) => {
                let s = s.trim_start_matches('(').trim_end_matches(')');
                let parts: Vec<&str> = s.split(',').map(|s| s.trim()).collect();
                if parts.len() != 3 { return Err("expected 3 numbers".into()); }
                Ok(Value::Vec3([
                    parts[0].parse().map_err(|e: std::num::ParseFloatError| e.to_string())?,
                    parts[1].parse().map_err(|e: std::num::ParseFloatError| e.to_string())?,
                    parts[2].parse().map_err(|e: std::num::ParseFloatError| e.to_string())?,
                ]))
            }
            Value::String(_) => Ok(Value::String(Box::from(s))),
        }
    }
}

pub struct DebugStore {
    values: HashMap<String, Value>,
    editing: Option<String>,
    edit_buffer: String,
}

impl DebugStore {
    pub fn new() -> Self {
        let mut values = HashMap::new();
        values.insert("player.speed".into(), Value::F32(5.0));
        values.insert("player.health".into(), Value::F32(100.0));
        values.insert("player.alive".into(), Value::Bool(true));
        values.insert("player.pos".into(), Value::Vec3([50.0, 30.0, 0.0]));
        values.insert("player.name".into(), Value::String("Hero".into()));
        values.insert("gravity".into(), Value::F32(9.8));
        Self { values, editing: None, edit_buffer: String::new() }
    }

    pub fn start_edit(&mut self, key: &str) {
        if let Some(v) = self.values.get(key) {
            self.editing = Some(key.to_string());
            self.edit_buffer = format!("{}", v);
        }
    }

    pub fn commit(&mut self, new_text: &str) {
        if let Some(key) = self.editing.take() {
            if let Some(target) = self.values.get(&key) {
                let target = target.clone();
                match Value::parse(new_text, &target) {
                    Ok(v) => {
                        self.values.insert(key, v);
                        println!("已更新");
                    }
                    Err(e) => println!("解析失败: {}", e),
                }
            }
        }
    }

    pub fn cancel(&mut self) {
        self.editing = None;
    }

    pub fn display(&self) {
        println!("\n=== Debug Values (F2 = 编辑选中) ===");
        for (k, v) in &self.values {
            let marker = if self.editing.as_deref() == Some(k.as_str()) { "*" } else { " " };
            println!("{} {:30}: {}", marker, k, v);
        }
    }
}

fn main() {
    let mut store = DebugStore::new();

    loop {
        store.display();
        print!("\n[e] 编辑 [q] 退出: ");
        io::stdout().flush().unwrap();
        let mut input = String::new();
        io::stdin().read_line(&mut input).unwrap();

        match input.trim() {
            "q" => break,
            "e" => {
                print!("键名: ");
                io::stdout().flush().unwrap();
                let mut key = String::new();
                io::stdin().read_line(&mut key).unwrap();
                let key = key.trim();
                if !store.values.contains_key(key) {
                    println!("未找到: {}", key);
                    continue;
                }
                store.start_edit(key);
                println!("当前: {} (回车保留)", store.edit_buffer);
                print!("新值: ");
                io::stdout().flush().unwrap();
                let mut val = String::new();
                io::stdin().read_line(&mut val).unwrap();
                let val = val.trim();
                let final_val = if val.is_empty() { &store.edit_buffer } else { val };
                store.commit(final_val);
            }
            _ => {}
        }
    }
}
```

## 10 · 深入:debug value 编辑的实现

casey 在 day252 允许 debug value 编辑——用户可以在 UI 里直接修改 debug 变量,实时影响游戏。

### 10.1 编辑的实现

```rust
fn draw_editable_value(ui: &mut Ui, value: &mut DebugValue) {
    match value {
        DebugValue::Float(f) => {
            ui.add(egui::DragValue::new(f).speed(0.1).range(-100.0..=100.0));
        }
        DebugValue::Int(i) => {
            ui.add(egui::DragValue::new(i).range(0..=1000));
        }
        DebugValue::Bool(b) => {
            ui.checkbox(b);
        }
        DebugValue::Text(s) => {
            ui.text_edit_singleline(s);
        }
    }
}
```

用户拖动 / 输入,直接修改 debug value。

### 10.2 实时反馈

debug value 修改后,游戏逻辑立即反映:

```rust
fn update_player(state: &mut GameState) {
    // 读 debug value,不是硬编码
    let speed = state.debug_store.get_f32("player/speed");
    state.player.position += state.player.velocity * speed * dt;
}
```

开发者修改"player/speed",游戏立即按新速度运行。无需重启、无需重新编译。
