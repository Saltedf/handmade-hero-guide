# Day 594 · 从中心-半径切换到最小-最大

> Casey 之前用 AABB(Axis-Aligned Bounding Box,轴对齐包围盒)表示"一个体素的范围",存为中心点 + 半径。今天他改成 min-max 表示——存为两个对角点。听起来微不足道,但这是 Day 595 k-d tree 的前置准备。

## 0 · 为什么要有这一天

AABB 是 3D 图形学里最常用的"物体边界"表示。两种存法:

**Center-Radius**(中心 + 半径):

```rust
struct AABB {
    center: Vec3,
    radius: Vec3,  // 半径,每轴不同
}
```

物体范围 = `[center - radius, center + radius]`。

**Min-Max**(最小 + 最大):

```rust
struct AABB {
    min: Vec3,
    max: Vec3,
}
```

物体范围 = `[min, max]`。

两种数学等价,可以互转:

```
min = center - radius
max = center + radius
center = (min + max) / 2
radius = (max - min) / 2
```

那为什么要换?

**关键差别**:
- Center-Radius:**求交测试**简洁(下面展开)
- Min-Max:**比较操作**简洁(`<` 一行判断)

Casey 在 Day 594 切换,因为后续 k-d tree 需要"按某轴比较两个 AABB",Min-Max 让比较简洁。

心理锚点:看完这集,你能识别"同一数学概念的不同表达",理解表达方式影响代码清晰度和性能,能在自己写代码时选择合适表达。

## 1 · Casey 今天做了什么

Casey 这一天的几个动作:

1. **决定**:Day 595+ 要做 k-d tree,需要按轴排序 AABB。Min-Max 比 Center-Radius 在"按轴比较"上简洁。

## 2 · 心智模型

### 类比:矩形坐标的两种写法

你想描述一个矩形。两种说法:

**说法 1(中心 + 尺寸)**:"矩形中心在 (5, 3),宽 4,高 2"。但仔细想,"宽 4"是"半宽 2"还是"全宽 4"?容易混淆。

**说法 2(对角点)**:"矩形左下 (3, 2),右上 (7, 4)"。无歧义。

实际编程时:
- 想算"矩形中心",说法 1 直接给
- 想算"两个矩形是否重叠",说法 2 直接比(右下 x > 另一左上 x 等)
- 想算"按 x 排序",说法 2 用 min.x 比较

不同操作适合不同表达。

### 严谨原理:AABB 相交测试

两个 AABB 是否相交?

**Min-Max 表达**:

```rust
fn intersects(a: &AABB, b: &AABB) -> bool {
    // 三轴都重叠才相交
    a.max.x >= b.min.x && a.min.x <= b.max.x &&
    a.max.y >= b.min.y && a.min.y <= b.max.y &&
    a.max.z >= b.min.z && a.min.z <= b.max.z
}
```

**Center-Radius 表达**:

```rust
fn intersects(a: &AABB, b: &AABB) -> bool {
    let dx = (a.center.x - b.center.x).abs();
    let dy = (a.center.y - b.center.y).abs();
    let dz = (a.center.z - b.center.z).abs();
    dx <= a.radius.x + b.radius.x &&
    dy <= a.radius.y + b.radius.y &&
    dz <= a.radius.z + b.radius.z
}
```

**比较**:
- Min-Max:6 次比较
- Center-Radius:3 次比较 + 3 次绝对值 + 3 次加法 + 3 次比较

Min-Max 在相交测试上**略快**(少一些算术)。但 Center-Radius 在**求距离**上简洁(中心点距离直接算)。

Casey 切换到 Min-Max 后:
- 相交测试变简洁
- "按轴比较"变简洁(用于 k-d tree)
- 代价:"求中心"需要 `(min + max) / 2`(一次加法 + 一次乘法)

### Min-Max 的 k-d tree 友好性

k-d tree 按"某轴"递归划分空间。每次划分,要决定"这个 AABB 属于左子树还是右子树"——比较 AABB 的 min.x 和 max.x 与划分平面。

```rust
// Center-Radius
let center_x = a.center.x;
if center_x < split_x {
    // 左子树
}

// Min-Max
let min_x = a.min.x;
let max_x = a.max.x;
if max_x < split_x {
    // 完全在左
} else if min_x >= split_x {
    // 完全在右
} else {
    // 跨越,两边都要查
}
```

Min-Max 让"AABB 完全在某侧"的判断简洁——直接看 min/max。Center-Radius 需要先算 min/max(每次都算)。

### Rust 实现

```rust
#[derive(Copy, Clone, Debug)]
struct AABB {
    min: Vec3,
    max: Vec3,
}

impl AABB {
    fn new(min: Vec3, max: Vec3) -> Self {
        Self { min, max }
    }
    
    fn from_center_radius(center: Vec3, radius: Vec3) -> Self {
        Self {
            min: Vec3 {
                x: center.x - radius.x,
                y: center.y - radius.y,
                z: center.z - radius.z,
            },
            max: Vec3 {
                x: center.x + radius.x,
                y: center.y + radius.y,
                z: center.z + radius.z,
            },
        }
    }
    
    fn center(&self) -> Vec3 {
        Vec3 {
            x: (self.min.x + self.max.x) * 0.5,
            y: (self.min.y + self.max.y) * 0.5,
            z: (self.min.z + self.max.z) * 0.5,
        }
    }
    
    fn intersects(&self, other: &AABB) -> bool {
        self.max.x >= other.min.x && self.min.x <= other.max.x &&
        self.max.y >= other.min.y && self.min.y <= other.max.y &&
        self.max.z >= other.min.z && self.min.z <= other.max.z
    }
    
    fn contains(&self, point: Vec3) -> bool {
        point.x >= self.min.x && point.x <= self.max.x &&
        point.y >= self.min.y && point.y <= self.max.y &&
        point.z >= self.min.z && point.z <= self.max.z
    }
}
```

**每行解释**:
- `min` 和 `max` 通常是 AABB 的两个对角点(左下后 + 右上前)。
- `center()` — 中点,需要时计算(不存)。
- `intersects` — 6 个比较,逻辑与(&&)。
- `contains(point)` — 检查点是否在 AABB 内,3 个比较。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

AABB 是游戏开发的基础工具:
- **碰撞检测**:AABB-AABB 相交是最便宜的碰撞测试
- **视锥剔除**:相机视锥 vs 物体 AABB,决定是否渲染
- **光线投射**:ray vs AABB 相交(用 slab method)
- **空间划分**:BVH / k-d tree / 八叉树的叶子节点是 AABB

**变体**:
- **AABB**(轴对齐):旋转无关,快
- **OBB**(Oriented Bounding Box,有向):可以旋转,慢但精确

**ray-AABB 相交**(slab method):

```rust
fn ray_aabb_intersect(ray: &Ray, aabb: &AABB) -> Option<f32> {
    let mut t_min = f32::NEG_INFINITY;
    let mut t_max = f32::INFINITY;
    
    for axis in 0..3 {
        let ray_origin = ray.origin[axis];
        let ray_dir = ray.dir[axis];
        let min = aabb.min[axis];
        let max = aabb.max[axis];
        
        if ray_dir.abs() < 1e-10 {
            // 光线平行于这个轴的 slab
            if ray_origin < min || ray_origin > max {
                return None;
            }
        } else {
            let t1 = (min - ray_origin) / ray_dir;
            let t2 = (max - ray_origin) / ray_dir;
            let (t1, t2) = if t1 < t2 { (t1, t2) } else { (t2, t1) };
            t_min = t_min.max(t1);
            t_max = t_max.min(t2);
            if t_min > t_max {
                return None;
            }
        }
    }
    
    if t_max < 0.0 {
        return None;  // AABB 在光后面
    }
    Some(t_min.max(0.0))
}
```

这是 Day 590 Grid DDA 的"非网格"版本,用于不规则场景。

### 3.2 · 🎨 图形学视角

**Slab method 几何直觉**:AABB 看作"6 个 infinite slab"(无限平面组)的交集,每对 slab 限制一轴。光线穿过每个 slab 的"进入 t1"和"离开 t2"。光线在 AABB 内的 t 范围是 `[max(t1), min(t2)]`——所有 slab 的"重叠"。

**比较**:
- **DDA**:对网格(规则 cell)最优
- **Slab method**:对单个 AABB 通用
- **Plücker coordinates**:对任意凸多边形

Casey 用 DDA 处理网格,后面 k-d tree 用 Slab method 处理子节点 AABB。

### 3.3 · 🐧 Linux 系统编程视角

这一集主要是数学,Linux 系统调用面没什么。但**SIMD**值得一提。

Min-Max AABB 的相交测试,6 个比较可以 SIMD 化:

```rust
use std::arch::x86_64::*;

#[target_feature(enable = "sse2")]
unsafe fn intersects_simd(a: &AABB, b: &AABB) -> bool {
    // 加载 min, max(各 3 个 f32,pad 到 4)
    let a_min = _mm_set_ps(a.min.x, a.min.y, a.min.z, 0.0);
    let a_max = _mm_set_ps(a.max.x, a.max.y, a.max.z, 0.0);
    let b_min = _mm_set_ps(b.min.x, b.min.y, b.min.z, 0.0);
    let b_max = _mm_set_ps(b.max.x, b.max.y, b.max.z, 0.0);
    
    // a.max >= b.min
    let cond1 = _mm_cmpge_ps(a_max, b_min);
    // a.min <= b.max
    let cond2 = _mm_cmple_ps(a_min, b_max);
    // 两个条件 AND
    let both = _mm_and_ps(cond1, cond2);
    // 取 mask(检查所有 lane 都 true)
    let mask = _mm_movemask_ps(both) & 0x7;  // 取低 3 位
    mask == 0x7  // 三个 lane 都 true
}
```

但 SSE 的 setup 开销可能比标量版本还慢(对单个 AABB 测试)。SIMD 优势在**批量测试**——同时测 4 个 AABB。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 Min-Max AABB 在 k-d tree 构造时比 Center-Radius 更友好?

**参考解答**:k-d tree 构造时要"按某轴划分子节点"。每个 AABB 需要决定属于左 / 右 / 跨越。Min-Max 直接给出 `aabb.min[axis]` 和 `aabb.max[axis]`,判断"完全在左"(`max < split`)、"完全在右"(`min >= split`)、"跨越"(`min < split && max >= split`)。

Center-Radius 需要每次算 `min = center - radius` 和 `max = center + radius`(2 次加法 + 2 次减法),才能比较。每次 k-d tree 划分都算,代价累积。

Min-Max 让"按轴排序 AABB"操作简洁,适合 BVH / k-d tree 构造。

```rust
#[derive(Copy, Clone, Debug, PartialEq)]
struct Vec3 { x: f32, y: f32, z: f32 }

impl Vec3 {
    fn new(x: f32, y: f32, z: f32) -> Self { Self { x, y, z } }
}

#[derive(Copy, Clone, Debug)]
struct AABB {
    min: Vec3,
    max: Vec3,
}

impl AABB {
    fn new(min: Vec3, max: Vec3) -> Self {
        Self { min, max }
    }
    
    fn from_center_radius(center: Vec3, radius: Vec3) -> Self {
        Self {
            min: Vec3::new(center.x - radius.x, center.y - radius.y, center.z - radius.z),
            max: Vec3::new(center.x + radius.x, center.y + radius.y, center.z + radius.z),
        }
    }
    
    fn center(&self) -> Vec3 {
        Vec3::new(
            (self.min.x + self.max.x) * 0.5,
            (self.min.y + self.max.y) * 0.5,
            (self.min.z + self.max.z) * 0.5,
        )
    }
    
    fn intersects(&self, other: &AABB) -> bool {
        self.max.x >= other.min.x && self.min.x <= other.max.x &&
        self.max.y >= other.min.y && self.min.y <= other.max.y &&
        self.max.z >= other.min.z && self.min.z <= other.max.z
    }
    
    fn contains(&self, p: Vec3) -> bool {
        p.x >= self.min.x && p.x <= self.max.x &&
        p.y >= self.min.y && p.y <= self.max.y &&
        p.z >= self.min.z && p.z <= self.max.z
    }
}

fn main() {
    let a = AABB::new(Vec3::new(0.0, 0.0, 0.0), Vec3::new(2.0, 2.0, 2.0));
    let b = AABB::new(Vec3::new(1.0, 1.0, 1.0), Vec3::new(3.0, 3.0, 3.0));
    assert!(a.intersects(&b));
    
    let c = AABB::new(Vec3::new(5.0, 5.0, 5.0), Vec3::new(6.0, 6.0, 6.0));
    assert!(!a.intersects(&c));
    
    assert!(a.contains(Vec3::new(1.0, 1.0, 1.0)));
    assert!(!a.contains(Vec3::new(3.0, 0.0, 0.0)));
    
    println!("All tests passed");
}
```

## 8 · Rust / Arch 落地代码

完整可跑示例(基于 Lv2,加 ray-AABB):

```rust
// (Vec3, AABB 同 Lv2)

struct Ray {
    origin: Vec3,
    dir: Vec3,
}

impl AABB {
    fn ray_intersect(&self, ray: &Ray) -> Option<f32> {
        let mut t_min = f32::NEG_INFINITY;
        let mut t_max = f32::INFINITY;
        
        let axes = [(ray.origin.x, ray.dir.x, self.min.x, self.max.x),
                    (ray.origin.y, ray.dir.y, self.min.y, self.max.y),
                    (ray.origin.z, ray.dir.z, self.min.z, self.max.z)];
        
        for (origin, dir, mn, mx) in axes.iter() {
            if dir.abs() < 1e-10 {
                if *origin < *mn || *origin > *mx {
                    return None;
                }
            } else {
                let t1 = (*mn - *origin) / dir;
                let t2 = (*mx - *origin) / dir;
                let (t1, t2) = if t1 < t2 { (t1, t2) } else { (t2, t1) };
                t_min = t_min.max(t1);
                t_max = t_max.min(t2);
                if t_min > t_max {
                    return None;
                }
            }
        }
        
        if t_max < 0.0 {
            None
        } else {
            Some(t_min.max(0.0))
        }
    }
}

fn main() {
    let aabb = AABB::new(Vec3::new(0.0, 0.0, 0.0), Vec3::new(2.0, 2.0, 2.0));
    
    // 光从 (-1, 1, 1) 朝 +x,应该相交
    let ray1 = Ray { origin: Vec3::new(-1.0, 1.0, 1.0), dir: Vec3::new(1.0, 0.0, 0.0) };
    if let Some(t) = aabb.ray_intersect(&ray1) {
        println!("Ray 1 hits at t={:.2} (point {:?}", t, 
                 Vec3::new(ray1.origin.x + t * ray1.dir.x, 1.0, 1.0));
    }
    
    // 光从 (5, 5, 5) 朝 +x,不应该相交
    let ray2 = Ray { origin: Vec3::new(5.0, 5.0, 5.0), dir: Vec3::new(1.0, 0.0, 0.0) };
    println!("Ray 2 hits: {:?}", aabb.ray_intersect(&ray2));
    
    // 性能测试:100 万次 ray-AABB
    let start = std::time::Instant::now();
    for i in 0..1_000_000 {
        let r = Ray {
            origin: Vec3::new(-1.0 + i as f32 * 1e-6, 1.0, 1.0),
            dir: Vec3::new(1.0, 0.0, 0.0),
        };
        std::hint::black_box(aabb.ray_intersect(&r));
    }
    let elapsed = start.elapsed();
    println!("\n1M ray-AABB tests: {:?} ({:.1} ns/test)",
             elapsed, elapsed.as_nanos() as f64 / 1_000_000.0);
}
```

### A.2 Voxel lighting 的核心问题

工业级 voxel lighting 解决以下核心问题:

**1. 计算量**:
- 大场景(几百万 voxel)
- 每 voxel 要算多方向光
- 每方向要 raycast(检查遮挡)

**2. 实时性**:
- 玩家编辑 voxel(挖 / 放)
- 光照要立即更新
- 16.67 ms 帧预算

**3. 内存**:
- 每 voxel 存光照值(RGB 或 SH)
- 大场景内存爆炸
- 需要 streaming

**4. 准确性**:
- 直接光(sun)
- 间接光(bounce)
- 阴影(soft / hard)
- 反射(diffuse / specular)

工业方案在这些问题之间权衡。Casey 的 HH 教基础权衡。

### A.3 性能优化的具体技术

**Spatial partitioning**:
- Grid:固定大小 voxel,直接索引
- Octree:稀疏,只存有内容的节点
- BVH:bounding volume hierarchy,GPU 友好
- k-d tree:递归 axis-aligned split

**Temporal coherence**:
- 帧间复用(上一帧光照 + 增量)
- TAA(temporal anti-aliasing)
- 时序累积(低噪点)

**Level of detail**:
- 远处 voxel 粗采样
- 近处 voxel 精细
- mipmap voxel atlas

**GPU compute**:
- Vulkan / DX12 / Metal compute shader
- 自定义 ray tracing shader
- RTX 核心加速

### A.8 Voxel lighting 算法的具体实现细节

让我深入讲讲 voxel lighting 算法的实现细节:

**Direct lighting**(直接光):

```rust
fn compute_direct_lighting(
    world: &World,
    sun_dir: Vec3,
    sun_color: RGB,
) -> LightAtlas {
    let mut atlas = LightAtlas::new(world.width, world.height, world.depth);
    
    for z in 0..world.depth {
        for y in 0..world.height {
            for x in 0..world.width {
                if world.get(x, y, z).is_air() { continue; }
                
                // 检查是否被遮挡(从 voxel 到 sun 方向)
                let voxel_pos = Vec3::new(x as f32 + 0.5, y as f32 + 0.5, z as f32 + 0.5);
                let ray = Ray::new(voxel_pos, sun_dir);
                let occluded = grid_dda(world, ray, 100.0).is_some();
                
                if !occluded {
                    // 计算法线(根据邻居)
                    let normal = compute_normal(world, x, y, z);
                    let lambert = normal.dot(sun_dir).max(0.0);
                    let light = sun_color * lambert;
                    atlas.set(x, y, z, light);
                }
            }
        }
    }
    
    atlas
}
```

**Indirect lighting**(间接光 / bounce):

```rust
fn compute_indirect_lighting(
    world: &World,
    direct: &LightAtlas,
    bounces: usize,
) -> LightAtlas {
    let mut current = direct.clone();
    
    for _ in 0..bounces {
        let mut next = current.clone();
        
        for z in 0..world.depth {
            for y in 0..world.height {
                for x in 0..world.width {
                    if world.get(x, y, z).is_air() { continue; }
                    
                    // 累加 6 邻居的光(简化 diffuse)
                    let mut accumulated = RGB::black();
                    for (dx, dy, dz) in NEIGHBORS_6 {
                        let nx = x as i32 + dx;
                        let ny = y as i32 + dy;
                        let nz = z as i32 + dz;
                        if nx >= 0 && ny >= 0 && nz >= 0 {
                            let n_light = current.get(nx as u32, ny as u32, nz as u32);
                            accumulated += n_light * 0.15;  // bounce factor
                        }
                    }
                    
                    let cur = current.get(x, y, z);
                    next.set(x, y, z, cur + accumulated);
                }
            }
        }
        
        current = next;
    }
    
    current
}
```

### A.9 Voxel 法线计算

Voxel 表面法线计算:

```rust
fn compute_normal(world: &World, x: u32, y: u32, z: u32) -> Vec3 {
    // Sobel filter 算法线(类似图像边缘检测)
    let mut sx = 0.0; let mut sy = 0.0; let mut sz = 0.0;
    
    for dz in -1i32..=1 {
        for dy in -1i32..=1 {
            for dx in -1i32..=1 {
                let nx = x as i32 + dx;
                let ny = y as i32 + dy;
                let nz = z as i32 + dz;
                let density = if in_bounds(world, nx, ny, nz) && world.get(nx, ny, nz).is_solid() {
                    1.0
                } else { 0.0 };
                sx += dx as f32 * density;
                sy += dy as f32 * density;
                sz += dz as f32 * density;
            }
        }
    }
    
    Vec3::new(sx, sy, sz).normalize()
}
```

法线用于 Lambert / Phong 光照计算。
