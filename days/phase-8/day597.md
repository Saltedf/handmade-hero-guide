# Day 597 · 基础 K-d 树构造

> Day 596 完成了 k-d tree 遍历。但遍历的前提是有 k-d tree,而 k-d tree 怎么"构造"还没说。今天 Casey 实现 k-d tree 构造——把一组三角形组织成树。

## 0 · 为什么要有这一天

k-d tree 遍历是"查询"——给定树,查光线。k-d tree 构造是"准备"——把场景几何变成树。两件事都很复杂。

**构造的核心问题**:
1. **选哪个轴划分?**(x / y / z)
2. **选哪个位置划分?**(在哪个值切)
3. **何时停止?**(叶子节点物体数阈值)

每种选择都影响最终树的"质量"——平衡性、查询速度。

**简化的构造策略**(Casey 在 Day 597 用):
1. **轴**:轮换(x → y → z → x ...)。简单
2. **位置**:物体中心的中位数。简单
3. **停止**:叶子物体数 ≤ 8。简单

**工业级策略**(Day 590+ 不实现):
1. **轴**:选"方差最大"的轴(让划分最均匀)
2. **位置**:用 SAH(Surface Area Heuristic)优化,让"光访问概率 × 节点数"最小
3. **停止**:叶子物体数 ≤ 1-2,或深度 > 30

工业级构造能再快 1.5-2 倍查询,但构造复杂得多。Casey 在 Day 597 用简化版,够用。

心理锚点:看完这集,你能实现 k-d tree 构造,理解"为什么选轴和位置影响质量",能在自己写树结构代码时考虑"平衡性"。

## 2 · 心智模型

### 类比:图书馆整理

图书馆新进了 1000 本书。图书管理员要整理。

**简单方法**:按"作者首字母"分两组(A-M, N-Z)。每组再按"出版年代"分两组。每个分组按"主题"分。直到每组 ≤ 8 本书。

**类比**:
- "作者首字母" = x 轴
- "出版年代" = y 轴
- "主题" = z 轴
- 轮换 = 第一层按 x,第二层按 y,第三层按 z,第四层回到 x ...

每个叶子是一个"书架",放 ≤ 8 本书。

### 严谨原理:递归构造

```rust
fn build(triangles: Vec<usize>, all_tris: &[Triangle], depth: usize) -> KdNode {
    if triangles.len() <= 8 {
        // 叶子
        return KdNode {
            axis: 3,  // leaf
            split: 0.0,
            left: u32::MAX,
            right: u32::MAX,
            triangles,
        };
    }
    
    let axis = (depth % 3) as u8;  // 轮换 x/y/z
    let split = median(&triangles, all_tris, axis);  // 中位数
    
    // 分组
    let (left_tris, right_tris): (Vec<_>, Vec<_>) = triangles.into_iter()
        .partition(|&i| {
            let tri = &all_tris[i];
            let center = tri.center();
            center[axis as usize] < split
        });
    
    let left = build(left_tris, all_tris, depth + 1);
    let right = build(right_tris, all_tris, depth + 1);
    
    KdNode {
        axis,
        split,
        left: ...,  // arena index
        right: ...,
        triangles: vec![],
    }
}

fn median(tris: &[usize], all: &[Triangle], axis: u8) -> f32 {
    let mut centers: Vec<f32> = tris.iter()
        .map(|&i| all[i].center()[axis as usize])
        .collect();
    centers.sort_by(|a, b| a.partial_cmp(b).unwrap());
    centers[centers.len() / 2]
}
```

**每行解释**:
- `(depth % 3) as u8` — 轮换 axis。depth=0 是 x,depth=1 是 y,depth=2 是 z,depth=3 回 x。
- `triangles.into_iter().partition(...)` — Rust 标准库的"按条件分组"。
- `median` — 排序后取中位数。简化版,工业级用 nth_element(O(N) 而不是 O(N log N))。

### 三角形跨越划分

三角形可能"跨越"划分平面——三角形 AABB 跨越 split,中心在一侧,但形状在两边。

**简单方案**(Casey 用):按"中心"分组。三角形中心 < split 进左子树,>= split 进右子树。

**问题**:三角形可能跨子树。查询时如果光线在左子树命中,实际三角形可能在右子树的范围。导致漏命中。

**正确方案**(工业级):
- 三角形完全在左 → 进左子树
- 三角形完全在右 → 进右子树
- 三角形跨越 → 加到"当前节点"(不递归)

Casey 在 Day 597 用简单方案,可能出现漏命中。Day 598 修复。

### Arena 分配

```rust
struct KdTree {
    nodes: Vec<KdNode>,
    triangles: Vec<Triangle>,
}

impl KdTree {
    fn build(triangles: Vec<Triangle>) -> Self {
        let mut tree = Self {
            nodes: Vec::new(),
            triangles,
        };
        let root_indices: Vec<usize> = (0..tree.triangles.len()).collect();
        let _root = tree.build_recursive(root_indices, 0);
        tree
    }
    
    fn build_recursive(&mut self, tris: Vec<usize>, depth: usize) -> u32 {
        if tris.len() <= 8 {
            let idx = self.nodes.len() as u32;
            self.nodes.push(KdNode {
                axis: 3,
                split: 0.0,
                left: u32::MAX,
                right: u32::MAX,
                triangles: tris,
            });
            return idx;
        }
        
        let axis = (depth % 3) as u8;
        let split = self.median(&tris, axis);
        
        // 当前节点先占位(预分配 index)
        let current_idx = self.nodes.len() as u32;
        self.nodes.push(KdNode {
            axis, split, left: u32::MAX, right: u32::MAX, triangles: vec![],
        });
        
        // 分组
        let (left_tris, right_tris): (Vec<_>, Vec<_>) = tris.into_iter()
            .partition(|&i| self.triangles[i].center()[axis as usize] < split);
        
        let left = if !left_tris.is_empty() {
            self.build_recursive(left_tris, depth + 1)
        } else {
            u32::MAX
        };
        let right = if !right_tris.is_empty() {
            self.build_recursive(right_tris, depth + 1)
        } else {
            u32::MAX
        };
        
        // 回填
        self.nodes[current_idx as usize].left = left;
        self.nodes[current_idx as usize].right = right;
        
        current_idx
    }
    
    fn median(&self, tris: &[usize], axis: u8) -> f32 {
        let mut centers: Vec<f32> = tris.iter()
            .map(|&i| self.triangles[i].center()[axis as usize])
            .collect();
        centers.sort_by(|a, b| a.partial_cmp(b).unwrap());
        centers[centers.len() / 2]
    }
}
```

**每行解释**:
- "Arena" 模式——所有节点存在 `Vec<KdNode>` 里,用 index 引用,不用 `Box<KdNode>`。
- "预分配 index"——先 push 占位,递归构造子树后再回填 left/right。
- 避免递归 Box 的内存碎片,cache 友好。

### 平衡性检查

构造完,检查树是否平衡:

```rust
impl KdTree {
    fn depth(&self, idx: u32) -> usize {
        if idx == u32::MAX { return 0; }
        let node = &self.nodes[idx as usize];
        if node.axis == 3 { return 1; }
        1 + self.depth(node.left).max(self.depth(node.right))
    }
    
    fn node_count(&self, idx: u32) -> usize {
        if idx == u32::MAX { return 0; }
        let node = &self.nodes[idx as usize];
        1 + self.node_count(node.left) + self.node_count(node.right)
    }
}
```

中位数划分保证树**接近平衡**——左右子树大小相近。深度 ≈ log2(N)。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏工业里 k-d tree / BVH 构造的关键是 **SAH(Surface Area Heuristic)**。

**SAH 公式**:

```
cost(node) = traversal_cost + hit_probability * cost(left) + (1-hit_probability) * cost(right)
```

`hit_probability` 由子节点的"表面积 / 父节点表面积"决定。SAH 选让 cost 最小的 axis + split。

**简化 SAH**(SAH-k):
- 不遍历所有 split,只试 bin(如 32 个)
- 每 bin 算 cost,选最优 bin

**全 SAH**:
- 遍历所有可能 split(物体边界)
- 精确但慢(O(N²) 或 O(N log N))

**Spatial SAH / SBVH**:
- 允许三角形分裂到两个子节点
- 最高质量,但内存大

Casey 在 Day 597 用"中位数划分",简单但比 SAH 差 1.5-2 倍。Day 590+ 优化阶段可能升级 SAH。

### 3.2 · 🎨 图形学视角

**SAH 的理论基础**:光从随机方向射入,命中某子节点的概率 = 子节点表面积 / 父节点表面积(对凸包)。SAH 优化"期望访问的节点数",数学上合理。

**SAH 不是万能**:
- 对均匀分布场景,SAH 与中位数差不多
- 对非均匀分布(墙边、角落),SAH 显著好

**k-d tree vs BVH 构造**:
- k-d tree:递归划分空间,叶子存物体索引
- BVH:递归划分物体,每节点有 AABB

**SBVH**(Spatial BVH):允许三角形分裂,质量最高。2014 年论文(Dammertz et al.)。

### 3.3 · 🐧 Linux 系统编程视角

构造算法的 Linux 性能:

```bash
sudo perf stat -e cache-misses ./raytracer
# k-d tree 构造通常 cache miss 高,因为随机访问三角形
```

**优化**:
- 排序三角形索引(按构造顺序),cache 友好
- 用更紧凑的 triangle 表示(顶点用 u32 index 而不是 f32)

**多线程构造**:递归构造可以并行——左右子树独立构造。

```rust
let (left, right) = rayon::join(
    || self.build_recursive(left_tris, depth + 1),
    || self.build_recursive(right_tris, depth + 1),
);
```

但 Rust 的 `&mut self` 不能同时被两个闭包捕获,需要重构为"先收集子树,再 merge"。

### 3.4 · 🦀 Rust 生态视角

Rust 实现递归构造的几个细节:

**1. 借用检查**:递归调用 `self.build_recursive(...)`,每次都 `&mut self`,Rust 报错"already borrowed"。

**解决**:把 `&mut self` 拆成不同字段,或用 arena:

```rust
// 不工作
let left = self.build_recursive(left_tris, depth + 1);
let right = self.build_recursive(right_tris, depth + 1);
// 第二行报错:self already borrowed by first call

// 工作(arena + 平行收集)
let (left, right) = rayon::join(
    || self.build_recursive(left_tris, depth + 1),  // 但 &mut self 仍冲突
    || self.build_recursive(right_tris, depth + 1),
);

// 真正可行:拆分 self
struct KdTreeBuilder {
    nodes: Vec<KdNode>,
    triangles: Vec<Triangle>,
}

impl KdTreeBuilder {
    fn build_recursive(&mut self, tris: Vec<usize>, depth: usize) -> u32 {
        // 顺序递归,不并行
        // ...
    }
}
```

**2. `partial_cmp` for f32**:f32 有 NaN,不能直接 `sort()`。必须用 `sort_by(|a, b| a.partial_cmp(b).unwrap())`。

**3. Vec::partition**:Rust 标准库的方法,把 Vec 按条件分两组。

```rust
let (evens, odds): (Vec<_>, Vec<_>) = numbers.into_iter()
    .partition(|n| n % 2 == 0);
```

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么"中位数划分"能让 k-d tree 平衡,而"固定值划分"(如 x = 0)不能?

**参考解答**:中位数划分保证左右子树"物体数"相近——左子树有 N/2 个,右子树有 N/2 个。深度 ≈ log2 N。

固定值划分(如 x=0)不保证平衡——如果所有物体中心 x > 0,左子树为空,右子树有所有 N 个物体。退化为链表(深度 N)。

平衡树保证查询 O(log N),退化树最坏 O(N)。

### Lv2 · 动手实践

**题**:实现 `KdTree::build`(2D 版,简化),插入 8 个点,打印树结构。测试:
- 8 个点,深度应该 ≤ 4
- 4 个点(叶子阈值 4),深度 ≤ 2

完成标准:`cargo run` 打印合理的树结构。

**参考解答**:

```rust
#[derive(Clone)]
struct Point { x: f32, y: f32 }

struct KdNode2D {
    axis: u8,  // 0=x, 1=y, 2=leaf
    split: f32,
    left: Option<Box<KdNode2D>>,
    right: Option<Box<KdNode2D>>,
    points: Vec<Point>,  // 仅叶子
}

fn build(points: Vec<Point>, depth: usize) -> Option<Box<KdNode2D>> {
    if points.is_empty() { return None; }
    if points.len() <= 2 {
        return Some(Box::new(KdNode2D {
            axis: 2, split: 0.0, left: None, right: None, points,
        }));
    }
    let axis = (depth % 2) as u8;
    let mut sorted = points.clone();
    sorted.sort_by(|a, b| {
        let av = if axis == 0 { a.x } else { a.y };
        let bv = if axis == 0 { b.x } else { b.y };
        av.partial_cmp(&bv).unwrap()
    });
    let mid = sorted.len() / 2;
    let split = if axis == 0 { sorted[mid].x } else { sorted[mid].y };
    
    let (left_pts, right_pts): (Vec<_>, Vec<_>) = sorted.into_iter()
        .partition(|p| {
            let v = if axis == 0 { p.x } else { p.y };
            v < split
        });
    
    Some(Box::new(KdNode2D {
        axis, split,
        left: build(left_pts, depth + 1),
        right: build(right_pts, depth + 1),
        points: vec![],
    }))
}

fn print_tree(node: &Option<Box<KdNode2D>>, depth: usize) {
    if let Some(n) = node {
        let indent = "  ".repeat(depth);
        if n.axis == 2 {
            println!("{}Leaf: {} points", indent, n.points.len());
        } else {
            let axis_name = if n.axis == 0 { "x" } else { "y" };
            println!("{}Internal: {} = {}", indent, axis_name, n.split);
            print_tree(&n.left, depth + 1);
            print_tree(&n.right, depth + 1);
        }
    }
}

fn main() {
    let points: Vec<Point> = vec![
        Point { x: 5.0, y: 5.0 },
        Point { x: 3.0, y: 7.0 },
        Point { x: 8.0, y: 2.0 },
        Point { x: 1.0, y: 9.0 },
        Point { x: 6.0, y: 6.0 },
        Point { x: 4.0, y: 4.0 },
        Point { x: 9.0, y: 8.0 },
        Point { x: 2.0, y: 3.0 },
    ];
    let tree = build(points, 0);
    print_tree(&tree, 0);
}
```

## 8 · Rust / Arch 落地代码

完整可跑示例:

```rust
// (Point, KdNode2D, build, print_tree 同 Lv2)

fn main() {
    let points: Vec<Point> = (0..32).map(|i| {
        let t = i as f32 * 0.5;
        Point {
            x: t.sin() * 5.0 + 5.0,
            y: t.cos() * 5.0 + 5.0,
        }
    }).collect();
    
    println!("Building k-d tree with {} points...\n", points.len());
    let tree = build(points, 0);
    print_tree(&tree, 0);
    
    // 计算深度和节点数
    fn stats(node: &Option<Box<KdNode2D>>) -> (usize, usize) {
        if let Some(n) = node {
            let (ld, lc) = stats(&n.left);
            let (rd, rc) = stats(&n.right);
            (1 + ld.max(rd), 1 + lc + rc)
        } else {
            (0, 0)
        }
    }
    let (depth, count) = stats(&tree);
    println!("\nDepth: {}, Node count: {}", depth, count);
    println!("Expected depth for 32 points: ~{} (log2 32)", (32f32).log2() as usize);
}
```

### A.3 性能优化的实际流程

工业性能优化的标准流程:

**Step 1:测量**(cargo flamegraph / perf)
- 找最慢的函数
- 不要猜,要测

**Step 2:分析**(为什么慢)
- 算法?(O(N²) vs O(N log N))
- 内存?(cache miss)
- 同步?(锁等待)
- 分支?(branch mispredict)

**Step 3:优化**(对症下药)
- 算法:换数据结构
- 内存:SoA / prefetch
- 同步:细化锁
- 分支:branchless

**Step 4:验证**(再测)
- 看新 profile
- 性能提升 vs 代码复杂度
- 不值得就回滚

**Step 5:文档**(给后人)
- commit message 解释为什么
- 注释 hot path 的考量

### A.11 完整 Rust voxel lighting 实现

让我提供一个完整的 Rust voxel lighting 实现示例,综合前面所有概念:

```rust
use std::collections::HashMap;

const CHUNK_SIZE: u32 = 32;

struct Voxel {
    material: u8,
    color: [u8; 3],
}

struct Chunk {
    voxels: Vec<Voxel>,
    light: Vec<[u8; 4]>,  // RGBE
}

struct World {
    chunks: HashMap<(i32, i32, i32), Chunk>,
    sun_dir: Vec3,
    sun_color: [f32; 3],
}

impl World {
    fn get_voxel(&self, x: i32, y: i32, z: i32) -> Option<&Voxel> {
        let (cx, cy, cz) = (x.div_euclid(CHUNK_SIZE as i32), 
                            y.div_euclid(CHUNK_SIZE as i32),
                            z.div_euclid(CHUNK_SIZE as i32));
        let chunk = self.chunks.get(&(cx, cy, cz))?;
        let (lx, ly, lz) = (x.rem_euclid(CHUNK_SIZE as i32) as usize,
                            y.rem_euclid(CHUNK_SIZE as i32) as usize,
                            z.rem_euclid(CHUNK_SIZE as i32) as usize);
        let idx = lz * (CHUNK_SIZE as usize).pow(2) + ly * CHUNK_SIZE as usize + lx;
        Some(&chunk.voxels[idx])
    }
    
    fn is_solid(&self, x: i32, y: i32, z: i32) -> bool {
        self.get_voxel(x, y, z).map(|v| v.material != 0).unwrap_or(false)
    }
}

fn grid_dda(world: &World, start: Vec3, dir: Vec3, max_dist: f32) -> bool {
    let mut cx = start.x.floor() as i32;
    let mut cy = start.y.floor() as i32;
    let mut cz = start.z.floor() as i32;
    
    let step_x = if dir.x > 0.0 { 1 } else { -1 };
    let step_y = if dir.y > 0.0 { 1 } else { -1 };
    let step_z = if dir.z > 0.0 { 1 } else { -1 };
    
    let t_delta_x = if dir.x.abs() > 1e-10 { 1.0 / dir.x.abs() } else { f32::INFINITY };
    let t_delta_y = if dir.y.abs() > 1e-10 { 1.0 / dir.y.abs() } else { f32::INFINITY };
    let t_delta_z = if dir.z.abs() > 1e-10 { 1.0 / dir.z.abs() } else { f32::INFINITY };
    
    let mut t_max_x = if dir.x.abs() > 1e-10 {
        (((cx + if dir.x > 0 { 1 } else { 0 }) as f32) - start.x) / dir.x
    } else { f32::INFINITY };
    let mut t_max_y = /* similar */;
    let mut t_max_z = /* similar */;
    
    let mut t = 0.0;
    while t < max_dist {
        if world.is_solid(cx, cy, cz) {
            return true;  // occluded
        }
        
        if t_max_x < t_max_y && t_max_x < t_max_z {
            cx += step_x;
            t = t_max_x;
            t_max_x += t_delta_x;
        } else if t_max_y < t_max_z {
            cy += step_y;
            t = t_max_y;
            t_max_y += t_delta_y;
        } else {
            cz += step_z;
            t = t_max_z;
            t_max_z += t_delta_z;
        }
    }
    false
}

fn compute_direct_lighting(world: &World, x: i32, y: i32, z: i32) -> [f32; 3] {
    let voxel_pos = Vec3::new(x as f32 + 0.5, y as f32 + 0.5, z as f32 + 0.5);
    
    // 是否被遮挡
    if grid_dda(world, voxel_pos, world.sun_dir, 100.0) {
        return [0.0; 3];  // 阴影
    }
    
    // Lambert 光照
    let normal = compute_normal(world, x, y, z);
    let lambert = normal.dot(world.sun_dir).max(0.0);
    
    [
        world.sun_color[0] * lambert,
        world.sun_color[1] * lambert,
        world.sun_color[2] * lambert,
    ]
}

fn compute_normal(world: &World, x: i32, y: i32, z: i32) -> Vec3 {
    let dx = if world.is_solid(x-1, y, z) { 1.0 } else { 0.0 } 
           - if world.is_solid(x+1, y, z) { 1.0 } else { 0.0 };
    let dy = if world.is_solid(x, y-1, z) { 1.0 } else { 0.0 }
           - if world.is_solid(x, y+1, z) { 1.0 } else { 0.0 };
    let dz = if world.is_solid(x, y, z-1) { 1.0 } else { 0.0 }
           - if world.is_solid(x, y, z+1) { 1.0 } else { 0.0 };
    
    Vec3::new(dx, dy, dz).normalize()
}
```
