# Day 593 · 调试光照验证

> Day 592 加了 trace 系统,Casey 看完 trace 发现奇怪现象——某些体素的辐射值异常高(超出物理合理范围)。今天他要验证光照系统的"正确性",不只是"能跑"。

## 0 · 为什么要有这一天

光照系统跑通了,画面看起来"对",但 Casey 怀疑某些细节有问题:
- 某些体素亮度 > 10(直接光只有 1.0,怎么会有 10 倍?)
- 某些 texel 出现 NaN(0 / 0?)
- 某些体素的光照"漏"到不该亮的区域(光泄漏)

这些都是**正确性问题**,不是性能问题。Benchmark 测不出(只测时间),Trace 能记录数据(但需要主动检查)。

**光照验证**(Validation)是检查"光照是否符合物理预期"的方法:
- **能量守恒**:总输出能量 ≤ 总输入能量
- **无 NaN/Inf**:所有数值有限
- **无突变**:相邻体素亮度差不超过阈值
- **遮挡正确**:被墙挡住的方向不该亮

Casey 这一天加这些验证,发现并修复一个"能量泄漏"bug——某次迭代的光被错误地"放大"了。

心理锚点:看完这集,你能给光照系统加"正确性检查",理解"代码能跑 ≠ 结果对",能在自己写数值代码时主动验证。

## 1 · Casey 今天做了什么

Casey 这一天的几个动作:

1. **加 assertion**:在每个 propagate 函数末尾加 `assert!(check_invariants(world))`,违反立刻 panic。
2. **定义不变量**:
   - 所有 texel 有限(无 NaN / Inf)
   - 总能量 ≤ 输入能量 × 反射率(< 1.0)
   - 相邻体素 diffuse_color 差 < 阈值
3. **发现 bug**:断言失败,某体素的 diffuse_color = 5.0(应该 ≤ 1.0)。Casey 用 trace 倒查发现:`gather_incoming_light` 里漏了一个 `* albedo` 衰减。
4. **修 bug**:加 `* albedo`,assertion 通过。

这一天的工程产出大约 80 行 Rust 代码,价值在于**让代码自我检查正确性**——这是工程化的关键。

## 2 · 心智模型

### 类比:财务审计

公司财务每月做账,但年底要做"审计"——检查账目是否平衡、有没有虚假数字、有没有违规。审计本身不产生钱,但能发现问题。

代码的 assertion 完全一样——平时运行不"产生"功能,但能在出问题时立即报警,而不是让错误传播到最终画面。

### 严谨原理:不变量

**不变量**(Invariant):在程序某个状态点必须成立的条件。例如:
- 数组索引 `< len`
- 浮点数值有限(非 NaN 非 Inf)
- 能量守恒(输出 ≤ 输入)

**断言**(Assertion):代码里 `assert!(condition)`。如果 condition 不成立,Rust panic,程序终止。

```rust
fn check_lighting_invariants(world: &World) -> bool {
    for atlas in &world.atlases {
        for texel in &atlas.texels {
            // 检查有限
            if !texel.r.is_finite() || !texel.g.is_finite() || !texel.b.is_finite() {
                eprintln!("NaN/Inf detected in atlas");
                return false;
            }
            // 检查非负(光强不能负)
            if texel.r < 0.0 || texel.g < 0.0 || texel.b < 0.0 {
                eprintln!("Negative brightness detected");
                return false;
            }
            // 检查上限(避免能量爆炸)
            let max = texel.r.max(texel.g).max(texel.b);
            if max > 100.0 {
                eprintln!("Insane brightness {} detected", max);
                return false;
            }
        }
    }
    true
}

fn propagate(world: &mut World) {
    // ... propagate logic ...
    assert!(check_lighting_invariants(world), "Lighting invariants violated");
}
```

**每行解释**:
- `is_finite()` — Rust 的 f32 方法,返回 false 当 NaN 或 ±Inf。
- `max > 100.0` — 上限检查。100 是经验阈值,正常场景亮度 < 10,> 100 一定有 bug。
- `assert!(...)` — 失败时 panic,带错误信息。

### 能量守恒检查

物理上,Lambert 反射的能量守恒:反射光 ≤ 入射光(反射率 ≤ 1)。所以一次 propagate 后的总能量应 ≤ 之前的总能量 × 反射率。

```rust
fn total_energy(world: &World) -> f64 {
    let mut sum = 0.0f64;
    for atlas in &world.atlases {
        for texel in &atlas.texels {
            sum += (texel.r + texel.g + texel.b) as f64;
        }
    }
    sum
}

fn propagate_with_check(world: &mut World) {
    let e_before = total_energy(world);
    propagate_infinite_bounces(world, 1);
    let e_after = total_energy(world);
    
    // 一轮迭代后,能量应 ≤ 之前 × max_reflectance
    let max_reflectance = 0.9;  // 假设
    let expected_max = e_before * max_reflectance + 1e-6;  // tolerance
    if e_after > expected_max {
        eprintln!("Energy increased: before={}, after={}, expected_max={}",
            e_before, e_after, expected_max);
    }
}
```

**关键**:tolerance `1e-6` 容许浮点误差。`f64` 累加避免 f32 精度问题。

fn check_occlusion(world: &World) -> bool {
    // 对每个 atlas 的每个方向,做 raycast 看是否被遮挡
    for (i, atlas) in world.atlases.iter().enumerate() {
        for ty in 0..atlas.dim {

## 4 · 认知地图

### 4.1 上级

- **不变量**(Invariant)— 程序状态必须成立的条件
- **断言**(Assertion)— 强制检查不变量

### 4.2 同级(并行方案)

| 方案 | 关键差别 | 何时用 | 本项目选了哪个 |
|---|---|---|---|
| `assert!` | 总是检查 | 关键不变量 | ✅ Day 593 |
| `debug_assert!` | 仅 debug | 性能敏感 | 辅助 |

### 历史演化

- **1960s**:ALGOL 引入 assertion 概念

- **Debug build**:开 `debug_assertions`,所有 assertion 跑,性能慢

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么能量守恒检查要在 `f64` 上做累加,而不是 `f32`?

**参考解答**:`f32` 只有 23 位尾数(约 7 位有效数字)。1000 个体素 × 256 texel × 3 通道 = 768000 个数值累加。如果每个数值 ~ 1.0,总和 ~ 768000。f32 累加到 768000 时,精度只有 ~ 0.1(768000 的第 7 位),小数值(< 0.1)被舍去。

`f64` 有 52 位尾数(约 15-17 位有效数字)。累加到 768000 仍能保留小数点后 10 位的精度。

能量守恒检查需要精度(< 1% 误差),所以必须 f64。

### Lv2 · 动手实践

**题**:实现 `check_lighting_invariants(world: &World) -> bool`,检查:
- 所有 texel 有限(无 NaN / Inf)
- 所有 texel 非负
- 所有 texel < 100

测试:
- 正常数据通过
- 故意放 NaN,应该返回 false

完成标准:`cargo run` 测试通过。

**参考解答**:

```rust
#[derive(Default)]
struct Texel { r: f32, g: f32, b: f32 }

struct Atlas {
    texels: Vec<Texel>,
}

struct World {
    atlases: Vec<Atlas>,
}

fn check_invariants(world: &World) -> bool {
    for (i, atlas) in world.atlases.iter().enumerate() {
        for (j, texel) in atlas.texels.iter().enumerate() {
            if !texel.r.is_finite() || !texel.g.is_finite() || !texel.b.is_finite() {
                eprintln!("Atlas {} texel {} has NaN/Inf", i, j);
                return false;
            }
            if texel.r < 0.0 || texel.g < 0.0 || texel.b < 0.0 {
                eprintln!("Atlas {} texel {} negative", i, j);
                return false;
            }
            let max = texel.r.max(texel.g).max(texel.b);
            if max > 100.0 {
                eprintln!("Atlas {} texel {} too bright: {}", i, j, max);
                return false;
            }
        }
    }
    true
}

fn main() {
    let mut world = World {
        atlases: vec![Atlas { texels: vec![Texel::default(); 256] }],
    };
    assert!(check_invariants(&world));
    
    // 故意破坏
    world.atlases[0].texels[100].r = f32::NAN;
    assert!(!check_invariants(&world));
    
    world.atlases[0].texels[100].r = 1.0;
    world.atlases[0].texels[100].g = 200.0;
    assert!(!check_invariants(&world));
    
    println!("All invariant tests passed");
}
```

## 8 · Rust / Arch 落地代码

完整可跑示例:

```rust
#[derive(Default, Clone)]
struct RGB32F { r: f32, g: f32, b: f32 }

struct Atlas {
    texels: Vec<RGB32F>,
}

struct World {
    atlases: Vec<Atlas>,
}

#[derive(Debug)]
enum InvariantViolation {
    NonFinite { atlas: usize, texel: usize, channel: char, value: f32 },
    Negative { atlas: usize, texel: usize, channel: char, value: f32 },
    TooBright { atlas: usize, texel: usize, value: f32 },
}

fn check_invariants(world: &World) -> Result<(), InvariantViolation> {
    for (i, atlas) in world.atlases.iter().enumerate() {
        for (j, texel) in atlas.texels.iter().enumerate() {
            // 检查有限性
            if !texel.r.is_finite() {
                return Err(InvariantViolation::NonFinite { atlas: i, texel: j, channel: 'r', value: texel.r });
            }
            if !texel.g.is_finite() {
                return Err(InvariantViolation::NonFinite { atlas: i, texel: j, channel: 'g', value: texel.g });
            }
            if !texel.b.is_finite() {
                return Err(InvariantViolation::NonFinite { atlas: i, texel: j, channel: 'b', value: texel.b });
            }
            // 检查非负
            if texel.r < 0.0 {
                return Err(InvariantViolation::Negative { atlas: i, texel: j, channel: 'r', value: texel.r });
            }
            if texel.g < 0.0 {
                return Err(InvariantViolation::Negative { atlas: i, texel: j, channel: 'g', value: texel.g });
            }
            if texel.b < 0.0 {
                return Err(InvariantViolation::Negative { atlas: i, texel: j, channel: 'b', value: texel.b });
            }
            // 检查上限
            let max = texel.r.max(texel.g).max(texel.b);
            if max > 100.0 {
                return Err(InvariantViolation::TooBright { atlas: i, texel: j, value: max });
            }
        }
    }
    Ok(())
}

fn total_energy_f64(world: &World) -> f64 {
    let mut sum = 0.0f64;
    for atlas in &world.atlases {
        for texel in &atlas.texels {
            sum += texel.r as f64 + texel.g as f64 + texel.b as f64;
        }
    }
    sum
}

fn propagate_and_check(world: &mut World, iterations: usize) {
    let mut prev_energy = total_energy_f64(world);
    
    for iter in 0..iterations {
        // (实际 propagate 在这里)
        // 模拟:每个体素亮度 * 0.9
        for atlas in &mut world.atlases {
            for texel in &mut atlas.texels {
                texel.r *= 0.9;
                texel.g *= 0.9;
                texel.b *= 0.9;
            }
        }
        
        let new_energy = total_energy_f64(world);
        println!("Iter {}: energy before={:.4} after={:.4}", iter, prev_energy, new_energy);
        
        if let Err(e) = check_invariants(world) {
            eprintln!("INVARIANT VIOLATION: {:?}", e);
            panic!();
        }
        
        // 能量应该减少(反射率 < 1)
        if new_energy > prev_energy * 1.001 {  // tolerance
            eprintln!("Energy increased unexpectedly!");
            // 不 panic,只警告(某些场景能量可以临时增加,如直接光注入)
        }
        
        prev_energy = new_energy;
    }
}

fn main() {
    let mut world = World {
        atlases: (0..10).map(|_| Atlas {
            texels: (0..256).map(|_| RGB32F { r: 1.0, g: 0.9, b: 0.8 }).collect()
        }).collect(),
    };
    
    let initial_energy = total_energy_f64(&world);
    println!("Initial energy: {:.4}", initial_energy);
    
    propagate_and_check(&mut world, 5);
    
    println!("\nFinal invariants check: {:?}", check_invariants(&world));
}
```

### A.2 Voxel lighting 的核心问题

工业级 voxel lighting 解决以下核心问题:

**1. 计算量**:
- 大场景(几百万 voxel)
- 每 voxel 要算多方向光
- 每方向要 raycast(检查遮挡)

**2. 实时性**:
- 玩家编辑 voxel(挖 / 放)
- 光照要立即更新
- 16.67 ms 帧预算

**3. 内存**:

### A.8 Voxel lighting 算法的具体实现细节

让我深入讲讲 voxel lighting 算法的实现细节:

**Direct lighting**(直接光):

```rust
fn compute_direct_lighting(
    world: &World,
    sun_dir: Vec3,
    sun_color: RGB,
) -> LightAtlas {
    let mut atlas = LightAtlas::new(world.width, world.height, world.depth);
    
    for z in 0..world.depth {
        for y in 0..world.height {
            for x in 0..world.width {
                if world.get(x, y, z).is_air() { continue; }
                
                // 检查是否被遮挡(从 voxel 到 sun 方向)
                let voxel_pos = Vec3::new(x as f32 + 0.5, y as f32 + 0.5, z as f32 + 0.5);
                let ray = Ray::new(voxel_pos, sun_dir);
                let occluded = grid_dda(world, ray, 100.0).is_some();
                
                if !occluded {
                    // 计算法线(根据邻居)
                    let normal = compute_normal(world, x, y, z);
                    let lambert = normal.dot(sun_dir).max(0.0);
                    let light = sun_color * lambert;
                    atlas.set(x, y, z, light);
                }
            }
        }
    }
    
    atlas
}
```

**Indirect lighting**(间接光 / bounce):

```rust
fn compute_indirect_lighting(
    world: &World,
    direct: &LightAtlas,
    bounces: usize,
) -> LightAtlas {
    let mut current = direct.clone();
    
    for _ in 0..bounces {
        let mut next = current.clone();
        
        for z in 0..world.depth {
            for y in 0..world.height {
                for x in 0..world.width {
                    if world.get(x, y, z).is_air() { continue; }
                    
                    // 累加 6 邻居的光(简化 diffuse)
                    let mut accumulated = RGB::black();
                    for (dx, dy, dz) in NEIGHBORS_6 {
                        let nx = x as i32 + dx;
                        let ny = y as i32 + dy;
                        let nz = z as i32 + dz;
                        if nx >= 0 && ny >= 0 && nz >= 0 {
                            let n_light = current.get(nx as u32, ny as u32, nz as u32);
                            accumulated += n_light * 0.15;  // bounce factor
                        }
                    }
                    
                    let cur = current.get(x, y, z);
                    next.set(x, y, z, cur + accumulated);
                }
            }
        }
        
        current = next;
    }
    
    current
}
```

### A.9 Voxel 法线计算

Voxel 表面法线计算:

```rust
fn compute_normal(world: &World, x: u32, y: u32, z: u32) -> Vec3 {
    // Sobel filter 算法线(类似图像边缘检测)
    let mut sx = 0.0; let mut sy = 0.0; let mut sz = 0.0;
    
    for dz in -1i32..=1 {
        for dy in -1i32..=1 {
            for dx in -1i32..=1 {
                let nx = x as i32 + dx;
                let ny = y as i32 + dy;
                let nz = z as i32 + dz;
                let density = if in_bounds(world, nx, ny, nz) && world.get(nx, ny, nz).is_solid() {
                    1.0
                } else { 0.0 };
                sx += dx as f32 * density;
                sy += dy as f32 * density;
                sz += dz as f32 * density;
            }
        }
    }
    
    Vec3::new(sx, sy, sz).normalize()
}
```

法线用于 Lambert / Phong 光照计算。
