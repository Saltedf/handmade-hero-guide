## 1 · Casey 今天做了什么

Casey 这一天的几个动作:

1. **定义方向 bin**:用八面体编码把方向空间量化到 32×32 = 1024 bin。
2. **预生成所有 bin**:启动时遍历所有 bin,每个 bin 生成 walk table。

## 2 · 心智模型

### 类比:电话号码本

你想找朋友的电话。两种方法:

**方法 1(现查)**:每次问人"张三的电话是多少"。慢。

**方法 2(查表)**:电话本预先存所有朋友的电话。问的时候直接查。快。

电话本 = walk table。预先存所有方向的 raycast 结果(实际上是"格子序列"),运行时查表替代算。

### 严谨原理:方向 bin

每个 bin 是 3D 方向空间的一个"代表方向"。用八面体编码:

```rust
fn direction_to_bin(dir: Vec3, n_bins_per_axis: usize) -> usize {
    let (u, v) = encode_octahedral(dir.normalize());  // [-1, 1]²
    let bx = ((u + 1.0) * 0.5 * n_bins_per_axis as f32) as usize;
    let by = ((v + 1.0) * 0.5 * n_bins_per_axis as f32) as usize;
    let bx = bx.min(n_bins_per_axis - 1);
    let by = by.min(n_bins_per_axis - 1);
    by * n_bins_per_axis + bx
}

fn bin_to_direction(bin_idx: usize, n_bins_per_axis: usize) -> Vec3 {
    let bx = bin_idx % n_bins_per_axis;
    let by = bin_idx / n_bins_per_axis;
    let u = (bx as f32 / (n_bins_per_axis - 1) as f32) * 2.0 - 1.0;
    let v = (by as f32 / (n_bins_per_axis - 1) as f32) * 2.0 - 1.0;
    decode_octahedral(u, v)
}
```

**每个 bin**:`bx = 0..32, by = 0..32`,共 1024 个 bin。每个 bin 的代表方向是 bin 中心的 decode 结果。

### 全局 walk table

```rust
use std::sync::OnceLock;

const N_BINS_PER_AXIS: usize = 32;
const N_BINS: usize = N_BINS_PER_AXIS * N_BINS_PER_AXIS;
const MAX_STEPS: usize = 64;

static WALK_TABLES: OnceLock<Vec<Vec<WalkStep>>> = OnceLock::new();

#[derive(Copy, Clone)]
struct WalkStep {
    delta_x: i8,
    delta_y: i8,
    delta_z: i8,
    t_to_next: f32,
}

fn init_walk_tables() -> Vec<Vec<WalkStep>> {
    let mut tables = Vec::with_capacity(N_BINS);
    for bin_idx in 0..N_BINS {
        let dir = bin_to_direction(bin_idx, N_BINS_PER_AXIS);
        tables.push(generate_walk_table(dir, MAX_STEPS));
    }
    tables
}

fn get_walk_tables() -> &'static Vec<Vec<WalkStep>> {
    WALK_TABLES.get_or_init(init_walk_tables)
}
```

**关键**:
- `OnceLock` 让初始化只发生一次(线程安全)。
- `&'static` 让 caller 拿到静态引用,无生命周期问题。
- 1024 个 bin,每个最多 64 步,总内存 ~512 KB。

### 查表 raycast

```rust
fn raycast_with_tables(
    world: &World,
    origin: Vec3,
    dir: Vec3,
    max_dist: f32,
) -> Option<HitInfo> {
    let bin_idx = direction_to_bin(dir, N_BINS_PER_AXIS);
    let table = &get_walk_tables()[bin_idx];
    
    let mut cx = (origin.x).floor() as i32;
    let mut cy = (origin.y).floor() as i32;
    let mut cz = (origin.z).floor() as i32;
    
    let mut t = 0.0;
    let mut last_axis = 0u8;
    let mut last_step = 1i32;
    
    for step in table {
        // Early termination
        if !world.is_in_bounds(cx, cy, cz) {
            return None;
        }
        if t > max_dist {
            return None;
        }
        
        if world.is_solid(cx, cy, cz) {
            let point = Vec3::new(
                origin.x + dir.x * t,
                origin.y + dir.y * t,
                origin.z + dir.z * t,
            );
            let normal = match last_axis {
                0 => Vec3::new(-last_step as f32, 0.0, 0.0),
                1 => Vec3::new(0.0, -last_step as f32, 0.0),
                _ => Vec3::new(0.0, 0.0, -last_step as f32),
            };
            return Some(HitInfo { point, normal, distance: t, voxel: (cx, cy, cz) });
        }
        
        // 应用 walk step
        cx += step.delta_x as i32;
        cy += step.delta_y as i32;
        cz += step.delta_z as i32;
        t += step.t_to_next;
        if step.delta_x != 0 { last_axis = 0; last_step = step.delta_x as i32; }
        else if step.delta_y != 0 { last_axis = 1; last_step = step.delta_y as i32; }
        else { last_axis = 2; last_step = step.delta_z as i32; }
    }
    None
}
```

**关键**:
- `direction_to_bin` 把任意方向映射到 1024 bin 之一。
- `table[i]` 是该 bin 的步进序列。
- 内循环:边界检查 + solid 检查 + 应用 step。

### 性能对比

```rust
// DDA 版:每步算 t_max 比较 + 3 个加
// 查表版:每步查 1 个 step + 应用 3 个加

// DDA 内循环约 10 ns / 步
// 查表版内循环约 4 ns / 步
// 速度提升 2.5 倍
```

但**有误差**:方向 bin 量化让实际方向和 bin 中心略有偏差。对短距离(< 10 米)raycast,误差可忽略;对长距离(> 100 米),误差累积,可能撞错格子。

Casey 接受这个误差(因为光照计算本身就近似)。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏工业里"启动预算 + 运行时查表"模式广泛使用:
- **启动时**:加载贴图、模型、shader、walk table
- **运行时**:每帧查询,不重算

**踩过的坑**:
- **bin 太少**:量化误差大,光"撞错"。解决:增加 bin 数
- **bin 太多**:内存爆,cache miss 多。解决:测实际命中率,选合适 bin 数
- **场景变化**:walk table 基于固定场景,场景变要重算

Casey 的 1024 bin 是经验值。

### 3.2 · 🎨 图形学视角

**离散化 vs 连续**:walk table 是离散化(方向量化),原始 DDA 是连续。离散化让计算简化,但损失精度。

**Quality vs Performance**:walk table 换性能,损失精度。游戏开发经常做这种 trade-off。

**Quantization Error**:方向 bin 化的误差 = bin 之间角度差。1024 bin(32×32 八面体),每个 bin 约 10 度宽度。对 10 米距离,横向偏差 ~ 1 米(可能撞错格子)。

### 3.3 · 🐧 Linux 系统编程视角

这一集主要是预计算,Linux 系统调用面没什么。但**程序启动时间**值得一提。

walk table 启动时生成,1024 bin × 64 步,大约 10-50 ms。游戏启动慢 50 ms 用户感知不到。

**优化**:
- 用 `OnceLock::get_or_init` 懒加载(第一次 raycast 时才生成)
- 多线程并行生成(每个 bin 独立)

```rust
fn init_walk_tables_parallel() -> Vec<Vec<WalkStep>> {
    use rayon::prelude::*;
    (0..N_BINS).into_par_iter().map(|bin_idx| {
        let dir = bin_to_direction(bin_idx, N_BINS_PER_AXIS);
        generate_walk_table(dir, MAX_STEPS)
    }).collect()
}
```

8 核并行,启动时间从 50 ms 降到 10 ms。

### 3.4 · 🦀 Rust 生态视角

Rust 实现全局静态表的几个方式:

**1. `lazy_static` crate**(老方式):

```rust
use lazy_static::lazy_static;
lazy_static! {
    static ref WALK_TABLES: Vec<Vec<WalkStep>> = init_walk_tables();
}
```

需要 `lazy_static` 依赖。

**2. `OnceLock`**(标准库,1.70+):

```rust
use std::sync::OnceLock;
static WALK_TABLES: OnceLock<Vec<Vec<WalkStep>>> = OnceLock::new();
let tables = WALK_TABLES.get_or_init(init_walk_tables);
```

标准库,无依赖。

**3. `Lazy` (once_cell crate)**:

```rust
use once_cell::sync::Lazy;
static WALK_TABLES: Lazy<Vec<Vec<WalkStep>>> = Lazy::new(init_walk_tables);
```

需要 `once_cell` 依赖。

Casey 用 `OnceLock`(现代 Rust 标准)。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:Walk table 用 32×32 = 1024 bin,每个 bin 一个表。如果改用 16×16 = 256 bin,会发生什么?性能 / 精度 / 内存的 trade-off?

**参考解答**:
- **内存**:256 × 64 × 8 = 128 KB(原 512 KB 的 1/4)。cache 更友好
- **精度**:每个 bin 覆盖更大方向范围(约 22 度,原 10 度)。量化误差更大,光可能撞错格子
- **性能**:bin 数少,bin_idx 计算简单一点(略快);但 cache miss 少,内循环可能更快
- **总体**:对小场景(< 10 米),256 bin 够用;大场景(> 50 米),需要 1024 bin 保持精度

### Lv2 · 动手实践

**题**:实现完整 walk table 系统(2D 简化版),包括 bin 化、预生成、查表 raycast。测试:
- 1024 条光线
- 与 Grid DDA 对比性能

完成标准:`cargo run` 显示查表版快 2 倍以上。

**参考解答**:

```rust
const N_BINS_PER_AXIS: usize = 16;
const N_BINS: usize = N_BINS_PER_AXIS * N_BINS_PER_AXIS;
const MAX_STEPS: usize = 32;

#[derive(Copy, Clone)]
struct WalkStep2D {
    delta_x: i8,
    delta_y: i8,
    t_to_next: f32,
}

fn dir_to_bin_2d(dx: f32, dy: f32) -> usize {
    let len = (dx*dx + dy*dy).sqrt();
    let dx = dx / len;
    let dy = dy / len;
    let bx = ((dx + 1.0) * 0.5 * N_BINS_PER_AXIS as f32) as usize;
    let by = ((dy + 1.0) * 0.5 * N_BINS_PER_AXIS as f32) as usize;
    let bx = bx.min(N_BINS_PER_AXIS - 1);
    let by = by.min(N_BINS_PER_AXIS - 1);
    by * N_BINS_PER_AXIS + bx
}

fn bin_to_dir_2d(bin: usize) -> (f32, f32) {
    let bx = bin % N_BINS_PER_AXIS;
    let by = bin / N_BINS_PER_AXIS;
    let dx = (bx as f32 / (N_BINS_PER_AXIS - 1) as f32) * 2.0 - 1.0;
    let dy = (by as f32 / (N_BINS_PER_AXIS - 1) as f32) * 2.0 - 1.0;
    let len = (dx*dx + dy*dy).sqrt();
    (dx/len, dy/len)
}

fn gen_walk_table_2d(dx: f32, dy: f32) -> Vec<WalkStep2D> {
    let mut table = Vec::with_capacity(MAX_STEPS);
    let step_x = if dx > 0.0 { 1i8 } else { -1 };
    let step_y = if dy > 0.0 { 1 } else { -1 };
    let mut t_max_x = if dx.abs() > 1e-10 { 1.0 / dx.abs() } else { f32::INFINITY };
    let mut t_max_y = if dy.abs() > 1e-10 { 1.0 / dy.abs() } else { f32::INFINITY };
    let t_dx = t_max_x;
    let t_dy = t_max_y;
    let mut prev = 0.0;
    for _ in 0..MAX_STEPS {
        if t_max_x < t_max_y {
            let t = t_max_x;
            t_max_x += t_dx;
            table.push(WalkStep2D { delta_x: step_x, delta_y: 0, t_to_next: t - prev });
            prev = t;
        } else {
            let t = t_max_y;
            t_max_y += t_dy;
            table.push(WalkStep2D { delta_x: 0, delta_y: step_y, t_to_next: t - prev });
            prev = t;
        }
    }
    table
}

fn gen_all_tables_2d() -> Vec<Vec<WalkStep2D>> {
    (0..N_BINS).map(|bin| {
        let (dx, dy) = bin_to_dir_2d(bin);
        gen_walk_table_2d(dx, dy)
    }).collect()
}

struct World2D {
    dim: usize,
    cells: Vec<bool>,
}
impl World2D {
    fn new(dim: usize) -> Self { Self { dim, cells: vec![false; dim*dim] } }
    fn is_solid(&self, x: i32, y: i32) -> bool {
        if x < 0 || y < 0 || x >= self.dim as i32 || y >= self.dim as i32 { return false; }
        self.cells[y as usize * self.dim + x as usize]
    }
    fn is_in_bounds(&self, x: i32, y: i32) -> bool {
        x >= 0 && y >= 0 && x < self.dim as i32 && y < self.dim as i32
    }
}

fn raycast_table(world: &World2D, ox: f32, oy: f32, dx: f32, dy: f32, tables: &[Vec<WalkStep2D>]) -> Option<(i32, i32)> {
    let bin = dir_to_bin_2d(dx, dy);
    let table = &tables[bin];
    let mut cx = ox.floor() as i32;
    let mut cy = oy.floor() as i32;
    let mut t = 0.0;
    let max_dist = 100.0;
    for step in table {
        if !world.is_in_bounds(cx, cy) { return None; }
        if world.is_solid(cx, cy) { return Some((cx, cy)); }
        if t > max_dist { return None; }
        cx += step.delta_x as i32;
        cy += step.delta_y as i32;
        t += step.t_to_next;
    }
    None
}

fn main() {
    let tables = gen_all_tables_2d();
    println!("Generated {} walk tables", tables.len());
    
    let mut world = World2D::new(64);
    world.cells[32 * 64 + 32] = true;  // 墙在 (32, 32)
    
    let n = 1000;
    let rays: Vec<(f32, f32, f32, f32)> = (0..n).map(|i| {
        let t = i as f32 * 0.01;
        (0.5, 0.5, t.sin(), t.cos())
    }).collect();
    
    let start = std::time::Instant::now();
    let mut hits = 0;
    for &(ox, oy, dx, dy) in &rays {
        if raycast_table(&world, ox, oy, dx, dy, &tables).is_some() {
            hits += 1;
        }
    }
    let elapsed = start.elapsed();
    println!("{} rays: {} hits in {:?} ({:.1} ns/ray)",
        n, hits, elapsed, elapsed.as_nanos() as f64 / n as f64);
}
```

```rust
use std::sync::OnceLock;

// (常量、WalkStep2D、World2D、dir_to_bin_2d、bin_to_dir_2d、gen_walk_table_2d、gen_all_tables_2d 同 Lv2)

static TABLES: OnceLock<Vec<Vec<WalkStep2D>>> = OnceLock::new();

fn get_tables() -> &'static Vec<Vec<WalkStep2D>> {
    TABLES.get_or_init(gen_all_tables_2d)
}

fn main() {
    println!("First call (will init tables)...");
    let start_init = std::time::Instant::now();
    let _ = get_tables();
    println!("Tables init: {:?}", start_init.elapsed());
    
    let mut world = World2D::new(64);
    for i in 0..64 {
        world.cells[32 * 64 + i] = true;  // x=32 处一面墙
    }
    
    // 性能对比
    let n = 10_000;
    let rays: Vec<(f32, f32, f32, f32)> = (0..n).map(|i| {
        let t = i as f32 * 0.001;
        (0.5, 0.5, t.sin(), t.cos())
    }).collect();
    
    let start = std::time::Instant::now();
    let mut hits = 0;
    for &(ox, oy, dx, dy) in &rays {
        if raycast_table(&world, ox, oy, dx, dy, get_tables()).is_some() {
            hits += 1;
        }
    }
    let elapsed = start.elapsed();
    println!("\n{} table rays: {} hits in {:?} ({:.1} ns/ray)",
        n, hits, elapsed, elapsed.as_nanos() as f64 / n as f64);
    
    // 内存占用估算
    let mem = N_BINS * MAX_STEPS * std::mem::size_of::<WalkStep2D>();
    println!("\nTable memory: {} bytes ({:.1} KB)", mem, mem as f64 / 1024.0);
    println!("Bin count: {}", N_BINS);
}
```

### A.3 性能优化的实际流程

工业性能优化的标准流程:

**Step 1:测量**(cargo flamegraph / perf)
- 找最慢的函数
- 不要猜,要测

**Step 2:分析**(为什么慢)
- 算法?(O(N²) vs O(N log N))
- 内存?(cache miss)
- 同步?(锁等待)
- 分支?(branch mispredict)

**Step 3:优化**(对症下药)
- 算法:换数据结构
- 内存:SoA / prefetch
- 同步:细化锁
- 分支:branchless

**Step 4:验证**(再测)
- 看新 profile
- 性能提升 vs 代码复杂度
- 不值得就回滚

**Step 5:文档**(给后人)
- commit message 解释为什么
- 注释 hot path 的考量

### A.5 Voxel lighting 的未来

学术 / 工业前沿:

**1. Real-time path tracing on RTX**:
- RTX 核心加速 voxel raycast
- 真实光传播(无简化)
- Minecraft RTX、Teardown 已经实现

**2. Neural voxel lighting**:
- 神经网络压缩 SH 数据
- 推理时光照实时算
- 研究(NeRF、Neural radiance cache)

**3. Differentiable rendering**:
- 光照对几何的偏导
- 反向传播到材质 / 几何
- 应用:材质反推、自动优化

**4. Wavelet voxel**:
- Wavelet 变换替代 SH
- 多分辨率,更适合稀疏数据
- 研究(Wavelet GVT)

这些是未来 5-10 年的方向。

### A.11 完整 Rust voxel lighting 实现

让我提供一个完整的 Rust voxel lighting 实现示例,综合前面所有概念:

```rust
use std::collections::HashMap;

const CHUNK_SIZE: u32 = 32;

struct Voxel {
    material: u8,
    color: [u8; 3],
}

struct Chunk {
    voxels: Vec<Voxel>,
    light: Vec<[u8; 4]>,  // RGBE
}

struct World {
    chunks: HashMap<(i32, i32, i32), Chunk>,
    sun_dir: Vec3,
    sun_color: [f32; 3],
}

impl World {
    fn get_voxel(&self, x: i32, y: i32, z: i32) -> Option<&Voxel> {
        let (cx, cy, cz) = (x.div_euclid(CHUNK_SIZE as i32), 
                            y.div_euclid(CHUNK_SIZE as i32),
                            z.div_euclid(CHUNK_SIZE as i32));
        let chunk = self.chunks.get(&(cx, cy, cz))?;
        let (lx, ly, lz) = (x.rem_euclid(CHUNK_SIZE as i32) as usize,
                            y.rem_euclid(CHUNK_SIZE as i32) as usize,
                            z.rem_euclid(CHUNK_SIZE as i32) as usize);
        let idx = lz * (CHUNK_SIZE as usize).pow(2) + ly * CHUNK_SIZE as usize + lx;
        Some(&chunk.voxels[idx])
    }
    
    fn is_solid(&self, x: i32, y: i32, z: i32) -> bool {
        self.get_voxel(x, y, z).map(|v| v.material != 0).unwrap_or(false)
    }
}

fn grid_dda(world: &World, start: Vec3, dir: Vec3, max_dist: f32) -> bool {
    let mut cx = start.x.floor() as i32;
    let mut cy = start.y.floor() as i32;
    let mut cz = start.z.floor() as i32;
    
    let step_x = if dir.x > 0.0 { 1 } else { -1 };
    let step_y = if dir.y > 0.0 { 1 } else { -1 };
    let step_z = if dir.z > 0.0 { 1 } else { -1 };
    
    let t_delta_x = if dir.x.abs() > 1e-10 { 1.0 / dir.x.abs() } else { f32::INFINITY };
    let t_delta_y = if dir.y.abs() > 1e-10 { 1.0 / dir.y.abs() } else { f32::INFINITY };
    let t_delta_z = if dir.z.abs() > 1e-10 { 1.0 / dir.z.abs() } else { f32::INFINITY };
    
    let mut t_max_x = if dir.x.abs() > 1e-10 {
        (((cx + if dir.x > 0 { 1 } else { 0 }) as f32) - start.x) / dir.x
    } else { f32::INFINITY };
    let mut t_max_y = /* similar */;
    let mut t_max_z = /* similar */;
    
    let mut t = 0.0;
    while t < max_dist {
        if world.is_solid(cx, cy, cz) {
            return true;  // occluded
        }
        
        if t_max_x < t_max_y && t_max_x < t_max_z {
            cx += step_x;
            t = t_max_x;
            t_max_x += t_delta_x;
        } else if t_max_y < t_max_z {
            cy += step_y;
            t = t_max_y;
            t_max_y += t_delta_y;
        } else {
            cz += step_z;
            t = t_max_z;
            t_max_z += t_delta_z;
        }
    }
    false
}

fn compute_direct_lighting(world: &World, x: i32, y: i32, z: i32) -> [f32; 3] {
    let voxel_pos = Vec3::new(x as f32 + 0.5, y as f32 + 0.5, z as f32 + 0.5);
    
    // 是否被遮挡
    if grid_dda(world, voxel_pos, world.sun_dir, 100.0) {
        return [0.0; 3];  // 阴影
    }
    
    // Lambert 光照
    let normal = compute_normal(world, x, y, z);
    let lambert = normal.dot(world.sun_dir).max(0.0);
    
    [
        world.sun_color[0] * lambert,
        world.sun_color[1] * lambert,
        world.sun_color[2] * lambert,
    ]
}

fn compute_normal(world: &World, x: i32, y: i32, z: i32) -> Vec3 {
    let dx = if world.is_solid(x-1, y, z) { 1.0 } else { 0.0 } 
           - if world.is_solid(x+1, y, z) { 1.0 } else { 0.0 };
    let dy = if world.is_solid(x, y-1, z) { 1.0 } else { 0.0 }
           - if world.is_solid(x, y+1, z) { 1.0 } else { 0.0 };
    let dz = if world.is_solid(x, y, z-1) { 1.0 } else { 0.0 }
           - if world.is_solid(x, y, z+1) { 1.0 } else { 0.0 };
    
    Vec3::new(dx, dy, dz).normalize()
}
```
