
# Day 604 · 加体素工具结构

> Day 590-603 加了很多体素相关代码(Grid DDA、walk table、raycast),但散落在多处。今天 Casey 把这些"体素操作"封装到一个 `VoxelUtility` 结构里,让代码组织更清晰。

## 0 · 为什么要有这一天

之前的体素代码分散:

```rust
// 各处都有这种代码
let cx = (pos.x / cell_size).floor() as i32;
let cy = (pos.y / cell_size).floor() as i32;
let cz = (pos.z / cell_size).floor() as i32;
let idx = cz * dim * dim + cy * dim + cx;
```

每次都要写"floor + 转 i32 + 算 index",重复且容易出错(比如 cell_size 不同地方不一致)。

**VoxelUtility 结构**封装这些操作:

```rust
struct VoxelUtility {
    cell_size: f32,
    dim: usize,
}

impl VoxelUtility {
    fn world_to_voxel(&self, pos: Vec3) -> (i32, i32, i32) { ... }
    fn voxel_to_index(&self, x: i32, y: i32, z: i32) -> Option<usize> { ... }
    fn index_to_voxel(&self, idx: usize) -> (i32, i32, i32) { ... }
    fn voxel_center(&self, x: i32, y: i32, z: i32) -> Vec3 { ... }
    fn is_in_bounds(&self, x: i32, y: i32, z: i32) -> bool { ... }
}
```

所有"体素相关"代码都通过 VoxelUtility 操作,避免重复。

心理锚点:看完这集,你能识别"代码重复"的征兆,能用 struct + impl 封装一组相关操作,理解"工具类"在工程化代码中的价值。

## 2 · 心智模型

### 类比:厨房工具收纳

厨房里有刀、勺、锅铲等工具,散落在台面各处。每次做饭都要"找工具"。

**整理**:把所有工具挂在工具架上,每个工具有固定位置。做饭时直接拿,不用找。

VoxelUtility 完全一样——把所有"体素相关操作"封装到一个 struct,调用方"直接用",不用每次重写。

### 严谨原理:工具类

**工具类**(Utility class)是面向对象的封装模式。把一组相关操作封装,提供清晰接口。

VoxelUtility 接口:

```rust
#[derive(Copy, Clone, Debug)]
struct VoxelUtility {
    cell_size: f32,
    dim_x: usize,
    dim_y: usize,
    dim_z: usize,
}

impl VoxelUtility {
    fn new(cell_size: f32, dim_x: usize, dim_y: usize, dim_z: usize) -> Self {
        Self { cell_size, dim_x, dim_y, dim_z }
    }
    
    /// 世界坐标 → 体素坐标
    fn world_to_voxel(&self, pos: Vec3) -> (i32, i32, i32) {
        let inv = 1.0 / self.cell_size;
        (
            (pos.x * inv).floor() as i32,
            (pos.y * inv).floor() as i32,
            (pos.z * inv).floor() as i32,
        )
    }
    
    /// 体素坐标 → 数组索引
    fn voxel_to_index(&self, x: i32, y: i32, z: i32) -> Option<usize> {
        if !self.is_in_bounds(x, y, z) {
            return None;
        }
        Some((z as usize) * self.dim_x * self.dim_y 
            + (y as usize) * self.dim_x 
            + x as usize)
    }
    
    /// 数组索引 → 体素坐标
    fn index_to_voxel(&self, idx: usize) -> (i32, i32, i32) {
        let z = idx / (self.dim_x * self.dim_y);
        let y = (idx / self.dim_x) % self.dim_y;
        let x = idx % self.dim_x;
        (x as i32, y as i32, z as i32)
    }
    
    /// 体素中心的世界坐标
    fn voxel_center(&self, x: i32, y: i32, z: i32) -> Vec3 {
        Vec3::new(
            (x as f32 + 0.5) * self.cell_size,
            (y as f32 + 0.5) * self.cell_size,
            (z as f32 + 0.5) * self.cell_size,
        )
    }
    
    /// 体素 min 角的世界坐标
    fn voxel_min(&self, x: i32, y: i32, z: i32) -> Vec3 {
        Vec3::new(
            x as f32 * self.cell_size,
            y as f32 * self.cell_size,
            z as f32 * self.cell_size,
        )
    }
    
    /// 体素 max 角的世界坐标
    fn voxel_max(&self, x: i32, y: i32, z: i32) -> Vec3 {
        Vec3::new(
            (x as f32 + 1.0) * self.cell_size,
            (y as f32 + 1.0) * self.cell_size,
            (z as f32 + 1.0) * self.cell_size,
        )
    }
    
    /// 是否在网格内
    fn is_in_bounds(&self, x: i32, y: i32, z: i32) -> bool {
        x >= 0 && y >= 0 && z >= 0 &&
        (x as usize) < self.dim_x &&
        (y as usize) < self.dim_y &&
        (z as usize) < self.dim_z
    }
    
    /// 在体素内的局部坐标 [0, 1)
    fn world_to_local(&self, pos: Vec3) -> (f32, f32, f32) {
        let inv = 1.0 / self.cell_size;
        let lx = (pos.x * inv).fract();
        let ly = (pos.y * inv).fract();
        let lz = (pos.z * inv).fract();
        (lx, ly, lz)
    }
}
```

**每行解释**:
- `inv = 1.0 / cell_size` — 预算倒数,用乘法代替除法(更快)。
- `floor() as i32` — 浮点 floor + 转 i32(截断)。
- `(idx / dim_x) % dim_y` — 3D index 解码。
- `(x + 0.5) * cell_size` — 体素中心,加 0.5(半个 cell)。
- `fract()` — 取小数部分,用于"在体素内的局部坐标"。

### 使用 VoxelUtility

```rust
struct World {
    util: VoxelUtility,
    cells: Vec<bool>,
}

impl World {
    fn new(dim_x: usize, dim_y: usize, dim_z: usize, cell_size: f32) -> Self {
        Self {
            util: VoxelUtility::new(cell_size, dim_x, dim_y, dim_z),
            cells: vec![false; dim_x * dim_y * dim_z],
        }
    }
    
    fn is_solid(&self, pos: Vec3) -> bool {
        let (x, y, z) = self.util.world_to_voxel(pos);
        match self.util.voxel_to_index(x, y, z) {
            Some(idx) => self.cells[idx],
            None => false,
        }
    }
    
    fn set_solid(&mut self, pos: Vec3, solid: bool) {
        let (x, y, z) = self.util.world_to_voxel(pos);
        if let Some(idx) = self.util.voxel_to_index(x, y, z) {
            self.cells[idx] = solid;
        }
    }
}
```

**关键改进**:
- 之前每次 `floor + as i32 + 索引`,重复 5-10 行
- 现在 `world_to_voxel` + `voxel_to_index`,2 行

### 之前 vs 之后

之前(raycast 内):

```rust
let cell_size = 1.0;
let mut cx = (ray.origin.x / cell_size).floor() as i32;
let mut cy = (ray.origin.y / cell_size).floor() as i32;
let mut cz = (ray.origin.z / cell_size).floor() as i32;
let dim = world.dim;

// ... raycast loop

if cx < 0 || cy < 0 || cz < 0 || cx >= dim || cy >= dim || cz >= dim {
    return None;
}
let idx = (cz * dim * dim + cy * dim + cx) as usize;
if world.cells[idx] {
    return Some(HitInfo { ... });
}
```

之后:

```rust
let util = &world.util;
let (mut cx, mut cy, mut cz) = util.world_to_voxel(ray.origin);

// ... raycast loop

if !util.is_in_bounds(cx, cy, cz) { return None; }
if let Some(idx) = util.voxel_to_index(cx, cy, cz) {
    if world.cells[idx] {
        let center = util.voxel_center(cx, cy, cz);
        return Some(HitInfo { point: center, ... });
    }
}
```

代码更短,意图更清晰。

## 3 · 四域深入

### 3.1 · 🎮 游戏编程视角

游戏工业里"工具类"无处不在:
- **Unity**:Mathf、Vector3 等 static 类
- **Unreal**:FMath、FVector
- **bevy**:math 操作 trait

**踩过的坑**:
- **过度封装**:工具类太大,什么都塞进去,变 "God Object"。解决:每个 struct 职责单一
- **泛型地狱**:为了通用性,把 cell_size、dim 等做成泛型。编译时间爆炸。解决:用具体类型
- **API 不一致**:不同工具类 API 风格不一致,调用方困惑。解决:统一命名约定

### 3.2 · 🎨 图形学视角

图形学里有大量"坐标变换"——local / world / view / clip / NDC / screen。每种变换有对应工具类。

**Transform utility**(常见):

```rust
struct Transform {
    pos: Vec3,
    rotation: Quat,
    scale: Vec3,
}

impl Transform {
    fn local_to_world(&self, p: Vec3) -> Vec3 { ... }
    fn world_to_local(&self, p: Vec3) -> Vec3 { ... }
    fn matrix(&self) -> Mat4 { ... }
}
```

VoxelUtility 是这种"坐标变换工具"在体素场景下的具体实现。

### 3.3 · 🐧 Linux 系统编程视角

Linux 内核也有类似"工具结构":
- `struct list_head` — 链表节点,通用工具
- `struct kref` — 引用计数,通用工具
- `struct timer_list` — 定时器,通用工具

这些"工具"在内核各处复用,代码 DRY。

**Rust 标准库的工具**:很多容器(Vec / HashMap)都是这种思路——封装一组操作,提供清晰 API。

### 3.4 · 🦀 Rust 生态视角

Rust 表达"工具结构"的几个细节:

**1. `#[derive(Copy, Clone, Debug)]`**:VoxelUtility 只有几个 f32 / usize,Copy 友好。

**2. 静态方法 vs 实例方法**:

```rust
impl VoxelUtility {
    // 静态方法(关联函数)
    fn new(cell_size: f32, ...) -> Self { ... }
    
    // 实例方法
    fn world_to_voxel(&self, pos: Vec3) -> (i32, i32, i32) { ... }
}

// 调用
let util = VoxelUtility::new(1.0, 16, 16, 16);  // 静态
let v = util.world_to_voxel(pos);  // 实例
```

**3. `Option<usize>`**:voxel_to_index 返回 Option,显式表达"可能越界"。

**4. trait 抽象**:如果将来要支持不同 cell_size 的网格,可以用 trait:

```rust
trait VoxelCoord {
    fn world_to_voxel(&self, pos: Vec3) -> (i32, i32, i32);
}

impl VoxelCoord for VoxelUtility { ... }
```

Casey 在 Day 604 不做 trait,直接 struct。

### 历史演化

### OOP vs DOD 工具类

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 VoxelUtility 要存 `cell_size` 和 `dim`,而不是每次传参?

**参考解答**:存到 struct 里有两个好处:
1. **避免重复传参**:每次方法调用不用传 cell_size,dim,代码简洁
2. **一致性保证**:同一个 VoxelUtility 实例的所有方法用同样的 cell_size 和 dim,不会出现"某处用 1.0 cell_size,另一处用 0.5"的不一致

代价:每个 VoxelUtility 实例占内存(40 字节左右)。但通常整个程序只有 1-2 个实例,代价可忽略。

struct Vec3 { x: f32, y: f32, z: f32 }
impl Vec3 { fn new(x: f32, y: f32, z: f32) -> Self { Self { x, y, z } } }

#[derive(Copy, Clone, Debug)]
struct VoxelUtility {
    cell_size: f32,
    dim_x: usize,
    dim_y: usize,
    dim_z: usize,
}

impl VoxelUtility {
    fn new(cell_size: f32, dim_x: usize, dim_y: usize, dim_z: usize) -> Self {
        Self { cell_size, dim_x, dim_y, dim_z }
    }
    
    fn world_to_voxel(&self, pos: Vec3) -> (i32, i32, i32) {
        let inv = 1.0 / self.cell_size;
        (
            (pos.x * inv).floor() as i32,
            (pos.y * inv).floor() as i32,
            (pos.z * inv).floor() as i32,
        )
    }
    
    fn voxel_to_index(&self, x: i32, y: i32, z: i32) -> Option<usize> {
        if !self.is_in_bounds(x, y, z) { return None; }
        Some(z as usize * self.dim_x * self.dim_y 
            + y as usize * self.dim_x 
            + x as usize)
    }
    
    fn voxel_center(&self, x: i32, y: i32, z: i32) -> Vec3 {
        Vec3::new(
            (x as f32 + 0.5) * self.cell_size,
            (y as f32 + 0.5) * self.cell_size,
            (z as f32 + 0.5) * self.cell_size,
        )
    }
    
    fn is_in_bounds(&self, x: i32, y: i32, z: i32) -> bool {
        x >= 0 && y >= 0 && z >= 0 &&
        (x as usize) < self.dim_x &&
        (y as usize) < self.dim_y &&
        (z as usize) < self.dim_z
    }
}

fn main() {
    let util = VoxelUtility::new(1.0, 16, 16, 16);
    
    let v = util.world_to_voxel(Vec3::new(1.5, 2.7, 3.4));
    println!("world_to_voxel((1.5, 2.7, 3.4)): {:?}", v);
    assert_eq!(v, (1, 2, 3));
    
    let idx = util.voxel_to_index(1, 2, 3);
    println!("voxel_to_index(1, 2, 3): {:?}", idx);
    assert_eq!(idx, Some(3 * 16 * 16 + 2 * 16 + 1));
    
    let center = util.voxel_center(1, 2, 3);
    println!("voxel_center(1, 2, 3): {:?}", center);
    assert_eq!(center, Vec3::new(1.5, 2.5, 3.5));
    
    // 越界测试
    assert_eq!(util.voxel_to_index(-1, 0, 0), None);
    assert_eq!(util.voxel_to_index(16, 0, 0), None);
    
    println!("All tests passed");

## 8 · Rust / Arch 落地代码

完整可跑示例(基于 Lv2):

```rust
// (Vec3, VoxelUtility 同 Lv2)

impl VoxelUtility {
    fn voxel_min(&self, x: i32, y: i32, z: i32) -> Vec3 {
        Vec3::new(
            x as f32 * self.cell_size,
            y as f32 * self.cell_size,
            z as f32 * self.cell_size,
        )
    }
    
    fn voxel_max(&self, x: i32, y: i32, z: i32) -> Vec3 {
        Vec3::new(
            (x as f32 + 1.0) * self.cell_size,
            (y as f32 + 1.0) * self.cell_size,
            (z as f32 + 1.0) * self.cell_size,
        )
    }
    
    fn index_to_voxel(&self, idx: usize) -> (i32, i32, i32) {
        let z = idx / (self.dim_x * self.dim_y);
        let y = (idx / self.dim_x) % self.dim_y;
        let x = idx % self.dim_x;
        (x as i32, y as i32, z as i32)
    }
    
    fn world_to_local(&self, pos: Vec3) -> (f32, f32, f32) {
        let inv = 1.0 / self.cell_size;
        (
            (pos.x * inv).fract(),
            (pos.y * inv).fract(),
            (pos.z * inv).fract(),
        )
    }
    
    fn total_voxels(&self) -> usize {
        self.dim_x * self.dim_y * self.dim_z
    }
}

fn main() {
    let util = VoxelUtility::new(0.5, 32, 32, 32);  // 0.5m 格, 32^3 个
    
    println!("VoxelUtility {{ cell_size: {}, dims: {}x{}x{} }}",
        util.cell_size, util.dim_x, util.dim_y, util.dim_z);
    println!("Total voxels: {}", util.total_voxels());
    
    // 一些坐标转换
    let test_positions = [
        Vec3::new(0.3, 0.7, 1.0),
        Vec3::new(1.5, 2.5, 3.5),
        Vec3::new(15.9, 15.9, 15.9),
    ];
    
    for pos in &test_positions {
        let voxel = util.world_to_voxel(*pos);
        let idx = util.voxel_to_index(voxel.0, voxel.1, voxel.2);
        let center = util.voxel_center(voxel.0, voxel.1, voxel.2);
        let local = util.world_to_local(*pos);
        println!("\nPosition ({}, {}, {}):", pos.x, pos.y, pos.z);
        println!("  Voxel: {:?}", voxel);
        println!("  Index: {:?}", idx);
        println!("  Center: ({}, {}, {})", center.x, center.y, center.z);
        println!("  Local (in voxel): ({:.2}, {:.2}, {:.2})", local.0, local.1, local.2);
    }
    
    // 验证 round-trip
    println!("\nRound-trip test:");
    for i in 0..10 {
        let voxel = (i, i + 1, i + 2);
        let idx = util.voxel_to_index(voxel.0, voxel.1, voxel.2).unwrap();
        let back = util.index_to_voxel(idx);
        assert_eq!(voxel, back);
    }
    println!("All round-trips passed");
}
```

- center 偏移 — 检查 `+ 0.5`(中心 vs 角点)
- fract 返回负数 — `fract()` 对负数返回负数,需要 `((x * inv).rem_euclid(1.0))`

### A.2 Voxel lighting 的核心问题

工业级 voxel lighting 解决以下核心问题:

**1. 计算量**:
- 大场景(几百万 voxel)
- 每 voxel 要算多方向光
- 每方向要 raycast(检查遮挡)

**2. 实时性**:
- 玩家编辑 voxel(挖 / 放)
- 光照要立即更新
- 16.67 ms 帧预算

**3. 内存**:
- 每 voxel 存光照值(RGB 或 SH)
- 大场景内存爆炸
- 需要 streaming

**4. 准确性**:
- 直接光(sun)
- 间接光(bounce)
- 阴影(soft / hard)
- 反射(diffuse / specular)

工业方案在这些问题之间权衡。Casey 的 HH 教基础权衡。

### A.3 性能优化的具体技术

**Spatial partitioning**:
- Grid:固定大小 voxel,直接索引
- Octree:稀疏,只存有内容的节点
- BVH:bounding volume hierarchy,GPU 友好
- k-d tree:递归 axis-aligned split

**Temporal coherence**:
- 帧间复用(上一帧光照 + 增量)
- TAA(temporal anti-aliasing)
- 时序累积(低噪点)

**Level of detail**:
- 远处 voxel 粗采样
- 近处 voxel 精细
- mipmap voxel atlas

**GPU compute**:
- Vulkan / DX12 / Metal compute shader
- 自定义 ray tracing shader
- RTX 核心加速

### A.8 Voxel lighting 算法的具体实现细节

让我深入讲讲 voxel lighting 算法的实现细节:

**Direct lighting**(直接光):

```rust
fn compute_direct_lighting(
    world: &World,
    sun_dir: Vec3,
    sun_color: RGB,
) -> LightAtlas {
    let mut atlas = LightAtlas::new(world.width, world.height, world.depth);
    
    for z in 0..world.depth {
        for y in 0..world.height {
            for x in 0..world.width {
                if world.get(x, y, z).is_air() { continue; }
                
                // 检查是否被遮挡(从 voxel 到 sun 方向)
                let voxel_pos = Vec3::new(x as f32 + 0.5, y as f32 + 0.5, z as f32 + 0.5);
                let ray = Ray::new(voxel_pos, sun_dir);
                let occluded = grid_dda(world, ray, 100.0).is_some();
                
                if !occluded {
                    // 计算法线(根据邻居)
                    let normal = compute_normal(world, x, y, z);
                    let lambert = normal.dot(sun_dir).max(0.0);
                    let light = sun_color * lambert;
                    atlas.set(x, y, z, light);
                }
            }
        }
    }
    
    atlas
}
```

**Indirect lighting**(间接光 / bounce):

```rust
fn compute_indirect_lighting(
    world: &World,
    direct: &LightAtlas,
    bounces: usize,
) -> LightAtlas {
    let mut current = direct.clone();
    
    for _ in 0..bounces {
        let mut next = current.clone();
        
        for z in 0..world.depth {
            for y in 0..world.height {
                for x in 0..world.width {
                    if world.get(x, y, z).is_air() { continue; }
                    
                    // 累加 6 邻居的光(简化 diffuse)
                    let mut accumulated = RGB::black();
                    for (dx, dy, dz) in NEIGHBORS_6 {
                        let nx = x as i32 + dx;
                        let ny = y as i32 + dy;
                        let nz = z as i32 + dz;
                        if nx >= 0 && ny >= 0 && nz >= 0 {
                            let n_light = current.get(nx as u32, ny as u32, nz as u32);
                            accumulated += n_light * 0.15;  // bounce factor
                        }
                    }
                    
                    let cur = current.get(x, y, z);
                    next.set(x, y, z, cur + accumulated);
                }
            }
        }
        
        current = next;
    }
    
    current
}
```

### A.9 Voxel 法线计算

Voxel 表面法线计算:

```rust
fn compute_normal(world: &World, x: u32, y: u32, z: u32) -> Vec3 {
    // Sobel filter 算法线(类似图像边缘检测)
    let mut sx = 0.0; let mut sy = 0.0; let mut sz = 0.0;
    
    for dz in -1i32..=1 {
        for dy in -1i32..=1 {
            for dx in -1i32..=1 {
                let nx = x as i32 + dx;
                let ny = y as i32 + dy;
                let nz = z as i32 + dz;
                let density = if in_bounds(world, nx, ny, nz) && world.get(nx, ny, nz).is_solid() {
                    1.0
                } else { 0.0 };
                sx += dx as f32 * density;
                sy += dy as f32 * density;
                sz += dz as f32 * density;
            }
        }
    }
    
    Vec3::new(sx, sy, sz).normalize()
}
```

法线用于 Lambert / Phong 光照计算。
