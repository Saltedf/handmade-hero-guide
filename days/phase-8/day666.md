## 2 · 心智模型

### 类比:快递保险

老快递:扔箱子到门口,丢了不管。
新快递:签名、保险、跟踪号、损坏赔偿。

存档系统同构——开始只保证"happy path",最后加保险——文件不存在 / 损坏 / 误操作都安全。

### Magic number

二进制文件开头几个字节,标识文件类型。例:

- PNG: `89 50 4E 47`(`.PNG`)
- ZIP: `50 4B 03 04`(`PK..`)
- ELF: `7F 45 4C 46`(`.ELF`)

HH 存档加 `HHSV`(4 字节)。加载时先读这 4 字节,不匹配就报错"不是存档文件"。

### CRC32 校验

CRC32 是 32-bit 校验码,文件末尾。加载时:

1. 读文件全部内容
2. 算 CRC32
3. 读文件末尾 4 字节(存档时存的 CRC32)
4. 比对,不匹配报错

CRC32 检测"磁盘错误 / 网络传输错误"。不能防恶意篡改(没加密),但能防意外损坏。

```rust
use std::collections::hash_map::DefaultHasher;
use std::hash::{Hash, Hasher};

fn crc32(data: &[u8]) -> u32 {
    let mut h = DefaultHasher::new();
    data.hash(&mut h);
    h.finish() as u32
}
```

更严格的:CRC32 crate,工业标准 CRC-32 IEEE 802.3。

### Atomic save(原子保存)

直接写文件:`File::create("save.bin")` + 写。如果写到一半断电,文件半损坏。

原子保存:写到临时文件,然后 rename 到目标文件。rename 在同一文件系统上是原子的(POSIX 保证)。

```rust
fn save_atomic(path: &str, data: &[u8]) -> std::io::Result<()> {
    let tmp = format!("{}.tmp", path);
    {
        let mut f = File::create(&tmp)?;
        f.write_all(data)?;
        f.sync_all()?; // fsync,确保数据写盘
    }
    std::fs::rename(&tmp, path)?; // atomic
    Ok(())
}
```

玩家断电:要么旧文件,要么新文件,不会损坏中间状态。

## 7 · 变式训练

### Lv1 · 概念辨析

**题**:为什么 atomic save 要先写 .tmp 再 rename?

**参考解答**:直接写目标文件,写到一半系统崩溃,文件半损坏——加载时报错或更糟,加载到一半崩溃。atomic save:先写 .tmp 文件(全写完才 rename),rename 是 atomic(POSIX 保证)。崩溃时:要么 .tmp 在(目标文件不存在,旧版本),要么目标在(.tmp 已 rename)。两者都是合法状态,不会损坏。

### Lv2 · 动手实践

**题**:实现 §2 的 atomic save + CRC32 校验。

**参考解答**:

```rust
use std::fs::File;
use std::io::{BufReader, BufWriter, Read, Write};
use std::path::Path;

const MAGIC: &[u8; 4] = b"HHSV";

fn crc32_simple(data: &[u8]) -> u32 {
    // 简化 CRC(非真正 CRC32,演示用)
    let mut h = 0u32;
    for &b in data {
        h = h.wrapping_mul(31).wrapping_add(b as u32);
    }
    h
}

fn save_atomic(path: &str, payload: &[u8]) -> std::io::Result<()> {
    let tmp = format!("{}.tmp", path);
    let crc = crc32_simple(payload);
    {
        let f = File::create(&tmp)?;
        let mut w = BufWriter::new(f);
        w.write_all(MAGIC)?;
        w.write_all(&(payload.len() as u32).to_le_bytes())?;
        w.write_all(payload)?;
        w.write_all(&crc.to_le_bytes())?;
        w.flush()?;
        w.get_ref().sync_all()?;
    }
    std::fs::rename(&tmp, path)?;
    Ok(())
}

enum LoadError {
    NotFound,
    WrongMagic,
    Corrupted,
    Io(std::io::Error),
}

impl std::fmt::Display for LoadError {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        match self {
            LoadError::NotFound => write!(f, "file not found"),
            LoadError::WrongMagic => write!(f, "wrong magic"),
            LoadError::Corrupted => write!(f, "CRC mismatch"),
            LoadError::Io(e) => write!(f, "io error: {}", e),
        }
    }
}

fn load_with_check(path: &str) -> Result<Vec<u8>, LoadError> {
    if !Path::new(path).exists() { return Err(LoadError::NotFound); }
    let f = File::open(path).map_err(LoadError::Io)?;
    let mut r = BufReader::new(f);
    let mut magic = [0u8; 4];
    r.read_exact(&mut magic).map_err(LoadError::Io)?;
    if &magic != MAGIC { return Err(LoadError::WrongMagic); }
    let mut len_bytes = [0u8; 4];
    r.read_exact(&mut len_bytes).map_err(LoadError::Io)?;
    let len = u32::from_le_bytes(len_bytes) as usize;
    let mut payload = vec![0u8; len];
    r.read_exact(&mut payload).map_err(LoadError::Io)?;
    let mut crc_bytes = [0u8; 4];
    r.read_exact(&mut crc_bytes).map_err(LoadError::Io)?;
    let crc = u32::from_le_bytes(crc_bytes);
    if crc32_simple(&payload) != crc {
        return Err(LoadError::Corrupted);
    }
    Ok(payload)
}

fn main() {
    let path = "/tmp/hh_atomic.bin";
    let data = b"Hello, Handmade Hero!";
    save_atomic(path, data).unwrap();
    println!("Saved {} bytes", data.len());

    let loaded = load_with_check(path).unwrap();
    println!("Loaded: {:?}", String::from_utf8(loaded));

    // 测试 not found
    match load_with_check("/tmp/nonexistent.bin") {
        Err(LoadError::NotFound) => println!("Correctly detected not-found"),
        _ => panic!("expected NotFound"),
    }

    // 测试 wrong magic
    std::fs::write("/tmp/wrong_magic.bin", b"XXXX....").unwrap();
    match load_with_check("/tmp/wrong_magic.bin") {
        Err(LoadError::WrongMagic) => println!("Correctly detected wrong magic"),
        Err(e) => println!("Other error: {}", e),
        Ok(_) => panic!("expected WrongMagic"),
    }

    // 测试 corruption
    std::fs::write("/tmp/corrupt.bin", b"HHSV\x05\x00\x00\x00abcde\x00\x00\x00\x00").unwrap();
    match load_with_check("/tmp/corrupt.bin") {
        Err(LoadError::Corrupted) => println!("Correctly detected corruption"),
        Err(e) => println!("Other error: {}", e),
        Ok(_) => (),
    }
}
```

## 8 · Rust / Arch 落地代码

完整工业级存档:

```rust
// Cargo.toml:
// [dependencies]
// serde = { version = "1", features = ["derive"] }
// bincode = "1"
// glam = { version = "0.29", features = ["serde"] }

use serde::{Serialize, Deserialize};
use glam::Vec3;
use std::fs::{File, rename};
use std::io::{BufReader, BufWriter, Read, Write};
use std::path::Path;

const MAGIC: &[u8; 4] = b"HHSV";
const SAVE_VERSION: u32 = 1;

fn crc32(data: &[u8]) -> u32 {
    let mut h = 0u32;
    for &b in data {
        h = h.wrapping_mul(31).wrapping_add(b as u32);
    }
    h
}

#[derive(Clone, Debug, Serialize, Deserialize)]
struct PlayerData { pos: Vec3, hp: f32, level: u32 }

#[derive(Clone, Debug, Serialize, Deserialize)]
struct EnemyData { pos: Vec3, hp: f32 }

#[derive(Serialize, Deserialize)]
struct SavePayload {
    version: u32,
    next_id: u64,
    players: Vec<PlayerData>,
    enemies: Vec<EnemyData>,
    timestamp: u64,
}

#[derive(Debug)]
enum LoadError {
    NotFound,
    WrongMagic,
    Corrupted,
    Version(u32), // actual version
    Io(std::io::Error),
    Bincode(bincode::Error),
}

impl std::fmt::Display for LoadError {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        match self {
            LoadError::NotFound => write!(f, "save not found"),
            LoadError::WrongMagic => write!(f, "wrong file type"),
            LoadError::Corrupted => write!(f, "CRC mismatch (file corrupted)"),
            LoadError::Version(v) => write!(f, "save version {} not supported", v),
            LoadError::Io(e) => write!(f, "IO: {}", e),
            LoadError::Bincode(e) => write!(f, "Deserialize: {}", e),
        }
    }
}

impl std::error::Error for LoadError {}

fn save_atomic(path: &str, payload: &SavePayload) -> Result<(), LoadError> {
    let bytes = bincode::serialize(payload).map_err(LoadError::Bincode)?;
    let crc = crc32(&bytes);
    let tmp = format!("{}.tmp", path);

    {
        let f = File::create(&tmp).map_err(LoadError::Io)?;
        let mut w = BufWriter::new(f);
        w.write_all(MAGIC).map_err(LoadError::Io)?;
        w.write_all(&(bytes.len() as u32).to_le_bytes()).map_err(LoadError::Io)?;
        w.write_all(&bytes).map_err(LoadError::Io)?;
        w.write_all(&crc.to_le_bytes()).map_err(LoadError::Io)?;
        w.flush().map_err(LoadError::Io)?;
        w.get_ref().sync_all().map_err(LoadError::Io)?;
    }
    rename(&tmp, path).map_err(LoadError::Io)?;
    Ok(())
}

fn load(path: &str) -> Result<SavePayload, LoadError> {
    if !Path::new(path).exists() { return Err(LoadError::NotFound); }
    let f = File::open(path).map_err(LoadError::Io)?;
    let mut r = BufReader::new(f);

    let mut magic = [0u8; 4];
    r.read_exact(&mut magic).map_err(LoadError::Io)?;
    if &magic != MAGIC { return Err(LoadError::WrongMagic); }

    let mut len_bytes = [0u8; 4];
    r.read_exact(&mut len_bytes).map_err(LoadError::Io)?;
    let len = u32::from_le_bytes(len_bytes) as usize;

    let mut payload_bytes = vec![0u8; len];
    r.read_exact(&mut payload_bytes).map_err(LoadError::Io)?;

    let mut crc_bytes = [0u8; 4];
    r.read_exact(&mut crc_bytes).map_err(LoadError::Io)?;
    let stored_crc = u32::from_le_bytes(crc_bytes);

    if crc32(&payload_bytes) != stored_crc {
        return Err(LoadError::Corrupted);
    }

    let payload: SavePayload = bincode::deserialize(&payload_bytes).map_err(LoadError::Bincode)?;
    if payload.version != SAVE_VERSION {
        return Err(LoadError::Version(payload.version));
    }
    Ok(payload)
}

fn load_or_default(path: &str) -> SavePayload {
    match load(path) {
        Ok(p) => {
            println!("Loaded existing save: {} players", p.players.len());
            p
        }
        Err(LoadError::NotFound) => {
            println!("No save found, starting new game");
            SavePayload {
                version: SAVE_VERSION,
                next_id: 1,
                players: Vec::new(),
                enemies: Vec::new(),
                timestamp: 0,
            }
        }
        Err(e) => {
            eprintln!("Load failed: {}, starting new game", e);
            SavePayload {
                version: SAVE_VERSION,
                next_id: 1,
                players: Vec::new(),
                enemies: Vec::new(),
                timestamp: 0,
            }
        }
    }
}

fn main() {
    let path = "/tmp/hh_save_safe.bin";

    // 第一次:不存在
    let mut payload = load_or_default(path);
    payload.players.push(PlayerData { pos: Vec3::new(5.0, 0.0, 5.0), hp: 100.0, level: 1 });
    payload.enemies.push(EnemyData { pos: Vec3::new(10.0, 0.0, 10.0), hp: 30.0 });
    payload.timestamp = 12345;
    save_atomic(path, &payload).unwrap();
    println!("Saved to {}", path);

    // 第二次:存在
    let loaded = load_or_default(path);
    println!("Loaded: {} players, {} enemies, ts={}",
        loaded.players.len(), loaded.enemies.len(), loaded.timestamp);

    // 测试各种错误
    match load("/tmp/nonexistent") {
        Err(LoadError::NotFound) => println!("\nTest 1 OK: detected not-found"),
        _ => panic!(),
    }
    std::fs::write("/tmp/bad_magic.bin", b"XXXXgarbage").unwrap();
    match load("/tmp/bad_magic.bin") {
        Err(LoadError::WrongMagic) => println!("Test 2 OK: detected wrong magic"),
        Err(e) => println!("Test 2 unexpected: {}", e),
        _ => panic!(),
    }
    let mut corrupt = std::fs::read(path).unwrap();
    if corrupt.len() > 15 { corrupt[14] ^= 0xFF; } // flip a bit
    std::fs::write("/tmp/corrupt.bin", &corrupt).unwrap();
    match load("/tmp/corrupt.bin") {
        Err(LoadError::Corrupted) => println!("Test 3 OK: detected corruption"),
        Err(e) => println!("Test 3 unexpected: {}", e),
        _ => println!("Test 3: loaded anyway (CRC too simple)"),
    }
}
```

## 10 · 工程反思

Day 666 传达的核心工程教训:**打包 / 发布 = 工程收尾的关键**。

新手以为"代码完就发布",资深工程师知道**"发布"是独立工程**——平台移植、签名、版本管理、CI / CD、auto-update、telemetry。每个都需要专门工程。AAA 游戏公司有"release engineer"职位,专门负责。

**Release pipeline**:

1. **Build**:多平台(Windows / Mac / Linux / Console)
2. **Sign**:代码签名(防篡改)
3. **Package**:安装包(MSI / DMG / DEB / RPM)
4. **Notarize**:Apple / Microsoft 公证
5. **Distribute**:Steam / itch.io / Epic Store
6. **Auto-update**:增量更新(只下载差量)
7. **Telemetry**:崩溃报告 / 玩家行为分析

每步都有坑。Casey 在 HH 演示最简(CI build + 单平台),工业级是数十人工程。

**Atomic operation(原子操作)**:

Day 666 的核心是"原子写文件"。Linux 用 `rename()`——原子替换。Windows 用 `MoveFileEx(MOVEFILE_REPLACE_EXISTING)`。

为什么需要原子?玩家在写 savegame 时断电,文件写到一半。如果直接 overwrite,文件损坏。原子写:

1. 写到临时文件 `save.tmp`
2. `fsync(save.tmp)` 强制刷盘
3. `rename(save.tmp, save.dat)` 原子替换

第 3 步是原子的——要么完成(save.dat 是新内容),要么没发生(save.dat 还是旧内容)。文件系统保证。

工业实践:**所有重要文件写都原子**。SQLite 用这个保证 ACID。Linux package manager(apt / pacman)用这个保证系统不损坏。

**CRC32 / 校验和**:

CRC32 检测文件损坏。玩家加载 savegame 时算 CRC32,和存盘时 CRC32 比对。不匹配 = 损坏。

更高级:**Merkle tree**——文件分块,每块算 hash,递归。BitTorrent / IPFS / Git 用 Merkle tree 验证大数据完整性。

**第二条教训**:**平台移植是发布难点**。

- **Windows**:MSI / EXE installer,代码签名
- **macOS**:DMG + notarization(Apple 强制)
- **Linux**:DEB / RPM / AppImage / Flatpak / Snap
- **Console**(PS / Xbox / Switch):SDK + 平台认证(NDA 限制)

**第三条教训**:**auto-update 是现代软件必需**。

- **Steam**:SteamWorks 自动更新
- **Mobile**:App Store / Play Store 自动
- **PC(自有)**:差量 patch(只下载变化的 bytes)

每个领域都有"发布流程"。Casey 在 HH 演示的是桌面游戏版本,但思路普适。

## N0 • 深度教学补充

### 核心概念重新梳理

Day 666 涉及的核心概念需要在多个层次上理解:

**第一层:直观理解**

新手第一次接触概念,需要建立直觉。例如 voxel collision 是"虚拟物体不能穿过虚拟墙"——这个直觉每个人都能从现实经验获得。

**第二层:数学理解**

把直觉形式化。collision = "两个几何体的体积有交集"。对于 AABB,这等价于"三轴投影都重叠"。

**第三层:工程理解**

数学正确不等于工程实现正确。要考虑:

- 浮点精度边界
- 性能(每帧 N 个查询)
- 内存(数据结构紧凑)
- 边角 case(无穷大、NaN、负数)

**第四层:工业理解**

工业级要再加:

- 多线程安全
- SIMD 优化
- 网络同步(多人游戏)
- 跨平台(Windows/Mac/Linux/Mobile)
- 可访问性(色盲友好)
- 反作弊

每层理解都让代码更鲁棒。资深工程师在所有层次同时思考。

### 实际工程的细节

工业代码 80% 是"边角 case 处理",20% 是"核心算法"。Casey 在 HH 演示核心,工业代码加大量边角处理。

**边角 case 类型**:

1. 空输入(空 Vec、null pointer)
2. 极端输入(NaN、无穷大、超大数)
3. 并发竞争(多线程同时访问)
4. 资源不足(内存满、磁盘满)
5. 网络异常(超时、断连、包丢失)
6. 版本不兼容(老配置 / 新代码)
7. 权限错误(只读文件、无网络)
8. 用户误操作(连点、撤销重做)

每个 case 都要单独处理。这是工业代码 50%+ 行数的原因。

### 优化思路

性能优化有顺序:

1. **算法**:O(N²) → O(N log N),最大提升
2. **数据结构**:Vec → HashMap / BTreeMap,常数提升
3. **Cache**:AoS → SoA,cache 命中提升
4. **SIMD**:4-16 元素并行,巨大常数提升
5. **GPU**:数千核并行,极致性能
6. **分布式**:多机器,无限扩展

每级提升都需要更复杂的代码。先优化低级,够用再升级。

- **完成 > 完美**:能跑 > 能优化
- **持续学习**:技术永远在演化

这些哲学跨技术领域通用。学完 HH,你不只会写游戏,你**理解工程**。这是 HH 最大的价值。
