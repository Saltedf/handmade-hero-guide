## 2 · 心智模型

### 类比:壁纸的图案

壁纸的图案有几种:

- **纯色**:简单,但单调
- **重复**(条纹 / 格子):有规律,工业感
- **半随机**(有机纹理):自然,温馨
- **完全随机**:杂乱

每种 pattern 适合不同场景。游戏 tile 完全一样:

- 地板:有机纹理(木板 / 石板)
- 墙:重复纹理(砖块)
- 装饰:半随机(植物)

**今天的 pattern 系统**让美术选择合适的 pattern。

### 严谨:Pattern 算法

#### 2.1 CheckerboardPattern

最简单:`(x + y) % n_variants`

```rust
struct CheckerboardPattern;

impl Pattern for CheckerboardPattern {
    fn select_variant(&self, x: i32, y: i32, n_variants: usize, _rng: &mut Lcg) -> usize {
        ((x + y) as usize) % n_variants
    }
}
```

**特点**:规则、可预测、几何感强。适合棋盘、tile-based 地板。

#### 2.2 StripesPattern

沿一个方向重复:`x / stripe_width % n_variants`

```rust
struct StripesPattern { stripe_width: i32 }

impl Pattern for StripesPattern {
    fn select_variant(&self, x: i32, _y: i32, n_variants: usize, _rng: &mut Lcg) -> usize {
        ((x / self.stripe_width) as usize) % n_variants
    }
}
```

**特点**:线性、连续。适合木板、地毯。

#### 2.3 BlobPattern

用低频 noise 决定区域:

```rust
struct BlobPattern { scale: f32, seed: u64 }

impl Pattern for BlobPattern {
    fn select_variant(&self, x: i32, y: i32, n_variants: usize, _rng: &mut Lcg) -> usize {
        // 用 sin 函数模拟低频 noise(简化版)
        let nx = x as f32 / self.scale;
        let ny = y as f32 / self.scale;
        let value = (nx.sin() * ny.cos() + 1.0) / 2.0;  // 0..1
        (value * n_variants as f32) as usize % n_variants
    }
}
```

**特点**:连续、有"团块感"。适合自然纹理(草地、岩石)。

#### 2.4 NoisePattern

直接 Perlin noise(或简化版):

```rust
struct NoisePattern { scale: f32, seed: u64 }

impl Pattern for NoisePattern {
    fn select_variant(&self, x: i32, y: i32, n_variants: usize, _rng: &mut Lcg) -> usize {
        // 简化 noise(实际用 perlin-rs)
        let value = simple_noise(self.seed, x as f32 * self.scale, y as f32 * self.scale);
        ((value + 1.0) / 2.0 * n_variants as f32) as usize % n_variants
    }
}

fn simple_noise(seed: u64, x: f32, y: f32) -> f32 {
    // 简化版:用 sin + 不同频率叠加
    let s = seed as f32;
    (x * 1.0 + s).sin() * 0.5 +
    (y * 1.3 + s).sin() * 0.3 +
    ((x + y) * 0.7 + s).sin() * 0.2
}
```

**特点**:最像"自然"。适合森林、自然地形。

### 2.5 Pattern trait

```rust
trait Pattern {
    fn select_variant(&self, x: i32, y: i32, n_variants: usize, rng: &mut Lcg) -> usize;
}
```

每个 pattern 实现这个 trait,WorldGenerator 不知道具体 pattern,只调用 trait method。

### 2.6 关联到 tile tag

```rust
struct WorldGenerator {
    patterns: HashMap<u64, Box<dyn Pattern>>,  // tag_hash → pattern
    rng: Lcg,
    assets: AssetStore,
}

impl WorldGenerator {
    fn gen_tile(&mut self, x: i32, y: i32, tag: &str) -> u32 {
        let candidates = self.assets.get_all_with_tag(tag);
        let n = candidates.len();
        if n == 0 { panic!("missing tag"); }

        let tag_hash = fnv1a(tag);
        let variant_idx = if let Some(pattern) = self.patterns.get(&tag_hash) {
            pattern.select_variant(x, y, n, &mut self.rng)
        } else {
            // 没指定 pattern,纯随机
            self.rng.gen_range(n)
        };

        candidates[variant_idx]
    }
}
```

**关键**:pattern 是可选的——某些 tile 用 pattern,某些用纯随机。灵活性高。

### 2.7 配置示例

```rust
fn setup_patterns() -> HashMap<u64, Box<dyn Pattern>> {
    let mut patterns: HashMap<u64, Box<dyn Pattern>> = HashMap::new();

    // 木地板:条纹
    patterns.insert(fnv1a("floor_wood"), Box::new(StripesPattern { stripe_width: 3 }));

    // 石头墙:团块
    patterns.insert(fnv1a("wall_stone"), Box::new(BlobPattern { scale: 4.0, seed: 42 }));

    // 草地:noise
    patterns.insert(fnv1a("floor_grass"), Box::new(NoisePattern { scale: 0.3, seed: 42 }));

    // 棋盘格(装饰)
    patterns.insert(fnv1a("floor_checker"), Box::new(CheckerboardPattern));

    patterns
}
```

每个 tile 类型选合适的 pattern,**视觉上立刻有质感**。

### 3.4 · 🦀 Rust 生态视角

Rust 的 pattern 表达:

#### 模式 1:trait + Box<dyn>(本日)

```rust
trait Pattern { ... }
struct WorldGen { patterns: HashMap<u64, Box<dyn Pattern>> }
```

灵活,但 dynamic dispatch。

#### 模式 2:enum

```rust
enum Pattern {
    Checkerboard,
    Stripes { width: i32 },
    Blob { scale: f32, seed: u64 },
    Noise { scale: f32, seed: u64 },
}

impl Pattern {
    fn select(&self, x, y, n) -> usize { ... }
}
```

无 dynamic dispatch。加新 pattern 改 enum。

#### 模式 3:closures

```rust
type PatternFn = Box<dyn Fn(i32, i32, usize) -> usize>;

struct WorldGen { patterns: HashMap<u64, PatternFn> }
```

闭包版本,灵活。

**Casey 选择**:模式 1(trait)。

```rust
trait Pattern {
    fn select(&self, x: i32, y: i32, n: usize) -> usize;
}

struct Checkerboard;
impl Pattern for Checkerboard {
    fn select(&self, x: i32, y: i32, n: usize) -> usize {
        ((x + y) as usize) % n
    }
}

struct Stripes { width: i32 }
impl Pattern for Stripes {
    fn select(&self, x: i32, _y: i32, n: usize) -> usize {
        ((x / self.width) as usize) % n
    }
}

struct Blob { scale: f32 }
impl Pattern for Blob {
    fn select(&self, x: i32, y: i32, n: usize) -> usize {
        let nx = x as f32 / self.scale;
        let ny = y as f32 / self.scale;
        let v = (nx.sin() * ny.cos() + 1.0) / 2.0;
        (v * n as f32) as usize % n
    }
}

struct Noise;
impl Pattern for Noise {
    fn select(&self, x: i32, y: i32, n: usize) -> usize {
        let v = ((x as f32 * 0.7).sin() + (y as f32 * 1.1).sin() + 2.0) / 4.0;
        (v * n as f32) as usize % n
    }
}

fn render<P: Pattern>(pattern: &P, w: i32, h: i32, n_variants: usize, label: &str) {
    println!("\n=== {} ===", label);
    for y in 0..h {
        for x in 0..w {
            let v = pattern.select(x, y, n_variants);
            print!("{}", v + 1);  // 1-indexed for display
        }
        println!();
    }
}

fn main() {
    render(&Checkerboard, 10, 10, 4, "Checkerboard");
    render(&Stripes { width: 3 }, 10, 10, 4, "Stripes (width=3)");
    render(&Blob { scale: 4.0 }, 10, 10, 4, "Blob (scale=4)");
    render(&Noise, 10, 10, 4, "Noise");
}
```

## 附录 · Wave Function Collapse(WFC)深度

Day 630 的 4 种 pattern 是基础。进阶有 WFC——2016 年爆款算法。

### WFC 原理

**问题**:给定一组 tile 和它们的"邻居约束",生成大网格满足所有约束。

**例子**:火车站 tile 系统:

- 直轨只能接直轨或弯轨
- 弯轨只能接直轨
- 不能有"断轨"

WFC 算法:

1. 每个位置初始可以是任何 tile(superposition)
2. 选一个"熵最低"的位置(候选最少)
3. collapse 它到某个具体 tile(随机选)
4. **传播约束**:邻居 tile 的候选根据规则更新
5. 重复,直到所有位置 collapse

### WFC vs Perlin noise

| 维度 | Perlin noise | WFC |
|---|---|---|
| 输出 | 连续值(0..1) | 离散 tile |
| 约束 | 仅"连贯" | 任意规则 |
| 复杂度 | O(N) | O(N^2) 最坏 |
| 灵活度 | 低 | 极高 |

WFC 适合"有复杂规则的场景",Perlin 适合"连贯连续值"。

### WFC 的应用

- **Caves of Qud**:roguelike 地图
- **Townsfolk**:城市生成
- **Bad North**:岛屿地形
- **Circuit Superplayer**:电路图

每个都用 WFC 产生"看起来手工设计"的场景。

### WFC 的局限

1. **慢**:O(N^2) 最坏,大网格跑几秒
2. **可能死锁**:约束冲突时无法继续
3. **难度调**:约束规则设计难

**优化**:Overlapping WFC(用样本图学习约束)、Tiled WFC(预定义约束)。

## 附录 II · Cellular Automata(元胞自动机)

Day 630 介绍的 pattern 中,还有一个值得深入:**Cellular Automata(CA)**。

### CA 原理

康威生命游戏(Conway's Game of Life)是最著名的 CA:

- 网格上每个 cell 是 alive(1)或 dead(0)
- 每代根据规则更新:
  - 活 cell 周围 2-3 个活 cell:继续活
  - 活 cell < 2 或 > 3 个活 cell:死(孤独 / 拥挤)
  - 死 cell 周围 3 个活 cell:复活

简单规则产生复杂模式(滑翔机、振荡器)。

### CA 在游戏中的应用

- **Caves of Qud / Dwarf Fortress**:洞穴生成。初始随机 + 几代 CA 演化 = 自然洞穴
- **Noita**:每个像素都是 CA cell
- **The Sims**:病毒传播 CA
- **Minecraft**:红石电路是 CA

### CA 的算法

```rust
fn ca_step(grid: &mut Vec<Vec<u8>>, rule: fn(u8, u8) -> u8) {
    let h = grid.len();
    let w = grid[0].len();
    let mut new_grid = grid.clone();
    for y in 0..h {
        for x in 0..w {
            let mut neighbors = 0;
            for dy in -1..=1 {
                for dx in -1..=1 {
                    if dx == 0 && dy == 0 { continue; }
                    let nx = (x as i32 + dx) as usize;
                    let ny = (y as i32 + dy) as usize;
                    if nx < w && ny < h && grid[ny][nx] == 1 {
                        neighbors += 1;
                    }
                }
            }
            new_grid[y][x] = rule(grid[y][x], neighbors);
        }
    }
    *grid = new_grid;
}

fn conway_rule(cell: u8, neighbors: u8) -> u8 {
    if cell == 1 {
        if neighbors == 2 || neighbors == 3 { 1 } else { 0 }
    } else {
        if neighbors == 3 { 1 } else { 0 }
    }
}
```

```rust
fn generate_cave(w: usize, h: usize, fill_prob: f32, generations: usize) -> Vec<Vec<u8>> {
    let mut grid = vec![vec![0; w]; h];
    // 初始随机填充
    let mut rng = Lcg::new(42);
    for y in 0..h {
        for x in 0..w {
            if rng.next_u32() as f32 / u32::MAX as f32 < fill_prob {
                grid[y][x] = 1;
            }
        }
    }
    // 演化
    for _ in 0..generations {
        ca_step(&mut grid, conway_rule);
    }
    grid
}
```

**效果**:随机噪声 + 几代 CA = 自然洞穴。比纯随机看起来"自然"。

### CA 的变体

- **Rock-Paper-Scissors**:3 状态循环克制
- **Cyclic CA**:状态循环演化,产生螺旋
- **Forest fire**:树 / 火 / 灰烬 三态
- **Sand falling**:粒子下落,产生沙堆

每种 CA 都解决不同问题。**核心都是"局部规则产生全局模式"**。

### Pattern 的"组合"

不同 pattern 可以组合:

```rust
struct ComposedPattern { a: Box<dyn Pattern>, b: Box<dyn Pattern>, blend: f32 }

impl Pattern for ComposedPattern {
    fn select(&self, x: i32, y: i32, n: usize) -> usize {
        // 50% 概率用 A,50% 用 B
        if simple_noise(0, x as f32, y as f32) > self.blend {
            self.a.select(x, y, n)
        } else {
            self.b.select(x, y, n)
        }
    }
}
```

组合产生更丰富的 pattern。比如 Checkerboard + Noise = "破碎棋盘",有规则但又不死板。

### Pattern 的"分层"

不同 scale 的 pattern 叠加:

- 大 scale:Blob pattern(区域划分)
- 中 scale:Noise pattern(局部纹理)
- 小 scale:Stripes pattern(微细节)

三层叠加产生"有层次的纹理"——类似真实世界的纹理(石墙有大区域 + 局部纹理 + 微细节)。

每个工具都是"pattern + 组合"的不同实现。**核心思想相同**。
